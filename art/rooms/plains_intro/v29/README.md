# v29 平原起步三房的实机画面

整房图由正式世界宿主按锁定绑定装配。采集相机覆盖房间文档的整个 `bounds`，隐藏界面，并按每世界单位一个像素单次渲染。P02 的下边界为 845.8593，最后一行也计入输出。P03 以竖图保留完整上下折返。

| 房间 | 整房 PNG | 触控录像所示路线 |
| --- | --- | --- |
| P01 风铃坡起点 | 1560 × 825 | 从倒地起身走向地上的枪，按互动拾取，在试枪台下跳起并向下开枪，登台开启宝箱、收足五枚金币。 |
| P02 田埂反冲教学 | 1650 × 846 | 从西门起步，反冲越过中央断口撞响钟台，返回低处，靠近草径后从根间向下进入 P16。 |
| P03 沟谷升坡 | 840 × 1710 | 从谷底西入口跳上散币石台，逐级爬到东侧转角后向西折返；经过守卫与上部折返后抵达左上旧路。 |

三段视频均从生产标题的「新游戏」进入。P02、P03 在当前独立新档实际取得 P01 地枪后，由正式宿主在各自的接收门装载，视频从门内开始。每房保存一段连续原速画面及引擎音轨，通过分别按下、拖动、松开虚拟手指操作正式触控面板。移动与攻击都使用正常控制器、碰撞和跟随镜头。环境为桌面 Godot 的手机横屏布局。

在仓库根目录运行下列命令。录屏需要可用的图形显示、项目锁定的 Godot、FFmpeg、Python 3 和足够的临时空间。无物理显卡时可以使用 X11 软件渲染。

```sh
for room in P01 P02 P03; do
  bash art/rooms/plains_intro/v29/record.sh "$room" /tmp/world-v29-review || break
done
```

脚本为每次运行创建独立的临时存档。每房输出 `*-overview.png`、`*-play.mp4`、`*-cover.jpg`。`*-sources.json` 记录锁包、房间文档与直接引用的美术文件指纹。整房图先核对世界包与正式文档的边界；视频在实际确认拾取、落点、奖励或通路后记录帧号，剪去镜头准备和退出段。[房间构图采集](overview.gd) · [触控动作及断言](play.gd) · [按帧导出](export.py)
