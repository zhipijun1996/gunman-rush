# P03 沟谷升坡

从 P02 进入时，玩家先沿谷底向东走。岩棚上连续的草缘勾出回头路，西侧背岩的位置贯穿谷底和上层两个视角。右肩的遮挡使两条路分开，首访沿开阔台面向西回到旧路，带着 W 回访时可以从岩腹下走到背面，蹬过石壁进入菌光龛。门、落点和回访奖励的位置由[正式房间](../../../production/rooms/world/P03.json)持有。

谷地共享 P02 的远景。后壁使用一张风化石灰岩原画，西侧与上层旧路相接，东侧延续到 P13 的接入段。前方岩面按正式碰撞轮廓取样，保留原生地形的草缘；接近门槛时逐渐露出两侧共用的材质。菌光取自区域像素库，分别长在通道地面、井侧岩缝和收藏台面。

原画身份、菌类和纹理来源、游戏资产哈希见[来源表](sources.json)。安装 Pillow 和 NumPy 后，在仓库根目录运行以下命令即可从原画与房间重建运行图。

```sh
python3 art/rooms/P03/bake_ravine.py
```
