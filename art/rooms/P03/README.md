# P03 沟谷升坡

西下田口、上方旧路和岩脊后的东壁龛分别接 d002、d003 和 d017。三处门线来自 v29 的 840 × 1710 沟谷。田口先沿草地向东，第一块石台可绕过沟底的小虫并停下拾取五枚散币。上行时，宽草肩留给玩家换向，中段的巡检机把横移与开火后退放在同一座稳定落台。田口上方那条向西的草路通往 P04。[正式房间](../../../production/rooms/world/P03.json)

沟谷中央的石台露出同一条分层石脊。西侧短台与低处仅有的一座勘测木栈承接失足的玩家。隔着岩脊可望见东侧的齿轮。要从谷底绕进岩脊与东壁之间的通道，使用已取得的壁跳能力上攀，方可到达壁龛、主动取走 TG02，再进入 P13 门侧。从壁龛也可落回沟底。

背景使用风铃平原的石灰岩原画。近处的风化面取自同一原画，跟随房间的实际碰撞轮廓，在草冠和三处门侧保留平原 TileSet。木栈背后的框架采自平原磨坊，石块和风草均来自平原。[来源与烘焙记录](sources.json)
