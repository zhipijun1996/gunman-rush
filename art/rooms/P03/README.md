# P03 沟谷升坡

从 P02 进入，谷底田埂小虫在两道矮坎间巡逻。玩家可从坎上看准它的方向，迎面开枪或跳过，随后在低路停步拾取散币。越过东侧几层天然石台后，空口露出对岸的长草缘，玩家要转身向西。起跳肩台和接人台之间留出一段完整天空，手机横屏上可以同时辨认出发边、空隙与落点。[正式房间](../../../production/rooms/world/P03.json)

上台东端留给玩家着地。失控巡检机守在台面西侧，抬炮后射出单发，再次瞄准前有一段恢复时间。玩家可以在平台东侧还击，也能等子弹过去后从它上方通过。落脚失误会回到下层石台或平坦沟底。更深处的东壁是另一条路线，从谷底风草后方能仰见岩层裂隙与龛内的齿轮，掌握壁跳后再上攀横移。

远处与 P02 共用天光，背岩连接西上的旧路与谷底。前方岩层按实际碰撞轮廓取样，边缘留给平原的原生地形。东龛的风草、石块与风化石缝都来自这条谷地。P13 接收段沿用相同的草石与背壁相位。[P13 接缝](../plains_intro/README.md)

原画身份、草石来源与运行图哈希见[来源表](sources.json)。在仓库根目录安装 Pillow 与 NumPy 后，可重建两侧画件。

```sh
python3 art/rooms/P03/bake_ravine.py
python3 art/rooms/plains_intro/build_ridge_backwall.py
```
