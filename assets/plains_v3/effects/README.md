# 平原战斗表现候选

AI 原始 RGBA 图集，共 12 个独立静态特效键：枪口、命中、钟械死亡碎片、金币闪光、跳跃、落地尘、右向弹体、左向反冲、跳跃补给、弹药补给、警告环、护盾破碎。没有真实逐帧动画；可由表现层缩放/旋转/淡出/粒子编排，但生命期、位置和事件消费必须沿用既有系统。

manifest.json 提供源像素区域、局部锚点、hash、方向与 alpha>=128 的可见范围；特效光晕保留真实 alpha。弹体向右，反冲向左，不能把图片方向当作攻击或位移逻辑。warning_ring 仅辅助材质，不替代实际动态攻击预告或危险碰撞。shield_break 是储备表现键，不表示新增护盾能力。
