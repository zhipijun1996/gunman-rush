# 平原敌人动作素材候选

风格锚点为 `assets/biome_style_review/windchime_plains.png`，对应用户场景示意图第1格。新增 PNG 为 image_gen 原创生成后直接复制，未重采样、裁改或覆盖原有20张 v3 源图。运行时通过 manifest 中的区域取样。

两张1536×1024图各包含6个不同姿态：甲虫两步行姿态、预警、冲刺、恢复、死亡；草籽哨兵两呼吸姿态、预警、吐籽、恢复、死亡。不是完整逐帧高帧率动画；受伤使用实际事件染色，不声称提供独立受伤帧。飞虫继续使用旧分件与程序旋翼，不声称新增手绘飞行动画。

`manifest.json` 记录每张图和每个区域的SHA、区域、实际可见边界与脚底锚点。身体朝右；表现消费者根据实际朝向镜像，脚底映射到角色本地 `(0,16)`。保持固定物种缩放，不能每帧自动适配同一方框，否则攻击姿态会被压缩。碰撞、攻击时序、伤害和移动不从图片推导。

验证命令：`python3 tools/check_meadow_enemy_art.py`；检查2个源图、12个不同区域、透明度、脚底锚点和Godot .85导入压缩。像素不同只证明不是重复复制；已人工检查姿态可辨，实际播放、镜像、合屏和手机可读性仍需运行验收。用户尚未确认本批视觉品质。
