# 共鸣蓄力回复表现

母版为正式默认角色 `motion_v1/motion_source.png` 首帧，脚底枢轴(168,242)、身体182px，运行显示44wu。生成源是以实际待机参考制作的8格透明图集；0和7为比例控制，1收臂、2聚气、3/4持续集气、5舒展释放、6收势。原始生成图保留在generated/player.png。

`tools/build_player_focus.py`仅按同一个46/311尺度nearest采样和脚底登记，输出80×64单格；运行同其他补帧乘44/46，不逐帧缩放、不旋转站姿。build.json记录源摘要、每格裁切与锚点。音频为同脚本原创确定性合成：1.04秒上行集气、0.55秒短恢复和弦，没有第三方录音。

WorldFocusHeal拥有接受／取消／提交后的表现，PlayerAuthoredPoses绘制独立姿态；GameAudio沿原有12声部池播放并按所有者停止。集气是向胸口汇入的有限光点，提交成功才向外释放；取消不播放恢复。消耗、恢复与存档事务保持原规则。参数和取消合同见[资源规范](../../../docs/bible/combat_and_recharge.md)。
