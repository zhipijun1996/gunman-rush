# 共鸣蓄力回复表现

母版为正式默认角色 `motion_v1/motion_source.png` 首帧，脚底枢轴(168,242)、身体182px，运行显示44wu。生成源是以实际待机参考制作的8格透明图集；0和7为比例控制，1收臂、2聚气、3/4持续集气、5舒展释放、6收势。原始生成图保留在generated/player.png。

`tools/build_player_focus.py`仅按同一个46/311尺度nearest采样和脚底登记，输出80×64单格；运行同其他补帧乘44/46，不逐帧缩放、不旋转站姿。build.json记录源摘要、每格裁切与锚点。音频与特效已由当前 [视听制作源](../../../assets/audio/vfx_renewal/README.md) 重制；`--audio-only`转交同一制作源，不再生成旧声音。

WorldFocusHeal拥有接受／取消／提交后的表现，PlayerAuthoredPoses绘制独立姿态；GameAudio沿原有12声部池播放并按所有者停止。集气使用交错收束弧、胸前亮核与细光点；成功后脚底光瓣展开，扁光带向上掠过身体，细星屑上扬。原双侧高气流、粗射线与八向放射已删除。集气空气／玻璃谐波在取消时停止，成功才发恢复落点与清亮双音；声部优先级80，可替换低优先级声部。消耗、恢复与存档事务保持原规则。参数和取消合同见[资源规范](../../../docs/bible/combat_and_recharge.md)。
