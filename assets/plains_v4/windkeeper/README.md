# 牧风者原创候选素材

风格锚点为 `docs/references/biome_style_board_1.jpg` 第一格：手绘草甸、旧橡木、暖黄铜、奶油白羊毛与苔绿。2026-10-10 使用 `image_gen.imagegen` 生成并逐图检查。源 PNG 原样保存；Godot 导入采用有损质量 0.85，原图不压缩或重绘。

`body_actions.png` 有六个有限关键姿态：站立、踏地前摇、低头冲撞、嵌角暴露、风车暴走、疲惫跪伏。不是完整逐帧动画；呼吸、状态过渡与旋转由表现代码补充。羊体本身只有风车背架，转子从 `parts.png` 独立绘制。

`parts.png` 包含可绕实际轮毂旋转的四叶风车、完整风铃核心、木支架、破裂风铃核心。生成器实际输出尺寸与均匀格子不完全一致，必须使用 `manifest.json` 的已量测裁剪与锚点，禁止直接按网格切图。

羊体建议共用 0.35 源像素比例，以脚底锚点对齐站立地面；姿态变化不应各自拉伸为同尺寸。轮毂以 rotor 的 anchor_px 为中心，建议约 0.19 比例。小核心可缩到约 20–26 世界单位，不以画面尺寸推导碰撞或暴露位置。颈侧、背部命中核心由 Boss 消费者定位。

校验：`python3 tools/check_windkeeper_art.py`。记录 SHA、RGBA、透明区域、各姿态区域/锚点与导入设置；碰撞、Boss 玩法、设备表现与用户画风认可分别验收。
