# 可复用视觉素材

本目录保留main中已有的源图、候选与素材；是否使用由当前代码消费者和本次任务决定。当前全局规范为 [Visual Bible](../../docs/bible/visual_bible.md)，制作从 [模块导航](../../docs/project/module_map.md) 定位实际表现入口。

[来源索引](provenance_index.json)记录原图、prompt、参考来源及文件身份。未知模型、工具参数和许可保持未知；历史Git链接仅用于追溯，不是当前验收或开发前置。使用具体素材时读取其相邻来源/许可，不加载整套实验记录。

角色源图与落脚位置见 [actors](actors/README.md)。概念图和paintover不作为实机证据；新的截图、录屏与审查报告写入build/或构建产物，交接记录本次实际结论和链接。
