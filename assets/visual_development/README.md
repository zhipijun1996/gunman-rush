# 视觉开发唯一入口

当前用户选择为 **B「雨釉与偏心」**。这是风格方向选择；母版、派生素材与游戏内组合仍是候选，不代表 G2、玩家认可或正式发布。这里是实验来源库，不能自动加入正式资产池。

新 worker 默认只读 [style_master](../../resources/visual_development/style_master.json)、[B1 母版](master/b1_master.png)、[B 方向板](proposals/b_board.png) 与[两个短制作范例](../../docs/evidence/visual_language/recipes.md)。具体任务再按需读该素材自己的 prompt、record 与测量数据，不加载全部 PR 历史。

[provenance_index.json](provenance_index.json) 统一索引原图、实际文件 SHA、prompt、参考来源、已有时钟与原始记录。未记录的模型、许可、工具参数、时间保持未知；相同字节原图的定位不能补造调用历史。旧记录中的“未批准”是生成当时状态，不能删改为当前已批准。所有商业许可仍未知。

母版内四格步骤是生成的教学示意，**不是四次真实编辑历史**。真实两次制作是 [value_block](props/value_block.png) → [material_pass](props/material_pass.png)；两次都未达到严格 atlas 格线，后来真实单物件生成 tree / shelter。失败候选保留，不以裁切或重命名冒称格线成功。

角色实际区域、脚底与缺陷见 [actors](actors/README.md)；环境家族的 record/family 按需读取。连续草地是独立背景候选，不是可行走地形或 G2 成功证据。概念迁移图、paintover 均不是实机截图；历史记录中的失败采集也不代表完整路线通过。
