# Generated courier body animation

Task UNDERWORLD-PLAINS-01, six-feedback rework. Two actual image-generation calls produced 20 distinct source RGBA body keyframes: run8 plus idle/rise/fall/land/hurt/death2 each. Original transparent PNGs and verbatim requests remain in `generated/`. Unknown model, token count and price are not invented. The reference is the project's previously generated Underworld courier, not a character taken from the publisher tileset.

`python tools/build_underworld_player_animation.py --check` reproduces both runtime PNGs and the real-consumer JSON without writes. The recipe records full source crops, one nearest scale per page and measured pivot/foot translations. No new character pixels are programmatically drawn; no single image is bobbed/squashed to claim several keyframes. The source image did not satisfy strict equal-cell layout/baseline instructions, especially state-page boots and the final prone scarf. That failed original generation layout remains recorded. The production consumer uses measured complete nonoverlapping figure regions, not equal cuts that clip the feet. Low-alpha source texels are preserved, not repainted or threshold-deleted.

80x64 is a padded canvas, not the body-height measurement. The derived idle's actual alpha>=128 body is 46px high, mapped to the shared `UnderworldActors.HUMANOID_HEIGHT` (44wu). Contact frames share source foot anchor y58; flight poses preserve their own foot lift. Standard standing opaque height is therefore 44wu; posed stretch/crouch/death heights naturally differ. Runtime uses legal horizontal mirroring around the body pivot for left movement.

`UnderworldPlayer` reads the actual Motor normal-velocity movement channel, retaining last locomotion facing at rest; pointing right cannot make an A-walking body face right. The weapon is a separate existing anchor-driven layer. `animation_receipt()` reads cached actual renderer state/frame/source pixel hash and the existing authoritative CourierVisual muzzle. JSON is read once in `_ready`; PNG hashes are not recomputed during `_process`.

The technical fixture drives actual Router/Motor movement, left/right, stop/reversal, opposed aim, accepted shooting and jump/fall/land. Hurt/death use explicitly submitted valid HealthState requests as lifecycle fixtures; no claim of natural combat. Pause freezes the actual actor and Motor. Cancellation/stale-health epoch counterexamples are included. Visual code does not alter collision, resources, damage or save rules. Component media lives under ignored `build/underworld_player_animation/`, identified as HEAD a44b856e + dirty component hashes; it does not relabel historical deployment F. Root will recapture formal/Home consumers after its next runtime freeze.

A recorded normal-rate 60fps real-rendered clip is not, on its own, user animation, audio, device, formal route or commercial-art approval. Original/native-size selected decoded frames were actually viewed; full-speed playback and listening are separate unverified steps in this component tool context.
