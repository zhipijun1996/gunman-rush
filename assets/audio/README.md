# Original windchime cue

`windchime_open.wav` is original deterministic modal synthesis generated by
`python3 tools/generate_windchime_audio.py`; no third-party samples, recording,
voice or music. Four decaying sine partials approximate a light brass chime.
22,050 Hz mono PCM, 0.85 seconds, −10 dB consumer volume, one voice per switch.
The audio is emitted only after an accepted projectile opens the switch;
pause/cancellation stops it. No looping music or background music was generated.
Web audio remains subject to the browser's user-interaction unlock policy.
