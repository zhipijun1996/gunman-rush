# 牧风者主动追压 · 声音候选 01

只用于 `WINDKEEPER-PRESSURE-01` 的正式新牧风者表现。32条短声音（21条基础声音及11个首招连段变体）均由保留的CC0金属、链条、石木、布料、风/叶片和铜铃录音加工，不使用正弦或随机噪声充当主素材，不生成或替换BGM，不改变主角受伤A或全局已选单项。

六种预警分别表现承重/双拍、深压弹簧、侧转叶片、帆面吸风、钟芯蓄籽和高抬肢体。重踏/落地/横扫/风压/风籽/踏台各有独立实际释放声；连招衔接是仍绷紧的短链布声，最终收招才松帆卸力。死亡拆成卡滞、躯干落地/叶片掉落和依次失声的末铃三层，由实际死亡事件推进。

`WindkeeperPressureAudio` 只订阅 Encounter 接受的 `windkeeper_*` 事件。状态观察不再次发声；命中短限频并让位给危险预告；单踏/双踏读取起手已冻结plan；所有双连/三连仅在第一招嵌入两/三拍铃标记，第二招不重复整组宣告，始终只占一个共享voice。沿现有GameAudio的12voice池，每个本Boss最多4条并发，优先挤出低优先反应，不抢主角受伤/死亡。无额外AudioStreamPlayer、循环床音或墙钟定时器。暂停/取消/卸载/health epoch切换清理本来源，死亡开始立即清攻击声、仅保死亡后续事件。

`_sources`保留原始输入或已审核的项目衍生原字节（`.gdignore`排除运行导入）。`sources.json`逐条记录作者、来源、许可、原文件/项目路径和SHA；风/铃/叶片沿原quiet-02实际衍生，原始录音SHA和加工配方链均保留，不宣称为新录音。CC0全文与源网页一并保留。

重建：`python3 tools/build_windkeeper_pressure_01_audio.py`。输出单声道44.1kHz/16bit、峰值不高于−6dBFS；配方、输入与加工器指纹见manifest。技术指标不能代签听感/疲劳、BGM混音或真机；听审以root录制的同源实际战斗原声为准。
