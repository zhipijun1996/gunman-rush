# ability-creator

## 适用任务

新增或实质修改H/W/D等移动／战斗能力、授予与能力锁。

## 操作

先更新该能力的数据规范和受影响的能力锁设计，再修改授予、配置与实现；状态和恢复条件写入正文，数值引用配置字段。

1. 从 `game/player/actions/`、`PlayerController` 和真实授予入口定位现有能力。读取动作入口中该能力的章节，以及目标地区能力门槛。
2. 写清可用状态、输入仲裁、次数／冷却、成功恢复与取消条件。能力只向唯一PlayerMotor提交运动；显示事件来自已接受动作。
3. 先完成一个真实输入切片，再验证地面／空中／墙面、移动参照、暂停／死亡／切图、授予／移除及回程。新能力影响地图准入时同步真实能力快照。

## 验证与交付

用 `all-weapons`、`weapon-feel` 或目标地区Motor专项中的相关检查，覆盖成功、失败和中断。交付能力状态表、授予代码、真实轨迹及教学／能力锁验证。

任务使用 [现有设计卡](../../../docs/templates/ability_design.md)。质量阶段、独立审查、证据与未验声明共用 [开发质量](../../../docs/development_quality.md)；验证选择见 [Harness](../../../docs/harness.md)，代码落点见 [模块导航](../../../docs/module_map.md)。

文档读取与维护顺序按 [AGENTS](../../../AGENTS.md)；只加载本专业任务涉及的圣经、数据和工作线。
