# animation-vfx

## 适用任务

人物、敌人、Boss、机关动作、过渡、射击反馈或动态视听表现。

## 操作

1. 定位实际表现宿主、接受事件与姿态权威；读取 [动画规范](../../../docs/animation_vfx_standards.md) 和该实体动作设计。
2. 用状态／进入／持续／退出／中断表确定身体、附件、武器、预警与命中帧；从一个连续样板验证脚底、枪口、转向和遮挡。
3. 效果按已接受事件与来源生命周期创建／取消；死亡、暂停、切图及回退清理旧视觉与声音，玩法结果仍归原状态服务。
4. 环境动态按空间层、风向和可读性设计，与scene-composer／audio-director协调统一节奏。

## 验证与交付

选择受影响的表现／武器／伤害／Boss专项，查看正常速度连续音画。交付动作表、运行素材与消费者、进入退出反例及性能观测。

任务使用 [现有设计卡](../../../docs/templates/iteration.md)。质量阶段、独立审查、证据与未验声明共用 [开发质量](../../../docs/development_quality.md)；验证选择见 [Harness](../../../docs/harness.md)，代码落点见 [模块导航](../../../docs/module_map.md)。
