# animation-vfx

按 Visual Bible 的正式人物、1wu 采样与 nearest 制作。身体动作、特效、声音和镜头消费已接受事件；表现不拥有运动、伤害、资源、随机流、保存、Q资格或冷却。

## 先定位

1. 从任务表、模块导航和对象规范找到真实入口及消费者。区分正式世界、仍有开发消费者的武器／道具与无消费者历史稿，先列本次效果清单。
2. 整理进入／持续／成功／中断／退出的身体、附件、武器、预告、命中和声音。碰撞不等于扣血，蓄力完成不等于事务成功，拖尾不等于保护仍有效。
3. 提取当前运行身体及真实显示变换作母版，检查头身、胸腹、四肢、脚底、枪口、朝向、重心及遮挡。不能用旧立绘、默认演示人形或统一总高度代替。

## 找参考和制作

pixelfx 的工具使用 Node 18+，GIF／MP4 另需 ffmpeg。入口及许可见 [项目适配](references/pixelfx.md)。

```sh
python3 tools/vfx/pixelfx.py setup
python3 tools/vfx/pixelfx.py list muzzle
python3 tools/vfx/pixelfx.py render impacts/hit-spark --all --gif
```

1. 用一句话定义功能、形状、主方向、颜色、关键帧和收尾；从上游选两三个近似效果，实际渲染后选择。
2. 优先调整 palette、seed、light 和效果自身选项。改编源码保存在 `tools/vfx/effects/`，工具同步到隔离制作目录的 `src/fx/gunman/`；不在 build 中保留唯一源稿。
3. 新效果或大改开放方向做3–5个不同形状／运动方案。渲染、打开逐帧图、看正常速度、修最明显的问题，至少三轮；这不是重复运行同一检查。保存最终源稿，删除废弃稿。
4. 先读隔离目录 `docs/AUTHORING.md`，遵守局部坐标、确定性种子、循环接缝与一次性效果结束为空。方向效果朝右，贴地效果以脚底为原点；烟、碎屑、亮芯分别有自己的速度和消失过程。
5. 在实际显示尺度检查：轮廓清楚、明暗分级、一个主焦点；亮芯短促，次级运动收敛。硬形状保持像素阶梯，软化留给少量烟／冷雾和光；不能靠满屏辉光、扩大粒子或统一光圈代替造型。

## 接入 Godot

- 短促且固定的效果优先离线图集；真实轨迹、光束端点、动态范围、状态外壳保留原生绘制。不要逐帧运行 JS 或上传像素缓冲。
- 导出保留帧时长、循环、尺寸、锚点、种子、源文件与上游 SHA。Aseprite JSON 需要转换，不能声称 Godot 会原生自动导入。枪口和地面原点不同；按实际可见像素校准。
- 普通透明导出会烘焙辉光并合并层次。前后遮挡或独立加光有实际需要时分别导出 back／front、color／light，不把合成图整张再作加法混合。
- 演示 `act` 只作运动参考。沿本项目接受事件同步身体关键帧，不从演示时序、动画结束信号或粒子碰撞施加伤害／停顿／击退。
- 按真实宿主取消和清理；验证受伤、死亡、暂停、设备切换、换武器、切房、恢复与回退。优先复用现有有界数组和实例上限，不新增每帧节点或全局随机调用；减弱特效保留必要预告和状态辨识。

## 验证与交付

```sh
python3 tools/vfx/pixelfx.py check gunman
python3 tools/vfx/pixelfx.py render gunman --all --gif
```

先在一处正式场景成立，再检查另一种明暗空间及连续触发。选择受影响的表现／武器／伤害／Boss专项，查看正常速度连续音画，核对未命中、拒绝、取消与结束反例。检查实例峰值、空闲开销及纹理占用；上游检查不能代签 Godot 合屏或实体设备性能。

交付效果清单、运行素材与消费者、来源许可、进入退出反例和实际检查。临时逐帧图、录像及日志写入 build/；长期规则维护在 [Visual Bible](../../../docs/bible/visual_bible.md)，实现与检查入口维护在 [模块导航](../../../docs/project/module_map.md)。
