# level-module-creator

## 适用任务

固定房间/Section内容制作与机关复用；名称保留兼容，不用于随机模块扩池。

## 操作

1. 以 schema 3 房间数据放置地形、机关与怪物，给每个实例稳定 ID。
2. 在 `production/` 的实际控制器、材质和机关消费者中检查入口、落点、信号与恢复。
3. 旧世界设计仅用于冻结平原的复现。

## 验证与交付

用真实Motor验证出返程、上下门落脚、镜头及状态；按任务区分结构与完整美术/遭遇。
