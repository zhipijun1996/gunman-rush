# Godot 房间美术

**整房先设计，正式镜头验收，玩法信息最清楚。基础缺陷由施工者修好后再交付。**

## 开工只读必要输入

- 仓库 `AGENTS.md`、当前工作线、目标房及直接邻房的场景／合同。
- 项目 [Visual Bible](../../../docs/bible/visual_bible.md) 和目标区域 Bible：持有现行设计规则，本技能只定义执行方法。
- 首次校准画风时读 [视觉基准](references/versioned-style-standard.md)，并查看 `assets/approved-five-regions.png`、`approved-tiles-and-props.png`、`current-plains-forest-v2.png`；以后按改动恢复对应参考。

先核实际加载入口、角色尺度、镜头和已接入资产；参考图或素材包存在不代表正式游戏已采用。房间坐标、进度、历史和具体参数留在项目源与当前交接，不写入本技能。

## 四步制作

1. **先构图。** 保存修改前整房图；用一句话确定场所。按[门口协作规则](../../../docs/bible/room_authoring.md)统筹本房全部出口及直接邻接，再结合路线、房形和角色，安排全房体量、明暗、景深、地标、前景宿主与光源。沿正式镜头检查入口、动作段、落点及出口；先让无装饰的大结构成立。关卡或轮廓不合理可调整，但须与关卡技能复验职责、能力要求、连接和失败恢复。
2. **再选材。** 以实际腔体、进入方向、像素密度和材质判断适配；适合才复用，缺件再绘。概念构图获认可不等于可替换正式tile或角色画法。门口连同接近平台、围合、门槛和内外纵深设计；有归属的前景才放置，普通悬台不默认加柱。
3. **按整体组装。** 先完成结构与景深，再细化构件、光照和运动；各阶段同机位比较。贴地实体保持世界坐标，独立景深有自己的地面与遮挡。几何变化后同步检查附着物、危险和两侧接缝。新增细节破坏构图时删减或重作。
4. **实际走查。** 默认一房闭环，相邻房验接缝；批量授权也逐房完成。用正式控制器、正常镜头与速度穿过本次受影响的路线并返回，检查不同高度和移动状态。发现下表缺陷先修复，再扩展；仅检查局部就只声明局部结果。

## 交付前六项检查

按本次影响选择检查项，在现有交接简记观察位置、结论和缺口，不另建重复报告；不能只写“已自检”。具体标准沿用 Visual Bible。

| 检查 | 必须看什么 |
| --- | --- |
| 接地与接缝 | 正常镜头近查可见脚底、基座、根部、梁底、平台端头；有无空隙、穿插、重叠或假支撑 |
| 入口连续 | 两侧正常镜头成对看，并实际往返；岸顶、净空、材料、室内外及进入方向是否一致、可辨 |
| 构图与材质 | 整房体量及沿途机位是否协调；换材是否有场所依据；新件有无突兀画法、比例或像素密度 |
| 玩法可读 | 带角色、怪物、弹道与危险观察动作过程；落点、预警、路线和交互是否始终清楚 |
| 光照合理 | 亮暗能否对应天光、开口或灯具；角色原色可读；移动与跨房时有无无来源的明暗跳变 |
| 景深与运动 | 镜头移动时有无漂根、露底、地平线跳变；云与地表分离，风与粒子可感知且不遮危险 |

整图检查构图，正常镜头检查细节，连续操作检查变化；三者互不替代。CI、可达性和截图产出不能证明视觉通过。
