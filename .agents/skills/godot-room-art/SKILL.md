# Godot 房间美术

**先完成一间实际房间的整体画面，再从成品提炼复用；区域套件不是制作前提。**

## 输入与职责

按需读项目AGENTS、当前工作线、目标区域／房间及直接邻接。设计圣经持有画风与玩法权威；本技能持有场景美术生产主流程。其它美术职能技能按职责提供输入或审查，不复制第二套制作流程。玩法、碰撞、机关状态与奖励归其现有所有者。

核实际加载入口、相机、角色、地形、已有定义和消费者，再看当前用户参考。历史画面只约束其实际获认可的内容；素材存在、旧技术通过和相对改善反馈均不自动成为本轮美术认可。涉及Underworld素材时按需读[基准](references/versioned-style-standard.md)，不要为保存旧大件或PNG牺牲当前整体。

同名云端与仓库技能有差异时，按项目AGENTS指定入口执行；注明未同步范围，不假称已回写云端。参数归实际配置／Definition，进度与试验结论归现有任务交接，不复制进本技能。

## 选择本次工作

| 任务 | 制作单位与通过范围 |
| --- | --- |
| 整房制作或重做 | 一间实际可装载房间；先完成地形、平台、建筑和角色的共同画面，再检查沿途镜头与实际动作 |
| 找方向或验证渲染 | 代表结构／固定机位原型；按[引擎前置](references/engine-first-2d.md)验证，不能据此承诺完整景深或量产 |
| 从成品提炼或测试复用 | 先有整体成立的实际房间，再按[可选复用实验](references/regional-kit-production.md)检验具体对象与目标；不默认要求区域套件或固定数量房型 |
| 使用已有素材制作房间 | 按本房需要选用已验证内容，补齐不适配部分；本房整体仍须成立，不以保存旧资产或提高复用率优先 |
| 局部修复或工程接入 | 整体仍成立、问题确为局部时只修相关风险，之后回看整屏；整屏被否决则回到布局、主素材或共享规则 |

区域套件只是可选且待验证的组织方式，不是所有房间的强制生产规则。无须先备齐区域资产族，也不预设普通房全靠套件、只有地标才可定制。是否提炼与复用，以成品画面和实际成本证据决定。沿项目已有目录、定义、组合和编辑流程绑定，不另建运行时库或房间格式。

## 制作主流程

1. **把参考转成决策。** 按[构图与选材](references/art-direction.md)指出空间轮廓、视线与明暗分组、细节密度和玩法面。明确具体素材的保留、改绘、弃用；“增加层次”和题材清单不足以指导施工。
2. **先确定引擎如何画。** 在真实视口与角色尺度下安排地形、主体、出口和前后关系，明确静态绘制、完整独立景深、运行时灯光／遮罩／水面与动态实体各自职责。以引擎实帧和材质母版约束生成；生成后仍核轮廓、尺度与通道，模型偏离时返工，不迁就其错误。
3. **先让本房整体成立。** 选一间有真实职责、地形、出入口和加载入口的房间，在同一正常镜头里共同设计地形、平台、建筑和角色；沿途机位仍须连贯。校准材质画法、像素密度、比例、明暗和连接，实际Terrain／Tile尽早入画；画法不适配时改对应母版，不用漂亮背景遮住异族平台。按本房需要制作或定制，不先做套件清单，也不把同一构件硬套不同空间。几何调整保留职责与连接，复验能力门、净空、恢复和邻接。
4. **按职责生产资产。** 需要独立运动／视差／破坏的素材从开始画完整，包含会露出的底座、边界和后方覆盖。静态连贯组画可保留；互补遮罩只证明同坐标受光分区，不能计作完整独立后景。可见像素尽量原样使用，再次生成属于重绘；缺失补画与可见部分改绘分开。真实角色和地形尽早合屏，概念图认可不授权更换正式画法。
5. **完成实际房间的检查。** 先审看静止整屏中地形、平台和建筑是否统一，再看整房、正常镜头、连续移动与必要效果开关。用正式控制器复验受影响的动作、危险和落点。单个漂亮窗口、概念图、独立构件或抽象夹具不能签收实际整房；引擎前置只帮助约束转译，不保证美术自然成立。
6. **从成品决定复用与扩展。** 本房整体成立后，才提炼确有共性的材质、接头、结构或表现配置。任务需要验证复用时再按[可选复用实验](references/regional-kit-production.md)检查目标空间、重复感与实际成本；失败可放弃该项复用，不强推成区域套件。已有有效素材仍可直接使用。授权整区制作时逐房完成其职责与画面、成对检查入口，不以单房、套件或样房数量签收全区。

制作者自行淘汰可见失败，记录继续、返工或未验证及具体位置，不把基础筛选推给用户，也不新增逐阶段用户审批。技术、视觉、复用、用户反馈、设备和部署结果分别记录。

## 实现检查与交付

按[质量与复用](references/quality-and-reuse.md)选择接地／接缝、入口连续、构图材质、玩法可读、光照及景深运动检查。正常镜头看细节、整房看体量、连续操作看变化；CI、逐像素回拼和可达性都不能单独证明美术通过。

交付当前范围的真实整屏、必要动态片段、同机位前后或意图／实机对照。保留源图、完整提示词、实际参考、裁切／烘焙、锚点、许可和哈希；资产、组合与房间的验证范围分开。否决方案不作正向基准，部署失败不写成线上已更新。媒体与源配置沿项目既有位置维护。
