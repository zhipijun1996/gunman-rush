# Godot 房间美术

**先证明整屏值得制作，再制作它的部件。旧素材、已投入工时和技术通过都不能保送构图。**

## 开工只读必要输入

- 仓库AGENTS、当前工作线、目标房及直接邻房的场景／合同。项目设计圣经与用户当前要求持有设计权威，本技能定义制作方法。
- 实际角色、地形材质、正式镜头，以及用户本次给的参考。历史样片只约束它实际获认可的内容，不能覆盖更新的否决或替代当前参考。
- 涉及既有Underworld素材时按需读[视觉基准](references/versioned-style-standard.md)并恢复对应样片；不把整套旧素材当成本房必须使用的清单。

先核实际加载入口、角色尺度、镜头和已接入资产。区分本次任务：整房视觉重做、已成立画面的局部美术修改、或工程接入。整屏已被否决时执行完整流程；只有整体仍成立且问题确为局部时才走局部修补。不要把用户说的整屏难看缩成接地、光照或裁切任务。

同名技能存在多个来源时，项目AGENTS指定的仓库版是本项目执行入口；外部版只提供未冲突的参考。发现陈旧来源，明确记录未同步范围，不假称已经更新云端。房间参数、进度与历史归项目源及当前交接。

## 制作与淘汰

1. **把参考转成决策。** 按[构图与选材方法](references/art-direction.md)记录：空间由什么轮廓形成、哪里吸引视线、明暗怎样分组、细节集中在哪里、玩法面如何识别。逐项指出当前图的差异和要删除／重作的东西。风格词、题材清单及“增加层次”不能替代这些决策。
2. **先确定引擎如何画，再比较方案。** 按[引擎前置的2D制作](references/engine-first-2d.md)，在Godot中固定实际相机、正式角色尺度与地形、结构轮廓和遮挡；提前划分静态绘制、运行时灯光／遮罩／水面及独立动态实体的职责。用实帧约束生成，不从一张包含全部光影的整图反推所有节点。整体重做时比较少量轮廓确实不同的全屏方案，不以保留旧地标为前提；把真实资源接回后的合屏作为可实现方案。若仍像完整道具并排、焦点互抢或动作面不清楚，淘汰布局或主素材；停止补根、加柱、贴草和加灯。已有明确方案依据时可只做一个方案，不为凑数量造图。
3. **验证材质能实现方案。** 用正式tile、角色和代表新构件在目标机位合屏。生成图只能是构图意图，不能用生成地面覆盖真实tile就声称接入完成。已有素材分别决定保留、改绘或弃用；不适配的完整大件不进入补连接件阶段。只有整体已成立且连接面明确时才补件。概念图认可不授权更换正式角色或地形画法。
4. **按预先分配的职责组装。** 每层、实体和地形有用途、锚点与遮挡；先连续结构和大小明暗，再细化。拆层优先保留可见像素；再次生成属于重绘，不能默认与原稿相同。遮挡后补画与可见部分重绘分开。确需新绘时携带引擎实帧、选定全屏和实际材质参照。静态绘制可以保留连贯组画；同一纹理的互补遮罩可用于受光分区，但不能宣称已有完整独立后景或可单独视差。分阶段同机位比较，主次或空间损失时回到对应阶段，不以新增装饰掩盖。贴地实体固定世界坐标，独立景深有自己的地面；普通悬台不自动加柱。几何调整须复验房间职责、能力门、恢复和邻接。
5. **分别作美术判断和工程验证。** 制作者先自行淘汰已知失败方案，再交付对照；不把基础筛选交给用户。静态合屏成立后再检查运动和正式路线；纯静态试验明确止于静态，不能宣称正式玩法通过。默认一房闭环、邻房验缝；批量授权也逐房重验。取证见[质量与复用](references/quality-and-reuse.md)。

每阶段只有三种结论：继续、返工、未验证。写明画面中可指出的位置和原因。这是制作者的工作判断，不新增用户逐阶段审批。技术结果、美术判断、用户反馈独立记录；制作授权不等于视觉认可。

## 通过整屏筛选后的实现检查

| 检查 | 必须看什么 |
| --- | --- |
| 接地与接缝 | 正常镜头看脚底、基座、根部、梁底、平台端头；有无空隙、穿插、重叠或假支撑 |
| 入口连续 | 两侧正常镜头成对看并往返；岸顶、净空、材料、室内外及进入方向是否一致可辨 |
| 构图与材质 | 整房及沿途机位是否保留选定方案；新件画法、比例、像素密度和换材是否有场所依据 |
| 玩法可读 | 带角色、怪物、弹道与危险看动作；落点、预警、路线、交互是否清楚 |
| 光照合理 | 明暗对应天光、开口或灯具；角色原色可读；移动与跨房有无无来源跳变 |
| 景深与运动 | 有无漂根、露底、地平线跳变；云与地表分离，风和粒子不遮危险 |

整图检查构图，正常镜头检查细节，连续操作检查变化；三者互不替代。CI、可达性和截图产出不能证明视觉通过。即使技术缺陷全消失，整屏仍可判返工。检查结果写现有交接，不另建重复报告。
