# Godot 分层组装

## 先核对版本和项目入口

读取 `project.godot`、当前房间加载方式、地形实际消费者及角色显示代码。依据实际版本选择节点和参数。旧森林样例与当前素材包的视差实现分别按各自源码核对；以下节点说明是项目扩展时可选的实现方式。

Godot 当前文档推荐 `Parallax2D`；`scroll_scale` 控制相对滚动倍率。支持该节点的项目可按独立层使用它。已有 `ParallaxBackground` / `ParallaxLayer` 或自定义位移时，先核对当前行为，再决定是否迁移。

## 图层与坐标

| 层 | 坐标与行为 | 检查重点 |
| --- | --- | --- |
| 远景 | 独立低倍率视差 | 低对比、边界覆盖与接缝 |
| 中景大结构 | 独立中倍率视差 | 空间轮廓、可见路线 |
| 地形与表面 | 世界坐标，跟随地形 | 可站立边缘与碰撞一致 |
| 角色、敌人、交互 | 项目玩法坐标 | 轮廓与战斗信息清楚 |
| 平台附着前景 | 与所属平台共享变换 | 根部不漂移，局部遮挡适量 |
| 独立近景 | 单独近景视差 | 镜头移动时不持续遮住关键对象 |
| 光与粒子 | 按作用范围与深度分层 | 遮挡、明暗和运动可读性 |

平台附着前景用平台本身或统一世界父节点定位，位移倍率1。叶尖摆动时保持根部固定，移动平台继承平台位移。独立近景另作一层：v2左右实例倍率1.08/1.12，基座放在主平台高度附近，保留完整低轮廓与透明外边，不要求占满整屏。

对独立近景使用世界坐标 `platform_band` 遮罩：优先按 `mask.surfaceY` 指定实际平台的世界上沿，未指定时才按素材位置选最近表面；多层房间应显式指定。样例上下带宽各72px、边缘渐隐8px，仅在靠地面的基座逐渐启用平台支撑/裂隙裁切，上部枝叶可以自然伸出。遮罩与素材分开变换，素材仍有独立视差。不要把整片植物按平台矩形硬切。

用 `heroReveal:{radiusX:30,radiusY:48,minAlpha:0.15}` 在角色附近做椭圆局部避让，半径30/48px、中心最低alpha0.15；按实际角色位置更新，保留其余近景的厚度。这些是样例起点，依角色和战斗空间调整。`mask.surfaceY` 是世界平台高度，不是地形图块的 `surfaceY` 顶饰偏移。

设置稳定的绘制顺序。用实际画面检查透明层、粒子、角色和荆棘的交叠。让远景底板、中景PNG与近景PNG分别可隐藏和独立移动；底板中画出的内部远近关系不额外算图层。检查相机所有允许位置；只有具备无缝边缘的背景才直接重复。竖井要检查纵向覆盖，长廊要检查水平接续。

## 像素处理

1. 以项目逻辑分辨率、角色尺寸和相机缩放决定素材最终尺寸。
2. 保留源图；将需要的尺寸变体按最近邻采样烘焙，记录切片范围、锚点、来源和显示尺寸。
3. 当前基准采用 1 世界单位对应 1 素材像素，地形格32px/32wu，实体图集原尺寸绘制，原角色身体高约44wu。640×360样例是局部取景；移植时先换算项目自己的单位与镜头。
4. 选择最近邻纹理过滤；避免无意的分数缩放和非等比拉伸。按原生比例放置，优先使用原生尺寸、水平翻转和检查过的朝向/尺寸变体；需要任意角度或新尺寸时预先烘焙并检查轮廓。最终精灵角点、相机显示偏移和视差偏移按同一网格处理。
5. 物理运动保留小数精度。需要吸附时处理显示节点，复核相机平滑和插值后的最终画面。
6. 清理实体素材的杂散透明晕边。v2生成实体和内角按alpha≥128烘焙硬边，先检查低alpha彩边的真实值；原项目地形有效半透明像素、雾、柔光及运行时遮罩按语义保留，不对所有图集统一二值化。
7. 分别检查像素网格与美术语言：最近邻缩放只能规范采样，材质密度、像素簇和轮廓仍需视觉挑选与修整。

缩略预览用于可读性检查，不能据此证明原生分辨率的像素正确；同时查看原尺寸或整数倍放大。

## 地形与荆棘

把地形碰撞与装饰层分开，复用项目的实体碰撞和伤害机制。v2以32px占格生成47邻接TileMap，整张视觉层统一减该材质 `surfaceY`；外置灰盒碰撞保持原占格，关闭TileMap自带碰撞。单独导入的 `.tres` 带完整32×32碰撞，接入时选一种来源。47资源和规范位序见 `autotile-47.md`。荆棘按地面、侧壁、倒挂分别设置附着面及伤害形状，保护安全落脚区和出入口，按正式角色体积检查接触。

美术轮廓与伤害形状共同表达危险边界。可以从透明图提取轮廓作为初稿，再依据角色体积、孔洞语义与容错调整；检查实际接触和复位行为。沿用项目已有的地形伤害、无敌和重生规则。

## 色调与柔光

全局画布色调可用 `CanvasModulate`；同一画布只设置一个整体调制来源。分层材质可使用各层调色或 shader，检查叠加后的实际明度。

局部柔光可用 `PointLight2D` 配合径向渐变纹理，中心亮、边缘渐透明。设置颜色、能量、半径与作用对象；按实际效果选择混合模式。地形、构件与附着前景共享局部光；角色和怪物的原色保护及随身补光按项目现行 Visual Bible 执行，与固定地标光分别控制。

将灯位贴合精灵中真正发光的菌褶、灯芯、炉口或裂隙。为地形配置 `LightOccluder2D` 并核对作用层，避免地形背面被穿透照亮。通过短接触影让脚底、灯座和构件接地；仅在实际实现并观察后声称大型构件也有投影。

自定义 Canvas/shader 光场使用浮点系数累加灯光，最终写RGB时才截断；允许局部灯能量大于1。保持受光面比原材质明亮，避免提前把每灯颜色截到1。保留同帧光照开关，原色状态仍包含素材本身画出的明暗。

最近邻只规范纹理采样。需要统一像素化灯光与效果时，核对实际低分辨率视口、输出缩放和效果采样；不要因纹理是nearest就推断光晕已经像素对齐。

## 风中光点

用统一主风向、轻微阵风和不同深度速度建立连续流动。给主层足够亮的像素光核，为少量光点配置短尾；将分布放在可见空气带。按画面面积调整数量与覆盖，避免粒子长期藏在树冠或地面后。

远、中层接受地形遮挡；近层保持稀疏，并保护角色、荆棘及关键落脚边缘。光核与短尾落在显示像素网格上。区分粒子暂停、隐藏和镜头移动，检查暂停/恢复与边界循环。

以最终显示尺寸检查可见性；当前每区参数从素材包 `study.json` 读取。旧森林三层实验见 `forest-sample.md`，其数量和速度仅适合旧视口。其它区域可用同一控制方式驱动孢子、火星或冰尘，但重新设计运动速度、方向和形状。

## 官方依据

核对日期：2026-11-06。使用时按项目版本复核相关接口。

- [Parallax2D](https://docs.godotengine.org/en/stable/classes/class_parallax2d.html)：视差滚动、倍率和重复范围。
- [2D Parallax](https://docs.godotengine.org/en/stable/tutorials/2d/2d_parallax.html)：分层与纹理覆盖、重复和定位。
- [CanvasModulate](https://docs.godotengine.org/en/stable/classes/class_canvasmodulate.html)：画布统一色调。
- [PointLight2D](https://docs.godotengine.org/en/stable/classes/class_pointlight2d.html)：基于纹理的局部光源。
