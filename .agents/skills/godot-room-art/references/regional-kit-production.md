# 从成品提炼复用：可选实验

## 适用范围

区域套件是待验证的复用假设，不是默认生产单位或所有房间的强制规则。本页只在整体成立的实际房间完成后，或任务明确要求研究复用时使用；常规制作按[主流程](../SKILL.md)先完成本房。保留现有文件路径供引用，不据名称赋予其已验证地位。

实验可以先测单件能力，但须如实标为局部实验，不能替代实际房间。既有资产不因本页成为禁用内容；选择以本房合屏为准。没有证据时，不预设普通房全部套件化、地标才可定制，也不预设每房专画整景。

## 提炼之前

先在一间实际房间里共同完成真实地形、平台、建筑和角色，核正常镜头、沿途画面、必要效果及受影响动作。单个固定机位、孤立拱廊、抽象几何夹具或一张概念图，都不足以证明整房或复用方法成立。引擎前置约束转译，不能代替整体画面判断。

从成品中指出具体可复用对象：某种材质、接头、构件、附着关系或表现配置。记录实际源、锚点、连接面、尺寸／方向与渲染职责，不先补一整套未被本房需要的资产族。保持原成品可恢复，避免提炼过程破坏已成立的画面。

| 候选对象 | 需要保持的实际关系 |
| --- | --- |
| 地形与平台材质 | 同族画法、像素密度、边缘、台底及转角接续；系统拓扑与材质画法分别判断 |
| 建筑或结构 | 实际跨度、端头、连接、前后关系；允许为目标房补件或定制，不任意拉伸或堆重复构件 |
| 独立景深 | 完整轮廓与会露出的后方、镜头覆盖和深度身份；同图受光分区不等于独立背景 |
| 表现配置 | 环境明暗、实际灯源、遮挡、风与水的适用条件；不靠通用效果掩盖材质冲突 |

运行仍沿现有Definition、组合、资源清单与房间数据。纯贴图、实体、机关和怪物保留各自分类与状态所有者；不新增另一套注册协议，不因图片创造碰撞。嵌套、尺寸与覆盖能力以真实消费者为准。

## 按具体假设验证

明确想复用什么、用于哪个实际目标、可能节省什么，以及可能损失什么。跨度、方向或遮挡有风险时，选择对应目标检查；横向通道、竖井和宽厅只是可选样本，不是固定配额，也不要求任何房间制作都先通过多房型测试。

- 保留同一批候选源与已成立房间作对照，实际移动镜头、显隐必要图层，检查接续、露底、重复感、焦点和玩法面。
- 核角色、平台、地形与建筑在目标房是否仍统一；逐层独立、资源引用一致或脚本通过均不足以证明画面好看。
- 需要补件、改画或专属遮罩时如实记录。专属内容可以服务目标房，但不能据此宣称该部分已通用；也不为提高复用率牺牲整体。
- 记录真实新增、共享修改、逐房修补及制作成本。未测人工时间就不宣称工时下降；共享改动须复看受影响画面。
- 实际几何改变时复验正式控制器、落点、恢复与相邻连接；美术实验未覆盖的功能继续标未验。

结果可为继续复用、补齐有限变体、保留为单房定制或放弃提炼。单件失败不推导所有复用都无效，单房改善也不升级为整个区域可量产。保持技术结果、视觉判断、成本和用户反馈分开。

## 扩展边界

只在实际成立的范围使用候选对象，其余空间按本房需要制作。套件不是扩大制作的唯一前提；扩展仍取决于真实房间、路线与当前任务范围。每个目标房检查整体和沿途机位，相邻房成对核入口，不把同一结构重复摆放视为已经形成不同场所。

进度、失败实例和实验结论归现有任务交接，不把单次结果写成长期通用规则。明确授权整区时，仍持续完成其全部房间与串联检查；局部实验或套件引用不能签收未完成内容。
