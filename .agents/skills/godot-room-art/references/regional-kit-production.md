# 区域套件与跨房型生产

## 生产单位

以区域共享的材质、结构家族、独立景深、组合关系和受光方式组织套件，在完整房间中联合设计。普通房引用套件完成布局，重要入口、地标和剧情空间按职责定制；不默认每房生成一张专属整景。

套件是工作组织，不新增一套房间数据或万能节点。沿现有Definition、组合、资源清单与编辑目录落地。已有组合能展开成员与稳定身份时直接复用；其实际支持的嵌套、尺寸和覆盖能力以代码为准。没有消费者的参数不得写成已支持功能，也不能用整房脚本补齐每个新实例。

## 从完整场所决定最小资产族

先选同区具有真实职责的样房及有差异的验证几何，安排路线、入口、体量、前后关系与角色。读当前参考，确定主材质、像素簇、明暗与细节分布。已有认可材质可作起点，但必须在实际合屏验证；旧素材不适配时明确弃用或改绘。

| 资产／组合 | 要解决的问题 |
| --- | --- |
| 地形母版 | 主体、边缘、内外角、接缝及危险表面的同族材质；拓扑、画法与碰撞分别管理 |
| 结构族 | 墙、桥跨、端头、入口、必要支撑的接合、比例、受光与遮挡；不能只是一组独立道具 |
| 景深族 | 完整远景、中景和近景，明确世界附着或独立深度、可露出的边界与镜头覆盖 |
| 表现配置 | 环境明暗、真实灯源、遮罩、风和水面的职责与实际能力，不重复烘焙／计算同一效果 |
| 独特场所 | 在共享语言内设计重要地标与特定入口，不要求普通通路都堆强地标 |

从已选空间确定所需跨度、方向和尺寸变体。连接面、锚点、可重复中段与端头在制作前明确；有语义的破损边和洞口不能靠翻转／旋转冒充另一方向。未制作的覆盖范围应记录缺口，不靠运行时非等比拉伸或整图放大补齐。

空间组合把实体、饰面、景深、附着和灯位的关系一起校准。各成员保留自己的分类与状态所有者：静态实体归地形，纯贴图归表现，能触发／响应的行为归机关，怪物归既有怪物库。组合不凭图片创造碰撞，不复制机关／奖励状态。

## 用引擎约束资产生产

在样房中先固定实际镜头尺度、地形、角色、组合接口和动态职责，再按engine-first-2d生成。生成时提供实际输入与材质母版；核对结构，禁止用生成偏移反向修改正确的碰撞和连接。

独立素材从开始绘制完整轮廓与必要遮挡区域，不把整幅画任意截成不完整植物或背景。固定组画可以用于定制场所、静态背景或原型；同一张画的受光分区不能自动升级成可独立移动的景深套件。按asset-contract保留完整来源与真实消费者映射。

先在一间实际样房中校准结构、材质和光照，再扩充端头／变体。新件破坏整体时改母版、形状家族或组合关系；不要为保住不适配大件给每房补根、补柱、补灯。

## 复用验证与可继续条件

按当前风险选择不同几何，例如横向通道、竖井和宽厅。这里的房型是验证例子，不是所有任务固定配额；至少须有实际不同结构暴露跨度、纵向覆盖或遮挡问题。保留同一批关键资源和公共组合；允许换布局、选已定义变体和参数，不为每间样房重画完整背景。

在正式入口／控制器和实际镜头范围内检查：

- 地形、平台、危险和角色可辨，入口与落点安全；美术适配引起的几何变化复验合法动作、恢复和邻接。
- 横向、纵向和返回移动无露底、漂根或地平线跳变。逐层隐藏／恢复，确认独立层具备真实完整轮廓与覆盖。
- 不同跨度下端头、中段、墙顶与台底接续成立；像素簇、比例、材质密度和明暗仍属同一家族。
- 灯位贴合可见光源，实际遮挡、受光分区和必要水面在不同机位成立；没有这些功能时明确未实现，不拿静态画出效果替代。
- 相同资源可以直接引用，局部覆盖不复制整套配置。若每房都需要专属遮罩、坐标硬编码或连接补画，应重新判断共享组合能力与素材完整性。

出现共享缺陷时回到母版／组合修复，再看受影响样房；本房焦点或空间比例问题回到本房。技术通过、美术判断、跨房型适用范围和用户反馈分别记录。一个固定机位或一张完整底图没有证明复用；套件可复用也不代表整区每房已经验收。

## 扩展与迁移

仅在已验证范围内按区域逐批适配现有房间。保留已确定的房间职责、能力门、状态身份和连接；几何与素材能力不匹配时协同调整局部轮廓并复验，而非冻结任意灰盒或强行塞图。普通房以引用、布局和适用参数为主，少数独特空间保留定制制作。

从可装载的房间批量出正式尺度机位和连续整图，检查重复构图、入口接续及共享缺陷。批量截图只帮助筛选，仍须实际查看与操作；未编写房间、未测设备和未测来向不能计入通过范围。不得把本流程或套件清单的存在写成已完成批量美术迁移。
