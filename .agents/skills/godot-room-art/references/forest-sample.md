# 森林样例：根洞里的旧风铃

这是早期森林实验的历史记录。继续制作16区 Underworld 素材时，以 `versioned-style-standard.md` 与技能内五区认可画面为基准；本页用于追溯旧风场、分层和固定布局实现。不要把本页的1024×576视口、风点数量或旧整屏结构直接应用到当前样例。

## 定位样例

完整配套包将本技能放在 `skills/godot-room-art/`，将独立工程放在 `forest-room-demo/`。这两个目录位于同一个解压根目录。技能被单独安装后，使用用户提供的样例路径或在当前工作区定向查找 `forest-room-demo/README.md`。

只有技能时，先看随附 `assets/forest-reference.webp` 和本页参数；继续使用当前项目的素材与房间入口。需要复现原样例时再取得配套工程。

## 样例实际包含

- 16 种环境源素材及项目角色；像素图集共 56 个尺寸变体，数量包含角色。
- 三张大背景/前景层、五块地形、平台附着植物、四处荆棘、风铃与局部柔光。
- 可分层查看的网页场景、四阶段截图、6 秒动态视频，以及独立 Godot 工程。
- `previews/asset-contact-sheet.png` 只展示最初 12 件小素材。

查看 `README.md`、`PIXEL_ASSETS.md` 和 `SOURCES.md` 获取运行、像素及来源说明。保留这些来源信息；本包不另行赋予第三方素材开放许可。

## 参数起点

这些是该样房的实际参数。新房先核对角色、镜头和空间，按需要调整。

| 项目 | 当前值 |
| --- | --- |
| 逻辑视口 | 1024 × 576 |
| 世界宽度 | 1600 |
| 显示网格 | 1 世界单位 = 1 逻辑像素 |
| 角色身体高度 | 约 44 逻辑像素 |
| 场景视差 | 远景 0.18，中景 0.48，独立近景 1.22 |
| 平台附着前景 | 与地形同坐标；镜头相对位移倍率 1 |

| 风点层 | 数量 | 光核 | 水平基础速度 | 不透明度 |
| --- | ---: | --- | ---: | ---: |
| 远层 | 12 | 2 × 2 px | 24 px/s | 0.44 |
| 主层 | 20 | 3 × 3 px | 48 px/s | 0.74 |
| 近层 | 8 | 3 × 3 或 4 × 4 px | 80 px/s | 0.88 |

风从左向右略向上；主、近层使用奶白亮核。少量光点有 5 / 8 / 10 px 渐淡短尾，主、近层尾迹厚 2 px，另有一像素淡光边。近层保护角色、荆棘和落脚上沿。主层种子集中在 y=178–406 的空气带；该坐标仅适合本样房。

## 复用前需处理的样例假设

- `scene.js` 固定房宽、地形、装饰、角色、风铃与镜头；它导出布局，尚不读取任意新房间布局。
- `godot/build_scene.py` 用固定五个地形名称与数组 `zip`，超过五块会漏生成；另有角色、灯光和相机固定位置。通用化时按数据完整生成。
- `godot/room.gd` 当前使用固定水平镜头范围；竖井需适配纵向范围。
- `bake-assets.cjs` 接受 `--layout`，仍使用固定森林源文件、`layout.bell`、角色尺寸和大背景尺寸。使用其它区域素材前调整输入映射。
- 三张大图尚未证明支持任意拼接和平铺；巨型根拱门受当前横向构图限制。
- 荆棘碰撞从不透明外缘提取，填充内部孔洞并忽略小于 3 平方像素的碎点；按实际危险语义复核。

## 复现入口

进入 `forest-room-demo/`，先检查所需工具是否可用，再运行对应命令。普通查看 Godot 场景无需 Node 或 Python；导入 `godot/project.godot`，按 F6 运行房间。

| 操作 | 入口 | 依赖 |
| --- | --- | --- |
| 网页查看 | 浏览器打开 `preview-template.html`，需要时用本地静态服务 | 浏览器 |
| 四阶段截图 | `node render-preview.cjs --all` | `@napi-rs/canvas` |
| 六秒风场视频 | `node render-wind-video.cjs` | `@napi-rs/canvas`、FFmpeg |
| 导出布局 | `node render-preview.cjs --dump-layout previews/scene-layout.json` | `@napi-rs/canvas` |
| 像素烘焙 | `node bake-assets.cjs --layout previews/scene-layout.json` | `sharp` |
| 单文件网页 | `node build-preview.cjs` | `sharp` |
| 重建样例 Godot 场景 | `python3 godot/build_scene.py` | Python 3；先保留手工编辑副本 |

按当前任务调用其中需要的入口。配套包保留各脚本使用的相对路径；独立原图、像素图集与运行工程均可继续编辑。
