# 引擎前置的2D制作

本页用于确定可实现的绘制职责与验证转译，不保证画面自然成立。整房任务按[主流程](../SKILL.md)先完成一间实际房间中地形、平台、建筑与角色的共同画面；从成品提炼复用仅按需进入[可选实验](regional-kit-production.md)。固定机位连贯组画可用于原型或定制空间，但受光分区不能当作完整独立景深库。

## 生成之前

先用正式引擎和相机保存实际灰盒：真实地形、正式角色、主要结构与出入口。不要用生成图里近似的地面和人物代替。固定本次画幅、世界坐标、像素换算和必要轮廓；坐标、灯位及实例参数只归项目配置。

本房已有机关与真实地形、平台、建筑共同提供画法和尺度参照，标明安装点、运动范围与需要响应的部件。需要独立运动或切换状态的部件保留独立素材与真实消费者，不烘成不可分离的静态底图；只有装饰替身的画面不算机关合屏验证。

为画面各部分确定消费者：静态环境／建筑、真实碰撞地形、动态角色与机关、局部灯光及阴影、遮罩、水面。明确哪些明暗留在图中，哪些由运行时实现，避免同一灯光既画进素材又重复计算。静态环境可以保留连贯组画，不为图层数量拆开所有物体。

导出与同一灰盒同坐标的结构／受光遮罩和必要的保护区。带正式角色的实帧提供尺度；生产绘制输入可另隐藏动态实体，防止生成额外角色、机关或假平台。实际送入的参考、完整提示词及不可改变项必须保存。

## 生成与实际合屏

生成必须受实际灰盒、相机和渲染职责约束。给出参考不能保证模型遵守；查看轮廓、开口、地平线、动作带与局部光源位置。需要时用叠加观察。明显改动空间或新增假地形时返工，不把变化留给组装者补救。

先把真实地形、平台、角色与建筑合屏；只验证代表结构时标为局部实验，整房任务仍须回到实际房间与沿途机位。原始生图只是制作输入，不能把包含替代人物、替代地面的原图当作已验证目标。若实际材质承接不了效果，判断材质是否应重做，不能为了保存旧PNG牺牲目标；地形系统与材质画法分别评估。

## 组装与复核

可见像素尽量原样使用。按引擎既定遮罩划分同一组画的受光区域时，使用同一原生纹理和同坐标互补遮罩；关闭运行时效果后可检查回拼是否保持原像素。这只证明传输与遮罩忠实，不证明美术质量。

互补遮罩没有恢复被遮挡的背景，因此这些片段只能按共同坐标使用。需要独立视差、移动、破坏或相机露出背面时，必须先补全所需遮挡区域；不把同一整图重复裁切计作独立素材库。

逐项打开实际地形、角色、局部光、遮挡与水面，记录每一步的可见变化。水面先确定水位、反射取样对象和目标是否能出现在画幅内，不能最后再补一条通用暗色带。动态光检查开关前后受光范围及不该被照亮的远景；无必要的动态光可以保留为静态绘制。

最终判断仍看正常镜头下的完整画面。灰盒参考、像素回拼、节点存在和灯光开关都不能独立证明画面成立。只完成代表结构时，不声称已验证整房游玩、跨房、独立景深或其它房形。
