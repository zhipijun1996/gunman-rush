# 构图与素材设计

## 保持的视觉关系

先查看技能内已认可的五区 Canvas 拼装，再核对项目实际画面；把两类证据的适用范围分别记录。沿用角色比例、像素密度、轮廓处理、材质颗粒、远近对比和危险物语义。将区域变化落实到形状、材质、光和运动。具体标准见 `versioned-style-standard.md`。

| 设计层级 | 保持或决定的内容 |
| --- | --- |
| 全项目 | 角色比例、像素显示规则、玩法可读性、交互与危险语义 |
| 同一区域 | 主材质、形状家族、配色、背景结构、光线和环境运动 |
| 单个房间 | 路线、空间比例、视觉焦点、地标、前景位置和疏密节奏 |

普通通路允许安静、简洁；枢纽、区域入口与剧情房使用更强的独特结构。检查相邻房间的节奏与方向感。

## 房间搭建顺序

1. 用实际角色与镜头检查灰盒。标出可站立表面、视线、危险区和出入口。
2. 选择一个主形：贯穿空间的大树根、井壁、桥体、菌柱或机械梁架。让它解释空间如何形成。
3. 给主形、玩法层和背景建立明度关系。角色周围和动作通道保留安静背景。
4. 用结构件连接平台端部、墙面、台底与转角，使材质沿着地形生长。
5. 用小植物、石头、藤枝或碎件补充局部变化。按光照、潮湿、依附面等环境逻辑成组摆放。
6. 在少量位置加入前景，让前、中、后有交叠。检查整段镜头运动中的遮挡。
7. 放置地标和局部光，再加入可辨认的环境运动。

每一步都用真实素材合成观察。若大形、路线或焦点不清楚，先处理这些问题，再增加细节。

## 素材分工

| 素材 | 制作要求 | 复用方式 |
| --- | --- | --- |
| 地形结构件 | 平台端部、中段、台底、墙面和转角有一致材质 | 依据表面朝向、连接点和跨度组合 |
| 大型空间件 | 有明确轮廓，预留视线和通行空间 | 调整组合与位置；长廊、竖井采用对应接续件 |
| 表面装饰 | 明确底部或悬挂锚点，透明背景，像素密度一致 | 成组摆放，使用少量预制尺寸和适当翻转 |
| 危险物 | 地面、侧壁、倒挂都有可识别的尖锐轮廓 | 结合伤害区域与安全边缘组装 |
| 背景 | 低对比，覆盖镜头边界，接缝可检查 | 为需要的轴向设计接续或重复能力 |
| 地标 | 与区域叙事和房间职责关联 | 在特定房间使用，保留空间辨识度 |

AI 素材输入包含：已认可的参考画面、区域材质局部、目标尺寸、角色比例、朝向、连接面、透明度需求及具体用途。输出后检查轮廓与锚点；把通过的素材保留为后续参考。

原始大背景可用于确定氛围。用于多个房间时，检查其中哪些部分可独立组合、哪些构图已经固定。用独立中景与稀疏近景构件建立真实可移动层，保留平台附着前景。新增结构件优先覆盖实际遇到的地形缺口。

针对v2景深，画完整、有自然收尾的低轮廓植物、碎岩或构件组合，四边保留透明余量；不要从大画面截出带矩形断面的枝叶充当前景。将其根部/底座放到主平台高度附近，再用轻微视差与基座遮罩表达距离。保持上部轮廓完整，缩短或补画尺寸变体时保持原始比例与像素密度。

平原、森林背景重绘保留各区材料与光源关系，同时重新处理空间主形和动作带留白。以 `region.background` 显式选择版本；背景表可同时保留旧图和新候选，不能因为文件已参与样例而把它记录成用户认可。

## 跨区域设计

从 `region-catalog.json` 按正式 ID 取目标区域。区分仓库已有的身份/剧情信息、用户已认可五区方向和本轮扩展材质；只有对应字段改变时才调整该部分。

先确定主材料如何形成边界，再决定构件、附着物和光源。例如让萤雾沼泽使用湿泥炭、芦苇和旧闸，风蚀峡谷使用横层砂岩与斜桥，回声矿井使用矿岩、木支护和轨道。保留同一套细像素完成度、安静内面、局部受光和角色比例。

让16区的轮廓可区分。使用不同的空间主形，避免所有房间都依赖一个相同大小的拱门；允许同区普通通路采用安静构图，重要入口再使用独特地标。
