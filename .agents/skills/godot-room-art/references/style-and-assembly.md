# Underworld 区域美术与拼装基准

项目现行 `docs/bible/visual_bible.md` 是优先级更高的规则；这里是可操作的制作方法。当前稳定风格锚点：`underworld-regional-v1`（2026-11-07 用户认可五区 Canvas 方向）。`v2-47-depth-expansion` 是素材扩展版本；平原、森林重绘背景尚属候选，不自动变成用户已认可标准。

**尺度：**正式地形原生32×32px／32wu，世界表现 1wu 采样、nearest；原样例角色身体约44wu，迁入主项目以真实角色资源和相机为准，不把样例640×360改成正式视口。显示像素可取整，物理保留小数精度。

**材料：**同样的细像素簇、安静深色腹部、稀疏草沿或材料受光细边。根据区域改变根土、菌岩、泥炭、砂岩、冰岩、石雕、金属砖基、玄武岩和黄铜构件；避免每个表面铺细碎噪声、粗厚描边或不同尺度的像素。

**47邻接：**16区域各47合法八邻接（共752格）；掩码N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128。只有相邻两条直边同时存在时才保留对角位。现有 v2 工具按掩码升序把47格排入 8列×6行、每格32px 图集；预留1格透明。其余15区由九宫格供体与每区4个真正内凹角供体组成；不能把九格复制命名成47格。新素材要检查洞口、单格、薄平台、竖柱、T形与十字。

**景深：**独立远景低速低对比，中景负责建筑/植被地标，玩法层保持准确碰撞和站立轮廓。贴平台前景与其宿主同世界倍率；独立近景优先高度接近平台、左右末端自然收细的完整物件，可用约1.08～1.12的轻微视差与基座遮罩，不硬拉伸到统一宽高。遮罩surfaceY是平台世界高度，不等于图集中的像素surfaceY；相机范围变化时另验覆盖接缝。

**光影：**多层共享环境色，定向日光与局部实物灯光叠加；光核对准灯具实处，地形能挡光，灯座与角色接地有短阴影。角色、弹道、危险区优先清楚。亮度控制避免硬环和漏光。

**质量：**先大形、后材料、再图层、最后灯光与运动。原图、裁切bbox、透明度处理、锚点、许可和源图哈希需要与正式资产同存。横向/竖向/低顶分别实测，静图不能证明不同房型复用。验证实际运行与用户视觉认可分别记录。

样例文件若已接入：`art/world-art-v2/study.json`、`assets/pixel/manifest.json`、`assets/terrain47/manifest.json` 与 `region-catalog.json`；使用这几个实际版本，勿把本页作第二份数值源。
