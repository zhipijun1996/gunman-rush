# 房间动作与怪物遭遇

## 一句动作命题

写明：玩家面对什么可见局面，选择什么射向/时机/目标，反冲到哪个落点，结果带来什么下一步机会，失误后处于哪里。机关或战斗房再写清这一枪改变的环境/敌人状态。

地形动作房可以只改变玩家位置与可用动作；机关房分别验证弹丸作用和反冲位移；遭遇房允许合理站射、走位或绕行，让反冲提供实际优势。

承担反冲通行的关键环节应有普通动作无法替代的空间关系。接受另一种合理的反冲解法，不用射击次数、检查点计数或指定回放顺序解锁通路。

## 让动作产生后续局面

通常围绕一个主题发展少量连续判断；短教学可以只有一拍。每拍记录“看见何种差别 → 改变哪个决定 → 得到何种结果”。基础练习可重复节奏，进阶内容应让前一枪影响后续时机、目标、射向、弹药或落点选择。

可以探索长横跨接抬升、低檐换射向、移动落点接离台、击中目标后空中续枪、攻击后撤接越敌换边等关系。根据地形与敌人实际规则组合，变化不以坑数、枪数或平台数量计。

## 先决定主要压力，再布怪

分别观察地形精度、战斗威胁、时机和失败代价；压力来自同时发生的要求。

| 场所 | 默认处理 | 观察重点 |
| --- | --- | --- |
| 复杂连续障碍/精密移动落点 | 给读地形和动作留空间；可在准备区或完成后的宽落点安排遭遇 | 自由追击、远处弹幕是否侵入必须专注的动作段 |
| 普通穿越/宽平台/缓坡 | 主动考虑轻遭遇 | 敌人是否使玩家改变瞄准、进退、跳跃或落点 |
| 战斗空间 | 用地形提供可读退路和换位机会，再安排敌人协同 | 攻击覆盖、预警、收招与反冲落点是否匹配 |
| 探索支路/奖励接近 | 按收益、发现感和回程安排遭遇 | 战斗是否遮住线索、是否重复堵住回程 |
| 初次机关观察/地图辨认/对话/休息 | 保留必要安静 | 玩家能否看清联系、读信息、恢复控制 |
| 命中续枪的专门动作 | 把敌人作为明确、可读的动作目标 | 击败后再试是否仍能通行或返回 |

复杂平台与战斗可以有专门组合，但先分别教过、给足空间并验证失败恢复。以实际同时激活的威胁决定数量和组合，不规定每房怪数、怪物比例或强制战斗门。

## 给每只敌人一个空间作用

选怪前写清它会改变玩家的哪一个决定：

- 逼近：迫使玩家选择攻击后撤、越敌或绕到另一层。
- 封线：改变接近角度、开枪时机或落点；保留可读的避让空间。
- 空中目标：提供不同瞄准角度，命中可能形成下一次反冲机会。
- 可打断威胁：让玩家在移动避开和主动射击打断之间选择。
- 落点争夺：让玩家权衡先清理、从另一侧进入或换落点。

实际演算开枪后的反冲去向。敌人可以改变通路的使用方式；只延长清怪时间的布置应重排。普通战斗中的反冲价值允许表现为速度、站位、节奏或连贯性，不必把每只敌人做成跳跃开锁题。

检查巡逻边界、悬崖处理、攻击射线、弹丸寿命、激活范围和归位路径。让预警在镜头中可见，进门、第一次落脚和失败返回时有辨认威胁的机会；邻段敌人不能无意中持续覆盖狭窄重试点。

## 从能力包络做几何

使用当前真实控制器测普通满跳、短跳、土狼时间、不同射向反冲、冷却、接地补枪、命中回枪及该阶段合法能力。关键跨距同时考虑角色宽高、净空、运动相位和弹丸碰撞。

枚举所有可站立面：起点岸边、低层、坡中、台阶、梁顶、平台两端、敌人附近与各来向入口。检查普通连跳、等台、从低层前进再抬升、梁顶绕行及反冲替代路径。

对关键障碍保留目标反冲的可操作余量。镜头下看到目标和落点后才能要求判断；沿项目统一缩放校准地形，不通过逐房缩放或修改基础物理掩盖问题。

## 把失误设计成局面

按用途选择：

| 恢复方式 | 要达到的效果 |
| --- | --- |
| 就地重组 | 落地补枪，换一种反冲回到主路 |
| 返回当前拍 | 从低层回到可再次处理当前挑战的位置；恢复路没有独立绕过核心体验的前进出口 |
| 分步完成 | 分多次落地/反冲解决相同目标，用可观察步骤换取较低操作压力 |

检查已经杀怪、已经开门、误停平台、从另一侧进入之后的恢复。敌人若提供必需的空中回枪，至少验证命中后失败、清怪后重入和漏枪落地。用可见地形或项目正式重试规则解决资源问题。

本阶段可取得的目标在失误或清怪后，仍应能重试，或经符合反冲主题的替代路线抵达。能退回入口只证明没有软锁，不能代替目标可重新挑战；远期能力预览按其合法阶段另验。若重试依赖正式休息周期，核对往返成本是否适合本房用途，不把长途重跑当默认恢复。

沿项目保存合同处理普通跨房、休息、死亡、地形失败与重启；保持敌人、门、奖励的正确寿命。房间脚本不偷偷刷怪、回血、补弹或重置机关来完成演示。

## 三个实验案例的用途

以下名称是本轮实验别名，不用于替换或推定现行世界的房号映射；案例支持这些局部认识，不代表整区已验收。

| 案例 | 可复用的认识 | 使用边界 |
| --- | --- | --- |
| P22 引渠 | 接受下层直接反冲上岸；把单动作扩展到不同空间条件 | 近似顶点开枪的三拍仍是基础练习；水纹/风车不等于风力机关 |
| P26 内廊 | 分别检验召回、反冲登台、开闸和抬升；失败后保留机关状态 | 允许先停台或利用运动台；不强制指定射铃次数 |
| P25 果园 | 真实命中返还的一枪在同次腾空使用；死亡目标不封死重试 | 连续换向属于已学回枪后的进阶；分步反冲也是正常解 |

使用这些认识设计新关系。重新核实当前物理和镜头，按正式世界接口施工；实验的坐标、尺寸、缩放、伤害和独立 runner 不属于本方法的固定参数。
