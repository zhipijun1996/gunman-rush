# 区域编排

## 区域契约

从当前世界输入确定本区房间、连接、已授予能力、永久目标、NPC/休息/Boss/奖励身份。区分首访、获得本区能力后、带外区能力回访三种路线；按实际规则使用其中适用的阶段。

用一段话写区域体验：玩家在这里主要学会或运用怎样的反冲关系；环境怎样改变方向、时机、目标或落点；区域的安静与紧张如何交替。将剧情目标、远景地标和空间路线联系起来。

继承当前世界的连接与身份。局部地形、房间体量和施工门位服务体验，同时满足跨房接缝和资格；需要改变宏观拓扑时按任务授权调整唯一源。

## 全区职责表

为当前范围的每个房间保留一行，复用现有对象字段。最小信息为：

| 字段 | 内容 |
| --- | --- |
| 房号/分区/路线 | 身份与主线、支路、回环位置；直接邻接引用 |
| 来向与阶段 | 首访入口、已知动作、合法能力；不同来向的差别 |
| 主要职责 | 穿越、遭遇、探索、枢纽、休息、剧情、奖励、Boss等主职责；标出主线必经的反冲学习/运用节点 |
| 体验句 | 玩家看见什么，作什么决定，完成后得到什么机会 |
| 地形与遭遇 | 主要空间关系、机制和敌人承担的作用；空白段的用途 |
| 压力与恢复 | 主要压力、舒缓位置、失误实际去向 |
| 目标和回访 | 收益/剧情/能力预览/捷径及永久状态引用 |

只给复杂动作或关键状态补详细合同，避免每个过渡房都生成长策划案。实现进度仍由项目任务表管理，职责表只持有内容设计与必要链接。

## 沿实际路线安排节奏

先建立能完成区域目标并返回的路线，再补支路与回访。根据玩家可能走的顺序检查：

- 初见机制有可观察准备；第一次尝试允许理解结果；随后改变一项主要条件；在后续熟悉空间里再组合。
- 沿首访主线核对反冲从学习到运用的连续性；若核心推进问题都能用普通走跳与站射解决，应调整必经空间关系。安静房、普通遭遇和自由探索仍按各自用途判断。
- 在需要不同判断的挑战之间安排轻战斗、探索、地标观察或休息。舒缓房可以无敌，普通穿越也不必永远空白。
- 比较连续几房的输入节奏、移动方向、目标类型和空间展开。若都像“跑到边缘—顶点开枪—落宽岸”，调整其中承担进阶职责的房间。
- 对承担变化的连续房，不能只替换宽平台上的怪物物种；若实际处理仍是站射后继续走，重新组织接近角度、反冲落点、目标/出口或回路关系。基础练习与舒缓按既定职责保留。
- 让一段完成后的落点成为下一机会：新射线、制高点、分支入口、近路或前方状态预览。
- 在Boss/强挑战前提供整备和辨路，之后提供真实胜利、目标领取与有意义的后续出口。

用路线和体验判断节奏，不规定每隔几间必须打怪/休息，不套统一难度百分比。简易段也可让熟练玩家流畅穿过，进阶技巧提供更连贯或更灵活的解法。

## 探索和回访

给岔路可辨认的目的：看得见的收集物、人物、地标、路线连通、可预览的能力门或不同环境。世界数据规定的奖励和身份保持唯一。

让玩家在进入支路前获得足够线索，能判断风险并退回。隐藏内容用地形、声音、构图或环境线索引导，保留发现感。

对已开启的捷径和回环，检查它是否降低回程成本、连接熟悉地点，以及从另一侧看是否认得出来。保持敌人周期、门状态与奖励领取一致；回访的体验变化来自能力、路线和永久状态。

对枢纽分支分别设计方向辨识和近期目标。只有高难远期预览的分支，不能代替初访就有意义的探索选择。按世界要求安排重要地标的首次露出与再次看见，不靠强制说明文字承担空间叙事。

## 房间体量

先安排观察位置、动作包络、落点、下一问题和恢复，再决定边界。普通镜头遵循项目统一尺度，必要时用合法边界和前瞻策略调整信息。

横跨、纵向绕行、局部回环和多层空间可以有不同尺寸。大房的各段有用途，小房负责清晰的单一体验。房内相近空间若只有空跑，缩短或加入有效遭遇/探索；避免为“更大”延长失败返程。

## 制作顺序

1. 完成全区职责表、能力阶段与关键路线。
2. 根据未验证风险选择少量代表内容：一种新空间关系、一种新机制或一种新遭遇。已有可靠内容直接复用其规则和实现。
3. 把代表内容接入正式房间接口，验证它与邻接的来向、状态和镜头，再落实其余房间。
4. 以连通片区分批制作，持续比较相邻房间的重复和压力；复杂跳跃、普通战斗、探索与枢纽分别按职责判断。
5. 完成整个授权范围的房间、跨房路线和回访。代表房只承担校准，不取代整区交付。

迁移到其他区域时，更新能力阶段、环境规则、敌人和子区域语言；保留这个顺序，重新设计动作关系，避免给平原几何换皮。
