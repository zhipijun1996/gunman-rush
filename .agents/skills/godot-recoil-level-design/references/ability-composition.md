# 多能力组合与区域迁移

## 规则放在哪里

共用 Skill 持有设计与验证方法；目标区域 Bible 定义空间、生态、主要动作及协同能力；能力对象规范定义行为、恢复和参数；世界源定义实际授予、房间资格与连接。制作时只读本区和相关能力。gunman-rush 从 `docs/data/abilities.md`、`docs/bible/player_mechanics.md`、`docs/bible/combat_and_recharge.md` 及模块导航定位真实消费者。

区域无需一一对应新能力，同一能力可在多个区域用不同空间关系展开。平原以基础反冲主导；其他区域可侧重牵引换向、延后抬升、墙面转换或受保护的反冲穿越。反冲通过与新动作协同保持项目特色，不要求每间房使用全部能力。

## 先按来向确定能力

从真实路线取得玩家进入每个房间/Section 时的能力，不能仅按区域序号假定“到这里一定全会”。区分进入某区的最低资格、深入主体的资格、房内奖励支路的资格，以及带后续能力回来时的状态。

将以下信息并入现有房间合同，不另建能力数据库：

| 信息 | 需要明确的内容 |
| --- | --- |
| 可用能力 | 各合法入口/阶段实际已授予的能力、上游已介绍的用法，及本段相关资源 |
| 最低通行组合 | 哪些能力必须同时有，哪些组合任选其一；沿用世界条件 |
| 主要动作与协同 | 本段最重要的判断，以及其他能力如何改变其起点、目标、射线、时机、资源或落点 |
| 允许解法与回访 | 首访合理替代、新能力后的近路、可提前看见但暂不可取的目标 |
| 恢复 | 消耗与恢复事件、失误落点、目标消失后怎样重新完成当期目标 |

## 让能力相互改变条件

用实际状态串联动作：第一动作完成后，第二动作获得了什么原来没有的条件？例如反冲先离开遮挡，钩索才有射线；钩索踢离后，反冲把身体送向另一侧；额外跳跃延后到侧窗下方再用，改变高度与下一枪的方向。这些是关系示意，必须按当前控制器确认能否接续。

若只是把两段无关的单能力题首尾相接，标作分段练习；承担组合进阶时，让切换产生实际依赖。不要用固定操作次数或输入顺序强制“演出组合”。先让玩家理解单项结果，再改变条件、加入协同，最后在已知关系上形成进阶路线。

按动作分工选能力，不按列表凑齐：

| 动作 | 可用于组织的判断 | 需要读取/验证的边界 |
| --- | --- | --- |
| 反冲 | 射击与身体反向运动，攻击后撤、换边、接续 | 弹药、射向、爆发取消、冷却及真实命中 |
| 钩索 | 从锚点牵引接近，横向/斜下借力，踢离后换向 | 真实射程与射线、目标类型、发射资格、踢离/停留/取消 |
| 额外跳跃 | 延后抬升、越低檐后起跳、修正落点和延长决策窗口 | 实际剩余次数、恢复事件、与反冲的切换，不默认速度叠加 |
| 墙面动作 | 转换接近方向、利用墙面继续上行或重组动作 | 真实离墙/重贴与成功动作，有效新攀附立即恢复次数，持续贴住不重复触发 |
| 反冲保护 | 在合法保护窗口内穿过相应威胁，再找到安全落点 | 当前保护对象、实体碰撞、触发资格、落地条件、冷却和结束时机 |

敌人既可施压，也可能是合法牵引或命中恢复目标。必须查它是否支持对应交互，允许玩家先清理时也检查路线；不把任意敌人当作永久锚点。复杂多能力切换已构成主要压力时，沿房间与遭遇方法控制额外干扰。

## 区分能力锁、练习和高效路线

正式能力锁用于控制世界资格：缺少所需组合时不能越过对应边界，预览有退路；取得后可通过并返回。声明为能力锁的对象必须同时检查数据条件和真实几何，不能仅靠按钮拒绝来冒充动作障碍。存在任选其一的合法组合时，移除一种能力仍可通过可以是正确结果；全部合法组合均不满足时，才要求不能跨过门槛。

动作练习与主题遭遇用于学习和运用，合理替代解是否保留取决于本房职责。高效路线可以让某组合更快、更连贯或更有利，同时允许其他合法走法。不要把“推荐用钩索”自动写成“没有钩索必须无法通过”。

回访时，新增能力使旧挑战更容易、出现近路或改变接近角度，可以是成长回报。只对仍须保留的世界门槛做防绕过检查，不为维持旧难度全面封死新能力的合理用途。

## 验证真实组合

从真实来向和资源状态执行整段，记录各动作接受/取消、消耗/恢复及落点；不能把各能力单测成功或最大距离之和当作组合成立。恢复只恢复已授予资格，弹药、跳跃次数、钩索资格、慢时资源与保护资格按各自主人处理。

按风险选择最小充分的状态：当前最低合法组合、被允许的替代组合、会影响门槛的后续能力、一次关键失败恢复。无需遍历所有能力与装备的笛卡尔积。

对正式能力锁，保留其他已授予动作，移除所需能力/组合做相关反例；对纯反冲环节仍用关闭反冲的对照。对保护能力只移除保护，保留基础位移，再核对允许穿越与仍然危险的对象。具体碰撞矩阵、落地资格和计时从现行能力规范读取，不把“无敌”当成所有危险与实体都能穿过。

分别走首访、取得能力后、后期回访，以及失误/清怪/重入后的相关路线。缺少正式实现时先完成最小能力或接口适配，再验证组合；不要调试授予尚未取得的能力来通过首访。

Q的冷却约束按目标项目的能力合同执行（gunman-rush入口为 `docs/data/abilities.md`）：需要保护的动作接在可停留等待处后的第一次反冲，不能在连续空中链中途卡冷却。
