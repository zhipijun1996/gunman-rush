# 风铃平原应用

先读项目现行 `docs/bible/regions/windchime_plains.md`、世界输入和相关物种/机关规范。本页提供应用方法；房号、连接、能力取得、NPC、Boss、奖励和数值从当前项目提取。

当前项目采用 PR141 附件 v07.1；从 `docs/data/world/README.md` 查询现行来源。P-R01—P-R35 全部在范围内，原 P-R03 单房教学已拆为草坡、车厢、引渠、候车棚、望站坡，教学记录不锁门。不要恢复旧五房环路或旧地图计数。

## 从现行规范取得输入

- 从平原 Bible 提取核心动作、学习方向、子区域的空间/生态用途和整体情绪；不在此维护第二份主题表。
- 从当前世界摘要取得全部 P 房、Section、来向、目标、能力门、永久捷径与跨区邻接。把 Bible 的空间语言对应到真实位置，不为了凑类别新增分区或平均分配房型。
- 从动作和资源合同核实首访基础动作与回枪，再按真实授予区分获得本区能力后、带外区能力回访的路线。未来能力预览与当期可完成目标分别记录。
- 从当前场景和服务消费者核实小站、修钟、NPC、Boss与奖励的实现程度，保留当前身份和明确缺口。

## 落到职责表与具体房间

沿 [区域编排](region-planning.md) 标出首访必经的反冲学习与运用节点，并为普通遭遇写出反冲的具体收益。将旧路回望、地标再次看见、支路返回和能力后新用途落到真实连接。

逐房应用 [房间与遭遇](room-and-enemies.md)，回答四个问题：

1. 当前子区域的地貌或设施改变了哪一个决定？若只换材质/命名，继续调整空间关系。
2. 根据 Bible 的学习方向，本房是在初见、练习、变化还是组合？玩家从哪些前房已经理解所需动作？
3. 本房主要压力来自哪里？普通宽地的敌人有什么作用，精密连续段如何避开无意的外来干扰，安静段承担什么用途？
4. 本阶段目标在失误、清怪及重入后是否仍能完成？正式能力预览的退路与可重试挑战分别验证。

机关需求先对照对象规范和实现。传动线、支撑和铃状态应显示实际规则；风力、水位或时序需要参与通行时，先在授权内容范围内完成最小机制实现与验证，此前不能按有效运动规则出题。实测动作后再将碰撞、视野和承载约束交给美术。

## 现有敌人的选用线索

从 `EnemyFactory`、`EnemyBehaviorRegistry` 和对象规范核实当前行为，再选择空间。以下是已核对实现的定位线索，参数仍归正式 Definition：

| 行为 | 适合制造的判断 | 需要核对的场地条件 |
| --- | --- | --- |
| `patrol` | 简单瞄准、攻击后撤、越敌换边 | 巡逻边界与首见距离 |
| `charger` | 预警、进退、换层、收招窗口 | 够宽的冲锋带与合理归位 |
| `hopper` | 判断锁定落点后换位 | 宽阶地、跳跃与归位路径 |
| `diver` | 空中瞄准、横向避让、换边 | 俯冲前可见，回旋空间足够 |
| `sentry` / `fan_sentry` | 读射线和弹道后接近 | 同时覆盖和弹丸寿命，不跨段压制精密连跳 |
| `root_bell` | 避开地面标记或射击打断 | 当前实现依赖同层宽实体地面，不直接放在单向窄枝台 |

旧 Demo 的数量配置或模块上限仅用于原消费者，不当作完整平原的配额。每间房说明选怪理由与可反制空间；沿路线渐进介绍再组合。

## Boss与整区完成

从世界取得Boss位置、胜利身份、能力与唯一奖励，从对象规范取得招式与反制，再按 room_authoring 核对整备、入场、封门、战后出口与返回。

以现行世界源中全部 P 房为覆盖范围，逐房核对职责与实际场景；验证首访主线、分支返回、获得能力后的回访、跨区边界预览和永久捷径。发现尚未定义的正式剧情/装备内容时，保留身份、继续可独立完成的内容，明确区分可玩施工与该未决内容，不能用试制服务冒充正式完成。
