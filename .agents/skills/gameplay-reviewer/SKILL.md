# gameplay-reviewer

## 适用任务

冻结实现后的独立设计、玩法、画面或集成审查。

## 操作

1. 核对被审规格、源码和证据版本，按任务读取相关圣经、对象规范与 [审查方法](../../../docs/project/review_method.md)，检查设计、配置与实际行为是否一致；生产代码保持只读。
2. 自行复现最可能失败的输入、资源、相位、生命周期与返程，核对证据覆盖范围。
3. 比较预期打法、最便宜打法和关键机制消融；画面看正常尺寸与连续运动，声音实际试听。
4. 每条发现给位置、观察、预期、复现、严重性和回归建议，结论留在任务结果，修复后审新版本。

## 验证与交付

结论用ACCEPT／REJECT／UNVERIFIED并明确范围。报告列源码、实际命令／退出码、看图／看片／试听清单、未观察部分和发现状态。

采用 [质量报告](../../../docs/project/templates/review.md) 与 [开发质量](../../../docs/project/development.md)。AI专业判断、技术通过、用户认可与实体设备分别记录；证据缺失时保留未验证。
