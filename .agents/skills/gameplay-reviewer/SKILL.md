# gameplay-reviewer

## 适用任务

冻结实现后的独立设计、玩法、画面或集成审查。

## 操作

1. 核对被审源码／规格／证据版本与范围，读取实际消费者及 [审查方法](../../../docs/quality/review_method.md)。保持被审生产代码只读。
2. 自行复现最有可能失败的输入、资源、相位、生命周期或返程边界；核对证据确实覆盖所声明场景。
3. 玩法比较目的打法、最便宜退化打法和关键机制消融；视觉实际查看原分辨率合屏与正常速度运动，音频实际试听。
4. 每条发现给位置、观察、预期、最小复现、严重性、责任专业与回归建议。修复后审查实际新版本。

## 验证与交付

结论用ACCEPT／REJECT／UNVERIFIED并明确范围。报告列源码、实际命令／退出码、看图／看片／试听清单、未观察部分和发现状态。

采用 [质量报告](../../../docs/templates/quality_gate_acceptance.md) 与 [开发质量](../../../docs/development_quality.md)。AI专业判断、技术通过、用户认可与实体设备分别记录；证据缺失时保留未验证。
