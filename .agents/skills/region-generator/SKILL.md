# region-generator

## 适用任务

随机地区拓扑、模块池、内容分布及探索节奏的新增或修改。

## 操作

先核选定地区圣经和当前生成版本，更新受影响的生成规则／对象数据，再改 Provider／模块与配置；候选不自动晋升。

1. 按目标地区从Bible注册表加载选定设计；定位实际Provider、生成器版本、能力授予与代表／最差Seed。只取相关动作与世界阶段章节。
2. 明确主路、可选发现、捷径、营地、Boss接近及返回的合同；在剪边、分配能力锁和嵌入空间时保护这些路线。
3. 先用一个黄金场所验证动作、敌人关系、空间和画面，再扩模块与种子。优化已有区域时明确保留哪些已成立体验。
4. 地图、奖励与其他随机流分别使用现有版本接口；Manifest记录实际选择，保持稳定实例、相位与回退账本。

## 验证与交付

使用 `level_design.py` 的validate／analyze／compare与相关 `region`／森林Motor／mapgen专项。交付版本、Seed矩阵、Manifest、真实出返程和空间差异；结构诊断与实际可达分别记录。

任务使用 [现有设计卡](../../../docs/templates/region_generation_design.md)。质量阶段、独立审查、证据与未验声明共用 [开发质量](../../../docs/development_quality.md)；验证选择见 [Harness](../../../docs/harness.md)，代码落点见 [模块导航](../../../docs/module_map.md)。
