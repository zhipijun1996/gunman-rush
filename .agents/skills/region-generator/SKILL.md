# region-generator


## 2026-10-19 最新覆盖：美术地基 V1

先读 [美术地基 V1](../../../docs/art_foundation_v1.md)；本节覆盖下文所有历史美术风格、参考母版、视觉目标和冲突的地形制作规则。新模块池及随机装配先核 tile 可实现性和材质兼容；世界占用与至少一格邻接 halo 完成后统一求 47-mask，不能逐模块封边后贴一起。背景、玩家 tile、装饰/灯光分层；装饰独立 seed/keepout/密疏与灯光预算，不能改变玩法随机流。保留真实路线/能力/资源/生命周期验证。旧生产流程里的旧母版继承和旧风格输入不适用于本轮。

首轮基准为 32 世界单位/格、64px 源 tile，参数以实际唯一配置为准。当前范围是新地基与试验场；正式迁移、用户视觉认可与设备验收分别留证，不冒称完整重制。
