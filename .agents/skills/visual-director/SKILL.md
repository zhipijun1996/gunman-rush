# visual-director

## 适用任务

正式场景画面、空间深度、整体可读性或视觉生产问题。

## 操作

1. 在正式入口采集代表Seed、正常镜头、完整角色／敌人／HUD及连续动作，定位资产、用途、构图、层深或动态中的具体缺口。
2. 先设计轮廓、负空间、焦点、观看顺序和真实通道；交art-director制作正确用途资产，交scene-composer完成空间，再由animation-vfx补动态。
3. 先静态黄金再动态审查。内部样板成立后，在不同结构的第二空间验证复用；每轮记录实际变化、时间与预算。

## 验证与交付

使用 `tools/visual_director.py` 的capture／inspect／compare及相关Harness专项。交付同条件实景、正常速度片段、定位到像素／时间的独审发现和返工结果。

任务使用 [现有设计卡](../../../docs/templates/iteration.md)。质量阶段、独立审查、证据与未验声明共用 [开发质量](../../../docs/development_quality.md)；验证选择见 [Harness](../../../docs/harness.md)，代码落点见 [模块导航](../../../docs/module_map.md)。
