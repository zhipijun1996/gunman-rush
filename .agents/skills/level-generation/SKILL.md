# level-generation

所有命令从仓库根目录运行。现行规则见 [AGENTS](../../../AGENTS.md) 与 [当前状态](../../../docs/current_state.md)；数值和玩法不在 skill 中重复定义。

1. 读取当前生成/路线/对象/敌人契约，确认正式消费者和开发 Lab 区别；从实际能力 Definition 与输入配置获取性能，不复制固定默认值。
2. 先定义动作节奏：安全教学 → 组合操作 → 可选高风险收益 → 恢复/结算。描述横渡、攀升、折返、分岔的实际操作差异；模板名/hash 变化不能当多样性验收。
3. 为模块声明尺寸、端口、碰撞、移动平台/机关完整相位包络、动作预算、入口余量和失败保底。主路过滤未授予能力，不强制损血/慢时/凭空补弹。
4. 固定样片验证真实 PlayerMotor/弹体/平台携带；分别验证往返、反冲、动态相位与危险扫掠。几何图只作初筛，不能代替轨迹。失败保留 Seed、配置、Manifest 和输入序列。
5. 通过后才入正式池；独立随机流和版本化 Manifest 可复现。段回退保留实例相位/奖励账本，Boss 同帧死亡无奖，旧回调取消。
6. 跑 harness gameplay，素材变化再 art；用正式入口查看落点/预警/地图/出口，补用户实际探索评价。明确已验证 Seed 范围，不声称所有随机地图或主观趣味通过。

交付物：模块/配方与正式消费者、真实动作证据、失败保底和已验范围。
