# 项目文档入口

新开发先读[当前状态](project/current_state.md)和[模块导航](project/module_map.md)。普通房的现行规范为[房间制作](bible/room_authoring.md)、[机关对象目录](data/world_objects.md)与[地形材质](bible/terrain_materials.md)。任务、分支、验证结果分别归[任务表](project/tasks.md)、工作线与实际检查。

永久装备查阅[设计定稿](data/items.md)和[制作与接入](project/item_authoring.md)。

已有能力、怪物和战斗资料按对象查阅；数值以新工程实际 Definition 为准。[玩家动作](data/player_actions.md) · [物种资料](data/enemies/plains.md)

现行房号、区域与相邻门见[世界输入](data/world/README.md)。已接入实体见[房间绑定](../production/config/imported_world/bindings.json)。

冻结工程的旧地理、区域排期、房号、工作台导入合同与逐房审批仅供[冻结平原](project/worklines/plains_bible_v2_01/scope.md)复现。它们的原始版本可从[冻结文档树](https://github.com/zhipijun1996/gunman-rush/tree/4f2bb5e41573e930603789c64b52a0c15a6a3dc4/docs)查阅。
