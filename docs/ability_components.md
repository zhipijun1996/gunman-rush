# 动作能力组件

`PlayerController`读取统一意图，Jump／Shoot／Traversal等组件提交动作，PlayerMotor执行唯一碰撞运动。能力配置和Definition描述条件、次数、时钟与资源，实例状态属于当前角色。

## 授予、恢复与撤销

H／W／D分别表达钩索、墙面移动与额外跳跃。正式授予来自运行流程；练习入口可显式提供不同配置。核心能力权益与Boss金色道具独立，随机道具不是主路必需能力的发放保障。

有效接地、成功墙跳、拉近踢跳和真实空中伤害按当前能力政策恢复资格；恢复仅作用于已授予能力。动作次数、射击冷却、时间能量和共鸣分别管理，详细行为唯一见 [人物物理](player_mechanics.md) 与 [资源合同](combat_and_recharge.md)。

能力热变更从基础与有效来源重算。移除来源撤销旧请求和表现，空中容量变化按本次飞行账本钳制；普通卸装重装不重新获得空中次数。

## 地图合同

生成器使用实际capability_snapshot筛选模块。每条必经／回程路线验证真实身体、单武器、资源与能力授予；依赖未实现能力的内容只在明确开发切片中使用。

地区能力门槛见 [地区设计](design/player_actions/regions_v0.3.md)，动作输入见 [操作合同](controls_contract.md)。代码与检查见 [模块导航](module_map.md)。
