本轮继承远端 feature/plains-experience-energy 的 91d3ef4，初始工作区干净。当前 feature/plains-exploration-expansion 不合并历史 PR；最新用户要求优先于旧八关与固定三条上中下路线。只实现平原两个随机世界；第一小 Boss、第二大 Boss，第二胜利后的能力/下一地区仍是明确开发边界。

## 实际玩法差异

| 组合 | 操作 | 压力与决策 |
| --- | --- | --- |
| 齿轮节奏 | 观察运动、按住起跳、落稳 | 运动接触、等相位或立即过 |
| 双铃顺序 | 瞄准第一铃、推进、瞄准第二铃 | 顺序与瞄准，进退改变视线 |
| 终点限时门 | 射铃、跨坑、到远端门 | 计时覆盖跳跃，失败可重开 |
| 反冲横渡 | 长跳、向后下瞄准、射击位移 | 精力/空中弹药与距离 |
| 荆棘接齿轮 | 接近坑沿、跳过、落稳再观察 | 起跳点和第二次跳跃节奏 |
| 回收岸 | 选晚起跳省能，失误可反冲救场 | 距离与容错资源 |
| 水平摆渡 | 等靠岸、侧面登船、随动、上岸 | 相对运动与攻击窗口 |
| 低拱门 | 靠近齿轮、短按并松开起跳 | 短按避免撞顶、控制落点；满按也能通过 |
| 双横移齿轮 | 观察两独立相位，分两次跳过 | 运动方向、落地整备 |
| 井铃 | 跨井时向下射击，反冲并开门 | 瞄准/空中位移/坑；回程铃只接受出口侧开火 |

顺序铃要求两次有序瞄准；推进可以调整视线，并不是必须走到独占站位。低拱短按是提高控制的选择，不宣称只有短按才能通过；独立满按对照也能过，但产生两次顶碰。

这些是实际几何和真实弹体/机关消费者。名称不计作新增操作。候选优先抽最少使用的操作，避免连抽少数几个。第一图不抽双齿轮和顺序铃主路，第二图扩大动作组合。顶级支路比同变体高级支路加连续反冲、跨坑限时门或限时跨坑后反冲攀升。测试逐相位与双方向扫掠；图连通不代替真实移动。

## 空间、敌人与美术

生成 v6、随机流 v2：先生成有空缺的房间足迹，再截断不同列的横廊，选择 Boss 整备和两处反侧捷径；不固定三条贯通高度路线。woven_layers 为庭院交织，linked_rings 加单向下井和相邻攀升回程，crossroads 较宽的交汇结构偏升降台。竖井有交错踏台、真实碰撞携带升降台、向下反冲攀升三类，骨架采用不同权重。正向和逆向洪泛同时验证，每一自然下井必须有回程。单向井在实际模块中不放假梯子。横向连接只删可闭合画面缺口的段落，避免有实路而图不记。保底保留完整探索结构。

地标风车、钟台、铃树、溪石、维修蔓不再按固定行贴皮。复用 AI 手绘装饰和连续深度背景，不引入新占位美术。低拱/通道/齿轮/升降台使用既有 AI 地形、机关和对象美术。

正式保留 charger/sentry/diver，新增实际 fan_sentry 三枚独立、锁定预警方向的慢弹与 hopper 跃扑弧线；从正式实例数据读取半径/落点，预警不在攻击时改目标，阻塞也保持可见。摆渡侧射与俯冲错位布置，接触不要求全清；先预算关键走位窗口和长连接，最后路口巡守，第一图最多26、第二图36实例，同时攻击仍1/2。敌人掉落总预算保持，不随数量增长。恢复/卸载保留位置、HP、冷却和开火序列，补记锁定方向、落点与起跳点。

小 Boss 使用独立 plains_bellstrider_arena：清出铃芯上侧射线。小 Boss 无“只能从下面攻击”规则；大 Boss第二阶段上侧规则保持。两类 Boss 按 stable_id 分别记本局开场，开始新局清记录；开发练习也显示真实名称。用八个来源位置的真实扫掠弹体验证，护甲/地形仍正常挡弹。

## 道具与资源宝箱

原14道具保持，新6实际道具共20：稳射支架（地面反冲减半，空中保留）、回能绳索（落地回能×1.35）、轻击锤（开枪间隔×0.85）、止滑靴（地面减速×1.3）、散热风叶（落地回能等待×0.65）、野外药箱（生命上限+2，不补当前血）。全部来源 Modifier 重算/移除，不改基础物理配置。不存在散布，稳定性不会虚称改善弹道精度。

原九图标与新增六图标均为 image_gen 原图，透明、源 SHA、参考图、格子范围完整记录；原始 PNG 不编辑，Godot 导入压缩。三种资源卡复用 AI 金币、爱心、音符图。奖励/商店/构筑/获取提示都有图标、名字、说明、真实效果；中文字体覆盖新文字。

地图四个宝箱位置/档位固定预算，具体选择由 region_items-v2 记录：中级可为资源二选一或道具+资源，高/顶主要道具+资源。金币16/36/54，当前回血2/3/4，永久音符1/2/4；高级资源不退化成极少金币。选择顺序随机，高级音符和回血是真正可选。满血不显示无效回血，保留对应值音符替代；只剩一个可用道具仍保留，不偷偷变金币。

宝箱资源上限：金币122、回血11、音符8（逐个选最大值的保守上限，互斥选择不会同时给全种类）；选资源不叠加道具金币奖金，选道具保留8/18/30奖金。普通拾取与敌人掉落原预算分开。ResourceRewardChoice 仅展示，不能进入 BuildState；真实领取由钱包/Health/MetaSaveService提交。稳定 map/chest ID 与 run receipt前缀隔离，领取一次。点击先恢复物理，然后队列等待伤害批次，再验证 token/terminal：死亡优先，双击不重复排队，保存失败不标已领取、保留选择供重试。商店独立 region_shop流在七个实际蓝道具中抽固定库存商品，显示报价后买。
