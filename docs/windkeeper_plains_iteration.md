# D071 风铃平原与牧风者

用户明确授权完成当前任务后自主找出可优化项、迭代首个大关，并在验证后将最新版合入main。此前默认禁止合并已由这次明确授权覆盖；不得强推、覆盖他人改动或把技术验证称为真机/趣味性认可。

## 体验与美术

风铃平原继续原创手绘日光草甸、厚石灰岩地层、木桥和暖黄铜；用户风格板第一格为锚点。岩台草缘、根系、风化过渡与下层岩体应连续，不绘成孤立的一层石砖。荆棘根部与土壤/草缘衔接，危险尖端清晰且不改变碰撞。悬空设施使用明确木架/吊台，不能凭视觉填掉实际通道。特效短促、有界、只观察事件；UI突出血量、动作资源、Boss预警与目标，减少长调试文本遮挡。手机操作和镜头舒适性保持。

首区节奏：安全射铃教学→普通跨越→敌人预警与稳妥/挑战选择→铃与反冲组合→移动机关复合→休息与最终Boss。难度靠空间/前摇/安全台配置，不提高人物速度或强迫二跳。每段有观察与恢复空间；新增配置以真实Motor轨迹验证后入正式池。

## 牧风者：用户确认内容

背着风车的巨羊「牧风者」曾为村庄带来微风，现在背上的风车无法停止；旧风铃挂在毛发间，巨大笨重。作为正式第8关风铃平原Boss，替代正式流程的clockwork guardian占位；旧Boss仅保留开发与历史回归。

Ⅰ 草坡对峙：踏地冲击波可跳过；低头冲撞可通过反冲换侧；撞后羊角嵌入土坡，颈侧风铃核心露出。
Ⅱ 风车暴走：风叶扫过高低平台，局部气流改变跨越路线；保留稳定草台。利用风叶节奏登侧面高台，射击背部卡住的风铃。
Ⅲ 断桥追逐：短段追逐，每段末端撞桥墩；跨过断口后回身射击，反冲落到下一安全台并命中撞击时露出的核心。

## 实现边界与暂定参数

阶段、模式、Arena、受伤窗口和表现分别管理，不进入PlayerController。气流通过现有Motor运动修正接口接入，不直接写玩家位置；没有合适接口时新增明确局部外力入口，唯一move_and_slide规则不变。阶段切换/暂停/死亡/离开取消旧攻击，段回退保留HP、阶段和奖励账本。Boss同帧与玩家死亡保持玩家失败优先且无金奖；胜利必出金且只结算一次。

首版使用固定战斗核心与固定安全平台，外围装饰可随机。HP阈值、前摇、速度、局部气流数值、暴露窗口和追逐段长度均为可调demo策略，不视为用户锁定平衡值。每个阶段的核心位置必须真实弹体可命中；追逐允许安全停留点，不能用无限速度追死或要求未解锁能力。新增Boss正式消费者与开发直达练习均需可运行，但练习不写永久奖励。
