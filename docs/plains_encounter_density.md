# 平原路线遭遇密度（候选）

本切片保持现有平台几何、一跳和 260 基础速度，增加公共路与两条分支的独立遭遇编排。不是复刻遗忘十字路口地图，也不声称以下数值来自该作品。

战斗房早/中/晚期目标为 4/5/7 个敌人；金币房 3 个；道具房早期 3、后期 4 个。每条分支预留预算，余下分配公共路。商店、回血和 Boss 不加小怪。数值为 demo 暂定，安全候选不足明确记录缺额，不硬塞。

保留安全入口、机关观察/恢复落点、出口空间；巡逻完整包络避开危险、移动平台、地基和其他敌人。必要反冲/摆渡模块不放怪。敌人不改变非 Boss 出口开放规则。飞行与地面排列由独立随机流产生，完整实际计划、配置、版本、拒绝原因写入 RunManifest；布局输入不受敌人抽样影响。

敌人全部使用正式伤害批次和独立掉落账本。段回退保留实例、血量、相位及掉落，死亡和离场取消旧请求。奖励类型由房型决定，不由是否存在敌人决定。

验收区分：规划安全与复现检查、实际弹体/伤害/回退集成、真实 Motor 通过现有路线，以及用户最终趣味性与真机操作评价。几何检查不能代替带敌人玩法验证。

## 当前接入与范围

`PlainsEncounterPlanner` 使用 `encounters` 独立随机流，优先选择每条实际路线的 `plains_patrol_meadow`，其前一观察模块强制留空。宽草甸最多两个互不重叠的巡逻包络；三条路线各有配额，不能由整图均匀抽样挤占。配置与敌人基础定义快照、全部实例、随机流位置、逐路线缺额和拒绝原因完整记录在 `enemy_layout`。RunManifest 增加 encounter 版本，回放重算计划并拒绝篡改；不是仅保存一个 seed。

三个固定 Seed（density_0～2）的战斗样本：第1关实际3/4/4只，第4关5/5/4只，第7关7/5/7只。玩家只选择一条分支，对应实际经过的敌人数分别为2～3、3～4、3～5。统计是这组样本，不保证所有种子相同；安全不足仍可减少，并记录具体原因。金币/道具房也有较轻守卫；商店和回血房不加怪。

实际通行测试从生成出的草甸真实入口开始，经统一 Router 操作、一跳/260默认Motor越过地面巡逻或从飞行巡逻下方通过，无伤到达出口且守卫仍活。测试对种子做有界筛选，确保两个形态均有实例，不把缺失形态跳过当通过。位置fixture只用于选定遭遇段起点和独立子弹命中测试，不声称完成全关手动通关。整图原有几何/反冲/机关路线证明仍须分别运行。

未知项：手机实际密度感、同屏辨识度、表现开销与最终趣味性待用户试玩；尚未增加新的敌人攻击AI，风铃机关仍是下一阶段候选。
