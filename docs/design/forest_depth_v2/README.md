## 移除H会失去什么

这是机制反证，不是“有H按键就合格”。宽阶、营地与恢复岸故意不依赖H；它们提供观察和资源恢复。水平孔失去的是先拉近、来侧弹离再反冲接宽岸的连续方向选择，仍可花四枪或绕屋顶；下降孔失去下落途中选择接收位置／保留空中枪的打法，普通三R更快，不能宣称H垄断最优解。外根回冠失去保活萤作为临时空间支点的路线，仍能满跳双R或走下窗；上层A2活锚候选已经被正式强普通反证而淘汰。

守卫失去的是夺取真实移动铃、返撞4伤并打断身体跨场；反击关闭的同输入消融显著变慢，但一次躲避后射击仍是合法便宜策略。女王失去的是借活结进入新射角并剪除对应持续危险场的主动换场；普通换层追射合法且已更快。两场都不通过锁血逼按H。

目前证据支持“存在其他区域没有的空间／进攻选择”，不支持“森林绝大部分乐趣已获真人认可”。固定80路线的活敌H次数为0、敌人未被杀，说明它是可达性驾驶而不是动作多样性验证；专用生态整路、不同策略整战和正常影片须补这个盲区。若后续试玩发现玩家普遍把这些动作当额外负担而选择同一种普通解，应退回空间／收益设计，不能用动作数、强制能力门或高HP修补。
