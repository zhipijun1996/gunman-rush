# FOREST-DEPTH-02：织隙换位的森林

基线为PR76实际最新 `bee850c66b2f402d644d7daa4c13db91c8abe8f8`，工作分支 `feature/thorn-forest-depth`。本地WIP `0dd1fba0` 后继续迭代；registry默认已切到v2试玩候选，真实入口专项在验，新内容没有整区准入。本文描述当前选择和证据边界，不将历史候选当成正式地区。

## 诊断与体验目标

旧森林三种骨架共享相同分叉汇合和目的地，主要改变枝台数量、方向、长度；每图只有2–3只普通敌人，生态流未改变实际遭遇。钩索多用于前上方接台，旧两Boss均是锁旧位置、投种、定时开树心。技术检查能证明流程完成，却没有比较最便宜合法策略；旧完整Boss驾驶甚至不请求H。因此按断言扩产能得到可玩原型，不能自动得到有趣地区。

地区目标是：**看清缝隙和接收岸，选择接近方向；借固定环或活体拉近，再用反冲改变出路；把第一次看到的危险在回程变成捷径。** 移除H应改变主要探索和战斗的动作关系，而不是只让同一条爬台路线慢一点。合法低技术路线可以存在，需有真实的路线、风险或资源取舍。

## 实际运动权威

不修改Player或武器参数。身体24×36，H射程231，12px钩头扫掠，发射起点在请求时固定；拉近速度1150，近30停止、接触停顿0.10秒，随后向来侧／上方各约24px踢离。命中钩头不等于身体完成拉近；返击等行为必须读取真实Motor到达。成功踢离恢复下一H，不恢复空中枪数，空钩不恢复。

普通Pulse实际读取tuning：1200px/s、2秒寿命、1伤、0.25秒冷却；未消费的WeaponDefinition默认850／420／0.11不能用来推演射线或效率。既有Motor还包含武器动作顶点停留／混合；不能以即时满重力公式取代真实轨迹。碰撞需核全身体、实际枪口到目标九点路径和12px钩头，不能只核中心LOS。

## 比较后的选择与当前关卡语法

当前布局 `shared-tree-directional-cavities-v6` 使用一个共享实体巨木，而非连接三个实验盒。图1改变树腹／外根进入顺序，图2改变西庭、北庭与树腹的共边／共节点关系；独立cache抽样改变奖励的访问顺序。图2第三次拓扑抽样在水平双孔与下降转折孔间选择，图1保留水平教学。详细空间、真实端口及随机关系以[森林探索V2](../forest_exploration_v2.md)为准。

A2的H＋R可更稳定抵达宽岸中段，H零枪允许先接真实岸缘再走入；普通三R仍最快。部分身体合法落到岸缘不是作弊，不用人为要求全身体先越过岸来抹掉廉价解。另一个真实深窗aircatch在离檐至到达间完全无接触，H零枪比一枪慢37tick但保留枪与20精力；它只是局部备选，不冒签新增随机地图体验。

## Harness的必要改进

沿既有G0–G5、Skills、原harness与production_loop改进，没有另建生产系统。新检查使用每次真实执行唯一的输出路径，防止旧raw覆盖或被误读；两个坐标专属历史检查在精确bee冻结消费者内保持原断言，并输出小型SHA绑定证据包，当前默认入口另做强验。先列至少两个不同的玩家体验假设及旧方案，选最大价值的一项黄金；比较目的打法、最便宜合法打法、移除关键动作／对象，以及错误动作和自然恢复。评审读取真实轨迹、终速、资源、净空、容错与重复劳动，可选择继续、修改或删除，不能用计数、Hash或自动趣味分代替判断。

机制比较合同现在是推广前提；检查器只核结构与证据链，不鉴定原件真实性或乐趣。真实host两租约仅完成窄口02便携证据移植审计，实施与不同代理实际复核，scope complete／content false；不称整区自主生产完成。规则可迁移到冰川／火山／遗迹，因为比较的是能力、空间和玩家决策，而不是硬编码森林模块名。
