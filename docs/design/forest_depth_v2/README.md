# FOREST-DEPTH-02：从枝台攀升到织隙换位

基线 `bee850c66b2f402d644d7daa4c13db91c8abe8f8`，分支 `feature/thorn-forest-depth`，继承PR76的基本可玩消费者。2026-10-17用户明确授权重做关卡、生态、两Boss和必要生产流程；美术只做到功能可读，商业品质、玩家认可与实体设备另验。本文件记录设计取舍，尚不宣称新黄金或整区通过。

## 实现诊断

旧三family共享同一分叉汇合图与相同营地、奖励、Boss接近目的地；差别是升台步数、方向和镜像。图1两只、图2三只普通敌固定分配，生态随机流没有选择内容。所有主要上升路径复用同一“目标在前上方、来侧枝台接收”短语。两Boss共用锁旧落点、投种、等待、定时开放状态机；旧实弹通关消费者没有在战斗中请求H。旧技术通过的范围保留，不能用其证明探索或Boss设计优秀。

最新bee的实际CI还另有 `plains-redesign-golden/deleted_bank_negative` 失败，部署跳过。旧资源退出拒绝与这次结果均保留，不重签为设计问题，也不先把整轮工作挂在旧释放诊断上。

## 地区核心体验

**看清一条可穿过的缝，选择接近方向；借环或活体拉近，在来侧踢离后用反冲改变出路；回望时把原危险变成捷径。**

H不是传送、摆荡或途中可自由转向的绳索。实际身体24×36，资源覆盖射程231；接触后先停顿再向来侧／上方各24px踢离，成功踢离会恢复下一次H；空钩不恢复。射击反冲与真实命中恢复仍由原消费者结算。设计应利用这些状态，不能画一条中心线就声称身体可过。

## 学习与探索语法

稳定根盘先展示来侧弹离；枝间短爬保留为休息和定位。横向缺口让玩家决定拉近终点和下一次射击方向，斜洞让下落成为入口而非失败。固定环是合法保底，活锚只提供更直接进路／反击角度。狭窄区域必须提前看见身体净空和接收区，留可落稳观察位；难度来自选择方向和动作相互影响，不来自缩台、密刺或缩反应时间。

风险支线给出可见发现／收益与撤回，横联允许途中改意；取奖后沿已看见的另一层返回。普通怪分布按观察、承诺、恢复、组合安排，不按总数量填满空位。根盘奔袭、横联封线、旧枝投种、可选活锚各改变不同判断，营地与唯一接收岸不叠压。

## 黄金优先的实际依赖

1. 一个方向H／反冲黄金：目的打法、便宜的跳／反冲替代、无H、错误方向和一次自然恢复；真实调度、身体碰撞、正常资源，输出原轨迹及正常速度画面。
2. 两Boss各先做一个真正不同的机制黄金，与合法地面打法公平比较，再扩阶段与整场正常受伤战斗；女王第一机制可并行探索，不因另一Boss技术通过就准入。任何失败候选都不推广正式两图。
3. 新敌先单独真实遭遇，实际枪杀和活体出返；然后只组合已证不同压力，不以堆怪代替生态。
4. 推广到新版本两图：多根Seed、快走Boss／成长探索／高奖异路返回，兼容旧v1 Manifest及同局版本pin；所有新增物理类与最差相位实际验证。

主张与结果分栏：可达、实际判断和取舍、可读性、重复劳动、输入容错、正常受伤与恢复逐项留证。自动工具只核事实与证据完整性，不输出乐趣分数；独立专家可淘汰平庸候选，但不能代签玩家认可。

旧生成器／Boss场景和参数保留为v1消费者；v2新增独立内容并沿现RunManifest、RunRandomStream、RegionState、DamagePolicy与奖励流程接入。不以旧v1路线通过外推v2。坐标依赖旧测试保留原断言和真实旧版本执行；新当前正式消费者必须另有更强输入证明。不得按特定Seed偷偷回旧内容，也不将旧失败删除。

专项文档：方向挑战、敌人生态、守卫和女王由对应Skill作者给出真实参数、状态机、场地和未验项；本设计尚待黄金结果决定扩产或淘汰。

## 首轮淘汰记录（2026-10-17）

方向黄金03已证一次真实横向H→R→斜H接力→落下侧钩→回岸，全身与固定对照原件有独审。真实60fps电影4.9秒，但危险代理只显示DEEP DROP文字而未画准确边界，也未接正常扣血，不能签玩家可读危险或正式挑战。新验收器原先删事件仍放行，被独审拒绝；修复与同原件离线重验分别记源，不能重写原失败。下一黄金须把准确危险表现与实际FrameDamagePolicy接入。

根铃守卫首实验实际26/0、普通子弹可完整击杀，不代表玩法成立。公平连射对照69/0支持：同入口／初始资源下H打法3371tick、7窗、16次H、零伤；无H地面打法698tick、2窗、零伤；普通跳无H1074tick、3窗、零伤。因此淘汰该布局的H价值，不靠封远端射线或禁止地面打法修分。旧单弹驾驶10轮约61秒不是内容必然下限，已纠正，不将驾驶改善冒作设计改善。

根本流程缺口：既有Skill虽要求“真实”“独立审查”，技术消费者却主要检查可达、状态完成和清理，旧Boss战斗driver根本不请求H；目标体验没有便宜策略／移除关键动作的反证，审查对象容易变为通过断言。现沿原review_method、模板及production_loop补推广依赖，核比较齐备与独立结论；动作与危险还须从真实原件重建，结构检查不能鉴定趣味。另一教训是两个作者独立选“锁定→扑击→反击”仍会同构，因此Boss并行制作前也要跨设计比较实际玩家动词，而不只比较名字和形态。


## 当前反证与消费权威修正

守卫追击原型原先的零伤优势已撤回：真实 `move_and_collide` 的安全间距会使旧接触包围盒漏掉物理相撞。共享 ContactEmitter 现在可接收同帧、同session/actor epoch的真实物理接触信号，仍走原伤害政策与无敌帧，不放大身体、不直接扣血。boss11 实际109/0验证首次真实伤害及随后8tick健康不再下降；因接触源间隔0.7s，该8tick样本不能单独证明无敌帧拒绝第二次提交；H策略273tick损1血，地面369tick无伤，最便宜站桩193tick无伤。因此追击本身仍不足以支撑Boss身份，继续验证真实挡弹、可借用的移动金属铃，尚未准入。

普通Pulse实际消费者读取 tuning 的1200px/s、2s寿命、1伤与0.25s冷却；WeaponDefinition默认850／420／0.11并不决定该普通单发路径。先前以420射程或0.11间隔推演的结论撤销，武器物理不改。女王迁巢须靠真实树干遮挡改变射击角度，不能靠未生效的射程制造换位必要。

宏观双环候选完成96张Manifest的数据检查，但不代表探索有趣。formal02实际fast/growth各1692tick、相同edge序列、HP5→2，不记作两种探索体验；high_return因奖励接近台阶被更高地块遮挡而失败。只移动该接近台阶后复采，保留旧失败与原驾驶预算。
