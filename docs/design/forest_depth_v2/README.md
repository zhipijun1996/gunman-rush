# FOREST-DEPTH-02：织隙换位的森林

基线为PR76实际最新 `bee850c66b2f402d644d7daa4c13db91c8abe8f8`，工作分支 `feature/thorn-forest-depth`。本地WIP `40edd668` 后继续迭代；默认生成器仍v1，新内容没有整区准入。本文描述当前选择和证据边界，不将历史候选当成正式地区。

## 诊断与体验目标

旧森林三种骨架共享相同分叉汇合和目的地，主要改变枝台数量、方向、长度；每图只有2–3只普通敌人，生态流未改变实际遭遇。钩索多用于前上方接台，旧两Boss均是锁旧位置、投种、定时开树心。技术检查能证明流程完成，却没有比较最便宜合法策略；旧完整Boss驾驶甚至不请求H。因此按断言扩产能得到可玩原型，不能自动得到有趣地区。

地区目标是：**看清缝隙和接收岸，选择接近方向；借固定环或活体拉近，再用反冲改变出路；把第一次看到的危险在回程变成捷径。** 移除H应改变主要探索和战斗的动作关系，而不是只让同一条爬台路线慢一点。合法低技术路线可以存在，需有真实的路线、风险或资源取舍。

## 实际运动权威

不修改Player或武器参数。身体24×36，H射程231，12px钩头扫掠，发射起点在请求时固定；拉近速度1150，近30停止、接触停顿0.10秒，随后向来侧／上方各约24px踢离。命中钩头不等于身体完成拉近；返击等行为必须读取真实Motor到达。成功踢离恢复下一H，不恢复空中枪数，空钩不恢复。

普通Pulse实际读取tuning：1200px/s、2秒寿命、1伤、0.25秒冷却；未消费的WeaponDefinition默认850／420／0.11不能用来推演射线或效率。既有Motor还包含武器动作顶点停留／混合；不能以即时满重力公式取代真实轨迹。碰撞需核全身体、实际枪口到目标九点路径和12px钩头，不能只核中心LOS。

## 地块与连续动作语法

树腹是观察与回稳空间，实干双窗联系内外根盘；冠枝同时是目的地和下降观察点，根下有不损血的恢复阶与重新接近路线。安全观察点与奖品交互区不叠怪物伤害体；危险表现须画实际完整范围，尖刺朝向与身体接触一致。新美术只做可读灰盒和资产接口。

## Boss与生态的证据边界

守卫24实际H606帧／HP5／终能量26，一次躲铃后站射487帧／HP4／终能量100；不是H总支配。独立身体横追665.8px，第一阶段身体完成后才进入第二阶段的铃／身体并行；七种合法策略均完成，两部正常60fps完整片11.95与9.967秒。25在同机制／同Player字节下采六种有限输入时机，均实际返击、存活并完整击杀。独评只接受双招／两阶段灰盒机制，预警、返击反馈、正式App、音频和玩家／设备仍需验证。详见[守卫设计](../rootbell_guardian_v2.md)。

女王16局部H→R剪同结有真实因果，但自然战H600帧，对公平最强安全零H619帧仅快19帧且少15.5能量；第三织带成熟后仍可长期安全输出。整战REVISE。第三阶段慢速织带换层候选正在真实探针，不能用旧电影或观察者单次空中命中拼接成新完整战。详见[女王设计](../thorn_queen_v2.md)。

织棘蛛退役獾后的实际新采为31逻辑case／45断言零失败；相位对照保留“直接走111帧更便宜”和“等待／借锚更安全”的区别，不伪造H万能。详见[生态设计](../forest_enemy_ecology_v2.md)。所有实际参数以Resource与消费者为准。

## Harness的必要改进

沿既有G0–G5、Skills、原harness与production_loop改进，没有另建生产系统。先列至少两个不同的玩家体验假设及旧方案，选最大价值的一项黄金；比较目的打法、最便宜合法打法、移除关键动作／对象，以及错误动作和自然恢复。评审读取真实轨迹、终速、资源、净空、容错与重复劳动，可选择继续、修改或删除，不能用计数、Hash或自动趣味分代替判断。

机制比较合同现在是推广前提；检查器只核结构与证据链，不鉴定原件真实性或乐趣。真实host两租约仅完成窄口02便携证据移植审计，实施与不同代理实际复核，scope complete／content false；不称整区自主生产完成。规则可迁移到冰川／火山／遗迹，因为比较的是能力、空间和玩家决策，而不是硬编码森林模块名。
