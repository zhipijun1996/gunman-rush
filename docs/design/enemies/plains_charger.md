# 平原冲锋怪

地面近战敌人，通过可预读的直线冲锋迫使玩家跳跃、换位和选择落点。它考验对出手时机的判断，不依赖额外能力才能应对。

## 行为与应对

| 阶段 | 玩家能观察到的行为 |
| --- | --- |
| 巡逻 | 在出生位置附近往返移动；玩家进入可见范围后准备进攻，墙后或安全区内不直接发难 |
| 蓄势 | 转向玩家并给出身体预告与警告声；玩家可趁此跳起、换层或离开冲锋路线。预告期间失去目标则收招 |
| 冲锋 | 沿选定方向快速贴地冲出，不追着玩家转向，不发射远程攻击；遇墙或无支撑的边缘停止前进 |
| 收势 | 冲锋结束后短暂恢复，再重新选择行动；这是换位和反击的机会，不要求它先走回出生点 |
| 受伤 | 普通命中有受击停顿、横向退让和声音反馈，随后继续当前动作节奏；钩索与技能的特殊作用遵守各自设计 |
| 死亡 | 停止攻击和接触伤害，身体倒地并留尸；同一地图内返回时保持已击杀结果，不重复发放奖励 |

身体接触始终具有威胁。玩家可以提前跳过冲锋路线、引诱其出招后从侧后方攻击，或用射击反冲调整落点；应能看清预告、躲避空间和下一处安全落点。

## 外观、动作与声音

沿用平原统一像素风，身体比例、材质和朝向在移动、蓄势、冲锋、受伤与死亡间保持一致。蓄势有可读的重心变化，冲锋体现快速前冲，收势表现力度回落；警告标识辅助身体动作。

受伤后自然接回正在进行的动作，连续命中与致死不会突然换身体或闪回活体。尸体与真实地面、平台接触，返回场地后保持一致。警告、命中和死亡的声音应能分辨，同一次事件不重复播放。
