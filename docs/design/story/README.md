用户同意沿“王国反复度过灾难最后一天、家园保留成长、主角逐渐知晓循环、首通表面/多次深层结局”继续完善。具体的钟院试验、院长、老师责任、黎明06:00至午夜24:00、登记规则及三次成功结构是本轮推荐，不将一句“好的”扩大为全部创作定案。
