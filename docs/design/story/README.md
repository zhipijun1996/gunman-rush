## 一句话与核心反转

**主角带枪、手里剑或炸弹穿过失序的王国，救回被困钟心的老师，让日夜重新运转；随后发现，钟重新走动时，也重新开始征走穷人的明天。**

首通救人和恢复昼夜都是真的。深层真相是：灾难之前那份被怀念的“秩序”，本就建立在不公平的征时之上；教主角分辨对错的人，也签过那本账。

- [故事圣经](story_bible.md)：时间怎样运转、过去究竟发生什么、师徒具体关系、三次成功远征各改变什么。
- [16区故事与美术证据](region_narratives.md)：每区在征时网络中的位置、三阶段物证、随机剧情房与能力边界。
- [16区Boss设定](boss_narratives.md)：身份、立场、时间状态、为何挡路、败后及重复遭遇。
- [碎片呈现与家园NPC](narrative_delivery.md)：跨通关揭露顺序、保底事实、NPC冲突与最小制作顺序。
