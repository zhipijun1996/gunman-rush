## 推荐的故事核心

**一个小修钟匠，带着师父留下的反冲维修工具，走进没有明天的王国。他想把师父接回家，最后修好了世界，也终于完成了一次告别。**

君主把整个王国留在自己舍不得结束的一天；主角也一直想回到“师父还在等我”的那一天。两个人面对同一种失去，作出不同的选择。家园渐渐住进新朋友，让主角亲眼看见：明天不仅带走东西，也带来相遇。

首通即有完整修复与告别，不把真正结尾扣在刷齐16区域之后。后续远征修复余响、补全人的故事，不推翻第一次成功。

## 与现有设计的关系

沿用 [能力与16区域V0.3](../player_actions/regions_v0.3.md) 的六阶段、每局每层一个地区、每地区两张连通地图；不采用 [旧世界文档](../../world_and_story.md) 中已被覆盖的八小关等历史段落。区域名和稳定ID保持一致；入口/能力授予/邻接合法性仍以现行能力规范及实际消费者为准，本提案不另建路线真值。

沿用 [家园与保存契约](../../home_and_save.md) 的局内/永久分离、零血结束本局回家、非致命伤段内回退、信息持久化边界。故事不改变精力、空中射击、反冲或武器数值；不靠台词授予额外动作能力。枪是初始工具的称谓，多武器剧情统一称“维修工具”。

当前完整16区和剧情持久化并未落地。家园的既有永久升级功能继续工作；人物、成就及新剧情NPC不能因本文出现就标成已实现。纯文档交付不触发新的游戏部署。
