# 唯一时间规则：同一天回返 V0.3

> 这是本轮剧情的共同规则来源。具体细则为提案，未接运行。其他剧情卡片与此冲突时，先修卡片，不添加第二种时间魔法。

## 1. 一句话与日程

**午夜最后一声钟响，联网王国回到事故日黎明06:00。只有钟外小站及已经脱离追踪的人和物，不被回拨。**

时间在每轮内部正常向前。森林不会加速长大，冰川不会暂停人的代谢，墓园不会生成幽灵，星空不会独自多走数年。寒冷、巨树、浮空岛、发光菌本来就是这片童话世界的地貌与生命。

| 叙事段落 | 故事时段 | 玩家看见的当日进展 |
| --- | --- | --- |
| S1 风铃平原 | 黎明至早晨 | 邮车出发、庆典路牌、地方预警 |
| S2 自然外围 | 上午 | 封路、邮路延误、撤离请求被退回 |
| S3 文明遗迹 | 午间 | 总传动公开试运行，地方制动被中央旁路 |
| S4 灾难地带 | 傍晚 | 超压、决口、雪道受困、浮岛坍塌等连锁事故 |
| S5 核心外围 | 入夜 | 独立应急设施被封锁，危险逼近中枢 |
| S6 世界钟心 | 午夜前 | 人工停机与回返权限的最终处理 |

全区天气线固定为：清晨阵风与预警，上午第一阵强风折枝，午后主风暴到达。平原早晨已有的废维修桥缺口与邮车主桥是不同地标；邮车主桥只在午后进一步断裂。工城午间先有压机卡死与局部起火，入夜才有主动力爆炸；卡片和远景必须按这一先后表达。

这是叙事日程，不是实时18小时、倒计时或限速要求。光照和大事件按章节进展呈现；玩家练跳、看文字、暂停不会因现实耗时突然错过救人。同一地区两图内连续发生的事情有固定先后，不把到场镜头做成自动压死玩家的机关。

## 2. 钟回拨的是同一批人和物，不是复制一座王国

总钟保存事故日黎明的状态与身份追踪。午夜把仍在追踪内的同一个人/物恢复至黎明状态，再从那里重新发生因果；主角可以改变过程，事件不是无法干预的影片。

已经脱离追踪的本人不恢复，也不在旧位置复制。NPC离开后，原卧室会空着；其他仍联网的人只记得黎明前的关系，不突然获得一段“他一直住在家园”的假历史。

网内Boss同样恢复，所以每轮再战自然成立；不需要每位Boss另造回响、替身或新菌冠。若某位活人Boss真的脱网，不能又在原地刷出本人；本轮候选主Boss默认不加入家园，减少替代战斗的制作负担。

## 3. 家园为什么是唯一例外

家园原名“钟外校准站”，是钟院建设回返装置时预留的控制与观察站：观察者、轮次计数、试验日志必须留下，否则连操作者也会忘记刚刚回返过。后来关闭的宿舍、食堂和花圃被来人重新使用，逐渐成为家园。

地下封存的记录设备与地上生活区属于同一站、同一个排除范围，不是世界里另藏许多个不回拨的小宇宙。世界钟心在外界，仍会复位；院长、老师和所有外界人都服从同一规则。院长每天早晨能从控制站取得上一轮的报告，属于普通通信，不等于他另有保留肉身/记忆的特权魔法。

站内时间照常经过，人会长大、饭会冷、花会开。外面回到黎明时，站内正在烧的蜡烛不会重新变长；墙上值守簿可以写到第48次，而村里日历仍是同一日期。不写经历千百年，避免正常衰老与生活资源失真。

## 4. 救人必须是活人实际脱离追踪

脱网要求：本人活着、本人到达接引装置、知情同意、实际移交完成。纸上的登记只是记录这一结果，不能隔空写名字救人，不能替死人签字复活。

完成移交后，身份不再受晨间记录恢复；本人、家园经历、带回的记忆继续存在。下一轮原处空缺，无复制人、假尸体或新的同名者。独特物件若需永久带回，也必须真实移交，原处不重复生成。

救援不要求玩家实时护送全程：安全点接引后由小站归途线路带回，合法提交后本局失败仍保留。只见面未完成移交不算救成；重复触发、同帧死亡与迟到回调继续服从既有事务规则。装置与保存均是未来实现，不因本条就宣称已有系统。

离开家园的脱网者仍不会自动回拨。主角与参与外勤者必须绑定站内回程信标，在失去行动能力或午夜回拨前召回；它做运输和救援，不回拨身体、不重造尸体、不转移他人寿命。家园无伤害场景，不安排居民死于随机事件。

“把所有人慢慢搬走”可以是继续救援的努力，但不是唯一应被迫接受的未来：人们想保留故乡、与尚未离开的亲友共同生活，不该只有放弃故土才配拥有明天。真结局解决的是整个王国的循环，不以家园收齐人口代替。

## 5. 死亡边界必须诚实

| 情况 | 回返后的结果 |
| --- | --- |
| 事故日黎明前已经死亡 | 记录起点已经没有活人状态，不能带回 |
| 黎明活着、当日在网内死亡、未脱网 | 下一轮恢复黎明状态，可以重新改变当天结局 |
| 已经脱网后死亡 | 不再有回拨保护，不能靠搬回原屋复活 |
| 主角零血 | 玩法结束本局；叙事为致命后果前召回，不是死透后重生 |
| 真结局取消回返之后死亡 | 不再有下一次恢复，普通生命继续向前 |

不能沿用旧版笼统的“死人从不回来”。当天死者反复恢复，正是循环存在的直接后果；痛苦被遗忘也不等于没有发生过。永久不可追回的是起点前的失去、脱网后的死亡，以及最后一天真正结束之后的过去。

## 6. 一局结束不是世界立即重置

死亡、主动放弃或首通返家都只结束当前冒险。可以在家园交谈和整理；下一次出发从下一轮黎明开始，中间时段用休息/窗外钟声短过渡略去。玩家没有通过死亡遥控全世界回拨。

午夜前召回主角不会带回尚未移交的他人；救援是否完成有明确提示。故事不把失败等同又消耗一个人的寿命，不设置按死亡次数增加的惩罚。

临时构筑、金币、音符、永久升级仍按现有RunPolicy。记得钩索怎么用不等于下一局已经拿到钩索；武器与五大能力不由剧情改成永久全开。普通反冲、跳跃与射击不新增时间能力。唯一纪念物去重与一般局内物资不是同一经济规则，不为解释世界偷偷改掉落。

## 7. 同一天为何有随机地图

王国地理、主地标、灾难源与06:00状态固定。可玩地图抽取本次走过的道路组合，变化来自路线选择、可通行门桥、已有支路和不同遭遇。总钟的旧试验程序还可能在黎明后下达不同的普通桥门调度，形成不同路线，但不会凭空搬山或改写洞穴。

同一轮地图一旦生成便保持，不因死亡段回退、看剧情或暂停重抽。再次挑战同Seed的固定路线也符合剧情；不能把“时间把地图洗牌”当作随机性的万能解释。

两张随机连通图与“固定更大世界中不同路线”之间存在制作抽象，需要固定地标/入口出口/事件锚点的样板验证。若模块拼接真的让同一地理位置互相矛盾，应修关卡映射或承认换了另一条路线，不能增加地方时间漂移来圆。本轮不修改生成器或宣称字面空间已验证。

## 8. 哪些成果可以跨轮保留

| 可保留 | 外界仍会复位 |
| --- | --- |
| 脱网居民、家园陈设、唯一带回物件 | 网内居民、机器、敌人和已知房屋 |
| 住民记忆、档案、方案与已取得的站内权限 | 前轮拧过的阀门、清掉的障碍、停下的普通工厂 |
| 按现有政策提交的Meta事实与合法救援 | 本局临时构筑、RunCoin及未提交权益 |

同一机关“我学会怎么停”不等于“它以后一直停”。深层结局必须在最后同一轮设置应急节点、实施疏散并安全停机，再取消回返。前几轮保留知识和控制站权限，不能跨轮凭空累计外界物理修复。

## 9. 真结局之后怎样继续玩

真结局现实停留在第二天，钟外小站保留住民与记忆，王国不再回返。完整随机挑战明确从“旧日回放”进入，是游戏提供的历史重玩，不是主角再次发动时间魔法，也不从里面运出活人。

未读碎片可作为档案内容补看；现实人物只通过现实后日到访/邀请出现。原灾难在最后一轮被阻止，因此未提前入住的幸存者仍可能在故乡生活，后续可用少量来信与到访完成故事，不凭空再做一整套战后16区。回放中的遇见不直接等同现实救援成功。

回放的奖励政策必须另按实际消费者设计，不自动新建金币兑换、重复终局奖或将历史物资搬入现实。最小叙事交付允许只提供标明旧日的重玩入口与现实家园，未完成的回放消费者继续标制作中。
