# 16区域：最后一天的不同地方 V0.3

> 时间只按 [循环规则](loop_rules.md) 运作；当日事件链与人物责任见 [故事圣经](story_bible.md)，[Boss卡](boss_narratives.md)补充战斗身份。所有场景/对白/机关均为候选，不签已制作。

## 全区共用表达

鸣钟节试运行从午间走向傍晚连锁事故，午夜回返。每轮只走一条合法六区路线，其他区域发生的事可通过广播、远景和当事人交代。S1早晨、S2上午、S3午间、S4傍晚、S5入夜、S6午夜前，只是叙事进程，不是限时关卡。

“重复的小动作”指下一轮同一时段再看到，不是当前房间几秒钟回放一次。杯子正常落下，冰雪自然寒冷，林木本来繁茂；不画停住的水滴、混在一枝的四季、瞬间老化人体或时间流动的管线。

A为救师首轮，B为查明并接管无限试验，C为最后同一轮实施救援并断环。每阶段必要事实由 [安全交付矩阵](narrative_delivery.md) 保底；随机房补人的生活，不是16个必收钥匙。

永久入住人物与每轮必战的活人Boss分开。本人脱网后原位置不再出现；原岗位空缺/代班要有明确布景，不能复制本人。一般当日善举会复位，接入家园的活人会留下，最终轮的成功才成为王国真正的昨天。

## S1 风铃平原 `windchime_plains`｜基础跳跃+反冲

- **今天的生活与事故**：草坡居民给鸣钟节挂彩绳；清晨已起阵风，巡护机执行预防性警戒。可玩废维修桥原有缺口；邮车主桥在本轮上午封路，午后主风暴才使其断裂，不把午后事故提前演在早晨。平原不是钟心爆炸的抽象投影，有它自己的日常与危险。
- **重复的小动作**：送信人过桥时帽子被吹起，回身追帽，掉下一封信；一只羊咬住同一条彩绳。玩家第二次可以提前站到帽子落点。
- **主Boss**：现有牧风者，第一图保留鸣铃巡游机 Bellstrider。身份是原本负责风暴警戒与道路巡护的机器；主角要闯的恰是封锁路段。保留现有模型、行为、伤害、奖励与战斗契约，剧情不要求改造外观。
- **胜利改变**：本轮停止强制驱离、打开向内陆道路，村民得到局部避风机会；不永久改变下一轮机器的黎明状态。
- **A/B/C**：A 先看到警戒设备如何封路；B 调度底单与站内轮次记录证明封路被当成试验变量；C 提前送达预警，让村民自行收绳、撤离旧桥，机器的保护初衷终于被履行。
- **随机房**：“明天的新口味”，烘焙师准备明日才卖的点心，菜单空着一个名字。入住家园后能真的烤出新点心。不是每次刷完整个人都失忆。

## S2 荆棘森林 `thorn_forest`｜H

- **今天**：老林长久茂密，林务员正在剪开节庆游行路线。上午第一阵强风折断树冠，既有藤荆倒伏堵住林道；午后才是主风暴，不是森林时间提前。植物没有一天长几年的能力。
- **重复动作**：林务员用口哨叫回一只总衔错树枝的鸟，每次都说“不是这根”。
- **主Boss**：“冠枝鹿”，正常生活于老林的巨角兽，风暴惊扰后守护幼崽，把上层通道当成巢边。角上缠着多年旧枝；不是事故突然生成的怪物。
- **胜利**：破坏阻路的缠枝、迫退巨鹿，使其有撤回深林的路线；H借林间小生物或枝锚换位，基础反冲调整落点，不暗需其他能力。
- **A/B/C**：A 误以为野兽袭击使林道断；B 发现撤离告示曾被换成游行告示；C 走林道前先疏散幼兽与人，减少惊扰。真结局并非全林恢复空旷。
- **随机房**：“门框上的刻痕”，父亲给孩子量身高，孩子总问明年能否比窗高。家园回应是新一笔真实日期。

## S2 萤雾沼泽 `firefly_marsh`｜U1

- **今天**：水邮码头备船，洪峰将至，中央仍要求水闸保持节庆景观水位。入夜码头被淹，求援信出不去。
- **重复动作**：邮差把盖歪的邮戳擦掉重盖，第二次仍歪在相同角度。
- **主Boss**：“封港摆渡长”，当天活人，奉命查扣事故预警，怕失去饭碗，主动封闭水闸与港口。不是死者档案。
- **胜利**：缴械并打开本轮水闸，邮件能够离港；Boss以操作双水钟改变站位为主题，各U1分支有解。
- **A/B/C**：A 以为风暴令邮路停摆；B 找到早于警报的封港命令，明确人为延误；C 把预警和民船先送走，摆渡长要面对自己本日的选择。不能靠预言使他自动相信主角。
- **随机房**：“两封信”，同一人写一封报平安、一封求援，犹豫把哪封寄给母亲；主角可帮忙寄信并邀请入住，不必须让此人当摆渡长。

## S2 风蚀峡谷 `windswept_canyon`｜W

- **今天**：商队在关口等待出城，中央抽调牵引设备运送庆典重物，风暴使吊桥与岩道落石。道路有自然风，非永不换向的时间风。
- **重复动作**：驮兽总在关门前打一个喷嚏，关吏总晚一步放下手中的茶。
- **主Boss**：“关隘守长”，当天活人，封关防止混乱涌向王都，也不愿承认自己放行过超载车。他认为主角闯关会让本已危险的局面失控。
- **胜利**：解除关门机、迫使让出攀壁通道；不需要杀人。墙面为回攀、换边与躲避中心，只有W+R。
- **A/B/C**：A 封关看似合理；B 货单证明安全索被征给庆典，事故并非全是天气；C 先放行撤离商队、留出救援道，关长被要求承认责任。
- **随机房**：“两只木碗”，同行者本约好晚间吃饭，一人却被派去护送中央货车。家园带回的碗不必都来自死亡。

## S3 蕈灯地穴 `mushroom_caverns`｜H

- **今天**：地下仓库与居民洞穴依赖通风道，中央试运行挤占通风动力，工城午间压机卡死、小范围起火后的烟气倒灌；入夜才发生主动力爆炸。菌群本来存在，不靠时间泄漏形成。
- **重复动作**：守仓人把滴水下的杯子移开一寸，下一滴又落在杯里。
- **主Boss**：“守灯菌母”，长期生活在暖湿仓库的掠食巢群，受烟气刺激，封住避难出口。可以是童话生态生物，不需套新时间原理。
- **胜利**：打退菌冠、开通风闸，地下人有离开路线；H改变弹力蘑菇提供的运动轨迹。
- **A/B/C**：A 地穴天然危险；B 值班通话证明有人上午已报通风异常却被要求等待庆典后再修；C 从另一路通风、先撤人，不能靠一刀杀菌母替代疏散。
- **随机房**：“没有唱完的歌”，地下童声排练总被同一阵咳嗽打断，家园里终于唱完。普通声筒录音不是跨时间预知。

## S3 沉水遗迹 `sunken_ruins`｜H+U1

- **今天**：旧水务设施已废弃多年，但仍接有王都排洪支流；当日洪峰和错误调度将上层排水压入旧城。
- **重复动作**：浮在水上的小木船每次都撞上同一根柱，船上写着一个孩子的名字。
- **主Boss**：“闸门天平”，旧水务安全机，执行中央优先保城命令；拒绝地方手动排洪，会把水重新送回低处。
- **胜利**：解除中央优先阀、排出本轮一段积水，露出通道。U1开水闸、H追随浮锚，无游泳硬要求。
- **A/B/C**：A 古代遗址失灵；B 新近铆上的中央优先牌证明事故由当日调度引起；C 根据旧水路安排泄洪与撤离，低地住民不能为王都再牺牲一次。
- **随机房**：“纸船港口”，一间孩子自制的船棚，每艘船写一个想去的地方。通过本人/家人获救延续，不写“归还生命”。

## S3 齿轮工城 `gear_city`｜W+D

- **今天**：为了按时完成钟网试运行，工厂取消检修和晚班交接；一台压机先卡死，主动力过载，入夜爆炸。
- **重复动作**：饭盒在传送带上绕过一次，主人总说“再一件就吃”。
- **主Boss**：“末班监工”，安全与生产调度机器，最高优先仍是完成订单，阻止人员停工和主角打开紧急竖井。
- **胜利**：破坏本轮强制生产机构，打开疏散竖井；救下这里的人不会自动令别处压力消失。W+D用动态墙和活塞为主。
- **A/B/C**：A 机器失控；B 发现事故警报被人手动消音，提前知道过载；C 主角把停机权交还工人，排班表上第一次可以有他们主动结束的一班。
- **随机房**：“写到一半的辞职信”，工人打算节后辞职去学做风筝，每轮都没等到节后。家园可以挂起他的第一只风筝。

## S3 月冠古堡 `moon_crown_castle`｜U1

- **今天**：中央庆典继续，来宾收到外面“只是天气不佳”的通报；礼官把求援引到侧门，维持宴厅秩序。
- **重复动作**：侍者每次都在第三级台阶绊一下，托盘里只有一把勺子落下。
- **主Boss**：“最后一舞的礼官”，当日活人，操纵既有舞台和门禁。守住内廷入口，维护庆典与主上颜面；有人将事故消息送入，就等于承认封锁失败。
- **胜利**：打断强制舞台与封门，打开内廷通路、让在场人真正看见午间初火的烟柱与求援信号。U1+吊灯月镜，不硬需H/D。
- **A/B/C**：A 宴厅对灾难无知；B 侧门签收的多封求援证明并非无人告知；C 不再等庆典许可，打开外门把厅堂用作临时避难点。幕后人物动机留主案。
- **随机房**：“明年的邀请”，一位仆人把自己的邀请草稿写在废节目单背面，他也想在下一年请朋友吃饭，给普通生活而非王室独占的期待。

## S4 月影墓园 `moonshadow_cemetery`｜U1

- **今天**：墓园本就埋着许多往日逝者；灾难当天一场普通葬礼被疏散铃打断。关键证明：回返救不回黎明之前已经死去的人。
- **重复动作**：老人给墓前空椅撑伞，雨点落下时总说同一句“今天来晚了”。
- **主Boss**：“守门送葬人”，当天活人，关闭旧地下道保护送葬者，认为携武器的主角会引来追兵；可通过战斗使封路器械失效后停战。
- **胜利**：开通墓园后路、允许尚活的人撤离。既有虚实平台以已存在钟亭机关/童话桥器解释，不扩写为死者灵魂控制时间；命名可用雾桥或映月桥，但实体机关是否换美术属未来制作决策。
- **A/B/C**：A 仿佛所有人都能被下一轮救回；B 黎明前已刻好的墓碑提醒回返边界；C 接受不能救回所有过去，把活着的送葬人带离当天灾难。不要让主线靠随机房才知道回返边界。
- **随机房**：“留给后来人的伞”，原主人生前写“下次下雨，借别人”。伞最后可出现在家园门口，不令亡者复活。

## S4 霜镜冰川 `frostmirror_glacier`｜W或D

- **今天**：高地本来终年寒冷；运药雪橇清晨出发，午后桥被雪崩截断，救援总差几分钟。居民没有被冻结在时间里。
- **重复动作**：救援员系绳总先打错一结，同行人默默替他重系。
- **主Boss**：“封山救援机”，暴风雪时启动的安全装备，判断进入山道等同送死，封住通往高地的出口；主角需要突破其强制保护。
- **胜利**：关闭拒行装置、借机体/避风岸抵达安全山道；不瞬间融化冰川，药车本轮获救依赖救援动作。W/D各自可通。
- **A/B/C**：A 风雪无情；B 药车本可更早出发，却为庆典运输让路，虽清晨发车仍错过安全窗口；C 的S1预警于早晨送达，当地队伍午前改走备用线，主角在S4傍晚打通最后接应段并确认药品到达，不靠给病人“补时间”救治。
- **随机房**：“围巾最后半针”，老人说明天送给即将回来的孩子。温暖来自家园里围巾被真正穿上，不是大规模解冻。

## S4 熔火腹地 `ember_depths`｜H或W

- **今天**：地热和熔炉一直供暖供能；当日中央试运行抽走排压设备，工城超载后压力灌入主炉，傍晚发生同一场爆炸。
- **重复动作**：值炉人把杯子放下，汽笛恰好震掉杯沿一小片水。
- **主Boss**：“护炉巨机”，当日防火机器，防火系统把开启卸压旁路识别为损坏设施，堵住安全阀。不使用跨季催生或时间生物解释。
- **胜利**：打开本轮旁路、创造一条冷却通道，H离开喷口或W冷壁退出热流各成立。整个炉区无需完全熄灭。
- **A/B/C**：A 以为是自然喷发；B 检修单证明是提前可知的工程风险；C 卸压并撤走值班人，真结局后供热以正常维护继续。
- **随机房**：“留着的夜班饭”，两人约好交班后吃，饭菜总在爆炸前变凉；家园回应是有人开始准时交班。

## S4 破碎浮岛 `shattered_isles`｜移动任意两项

- **今天**：浮岛依靠古老浮空结构维持，本就需要维护；当日中央试运行触发过载，花园岛先倾斜，观礼平台随后崩落。无需“不同岛不同时间”。
- **重复动作**：一只风筝撞上塔尖，被主人拉回，再飞向同一角度。
- **主Boss**：“巡游舰长”，当天活人，正保护满载平民的撤离船，误认为主角要开启供中央用的牵引桥，危及船身。他在当日有合理误判，不需全知后故意不说。
- **胜利**：解除封锁架、迫使停战，主角保全船只后放行；不能炸毁避难船来庆祝胜利。三种双移动组合均可。
- **A/B/C**：A 以为岛屿天灾；B 发现维护队早已提交裂缝报告而庆典仍照常；C 放弃保全空中花园外观，先安排落地/撤离。不是再加局部延时供给。
- **随机房**：“风筝另一头”，岛上孩子与船上家长互相系留言，家园屋顶可重新放飞同一只风筝。

## S5 根脉圣殿 `root_sanctuary`｜H+W+U1

- **今天**：古老根网本来支撑土壤与地下水；大型钟网的管线施工伤及根系，当日事故烧断几处根桥，护林巨兽封闭通往中央的洞口。
- **重复动作**：祭守给幼苗浇水后把空壶倒一倒，最后一滴落在同一条石缝；这是一轮一天中的一次普通动作。
- **主Boss**：“护根者”，古老森林守护生物，保护被金属管道贯穿的根腹，阻止带中央通行证的主角继续开闸。无人的寿命在树内输送。
- **胜利**：拆下当日卡住根桥的装置、解除其战斗状态，给出通往核心的路。H+W+U1为主；根道开合可解释为既有生物伸缩和机关牵引，不写瞬间跨年生长。
- **A/B/C**：A 保护者似乎反对修钟；B 它反对的是不顾地方安全仍照常运行的工程；C 取得独立疏散/隔离通路，让结束回返不必伴随再次破坏森林。核心主线事实由同层保底终端另呈现。
- **随机房**：“落叶标本”，当地孩子收藏不同年份叶片，最新一格写“下一年”。无须靠年轮检测时间魔法。

## S5 逆时钟塔 `reverse_clocktower`｜W+D+U1

- **今天**：钟塔是世界钟的制动与应急调度站；事故前就进入超负荷，值守者照命令禁止停机。逆时之名来自齿轮反向传动与回返系统用途，不让玩家获得局部倒带。
- **重复动作**：值班文员在交班时找一次丢失的眼镜，眼镜其实挂在衣领；重复由大循环而非独立小循环产生。
- **主Boss**：“最后值守官”，当日安全机器，执行未经中枢许可不得紧急制动的规则，守住制动锁。
- **胜利**：打断本轮安全联锁，拿到当前循环的调度记录/核心路由，不意味着自行结束全局回返。W+D竖井、U1调机关相位，H为选修。
- **A/B/C**：A 可以重启钟；B 读到回返发生前已录入的正式命令，知道不是自然故障；C 找到撤销命令需要满足的操作条件（包含撤销“未合格再来”命令与安全卸载，操作细节由主案统一）。这一必要知识S5三候选都必须提供等价版本。
