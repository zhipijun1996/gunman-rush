# 16区域：同一段历史的三次阅读 V0.2

> 全部为候选。完整因果以 [故事圣经](story_bible.md) 为准，Boss身份见 [Boss设定](boss_narratives.md)，必要事实见 [呈现方案](narrative_delivery.md)。不从植物、天气直接征生命；自然异常来自控制设备失效，征时的受害者是实名账中的人。

## 1. 画面怎样表达时间

每区至少让玩家看见一处“时间正在做错事”，不只放齿轮与钟面：一棵树在数个季节间异常生长；船离港牌永远写明日；饭盒转了一圈，主人还没下班；冰窗内的水滴几乎不落；星空已经前进，官方星图却还指向昨天。

三种装置有不同外形语法：公共校时为开放刻度与多方向连接；留日锁是事故后强行卡住相位的外套锁环；征时层是更旧、向中央单向输送、带人名编号的细管与封蜡匣。**首通拆的是外套锁，第二轮才看懂下面那条更旧的管子。** 不靠发光颜色代替用途，也不将所有金属都画成恶。

固定同一处物件跨阶段变化，避免给16区做48套场景。每区两图：第一图呈现当地生活与异常，第二图把证物、主Boss和节点后果连起来。以下“第三阶段”是归还行动，不等同于全区生态已恢复；结局后仍可有地方残余危险。

## 4. 动作与呈现边界

剧情阅读只在稳定安全台由玩家明确开启；不在跳跃、瞄准、活塞窗口抢输入。动作触发用当前正式武器交互，不因称为“归还接口”就假定所有分支弹体都能命中。

S2森林所有侧室仅H+R；沼泽仅U1+R且每种Lv.2分支有解；峡谷仅W+R。S4所有OR/两移动组合都到同一事实槽；S5第三移动能力仅补支线；S6未见机关替换或重教。需要剧情状态的终端是未来实现项，不能在设计文档里直接视为已可用。

同一路线重复三次也能推进完整主线。换路线得到的是不同人的代价与做法，不是缺一不可的密码片。已救居民房变为新留言、后来人或留下的物件，现实家园与地区近况保持连续。
