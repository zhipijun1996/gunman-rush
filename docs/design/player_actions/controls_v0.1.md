# Gunman Rush｜跨平台武器与钩索操作规范 V0.1（设计提案）

> 日期：2026-10-13  
> 文档状态：**PROPOSED／待操作原型和玩家确认**；武器 Lv.1/Lv.2 已确认的机制、Lv.3 只新增战斗主动技能、共鸣能量的获取与消费规则仍以配套武器文档为准。本稿**提出**操作映射，不表示用户已确认具体按键/手势或已在正式游戏实现。  
> 配套：`Gunman_Rush_武器系统_三级技能与共鸣能量设计_v0.8.md`；`Gunman_Rush_能力锁与16场景关卡设计_v0.3.md`。  
> GitHub：https://github.com/zhipijun1996/gunman-rush ；当前正式输入依据 `docs/controls_contract.md`、`scripts/input/*`、`scripts/ui/touch_overlay.gd`、`config/input_profile.json`，必须实施前再次拉取最新基线。

## 0. 为什么必须统一设计

游戏动作不仅有「普通攻击」：还包括角色移动、可变跳/二段跳/墙跳、钩索瞄准与发动、三级武器主动技能，以及 Lv.2 的三连转向、激光持续、双闪改向、遥控回旋刃与召回、磁雷遥爆、奇点固定期间选择弹射方向。**不能每新增一个分支就增加一枚屏幕常驻按钮，也不能把所有动作塞进“松开右摇杆一定开枪”。**

### 0.1 已存在的正式操作事实（不要误写成已修改）

- **手机**：浮动左摇杆移动、浮动右摇杆瞄准；右杆有有效方向时**松手开枪**；有独立 `JUMP` 键；现有移动＋跳＋瞄准可能需要三指。触控事件按触点 index 捕获，菜单和跳跃先于摇杆命中；右半屏的空白触摸可能启动右浮动杆。
- **键鼠**：A/D 或方向键移动、Space 跳跃、鼠标指向目标；左键**按住瞄准、释放开枪**，相机变换与真实枪口偏移已处理。
- **手柄**：左杆移动，右杆瞄准，右杆由有效偏移回中后开枪；南侧面键跳跃。右杆需要武装与回中确认，避免漂移误发。
- `InputRouter` 目前仅消费 jump、jump_release、shoot_release、interact、drop_through；`PlayerController` 只按正式既有顺序运行跳跃、射击、唯一 PlayerMotor。钩索、Lv.2 持续攻击与情境动作、Lv.3 技能输入**尚不是正式输入协议**。
- 正式平原移动/跳跃不耗射击精力，普通攻击消耗射击精力，合法命中恢复精力及空中弹药。新增共鸣能量独立，不应混用旧资源。

### 0.2 核心操作设计原则（本稿建议）

1. **动作语义跨平台一致，物理按键不必一致**：相同角色状态、aim/action 事件序列应产生同样动作、伤害、位移与资源结算；三端可以采用不同适配手势。
2. **瞄准方向只有一个共享概念，但有明确用途模式**：同一时间右摇杆/鼠标可能控制 `ATTACK_AIM`、`GRAPPLE_AIM`、`BLADE_STEER`、`SINGULARITY_LAUNCH`、`SKILL_AIM`；HUD 明示当前模式，不允许静默把控刃当开枪或把选择弹射方向当投放奇点。
3. **五类基础指令足够覆盖所有武器**：`PRIMARY` 普攻、`GRAPPLE` 钩索、`CONTEXT` 情境副动作（召回/引爆）、`SKILL` Lv.3 主动战技、`JUMP` 跳跃；再加 `MOVE` 和 `AIM/STEER` 连续轴。二段跳/墙跳仍使用 `JUMP`，不要再单开按钮。
4. **同一触摸手势只允许结算一种发射指令**：一个主攻击手势切到钩索/技能/召回，必须取消该手势的待开火，不可同时打出一枪。
5. **手机优先考虑拇指换位与手势连续性**：普通动作不应默认要求四指并发；明确指出当前高精度“移动＋持续瞄准＋持续按跳跃”至少要三接触点的客观限制，在测试后决定双指辅助方案，不假装仅靠调整图标就能消除此限制。
6. **不能为了统一输入而偷改已确定武器规则**：回旋镖必须是右摇杆控刃、按召回键直线回收、真实接刃推动人物；奇点在角色已有位置生成，短时固定和吸引，结束时右杆任意方向弹射；磁雷保留真正的放置/遥爆分离。

## 1. 统一“动作意图”而不是统一每个设备的按法

| 语义 ID（建议） | 意图 | 关键边界 |
|---|---|---|
| `move_axis` | 角色横向移动 | 左轴，场景干扰可影响结果，不接管射击瞄准 |
| `jump_press/hold/release` | 小跳/大跳、空中二跳、贴墙蹬跳 | 使用现有 `JumpAbility` 优先级和可变跳；同帧行为显式仲裁 |
| `aim_update(direction, mode)` | 当前用途的世界方向 | 世界坐标、枪口/角色/飞刃参考点依据模式明确；失焦取消 |
| `primary_begin / primary_commit / primary_end` | 开始/提交/结束一次普通攻击包 | 离散攻击一般 commit；持续激光 begin→hold→end |
| `grapple_arm / grapple_commit / grapple_cancel` | 钩索方向武装/发射 | 必须有合法方向；独立能力和冷却；不触发普通开火 |
| `context_press` | 召回/遥爆等唯一情境功能 | 无可用对象时明确拒绝并反馈；不能误发普通攻击 |
| `weapon_skill_arm / weapon_skill_commit / cancel` | Lv.3 战斗主动技能 | 校验武器等级、战斗共鸣能量、状态；武器特有瞄准规则 |
| `active_aim_mode_changed` | 右侧控制器当前用途 | ATTACK_AIM / GRAPPLE_AIM / BLADE_STEER / SINGULARITY_LAUNCH / SKILL_AIM / NEUTRAL |
| `system_cancel` | 菜单、失焦、死亡、回退、设备换源 | **不**从取消生成 release/commit；不遗留下一次开火 |

**方向采样约定：** 以提交动作时的“最近有效方向”为准，控刃看飞刃本体，钩索和武器看真实角色起点；带接刃的回旋镖返程在 `context_press` 时锁定一条当前位置到角色的**直线路径**，其后不逐帧自动追踪。奇点在 `primary_commit` 时固定位于人物的位置快照，右轴随后切到 **SINGULARITY_LAUNCH**，并非再次选择投放坐标。

**统一的交互优先级（新提案）**：系统取消/死亡/伤害资格与菜单 > 正在执行的不可中断武器阶段 > 当前明确武装的钩索或三级技能 > 情境副动作 > 该手势待提交的普通攻击。若同帧另有 `jump`，保留既有“合法跳跃先于射击”的正式顺序，新增具体例外必须进入状态矩阵与测试。一个已发生的武器攻击包不因输入模式临时切换而产生第二次免费消耗/免费返还能量。

|---|---|---|---|
| 移动 | 左浮动摇杆 | A/D | 左摇杆 |
| 跳跃/二跳/墙跳 | 保留独立 `跳跃`，允许位置/大小自定义 | Space 按住/松开 | **A/南键**默认保留；可选 LT“精密平台配置” |

| 暂停/地图 | 上缘菜单、小地图 | Esc / M | Start/Menu / View（需定义配置） |

### 2.1 手机关键思路：右侧不是堆四颗常驻大按钮

建议把右半区设计成 **“主瞄准区＋两个可拖动起点（G钩索、S技能）＋一个状态情境按钮（召回/引爆）＋跳跃”**；功能有显式标签。具体空间位置、大小、透明度依安全区布局和拇指长度调整。主瞄准区仍可保留现有浮动摇杆；优先验证固定/半固定右侧战斗区是否比全右半屏浮动捕获更不会误触其他按钮。

**主动作单拇指操作示例**：右拇指从主区起触摸 → 拖动选择瞄准方向 → 抬指普通开火；或从 **G** 起触摸 → 拖方向 → 抬指发钩；或从 **S** 起触摸 → 拖方向 → 抬指释放技能。一个触点完成武器/钩索选择与指向，无须右拇指一直按主摇杆、同时另找手指按 G。旋转/返回状态的**召回**应支持直接单指点击，也支持把正在控刃的触点连续**滑入情境按钮区**；进入后该手势不再结算普通攻击。

**保留真实限制**：当前按住左摇杆移动＋按住右侧瞄准＋独立 JUMP 键确实需要第三触点。对于必须同时完成三动作的高难模块，建议并行测试：A. 三指精密操控布局（保留按钮，调整位置，允许自定义）；B. 两拇指辅助（输入缓冲/可选左摇杆上拨跳等方案，但不能与现有向上观察/交互无提示冲突）；不先强制改掉玩家熟悉的操作。绝不把第四指作为通关主路唯一前提。

### 2.2 键鼠关键思路：鼠标位置是天然共享瞄准器

鼠标能一直提供世界目标位置，因此 RMB 钩索和 Q 技能可在按住时用同一个指针不断修正方向；正常左键离散武器仍松手提交，激光 LMB 按住持续照射。回旋镖控刃期间，鼠标控制飞刃运动方向（可用光标相对飞刃的位置作 steering 向量），F 召回。若此时按住 RMB 准备钩索，鼠标暂时切到角色的钩索瞄准，飞刃保持上一有效控制或安全漂移策略；不让鼠标一边同时控制两个不同物体。

### 2.3 手柄关键思路：扳机与肩键解决“方向＋动作”同时输入

**方案 T（推荐试验）**：右杆始终提供方向，RT 启动普攻（离散型可按/抬键提交，持续型按住发射）；LB 发钩、RB 情境动作，Y 技能；A 保留跳跃。这样右摇杆不必松开便能连续调整三连枪的后续方向，也不会因为操纵飞刃或奇点而误发下一枪。

**方案 L（旧版兼容）**：右摇杆回中触发离散普攻，单独为持续激光增加扳机或按住行为。问题：当右杆进入控刃、钩索、奇点模式时，回中**绝不能被解释为普通射击**；三连枪第一发后继续拨杆时，也不能因为回中重复启动攻击包。若旧式控制在多武器上不够顺手，用户可选方案 T，不应未试验就强制替换原版习惯。

**跳跃精密可选映射**：A→LT 允许右拇指始终在右杆、左拇指持续移动时触发跳跃；但 LT 跳＋LB 钩索对同一只左手有组合负担，须提供逐键重映射和可达性验证。保留 A 跳作为第一版兼容；允许带背键手柄将跳跃映射到背键。不得仅以“手柄可以四指操作”为理由免除真实试玩。

## 3. 六条 Lv.2 武器：同一逻辑在三端怎样完成

| 分支 | 共用行为与状态 | 手机动作 | 键鼠动作 | 手柄动作（T 配置） |
|---|---|---|---|---|
| **三连机关枪** | 一次普通攻击提交开启**一个三发包**；每发前可读最新右方向；包内禁止因回中重复开包 | 右主区定向→抬指触发首发，短时**方案 A：再次触摸并拖动**右区改变后两发方向；**方案 B：主区按住启动三连、全过程保留右指控向**（需做 A/B）；没跟进用末方向 | LMB 抬键启动三发，鼠标在后两发前更新朝向 | RS 指向＋RT 开包，后两发继续转 RS |
| **恒流激光** | **持续型是输入例外**：主攻击 begin→持续更新→end；不允许每帧重复开包 | 触摸右主区并拖动＝照射；**抬指＝停束**；G 从 G 区起手，避免先射激光 | 按住 LMB 发束，松开停束；鼠标持续瞄准 | 按住 RT 发束，松开停束，RS 持续选向 |
| **散华双闪** | 一个包三刃、第一后闪＋第二较短闪；第二段允许改变方向 | 第一次主区抬指提交，短暂显示“二闪方向”区；**方案 A：再次触摸/拖动**改向；**方案 B：从主区持续按住，先触发第一闪、拖动改变第二闪、松开收尾**（需 A/B）；无输入时按上次合法方向执行 | LMB 抬键后三刃/首闪，随后鼠标位移决定第二闪 | RT 提交，RS 在第二闪前可调整方向 |
| **回旋手里剑** | 投出后后闪并清速度→`BLADE_STEER`→一键召回直线高速返身→成功接刃产生反冲 | 主区抬指投出；随后主区触摸/拖动控刃（**控刃阶段抬指不再发新刃**）；点击/滑入 `召回` | LMB 抬键投出；鼠标控刃，F 召回 | RT 投出；RS 控刃，RB 召回 |
| **磁吸遥爆雷** | 放置一个合法炸弹实例→人物自由移动→情境键遥爆；与角色相对站位决定反冲 | 主区抬指投放；右侧 `引爆` 按钮，或从主区滑到 `引爆`（须取消待投新雷） | LMB 抬键放置；F 引爆 | RS+RT 放置；RB 引爆 |
| **坍缩奇点** | 普攻触发时在**当前人物位置**生成并固定→有限时间吸引→右方向定向→自动坍缩弹射 | 主区抬指开奇点，立即显示“弹射方向”，右指**重新触摸右区**改向；离指保留最后向量，不会再次放奇点 | LMB 抬键开奇点，鼠标持续改向直到坍缩 | RT 开奇点，RS 始终可改向直到坍缩 |

### 3.1 三个手机重点风险与候选修正

- **机枪和散华都需发射后再次操作右区**。如果第二/第三段衔接过快，玩家来不及重新摸杆，不能靠放大时间窗任意改变已确认游戏节奏；应对比“发射后右侧保持操纵”的替代触发原型。实际按 60/120Hz 和手机录屏量测可控性，定数值前不得宣称已顺手。
- **奇点抬指后要再次触摸才能指定方向**。固定阶段必须允许人类正常手指移回，并始终显示预览箭头；初始方向由触发奇点时**最后有效主瞄准方向**提供（提案）；超时后按已预览方向弹射，不随机、不无限等玩家。另做“按住主区立即启动奇点、不中断触摸直接转向”的触屏专属实验，对比哪种更自然，但不能未经确认改变其他平台语义和资源阶段。
- **持续激光在拖杆时就会发射**，因此触摸 `G`、`S` 或情境区必须从触点起始就确定动作类型，不能先被整个右半屏识别成激光后又取消；激光停束与钩索武装不能无故出现一帧额外伤害。

### 3.2 三级主动技能：统一“技能键”而非每个技能另造一套输入

六个主动技能仅多一次独立 `SKILL` 意图，普通攻击仍严格保留各自 Lv.2 机制。按其动作类型分成三种呈现：

| 主动技能（候选） | 技能输入后 | 方向来源 | 技能后的特殊动作 |
|---|---|---|---|
| 机枪「弹幕风暴」 | 开始有界扫射窗口 | 最新 `SKILL_AIM`，扫射期间右向量可变 | 无新按钮；持续射击随窗口停止 |
| 激光「日晷贯穿炮」 | 短蓄力后一次高伤贯穿 | 技能武装期锁定/更新方向 | 一次强反冲，正常进入后摇 |
| 散华「千刃绽放」 | 一次大范围刃阵 | 技能提交时方向 | 一次强影闪，不进入新的普通双闪控制 |
| 回旋「噬月回刃」 | 发射强化大刃，进入同类控刃状态 | 右区/鼠标/右杆控刃 | **原有情境键召回**、接刃强反冲；不新增按钮 |
| 磁雷「磁暴猎杀雷」 | 投放一枚强化磁雷 | 技能提交方向 | **原有情境键引爆**，借爆反冲；不新增按钮 |
| 奇点「吞星坍缩」 | 原地生成强化奇点并固定 | 进入 `SINGULARITY_LAUNCH` 的右方向 | 到时自动强弹射；不新增按钮 |

技能和肉鸽道具消费共享共鸣能量，**扣费时刻**明确是合法技能启动的单一提交点；后续召回/引爆是同包第二阶段，不再扣第二次技能费用。若用户在控刃/磁雷已经存在时按技能键，新技能是否替换或禁止必须在武器 Definition 明示，不能无声删除普通炸弹/飞刃。技能按钮不足能量时灰化，并给拒绝反馈；输入被拒绝不可隐藏扣费、不可意外发普通攻击。

### 3.3 钩索：独立于六种武器的共同动作

**已确认钩索行为**：横向瞬间射出，命中合适敌人或机关，把角色拉向目标，接触后踢击并向前上方弹起。钩索方向/射程/目标合法性由能力和目标定义管理，不由当前武器分支决定。

**输入规则提案：** 钩索使用统一 `GRAPPLE`，不复用普通射击，也不占用「召回/引爆」情境键。按住钩索武装时右向量临时控制钩索瞄准，松开提交；**横向射出**意味着只接受正向水平扇区或有界瞄准角域，不能因为同一套方向输入就把原有钩索悄悄升级为全屏任意方向发射。若输入方向不合法，显示拒绝/矫正预览，具体角域在能力 Sheet 先确定。

三平台：手机从 G 小区拖到方向、抬指发钩；键鼠按住 RMB、用鼠标目标确认、抬键发钩；手柄按住 LB、RS 定方向、松开 LB 发钩。**被钩中后的拉近与踢跳为武器无关的自动动作**，持续方向修正是否可在拉近期允许由能力测试决定；不额外要求边拉边按跳，否则手机连续操作过重。

连技典型流程：`起跳 → 武器反冲 → 钩索武装/发出 → 命中→拉近→踢跳 → 后续射击/落地`；还须测 `钩索→回旋控刃→召回`、`磁雷放置→钩索→引爆`、`机枪三发中尝试钩索`、`奇点固定时钩索拒绝`。在武器复杂阶段**禁止同时双重控制右轴**：明示钩索优先或明确拒绝；不凭信号调用顺序决定结果。

### 3.4 三个必须实测 A/B 的手机发射问题

**不能为了保留所有分支的“松手才发射”，牺牲多阶段武器最重要的实时操控。** 手机右拇指离开触控屏，输入就中断；这是触屏与实体摇杆的物理差异，不是简单调冷却能彻底解决的。下列三项必须做两个操作原型，用普通玩家盲测而非开发者只看事件日志：

| 操作 | A：兼容松手式 | B：连续按住式 | 判定重点 |
|---|---|---|---|
| 三连机关枪 | 松手开第一发、迅速重新摸主区改第二三发 | 右指拖出方向后，按住期间进入三发包且持续改向；抬指结束控制，完整包不会凭空多发 | 是否来得及改变三次方向、误触、是否丧失瞄准准备时间 |
| 散华双闪 | 松手触发第一闪，重新摸主区改变第二闪 | 持续触摸完成第一闪，拖动改变第二闪方向，松开完成/收势 | 能否准确控制第二闪，以及连招操作节奏是否顺手 |
| 坍缩奇点 | 松手放置，短固定期内再摸主区选择弹射 | 主区在合法起手方向后**主动触发**奇点并继续保持触点定向直到坍缩（必须有清楚起手条件） | 急停速度、定向成功率、虚假的免费等待、是否和普攻触发混淆 |

B 型触控的起手语义只能对对应武器生效，不得改变 Lv.1 基础枪的松手开火或鼠标/手柄的现行基线。B 型不能通过“碰主区立刻开火”粗暴实现；应先验证死区、武装阈值、触觉/视觉预警和误触风险。**如果 A 型明显限制后两段方向，宁愿明确设计对应分支的移动端特例，也不要声称三端按法必须一致。**

## 4. 共用状态仲裁：最容易出现 Bug 的组合

| 当前状态 | 玩家输入 | 建议结果 | 不允许的情况 |
|---|---|---|---|
| 普攻瞄准尚未提交 | 右区滑到钩索/技能/情境 | 主攻待提交取消，切到目标动作的武装或执行 | 同一手势既开枪又发钩 |
| 激光持续射击 | 改按钩索 G | 先明确停束，再钩索武装 | 偷打一帧激光、双倍耗精力 |
| 机枪三连包进行 | 再次触发普通攻击 | 不另开包；右向量只服务当前后续两发 | 三连枪因每次回中变成六连枪 |
| 散华第一闪后 | 输入第二次右方向 | 仅改变第二次闪现方向，不又发一组三刃 | 额外扣一次攻击包、重复起闪 |
| 回旋刃正在控刃 | 按 `context_press` 召回 | 锁定笔直返身轨迹，之后可自由操作角色 | 召回同时发一枚普通手里剑 |
| 回旋刃控刃时 | 发钩 | 先明确切钩索模式，飞刃保持安全运动策略；是否允许需能力组合验收 | 一根右杆同时驾驶飞刃和钩索方向 |
| 磁雷已部署 | 使用钩索后引爆 | 钩索按独立事务，原雷合法保持；再按情境引爆 | 发钩悄悄引爆磁雷 |
| 奇点人物固定 | 普攻/钩索/跳跃/新技能 | 按奇点状态明确拒绝，HUD 标记剩余固定时间 | 中断固定后免费保留全部弹射 |
| 奇点固定 | 右区更新方向/回中 | 改变或保持最后有效弹射方向；到时自动释放 | 回中又触发一发普攻 |
| 技能共鸣不足 | 按技能 | 拒绝，显示缺口；不能启动攻击、不能扣射击精力 | 技能失败却消耗普通攻击包 |
| 暂停/失焦/设备断连 | 释放摇杆/按键 | `system_cancel`，持续效果遵守正式生命周期规则，不由伪造 release 提交攻击 | 恢复时自动射击、召回、引爆或弹射 |
| 死亡/段回退/切场 | 旧飞刃或奇点晚到回调 | 根据 actor/stage epoch 失效，释放持有输入；不污染新角色 | 复活后旧回刃把角色推走 |

## 5. HUD 与可访问性

- 模式态明确：正常时「瞄准」；回旋飞刃「操纵回旋刃 / 召回」；磁雷「已放置 / 引爆」；奇点「固定中 / 弹射方向 + 倒计时」；钩索「G 钩索」；技能「技能待释放」；拒绝时短提示原因。
- 生命、射击精力、共鸣能量三条视觉语义分离；Lv.3 技能按钮明确能量费用/可用状态；不默认把屏幕中心覆盖成巨大技能提示。
- 手机：左右手模式、按钮可移动/缩放、透明度、安全区/异形屏自适应；菜单、小地图、触控摇杆互斥；关键角色落点附近不能被按钮遮挡。触点移动/离开热区维持 capture，并以**起始 action mode** 为主，除了明确的滑入情境切换，避免误触。
- 键鼠：默认键可重映射、鼠标侧键只是可选快捷方式；鼠标/镜头坐标正确，回旋刃控制目标从飞刃本体计算。
- 手柄：摇杆死区与抖动、肩键按下/抬起、不同手柄键标、自定义配置；断连不伪造释放；支持触发键射击与兼容旧摇杆回中射击两套可对照方案。
- 可变跳高按住时间在钩索、机枪控向和激光照射时保持正常，不被全局输入 mode 清空。右摇杆的持续控制是否激活旧 `AirFocusAbility` 必须由明确的 `focus_eligible` 判定，不能控制回旋刃或奇点时无意无限启动慢时。

### 6.1 每个代表武器必须通过的真实操作关

1. **无敌人反冲断桥**：三端用相同技能组合跨越，不能偷用未获得的二跳/墙跳/钩索；验证普通攻击反冲本身仍有意义。
2. **钩索接反冲三平台**：本局仅有 H＋基础反冲。移动、跳跃、瞄准钩索、发钩、踢跳、继续射击。手机重点检查是否出现不得不使用第四根手指的主线动作。
3. **三连枪三向修正**：先向下、再向侧向、最后斜向，三端是否能明确控制第二和第三发；手机若做不到，不能把无输入沿用旧方向冒充“可自由转向”。
4. **持续激光＋钩索交替**：一秒内多次停束/瞄钩/发钩，不能误打激光、错误回能或突然冻结世界慢时。
5. **回旋刃操纵＋真召回**：控刃绕过可合法通行路径，在不同角度召回，再以入射方向接刃反冲。带障碍的回程必须遵守实体碰撞。
6. **磁雷＋移动＋遥爆＋钩索**：先放外部爆心，移动并钩索切换位置，然后遥爆推动自己；必须一键引爆且不同时误发第二雷。
7. **奇点空中急停＋再定向**：发奇点后固定，设备右方向选择斜上、正左、正下，时间到按所示弹射；手机必须有重新拨动时间窗口，不能依赖预知下一方向。
8. **Lv.3 战斗技能＋共鸣道具**：能量足/不足、目标命中/落空、回归原 Lv.2 普攻，符合统一账本并且有可观察的打怪价值。

### 6.2 量化检查（阈值先实验，禁止虚构“已达到”）

记录 `device_profile`, `weapon_branch`, `run/stage/actor epoch`, `gesture_id`, `action_id`, `input_phase`, `aim_mode`, `aim_vector`, `accepted/rejected(reason)`, `attack_packet_id`, `shot_energy_before/after`, `combat_energy_before/after`, `movement_request`, `motor_collision`, `successful_hit`, `touch_finger_count_peak`, `touch_transition_time`, `accidental_fire_count`。统计输入到动作响应时间、有效方向错误率、误发率、重复资源消费、连招完成率、连续操作造成的手指遮挡以及不同武器耗时。与固定 Seed、相同能力快照和同难度关卡一起复现。达到技术正确不等于玩家主观手感达标。

## 7. 未决与提案分级（下一轮需用户选择）

**已经确认的玩法不可改：** Lv.2 六分支逻辑、钩索可抓敌/机关并踢跳、三级只新增强力战斗主动技能、共鸣命中获得与共用消费。

**首选要验证但尚未锁定：** 手柄采用 RT 主动开火还是右杆回中；触屏主区离散开火和持续激光、钩索/技能拖动区域布局；奇点触屏投放后重新触摸定向还是按住即可定向；散华第二闪与三连中途转向在触屏上的可行性；钩索水平瞄准允许的角域；Lv.3 技能的瞄准/充能数值。

**严格不允许 Codex 擅改的事项：** 为简化输入而删除三级技能或任意 Lv.2 分支；用长按单一按钮隐式判断技能类型；把钩索变成武器中的一种弹体；把磁雷改回飞行遥控雷；把回旋镖召回改成自动曲线寻人；让奇点远程投放；用无敌帧/穿墙传送解决异步动作和位移互斥；把技术模拟通过写成人类真机认证。
