## 动作合同

当前运行行为由 [人物物理](../../player_mechanics.md)、[攻击资源](../../combat_and_recharge.md) 及实际Definition／Runtime维护。基础一发空中弹药，射击不耗时间能量；空中枪械与钩索瞄准慢时共用AirFocus。

位移距离、瞬闪／累积推力、回旋控制和触屏瞄准的具体分支合同见 [位移预算](../../quality/action_budget_spec.md)、[武器手感](../../quality/weapon_feel_spec.md)、[全武器](../../quality/all_weapons_spec.md)；恢复事件见 [空中恢复](../../quality/air_action_refill.md)。读取任务涉及的分支与真实消费者。

钩索360°瞄准发射。命中后的拉近／踢跳及有界离开保护只覆盖合法目标的身体接触，取消立即释放；其余伤害来源照常结算。

## 武器与能力

同一时刻只有一种当前武器家族及其等级／分支；同家族的多枚弹体归一个WeaponRuntime。H/W/D是独立移动能力，Lv.3技能属于当前武器，普通攻击保持Lv.2行为。升级／切换验证旧攻击、布置物与回调清理。

正式授予由运行流程决定，练习自由切换用于开发。Lv.3方案与平衡按各设计的提案状态处理；当前入口及实现缺口见 [当前状态](../../current_state.md)。
