## 最新用户补充：单武器

2026-10-13 用户原话：“现在的武器，同一时刻只会有一种。”

- 任一时刻仅一种当前装备/使用的武器家族及其当前等级/分支；不设计双持、并行武器槽或跨武器同时攻击。
- 同一武器可能具有多枚飞刃、三连段序、光束或布置物；它们属于同一个 WeaponRuntime，数量遵守该分支的攻击包和实例上限。单武器不等于只能存在一个弹体。
- H/W/D 为独立能力，可按动作仲裁与当前武器衔接；钩索不占第二武器槽。Lv.3 技能属于当前武器，普通攻击保持 Lv.2 行为。
- 武器是否可在局中切换、切换时机、开局解锁/选型仍未确定，不因“只有一种”自行增加换枪功能。U1/U2 已确定的分支选择与沿分支进化继续适用。
- 若后续存在更换/撤销/进化，必须验证旧攻击、布置物和回调的退出，具体清理/继承策略先进入设计卡；禁止旧飞刃、旧雷与新武器并行运行或污染新动作。当前阶段不擅自定所有进化阶段的中断政策。
