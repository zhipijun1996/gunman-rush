# 森林 v16 返省与取舍

任务 FOREST-VARIETY-03。依据[用户原话与截图信息](forest_variety_feedback_20261022.json)。v16 被明确否定；v15 的关卡设计获得肯定，待改的是体量、曲线、模块库与真实随机变化。旧技术收据保留原范围，不能冲销用户体验失败。

失误来自四个具体判断：把保留旧设计的优化扩大成替换骨架；把模块ID和图边数量当体验差异；在固定四段“主路/上方探索/更上大师”骨架内填充几何；让任意高差连接器每64wu补短平台，最后用路线通过汇报交付。代码源为forest_exploration_world.gd的build与_connect。上轮独审已指出长矩形根体和规则浮梯REWORK，仍被送入试玩，交付判断失败。

本轮保留v15的真实动作、空腔、生态和探索环，只在新版本扩展。模块先列它新增的观察/决定/去向/回报，明确旧复用、同族变体和新机制；没有实际不同判断的不计新增趣味。先测黄金和最便宜强替代，再接邻接；有高低出口还须在世界中进入不同目的地。多种子审查实际实体、连接与奖励关系及正常镜头，不把驾驶推荐变化算地图随机。

本轮已有技能已要求这些步骤，问题在执行，不能靠继续增加大流程解决。开发用受影响短反馈，试玩用快速Web；技术、专家判断、用户和设备分别记录。全图尚未通过时不发布成成功扩容，明确保留旧可玩版本。

用户同时要求：“同时要反省，为什么会出这样的错误”。不能归咎CI：CI的可达性检查只回答它被设计检查的问题，我把技术通过扩大成关卡质量、忽略已存在的艺术反对意见，才造成错误交付。

本轮独审又抓到同一种风险：新world签名把整个instance/program算作物理差异，虽然果实配置确实变了，新增平台布置却每map只有一种。原通过原样保存；新guard改为实际rect/one_way排序去重，明确排除ID/program/顺序/重复描述，真实拒绝当前候选两项。挪1wu/拆矩形也不能以此签趣味，人工机制/拓扑/画面判断仍必须成立。此事说明改口号不够，要让实际反例能驳回自己的结论。

目前可保留的成果是旧关卡正常探索、新休整侧根、指定附林/L出返的真实动作与奖励事实；新附林矩形大形两轮仍REWORK、随机丰富度不足，所以不发布。公开旧v15已实际恢复，新的失败不转嫁给玩家重复试错。
