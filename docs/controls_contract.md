# 输入契约

左轴 [-1,1] 控制横向速度。上下阈值 0.65，回到绝对值 <0.35 后重新武装；上请求交互，下请求单向平台穿透。跳跃按下沿请求一次起跳，保持状态控制升程，释放沿请求截断升程；短按小跳、长按大跳，不因保持而重复起跳。

左摇杆、右摇杆、跳跃键分别捕获 touch index，捕获后拖出控件仍归原控件，释放不影响其他手指。右杆初始死区半径 22%；死区内 current_direction=ZERO，回中心再松手取消。有效松手复制最后有效非零世界单位方向，再归零；一次释放至多一个请求。触控坐标不泄漏到玩法接口。

原型屏幕基准 1280×720；安全区相对锚点，半径/按钮大小可调。横屏、长宽比与边缘操作列入真机验收。移动+跳跃+瞄准需要三指，允许调布局，不擅改松手开枪。

动作队列最多 16 项，保留 100ms；超限丢弃新项并调试告警。每物理帧消费全部有效请求；同 tick 保留 jump/jump_release 的原始先后顺序，仅合并连续同类跳跃边沿，避免快速按放按被分类排序破坏；射击取最后有效方向；其他请求记录拒绝原因，不跨冷却排队。jump buffer 在 JumpLogic 中独立计时，不与队列重复延长。

clear(reason) 清轴、队列、捕获、缓冲并递增 epoch。暂停、死亡、系统取消、失焦调用；恢复需新触摸或新武装。真实触摸启用时过滤模拟鼠标。断连、暂停、失焦以及动作映射修改是取消事件，取消路径不能调用释放射击路径。

## 统一动作意图

TouchAdapter、KeyboardMouseAdapter、GamepadAdapter 各自产生横轴、上下交互、jump 按下沿、jump_release 释放沿和 shoot_release(direction)。统一经 InputRouter 消费；direction 是有限、非零的世界单位向量。单个手势属于发起它的适配器；设备提示切换不迁移未完成手势，也不把旧设备状态转换为射击。Router 的 tick 合并与 epoch 规则对三种设备相同。

## 键鼠

默认 A/D 或左右键移动，W/S 上下交互，Space 跳跃；鼠标位置经相机变换用于世界瞄准。射击动作默认鼠标左键：按下进入瞄准/武装，移动更新有效方向，释放时提交一次射击请求。只有一次有效按下后产生的释放才可射击；无有效方向、失焦、暂停或取消后的释放均不产生请求。可重映射射击按键，保持释放触发的语义。键鼠不受触屏半径或分辨率限制。

## 手柄

左摇杆移动与上下交互，独立跳跃动作默认南侧面键；右摇杆瞄准，回到死区触发射击。右轴先应用配置的灵敏度/曲线与径向死区，再转换为世界方向。输入档案使用 enter_deadzone、exit_deadzone（0 ≤ exit < enter < 1）、arm_confirm_ticks 和 center_confirm_ticks（正整数），以固定物理 tick 确认状态，避免渲染帧率改变防抖。默认值在实际引入 InputProfile 时建立唯一配置来源，不提前用文档数值替代调参文件。

状态与方向缓存契约：

1. 初始或取消后 WAIT_NEUTRAL：先观察到连续 center_confirm_ticks 的中心状态（幅度 ≤ exit_deadzone），才进入 READY；重连或恢复时已偏移的摇杆不能直接武装。
2. READY：幅度连续 arm_confirm_ticks 达到 enter_deadzone 后进入 ARMED；期间保存最新有效非零方向。小幅噪声与两阈值间游移不能武装。
3. ARMED：有效偏移继续更新 last_valid_direction；中心状态进入 CENTER_PENDING，冻结回中心前的有效方向。中间滞回带不更新有效方向、不触发射击。
4. CENTER_PENDING：连续 center_confirm_ticks 处于中心才提交一次 shoot_release(last_valid_direction)，然后清缓存回 READY。确认过程中离开中心会取消本次确认、返回 ARMED；真正有效的新偏移才更新方向。
5. READY 需再次满足完整武装条件才能再射；保持中心或阈值噪声不能重复射击。任何状态发生手柄断连、失焦、暂停、死亡或系统取消，立即清缓存并回 WAIT_NEUTRAL，不提交射击。

若多个状态转换在同一物理 tick 被采样，只采用本 tick 最终有效轴与已确认状态，不能用瞬时噪声完成武装和回中。输入采样序号与 Router 去重确保一次回中至多一个请求。手柄射击冷却或资源拒绝后也需重新武装，不能中心等待到冷却结束后自动重射。

## 提示、布局与配置

Android 横屏显示左/右摇杆与独立跳跃键；桌面隐藏触屏控件。提示根据最近有意义的触屏、键鼠或手柄输入切换，手柄漂移、设备连接事件、模拟鼠标不抢提示。连接状态与当前提示设备分别记录；手柄断连清其状态，下一次有效键鼠/触摸输入更新提示。

InputProfile 支持独立的左右杆死区、灵敏度/响应曲线、手柄按键映射、键鼠按键映射及触屏布局大小。物理参数仍来自 PlayerTuning，不能通过输入配置改世界重力、跳跃速度或反冲强度。单次按键对应一个动作，冲突映射需校验并提示；修改、恢复默认或加载配置时取消旧输入。具体配置 UI 按任务引入，不能声称本文已实现。

跨设备验证覆盖相同意图的动作顺序、取消和资源事务；跨屏幕验证相同物理初态/意图的轨迹，屏幕仅影响布局与瞄准坐标转换。触屏手感与性能仍必须 Android 真机验收。

## 本轮输入配置来源

输入配置唯一来源为 config/input_profile.json，由 InputProfile Resource 加载。原 player_tuning 的 aim_deadzone 迁移为独立设备阈值，物理/战斗参数仍只在 player_tuning.json。手柄默认 enter=0.22、exit=0.15、武装/回中各2个物理tick，左杆死区0.18；触屏右杆死区0.22，触屏回中心松手取消。键鼠按键/射击键和手柄跳跃键可通过配置重映射，加载/修改会取消旧输入。配置接口与实际设置 UI 分开验收。

## 可变跳高持有与取消

Router聚合触屏、键鼠、手柄的跳跃持有者：首个持有者按下产生jump，最后一个正常释放产生jump_release，键鼠多映射键也聚合。触屏捕获后拖出按钮仍保持，松手才释放。系统取消清状态，不生成普通释放或射击。恢复后旧按住输入须先释放再按下，不重新起跳。三种设备使用同一JumpAbility计时，不以渲染帧率或屏幕尺寸决定跳高。

## 主动瞄准慢时意图

Router增加aim_engaged，独立于aim_direction预览。触屏有效右杆、手柄已武装的有效右杆偏移、键鼠按住射击动作才置为true；归中、释放、切设备及clear置false。适配器只报告意图，不操作Engine.time_scale。空中资格、精力和倍率由AirFocusAbility决定。暂停/断连/失焦保留取消规则，无伪造射击。精力耗尽只关闭慢时，不取消合法瞄准/松手射击。
