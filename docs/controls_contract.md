# 输入契约

左轴 [-1,1] 控制横向速度。上下阈值 0.65，回到绝对值 <0.35 后重新武装；上请求交互，下请求单向平台穿透。跳跃只在按下沿触发。

左摇杆、右摇杆、跳跃键分别捕获 touch index，捕获后拖出控件仍归原控件，释放不影响其他手指。右杆初始死区半径 22%；死区内 current_direction=ZERO，回中心再松手取消。有效松手复制最后有效非零世界单位方向，再归零；一次释放至多一个请求。触控坐标不泄漏到玩法接口。

原型屏幕基准 1280×720；安全区相对锚点，半径/按钮大小可调。横屏、长宽比与边缘操作列入真机验收。移动+跳跃+瞄准需要三指，允许调布局，不擅改松手开枪。

动作队列最多 16 项，保留 100ms；超限丢弃新项并调试告警。每物理帧消费全部有效请求；同 tick 同类合并为一次，射击取最后有效方向；其他请求记录拒绝原因，不跨冷却排队。jump buffer 在 JumpLogic 中独立计时，不与队列重复延长。

clear(reason) 清轴、队列、捕获、缓冲并递增 epoch。暂停、死亡、系统取消、失焦调用；恢复需新触摸。真实触摸启用时过滤模拟鼠标。键鼠：A/D 或左右键、W/S 上下、Space 跳跃、鼠标拖瞄释放射击；统一经 Router。
