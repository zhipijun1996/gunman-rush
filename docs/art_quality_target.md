# 正式美术品质目标与平原精修路线

2026-10-10 用户反馈：现有美术不够满意、不够精美。本反馈覆盖将现有简化 SVG 视为最终风格的旧理解；已接入的功能、素材来源、尺寸和碰撞契约继续保留。世界背景以 [world_and_story.md](world_and_story.md) 为准，区域候选以 [world_regions.json](world_regions.json) 为准。本文是制作与验收目标，没有宣称已完成新素材。

## 目标画面

原创精致手绘童话：有设计感的角色剪影、自然的笔触、可信但适度概括的材质、柔和体积光和清楚的前中后景。平原明亮开阔，深处有衰败痕迹；其他区域通过光照和材质形成不同情绪。宏观轮廓、材质与少量故事物件构成精美感；纹理、粒子与装饰密度按实际屏幕控制。

已有平原概念图作为方向参考，实际关卡需要接近其材质、空间层次和光色关系。角色、平台、机关和背景需出现在同一幅实际游戏画面中评价。最终品质判断来自用户对合屏画面的认可，不以文件数量、XML 有效、导入成功或概念母版代替。

## 当前问题及修正

| 当前问题 | 精修目标 | 验收方法 |
| --- | --- | --- |
| 草岩表面像重复规则砖块，材质平且重复明显 | 不规则石层、土壤断面、稀疏苔草，轮廓与站立边有明确层次；用多种表面和独立装饰打散重复 | 连续长平台、深竖井和多种宽度均合屏检查 |
| 天空和山体偏几何色块，空间缺少细腻变化 | 云层体积、远山冷暖与大气透视；中景保留低对比并控制叙事物件数量 | 实际镜头平移/升降和手机缩小画面检查 |
| 角色与机械缺少统一绘画质感 | 同一套线条、受光和材质；布料与黄铜有区分，小尺寸仍保留面部与动作识别点 | 六动作、左右朝向、全角度瞄准与背景合屏 |
| 手绘 PNG 有透明光晕、中心偏差或不能拼接 | 通过 AI 编辑生成干净部件；校验 alpha、锚点、尺寸、接缝；未过关继续作来源候选 | 深浅底交替、重复铺贴、旋转及状态切换 |
| 模块重复既有造型而缺少地区身份 | 风铃花、维修站、木桥、风车构成平原记忆点；石材/机械作为共同世界语言 | 多个种子截图比对：功能一致、视觉有变化 |

## 全 AI 生产策略

AI 图像模型负责母版、材质和独立部件，AI 代码负责动画、图集、重复、遮罩和引擎接入。人负责选稿与验收。运行 SVG 暂作功能占位及低成本回退，不能以其数量证明精修完成。需要说明每件候选的来源和自动处理记录，不能把透明选项当作有效透明证明。

先建立一个平原黄金样板：角色站立/移动/空中姿态、草岩长平台与短落脚台、机械移动台、锯轮、补充物、安全锚点、两层以上背景和实际 HUD。以相同镜头和几何比较现有运行画面与精修画面。先定稿少量关键母版，再按母版编辑部件与变体；禁止各资产独立从文字提示重新发散。

角色精修保留脚底原点和独立武器肩轴；复杂材质仍需要六动作下的一致轮廓。机关使用独立贴图和程序运动，动态受光不画成只适用于单一朝向的强烈阴影。地形需要端头/中段/填充/转角/薄平台，不用整张关卡图覆盖随机地图。背景按层制作；单张绘画母版可以作氛围参照，未分层、未验循环就不作为无缝视差完成品。

图标、按钮和文字区域保持跨地区共用；图标可细腻，HUD 不大量遮挡落点。风铃花的家园语义、段内锚点的安全语义、资源装置的补充语义各自保持。故事特殊光效不抢功能颜色；停时效果不停止玩家输入或物理。

## 随机地图兼容

精修只更换表现，不改模块端口、站立面、碰撞、资源位置、机关轨迹与相位。横向地形循环、非等宽端头、内外角和遮罩按相同锚点接入；重复纹理之外的苔藓、破损和草叶以独立稳定装饰流添加。装饰进入已声明安全区，落点、危险扫掠范围和补充目标保持净空。

同一区域使用统一光源与色彩约束，昼夜/天气变体后置；不能让一个随机种子里每个模块有不同光照。横向、纵向、镜像和大高差都要验：背景不能在每段重置、竖向无限重复地平线、让高空变成空白或产生强接缝。当前单张背景的垂直覆盖限制需由世界相机和背景规则解决。

记录 `style_version/skin_version/asset_manifest_hash/decoration_seed`，保留玩法 Manifest 与表现 Manifest 的边界；新画面不能重抽正在游玩的关卡。新材质若影响平台判读，则调整美术而不是偷偷修改可达性或物理。

## 分批交付与通过门槛

1. 平原黄金样板：关键母版与固定挑战一段，展示原画尺度和实际手机尺度，由用户评价精美程度。
2. 模块精修：端头、循环块、填充、角件和装饰，覆盖短板、长岸、深井、断桥、升降台及左右镜像；真实接缝和透明边缘通过。
3. 表现统一：六类角色动作、瞄准/反冲、机关状态、特效与 UI 合屏，无漂移、闪烁和危险遮挡。
4. 随机批检：相同 Seed 的新旧画面对照、多个布局截图、真实相机运行；只验证美术覆盖，不冒称所有 Seed 可通关。
5. 性能与主题扩展：实际目标设备记录贴图内存、透明叠层、加载和帧时；平原通过后，再用同一套品质标准制作森林与古堡。
