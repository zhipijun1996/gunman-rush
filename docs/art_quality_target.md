# 美术品质目标

全局风格与采样唯一由 [Visual Bible](visual_bible.md) 维护，地区体验由选定Bible描述。品质以真实游戏镜头中的轮廓、材质、空间、光色、动态与可读性评价。

| 方面 | 目标 | 审查方式 |
| --- | --- | --- |
| 一致性 | 角色、地形、机关、物件与UI具有共同尺度及材质语言 | 正式区域合屏与跨区域对照 |
| 空间 | 围合、负空间、支撑与景层表达去向和场所身份 | 正常镜头移动、回望、纵横覆盖 |
| 可读性 | 危险、敌人预告、落点与交互目标可辨 | 真实角色／UI、手机缩小代理及实际设备 |
| 动态 | 身体与附件连续，反馈时点吻合接受事件 | 正常速度连续音画及必要逐帧定位 |
| 技术 | 接缝、alpha、锚点、采样、导出与预算有效 | 静态检查、实际GPU与PCK消费者 |

先完成一个真实黄金窗口，再扩资产族和不同结构空间。审查列实际观察图像／片段、位置、发现与修复；技术指标与AI专业判断不替代用户审美认可。未知项按 [开发质量](development_quality.md) 保留未验证。
