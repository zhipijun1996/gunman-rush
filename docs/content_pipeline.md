# AI 内容制作流程

目标：角色、动画、环境、UI、特效、音效、音乐尽可能由 AI 制作。已交付并接入平原demo候选；用户尚未认可其视觉精美度，正式精修素材未定稿，不承诺不存在的工具能力。

## 风格与制作

当前流程权威为 [Visual Bible](visual_bible.md)、[动画特效标准](animation_vfx_standards.md) 和 [G0–G5](development_quality.md)。童话手绘定位已明确，具体黄金样板仍须用户认可。参考优秀游戏的设计方法，不复制其形象、地图、素材或具体实现。历史三候选探索不构成新任务的固定数量要求。

每件素材记录 asset_id、类别、工具/模型/版本、prompt、生成日期、源文件、导出参数、来源/授权、人工修改和验收状态。沿用已建立的 assets/manifest.json。不能推断 AI 输出自动拥有所有商业权利，记录所用服务条款。

角色帧统一尺寸、脚底锚点、方向与透明背景；碰撞体独立于美术。先验证 idle/run/jump/fall/recoil/death 的一组样片，再批量生成。危险、可补充与背景必须视觉可区分；在手机缩小显示下检查。

## 音频

音效按 shot/recoil/land/recharge/death/checkpoint 事件驱动，记录采样率、格式、响度与峰值；通过 Audio Bus 控制音乐/音效。短音效 WAV，长音乐候选 Ogg，最终按设备加载预算验证。
音乐先做一段 30–60 秒原创循环：检查接缝、突变、削波和重复疲劳；记录 BPM、loop_start/end、工具授权。后期按区域或强度切换，不能影响物理时钟。

工具缺失时记录阻塞与生成提示词，不伪造音频。筛选 → 导入 → 真机观感/听感 → 定稿；源素材体积大时评估 LFS，不直接塞入普通 Git。


## 平原区域美术接入（ART-PLAINS-01）

用户授权复用美术分支风格作为第一个平原大关基础。权威素材与连接规范见[美术接入](demo_art_route.md)、[地形](terrain_art.md)、[背景](background_art.md)、[角色](character_art.md)。草顶冷灰岩石、低饱和青绿远山与旧黄铜机械保持跨模块连续；前景危险红橙、射击青色/跳跃琥珀语义保持。后续小模块、大动作段、转折/分叉均沿用功能轮廓与连接契约，不以装饰改变关卡可达性。

PlainsTerrainSkin仅绘制既有Rect2，端头裁剪/中段重复/填充裁剪，顶面精确对齐；PlainsBackground一个区域一实例，横向视差/无竖向循环，任意高差与镜像使用同一背景。PlayerVisualAdapter只观察角色与能力，枪/飘带纯视觉超出碰撞但不增加命中体。历史八关开发消费者已接入；当前正式两图探索、固定开发关与独立随机试玩共用平原皮肤；当前原创多层/动态图集见plains_visual_refresh.md。手机美术可读性/性能及风格最终确认仍待用户试玩；候选PNG未校准，不强行铺成无缝平台。


## 世界锚点驱动素材生产

新区域制作先读[世界与故事](world_and_story.md)、区域视觉/机制/故事目录，再沿角色比例、描边、锚点、顶面和功能色契约制作前中后景/平台连接件/独立装饰。概念图和同一AI提示词都不能替代透明边缘/接缝/比例/真实引擎检查。新形象与剧情工作名不自动取代courier候选。颜色与叙事能换，碰撞/动作逻辑只按独立验证机制扩展。

## 精修管线与停止扩产条件

用户2026-10-10指出当前美术不够精美。正式制作以[品质目标](art_quality_target.md)和[区域场景介绍](world_and_story.md)为准。现有89 SVG与2手绘PNG运行候选用于接口、拼接与功能参考；源图、候选、被拒绝图和已集成素材分别标记。不得再将导入成功称为视觉完成。

下一批先做平原黄金样板，从统一母版编辑角色部件、端头/中段/填充、机关与背景层，记录模型/参考版本与处理参数；将它们放入已有固定挑战，以相同镜头比较。透明光晕、错锚点、接缝、材质不一致或手机缩小不可读时继续修订，不以低细节矢量回退冒充用户认可的精修。用户认可黄金样板后再生成变体和随机装饰。仍以AI图像编辑和AI程序生产为主，人工负责筛选与验收。

## 当前资产合同（质量规范 v1）

先区域黄金合屏，后扩展资产。概念设计 → 母版确认 → 拆解 → 变体 → 透明/尺寸/锚点 → Godot 接入 → 合屏 → 用户质量验收；拒绝的母版保留并返工。模块地形覆盖长短/端头/内外角/厚度/表层填充/镜像/高低差/连续背景/装饰，不为拼图改变碰撞。

沿用 assets/manifest.json，新建或修改素材附 [资产规格](templates/art_asset_specification.md) 和 [元数据](templates/art_asset_metadata.json)，实例放 docs/quality/asset_records/。记录来源文件哈希、工具/模型、提示词或参考母版、处理方式、内容版本、实际使用路径/范围及授权来源/状态。未知写 unknown；旧资产不倒填模型或许可。原图和动画源文件继续遵循既有存储方式，元数据不能代替源素材。

工具只核对字段、路径、哈希和最终许可/认可证据存在，无法判断服务条款或合屏是否精美。美感、动作及玩家认可在同一质量记录分别验收；静图/音轨缺失/仅导入不算完成。

## 可变尺寸地形：边界先于变体（2026-10-13）

地面、墙、空中实体平台共享一套碰撞轮廓契约：四条边、四个凸角、四个凹角和内部填充；单向平台、移动平台另有明确的材质语义。先做整套边界母版和实际合屏，再扩展长短变体。禁止把完整物体（含端头）当作中段重复，也不能只让某个标准长度看起来正确。

素材规格必须记录：统一像素密度、站立线、连接口宽/高、边缘厚度、透明轮廓、凹角锚点、四边连接签名、可镜像方向、变体池和拼接兼容组。长度由中段重复/裁切及兼容变体组合；端头、转角不随长度拉伸。厚度超出素材适配范围时使用内部填充和对应上下边，不能拉长整张图片。跨模块边界用实际实体并集判断，内部接缝不画外轮廓。

自动检查覆盖短于双端头、长条、薄片、高墙、阶梯、L/T连接、重叠实体、内凹角、镜像、不同世界坐标相位；比较几何覆盖、边角选择、碰撞不变和连接签名。图像像素接缝检查只能证明指定连接条相容，不能自动证明自然或漂亮。连续运行合屏另外审查重复纹理、明显接缝、假可通行空洞和视线遮挡；未通过的生成图保留为候选，不得写最终可无缝拼接。

最新可变地形细则：[邻接与拼接契约](quality/terrain_tile_contract.md)。八方向边框不等于完备素材集；按局部拓扑枚举、共享接口、多格分块不变性及真实渲染验收。上一轮边框拼贴已被拒绝，不作为通过母版。

2026-10-13：已认可水粉石灰岩晋级正式平原；复用经验统一维护在 [地形契约](quality/terrain_tile_contract.md) 的生产/晋级规则，art-director、level-module-creator 和 gameplay-reviewer 共同引用，不再复制不同端头问题的特例清单。
