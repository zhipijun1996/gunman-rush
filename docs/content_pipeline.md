# 内容生产与资产接入

## 从用途到运行

1. 确认目标地区、玩家行为和实际镜头，从 [创作入口](creative_direction/README.md) 加载选定设计与当前技术参考。
2. 明确资产空间用途、完整轮廓、材质、锚点、采样与状态；先制作一个母版并接真实消费者。
3. 验证黄金合屏、连续动作、边界与生命周期后扩同族，再在不同结构空间核复用。
4. 用现有导出、许可与PCK检查验证实际资源闭包。

地形尺度由 [Visual Bible](visual_bible.md) 定义。47邻接、精确边界、solid／one-way／moving分别保持语义；装饰使用独立随机流和keepout。几何、纹理与碰撞各有明确所有者。

## 来源与登记

每件素材记录稳定ID、工具／模型、提示词、原文件、派生步骤、SHA、锚点／切片、来源、许可与运行消费者。沿用实际资产manifest及质量登记，原图与派生资源分别保存。来源未知时如实记录。

## 音画与发布

动作按 [动画标准](animation_vfx_standards.md) 接接受事件，声音按实际事件、并发和生命周期接入。BGM使用用户提供素材；SFX交可听候选及Godot原声对照。

临时输出进入build，精选证据保存真实来源与范围。按 [协作交付](cloud_production.md) 提供短片／Web／工程报告；公开资源核实际下载、版本和完整性。
