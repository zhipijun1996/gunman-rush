# AI 内容制作流程

目标：角色、动画、环境、UI、特效、音效、音乐尽可能由 AI 制作。当前未生成正式素材；不承诺不存在的工具能力。

## 风格与制作

按 [已确定风格](visual_and_gamefeel.md) 产出三种小范围候选：均以苦痛之路的手绘、幽暗层次与精密动作气质为方向，探索原创世界观与色调。用户选择具体方案后建立 style guide，不把整体风格重新标成未定。灰盒继续独立开发。

每件素材记录 asset_id、类别、工具/模型/版本、prompt、生成日期、源文件、导出参数、来源/授权、人工修改和验收状态。放 assets/manifest.json（引入首个素材再创建）。不能推断 AI 输出自动拥有所有商业权利，记录所用服务条款。

角色帧统一尺寸、脚底锚点、方向与透明背景；碰撞体独立于美术。先验证 idle/run/jump/fall/recoil/death 的一组样片，再批量生成。危险、可补充与背景必须视觉可区分；在手机缩小显示下检查。

## 音频

音效按 shot/recoil/land/recharge/death/checkpoint 事件驱动，记录采样率、格式、响度与峰值；通过 Audio Bus 控制音乐/音效。短音效 WAV，长音乐候选 Ogg，最终按设备加载预算验证。
音乐先做一段 30–60 秒原创循环：检查接缝、突变、削波和重复疲劳；记录 BPM、loop_start/end、工具授权。后期按区域或强度切换，不能影响物理时钟。

工具缺失时记录阻塞与生成提示词，不伪造音频。筛选 → 导入 → 真机观感/听感 → 定稿；源素材体积大时评估 LFS，不直接塞入普通 Git。


## 平原区域美术接入（ART-PLAINS-01）

用户授权复用美术分支风格作为第一个平原大关基础。权威素材与连接规范见[美术接入](demo_art_route.md)、[地形](terrain_art.md)、[背景](background_art.md)、[角色](character_art.md)。草顶冷灰岩石、低饱和青绿远山与旧黄铜机械保持跨模块连续；前景危险红橙、射击青色/跳跃琥珀语义保持。后续小模块、大动作段、转折/分叉均沿用功能轮廓与连接契约，不以装饰改变关卡可达性。

PlainsTerrainSkin仅绘制既有Rect2，端头裁剪/中段重复/填充裁剪，顶面精确对齐；PlainsBackground一个区域一实例，横向视差/无竖向循环，任意高差与镜像使用同一背景。PlayerVisualAdapter只观察角色与能力，枪/飘带纯视觉超出碰撞但不增加命中体。正式主题定义/随机十关尚未接入，当前固定十关与独立随机试玩均使用平原候选皮肤。手机美术可读性/性能及风格最终确认仍待用户试玩；候选PNG未校准，不强行铺成无缝平台。
