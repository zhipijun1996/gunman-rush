# D063 平原变化度：先改变一关的玩法结构

状态：宏观骨架与防重复仍为设计提案。D064已补入三种机制段落组合，见[本轮修订](plains_encounter_revision.md)；宏观图仍是一次分岔端口树，不能把段落主题当新拓扑。用户要求“每次进入有新体验”，本轮先修复默认固定种子，并完成输入试调。正式8关/Boss8、主题与关卡类型分离、末端单门、唯一Motor与版本化Manifest继续有效。

## 现状与根因

家园出发此前默认`rush-demo`，只要不改种子，就会重复相同内容。本轮默认空种子改为每次正式出发生成128位随机种子；显式种子仍原样使用，进入一局后所有地图、路线、奖励、商店和掉落仍使用各自确定性随机流。生成、死亡段回退与重放过程中不重新抽种子。种子写入现有RunManifest；随机新局不等于骨架已经多样。

`PlainsBranchLayout.generate`当前固定安全开头、公共挑战、同类分岔；后期上路升阶、下路宽沟，随后交替安全板和LIGHT模块。180个Seed产生172张不同布局，只证明坐标/模块组合不同，不能证明玩法体验不同。继续扩同类平台或任意叠齿轮，收益有限，并可能遮挡落点、产生无解组合。

## 建议采用的五层生成

1. **整局节奏**：8关中交替学习、强化、奖励/恢复和高潮，Boss第8必达。普通/金币/道具等是结算类型，独立于空间骨架；金币房也能是攀升或横渡。当前阶段曲线是候选，不替用户锁定最终平衡。
2. **整关骨架**：先确定空间图、分岔/汇合、净空和两个末端门，再填模块。左下安全开局不变，向上、横向或折返决定这一关的主要体验。不能靠旋转横向模块改变重力。
3. **挑战段落**：每关选择一个主机制、一个辅助机制，按“展示→变化→组合→喘息”组织。大模块负责连贯动作，小模块负责间距、落脚、分支和恢复；段落必须有安全观察位及挑战段起点。
4. **经过验证的模块变体**：离散平台间距/高差、机关轨迹/周期、敌人位置、镜像和可选支路来自验证集合，不任意连续拉伸。改变碰撞、危险或相位组合必须改变内容版本。画面装饰可单独随机。
5. **奖励与风险选择**：一条路稳定但收益普通，另一条更难但额外收集更丰富；明确显示风险和去向。敌人可绕过，金币/音符引导可选技巧路线；关键能力不靠随机掉落赌必经路可达。

## 首批六种骨架候选

| 骨架 | 主要动作与平原意象 | 组合约束与变化 |
| --- | --- | --- |
| 断桥横渡 | 普通跨跳→反冲跨沟→安全落脚，草甸断桥 | 长短间隙与上下绕行；反冲主路按当前能力准入 |
| 风车攀升 | 左右交错升降板、下射抬升、塔身侧路 | 安全等候台与镜头前瞻；锯轮不能堵住唯一着陆区 |
| 河谷下潜再上行 | 左下开局先上坡，进入谷底，再沿两岸攀回 | 下落有可见落点，不做盲跳；上下路线分别连通末端门 |
| 遗迹折返 | 先右行登高、向左折返、再选择两个终端路线 | 用高度分隔往返路，反向端口和接缝需真实轨迹验证 |
| 草甸双环路 | 两次分岔/汇合后再选择末端，短险路与长稳路 | 奖励唯一实例归属；汇合不能重复刷资源；第一版先做一处分岔再汇合 |
| 长段技巧挑战 | 一个手工大段落配若干微模块，连续反冲/摆渡 | 保留完整设计节奏，中间不插随机机关；难点前后安全恢复 |

优先实现断桥横渡、风车攀升、遗迹折返三种差异明显的骨架，再扩其余。每个骨架先做一个固定黄金样片和两种可验证编排，避免先造几十个未接入的定义。新增元素优先选会改变操作的升降板、横移板、可绕行机关、空中敌人；风/易碎板等新物理机制另立任务，不能直接塞进生成器。

## 组合算法与防重复

先由RoutePlanner/局内节奏选关卡类型，再由局部StageBlueprintPlanner选择骨架和空间区域。EncounterComposer把“动作段+观察台+资源恢复点”按动作预算填入区域，LevelGenerator现有模块实例化/端口/碰撞校验继续复用；不上万能全局事件总线，也不让玩家控制器知道地图类型。

模块接口补充入口/出口方向、高度带、可接受落地速度、所需跳跃/射击次数、资源恢复、动态机关完整包络及观察位置。动作难度通过动作链复杂度、容错宽度、时机与路线长度控制；不把机关数量直接等同难度。手机基准路线允许大幅移动/中立停步完成，不要求精确保持0.37一类连续轴值。调整移速后重算筛选包络并跑真实Motor，几何图连通不冒充可达。

同局使用按Seed确定的骨架袋与近期挑战标签历史，避免连续同骨架、连续重复核心动作序列，并限制连续高压。先把防重复范围限定局内，直接由已记录关卡序列重建；跨局记忆属于后续可选策略，必须把novelty_context及版本写进manifest，显式复现不能依赖未记录的本机历史。

随机流建议新增blueprint/encounter子流，从现有地图流的稳定标签派生；地图、相位、装饰、奖励、商店、敌人掉落继续隔离。Manifest记录骨架ID/版本、段落标签、实际模块及变体、端口图、能力快照、预算、尝试与保底原因。有限空间求解失败按同类型/能力兼容降级，不能无限重抽直到超时，也不能偷偷清空危险以冒充原挑战通过。

## 如何衡量“玩起来不同”

以下是下一阶段候选验收目标，尚无本轮运行数据：

- 同一固定阶段/房型跨至少200个Seed抽样，而不是把不同关卡编号混在一起，观察至少3种宏观骨架；报告每类占比，避免90%仍落一种。
- 同局普通动作房不连续同骨架；核心动作三连序列、纵横比例、最长连续动作段、回环数分别统计，不能只数布局hash。
- 原型期同一路径同模块连用至多2次；关卡独有标志性大段落不在同局重复。具体容错范围经试玩再定。
- 每个骨架固定样片、不同能力/镜像/动态相位及至少两个完整Seed都须真实Motor走通两条出口路线；记录无损扫掠、弹体数量、动作恢复、镜头/落点可见性。
- 正常新开局有新Seed，显式同Seed和同内容版本重放一致；改变奖励抽样不改地图。输入减速/空中资源变化不能使已接受的必经路线失效。
- 两出口仍位于各自路线末端；回退不重抽图、不重置奖励，普通活怪不锁门；Boss胜负与奖励独立规则不变。

## 分阶段任务

GEN-VARIETY-DESIGN-01：本设计及根因诊断。INPUT-COMFORT-01、SEED-FRESH-01：本轮实际改动。

GEN-RECOIL-GATE-02：按D064一跳平原基准校准反冲必需段及零枪反例，保留普通/可选反冲路径。
GEN-ARCHETYPE-01：先三种固定骨架样片、反向端口和真实路线，然后有界编排接入正式生成。
GEN-ENCOUNTER-01：给三骨架各补两种有辨识度段落；动态机关/敌人作为编排组合，增加可选收集支路。
GEN-NOVELTY-01：局内骨架袋/标签去重、Manifest升级、200Seed同条件分布和一局节奏验收。

先做到“相同关卡类型，换种子也能明显改变走法”，再批量扩大模块库。以上不作为本轮已经上线的功能。


## D063历史测量与D064现行能力规则

用户指出部分高台/宽台二跳能过，并询问是否前期只给一跳。D063时仍默认max_jumps=2；现已由用户明确决定平原一跳，旧建议被D064替代。当前260px升阶是单跳+反冲配方，也可以被双跳完成，不能标成“无枪一定不能过”。

真实60Hz Motor垂直样例：单次长跳150.366px，接近顶点二跳325.007px，两个样例实际回到地面且0弹体。这是给定策略测量，不是所有输入策略最大可达集的证明；既有560/620宽沟的双跳无枪轨迹负例继续保留。现有MovementCapabilityEnvelope主要是单跳筛选，不能单凭其中height/range或requires_burst字段认定二跳无法绕过。

下一阶段把段落分为基础跳跃、可选反冲捷径、基准能力下反冲必需挑战。后者按当前完整跳跃次数、各次起跳速度、保持/缓冲、空中修正、站位与全部中间可落脚点计算保守包络，并做零射击反例/实际反冲正例及手机可操作余量验证。首个升阶可试约380px，再验证至少一枪的完整动作链；此尺寸为设计候选，未改当前地图。地形在本局实例化后不因拾取道具而加宽加高；获得三跳等能力后绕过原难点属于构筑收益，不自动抵消。

一跳开局、森林前解锁二跳可作为独立成长方案，但须确定是固定流程授予还是局内/永久解锁，并重做早期关卡、失败重开体验与后期必需能力保证。D064现已确认平原一跳、后期每大关一个新能力；具体授予内容、时机和持久性仍待决定。
