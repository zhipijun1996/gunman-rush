# D062 平原分岔挑战与移动端反馈

本轮用户八项反馈优先于D060冲突部分。正式8关/Boss8、松手射击、唯一Motor、能力组件、局内/永久币、死亡优先和段内回退账本保持。

## 已确认设计

- 跳跃键在右摇杆右侧；左右半屏未被UI消费的触摸分别建立浮动摇杆原点，触摸点为中央，拖动矢量瞄准、有效松手一次发射。菜单/跳跃优先，三指独立捕获；无矢量轻触不发射，取消不发射。半透明，不让UI点击穿透成瞄准。
- 角色与敌人视觉增大，先调表现/镜头，不改变世界碰撞；增加适配平原的空中敌人。
- 普通房间不强制清怪才能进门，Boss仍需击败；战斗与探索收益保留。击杀怪物独立抽样金币、音符、爱心，金币概率高于音符、高于爱心。具体概率为可配置demo暂定，不视为正式平衡确认。
- 爱心为动态图标，接触恢复当前血量，不能混同最大血量升级。掉落/拾取一次结算，满血不吞有用的回血物。
- 分岔是中途选择上/右等不同路径，路径末端各有单独一扇门；途中不放终点门，不额外搭三层出口台。靠近门仍展示奖励/去向，ENTER才切关。

## 本轮算法切片

先规划公共路径、空间分岔与两条末端路线，再按能力/阶段/类型预算选不同尺寸模块，匹配端口位置、净空与动作恢复状态。模块包含反冲攀升/远距横渡、摆渡升降、荆棘跳、锯轮、落脚板与安全恢复；同模块允许水平镜像但需完整物理验证。

跨模块碰撞/机关全包络检查，端口直接重合，不生成额外接桥。两条路径分别记录节点列表与终端port；任一不能走到的分支不发布。随机绘制不等于任意组合都可玩，有限尝试失败保留错误/同类型能力兼容保底。地图、路线、击杀掉落、商店、奖励随机流分离，版本化manifest记录实际结果，不以抽样改动扰乱其它流。

不同类型与节奏：前两关教学，后续动作房加入反冲必需段；道具房动作组合更集中，金币房散落收集沿主路与两支路；商店/回血房保持短低压但出口分支独立，Boss核心保持固定。更多任意环路搜索后续，不能仅增加目录数量就声称全部完成。

## 本轮验收

A81：浮动触点精确原点、左右向量、多指跳跃、跳跃键优先、死区取消/失焦暂停不射击，真机手感独立。
A82：公共段后的两个独立非零长度路径都通向末端门，途中无终点门；端口/几何/危险无冲突，分支各自真实Motor全身扫掠和动作余量通过。
A83：代表后期路线实际发射弹体并借反冲跨越，移动平台真实携带；无反冲负例不能绕过明确枪需求挑战，不降低物理标准。
A84：普通房留有存活怪物仍可确认出门，Boss存活不可；残留伤害/掉落回调不能跨stage epoch。
A85：同Seed掉落重放，金币>音符>爱心，击杀幂等，生命归零取消未结算掉落，段回退不刷；爱心接触回血一次，满血保留。
A86：镜头/角色表现增大但碰撞不变；空中敌人/爱心动态表现；门仅一扇，艺术/手机性能需用户验收。

## 当前模块与实现边界

新增16个定义：单/双段反冲升阶、560/620像素宽沟、单/双段移动平台、荆棘桥/台阶、齿轮溪/林间齿轮、单/双段落脚台、跳石、挑战分岔/休息分岔、平面末端门落脚板。连同既有定义，目录共40项；不声称40项均在本轮随机池中使用。180次抽样实际见19种模块、172种布局，无保底触发。

[实际生成几何图](figures/plains_branch_layouts.svg)来自同版本Manifest，展示战斗、道具与商店布局；绘图不是物理可达证据。逐模块镜像/四相位和代表整关双路线的真实Motor证据见[验证记录](plains_branch_validation.md)。

`config/plains_branch_profile.json`为已消费的demo预算：每条路线最多8个危险模块、2个反冲模块、1个摆渡模块；安全起步2板、连续压力模块不超过2。前两关不强制反冲，第三关起动作房引入，第四关起摆渡；道具房可提早动作挑战，商店/回血房零危险。算法最多尝试4次，失败使用明确记录的同类型低压两路线保底。Boss固定核心、跳跃包络不足的特殊构筑使用记录原因的兼容路线，不虚称仍有同等挑战。

当前生成器为一次分岔的有界端口树，不是任意环路/多级分岔搜索。局部镜像入池仅限已支持反向端口的既有静态定义；新增16个定义均验证了镜像轨迹，但不能据此声称它们全部已随机镜像入池。下一步扩展多级分岔与非单调路线时，必须先补齐反向端口及跨模块完整物理证据。
