## 已接入与保留

草岩/木铜桥根据新manifest的standline与端头区域绘制，固定0.2等比端头、裁切中段，支持窄板与长岸；厚岩采用自然岩层交错镜像，保留准确站立边。几何边相接不代表绘画纹理已完全无缝，镜像花纹与脚底对齐仍需合屏/真机评审。三层新天空/丘陵/草甸，独立速度、大气透视、真实源图尺寸；有限远景只平滑漂移，不无限重复山脉。

金币、音符、红心瓶保留旋转/摆动/心跳和领取幂等；六类房型图标接入分岔告示牌及出口，文字与实际去向不变。出口仍是原来的门，因为v3的exit资产实为箭头路标；荆棘保持，避免新金属刺覆盖用户确认的语义；地面甲虫保留，因为图包不含行走敌人。UI稀有度框、部分补给/商店/短台变体仍为候选，不能按导入文件数量称全部运行替换。

装饰单独`PlainsSetDressing`：种子/版本/素材hash组成presentation manifest，不改变玩法manifest，独立decoration流。最多24件；低对比遗迹或风车置于地形后方，避开危险、出生、出口和路牌。石块/藤叶仅在厚平台实体表面站立线以下；没有碰撞、掉落或交互，不充当新机关。桥与风车蓝图因此有不同地标，装饰不冒充玩法变化。
