# 16区视觉分工：统一画法，分别设计地域

任务 `WINDCHIME-STYLE-01`。依据用户“差不多这样，再加点纹理和肌理……色调不太适合风铃平原，要考虑后续16个区域”的最新反馈制定。继承[六阶段与16区身份](design/player_actions/regions_v0.3.md)和现有地区ID；本文只规定美术候选分工，不开放地区、不改变能力锁、路线或机制。用户对画法的有限认可不代表已认可每区配色与实际素材。

共同画法：简洁而有设计的轮廓、有限明暗、材质大形、轻微风化颗粒、低对比多层远景；实体仍用47-tile体系，机关/装饰分层。人物、危险和交互的功能识别跨区保持稳定。地区差别至少同时体现**色温/明度、主材质、构造轮廓、景深与光源**，不能只调色。

## 平原本次要落实的变化

- 石体由深蓝改为暖灰橄榄石灰岩；顶沿保持麦奶油清晰线，草与花用低饱和绿和浅金。
- 远景由浮空宫城改为草甸、缓坡、旧风车、低钟塔和淡远山，给后续高空/古堡/钟塔保留造型空间。
- 跨格砌石服从同一世界坐标，不在模块边界重启。风化颗粒留在实体内，顶沿、落点和危险保持干净；变体不改变碰撞。
- 金属道具用旧黄铜，木构/阴影偏深绿褐；角色红披风和功能危险色保持稳定。

验证顺序不变：先一套真实材质与接缝，再MAP-00/MAP-01合屏和正常速度移镜；画法、平原配色、纹理强度和用户最终认可分别记证。正式随机和其他15区的生产不由此文冒称完成。
