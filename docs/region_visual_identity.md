# 16区视觉分工：统一画法，分别设计地域

当前任务 `UNDERWORLD-PLAINS-01`：用户已选择Underworld，并要求16区风格一致、色系与地域特色不同。[当前Tile生产流程](underworld_tile_production.md)是画法/接口的执行入口；旧暖石灰岩平原方向已被拒绝，不再是本表S1的生产依据。继承[六阶段与16区身份](design/player_actions/regions_v0.3.md)及地区ID；除已迁移的正式平原外，以下均是候选分工，不开放地区、不改变能力锁或玩法。

共同画法：一致的像素尺度、暗体与受控亮边、色阶/光向、清晰留白、低对比多层远景；实体按真实47邻接或明确非整格适配，机关/装饰分层。暗体语法不要求所有区域低明度或使用蓝紫色。功能性的安全/危险/交互识别跨区稳定；地区至少同时改变**色温/明度、主材质、构造轮廓、生态、景深与光源**。森林须生产树皮/根皮族，工城须生产钢板/铸铁族，不能把岩床换色称完成。

## 平原当前生产与下一地区

正式平原两图已使用上述S1组合。近处地标依附真实平台，远井架明确为非物理局部背景；三张不同景层分别跟实际镜头移动。荆棘和其他接触危险属于平台表面的材质状态，危险颜色与轮廓不能被地区装饰挪作安全提示。

下一地区先选主材质家族并制一组代表边/角/填充，再做黄金实景和三种子拼接、真实出返程及独审，准入后扩家族。森林和工城目前保留[两风格三地区实验](style_exploration_report.md)作探索证据，尚无正式完整原创材料族或开放流程；其他13区仍为视觉候选。用户选择Underworld方向不等于逐区配色或最终商业画面认可。
