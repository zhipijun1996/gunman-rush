# 金色道具解锁贴墙缓降（后续开发）

2026-10-10用户提出新增“爬墙”能力：可以粘在墙上缓慢下降，由某个金色道具解锁，后期森林或其他场景作为必备能力。**本轮仅纳入设计与任务，不实现或宣称已可用。** 本设计的已确认动作是贴墙缓降，不自行扩展为向上攀爬、墙跳、无限挂墙或自动攀顶。

## 组件、输入与资源边界

候选能力ID `wall_slide`，独立WallSlideAbility，金色ItemDefinition通过带source_id的能力授予效果启用；不用玩家脚本的全局bool，不让任意金色道具都授予。BuildState撤销来源后重新推导启用状态，多来源授予按来源集合去重。具体金色道具名称、获取位置、缓降速度、触发按键/贴墙条件、是否允许墙上开火及向上爬/墙跳另见Q016，未定部分不做运行默认。

候选交互是面向可附着墙、处于空中并持续向墙输入时贴附；脱离输入或离墙则恢复普通运动。触屏/键鼠/手柄统一意图，是否需要独立动作键待用户手感确认。普通墙、危险墙、不可附着墙通过独立SurfaceDefinition标签区分；装饰纹理不能决定附着资格。

能力只请求Motor约束下落速度/进入离开贴附状态，Motor继续是唯一位移入口；不直接改position、不增加第二个move_and_slide。缓降速度可配置，不能改全局重力。连续接触移动墙、外力/反冲、墙角与天花板需要明确仲裁和实际碰撞测试。

精力用途仍未定，**不自动消耗精力**。贴墙不算落地，不刷新跳跃、空中射击、冷却或AirFocus腾空上限，不能利用接触墙无限补动作资源。暂停、失焦、死亡、段回退、能力撤销清挂墙状态与旧请求；环境回退保留世界/奖励账本，按既有资源策略处理。

## 必备能力与肉鸽路线防死局

平原与当前主路仍不要求wall_slide。现有森林候选在第二层，不自动把所有森林主路改成需要金道具；后续明确标记 `late_forest_wall_route` 或其他后期能力门槛配置，只对这些路线要求该能力。普通森林与无能力兼容路线保留。

用户确认后期有必备能力路线，但**具体地区/关号与必得方式未定**。实施候选D053：

- 前置金色道具必须在进入门槛前确定性取得并完成授予，不能仅增加随机掉落权重或期望玩家在二选一中选中。
- 可以在前置必经Boss的那一个GOLD权益中指定能力道具，或另行设计必经授予；采用何种方式待Q016。不能私自把Boss固定一金变为两金或给二选一两个道具。
- 地区出口/模块图加载前校验实际AbilitySet，而非“曾经看见道具”。未领取、拒绝领取、授予失败时不允许提交能力必需路线；提供明确兼容路线或停留处理，不加载死图。
- 能力仍能配置启停，但进入必需路线后撤销须原子重验后续路线，提供已验证兼容通道/安全退出；没有合法处理时拒绝撤销，不靠全场reset或凭空还道具解决。
- 将需求ID/最低缓降性能、前置授予收据、门槛版本与实际能力快照记录Manifest。能力增强可以打开支路；额外能力不是当前平原的隐形要求。

## 地图、平衡与开发顺序

贴墙缓降改变可停留/瞄准时间，不能只以跳高包络判断可通关。新模块注明可附着墙区间、入口速度、墙面危险净空、允许停留时间和出口动作余量。先做“安全墙缓降→离墙跳跃/反冲→稳定台”的固定样片，再做较长森林竖井；周期尖刺与移动墙组合后置。

依次实施：可撤销能力授予消费者→单墙真实Motor/资源测试→三输入取消与墙角测试→固定模块→前置必得与路线门槛→模块入池/真实设备。当前先完成平原能力绑定生成，不创建没有消费者的空WallSlideAbility或空金色道具资源。

验收A64：无道具不可贴附；指定金道具授予一次、重复/撤销来源正确；缓降速度/取消/反冲仲裁正确；墙接触不补动作资源；危险墙不可借附着规避DamagePolicy；三设备意图一致；无能力不提交必需路线；合法路线确保前置授予；不同Seed不能遗漏必得；撤销不致死局；同Seed/版本/能力/路线复现。实际结果当前全部未验证。
