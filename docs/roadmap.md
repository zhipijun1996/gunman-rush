# 路线图

| 阶段 | 交付 | 完成门槛 |
| --- | --- | --- |
| M0 | 文档、管理、关联仓库 | 文档检查与同步 |
| M1 | 固定灰盒人物原型、可配置能力 | ENV-01 精确引擎版本门槛；A01–A08、A18 自动与桌面证据 |
| M2 | 安卓输入与 debug APK、键鼠/手柄适配及 Windows 构建验证 | A09–A10 Android 真机证据；A24–A28 分设备与分平台证据 |
| M3 | 固定挑战与续航机关 | A11–A16 验收 |
| M4 | 少量模块化随机地图 | A17 + 真人抽样 |
| M5 | 肉鸽循环与内容扩展 | 单独细化后验收 |
| 后期平台 | Windows 正式版本与可选 Steam 服务 | 单独规格/任务；A29–A30；Windows 实机验收 |

AI 风格样片可与 M2 独立推进，正式批量美术晚于 M3 操作稳定。音乐工具缺失不阻塞灰盒。阶段不是日历承诺。

Android 横屏当前优先，Windows 是正式目标；ENV-01 先准备 Windows Desktop 导出条件，工程和输入就绪后独立验证 Windows 构建，不以 Linux 桌面调试代替。Steam 第一版优先 Windows，Linux、macOS、Steam Deck 后续分别安排构建、设备与输入验收。

所有平台共用人物、能力、世界、敌人/Boss 和地图；先建立输入、存档与平台服务边界，不更换引擎。当前不实现完整 Steamworks、商店发布或 Steam 账号要求。持久存档与云同步/成就接入分别细化，并保留无 SDK 可运行路径。固定挑战的 Android 真机 A15–A16 未通过时，GEN-01 仍不能开始。
