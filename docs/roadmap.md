# 分阶段路线图

新增设计替代旧M4先随机/M5再细化循环的顺序；旧任务ID保留便于追踪，但目标重新定义。阶段不是日期承诺。

| 阶段 | 有界交付 | 完成门槛 |
| --- | --- | --- |
| P0 | 权威设计/职责/策略状态与依赖整合 | DOC-02、文档链接/依赖/正式10关与测试3关检查 |
| P1 | 保留现有角色/射击/输入/能力原型 | BASE-01实际回归；原型手感/设备证据继续独立等待 |
| P2 | 固定图Health/Stamina接口、一个敌人、怪物伤害/环境回退/真正死亡 | HEALTH/ENEMY/DAMAGE/SEGMENT/DEATH最小集成；无完整家园经济或路线系统 |
| P3 | 一个补给、来源Modifier、二选一道具、最简商店 | 原子/幂等交易与回退不刷；新增系统在实际消费者出现时实现 |
| P4 | 固定3关开发链、两出口、一个Boss/金奖励、Home入口/返回 | 短RunProfile独立标记；Boss/终局竞争与真实固定挑战验证 |
| P5 | 正式每大关10关、Boss必达、模块化随机、Boss兼容外围 | RUN-TEN-01及GEN-01；LEVEL-02真机固定链门槛、完整Manifest/独立RNG回放 |
| P6 | Meta/版本化存档；依序添加主题、人物、枪支、道具、剧情 | 经济待决定项先确认；每项独立数据/测试/真机验收 |
| 平台后期 | Windows正式版与可选Steam；Linux/macOS/Steam Deck | 分平台构建/实机；无SDK普通游戏仍运行 |

当前连续迭代按P2→P3→P4分步接入固定可玩demo闭环；阶段内先检查/测试再组合，不把所有系统一次塞进未验证的大改动。P4家园仅独立内存摘要与开局入口，P6仍负责真实永久经济、持久存档和剧情。代码/自动验证与设备验收状态分别见任务、验收与交接，不把短开发链当成正式十关完成。

固定新伤害/动作链与P4集成可以在现有可执行原型上迭代，旧LEVEL-01未真机通过不阻塞写契约或P2固定组件，但阻塞GEN的地图生成。LEVEL-02明确验收迁移后的固定挑战，不拿旧即死检查点通过代替新规则。正式10关是已确定产品规则，3关仅开发配置，不降低正式标准。

Android/iPhone共享Web快速反馈，APK按需，Windows单独导出/实机；原生iOS/Steam商店发布不在此范围。固定操作与配色用户验收后才批量原创素材，音乐工具缺失如实记录。精力/发射变体/血量奖励/货币等待定项详见decisions，后续不擅自补成已确认规则。
