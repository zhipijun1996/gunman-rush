# 人物物理

参数以 [player_tuning.json](../config/player_tuning.json) 为准。X 右、Y 下。普通速度与反冲速度分开。默认 recoil_mode=shot_burst：成功射击进入反方向短爆发；legacy_impulse保留原来的v=normal+recoil、添加-I*d与exp(-dt/tau)指数衰减。下落上限只限制普通竖直速度。候选参数与资料可信度见 [手感试调](gamefeel_tuning.md)。

## 跳跃

有效接地后 used_jumps=0。第 N 次跳跃设置 normal.y=jump_speeds[min(N-1,数组末项索引)]，次数上限取 max_jumps。legacy模式跳跃不清除竖直反冲；burst窗口位移由爆发独占；新的有效跳跃会立即结束当前爆发，接管普通运动。同帧仍先跳后射，burst激活清普通竖直速度，因此同帧射击覆盖跳跃速度但不返还已消费次数。该优先级明确列为试玩项，不将其冒充空洞骑士规则。主动起跳立即清土狼资格。步行离开平台的土狼窗口内可用第一跳；窗口耗尽后将第一跳资格视为已用，余量取 max(0,max_jumps-used_jumps)。缓冲在落地后立即尝试，触发消耗一次且不连续重复。具体时钟边界与自动证据见验收记录。

## 射击计数

ActionResources 有 shot_charges 和 pending_ground_shots。空中成功射击立即消耗一次。地面成功射击受冷却限制，同时记入 pending_ground_shots；该帧保持接地则清账并维持满额；若射击导致离地，则新腾空剩余=max(0,max_charges-pending_ground_shots)。不得在起飞同帧被“仍接地”误恢复。

有效落地为上一帧空中、本帧有可站立地面且非主动离地。持续地面不重复发送 landed；侧墙、天花板不恢复。单向平台下穿期间不恢复。

## 碰撞

move_and_slide 后对每个碰撞法线，将 normal 与 recoil 中朝表面的分量各自投影消除；避免下一帧复活朝墙反冲。处理斜坡与多个法线。移动平台速度只由 Motor 统一处理，避免双加。

下穿只暂时忽略脚下单向平台，时间与恢复条件可配置；不得关闭全部世界碰撞。正式任意已结算伤害归零结束run、取消旧token并回家园；新局才按基础配置建立资源。非致命环境回退清两种速度/输入/缓冲与持续慢时，暂定恢复动作次数而保留精力/冷却/世界账本；不复用整场景reset，详见damage_and_respawn。当前旧die/reset_at仍是待显式隔离的Legacy灰盒，不代表正式实现。

射击与跳跃同帧先跳后射；新跳跃视为空中，消耗射击。完整顺序见 [架构](architecture.md)。高速弹体和危险区需要 sweep/segment 验证，不仅依赖离散重叠。

## 可配置能力

本文二段跳与两次射击是默认实例。实现必须符合 [能力组件](ability_components.md)，支持 max_jumps=0/1/2/3/N 和 max_air_shots=0/N，不能硬编码第三跳永远拒绝；跳跃速度数组配置与空中增减边界按该契约执行。


## 射击短爆发试调

用户试玩反馈授权尝试每枪一段快速位移。默认shot_burst_speed=1100、shot_burst_duration=0.14，无障碍位移154世界像素；不是瞬移，也不绕过move_and_slide。每枪重新设置爆发速度/时长，不叠加速度；方向为射击的单位反向。激活时清normal.y与普通速度反向分量，避免旧下落抵消抬升。窗口内冻结重力及普通竖直速度，普通x继续响应输入为结束接管准备；实际位移只取burst速度。

最后不足一物理帧按剩余时长比例缩放速度，60Hz中0.14秒跨9tick，累计位移按1100×0.14，不额外多走一个整帧。墙/顶碰撞后直接投影持久反冲向量，下一tick不重建原方向；结束/禁用/死亡/重生清爆发时钟与反冲，再恢复普通运动。没有新增无敌帧。

普通移动候选330，地面加/减速与空中加速度19800：从静止到满速1tick，空中全速反向2tick。重力2600、跳跃[-666,-732.6]、普通落速上限800；默认次数与土狼/缓冲保持原值。可变跳高开启：维持跳跃速度最短4/60秒、最长9/60秒；释放时在达到最短升程后将属于跳跃的上升速度切为0。超过维持窗口但仍在上升的跳跃也能释放截断，下降不截断。射击会解除跳跃对升程的控制，释放跳跃不能削弱反冲。提前释放的缓冲跳仍为小跳；死亡、暂停、失焦、禁用、撞顶和落地清理持有状态。参数与社区来源见 [可变跳高报告](variable_jump_report.md)。

## 空中瞄准慢时（保留的原型实验）

最新正式设计把精力用途标为待决策。本节只描述此前授权并已实现的试调，保留代码/测试，不将其私有精力默认绑定正式角色，也不让移动/跳跃/射击消耗精力。

AirFocusAbility是可启停独立能力。人物在空中且有有效主动瞄准意图时，缩放全场游戏时间；触屏右杆拖出死区、手柄右杆武装偏移、键鼠按住射击键瞄准使用同一规则。普通鼠标移动预览、死区噪声、地面瞄准不触发。世界物理、弹体、机关、动作冷却和挑战clock共同变慢，UI与输入事件保持响应；不改世界速度/重力参数。

候选值唯一来自config/player_tuning.json：air_focus_enabled=true，focus_time_scale=.25，精力容量100、每真实秒消耗45、接地每真实秒恢复30，每次腾空累计最多2真实秒。松手/回中心、成功射击、取消、失焦、暂停、死亡、能力禁用与场景卸载恢复进入前时间倍率。精力耗尽立即退出；空中不恢复，恢复到15才解除耗尽锁定。腾空预算只有接地重置，反复拖杆不能绕过上限。重生恢复初始精力/预算，不把接地恢复写成瞬间回满。

精力、最长期限按真实时间；跳跃/反冲/冷却仍按缩放后的游戏时间，避免减速倍率同时暗中延长可用精力。能力不移动人物；Controller每帧仍一次Motor调用。能力参数可由后续道具修改，当前只实现配置与能力启停，不实现随机道具系统。单玩家当前只有该能力持有Engine.time_scale；未来其他全局慢时来源接入前须升级集中仲裁，不能各自覆盖。
