# D072 平原当前版本优化实施

来源：[用户实施文档](plains_current_optimization_spec.md)，包含10.1–10.6新增要求。开发基线为再次fetch确认的 `ab51fca`；分支 `fix/plains-experience-polish`。本轮不实现森林、一枪精力迁移、二跳或墙跳。用户反馈的所有Boss Bug尚无完整复现步骤，不把以下已复现问题认定为全部Bug。所有体验任务保持 awaiting-device，森林暂停继续生效。

## Boss正确性与演出

第三阶段为 observe → chase → pier_warning → pier_impact → pier_open → next_pier/final_hold。前两墩推进，第三墩只在原地重复预警/撞击/露铃/恢复；没有取模、回传或无限追出边界。0.8秒预警、0.2秒撞击、原exposed_seconds+1窗口、0.8秒恢复均由WindkeeperDefinition配置；撞击是12px真实扫掠圆、单独事件ID，不使用整幅巨羊图作伤害体。

同一 `tests/plains_final_pier_repro.gd` 在独立旧main检出上失败：漏打50游戏秒，rewinds=2、final_pier=0，退出1；新版rewinds=0、final_pier=2、x=833.998，退出0。两个版本同一实际桥面初始fixture、真实运行时钟，无额外Boss伤害。完整CSV在 `user://final-pier-trace.csv`，构建证据包另存两版轨迹。

阶段切换立即关闭弱点、取消旧攻击/外力，1.1秒预告后经BossMotor有界移动到下一站位。第三阶段等待玩家到上层或岸边再撤地面，玩家始终可操作，不补血或枪。地面/桥面/半空触发有独立真实位置fixture。Arena/模块版本4、Boss契约版本2；Manifest验证同步。暂停冻结状态/时钟/走位，正式App和Lab都不重置为observe；段回退清攻击并保留阶段/墩号/断桥，末墩恢复预警。死亡/离场彻底取消。

奖励点从实际arena module的三块桥面世界坐标读取，分别为本地(350,452)/(640,452)/(870,452)，不用Arena内缩边界猜桥台。三个奖点有真实向下支撑射线；正式App同帧双死失败优先、一次金奖、ENTER/STAY及Home仍由现有批次/领取规则负责。

正式UI读取HealthState：立即血条、0.32秒残血延迟、两处阶段刻度、关闭弱点时的盾形轮廓、终局归零淡出。首次3.2秒登场，重复会话挑战1秒，可按钮跳过；攻击在演出结束后开始，操作未锁住。名字使用原创排版与OFL字体子集，血条移到玩家HUD右侧；移除场景重复悬浮Boss名。过场不设置Engine.time_scale，空中慢瞄仍0.20。

## 镜头与动作

普通镜头由对称Y死区改为非对称下降阈值/滞回；下降安全修正同步重定位anchor，避免目标继续拉回旧构图。落地不调用snap/reset，不用枪朝向决定前视。长下落仍按真实位置跟随且角色可见。每步 `follow_trace` 记录actor、anchor、session、bounds clamp、安全修正；Boss额外给出铃或下一桥台的有界构图焦点，以90px/秒平滑将高大羊身和桥台玩家纳入同一纵向视野，缩放保持1.95。连续真实Motor分岔路线CSV由 `tests/plains_camera_trace_runner.gd` 生成，两个支路覆盖跳跃、反冲、落地，不能冒充所有设备或六场景人工验收。

主角：按实际地速推进跑步帧，80ms上身倾斜过渡、100ms落地压缩、反冲沿实际方向承压；用每帧素材pivot重新求transform，105项脚底/瞄准/不改输入与碰撞检查保留。巨羊：9帧时长量级的姿态混合、准备/发力/运动/撞停/恢复的体重变形、实际位移驱动四段踝部步态、风车延迟跟随及实际blade_angle、独立核心受击裂闪。没有重画衣服/脸或改角色Motor。现有六张母版仍是候选，部件裁切步态与角/耳/毛束的美术效果需要用户再看连续录像，不标为最终动画品质完成。

## 弹体、反馈与声音

PlayerProjectile为暖白核/短方向尾，EnemyAttackProjectile为有深轮廓的菱形危险种子，BossProjectile为实际圆包络内的贴地弧头/低尘带。风叶/撞墩的伤害提交代理不画成虚假飞行弹丸；叶缘线仅对齐真实四臂轨迹。暂停冻结、生命周期/epoch取消照旧；低特效不移除弹体本体或危险边缘。

枪火读取独立weapon transform和素材manifest muzzle/pivot，80ms固定短闪，无尘粒重力。反冲短线无重力，尘叶保留重力，落地数量随实际下降速度在3–10内变化。护甲灰闪/叮声，与核心暖裂闪/钟音分开；核心表现订阅实际APPLIED健康事件，不能凭接受排队请求伪造伤害。新增原创、可重生成合成音由 `tools/generate_plains_combat_audio.py` 生成；设置新增低装饰特效/静音，会话内生效，不改变存档。没有新增镜头震动。

**单列弹体行为改变**：真实弹体由原角色中心转到已标注枪口；中心→枪口仍先做相同形状扫掠，避免贴墙绕过遮挡。发射事件先登记合法资格，扫掠在物理tick执行，保留已发射弹体生命周期。角色速度、跳高、碰撞、反冲和输入未改变。岸边向下射铃的安全开火位置由原本地x270改为277，保持 ±0.05rad 两侧方向与完整同发反冲轨迹验证；不通过缩地形/减伤害掩盖枪口回归。
