# 肉鸽平台跳跃游戏设计建议与 Codex 开发交接

版本：v0.2 反作用力位移核心版  
整理日期：2026年10月10日  
用途：让 Codex 理解玩法方向、世界观、大关路线、剧情组织与制作约束，并据此推进分阶段开发。

本版根据用户最新说明修订：开枪产生反作用力位移是已有核心玩法，所有世界观与关卡建议应围绕该机制展开。本文整合当前讨论的建议。用户已有设想与新增建议分别标明；游戏名称、世界观、场景数量和剧情结局均未最终定稿，不应误认为已经确认的产品需求。无需一次实现全部内容。

## 1 核心方向与需求状态

### 1.1 用户已有设想

- 类型为以开枪反作用力位移为核心的肉鸽平台跳跃游戏，射击同时是移动操作，重点是跳跳乐，参考《空洞骑士》苦痛之路的操作挑战；战斗不是体验重心。
- 人物拥有血量、精力条和枪支。后续可扩展不同角色、流派与枪支手感；射击反作用力用于位移已经确认，具体数值与其他作用尚未确定。
- 第一大关固定为平原，后续希望包含火山、冰川、城堡、遗迹、墓地等不同场景。
- 每个大关是一个场景，含10个小关，最后一个小关为Boss关。击败Boss必出一个金道具。
- 小关地图随机生成，含敌人；普通小关设置两个出口，用于选择下一小关类型。
- 小关类型可包括商店、金币奖励、血量奖励、道具奖励等。道具奖励采用二选一，后续允许扩展。
- Boss地图也希望部分随机。
- 美术主要依靠AI生成，偏好童话、手绘、较简洁且能稳定统一的风格。
- 资产必须模块化、可拼接，服务于随机地图，而非仅生成整张场景概念图。

### 1.2 本文推荐方案

核心操作是朝一个方向开枪，借反作用力向相反方向位移。场景机制、奖励构筑与Boss挑战都应服务于射击方向、时机和落点控制。

采用“固定起点与终点，中间按层级分叉”的大关网络。完整世界规划16个场景，普通完整路线经过6个大关。每局开放出口在允许的连接内变化，由玩家选择路线。

建议世界观暂名《失序之钟》：童话世界的时间装置破碎，季节、道路与生命循环失序。主角携带与世界之钟同源的便携脉冲装置，借发射脉冲的反作用力穿越破碎世界。随机地图、区域连接变化与主角复活，都由同一背景解释。

情感基调建议为“治愈童话与隐藏的悲伤”，游玩体验以明快冒险、跳跃和探索为主。忧伤通过探索逐渐显露，避免长篇对话干扰节奏。

### 1.3 尚待决定的内容

| 项目 | 当前处理方式 |
| --- | --- |

| 主角身份与外形 | 小小旅人，真实身份可与世界之钟关联；未定稿 |

## 2 世界背景与剧情前提

很久以前，世界之钟维持着四季与时间的流转。钟声响起，春天开花、夏天生长、秋天落叶、冬天降雪。

王国的君主试图停止世界之钟，让国度永远停留在最美好的时刻。工匠建造了控制装置，但计划失败，世界之钟破碎。

此后，各地的季节与时间不再协调：森林无限生长，雪城凝固在最后一天，地下熔炉持续过热，灵魂无法安息，无人机械仍在运行。断裂的地脉、浮空桥与古代通道随残存的钟声重新排列。

主角从平原上一朵发光的花中醒来，身旁放着一把小小的脉冲枪。枪内的光点随远方钟声闪动。他不记得自己是谁，只听见远方的钟声。他循着声音寻找源头。失败后，他再次在平原苏醒，而对世界的认识逐渐保留。

建议把随机性解释为“世界之钟每次尝试转动时，局部空间重新排列”。区域的地理与历史联系稳定，具体道路和当局可用出口变化。不要把随机性解释成所有地方都可以毫无理由互相连接。

后期可以揭示：君主并非仅为了永生，也可能试图阻止一场灾难或留住即将失去的人。守钟人曾是拯救王国的英雄。重启时间会恢复自然循环，也会让某些被异常时间保存的事物走向终结。

该反转与主角复活的具体原理属于剧情待定内容，Codex不应自行写死成大量对话、角色关系或复杂结局系统。

### 2.1 让反作用力成为世界的一部分

建议世界之钟不仅管理时间，也通过周期脉冲协调各地的运动与季节循环。古代工匠把这种动力封装成工具，暂称“鸣钟枪”。它发射短促的光脉冲，并将使用者推向相反方向。名称、能源与外形为新增建议，物理表现以现有游戏实现为准。

这种装置最初是维修工具：守钟人借它跨越钟塔的断桥、抵抗风道、接近摆锤和校准远处装置。因此，主角使用枪跨越平台具有明确的世界内用途。枪仍可承担攻击功能，但叙事重点是移动、维修和重新连接世界。

世界破碎后，旧道路变成悬台与裂隙。其他居民依赖桥梁或停摆交通设施，主角则能用脉冲枪在断路之间穿行。平原的风铃、工城的活塞、火山的动力井与钟塔的摆锤，可以通过共同的脉冲标记表达同一种文明技术。

守钟人可能是主角过去的身份，也可能只是枪的来源。这两种方向先保留，不把身份反转写死。复活与道路重排仍由世界之钟解释；不必为了融合射击机制把每次死亡都解释成枪的作用。

### 2.2 美术与叙事表达

枪建议采用童话维修工具的形态：小巧木质或黄铜外壳、钟形枪口、发光核心，避免视觉上压过角色。枪口脉冲与位移轨迹短而清楚，可用钟声节拍强化射击反馈。装饰不能延迟输入响应或遮挡危险。

平原通过朝下射击升起、朝侧面射击横移的简单挑战教学。废弃维修站可留下姿势图、枪口方向与位移方向标记，让玩家在操作中了解装置用途。古堡陈列的停时装置和工城的维修记录，再逐步揭示它与世界之钟的关系。

这些解释不能替代实际规则：空中连射次数、反作用力大小、动量叠加、射击冷却和资源恢复，以现有实现或后续确认参数为准。

## 3 六层大关结构

| 层级 | 场景池 | 玩家体验与主线信息 |
| --- | --- | --- |
| 1 起点 | 风铃平原 | 学习基础操作，看到世界原本的美好和轻微异常 |
| 2 外围 | 荆棘森林、萤雾沼泽、风蚀峡谷 | 路线开始分叉，发现季节和环境失序 |
| 3 文明遗迹 | 蕈灯地穴、沉水遗迹、齿轮工城、月冠古堡 | 发现旧王国与人类干预时间的证据 |
| 4 失序地带 | 月影墓园、霜镜冰川、熔火腹地、破碎浮岛 | 体验灾难后果，跳跃组合更复杂 |
| 5 核心外围 | 根脉圣殿、逆时钟塔、星桥天门 | 理解时间循环、灾难过程与主角关联 |
| 6 终点 | 世界钟心 | 最终挑战，面对是否重启世界的选择 |

16个场景为长期内容池，单局不需要全部经过。标准路线每层选择一个场景，形成6个大关。隐藏捷径可例外，但不能破坏整体进程。

### 3.2 三条合法路线示例

1. 生命与死亡：平原 → 森林 → 地穴 → 墓园 → 根脉圣殿 → 世界钟心。侧重生命过度生长与死亡无法结束。
2. 机械与烈焰：平原 → 峡谷 → 工城 → 火山 → 钟塔 → 世界钟心。沿动力系统追踪工匠与灾难。
3. 失落的王国：平原 → 沼泽 → 遗迹 → 冰川 → 星桥 → 世界钟心。寻找被冻结的居民与古代天文装置。

以下机制为场景创意池，首版不要求全部制作。每个场景优先确立一个主要机制，再用少量通用机关组合。

| 逆时钟塔 | 钟针、摆锤、巨大齿轮与时间残影 | 摆锤、旋转平台、冻结机关 | 停止时间的完整过程 |
| 星桥天门 | 星空、悬桥、天文环与光路 | 光影平台；低重力区域可后置 | 世界之钟与天空的时间轨道相连 |

同层场景应保持相近的总体难度和奖励价值，但操作体验可以不同。冰川偏惯性与落点，火山偏连续移动与节奏；选择应考虑玩家偏好和本局构筑。

雾、隐藏平台、暴风雪等视觉效果不能遮蔽必须及时判断的落点与危险。高难度来自可读的操作挑战，而非随机遮挡。

## 5 大关与小关的两层选择

### 5.1 大关路线选择

大关Boss结束并领取金道具后，展示下一场景选择。候选项来自连接白名单，并受永久解锁状态影响。

建议常规分叉开放两个不同的有效出口；候选多于两个时按本局种子抽取两个。第五层自然汇入唯一终点，无需制造虚假的二选一。

未完成的场景不进入抽取池。生成前验证每个被选中的区域能继续到达最终关，避免死路。首版场景较少时可使用固定可通关路线，不强行随机出缺失内容。

出口应显示目的地、主要环境机制和必要的风险信息，使玩家能做选择。随机决定本局提供哪些路线，玩家决定走哪条。

### 5.2 大关内部的10个小关

10个小关指玩家实际依次经过10个节点，第10节点为Boss。不能误实现为10个都必须清理的并行房间，也不要把出口的候选房间计入通关数量。

普通小关的两个出口决定下一节点的类型，例如金币、恢复、道具、商店、挑战。节点类型影响奖励和挑战配置，当前大关的场景主题保持一致。

推荐流程：进入小关 → 完成跳跃与必要目标 → 获取本关奖励 → 比较两个下一关类型 → 选择出口 → 进入下一小关。第9小关之后统一进入Boss，可用一条明确出口，不为形式重复两条相同选项。

商店、奖励和挑战不是“安全/危险”两个标签的简单替代。保留用户已有类型，再为适用节点增加难度与奖励变体。

建议配置商店与恢复的间隔约束、防止同类节点过度重复的权重，以及最低资源保障；具体频率和数值通过试玩确定，不先写死。

六大关各10小关意味着标准局60个节点。普通小关约1分钟仍不包含Boss、购物、选择和死亡重试；45–75分钟只能作为待验证的目标。先保留10小关配置，另设开发用短流程，测试后再讨论是否调整正式局长。

## 6 平台挑战与 Boss 设计原则

必经路线应有稳定可理解的难度曲线。类似苦痛之路的极难连续跳跃优先放在可选奖励支路，玩家不完成仍能通关。该建议用于保护通关节奏，最终难度定位仍可由用户调整。

射击本身是移动体验的核心。玩家的每次开枪同时决定枪口方向与自身反向运动：向下射击可获得向上的推力，朝左射击可获得向右的推力，斜向射击则提供组合方向。已有速度如何与推力叠加由实际运动模型决定，不能仅依据枪口方向承诺最终轨迹。敌人可以形成路径压力或提供互动，但不能把体验重心转成站定刷怪。

Boss应主要考验位移、落点和机关节奏。枪支反作用力位移已经确认，伤害方式与精力消耗尚待确认；先实现明确预警、可躲避攻击与可恢复站位。

Boss地图采用经过验证的有限布局变体。固定关键站位与安全窗口，对外围平台或阶段组合做受控随机，避免独立随机平台与攻击导致不可躲避状态。

最终Boss暂称“最后的守钟人”。建议从玩家本局经过地区中抽取已学机制组合，形成路线反馈。需要限制同时激活的机关数量，逐阶段组合，不能直接叠加全部地区危险。

### 6.1 各场景如何围绕反作用力形成差异

| 场景组合 | 核心操作挑战 | 世界观融合 |
| --- | --- | --- |
| 平原 | 朝下射击抬升，侧向射击跨越短缺口 | 旧维修站与风铃标记教会主角使用工具 |
| 森林与地穴 | 斜向射击穿过枝隙，弹台后调整空中速度 | 植物占据原有脉冲维修路线 |
| 沼泽与遗迹 | 在浮沉平台间选择起射时机，空中反向修正 | 水道控制站与旧校准靶仍可辨认 |
| 峡谷与浮岛 | 借推力抵抗横风，改变空中轨迹 | 破碎运输线路变成空中断路 |
| 工城与钟塔 | 穿过活塞与摆锤窗口，按节奏连续位移 | 鸣钟枪回到它原本的维修环境 |
| 冰川 | 把射击推力用于加速和制动，提前管理落点 | 冻结设施保留了旧时代的运动轨迹 |
| 火山 | 利用热气流，控制推力避免越过安全落点 | 地下动力脉冲失控，枪与熔炉拥有同源视觉标记 |
| 墓园与星桥 | 按平台显隐节奏起射，在可读窗口中穿越 | 残存钟声维持间歇性的道路 |
| 世界钟心 | 组合本局学过的推力与环境交互 | 以曾用于维护世界的工具完成终局挑战 |

可新增少量远程脉冲开关，但必须区分“射击后移动”与“射中目标触发机关”两种反馈。枪支是否与环境碰撞产生额外推力、是否需要命中才能位移，不能自行添加，先遵循现有实现。

构筑优先改变位移方式与控制取舍，例如推力大小、连射节奏或空中控制；这些只是待测试的设计方向。任何升级都要验证通关能力，尤其强推力可能造成过冲，快速连射也可能消耗更多资源。避免所有道具只增加伤害，也避免尚未确定恢复方式就限制射击导致玩家被困。

## 7 随机地图与模块化资产

### 7.1 随机生成结构

建议采用“人工或程序设计并验证的挑战模块 + 规则拼接”，而不是完全独立随机撒平台。AI负责主要视觉资产生成，关卡逻辑、碰撞、连接和可达性由程序保证。

推荐生成顺序：确定种子与大关路线 → 生成10节点类型序列及选择候选 → 根据场景、难度与角色基础能力选择模块 → 对齐入口出口 → 配置机关与奖励 → 检查可达性与节奏 → 装饰 → 输出可复现地图。

检查失败时重抽模块或使用已验证的保底布局；设置重试上限，避免无限生成循环。

### 7.2 模块应记录的信息

| 信息 | 用途 |
| --- | --- |
| 唯一ID与主题标签 | 管理复用、追踪失败布局 |
| 占用范围与连接锚点 | 拼接房间与确定入口出口 |
| 静态碰撞与机关范围 | 将玩法几何与装饰分开 |
| 必经路径与可选支路 | 检查主线，保留高难奖励路线 |
| 所需移动能力与精力上限要求 | 防止生成角色无法完成的路线 |
| 难度与预计耗时 | 控制本关节奏与整局长度 |
| 机关周期与进入安全条件 | 处理动态平台的时间可达性 |
| 可用平台皮肤与装饰锚点 | 更换场景外观而不改变碰撞 |

### 7.3 必须满足的可达性约束

- 必经路径按基础角色能力验证，不依赖玩家尚未获取的二段跳、冲刺、特定枪支或稀有道具。
- 同时考虑水平距离、跳跃高度、落点宽度、头顶空间、惯性、风力和精力恢复条件。主线可达性必须模拟射击反作用力、瞄准方向、射击冷却、可用射击次数与动量叠加，不能只套普通跳跃抛物线。
- 动态机关检查可等待的位置、周期窗口与连续动作；仅检查静态平台距离不足以证明可通关。
- 增强移动能力可以开启可选奖励区，不能成为未经声明的主线门槛。枪支变体必须保证基础通关能力；改变后坐力或射速可能改变所有必经路径的可达性，应提供共同基础位移能力或按实际枪支重新验证，不能把减弱后坐力一律视为升级。
- 提供种子、模块列表与失败位置记录，便于Codex复现生成问题。

### 7.4 AI美术生产要求

先确定风格规范、角色比例、描边方式、色板、光照方向、世界单位与像素对应关系，再批量生成素材。概念实机图只用于确认方向，不直接当作可拼接关卡资产。

场景拆分为远景、中景、碰撞平台、前景装饰和特效。平台准备中段、左右端头、内外角和必要的连接件；装饰独立摆放，避免每段都带独特大花纹而暴露重复。

平台落脚边与实际碰撞对齐，危险物轮廓清晰，背景对比度低于前景。AI输出需要裁切、透明边缘检查、接缝修整和统一比例；不能预期仅靠同一提示词就能自动保证全部素材一致。

首版只验证一套平台拼接包与少量角色动作。角色动画可评估关键姿势生成后人工修整或骨骼动画，避免把逐帧一致性困难扩散到全部角色。

## 8 通用机关与场景差异

先实现六类共享逻辑：移动平台、周期出现或消失平台、弹跳平台、风力机关、升降机关、触碰危险物。

| 通用逻辑 | 平原外观 | 冰川外观 | 机械城外观 |
| --- | --- | --- | --- |
| 移动平台 | 木质吊台 | 漂浮冰块 | 轨道齿轮台 |
| 周期平台 | 开合花朵 | 周期消融冰台 | 定时机械台 |
| 弹跳平台 | 大花朵 | 弹性雪堆 | 金属弹簧 |
| 触碰危险 | 尖刺植物 | 冰刺 | 活塞尖刺 |

场景差异通过外观、参数、运动路径与组合方式表达。低摩擦、传送带、崩塌和时间冻结等新增行为应按需要独立实现，不能仅换皮宣称已经具备机制。

## 9 剧情如何适应随机路线

主线信息跟随层级推进，支线信息跟随场景变化。任何合法路线都能理解主线，探索其他路线则补全不同视角。

| 层级 | 无论选择哪个场景都应能获得的主线信息 |
| --- | --- |
| 1 | 世界有异常，远处的钟声在召唤主角 |
| 2 | 失序不限于局部，季节与自然循环已经紊乱 |
| 3 | 旧王国曾主动干预世界之钟 |
| 4 | 干预影响居民、生命、死亡与自然环境 |
| 5 | 灾难的原因、主角关联与重启代价逐渐明确 |
| 6 | 最终挑战与选择有前文支撑 |

可用破碎雕像、工匠笔记、冻结居民、空王座和短NPC互动叙事。关键主线线索放在必经区域或设替代投放，不能全部依赖稀有随机房间。

剧情系统记录发现过的线索、解锁的区域、Boss进度与结局状态。故事持久进度与本局装备分开保存。重复发现允许简化展示，死亡不应抹掉已经确认的故事信息。

## 10 隐藏路线与扩展场景

隐藏路线后置制作，提前提供可理解的线索。示例均为建议：

- 钟表匠密道：在齿轮工城完成困难跳跃后直达逆时钟塔，跳过第四层，并失去一次常规Boss奖励。需验证奖励和局长平衡，不能直接默认等价收益。
- 遗忘花园：携带森林获得的古老种子，在古堡打开隐藏温室，获取故事与特殊奖励。该方案需要明确种子如何获取及携带。

未来扩展主要增加同层分支，不必不断增加每局大关数。

| 场景创意 | 主要机制 | 可考虑的连接位置 |
| --- | --- | --- |
| 玩具工坊 | 弹簧、积木、机械玩具 | 机械城相关分支 |
| 水晶矿洞 | 光桥、折射、晶体反弹 | 峡谷、地穴、冰川之间 |
| 纸灯古镇 | 灯笼摆荡、屋檐、展开纸桥 | 古堡或墓园相关分支 |

这些是创意储备，不能自动加入首版开发范围。

## 11 分阶段开发与验收

### 阶段一 跳跃与生成原型

沿用现有项目技术栈，先验证现有反作用力射击运动模型、瞄准与输入、平台碰撞、掉落处理与少量通用机关。用占位图验证模块拼接和可达性，再接入一套平原资产。

验收：射击反作用力方向、速度叠加与碰撞稳定；同一种子可复现；生成失败有保底；必经路径不依赖随机道具；危险预警清楚；能完整走通一个含Boss的10节点大关。

### 阶段二 三场景纵向切片

优先制作平原、森林、古堡，验证视觉统一、随机拼接、场景过渡、Boss金道具与小关奖励选择。这是开发测试路线，只覆盖正式网络的前三层，不代表六层世界已经完成。

验收：两个小关出口确实影响下一节点类型；大关过渡正确；三套场景表现有区别但碰撞标准统一；记录实际时长与重复感。

### 阶段三 首个完整通关版本

沿一条合法路线补齐第四层、第五层与最终关，例如平原 → 森林 → 古堡 → 冰川 → 钟塔 → 世界钟心。先完成一条六层闭环，再增加另一条中期分支与第四层替代区域，形成可选择的完整路线。

验收：所有开放出口最终可达；每个已开放大关有10节点及Boss；Boss必出金道具；主线信息完整；保存和重新开始正确；局长有实测数据。

### 阶段四 扩展世界

逐步补齐16场景池、隐藏通道、永久路线解锁和剧情分支。未完成场景保留配置但不开放入口。新增内容复用底层机关，按需要增加少量独特机制。

## 12 给 Codex 的执行说明

请先阅读本文与现有仓库说明，检查已有引擎、角色运动、地图生成和素材结构。保留已确认需求，区分用户设想、本文建议和未定事项。不要因长期规划重建项目或一次实现16场景。

优先推进最小可玩闭环：射击反作用力位移手感 → 可验证的模块化随机地图 → 10节点大关与Boss → 小关出口选择和奖励 → 大关路线选择 → 场景美术 → 环境剧情。

建议将场景、连接白名单、小关类型、机关参数、奖励池和故事线索做成数据配置。配置应能表达已完成或未开放状态，以及连接条件。具体文件格式和目录沿用项目习惯，不预先强制架构。

实施时需要特别遵守：

1. 平原固定为起点；大关路线按白名单选择，不任意连接。
2. 小关出口选奖励或节点类型，大关出口选下一场景，两套状态分开。
3. 10小关含最后一个Boss节点，Boss击败后必出一个金道具。
4. 随机布局必须可复现且验证基础角色可通关，动态机关也要验证等待与通过窗口。
5. AI概念图不能替代模块化资产，碰撞几何与视觉装饰分开。
6. 开枪反作用力位移是已确认核心，不降级为普通跳跃的辅助技能；精力与弹药规则尚待确认，不自行把游戏改成战斗肉鸽。
7. 隐藏路线、复杂时间机制与多结局后置；先交付可玩的阶段成果。

每阶段交付请说明实现内容、如何运行、已完成的验证、当前限制与下一步。遇到缺失数值可采用清晰可调整的原型默认值，并注明；会显著改变玩法方向的选择应保留为待确认项。

最终目标是让玩家在清晰可读的童话世界中，通过开枪反作用力位移、随机路线与奖励选择形成不同的冒险经历。故事解释重复挑战，模块化生产支撑持续扩展。
