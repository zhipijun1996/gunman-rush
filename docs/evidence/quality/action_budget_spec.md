# 武器动作与位移预算

本页统一武器位移、瞬闪／推进时序和主瞄准方向。资源与输入分别按 [资源合同](../combat_and_recharge.md) 和 [输入合同](../controls_contract.md)，分支操控见 [武器手感](weapon_feel_spec.md)。数值未验平衡时保持候选状态。

- 基准D由真实PlayerTuning shot_burst_speed × shot_burst_duration决定，地面按ground_recoil_multiplier；预算指已接受武器运动的累计路径，碰撞可裁剪，转向可改变净位移；自然跳落与移动输入另列。
- Lv1枪/基础炸弹/手里剑 D。Lv2三连每段0.5D共1.5D；激光普攻完整限时推进1.5D；Lv2手里剑与回旋刃第一段D瞬闪，第二段0.5D。遥控炸弹和奇点D。Lv3普攻继承Lv2，主动技参数不冒充Lv2预算。
- 瞬闪由唯一Motor完整形体扫掠/碰撞投影完成，清掉所有速度；落点短暂停顿，期间跳跃可缓冲，受伤/死亡/装备/钩索等取消不留旧请求。候选停顿.075游戏秒。
- 向上反冲结束清掉潜藏下降速度，在顶点短驻后平滑恢复重力，类似大跳顶点。不能以减少基础全局gravity或增加武器预算解决下坠突变；自然跳跃保持原参数。
- 激光普攻开始当帧清速并停住，随后按时间递增加速，完整推进量上限1.5D，候选持续.60游戏秒；主动松开/耗尽/碰撞/取消可少于上限，满时自动关闭且持瞄准不自动重发。结束清除旧下降速度。Lv3瞬间炮击保留。
- 地面遥控炸弹继续投放/附着/按键引爆，近处合法自推D；空中发射走Lv1近身即时爆炸/自推D，无悬空遥爆物。判定以攻击包起手地空快照为准，不改装备或资源事务。
- 钩索瞄准辅助线与实际钩头同探测器；候选头吸附半径12世界单位，460范围仍有界；墙前不可吸到墙后目标。落空可见快回收，候选4200速度/.015停顿。拉近后踢跳固定45°，从目标左侧来则左上、右侧来则右上，不跟结束时改瞄准。
- Lv3技能复用主瞄准（手柄右杆/PC鼠标/手机射击杆），手机SKILL为独立触发按钮而非第四方向杆。没有当前方向时沿同设备最近有效主瞄准；切装/暂停/失焦清旧方向。Web触摸按下期间及松手后400ms屏蔽浏览器device0伪鼠标，防止抢主瞄准；之后真实鼠标仍能切设备。技能触发与瞄准松手不应附送普攻。


用真实 Router → Ability → PlayerMotor／Damageable 验证地空、左右、不同帧率、累计路径、碰撞裁剪、清速／顶点连续性、取消和三端方向。按实际消费者记录连续正常速度音画、独立审查和设备范围；不从局部动作测试推定正式成长或完整地区已交付。
