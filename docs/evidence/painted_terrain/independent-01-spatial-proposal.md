# 首轮只读绘画建议：风剥草毯下的厚土台

2026-10-17，PR75 `0905516` 基线。本轮采用现有 visual-director、art-director、scene-composer 的实景/资产/空间分工，只写独审，不改生产。实际看过 `docs/evidence/visual_language/media/candidate-recoil.png`、`candidate-encounter.png`、`candidate-lookback.png` 和 `assets/visual_development/master/b1_master.png`、`paintover_target.png`。后两者是设计图，不是实机。

建议完整空间：三岸共同成为被风侵蚀、有人维护的厚草土台。保持现有三岸碰撞和真实路线，改的是地形绘画结构。入口树根锁住旧岸；中岸用低频宽侧面为敌人提供安静舞台；高屋岸上宽下收、体量贯通，屋脚落在顶面接触阴影内。一个记忆点集中在接收岸：浅陶色补缝钉住风裂草唇，圆钝盘筑形承接B的人造物语汇。它不是新机关、攀爬点或平台；不得让装饰形状暗示虚假站面。草簇和已有屋旗方向统一，裂口中断被维护的连续草唇，表达风与脆弱秩序，不需要新增背景。

可直接绘制的截面：

- 浅暖草顶的窄斜面，正常画面约10–18px，仅向真实碰撞线后侧展，不跨gap。亮线指向可站面，但不变成等宽发光描边。
- 连续深褐根毡唇，约12–24px，少量断口；根丝成组而非满屏毛边，不能遮玩家脚底与危险预告。
- 主侧面用冷灰紫/褐色3–5块大面建立厚度，上部受草毡遮蔽、下部渐冷暗；少量斜向切面随坡势转折。先低频体积，最后才加局部纹理，不用亮黄岩条承担整块形体。
- 端头把草顶、根毡和侧面折成同一圆钝断面：亮面结束，暗转面连续下去，锚点对齐真实gap边。端部不是把水平条旋转90度，不画突出可站台阶。
- 高岸必须有整块竖向承重组织与屋基，不把纹理缩放到更高的矩形内。底部延出屏幕的暗体可保留；不凭空补悬浮石脚。

风险：条带如果过宽，会变成玩家脚下不存在的后排平台；草唇过厚会盖地面脉冲/锯；明亮陶补缝反复出现会抢过敌人与玩家；轮廓被圆化得超出碰撞会误导落脚。根/顶面/侧面可以共用母件，但端部与坡角要有明确接口，不靠等格atlas或重复UV猜拼接。

先看本空间240反冲、360遭遇、600回望实际像素：是否读到草顶厚度、端头转面和连续低频承重；是否仍一眼找到玩家/敌人/落点。此建议不是资产准入、实机通过或黄金认可，也不以旧方法失败预判新方法应停止。
