## 源码和来源核对

读取 `title_backdrop.gd`、`clockwork_theme.gd`、`game_typography.gd`、`project.godot`、`demo_menu.gd`，并检查 DemoApp 的六行选择器显示门控。插画是两个独立 TextureRect（标题背景与透明徽章），操作仍是 Godot Controls／Containers，未将整张 UI 图当作按钮实现。标题素材没有接入正式地区背景；角色、怪物和环境脚本保持原消费者，选择器只改变界面可见性。

`assets/ui/demo_ui_01/r2/generation_record.json` 和任务来源记录保留两个 image_gen 原 PNG 的 SHA、无参考图来源、工具、用途及未知模型信息；未伪称 CC0。Fusion Pixel 字体保留 OFL 与上游依赖许可证。本人用 fontTools 读取该字体的37689个 cmap 映射，标题实际中文文案缺字为0；这只证明本标题字符覆盖，不等于全项目覆盖与导出完成。

初审提出 `GameTypography` 仅局部持有旧路径 FontFile 可能在晚加载时重新读取原字体的风险。实现者已新增 `_legacy_fonts: Array[FontFile]` 持久引用；源码修正合理，**真实晚加载消费者与重新进场的字体一致性仍待运行验证**。这是全局表现接入，不能仅凭标题直接 preload 的新字体签旧 CanvasItem draw_string 消费者全部通过。

## 具体剩余缺口

1. 中文名称现在只是左上24px文字，主品牌几乎全由英文 `DISORDER CLOCK` 承担。当前能辨认，但中文游戏名称是否需要更强主标层级应交用户评价，不以英文徽章精细自动视为中文品牌完成。
2. 按钮虽有圆角、层次和清楚焦点，表面仍较平整；与细致、磨损的铜钟徽章相比有精细度差。继续全屏验证，避免其余菜单再次退回大量等重色块；不要求单纯增加纹理或装饰。
3. `title_backdrop` 目前按固定比例布局徽章，没有本次实际手机／窄窗像素证据；左侧按钮与右侧徽章在手机缩小时是否争夺空间、文字是否裁切仍未验。
4. “继续游戏（选择存档）”实际读取既有成长记录，子页明确说明回家园而非恢复局内位置；这一诚实边界可接受，不能报告已实现局内存档恢复。“新手教程”当前调用文字操作说明，不能报告新增了可操作教学关。
5. 徽章漂移与飘尘只有源码路径，尚未完整观看连续影片；不签动画节奏、声音或帧率。新字体对地图长标签、数值、设置、商店、奖励、Boss与家园的实际排版仍需完整合屏检查。

当前只为桌面标题静态方向准入。完整 HUD、触控／手柄、焦点恢复、导出字体闭包、不同尺寸和用户／设备评价均另验；不扩大为整项任务完成。
