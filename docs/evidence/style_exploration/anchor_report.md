# 风铃平原五锚点：来源、真实拼接接口与 16 区扩展研究

任务：WINDCHIME-ANCHOR-EXPERIMENT-01。研究日期 2026-10-19。范围：原始素材核验、源像素裁切派生、技术与生产潜力研究；本文不是 Godot 实机验收。实际场景、GPU 截图、同布局和随机 seed 验证由主实验记录提供。阅读了当前 AGENTS、art-director skill、新美术地基入口与地区 V0.3 文本；没有查看项目旧美术图作为创意参考。地区仍以 V0.3 的身份/机制为约束，其他 15 区未实现。

## 视觉语言和实际拼接事实

### 1. Retro Lines

视觉：近黑底、单像素亮色轮廓、折线型草缘/树枝、极少内部小方孔。独特性来自低信息密度、剪影和符号轮廓；不是高密度材质像素。亮绿/褐首组明显偏电子复古，直接铺开易产生荧光洞穴气氛；风铃平原需靠开阔景深和暖色风铃地标保留童话感。

原图 `Environment.png` 和 `With-Background/Environment.png` 均 1024×1440，原生 16px 网格；本轮使用带不透明暗底版本，避免透明实体中心泄露天空。首个原生框为 5×5：TL=(0,0)、T=(2,0)、TR=(4,0)、L=(0,2)、I=(2,2)、R=(4,2)、BL=(0,4)、B=(2,4)、BR=(4,4)。坐标以 16px 单位从零计。原生框内圈褐线跨第二圈，不能宣称一个 3×3 原生47全集。

派生：对上述格取 8px 象限组合，保留原生轮廓；内角使用实心暗底象限，表现为方形内接缝，未添加原创倒角。薄结构允许，但 1格平台顶底轮廓会接近，视觉更像线框块，应在实机读图判断。

### 2. Basic Platformer

视觉：明快草帽、粉褐土、深紫细边、两至三档像素阴影、圆角植被；最接近平原开阔/明快起点，原包已有 grass / desert / snow / autumn 四环境，是系列化可行性的真实证据。现有对象数量有限，直接混入 16 区会显通用入门包。

原图 `sTileset.png` 为128×160，16px基准，但并不是干净的等格47图集。左崖、顶部、底边在草土区域 (16,0) 起，右侧边界继续与填充图相接：不能误把 (2,0)/(2,1)/(2,2) 当完整右封口。

最终派生：左外角/左边来自原图 tile(1,0)/(1,1)/(1,2) 的左8px；右外角/右边是这些源象限的水平镜像。顶部和内部从向内半格取样；底边从 row2 下半取样。内角保持方形、不额外描边。完整每patch矩形与 horizontal_flip 已记 manifest。原图缺少专用单格短台，但象限组合可得到有顶草、底边及左右端帽的1格块；不能称原包原生支持47态。

### 3. Scribble Platformer

视觉：铅笔灰双轮廓、近白纸面、轻微不规则边、几何符号和清楚的独立积木。大形简单、可通过环境主色和局部主题线条统一，但平台每格有描边，连续长地面保留积木节奏；不能把外轮廓图集伪称无缝岩土。

`spritesheet_default.png` 704×704，必须依照 XML 的实际 rect；若干模块高65px，引起后续 y=321/385/449/513/577，不能按64px均匀网格裁装饰。本轮用原生 `tile_border.png`: x320 y385 w64 h64。所有47mask共享此原生积木，不通过局部拉伸或裁残轮廓伪造连续blob。Godot仍是 TileSet / TileMapLayer 真拼块；美术拓扑不依赖47mask外形。若下一阶段选择此风格，需要设计专用连续草/树皮/金属模块，与独立桥块语义分开。

### 4. Underworld

视觉：深蓝黑实体、疏落青黑颗粒、苔绿边缘点光、暖琥珀另一家族；以轮廓和局部亮面表达材料，比单纯黑色剪影更有空气。阴暗题材天然擅长，平原必须打开天空与远景而非把全世界都压成地穴。

`TileSet.png` 176×144，16px。绿色外壳原生3×3：TL(1,0)、T(2,0)、TR(3,0)、L(1,1)、I(2,1)、R(3,1)、BL(1,2)、B(2,2)、BR(3,2)。内角有2×2交会：iTL=(5,1)、iTR=(4,1)、iBL=(5,0)、iBR=(4,0)，这里 iTL 指空气位于当前实体 tile 左上对角时所用的左上象限。另有琥珀家族 rows4–6，不能跨家族随机替换绿边来制造噪声。

派生：原生四边/凸角/凹角/填充的 8px 象限组成真正47种不同图案；无需补画内角。该包在此五套中原生拓扑支持最完整。要特别看一格竖柱/薄台的两侧苔点是否过密，以及凹角接头的亮度是否抢落点。

### 5. Cavern Tile Set

视觉：有体积的石层、紫灰受光边、深暗内部、长垂挂岩齿；背景/背墙/前景岩体明确分层。材质与景深基础更接近完整银河城场景，但纹理、明暗方向和跨格结构约束更高。

`layers/tiles.png` 是512×288 **已经拼好的示例几何**，不是可随意整图随机取格的生产atlas；白色隐藏RGB在alpha0处不代表白边。可裁 top(12,9)、bottom(12,5)、left(7,3)、right(23,3)、fill(12,11)、TL(7,9)、TR(23,9)、BL(7,5)、BR(23,5)，均16px网格。底边原生岩齿真实存在，所以短台更尖、更厚；不要把岩齿轮廓当危险尖刺碰撞。

派生使用上述源象限与方形内角，不宣称原生47或已证明所有岩纹无缝。当前提取只代表一套可运行测试接口，下一轮高品质资产应制作连续表面母版与正确四边/内角，不能无限裁示例图扩成16区。

## 可直接接入的接口

`derived/{retro,basic,underworld,cavern,scribble}_blob47.png`：8列×6行，前47格有效；最后一格透明。项目原位序 N=1、NE=2、E=4、SE=8、S=16、SW=32、W=64、NW=128，剔除没有相邻正交支撑的对角后按数值升序。完整 mask→atlas 坐标见 JSON。

前四套16px，Scribble64px；运行统一32世界单位/格，nearest采样。处理仅源像素裁切、象限拼接、Basic右侧镜像；无程序补画、无 AI 图生。`build_atlases.py` 可再生。

实际47格的像素不同数量：Retro16、Basic16、Underworld47、Cavern16、Scribble1。47个配置坐标不等于47张独特图案，更不等于47态美术都已独立通过。Underworld内角原生；其他连续地形以内角方形收口适配，Scribble用独立积木语法。运行验证应分开记录这几种能力边界。

## 同一画法支持16区：内容矩阵

以下从 `regions_v0.3.md` 当前地区/动作文本推导新的生产拆分；不是恢复旧图或旧母版。统一像素尺度、轮廓厚度、受光方向、前中远景对比梯度、角色/危险/交互语义；地区至少同时改变材料、轮廓、空间/光源、标志物，不能仅换16套palette。

| 地区 | 独立主体材料 / 轮廓 | 必做地域标志与空间层次 | 可共享的技术接口 |
|---|---|---|---|
| 风铃平原 | 草土/浅岩、舒展顶沿 | 开阔草坡、断桥、风车、低钟塔；宽横向天空 | solid地表、one-way木桥、独立风铃 |
| 荆棘森林 | 树皮纵纹/枝节、树冠窄口 | 巨树竖井、交织枝台、可钩活锚点 | solid木质四边；H锚点稳定语义 |
| 萤雾沼泽 | 湿泥/浮叶、低平沉降轮廓 | 浅滩、水平水线、共鸣水钟与薄雾 | 地形与水面分层；U1交互语义 |
| 风蚀峡谷 | 层理岩、长直高壁/风槽 | 高竖壁、两壁井、横风留白 | 可攀墙面和危险墙面不同标签 |
| 蕈灯地穴 | 湿岩/菌褶、圆伞和倒垂轮廓 | 折返洞室、孢子井、分簇菌灯 | 岩体blob；弹伞独立物件/动画 |
| 月冠古堡 | 切割石/织物、尖拱和阳台 | 吊灯厅、月镜、围合室内窗光 | 建筑实体与吊灯运动件分离 |
| 沉水遗迹 | 浸水石/水线、方形环路 | 蓄池、升降柱、不同水位背墙 | 水位状态切换不烘进terrain |
| 齿轮工城 | 铆接金属/油污、桁架和窄井 | 活塞墙、管线、工业纵深 | moving件单独atlas与参考系 |
| 月影墓园 | 风化墓石/枯木、低矮稀疏轮廓 | 钟亭、虚影桥、薄雾留白 | 虚实状态用稳定功能标识 |
| 霜镜冰川 | 透明冰/压雪、切面和裂隙 | 冰瀑侧壁、碎冰与稳定岸对比 | 低摩擦/碎冰不同语义材质 |
| 熔火腹地 | 玄武岩/炉渣、断裂下缘 | 喷口、炉道、下方热光 | 危险热流与安全岩边分色 |
| 破碎浮岛 | 断石/悬根、大岛底和长断口 | 云海、岛链、远距空中锚点 | 完整底边不可用无底地表替代 |
| 根脉圣殿 | 巨根/祭坛石、根柱与生长环 | 动态根道、树心钟核、立体环路 | 固体根壁与伸缩桥独立 |
| 逆时钟塔 | 精密金属/钟面、同心与竖向节律 | 摆轮、垂直墙、相位光 | 移动/旋转构件不可烘进地形 |
| 星桥天门 | 天文石/细金属、长悬桥和星环 | 星空大留白、定向光流、亮路径 | 交互光桥与背景星轨区分 |
| 世界钟心 | 巨钟内壁/沿路材料残片、宏大环形 | 分段重组本局已见主题、轴心聚焦 | 用已选地区家族组合，不能混杂全部纹样 |

建议共同生产层：①约束配置与功能色；②每主材料完整四边/凸凹角/填充、薄结构；③地区中景/地标模块；④远景三层；⑤无碰撞小装饰与小动画。共享的是接口、画法和世界符号，地区主体地形不共用同一张图改色。

## 扩展和 AI 生产风险比较（研究判断，非已完成AI稳定性试验）

| 锚点 | 16区一致性 | 地域差异能力 | 生成/修补难点 | 可持续方案 |
|---|---|---|---|---|
| Retro | 很高，少线条容易锁 | 中，需重设计剪影避免16种发光空壳 | 单像素线粗和网格相位，AI容易造多余线 | AI只做轮廓/大形候选；人工或受控像素工具完成接口，不用AI整张47图 |
| Basic | 高，已有4环境真实系列 | 高，材料和植生容易扩 | 圆角/草帽/明度容易漂到通用卡通；边界全集不足 | 先32wu母版合屏→4角/4边/填充+薄台→小量主题物件；统一色阶和边厚 |
| Scribble | 高，线条可归一 | 中高，靠线形/结构而非复杂纹理 | AI线条粗细与闭合轮廓漂移；连续材料须新增 | 扫描/绘制统一笔刷；模板固定线宽；独立积木与连续地形分家 |
| Underworld | 高，暗体+边缘材料清楚 | 高，16区需覆盖明亮/湿润/机械，不能都暗洞 | 苔点密度/光边方向、暗部压死 | 以少数暗阶和单材质边缘建立原创完整家族；先解决许可确定性 |
| Cavern | 中高，材质丰富但难锁 | 很高，材料/构造/光源可真正变化 | 跨格岩层、角向受光、内角与薄台非常容易失败 | AI生成连续材质和地标母版；锁拓扑裁切/修补；完整接缝矩阵后再扩区 |

**未进行 image_gen 调用；不能把低复杂度推断写成已实测的 AI 生成稳定性。** 本轮源像素转换稳定可再生只证明受控派生，不证明AI能可靠生产16区。

建议下一阶段候选是 **Basic 的明快有限色阶语法** 与 **Cavern/Underworld 的材料边缘与层次语法**，由实机五套合屏结果决定最终1–2套，不把“原包更完整”自动等同“更好看”。若采用暗体方向，平原仍须有开阔明亮空气和暖风铃焦点；至少以明亮平原、湿润沼泽/菌窟、硬质工城三种相反材料做同风格压力测试，再谈16区量产。

生产顺序：用户选1–2套 → 同一正式镜头做原创黄金合屏 → 每套一主材料完整边界与薄结构 → 三seed/孔洞/阶梯/岛底/一格柱真实Godot验证 → 第二个对比强烈区域小样 → 锁世界级画法与地区设计卡 → 每次只准入一个材料家族扩展。每个家族保留来源许可、母版/派生hash、具体生成工具/模型/提示、失败图和修补记录；AI负责候选画法与中景资产，拓扑和碰撞接口由确定性管线控制。
