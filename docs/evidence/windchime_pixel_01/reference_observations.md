来源入口：https://www.animalwell.net/ 与 https://www.animalwell.net/press/build/Animal%20Well/index.html

- `images/screen_capybara.png`：大块暗部、有限高光轮廓、成簇垂植物与细小局部亮点；空间有包围感但角色落点边依然明确。
- `images/screen_crank.png`：矿物纹理有方向和密疏，蓝/紫局部亮暗不同；纵深由背景退让与局部发亮组织，不是整屏统一填色。
- `images/screen_crows.png`：建筑有切面/砌缝/雕刻层次；动物、藤蔓和吊灯一起建立生态，亮处是少数焦点。

本项目借鉴像素簇、材质方向、明暗层级与生态组织，不复制具体关卡、动物、角色或贴图；不把三图里的暗色地穴主题套到全部16区。风铃平原先做有晨光与风向线索的遗迹草甸小样。原PNG只作本地分析，不列游戏资产；版权归原权利人。图生背景请求没有附带这些原图。
