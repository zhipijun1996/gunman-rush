## 方法成本复核

`profile_before/`与`profile_after/`为同包衍生的观察性方法计时，包含插桩开销，不能代替上方原包RAF。10秒内机关绘制从4961次降至130次（每个显示帧合计9.37→0.42ms）；正式Stage物理回调的包含成本9.06→1.22ms，基础快照从604次降至130次（每个显示帧5.81→1.62ms）。父子方法成本有重叠，不能相加。敌人物理与软件渲染仍占用较多时间；当前没有真实硬件GPU计时。

## 实现与边界

- Web文件／资源读取分步留在主线程，完整库数据的校验／解码和原SDK求解由独立线程执行；验证、场景和Run提交留在主线程。
- 家园保留本次出发种子，按实际装备与容量准备；出发核实际请求、种子、配置和容量，只转移匹配的纯计算所有权。输入变化、取消、退出会终止旧准备。运行中无家园求解任务。
- 保持物理与探索频率；机关只刷新可见表现，完整状态按显示帧合并采集，显式保存同步采集；地形由真实变化事件失效，小地图复用实际几何与迷雾缓存；HUD消除每帧布局往返及隐藏调试文本格式化。
- 106个平原内容支持、真实基础一跳／一发空中弹药、三主路／六奖励、正式美术与界面保持不变；SDK0.4.1与模块包1.1.0原件未改。
