## Atlas、细粒度与边缘反例

代码检查范围：脚本创建AtlasTexture、原图import配置、shader顶点/片元、原母版实际RGBA；读取母版像素仅作测量，没有生成替代美术。

- Sprite2D nearest、master lossless无mipmap、`AtlasTexture.filter_clip=true`。shader使用实际Atlas UV及其导数推算采样偏移，没有把Atlas的UV误当独立图片的0..1空间。世界采样坐标通过MODEL_MATRIX含实际缩放且排除平移，目标为1wu格中心。
- 源锚点由原native尺寸逆变换，数值回到原crop局部坐标：grass_a[124,272]、grass_b[107,264]、grass_c[114,313]、branch_left[10,15]、branch_right[562,12]。
- 构造的串片反例：片元重采样会使UV在图元边缘向外移动，不能单靠 `filter_clip` metadata 宣称自定义UV一定受限。当前最小scale约.3896，半个1wu格最多偏移约1.284原像素；实测5个raw_crop外围2px的alpha最大均为1（1/255），没有相邻资产主体。当前原图条件下没有测出邻件主体污染，但GPU边缘裁切/微弱alpha尾部仍须实看。未来换成紧排atlas不能沿用这个结论；届时应显式约束采样UV或提供独立纹理。
- 构造的粗粒度反例：若把05 native 248px枝PNG放大到352wu，会出现大于1wu的旧源像素。当前实际绑定原始577/575px裁块后缩采样，没有采用该路径。
- 采样在item局部1wu网格。当前CanvasLayer默认变换下对应屏幕1px；若未来给CanvasLayer新增缩放、旋转或改变画面缩放合同，不能直接外推为仍与世界地形一致，需重验。

## 完整矩形、风与挂点反例

- 候选大小先作用于真实raw_crop尺寸和源锚点；position取整后重新计算实际挂点与bounds。保护比较使用完整原图显示bounds的grow(3)，没有取不透明子框、可见裁片或只查根点。
- shader风的两正弦最大绝对合计1.6wu；除以source_to_world抵消源缩放。对5件实际源锚点，整图顶点的最大位移上界依次为1.5488、1.5473、1.5553、1.5723、1.5638wu，均落在3wu扩框内。剪切系数在真实根/挂点处为0，未全树/全枝漂移。
- 构造的根进屏反例：世界候选经过round后可能比未取整投影更靠近屏幕。脚本检查的是重新计算的actual_anchor，不是未取整screen值；不满足12wu离屏则整件隐藏。枝使用屏外侧挂点，草使用屏幕底部以外根点，避免产生可跳假地面。
- 构造的透明度假计数反例：opacity=.0045现在会以`below_readable_opacity`拒绝；不会消耗显示池或递增grass/branch计数。大透明边界仍可能让面积门槛高估实际叶片面积，因此实机可读性不能由计数代替。

## 动态UI、警告与保护边界

- 每次refresh先隐藏全部3个Sprite，再从实际Control矩形、实际变换和祖先CanvasLayer可见性重建UI保护。文字、贴图、按钮、面板以及已识别的自绘Control都参与；透明布局Container不直接当全屏HUD，TouchOverlay按实际摇杆/按钮区域参与。
- 玩家身体、真实枪口、220wu瞄准线、实际钩索导引/绳段、敌人、实际投射物历史轨迹、实际碰撞形状、平台边缘、未领取奖励与boss场所参与。Protection合并仅扩大或保留覆盖，不以叶片alpha洞允许重叠。
- 可见敌人的telegraph/attack且其200×200wu区域进入视野时，整个前景隐藏；超过64个保护矩形也整个隐藏。没有用计数或metadata代替渲染隐藏。暂停时风停，但UI和保护每帧继续刷新。
- 代码层限制：自绘Control若在自身size以外画额外HUD，或新增自绘Container，通用矩形识别不能保证完整覆盖；当前boss场所保护另外隐藏前景，但这不等于通用自绘HUD已获覆盖证明。需要新增此类HUD时复查实际draw范围。
- 代码层限制：敌人全隐藏条件基于敌人区域与telegraph/attack枚举，而非所有警告实际绘制路径的包围框；新增超远攻击、屏外攻击源或不同state命名时，不能默认继承保护。当前素材/正式行为的实机攻击阶段仍须由主控测试。
- 代码层限制：process_priority=2000并不构成对未来所有晚执行UI回调的顺序保证。正常process/physics流程后会重新刷新，但若后续引入更晚的HUD/警告变更或其他Viewport，必须补验证。新/删除节点通过SceneTree信号维护WeakRef，不仅初始遍历。
