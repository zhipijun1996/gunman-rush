五类行为比旧两怪丰富，跨枝体真实弹道/接触/受阻恢复、C蛛线普通跳避与活萤返冠有具体作用。弱新獾、上层组合、无价值侧环被删除，是有效淘汰，不应补回凑数量。

已知结构缺陷仍在：当前推荐N02完整1013帧，根盘籽哨和冠蛛各1013帧全idle、HP不变；下萤自主移动但本路线不与它交互，C内蛛实际展开/收回且890真实伤玩家，跨枝体实际被H伤1。它不是旧“三怪全idle”的同一结论，也不是五怪全成为有效遭遇。主路相当部分生态仍旁置，安静恢复段与缺少判断的空段尚未系统区分。单路线不能外推所有地图都如此。

v10真实变化包含骨架进入关系、奖励目标/异路返回、水平或下降洞型、合资格R出生与可选西奖枝；不是纯镜像，也不是只改driver参观顺序。其变化仍来自少量资格受限组合，D与R入口不会遍布所有seed；共享主体与解决方法重复度高。旧80路线证明可达，不证明当前多Seed发现顺序、方法、风险回报和空间理解足够不同。隐藏区域的发现体验、跨Seed敌地形组合和重复劳动未获充分实际评审。

## 最多三项优先继续

1. **先补女王H的主动进攻/恢复价值。** 从已有活结与持续追击关系选一个最小假设，让借结确实带来不同射角、持续进攻或退路取舍；保最强普通cut/keep。若只有多绕一步或多按H，删/重做这一关系，不靠加HP、封普通岸或缩窗口。
2. **重编主路生态与节奏。** 用当前真正经过的根盘/树洞/冠枝关系，让敌人的承诺改变玩家选层/选方向，优先利用已有行为替换旁置遭遇；保观察与恢复，不通过塞怪/加频率填静段。以完整目的地和回程判断价值。
3. **把跨Seed差异推进到决策，再做初见试玩。** 在现有共享树体系中改变有收益的发现/回程/遭遇关系，而不是继续堆枝台形状；选少量真正不同的seed交给陌生玩家观察选择与重复劳动。专家轨迹比较和真实玩家反馈分开，允许淘汰无收益变化。

以上是继续做高品质地区的优先问题，不是新增验收框架。当前可继续试玩和迭代；核心目标未通过的结论保持。
