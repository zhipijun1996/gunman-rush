地图2 fast 本次原生同源严格通过：1848物理帧、19腿、末HP5，录制耗177.324秒，处于原240秒上限内。MP4为60fps、1860呈现帧、31秒原速。我逐张实际看了14张1280×720精确关键帧，并查看原片每秒抽取31个代表帧组成的整段时间覆盖缩略序列；结合原轨迹核对动作、敌人死亡与H目标。稀疏序列并非完整实时播放，我未听音轨、未真人操作。

2.12–9.78秒可见宽根岸上的两只新甲虫、朝向树皮盾和橙色预告，玩家跨到另一侧后实际弹体击杀。11.78–16.78秒旧织棘蛛红线和冲锋敌的身体语言又有区别；这些内容确实出现在普通路线，不只存在于敌人数量。后段爬回树洞，26.78秒可见木质上下荆棘、身体、枪线与锚点；所看画面未出现背景遮死角色或唯一目标。
