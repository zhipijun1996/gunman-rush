## Pack producer and limits

`python3 producer.py` only inventories/verifies and writes plan/summary. First planner stopped on dedup-path equality; second stopped on pre-overlay copy inventory. These planning refusals are retained, fixed explicitly through SHA-content dedup and genuine native/verifier inventory composition; no native failed or reran because of them.

After root-reviewed size approval, `python3 producer.py --pack-after-review` reads that plan, refuses source drift, refuses an existing archive, bounds metadata-inclusive uncompressed payload below64MiB and requires128MiB headroom in addition to raw payload. It compresses exactly once, then reads EVERY member back from tar and verifies SHA256/size. Originals are never deleted/rewritten. The archived planning flag archive_created:false is historical planning state; separate archive-receipt.json is the actual pack result. This is not a full asset/PCK/engine bundle and not a new verifier pass.
