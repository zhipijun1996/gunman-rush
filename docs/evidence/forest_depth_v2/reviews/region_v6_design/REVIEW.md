## 1. 种子现在确实改变一次空间动作，不再只有奖品顺序

骨架仍是同一棵共享巨木，并非大量不同宏观迷宫：入口M／R／W，camp内根／外根／北庭，cache在内外跨联或C，改变发现顺序、去程及回营方向。这些是有意义的探索关系，但奖品移位本身不应计成新动作。

V6新增第三次拓扑抽样独立选择图2第二孔：水平版在B站地横H后接同高C；A2版先离B檐、下瞄，经历实际windup自由下落，再侧拉接低90px的宽C。新普通返回用真实relay分两次爬升，不能沿用旧返回通过身份。整个Queen场地和prep随C高度平移，同一Boss目标对应了不同接近／接收状态。不是镜像、平台长短微扰或只挪Boss标记。

A2独审已纠正方向措辞：请求向右下27.43°，真正pull开始已因下落变成约4.87°；不能宣传持续大角度斜下牵引。差异仍真实，因为“撤离支撑何时发射、固定原点与身体何时接近、保枪接边还是R抢中岸”发生了变化。

F01旧问题获得实质修复：图2Boss主推进现在消费C；新北庭N→共享中继→S，正式580帧中132–218共87帧完成这段，而旧探索片132–465先下M再爬S共334帧。节省247帧不是加新标签；旧重复攀爬反馈已被处理，不能继续当现状指控。C→实际奖励→实际新高藤门也有原轨迹。

边界：这是“一棵树、有限骨架、两种穿越关系”，还不是任意种子持续产生全新解题语法。v4原16与V6单下降孔正式样例分别成立；当前80计划不能写成80已完成。新方向在正式全图中的视野／发现／回头选择还缺当前正常探索影片与真人材料。

## 2. 便宜普通解没有全面支配，但穿树H不是速度解

四例都HP5；最终返S均自然回满。C声明不是同一时长的精准节点停稳：H0R和3R原driver没在430±2停满12；elbow_formal01另有真正C节点12。不能把两种合同混算速度，亦不能禁止Godot合法部分脚面接收救H必要性。

强普通在速度／无伤上赢过HR，不是反例应删掉；H0R保枪与HR抢宽岸形成不同资源／接收状态。不能把到岸能量差说成Boss入口永久收益——沿宽prep步行自然回能，尚无同源普通正式全程证明差值仍保留。也没有有限扰动证明HR更容易，岸裕量不是舒适度测量。

这不足要求重做穿树：H提供另一个可理解的机动手段，低资源／保枪目标可能合理，玩家不必每次选它。若只按满资源速通，普通3R会胜，设计文档应直接承认。不要为了H快而改Player、缩岸、加伤或封屋顶。

## 3. F02不再是“只把怪带完”，但地图2主路仍基本不消费生态配方

正式可选远征是有目的的一整条路：拿奖真实指针选择→回camp自然心回血→再到R选择→E→门。四capture前538个完整frame对象完全相同，随后实际改变输入；我离线重算得到758／775／1123／836帧各自完成，门前都HP4、E100。

在R→E这个具体选择点，借活萤H真contact伤2→1，再R，70运动帧；普通满跳双R87帧，多耗一枪和20浅层能量。等另一巡相位额外365帧；低空误用枪后先自然落岸补弹再选H，148帧。后者不是“空弹H直接逃脱”。根哨身体伤、camp正常回血、E后蛛身体伤均保留，不能把整路叫无伤。它说明活敌可以成为有条件的交通资源，不只是新怪ID或强制钥匙；但365帧不是证明玩家必须等，门前自然回能也不支持永久能量优势。

另一面，**当前正式下降孔growth580帧，root_seed_watch、crown_thread、inner_thread全程idle且HP不变；lantern199帧dwell／93预告／288travel，HP不变，没有被该路线利用。** 实际路径走W→N→S→低C→奖励→prep，越过了旧内根802／外冠558／萤680的主要遭遇层。这个结论不是仅由怪数或距离猜测，见逐敌原轨迹统计。活萤巡航不等于玩家与其发生决策。

因此不能把可选图1远征的F02闭环扩大成“独立enemy_mix现在会改变图2主干解法”。图2可以保留安静的观察／穿树段；无需每条路都有战斗，更不应把怪塞在唯一接收岸。**仍值得返工的具体内容面是生态配方与实际被使用空间脱节，而不是全区增怪。** 最小改进是挑现有一个实际会再访问的高低交界，让现有敌类的预告／保活借点／正常绕行真正影响一次前进或返回选择，保宽观察岸及安静穿孔。若决定图2有意纯穿越＋Boss，则把该范围说清；不要继续把低层配方当它的主路随机玩法成果。本报告没有指定必须加第几只怪、必须承伤或必须H。

当前数据没有证明这一安静段是碰撞／AI程序bug，也没有证明既有蜘蛛或哨兵不可公平解决；不能因脚本没应对就宣内容强迫损血。四远征仅同一recipe，另一mix仍主要是位置／伤源变化的设计候选，不能外推全部种子。

## 4. 两Boss保住了地区H身份，移除H会丢掉具体互动

守卫是截获实体移动铃→真到达／踢→铃实际返回主人→4点Policy／打断，同时真实跨场追击；女王是借可伤活结→反冲弹剪断同结→永久停同网／改变后继网络，加上常态可伤的迁巢和真实射线遮挡。两者动作因果不同，不是两个等计时开弱点。

守卫普通先避铃再站射487tick／HP4，H606／HP5，普通更快但H无伤。女王最强edge1115击杀，H1492击杀，同伤1；H借剪提供持续改场，普通则确实普通换层／改射角，不再旧永久右岸全场共视。女王H后半仍多为宽中岸追踪输出，未证明每阶段都有持续高阶选择；edge也未走完P3完整高低巡回。这些限制沿用不同作者整战评审，不强迫加HP补戏。

所以“移除H游戏仍可通关”是真的；“移除H什么核心也不丢”不成立：会失去夺武返击、借剪同一危险网络和保活敌换层三种具体玩法。反过来，H在所有时间／伤害／资源轴全面胜出也不成立，不能声称它是必需或最佳策略。普通快解没有全面支配所有目标；它的合法强度应保留。H是否成为玩家主动喜欢的地区特色仍需人玩，不由自动驾驶H次数证明。
