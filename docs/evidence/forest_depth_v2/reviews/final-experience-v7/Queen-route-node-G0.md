# Queen实体路线结：G0有条件继续，不签价值

只读独立咨询，已读作者`root-structure-G0/NEXT-CONTRACT.md`；未改作者文件/main、未native。**允许一次build-only可证伪黄金，但先明确完整预告取消语义；暂不准入Boss/存档。** H仍拉Player，另新增结自身物理受力且普通弹也能推，这比只识别H事件的开门按钮更有可解释因果。真实位置选下一路线也可能产生主动性；若只是跨20px后按固定按钮招近靶，仍不能签H高潮。

1. **完整预告的合同冲突必须先消除。** “预告开始选近巢、结束才锁”加“锁前剪取消”可能让最后一帧剪结将已显示近线变远线，留下近零读新线时间。若剪结改变已显示路径，必须重走完整预告；或固定这轮已显示承诺，剪结只影响下一轮。不能在driver里硬避末帧，把漏洞留给玩家。
2. **最强普通应看圆弹擦角。** Player可到约(348,350)，向结(344,390)左上角(332,378)瞄`(-.55,+.835)`；该线到角的垂距约2px，小于真实弹半径3，中心LOS不交不等于真实弹不交。若其给约22px左分量越20阈值，普通一枪既操纵同路线，又反冲向右上撞干/爬顶。必须真实9px枪口+3pxShapeCast+Policy提交+完整返岸；不是本稿证明已能击中。命中退款按真实账本，不能把该枪必算净20E。贴身/枪口在内的合法情况同样不禁。
3. **锁后剪获得两利必须保留。** 真实推/拉→等路线完整锁定→普通第二枪剪，可以同时保近巢并清掉网。这符合已承诺飞行不能改，不能反向取消来救设计。因此“保结风险换近巢”的成本只存在于锁定前，不能写整轮永久代价。应在已有三策略的事件分析中保留此合法组合，不必立即扩一堆完整native。
4. **身体到达后的牵引有真实碰撞风险。** H实际到达后尚有contact停顿，结若向来侧玩家移动，可能先碰/推Player或被Player卡住，移动不足20；kick随后才开始。新CharacterBody必须明确真实collision层/mask和受力时序，不能忽略Player/改其盒子/移动Player来保证阈值。阻挡不到阈值应是合法失败，原继续射击/绕行仍通。

可证伪判据：从同自然前缀，H保结、最强普通单推、普通双剪都比较到**完整预告后的实际Boss hit＋同类宽岸12**，含准备/等待/退款/伤害与节点真实受阻。近/远路线至少要改变一个实际射角、有效输出时间或真实安全/恢复取舍，不能只换目标ID/方向字样。若普通单推同路、同恢复且更便宜，DROP H专有价值；若H只得到一个近巢按钮而无空间进攻选择，REVISE此结构。若H物理拉动让原被干阻挡的普通推需要绕侧，产生可观察成本与选择，才有理由继续。
