## 补核：保原warning末触发的垂直跳不能直接接受

按root提出的更窄变体，先核“不改原起跳触发，只在低台垂直跳”。本次无伤原地跳的实际样本为tick954离地、975顶点、996落地，约42帧空中，实际升高约150.31wu。把这条已记录基础跳曲线只向上平移低台130wu，并保原首次起跳时间：

所以**拒绝把“低台更高且相遇更慢”直接当保原触发即可无伤的可执行保证**。相遇变慢也会使玩家过早落台。此为源/轨迹投影，不是新策略已原生失败，更不排除其他位置或触发。
