## 0. 范围与已确认要求

### 0.1 用户已明确确认的要求（必须执行）

1. 一局按 **S1→S2→S3→S4→S5→S6** 六个阶段，从 16 个候选地区中每层选一个；**S1 固定风铃平原，S6 固定世界钟心**。前五阶段各完成后获得一个核心能力，进入 S6 时获得全部核心能力（能力选择的可行性见第2章）。
2. 核心能力：**钩索 H**、**攀壁/爬墙跳 W**、**二段跳 D**、**武器进化 I（U1）**、**武器进化 II（U2）**。
3. **S2 只拥有 S1 奖励的一个新能力**。S2 的入门、标准、高阶、隐藏挑战都只能要求“该地区对应的一项能力 + 基础跳跃/初始武器反冲的连续灵活应用”；**不允许在 S2 的任何必做或可选路径强制要求第二种后续核心能力**。以后跨局回访属于另一个未来系统，不列为当前 S2 方案。
4. **W 不只是缓降**：可贴墙缓降，可从墙上向外斜上蹬跳、空中修正并重新贴回同一面墙，借此反复向上攀登；也能在左右两墙之间交替蹬跳，爬升很高的竖井。不能将 W 实现为“一次墙跳后本次腾空绝对无法再墙跳”。
5. **凡以 U1 为门槛的场景，所有 Lv.2 武器分支必须具备不同的真实解法**；具体行为、资源及操作演示以[武器文档](weapons_v0.8.md)为准。
6. **S4 允许不同能力解法**：如 `W OR D`、`H OR W`、`任意两种移动能力`。必须构建并验证各自真实可通关的路线/模块，而非用标签声明通关。
7. **S5 三种地区采用各自双移动能力硬锁 + U1 共通要求；第三种移动能力用于高级挑战/隐藏奖励**。不把三种移动能力都作为 S5 主路硬要求。
8. **终极天赋机制暂不设计**。最后一次能力获得应按合法性规则完成；若只剩一个核心能力，不得伪装“三选一”。
9. 游戏主要乐趣是**开火产生反作用力的位移 + 精确平台跳跃 + 大地图随机探索**，战斗、敌人和 Boss 应服务于位移、机关及路线决策；不是把普通武器 DPS 叠数值的战斗游戏。

### 0.2 基线不可破坏

- 当前正式可玩范围：家园 → 两张非线性随机平原地图 → 第一图鸣铃巡游机（Bellstrider）与第二图牧风者 Boss → 开发边界返回家园；其他15地区、五大能力与多武器升级**均非已实现正式内容**。
- 当前平原一段跳、未命中基础两发空中射击；正式射击消耗精力，接受的真实命中回能/返还空中射击资源；移动/跳跃不消耗射击精力。保留这些已有契约，新增武器须声明如何兼容。
- `PlayerMotor` 仍是唯一角色运动求解/碰撞入口；不能用直接修改 `global_position`、第二次 `move_and_slide`、视觉节点平移或动画来决定实际游戏位移。
- 没有改动正式数值的授权时，不修改基础重力/跑速/初跳高度来“修复”新能力关卡；专项新模式与地形外力使用独立可配置策略。
- 现有回血、掉落、商店、Boss 保底金色道具、死亡优先、局内/永久资源、段内回退和确定性 `RunManifest` 必须保留并扩展；本设计的**通关核心能力授予**与**Boss 原有保底金道具**是两个不同权益，不互相挪用。
- 当前正式地区结构是**每地区两张随机连通的大地图**，不是历史八小关正式流程。本文中的“地区通关”指整个地区最后 Boss 胜利并完成权益结算；区域内两张图可以有各自的节奏/小 Boss/大 Boss，不得误改回八个独立小关。

## 1. 核心能力动作契约

能力 ID：`H=grapple`、`W=wall_climb`、`D=double_jump`、`U1=weapon_evolution_1`、`U2=weapon_evolution_2`。这是**建议的持久化 ID**，实现前需核查已有 `wall_slide` 等兼容 ID 和存档迁移，不能静默改 ID 导致旧数据丢失。

| 能力 | 输入与动作 | 空间优势 | 必须避免的漏洞/误解 |
|---|---|---|---|
| **H 钩索** | 以面朝/操作方向横向快速射钩；命中可钩锚点或允许牵引的敌人后，角色被高速拉近，接近瞬间踢中目标、沿移动方向斜上方小跳 | 远距锚点穿梭、借敌位移、衔接反冲 | 不是瞬移；不钩任意背景；钩索发射、飞行、命中、拉近、踢跳与落空有可读状态；不应免费无限刷新射击次数 |
| **W 攀壁/墙跳** | 空中面向可攀附墙时可贴墙缓降；按跳跃键从墙向外上方蹬；离墙后可操作方向回贴**同一面墙**、再次蹬跳，或在**两面墙之间交替**蹬跳 | 极高竖井、同墙连续攀升、狭缝下降、风区暂歇 | 不只缓降；也不是按一次键原地无限上升；每次再次蹬跳必须确实离墙、有效重新接触墙面；危险墙不能变安全墙；贴墙不补空中射击资源 |
| **D 二段跳** | 一次腾空中第二次跳跃；独立跳跃动画与羽翼扇动/散羽/气流特效，方向可控；第二跳高度候选低于第一跳 | 中途纠偏、跨越远台、延长滞空 | 不默认可三段跳；不能省略羽翼表现；能力授予时不凭空恢复已消耗的跳跃资格 |
| **U1 首次武器进化** | 当前基础武器升级到 Lv.2，**必须在两种分支中选其一并锁定**（详见[武器文档](weapons_v0.8.md)） | 攻击行为 + 反作用力运动形态变化；可解 Lv.2 共鸣机关 | 不是单纯伤害/射速加成；不能伪造所有武器相同解法 |
| **U2 二次武器进化** | 已拥有 U1 后，从当前 Lv.2 分支升级到 Lv.3，获得该分支专属主动技能；具体行为详见[武器文档](weapons_v0.8.md) | 高阶主动技与新的动作组合 | 不得绕过 U1 分支选型；不默认解锁所有武器或三种主动技 |

### 1.1 W「无限向上攀」的准确游戏规则

- **允许**：角色从右墙蹬出，向左上方飞，再调整方向回右墙，恢复可蹬墙状态后再次向左上蹬，循环爬升；两侧有墙时同理可左右交替。只要实际墙面几何和安全净空允许，理论上可沿高墙持续向上攀。
- **不允许**：角色没有真正分离墙面，在同一接触状态下每帧重复获得墙跳；靠视觉贴墙而碰撞检测并未接触；利用蹬墙穿过头顶实体碰撞。
- 需要明确 `wall_attach`、`wall_kick`、`detached`、`valid_reattach` 等状态和物理接触判定；短暂离墙禁止重触/反复触发的最小阈值是**待实机试调参数**，不能死锁同墙二次攀登。
- 每次有效再次接触可重置**墙跳动作的就绪资格**，但**不会重置普通空中二段跳、射击弹药或精力**。有效地面落地仍沿既有规则复位。
- 蹬墙产生斜上外推，玩家可以用空中方向、正常武器反冲调整并再贴墙；持续墙面接触的期间可缓降。反冲与墙跳冲突由 Motor 仲裁。
- 有效墙面由独立表面标签决定，冰壁/尖刺壁/移动机械壁必须声明是否可附着；移动墙的速度/碰撞携带不由表现处理。
- **必须提供五类原型验证**：①一面高墙反复蹬跳上升；②双墙宽/窄竖井交替攀升；③贴墙下降到安全台；④墙跳接反冲再贴墙；⑤危险墙、屋顶和过窄墙间不能穿模/重复刷资源。

### 1.2 H 与武器、敌人的关系

- 钩索起手有可视化前摇、极速横向投射、允许命中的锚点表面、接近/踢跳动画和接触判定；横向目标需在允许的高度带内，不写成任意方向免费传送。
- 钩中敌人发生可配置踢击伤害、短暂打断或借力；大 Boss 是否可钩由各 Boss 部位标签独立定义，不默认全 Boss 直接位移到脸上。
- 踢跳的斜上方向参考角色**被牵引的方向和实际接近方向**，避免从左右勾目标都强制向右弹。
- 与射击反冲连续使用时，状态切换必须平滑；取消、目标死亡、锚点消失、碰撞阻挡及资源不足均有明确、可观察的退场路径。

### 1.3 D 表现规范

- 第二次跳跃应有羽翼/羽毛扇动的可辨识 2D 动画，而不是简单添加白色粒子；起跳瞬间羽翼展开→下扑→散羽消失，与运动和音效同一接受事件触发。
- 低画质模式可以降低粒子，但不可删除必要的动作识别信息；上升高度、缓冲、土狼时间、与反冲叠加需按现有 `JumpAbility`/`PlayerMotor` 试验。

## 2. 能力成长、路线与防死局

### 2.1 核心成长流程

1. 一局进入平原时只有基础跳跃和当前基础武器（Lv.1）；开局武器种类按角色或开局选择决定，**具体开局解锁方式待后续确认**，但每局的 `base_weapon_id` 必须确定。
2. **S1 最后一场 Boss 通关后**，提供恰好三个核心能力候选：`H`、`W`、`U1`。取得 `H→森林`、`W→峡谷`、`U1→沼泽`；取得 U1 时立即选择该武器的 Lv.2 A/B 分支。
3. 完成 S2、S3、S4、S5 时，原则上授予五个核心能力中**尚未拥有的一项**，最后进入 S6 全部齐备。**U2 不能在 S2 结束时发放，最早允许在 S3 结束时出现**；U2 还必须已拥有 U1。
4. S2 通关后获得第二项核心能力，才能进入 S3。**进入和游玩 S2 时始终只有刚从平原拿到的一项核心能力**，该地区各层次挑战均禁止依赖第二项。
5. S3、S4 的候选能力与目的地应由合法性搜索生成：候选能力必须有至少一个实际可进入的下一地区，并且之后存在至少一条进入世界钟心的完整合法链。
6. S5 完成后，若按五核心能力必得机制只剩最后一项，应**直接授予最后缺失能力并清晰展示**。不要伪造三选一，也不要在这版引入尚未设计的终极天赋。
7. 局内取得的核心能力随本局持续，死亡后的持久解锁政策属于另一个 Meta 设计议题；当前文档不私自改成永久携带所有能力。

### 2.2 能力锁的三层语义

- **地区入口硬锁**：必须满足才能进入对应地区，与是否看见入口、是否曾在另一局获得过能力无关，只看本局真实能力快照。
- **地区内主路硬锁**：地区既然允许某种条件进入，从入口到 Boss 必须存在该条件下**真实可完成**的主路；S4 的 `OR` 必须至少分别提供对应方案的合法实现。
- **可选隐藏/高阶锁**：只影响支路、特别奖励、隐藏剧情或高难度跳跳乐，不得剥夺本局通关必要道具。S5 第三项移动能力仅用于此层。

### 2.4 地区线路图（候选拓扑）

保留 `docs/world_regions.json` 原29条地区连接，**建议增加6条**，使能力选择不被原拓扑锁死：

1. `windswept_canyon → mushroom_caverns`：峡谷底的背风洞连接地下菌窟。
2. `windswept_canyon → moon_crown_castle`：古风道连到城堡外围。
3. `moonshadow_cemetery → starbridge_gate`：安魂钟可唤起星桥。
4. `frostmirror_glacier → root_sanctuary`：冰下古根连接圣殿。
5. `ember_depths → starbridge_gate`：废弃热流装置通向空中天门。
6. `shattered_isles → root_sanctuary`：悬空古根回接根脉圣殿。

原图其他边不删除。35条边仅是待确认的候选连接；不要在未经设计审查时直接覆盖已经存在的 `world_regions.json` 并发布。

**简化逻辑枚举**：在严格遵守当前能力锁、每关一个尚未拥有的核心能力、U2最早S3后、且 U1 是 U2 前置的条件下，35边候选图共有 **51 种地区序列、221 种（地区序列 × 核心能力获取顺序）组合**。这一计数仅来自离散拓扑/能力布尔枚举，**不证明游戏关卡的真实物理可达、精力可持续或玩法品质**。原29边对应的同一模型是24种地区序列、118种组合。数值是候选内容验算基准，修改边或硬锁后必须重新计算。

**动态选择算法（必须严格实现）**：

```text
on_biome_boss_cleared(run_state):
  settle boss result and guaranteed GOLD entitlement exactly once
  for each unowned core ability:
    reject U2 unless U1 owned and current completed stage >= S3
    if choosing U1: require choosing exactly one legal Lv.2 branch
    hypothetical = apply ability + selected weapon branch
    valid_next_biomes = adjacent_biomes filtered by hard lock(hypothetical)
    keep candidate only if there is at least one next biome AND
        a complete future sequence of legal grants/transitions to S6
  present truthful remaining candidates (possibly 1 or 2; no fake triple choice)
  on confirm: commit ability grant + branch + next region selection atomically
  snapshot ids, receipt, weapon form, unlock graph and route version
  generate next region using the accepted snapshot; do not reroll grant on respawn
```

- 不可见的非法候选不要欺骗玩家；可以在 UI 明确展示锁住的能力或地区，但不能提交非法选项。
- 真正的三选一只保证 **S1**；后续取决于剩余能力和合法性，不得保证“任何时刻都有三个不同可选大能力”。
- 任一路线进入 S5 前都必须拥有 U1；S5 完成后必须能取得 S6 缺失的最后一个核心能力。
- 新增关卡、武器、能力或 RNG 消费者后重新跑所有状态枚举和能力锁测试。

## 3. 16个场景：地形身份、核心机制与挑战配方

**关卡设计准绳**：同样是有钩索，森林强调「主动连续突进」，地穴强调「环境给动量后中途改变轨迹」，沉水遗迹强调「改变地图连接」，星桥强调「跨大空间导航」。同一动作在不同地区承担不同的心理与操作任务，而不是复制同一种机关再换美术。

**挑战配方的等级**：`I`=无伤教学/观察；`C`=主路组合段（必须可通关）；`X`=可选高难/奖励支路。S2 `X` **也只能使用当前地区单能力 + 基础反冲 R**。每个配方先作独立可实测连续模块，待通过后加入随机池；以下是首轮蓝图，不锁死长度、像素、难度。

### S1 风铃平原｜R 与基础跳跃

- **地形**：开阔草坡、断桥、风车桥、缓坡和低钟塔；视觉明快、童话手绘。
- **独特机制**：基础反冲推进/制动、风铃开关、宽安全台、简单移动渡台。
- **I**：「断桥试射」——无害跨度，向后/向下射击学会改变落点。
- **C**：「草坡风车」——跑跳→空中反冲→短时机关平台→稳定落点，体验横向与向上两种反冲。
- **X**：「风铃回廊」——短跳、转身反冲、及时落台的连续动作；仍不需要 H/W/D/U1/U2。
- **Boss侧重点**：躲避/攻击窗口与射击反冲基本功；完成整个平原地区后 S1 三选一。

### S2 荆棘森林｜硬锁 H，仅 H+R 高阶

- **地形**：树干竖井、悬空枝台、交织树冠、移动萤虫与周期荆棘。
- **独特机制**：可钩敌人/锚点、钩索拉近与踢跳，连续目标选择。
- **I**：「第一株铃藤」——安全地面上的静态横向锚点，牵引→踢跳→宽枝台。
- **C**：「树冠接力」——基础跳跃→钩虫踢跳→朝斜下方开枪调整位置→落到上层枝台。
- **X**：「飞叶三连」——仅用 H 和 R 完成移动锚点三次接力；可使用基础跳跃但**绝不能强制二段跳/墙跳/Lv.2 武器**。
- **Boss侧重点**：借可钩的小型召唤物改变位置，而非站立换血。

### S2 萤雾沼泽｜硬锁 U1，仅 U1+其反冲高阶

- **地形**：沉降泥台、浮叶、浅滩水道、钟核和局部涨退水路。
- **独特机制**：双生水钟，共鸣激活改变桥面/水位；六种 Lv.2 分支有各自可操作的解法（见[武器文档·双生水钟六分支解法](weapons_v0.8.md)）。
- **I**：「单钟回响」——安全平台体验所属 Lv.2 武器的独特攻击形态。
- **C**：「双生水钟」——用当前进化分支在受限窗口完成两钟共鸣，并运用其反向位移过河。
- **X**：「雾潮三响」——连续机关+短落点+武器位移，**任何已选 Lv.2 分支仅凭 U1 和基础跳跃都能完成**。
- **Boss侧重点**：战斗中需要操作水钟改变站位，不依赖 H/W/D。

### S2 风蚀峡谷｜硬锁 W，仅 W+R 高阶

- **地形**：一面极高的可攀附岩壁、左右对峙的岩壁、短石台、横风区和背风凹槽。
- **独特机制**：**同墙连续再贴再跳**、双墙左右交替攀升、风场改变出墙/回贴轨迹。
- **I**：「单墙回攀」——向外蹬→空中回方向→贴回同一面墙→再蹬，至少实现两次合法循环而非一次性蹬墙。
- **C**：「双壁风井」——两侧墙连续交替上升，中间结合基础向下/斜下开枪反冲改变高度和位置。
- **X**：「百仞回风」——很高的单墙与断续双墙结合，玩家用 W+R 连续攀升、缓降、制动；**不需要钩索或二段跳**。
- **Boss侧重点**：墙面是躲避与反击的主要空间；进攻时以基础武器反冲辅助攀登。

### S3 蕈灯地穴｜硬锁 H

- **地形**：地下回折洞室、孢子上升井、不同弹性蘑菇、发光悬锚。
- **独特机制**：蘑菇给出外来初速度，玩家在弹起过程用钩索修改轨迹。
- **I**：「第一朵弹伞」——弹跳之后钩住固定蘑菇锚点。
- **C**：「回声菌井」——弹起→钩索→踢跳→反冲→安全落台。
- **X**：「逆向孢流」——若已持 D 或 W，加入二跳修正或墙面安全点；**主路仍仅需 H**。

### S3 月冠古堡｜硬锁 U1

- **地形**：摆动吊灯厅、多层城墙阳台、可反射月镜、临时桥门。
- **独特机制**：运动中瞄准移动目标、利用进化武器改变机关相位。
- **I**：「钟镜庭院」——独立安全区操作所属 Lv.2 攻击模式。
- **C**：「吊灯错拍」——乘摆动吊灯、反冲保持位置、击中移动月钟以开桥；六分支都有合法动作序列。
- **X**：「王座侧廊」——如果已拥有 H 或 D，可进入额外高台回廊；**主路仅需 U1**。

### S3 沉水遗迹｜硬锁 H+U1

- **地形**：多层方形环路、水位蓄池、升降柱、随水位移动的可钩锚点。
- **独特机制**：武器操作水闸切换水位 → 地图端口连通性改变 → 钩索进入原本不可达层。
- **I**：「一层水闸」——在安全平台切换水位，观察路径变化。
- **C**：「上升之钟」——先武器启钟→水位升起→钩住移动锚点→斜上踢跳进入第二层。
- **X**：「深层回环」——若已拥有额外 W/D，可进入可选深井/上层密室；主路仍 H+U1。
- **明确不做**：本版不附带复杂水下游泳能力。

### S3 齿轮工城｜硬锁 W+D

- **地形**：活塞夹壁、齿轮竖井、双侧移动墙、危险齿轮与机械接力台。
- **独特机制**：墙面实际移动 + 攀壁重附着 + 空中二段修正。
- **I**：「维修双壁」——用 W 往复墙跳，以 D 修正一次偏差。
- **C**：「活塞心室」——贴随动墙→蹬跳→二段跳越齿→武器反冲落入下一安全台。
- **X**：「工城内齿」——额外 H/U1 仅开启可选捷径，不改变 W+D 主路要求。

### S4 月影墓园｜硬锁 U1

- **地形**：钟亭、雾墓道、虚影桥、循环墓室。
- **独特机制**：武器击钟在有限窗口切换平台虚实状态，控制何时能够承重。
- **I**：「安魂钟」——明示虚平台切换周期及实体承重预警。
- **C**：「两界跳台」——射击改变一组桥的实体状态，在弹体/反冲与跳跃中完成跨越。
- **X**：「无声墓道」——依据额外 H/W/D 创建多种合法支路，但主路只需 U1。

### S4 霜镜冰川｜硬锁 W OR D（双解法）

- **地形**：低摩擦冰坡、限时碎冰、冰瀑侧壁、稳定石岸。
- **独特机制**：水平惯性与低摩擦导致的制动难题；武器反冲成为重要的修正手段。
- **I**：「冰面刹车」——观察惯性，学习基础反冲制动。
- **C-W**：「冰壁制动线」——W 贴墙消除危险下落并选择回登；不要求 D。
- **C-D**：「碎冰越步线」——D 在空中修正与跨越薄冰；不要求 W。
- **X**：「霜镜深渊」——W+D 同时拥有时出现额外纵深奖励路线。
- **验证**：`only W` 与 `only D` 两种能力快照下均存在独立完整主路线并能到 Boss。

### S4 熔火腹地｜硬锁 H OR W（双解法）

- **地形**：热流竖井、周期喷发口、会热胀变化的金属桥、玄武岩壁。
- **独特机制**：危险环境也提供向上的位移能量，玩家须在安全时机转向/退出气流。
- **I**：「热潮时刻」——预告喷发→观察上升推力→到稳定台。
- **C-H**：「火舌吊环」——热流抛起后 H 钩锚点移出危险中心。
- **C-W**：「冷却裂壁」——热流抛起后 W 贴侧墙控制高度，再蹬离炉口。
- **X**：「熔炉穹顶」——同时有 H+W 时的连续贴壁和钩索穿越。
- **验证**：`only H` 与 `only W` 都能凭基础武器通关；不以二段跳或 U1 作为暗中必要条件。

### S4 破碎浮岛｜硬锁三移动能力任意两项

- **地形**：长距离悬空岛链、云海、断桥、岛侧壁、可钩飘浮锚点。
- **独特机制**：长时间处于空中，使用双能力连续交接，感受高落差和动态目标选择。
- **I**：「云间断桥」——讲解高落差后的回收台与安全重试。
- **C-HD**：「空中锚跳」——二段跳延时接触 H 锚点。
- **C-HW**：「岛缘折返」——沿侧壁 W 缓降并借 H 跨向远岛。
- **C-WD**：「双塔升阶」——岛侧高塔 W+D 攀升再用基础反冲跨隙。
- **X**：「失落天空花园」——**仅 H+W+D 三移动能力**可进入高级连锁挑战。
- **验证**：三个不同的二能力入场组合必须各有合法主路，且各自值得玩，不能只改门标签。

### S5 根脉圣殿｜硬锁 H+W+U1，D 是高阶

- **地形**：动态生长的根道、立体回环、嵌入树心的钟核。
- **独特机制**：H 在不同根系间牵引，W 沿根壁回攀，U1 改变根桥开合以重构路线。
- **I**：「树根环门」——明确展示根桥改变连通关系。
- **C**：「双根回游」——H 钩→W 贴根壁→蹬墙→U1 激活回环桥。
- **X**：「圣殿心脉」——加入 D 的完整三移动能力连锁，用于额外奖励/隐藏叙事。

### S5 逆时钟塔｜硬锁 W+D+U1，H 是高阶

- **地形**：旋转钟轮、活塞垂直墙、周期摆锤和可短暂制动的机关。
- **独特机制**：W+D 连续竖井攀登，同时利用 U1 调整局部相位。
- **I**：「停摆的秒针」——读清平台周期/停止窗口。
- **C**：「逆行摆轮」——抓住安全相位，墙跳→二段跳→射击钟核→回贴墙面。
- **X**：「钟塔顶缘」——额外 H 用来钩住运动中的摆锤锚点，形成极限连锁。
- **明确不做**：本版不附带真正全局时间倒流/世界快照逆转。

### S5 星桥天门｜硬锁 H+D+U1，W 是高阶

- **地形**：星环、光桥、长斜空谷、定向光流、高空遗迹塔。
- **独特机制**：H+D 进行很长距离的空中导航，U1 激活/保持局部光桥。
- **I**：「第一座光环」——光桥显示时机与悬空锚点。
- **C**：「星辉折线」——二段跳→H 横向抓锚→踢跳→U1 激活桥并反冲落台。
- **X**：「天顶背壁」——追加 W 贴浮塔外壁制动和再起跳，形成立体回环。

### S6 世界钟心｜全部 H+W+D+U1+U2

- **地形**：根脉/机械/虚实/光桥主题交替出现的钟心外围与固定核心 Boss 战场。
- **独特机制**：**本局已学到的**动作和区域机关分段重组；全能力运用不是把所有危险同时打开。
- **I**：「钟心校准」——逐项提醒 H/W/D 与当前 Lv.3 分支主动技能的基础用法。
- **C**：「四象回廊」——墙攀→双跳→钩索→武器反冲，并结合两类已见机关；根据已完成场景替换未见的特殊机制或重新教学。
- **X**：「失序终脉」——完整三移动+三级武器技能的高难连锁挑战；不强制所有玩家完成才可打最终 Boss。
- **Boss**：利用真实 H/W/D/U1/U2 技能对抗明确预警的多阶段位移型 Boss；每个 Lv.3 分支必须有合法进攻/躲避方案。

## 4. 随机大地图生成与能力锁契约

### 4.1 生成分层

遵循现有生成方案：

1. **宏观图**：入口、Boss 路径、环路、捷径、深层奖励、回程、替代入口、地标与安全恢复区。
2. **区域节奏**：观察/教学、探索、平台连续挑战、机关/敌人干扰、缓冲、奖励与 Boss 前整备。
3. **动作模块**：有限、完整的挑战片段与其端口；每个模块有入口速度、方向、落点、资源、相位和能力约束。
4. **内容与经济**：敌人、藏品、音符/金币、商店、道具和宝箱；风险/路径成本/品质对应。
5. **体验导演**：重复率、节奏、岔路意义、可读性、失败重试、地图尺寸与玩家疲劳控制。

地图仍采用**非线性多环路大地图**，模块拼接不显露内部方格/拼接线。模块大小允许微型平台、短节奏段、整套连续挑战各异，不强制规则网格化。

### 4.2 模块建议数据形态（示意，非已实现字段）

对 `OR` 条件、三选二组合要有实际分支模版/兼容路径和测试，并分别计算无损主路与资源不足/边界路径。只是图论连通不等于玩家可达。

### 4.3 物理与资源证明

- 必须使用**真实 PlayerMotor/Controller + 当前实际 WeaponBehavior**回放，不可只依靠碰撞盒空几何估算或假设初始枪等效所有武器。
- 各入场合法能力组合、六种 Lv.2 分支、三种基础武器（详细定义见[武器文档](weapons_v0.8.md)）都应按地区门槛测试其确实可到安全 Boss 门；武器 Lv.3 是否拥有是当前构筑变量，不得假设所有 S4/S5 玩家必有三级。
- 允许更强的武器或能力开辟额外捷径，但**主路**不能依赖未取得的额外跳跃、未保证的金道具、耗血穿过危险地带或敌人随机出现后恰好命中回能。
- S2 各挑战明确配置 `forbidden_hidden_requirements`，机器测试应包括缺少其他全部能力的正向可达轨迹和缺失本层唯一能力的反例。
- 只给可选高阶区域放置高级奖励，且主路资源仍足够合理；深层奖励路需要可回程与不困死验证。
- 不要用候选模块数量、Seed hash 数量或几何连通取代真正的动作差异和玩家体验验证。

### 4.4 Manifest / 奖励与幂等

新增长期规则版本字段建议：`core_ability_catalog_version`、`weapon_family_version`、`weapon_branch_id`、`weapon_tier`、`ability_unlock_offer_id`、`ability_grant_receipt`、`capability_snapshot`、`region_gate_version`、`region_route_graph_version`、`branch_compatibility_version`。与旧字段兼容，能力授予/撤销必须重算真实状态。

通关 → Boss 原有金奖权益结算 → 核心能力合法候选 → 确认选择 → 原子提交能力/武器分支/下一地区 → 用新快照生成地图。同帧死亡优先、旧 epoch/过期奖励不能发能力、段内回退不能重复刷技能或更换已确定路线。成功结算后再加载下一地区，不可把能力授予藏在随机道具池。

### 5.1 地区侧必须自动验证的规则

1. `S2_entry_core_count == 1`；S2 的 I/C/X 路线全部满足 `requires ⊆ {S1_award, base_jump, base_recoil}`，不能隐藏要求第二个核心能力。
2. 同墙 W 在真实有效分离并重新接触后可连续多次攀高；双墙交替可持续爬升；接触墙壁不恢复普通 D/射击次数/精力。
3. U2 必须依赖 U1 且不得在 S2 通关后提供；每次能力候选必须存在后续完整合法路线；S6 入场五项齐备。
4. S4 冰川 `only W`、`only D`，熔火 `only H`、`only W`，浮岛 `H+W`、`H+D`、`W+D`，分别用真实物理证明完整主路；若某能力组合不符合该阶段的合法历史，仍在专门测试环境验证其几何解法。
5. S5 三个地区在各自 `双移动能力+U1` 条件下可完整过 Boss；第三移动能力只开启额外挑战，不准暗中成为主路前置。
6. 所有地图须完成不同武器轨迹／资源测试，且不能依赖未保证命中回能、随机必出道具、损血强闯、被卡死的回程。
7. 固定 Seed／内容版本／选择可复现；提供失败反例、回退与旧存档兼容；真实手感、美术、真机验收未做则标 `unverified`。

### 5.2 Codex 首轮任务（地区侧，可直接复制）

> 读取本《能力锁与16场景关卡设计规范 V0.3》及同目录《武器系统与升级天赋树设计 V0.3》，以最新开发分支和 `AGENTS.md`/`docs/current_state.md` 为事实基线。先执行 G0：梳理 H/W/D、U1/U2 授予接口、16场景硬锁／软锁、六条候选连边以及全局可达枚举，输出契约差异清单与任务 DAG。**暂不批量生成16个场景。** 下一个实现纵切首先验证 W 单墙离开／返回／再次攀升、双墙连续攀高与 R 反冲衔接。平原、S2 关卡不可偷偷要求未来能力。任何候选数值、素材、机关玩法须在可玩黄金样板后再冻结。按现有 Skills 和质量门槛留存失败记录与独立审查。

## 7. 验收精神

**标签可达 ≠ 真实物理可达 ≠ 有趣 ≠ 美术达标。** 一个场景必须使玩家使用不同的空间思维与动作策略，而不是仅换背景、怪物数值和陷阱颜色。S2 单能力和基础反冲就应具有深度；S3 双能力；S4 OR 的不同解法；S5 指定双能力硬锁＋第三能力高阶；S6 全能力汇总。任何未实测的趣味性和设备体验都不得标成 `passed`。
