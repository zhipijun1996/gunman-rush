## 诊断和实际取舍

旧 v11 明确保留普通下层前进通路，图 2 的快速路线直接选择 `grotto_eastward → undergrowth_to_old_root`。宽根盘还让玩家用极少普通跳跃横穿长距离。单纯再加高台或可选空中模块，无法纠正主路的能力密度。

探索过三种方向：继续扩大横向枝台；三个连续上升树腹；保留上升主干、加入横向窄荆棘和可以停留的侧向分流。第二种真实可走，但独立审查读取三条轨迹后发现三个上升短语均为 159 帧、相同相对事件，要求返工。最终保留第一次学习与上层复用，替换中段为已有真实物理基础的侧钩＋反冲荆棘口。没有把改 ID、镜像或动作计数当作新体验。

当前主干有七个连续空中短语：HHRH、RH、窄荆棘 HR、RH、HRHH、HHRH、按种子选择 HH/RH。进入观察岸后才重新起跳，中间动作必须在真实空气状态完成。主干从根部到旧树入口上升 1528 世界像素；这是实际坐标差，不能冒称相对旧版增加了 1528 像素。

根部另有两条真实空间路径：右侧铜环连续飞行，或左侧绿色停留环观察后再钩中段。两者汇入同一宽枝台；后者以时间换稳定观察，不赠送弹药。不同种子的全区探索多样性、真人学习难度与商业品质仍需单独评审。

## 深根地恢复的动作事实

深恢复地在世界 y=2000，正常站立中心 y=1982，没有普通向上梯子。三处绿色挂环都有实际宿主和可见藤系；挂环本身不改变玩家身体、弹药或基础动作参数。

`root_retry02` 记录：466 帧挂低环，502 帧挂中环，534 帧挂枝台下方出口环，每处真实停留 12 帧；546 帧实际向下开枪，555 帧身体从 y=1418.566 上升到 1264.566，581 帧在原入口 `(-1695.038, 1279.924)` 满足连续 12 帧全身支撑。钩头始终没有穿过木头；最后一枪让身体从下方穿过正式已有的单向枝台。这是两种真实动作不同碰撞语义的组合，没有修改 one-way 标志让恢复成立。

本轮还修正上层环与某些旧 Seed 的奖励枝台重叠：固定区域派生把最后一环放到该枝台下方，派生坐标由生成源码常量和严格读者共同读取。完整种子回归尚须覆盖实际邻接物，而不能仅根据该局部计算签通过。

## 证据边界

本包包含命令包装器原来源清单和原 JSON／日志；不包含每个历史脏工作区的完整源码副本。源清单只能绑定其记录的 SHA，不能冒充完整历史二进制可重建归档。最初 `spiral01` 的定义边界错误仅存在于会话控制台，没有伪造对应原始日志文件。

正常速度视频、真实镜头可读性、当前最终来源的全部路线和平台测试，必须由后续最终采证单独提供。此前原件不代签这些结果，也不代签人类手感、设备体验或“好玩”。
