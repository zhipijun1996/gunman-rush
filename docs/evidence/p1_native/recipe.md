# P1 原生制作范例（候选，不是定稿）

入口：`python3 tools/level_design.py route --request "改善平原美术" --output build/p1_next.json`。这是原Harness的生产计划；宿主仍要实际调用图像工具、接入、采集和独审，不能把route当执行完成。`preparation.visual_recipe`绑定当前P1源与SHA，不再默认加载已被用户拒绝的B绘画母版或把旧艺术准入继承给P1。

1. 读当前P1板/整屏提案、catalog、质量卡及首原生独审。先确定完整游戏镜头中主体与环境的明暗关系；40world角色在当前zoom1.25约50screen，源图大尺寸的精细线并不自动保留。
2. 原图保留大顶面→根肩→安静深土的完整绘画。沿真实顶边有限弧长采样；左右转面独立原画与实测outer_profile连接。最长809.44world岸本次只用源60..1193.22，未重复或全片压缩。新空间须重新计算有限源与接头需求，不复制本空间坐标或把无底面源用于薄浮台。
3. 实测PNG尺寸、alpha主体、站面、脚点/枪口，不相信提示中要求的尺寸或等格。多姿态矩形交叠会带入邻物；不以阈值剪像素救源。原hero有hurt/death邻物污染，原候选与回退记录留在revisions/first_01。
4. 以实际Godot角色、敌、锯和功能HUD校准草海/远架层深。首实片证明P1整体关系可进入引擎，但主体碎且中景草抢；下一轮实际重画主体大明暗、减少小线与细齿，再校准中景独立scale/anchor/opacity。不能给整屏滤镜冒充画法。
5. 同条件真实路线录像和整屏复查；来源、消费者、物理/输入、独立艺术判断、用户/设备认可分列。首黄金未准入不扩第二结构或Seed。另一地区继承画法/支撑连接与注意力关系，重画区域生态与材料，不强行共用平原贴图。

实际作品与最新结论见本目录最终交付报告；首失败独审`independent-first-01.md`保留。历史PR77范例仅按需提供技术恢复依据，未获用户认可的画风不成为强制权威。原图/派生记录在`assets/visual_development/p1_native/`；未知model、token/价格、商用许可保持unknown。
