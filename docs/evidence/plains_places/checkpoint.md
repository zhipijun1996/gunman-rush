# PLAINS-PLACES-01：候选制作检查点

基线 PR82 `4a4b3fd7d3ce8ae1ca0808ecb725935d0dd50e45`，独立分支 `feature/plains-place-grammar`；森林写集为空。用户偏好P1不等于最终艺术准入。

本轮假设：完整共同绘制的顶—肩—侧—底体块，可通过有限等比尺度与实测接口组成不同场所；不能表达的几何拒绝/重选。场所配方必须拥有玩法、围合、景层与连接合同，Seed实际重排场所。全图共享冷暖/光向、世界地标和视差参考，不逐房铺一张完整图。

预算：先1件完整岸体与1件中景功能源，3个候选原型共用；第一轮实机审查整体及连接，最多2次针对根因的制作返工。首艺术未准入不跑批Seed或扩正式池。阶段检查：源码/失败审计→源画与尺度/连接测量→三个原型正常路线→独审→仅准入后多Seed连接/最差样本。工程阻塞独立处理，不耗尽创作预算。

旧失败原件保持；新完整体块不继承PR82的薄带/alpha拼肩方法。真实Motor/武器/能力/资源/RNG/保存不改；新候选几何显式共同设计并另验。实际源画、源/实机SHA、路线、正常电影、失败与未验范围随检查点追加。
