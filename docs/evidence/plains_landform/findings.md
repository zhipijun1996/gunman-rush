# 实际制作链与根因

本轮从PR87/16e98690的实际美术开发树继续，非旧main。用户最新纠正是：关卡模块必须在生成时知道自己是什么环境构造，不能先产生矩形再要求美术适配。P1只有偏好，未获最终风格认可；森林和核心契约不在写集。

## 已修正的生产层

- **请求与权限**：`tools/level_design.py`旧`art_improvement`把玩法/碰撞请求排除；`visual_director.route`又无区别冻结几何。联合设计实际只能回到旧固定构造上修饰。现在共享`joint_landform_request`判意图，联合请求仅授权精确平原文件；纯调色/换纹理仍冻结碰撞，核心规则变更不因此放行。短指令实际生成了`build/plains_landform/short-prompt.json`，它是原production_loop计划，不是工作已自动完成的证明。
- **模块源**：`PlainsRegionGenerator`先选recipe，调用`PlainsJointRecoilPlan.program_for_recipe`，之后才确定跨度、嵌入和`PlatformingModuleDefinition`。新语言实际包含用途、材质、支承、前层实体、操作空气、后层地层、远景开口、暴露面和资产族接口。下层渡船作为上层岩脊的子程序，在Definition之前绑定；不把两段背景各做一张。
- **实际消费者**：Assembler把6个明确旧slab权属移交4个源多边形，Composer从同一源装完整Mesh、后地层和登记岩拱。原渡船、危险、端口和射击反冲仍用正式消费者；根部必须有真实背接交集，新增体积必须避开原动态机关与操作空气。默认正式Manifest与候选分开。未转换部分明确是legacy remainder。
- **生成可表达性**：真实PNG的画尺、两支座和负形先登记；生成端必须求支座能落在两岸的合法锚点区间，不能先随便造几何再缩图适配。此次是一个可执行家族，不代表所有配方已有环境语言。

## 真实反例揭示的下一层问题

1. 首方法真实8案例能通过，但完整形体仍被四幅材质涂成花墙。`visible_02`和独审01保留RETHINK：**程序前置不自动产生绘画体积**。恢复/物理正确不能签艺术。
2. 第二方法制作并消费一个真正独立的手绘岩拱（不是整屏图），在正常机位2160帧出现拱腹转面与两支座。它使空间有实质改善，但`visible_v6_01`仍REWORK：每条短边争抢整幅材质坐标，724px整幅覆盖薄实体，产生U形折叠与金色假落脚线；测量用的闭合负形又在洞口下方生成不存在的灰墙窗台。**错误在源绘画的实例化及开口拓扑，不能靠更多草/雾修复**。
3. 有界修正保留原PNG与2px/world：岩芯世界坐标；草土肩与侧面分别使用登记有效深度，不透明颜料连续混合；原始岩拱内缘不改，向下开放的地貌出口明确延续至区域后层底界外。实际材质参数必须从ShaderMaterial读回，与源登记核对。最终效果以之后真实影片和独审为准。
4. 新旧岸体接口与整区灰色后墙仍是显式风险。仅一个父子构造不可能证明整张平原已有统一地貌；扩大Seed或把其他旧块都套同样材质会重复此前失败。若最终仍不准入，不能写成美术生产成熟。

## 验证与成本边界

原103项检查中4失败、重复局部变量导入失败、动态ferry空气冲突及StaticBody/AnimatableBody分类错误均有原件；修正实际构造/类型识别，不删物理负例或降低阈值。当前246项专项通过，另24项VD、22项路由测试通过。完整CI/Web、真人、设备与实际听音未执行。旧PR历史只按需读，不要求每个worker加载全史。

本轮6次真实image_gen调用（230.359秒工具墙钟）已到初始预算，源字节、参考、SHA、许可未知状态见provenance。首实机148.883秒，v6实机178.949秒；二者路线4529tick、8案例、13枪、零回退，后者整体transport仍失败，因新子程序来源谓词未覆盖。原failed回执不改，独立新版来源复验与伪父ID拒绝另存。不能把这组耗时直接声称比PR87更快：制作范围不同、尚无艺术准入，也没有对等整区生产成功样本。

## 已固化和未固化

四个现有Skills只改实际顺序与入口，原Harness增加调用已有专项runner的check，不新增导演或质量体系。可固化的是环境源先于Definition、精确联合写集、真实源/消费者、先实机后扩产；当前绘画实例化还不是已验证黄金模板。发布与用户审美不由内部审查代签。

## 最终实机判定：后基质表示法被证伪

冻结源`2c615d3d`真实影片严格通过：4530物理帧、8案例、13枪、零回退，HP最低4最终5，原1310分支库及normal/reflected/no-shot在当前源复跑通过。电影75.583秒、60FPS、4535视频帧；native录制333.353秒，采集编码抽帧共405.819秒。不能将离线固定帧率当设备性能。

[独审03](independent-art-03.md)结论**RETHINK，首黄金未准入，不扩第二空间或Seed07美术**。曲岸U槽减轻、灰窗台消失，但2160帧出现向下贯穿的直边天空槽，1440/3780仍显露水平灰墙与平铺后层；完整岩拱本身可保留，其锐利高亮又与rear_vault身份混淆。没有全片实际播放、听音、真人误跳或设备证据，风险不能写成已证实的人机事故。

本次失败不能再全部归给贴图：环境源虽然在Definition之前，却仍以“区域大矩形后地层减去局部开口”表达世界。它缺少**开敞山谷的外界连通、背后山体的独立轮廓、跨屏剖面与远中近地貌的关系**。把开口延长仅改变错误的切口形状；把整个区域填成岩纹再挖孔的表示法停止继续微调。有限原型接管也让新旧消费者接口成为另一真实阻塞，不是随机Seed不好看。

下一关键实验应替换这层实际数据/消费者，而非新增导演：在一个连续的坡脊—开敞溪谷范围内，先共同画定地表包络、外界空气、有限山体轮廓与连接面，再投影原动作站面。验证“山谷开敞方向与后山轮廓”能在相机经过时保持连续，之后才允许跨模块推广。保留已验证源先行、实际碰撞保护、岩拱登记与严格采集；**本轮没有完成这项替代实验，也没有完成整区黄金**，不得从改进了模块语言推断艺术自动化已经成立。
