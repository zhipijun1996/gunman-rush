# 高奖入口与实际回程接收岸：证据导航

这是 `PLAINS-REWARD-ENTRY-01` 的 G0/G1 内容候选，不是独立审查或玩家认可。完整机器摘要在 [summary](history_and_design/summary.json)，实际源/Hash 在 [source snapshot](sources/source_snapshot.json)，逐文件原始 SHA、压缩 SHA 与原来源位置在 [index](index.json)。

- `preparation/`：原不同代理的实际诊断、两个失败和15组真实物理查询；未覆盖。
- `history_original_kill/`：早期不完整 capture 协议的原故障，不补字段冒充当前验证通过。
- `golden_before_default/`、`sources/golden_source.tar.gz`：首轮A隔离项目的同字节正式黄金，先实跑后默认；错误工具链启动也保留。
- `history_and_design/intermediate_a_source.tar.gz`、`actual_behavior_failure_a/`：A完整源与新增charger回程反例；A的原通过并不证明全部回程成立。
- `golden_b_before_default/`、`sources/golden_b_source.tar.gz`：第二候选B在完整正式场景的两策略及最差回程黄金。
- `current_encounter/`：最终B的11条完整正常出生路线、3个实际物理反例、22个数据因果反例，以及未删除的原14/回退资源/旧新四对/Bait。每条完整路线真实经过两模块、原生modal交易、异路回程和营地。
- `current_spatial/`、`current_experience/`、`current_old64/`、`actual_checks_b/`：最终B重新执行的20图/350语义、18格输入/255断言、原64/3105断言及原15套/协议。`actual_checks_a/` 与 `intermediate_a_*` 是旧A原件，不能换Hash计为B。
- `b_return_smoke_incomplete_fixture/`：首次回程反例漏设brain巡逻中心，实际unexpected-pass；保留其真实结果与源，不算负例通过。`b_return_physical_negative/` 和最终专项中的回程负例才完整配置原敌位，领箱后真实身体接触失败。
- `formal_paired_a/`、`formal_final_after_b/`、`final_comparison/`：当前完整观察器恢复旧生成器的真实失败，与最终B相同策略/能力对照。原始raw没有改路径/源字段。
- `actual_behavior_final_b/`、`history_and_design/return_actual_before_after.json`：sentry/charger额外正式路线。瞄lane的弹体先命中近guard、再lane，真实目标分别记录；不把误打近guard解释为精准瞄准已证。
- `intermediate_b_21/` 与 `history_and_design/first_b_source.tar.gz`：完整21版原件；`history_and_design/declared_guard_drill.json` 记录同一真实kill轨迹的旧/新删证对照。最终22版只改验收器，未改GD或内容。
- `rendered_failure/`：A中间源的正式1280×720、60FPS、双声道48k录像，在教程316 tick停，尚未到高奖。其来源在A归档中；不冒称B目标录像或美术验收。

当前源归档含689个实际运行/验证文件，核心133项与任务起点逐字节一致。图像/声音等484个共享资产逐项按Git blob核验，与 frozen_v9 manifest一致；完整旧源及资产依据沿用 `docs/evidence/plains_redesign/frozen_v9/manifest.json`。committed base30f只是基线，候选字节由归档与实际调用前后来源绑定。

可以在当前项目直接执行：

```sh
python3 tools/run_plains_encounter_policy_tests.py
python3 tools/run_plains_region_tests.py
python3 tools/run_plains_redesign_spatial_tests.py
python3 tools/run_plains_experience_golden_tests.py
python3 tools/run_plains_redesign_golden_tests.py
```

如需恢复某次原始证据到 ignored `build/`，按index的`source`相对项目路径创建目录；`compression=gzip`的便携文件先解压，再核`source_sha256`。仅写`build/`，已有同名文件必须Hash一致，禁止覆盖不同原件。JSON内绝对路径是实际生产环境路径，不应修改raw去冒充另一次调用；异机重放应以归档建立独立项目、恢复原相对产物位置、使用归档观察器与对应资产重新执行。源归档/实际脚本在 `history_and_design/` 可复现隔离黄金和生成100图对照。
