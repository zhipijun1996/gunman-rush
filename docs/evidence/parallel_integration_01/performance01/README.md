## Repair boundary

Only pure POSIX lexical work changes: compare path component prefixes instead of repeatedly constructing relative paths for every ancestor; derive the already-normalized relative name once from its components. Existing `abspath` normalization stays at the same `require` step. Symlink checks, stat/open/read checks, Git ownership, sparse handling, real media decoding, invocation/check assertions and the **60s budget** remain. No filesystem state or preflight result is cached; existing per-invocation lexical dictionaries remain local. No runner, sharding or retry change is introduced.

Final production file SHA: `6e113ff1f26cd6287680daeba196ace28c5eccb0277347c9e09096282cbb1214`. `paired.json` binds this file. `inventory.json` records exact archived bytes; it excludes itself. Original raw profiles are retained alongside readable summaries; temporary unit-fixture directories and caches are excluded. Independent review and fresh full CI are separate evidence.
