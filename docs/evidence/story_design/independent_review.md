# 独立剧情一致性审查

结论：**ACCEPT（仅设计一致性）**。

审查对象：`docs/design/story/README.md`、`story_bible.md`、`region_narratives.md`、`narrative_delivery.md`；对照 `docs/design/player_actions/regions_v0.3.md` 与 `docs/home_and_save.md`。只读审查，未修改生产文档，未参与本轮素材生成。

本结论允许这套文档作为 V0.1 候选提案进入用户评审，不代表故事已定案、正式消费者已实现、所有路线真实可达，亦不签署玩家感受、操作手感、设备适配、美术或存档实测通过。

## 未发现阻塞项

1. **主线因果闭合**：君主失去伴侣 → 留日工程由临时实验升级为永久命令 → 地方节律失联 → 师父人工支撑并送走学徒 → 学徒寻找师父 → 解除控制、完成告别。时间并非宇宙静止，因此局部生长、人物活动和损耗不构成直接矛盾。
2. **首次任一路线的必要证据有设计保底**：呈现文档第4节要求 S3 四区等效交付留日动机，S4 四区交付师父状态疑问，S5 三区明确肉身无法带回、维修原理与恢复后的变化；第6节保证安全必经槽与钟心前三图兜底。不依赖古堡、可选居民、死亡次数、回家次数或刷齐16区。此处验证的是覆盖契约，尚非逐房间正式脚本或实际路线证明。
3. **能力规则相容**：16区门槛与 V0.3 矩阵一致；S2 支线仍只用本层唯一能力；S4 OR 与三组双移动解法均被要求覆盖共同情报；S5 第三移动能力不藏独占主线。居民不给永久核心能力，终局未见过的机关必须重教或替换。
4. **失败与永久状态边界相容**：零血结束本局，回程仅解释活人救回，不让亡者复活；救援需合法提交并以稳定 ID 去重，死亡终态之后晚回调取消，永久结果与收据原子保存，不挪用 Boss 或经济权益。
5. **结局与重复游玩相容**：首通真实修复；后续为局部余响，家园保留结果；重战钟心明确为记录回响，师父不重复告别，居民不反复被抓。首通后信标独立运行已在呈现文档第9节明确，避免导师消散导致回程失效。

## 非阻塞的定稿提醒

- **S5 的实际证物尚待写成文本**：区域文档目前主要写地方历史和修复原理，师父肉身、回程设施独立运行等信息由呈现文档的统一契约补足。进入关卡制作前，应为根脉/钟塔/星桥各写一份可直接投放的短证物，避免制作者只读取单区条目而漏掉必要信息；目前跨文档并不矛盾。
- **重复解除同一地区 Boss 的解释可再压实一句**：既有文档说明故障装置与余响可反复出现，但未逐个定义已修复 Boss 下局为何再次失控。未来宜统一为“解除当次接线故障，不代表中央锁时已解除”，首通后则采用局部故障或历史回响变体。这属于演出精度问题，不影响当前全知故事闭合。
- **墓园的亡者应保持回响口径**：区域中“逝者不能远行”“亡者保留生活习惯”适合童话，但制作时宜明确为残留回响，避免误画成可以由回程线救活的肉身居民。这是防误读建议，当前没有直接承诺复活亡者。

没有提出要求用户先行补充信息的阻塞项；上述提醒可随剧情定稿与正式接入补齐。
