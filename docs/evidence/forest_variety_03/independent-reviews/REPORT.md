Existing verified phrase factories can serve as transport inside these modules. Every new branch must have a distinct player judgement (downward side-catch; reverse behind a trunk; high/low window with different exit; moving target opportunity with fixed fallback; recoil across a thorn shoulder), actual reward at a separate receiver, and a recovery/return that changes where the player goes. If ports fail clearance or require a tall ladder, reject that arrangement, choose a compatible module or design a proper sideways/downward challenge. Preserve whole-body/shot/fruit-ray clearance. 7. Validate one new branch in a real whole-map context first, including cheap alternative and return; inspect normal-scale actual GPU frames before more seeds. Then sample multiple fixed seeds and compare actual geometry and adjacency (not only manifests' hashes) and run both first-map ordinary, old optional skill, and reward-return strategies.
