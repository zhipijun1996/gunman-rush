# Round10 第二轮实际画面独审

结论：**ART_REWORK**。第二轮全部14张 1280×720 实际 PNG 已逐张查看，包括两张地图各自 arrival、rest、双窗 entry/crown/inner_root、L cache/lower_rejoin。原件路径、SHA、staged scope 逐张记录在 `review.json`。不是用源码尺寸推断画面，也不是用 manifest 不同推断地图视觉不同。

## 比 round09 确实改善的地方

双窗 entry 上方原封住画面的实心巨背体已露出森林背景，现在是顶缘约 y248..324 的横梁接左柱；下方接岸也明显变薄。约 x495、y639 的下窗果实和底部箱子能看见，不再被大岸体埋住。crown 右上方的封屏方块变成边框形体，视野更开放。inner_root 中央实心横块变薄，箱子上方的果实可读。减量是实际可见改善。

## 仍不应发布的原因

| 取景，两 map 均检查 | 实际观察 |
| --- | --- |
| 双窗 entry | 顶部仍是大号直角 L 梁，下面同色直角 T 梁；长横向表缘和平直竖柱组成的符号感强。接岸变薄使下方可读，没有解决整体不像树腹/缠根的轮廓问题。 |
| 双窗 crown | 约 x702..842 的竖直柱、y300 左右的长上梁、约 y530 的长下梁，仍与左侧孤立矩形块拼成几何线路图。真实站唇/接收关系可保留，不能将“剪薄后能看见背景”算自然平台美术完成。 |
| 双窗 inner_root | y237、479、635 附近仍有多层长水平带，中央 T 竖体与孤立薄枝的关系生硬。果实位置更清楚，但横带仍是主要画面节奏。 |
| L cache | L 形折臂、荆棘宿主与留白清楚，优于原重复梯。下方三片同高矩形台与底部长 catch 未变；领奖肩和上方折臂的视觉连续性仍弱。 |
| L lower_rejoin | 单片宽恢复面有功能，不等于重复梯。但它几乎横穿整屏，画面仍像大底板；不宜靠继续剪厚或改色把它当新母版。 |
| arrival / rest | 保持旧入口的果实和根桥关系，新 rest 是一片明确休整面。英文提示依旧压在人物下方附近表缘，不作为阻断旧版试玩的理由，但不利于正式画面的信息层次。 |

本组 map1/2 对应取景仍没有显著不同的模块构图，不能据此主张两地图的身份丰富；也不能外推所有 seed 完全相同。实际共享像素尺寸、背景深度和暖果实/橙人物对比是可保留基础。

本轮不建议第三轮继续换色、剪厚或拉尺寸救同一套直角母版。保留已实际走通的窗口/落脚/恢复意图作为候选，把自然树腹与缠根的前景轮廓留给明确的新美术实现。若之后改变实际实体，原通行证据必须按新几何限定；不能只画虚假支撑，也不应静默删除恢复面。旧 v15 公开试玩与此未完成附林分开，当前不发布附林。

这些静帧只证明取景所见，不证明箱子已领取、L 返回已成功、镜头跟随舒适或玩家认为有趣。玩法独审见单独 round11 报告。
