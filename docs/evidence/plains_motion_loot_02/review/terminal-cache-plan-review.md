# Terminal mesh cache: source plan review

Conditional acceptance of the design, pending concrete source and native625-point/draw evidence. No engine execution or repository edits by reviewer. Formula duplication/prepared-charger code currently in the root working tree is excluded; original deform stays authoritative.

Flora sentry/root_bell dead branches depend onlypoint/uv/size/clampeddeath. Fan returns atd>=1 before death_clock/captured-live work. Its static body pre-fit is also pose-independent. The outer dead floor clamp is unconditional atdeath>=1, and the Skin landing offset is zero under the proposed eligibility. These three terminal local meshes are source-independent of running pose clocks.

Ground targets are mathematically constant atdeath1, but Ground still evaluates every live joint/vitality operation then calls p.lerp(target,1). That identity alone does not establish exact float-byte independence. Run the full625 vertex bit matrix across all pose values, particularly air false→true on support loss. If any bit differs, retain original deformation and key the captured Ground inputsclock/stride/travel/load/strike/recovery/hurt/turn/air/vertical/drive/appendage_follow, or initially limit the cache toFlora. death_clock is not a Ground input; body_follow/aim are currently unused there.

Keep the cache per Skin, keyed bykind,fullbounds/geometryversion,texture identity and any still-relevant captured inputs. Private points/UV/topology are currently constructor-only; future mutation must invalidate them. A same-rig visible live/death0/partial/landing draw invalidates the claim that the current_mesh holds terminal vertices. This matters because visual/remains share one rig: a later terminal draw cannot skip upload after another consumer overwrites the mesh. Separate rigs must never share cache state.

Everydraw still performs culling,shader setup,currenttexture/tint/alpha and draw_mesh; transforms and moving/missing support remain owner-driven. Do not cache rendering commands, material values or visibility. Test same-rig alternating consumers, revival/offscreen return/new captured pose, support-loss air change, geometry/texture changes, landing and live transitions, and actual full mesh vertices/draw behavior. A health epoch does not directly affect local geometry, but transitions must invalidate/re-key properly. Theoretical cache correctness is not a native or performance pass; unchanged-route/80-corpus/budget evidence remains root's next work.
