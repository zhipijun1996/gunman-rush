# ITEM-ART-01：实际道具美术证据

当前是首批 **8 个独立图标、P24／P14／G16 三组动画**的开发样板，尚不是 72 件美术完成或用户认可。后续批量生产须先复核菜单、真实两区世界与连续动作。配置架构和原工作表玩法证据分别见 [维护说明](../../item_authoring.md)与[原 V5 证据](../item_v5_01/README.md)。

- 原始生成请求在 [generation](generation/)，实际源 PNG 在 `assets/items/v5/`；源图未改像素，整数采样窗口与动画时间轴在 `config/item_v5_art.json`。原生 64px／等格安全边请求没有全部达成，不能据此宣称源图规格通过。
- [采样与失败链](source-and-sampling/)保留第一张失败布局、实际 alpha／尺寸测量、无美术对照与错误大区域反例。第二张图仅按实测高分母窗口准入，不回写第一次失败。
- [首批原生与菜单](golden-stage/)：美术专项 156／0；正式 DemoMenu 在 1280×720、960×540 渲染与原 UI 功能检查共 183／0。菜单显示库存为显式 fixture，不能证明自然获取；后续仅调整测试的目录扩展守门不沿用这些数量签最新测试。
- [技术绑定](source-bindings/)保留旧 style15／creative18、预美术 style16／creative19 和 R08 影响分析。当前 61 个真实叶子哈希匹配，原 Bible32＋方向10 和四项绑定检查通过；哈希不代表艺术验收。

实际伤害策略成功提交后才播放接收特效；飞轮／巡钟机／裁决波的实体位置与施放事件仍由原效果组件拥有。PNG／图集缓存不持有角色，卸装和生命周期失效会清除对应表现。原 64 短效／8 长效、64MiB 纹理上界不提高。

连续影片与两区合屏尚待采集。未验证：其余 64 个图标、其余可见效果资源、实体安卓／手柄／低端性能、用户审美与完整 G5；音轨存在不等于听感认可。来源授权与工具未披露的模型信息如实保留 unknown。
