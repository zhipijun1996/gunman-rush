# PLAINS-TERRAIN-02 自检（非独立审查）

实现者与检查者为同一 Codex 会话，因此 independent_review=unverified；不能把本报告称为独立 ACCEPT。

从“表现不能改变物理、并集不依赖分块、消费者必须正式启用、材质应跟随承载体”四项不变量推导检查，未仅复述用户关于空中平台的反馈。

- PlainsRegionStage 在完成装配后创建表现，两个正式地图及重复进入经过同一入口；DemoApp 的开发分支只开启比较控件。
- PlainsTerrainStudy 收集实体矩形及支撑，显式排除单向桥。主渲染变化只覆盖旧实体绘制；机关、碰撞、掉落和生成不经过新表现组件。
- 移动平台的 ColorRect 属于其 AnimatableBody2D，纹理使用 shape_pixel；静态地图继续使用世界相位。不新增物理节点，不改平台时钟或 PlayerMotor。
- 既有破桥/恢复及并集/薄缝反例继续运行，补普通入口/两图/重开/长度厚度测试，未删除或放宽旧断言。测试中的第二图推进是生命周期 fixture，不宣称玩家通关。
- 新单行样板实际 GPU 暴露 %g 标签错误，原浏览器脚本只捕捉 Script/Shader/WebGL 导致假通过；原图、原日志和原报告已归档并明确撤回。改为 %s，并将所有引擎 ERROR: 纳入失败；修复后重新构建和拍摄。
- 第一轮新引擎 fixture 立即关闭活动 run 偶发输出退出资源警告；补显式 abandon_run 和帧间清理，验证结果留日志，不能由一次 headless 成功推断设备内存。

剩余边界：此轮没有新 AI 图，没有重制单向木桥；物理单向语义不能被统一石墙素材掩盖。手机 GPU、真实乘台视觉体验、独立审查及原背景底部断界仍须分开跟踪。用户只认可指定合屏美术，不能推定完整关卡趣味、Boss 或设备通过。
