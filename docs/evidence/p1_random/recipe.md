# P1 随机平原与可选人物：实际制作入口

本轮候选沿用 P1 绘画关系，不把单首空间的有限接受外推为全图艺术准入。用户授权正常随机地图和可选少女；没有授权修改能力、核心碰撞或森林。

**当前创作结论：仅把主土地形铺成 P1 已被用户否定。** 第一次正常地图仍混用旧悬台/机关/奖励；覆盖率不是整屏统一性。实际改法见 `unity/before.png → paintover.png` 的同屏关系，再看对应真实落实证据；绘改不是游戏背景。第二轮将浅木维修梁/完整底浮体/厚岩岸分开，让功能器物共享绘画与造物语言；不是再增加土体页。

源码试玩：先用仓库 Godot 导入项目，再执行 `bash tools/godot.sh --path . --script tools/p1_random_preview.gd -- --seed=level-design-v2-baseline/01 --avatar=p1_girl`。这是正常 `DemoApp.start_plains`、原生成器和原相机，手动操作；不是固定黄金三岸或自动驾驶。支持 `courier`、`p1_traveller`、`p1_girl`，游戏内右上角选择外观；仅同一 app 会话保留，不改存档。

新空间首先读取真实地形并集与交互语义。有限绘画截面按源预算分段重用；原连续轮廓能完整覆盖时保留原技术，台阶/孔洞使用实际占用列，源页的横向相位连续。网格必须等于真实实体面积并保留空气，验证失败保留原消费者。采样点恰落作者分块接缝时采用半开区间，与真实 Rect2 占用语义一致；不能把分块接缝当洞。不要以并集包围盒隐藏邻近但不属于并集的旧画面。

地形源、测量与派生见 `resources/visual_development/p1_random_family.json` 和 `assets/visual_development/p1_random/`。新增连接源解决有限截面预算，不按 Seed 生整屏。底面源只在原实体中参与颜色，透明根须不能挖出假天花板。浮台、单向、移动结构保持原语义消费者并逐项披露；没有适用源时不装假土体。

第二轮实际组件入口是 `p1_unity_components.json`、`P1StructureArt` 和 `p1_unity_props.gd`：先量真实图的站面、实体范围与接头，桥的中段和完整端帽/短撑分工；移动表现在原承载体局部坐标里移动。旧箱/射击风铃/音符货币的表现直接接原对象，不能新增装饰冒充交互。图生并未遵守等格，按实际1254px图校准；下裁荆棘/旗帜明确拒用。尚无新源的敌、硬币、心等仍是缺口，不以滤色蒙混。实际 `coverage.structures/props` 对应范围和正常镜头才是效果依据。

人物通过 `resources/art/avatars.json` 与单一 AvatarPresentation 所有者接入，校准先验后换，不合法的矩形或未知 ID 不释放当前外观。少女9姿态不是完整27状态动画；原控制器、枪口、武器与资源仍负责玩法。普通导出不自动纳入实验图，评审包显式纳入候选闭包。

短任务“改善随机平原美术，使用少女候选”先走已有 route 确认当前候选，再用此入口实现和采集。实际录像使用 `tools/p1_random_capture.gd`，由原 formal fast 驱动及严格退出验证；route、planner PASS、源图精美均不能签实机艺术。每次保存同条件截图、覆盖遗漏和真实生成结构；独立看完整画面后再扩 Seed，不用 hash 或不同名称冒充布局变化。
