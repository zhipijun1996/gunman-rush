# Underworld terrain technical golden

Task UNDERWORLD-PLAINS-01. Source-native green family copied from Asouris Underworld, custom permissive publisher statement (not CC0); exact SHA and license evidence in the runtime `terrain_build.json`.

The selected material is a **mixed adapter**: full 32wu cells whose eight neighbours are unambiguously full or empty use an actual 16px TileSet / TileMapLayer and the canonical 47-mask lookup. Partial cells and cells adjacent to partial neighbours use the same native 16px source edge and convex/concave quarter pixels, clipped to canonical union quads. This is not a conversion of all authored geometry into a grid. Physics bodies, collision, RNG and save data are untouched. Equal unions with altered author partitions produce identical GPU images. Concave and convex vertices use symbolic one-sided occupancy, not finite probes. Native alpha can round the visible edge inside the collision rectangle; the test does not equate that with opaque coverage.

239900 geometry checks and 239910 GPU+geometry checks passed over the five fixture outputs. GPU independently compares original vs split/reordered/duplicate-overlap rendering and rejects any visible pixels outside the exact union. `gpu_v1.log` and `gpu_v2.log` are actual runs. All five v2 images have identical byte hashes to the originally independently viewed v1 images, while case4 moves 22 additional unambiguous cells into the real TileMap consumer. Initial unavailable-display and audio fallback logs are retained. Images 0–2 cover thin hole/step/overlap-corner; images 3–4 cover non-grid slab and grid interior. Image4's shape exceeds the viewport at right/bottom, so its picture does not prove offscreen coverage.

This evidence proves bounded static material continuity and deterministic geometry presentation. It does not prove formal route completion, final aesthetics, animation, physical device performance, 16-region production readiness or user approval. The source texture is licensed reference art, not a newly generated original material.
