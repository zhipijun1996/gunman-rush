2026-10-13，分支 `fix/foundry-mobile-menu`，基于 `f721795` / PR56。用户报告右侧乱码、点击后卡住、无法换关。

本地 Web 导出、分块包完整性与缓存策略检查通过。桌面和两种触屏尺寸的 GUI/翻页/回放/暂停恢复继续实际截图复核；浏览器仿真不是 Android 真机验收。公开发布及构建信息见文末实际验证记录。
