# 共享画风继承：原文核对与最少约束

两份原始Bible本来一致。森林§2.1要求“保持精简、可组合的像素地形语言”，改变的是根盘/树洞/枝冠的有机空间轮廓；平原§2.1同样要求简洁像素形体、清楚轮廓和克制纹理。有机轮廓不构成另换画风的授权。

本轮“旧P1/Underworld只供历史”规则把已拒旧候选与仍正式使用的Underworld家族混同，方向错误。当前应继承正式平原16px/32wu、47核心与非整格精确边界适配及同一UnderworldPlayer；森林差异由树皮、苔藓、荆棘、树洞、生态和色域表现。可以扩展地区材料与形状，不需要重建一套组织、渲染框架或全项目美术门。

最少约束是：原Bible不改字节；把最新用户补充和实际正式参考作为追加的共同权威，绑定进所有地区create/optimize及缺Bible的proposed输入；漂移沿原调用/恢复守门；首个正式比例跨区黄金沿原G2独审看真实像素。不能以绑定了正确SHA、保留一个隐藏Underworld节点或通过47态就宣称画风一致，也不应因为森林颜色与根枝轮廓不同而拒绝合法地区变化。普通物理/global动作/文档修复不新增图像门槛。

建议反例和实际参考SHA见 `preliminary.json`。此前平原gap报告沿误规则写出的“活跃Underworld不作新输入、应另行重画”推断由此次纠正覆盖；原件保留，不把这次更正追认成当时判断正确。本文件只审规则与原文一致性，没有签像素、用户审美或实体设备。
