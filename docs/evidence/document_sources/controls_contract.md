# 操作与输入合同

## 意图与配置

TouchAdapter、KeyboardMouseAdapter、GamepadAdapter向InputRouter提交移动、交互、jump／jump_release、瞄准与shoot_release等意图；方向是有限非零世界单位向量。设备提示切换不迁移未完成手势。

配置唯一来自`config/input_profile.json`及InputProfile校验；会话设置改变后重新配置并取消旧输入。瞄准坐标先经当前镜头逆变换，再从实际枪口求方向。

## 触屏

未被UI消费的左右半屏触点建立浮动摇杆，跳跃／菜单先判定。移动、瞄准、跳跃和HOOK各自捕获touch index，拖出控件仍归原手势，释放不影响其他手指。

移动采用当前two_step模式，步行／跑动与回中滞回取InputProfile参数。右杆有效拖动瞄准，正常松手提交一次射击；回中心或系统取消清手势。HOOK拖动瞄准、松手出钩。布局、触点半径和安全区按实际设备验证。

## 键鼠

默认 A/D 或左右键移动，W/S 上下交互，Space 跳跃；鼠标位置经相机变换用于世界瞄准。射击动作默认鼠标左键：按下进入瞄准/武装，移动更新有效方向，释放时提交一次射击请求。只有一次有效按下后产生的释放才可射击；无有效方向、失焦、暂停或取消后的释放均不产生请求。可重映射射击按键，保持释放触发的语义。键鼠不受触屏半径或分辨率限制。

## 手柄

左摇杆移动与上下交互，独立跳跃动作默认南侧面键；右摇杆瞄准，回到死区触发射击。右轴先应用配置的灵敏度/曲线与径向死区，再转换为世界方向。输入档案使用 enter_deadzone、exit_deadzone（0 ≤ exit < enter < 1）、arm_confirm_ticks 和 center_confirm_ticks（正整数），以固定物理 tick 确认状态，避免渲染帧率改变防抖。默认值在实际引入 InputProfile 时建立唯一配置来源，不提前用文档数值替代调参文件。

状态与方向缓存契约：

1. 初始或取消后 WAIT_NEUTRAL：先观察到连续 center_confirm_ticks 的中心状态（幅度 ≤ exit_deadzone），才进入 READY；重连或恢复时已偏移的摇杆不能直接武装。
2. READY：幅度连续 arm_confirm_ticks 达到 enter_deadzone 后进入 ARMED；期间保存最新有效非零方向。小幅噪声与两阈值间游移不能武装。
3. ARMED：有效偏移继续更新 last_valid_direction；中心状态进入 CENTER_PENDING，冻结回中心前的有效方向。中间滞回带不更新有效方向、不触发射击。
4. CENTER_PENDING：连续 center_confirm_ticks 处于中心才提交一次 shoot_release(last_valid_direction)，然后清缓存回 READY。确认过程中离开中心会取消本次确认、返回 ARMED；真正有效的新偏移才更新方向。
5. READY 需再次满足完整武装条件才能再射；保持中心或阈值噪声不能重复射击。任何状态发生手柄断连、失焦、暂停、死亡或系统取消，立即清缓存并回 WAIT_NEUTRAL，不提交射击。

若多个状态转换在同一物理 tick 被采样，只采用本 tick 最终有效轴与已确认状态，不能用瞬时噪声完成武装和回中。输入采样序号与 Router 去重确保一次回中至多一个请求。手柄射击冷却或资源拒绝后也需重新武装，不能中心等待到冷却结束后自动重射。


## 能力与主动操作

PC右键／E、手柄LB按住钩索瞄准，正常松开出钩；取消和切设备不提交。F／手柄X为武器情境操作，Q／Y为武器技能，R／RB为主动道具。触屏按当前可用能力显示对应区域。

枪械与钩索有效空中瞄准共用AirFocus；资源与倍率唯一见 [资源合同](combat_and_recharge.md)。停留钩点可通过合法跳跃脱离，普通目标按TraversalAbility的踢跳政策处理。

## 队列与取消

Router队列最多16项、有效期100ms；超限拒绝新请求。每物理帧消费有效请求，保留jump／jump_release原始顺序，只合并连续同类边沿；射击取最后有效方向，冷却拒绝不延后自动射击。

跳跃持有者跨设备聚合：首个按下产生jump，最后一个正常释放产生jump_release。暂停、失焦、断连、系统取消、映射修改、回退和RunEnd清轴／队列／捕获／缓冲并递增epoch；恢复需新的触摸或重新武装。取消不走普通松手发射路径。

## 面板

标题提供开始游戏与开发入口；家园使用正式InputSetup。暂停打开背包，可切旅途／设置／帮助；地图与局内面板互斥并暂停世界，打开和关闭都保护旧输入。地图观察不揭示未探索区域。

菜单使用真实指针／触屏提交，核实际选中ID、回调次数、关闭及关闭后首个操作。代码和专项见 [模块导航](module_map.md)。
