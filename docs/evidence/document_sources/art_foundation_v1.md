# 美术制作基础

当前画风与全局规格由 [Visual Bible](visual_bible.md) 规定，地区方向与技术参考由 [Bible 注册表](creative_direction/bibles/registry.json) 选择。本页只规定素材进入真实消费者的制作方法。

正式地形原生 32px／32wu，世界表现 1wu 采样、nearest。源图像素、显示尺寸、物理尺寸和碰撞轮廓分别核对。47 邻接与精确矩形并集边界适配是不同职责；当前任意偏移矩形、窄墙和薄台不能为贴图强吸附到网格。dual-grid 仅在实际消费者、边界语义和回归证据齐全时采用。

先完成一件同族代表资产和真实空间用途，再做完整边、角、端头、内部、孔洞及变体。岩体连续有厚度，建筑有根基，植物有宿主。可站边、单向平台、移动机关与危险的材质和方向必须可读。远中近景使用不同对比度和运动关系，避开角色与落点。

素材须保留原图、提示／参考、许可和生成记录；入库前检查 alpha、裁切、锚点、采样及实际导出。先在真实镜头与玩家／敌人／UI／光照合屏，再扩同族资产，并用第二种空间验证复用。画面需有正常速度连续操作和声音，静态图不能代签动态可读性、性能或用户认可。

专业生产从相关 Skill 和 [内容流程](content_pipeline.md) 加载。素材验证不改变玩法 RNG、碰撞、资源和授予规则；需要共同重设计的空间先明确任务写集与验收。
