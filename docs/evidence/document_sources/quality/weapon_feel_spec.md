# 武器运动与操控手感

本页规定分支操控，位移总量、瞬闪停顿与激光推进曲线由 [动作预算](action_budget_spec.md) 统一规定。弹药、AirFocus 和恢复由 [资源合同](../combat_and_recharge.md) 规定，参数取实际 Definition，候选手感不等于用户认可。

- Lv.1 炸弹在已接受释放帧立即爆炸；保留近身爆心、遮挡与范围伤害。爆发的核心、冲击、火星和消散与真实伤害时序一致。
- 手里剑由唯一 Motor 取消旧速度并完整形体扫掠，不能以持续高速运动冒充瞬闪。散华第二段延迟后重新采样当前方向，期间允许移动／改瞄准；Lv.3 普攻沿同分支规则。
- 激光普攻起始清速、有限持续推进、可改方向，释放／耗尽／取消结束后恢复普通运动；推进曲线与总量只按动作预算。三级炮击是独立技能。
- 回旋刃先按发射方向飞行，空中可控刃，无输入保持航向；达射程后有限返航。自动接刃不触发第二反冲；情境召回锁定当时直线，真实扫掠回程且受墙阻，真实接刃后才产生第二段位移。
- 控刃慢时不增加普通瞄准时限，继续消耗共享 AirFocus；接刃、耗尽、落地、钩索、暂停或切装结束该状态，不补射击资源。

验收通过真实 Router → ShootAbility → Runtime → Motor／Entity。比较相同地空条件下的距离、瞬闪碰撞裁剪／清速、炸弹同帧 HP、激光各阶段、二闪改向、回旋射程／速度／墙阻／一次接刃，以及取消后的 epoch。覆盖 30/60/120Hz，正常速度音画、网页输入、独立审查与实体设备分别记录。

动作练习 HUD 不保留会把 Space 跳跃转为重开靶场的按钮焦点；菜单弹层保留原生导航。鼠标点完靶场后跳跃不得产生 practice_reset。
