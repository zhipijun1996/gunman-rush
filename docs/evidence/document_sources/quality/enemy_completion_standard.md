# 怪物完成标准

版本v1，2026-10-28；任务 `ENEMY-COMPLETION-01`。适用于普通怪物的新建、补齐和完成度核对；Boss还需满足[Boss设计卡](../templates/boss_design.md)的阶段与竞技场要求。

本标准把[总门槛](../development_quality.md)、[敌人契约](../enemies_and_bosses.md)和[动画规范](../animation_vfx_standards.md)落实为逐物种出口，继续使用原G0–G5、十一维、[policy.json](policy.json)和[Enemy Design Sheet](../templates/enemy_design.md)，不新增评分或工作流状态。建立标准不代表任何现有怪物通过。

## 完成的对象

每个物种须有完整的「辨认与接近 → 移动与交战 → 预警／攻击／恢复 → 受伤与恢复 → 死亡与退场」体验，并在实际出现的正式场景中成立。留尸物种还需完成落地、持有、支撑和状态恢复。共用组件通过不能代签每个物种或整条动作链。

先登记稳定ID、地区、职责、运动方式、攻击方式、死亡政策、实际能力前提和正式消费者。标准统一交付要求，不统一肢体数、动画帧数、画布或粒子量。新物种说明新增玩家判断；旧怪纯表现补齐引用原机制，不虚构新AI。

## 必需验收项

| ID／归属 | 完成条件 | 证据与失败条件 |
| --- | --- | --- |
| E01 设计／G0 | 身份、战斗职责、学习方式、反制和既有敌人差异明确；说明射击、反冲、跳跃、落点的关系 | 具体遭遇与机制对照。换图、加HP／速度不能冒充新机制；纯表现任务注明复用范围 |
| E02 行为／G1 | 感知、目标获得／丢失、移动、攻击、恢复、死亡遵循Definition；存在可行应对 | 真实输入、Motor、弹体及伤害回执；核距离、视线、安全区、墙／台边、无目标。生成成功不等于可接敌 |
| E03 身体美术／G2 | 活体与动作共用物种身份：轮廓、比例、肢体、材质、光向、功能色一致，符合已选区域与共享画风 | 真实玩家尺度母版和正式合屏。受伤换身体、材质跳变、拉伸或只能放大欣赏均失败 |
| E04 动作覆盖／G2 | 交代待机、移动、转向、预警、攻击、攻击恢复、受伤、受伤恢复、死亡、终态；补物种专属状态 | 状态→实际资源／程序表现→运行片段逐项对应。缺态、占位、只列状态名不通过；允许静止设计，不强制每态单独贴图 |
| E05 连续性／G2 | 进入、退出、中断、重复触发保持身体身份、重心、脚／附件锚及当前相位连续 | 正常速度完整片段加具体帧对；含移动→受伤→恢复、攻击周期、致死→终态、左右方向与连续命中。bbox相同不证明自然 |
| E06 命中反馈／G1–G2 | 接受伤害后有可读身体反应与方向／材质反馈，拒绝／护甲结果按其语义表现 | 回执与音画时间轴。落空不冒充命中；反馈不遮身体、弹道、预警、落点；表现不决定伤害、资源或强制位移 |
| E07 死亡终态／G1–G3 | 按已声明政策留尸、消失或碎解，死亡与奖励只结算一次 | 实弹致死与足够末尾观察；留尸核真实支撑、空中落尸、移动／消失支撑、保存恢复及不重播；消失核完整清理。现有charger／diver按留尸合同，不改消失绕过缺陷 |
| E08 声音／G2 | 攻击、接受受伤、拒绝、死亡的声音或静默设计语义明确，混音可辨、无重复／削波 | 正常速度带音轨实战与实际试听，换声交A/B和来源。波形、有音轨不代签听感；怪物工作不擅改武器声 |
| E09 遭遇／G1–G3 | 在实际准入地形、同伴、机关、镜头、资源下，预警、反制、安全落点及恢复机会成立 | 代表正式遭遇及设计允许的击杀／非击杀策略；镜头外发难、堵唯一出口、必损血、组合超压须修。Lab不代签正式池 |
| E10 接入／G3 | Definition、实例、安装器、表现替换、资源导出与生成路径一致；暂停、慢时、回退、死亡、重入／重载、epoch正确 | 每条实际使用链有运行证据；旧请求不伤新角色、音画／奖励不重播。历史链按当前授权另列，历史延期不豁免当前保存 |
| E11 性能与来源／G3–G4 | 纹理、特效、声音、尸体、节点有源自目标场景／设备的预算与回收策略；资产可追溯 | 采证前声明预算，测峰值、回收、帧时、内存；保PNG、prompt／参考、导入和许可，未知如实记录并处理准入。软件录制速度不当设备FPS |
| E12 验收／G4–G5 | 适用检查通过，独审无未关闭拒绝，用户与目标设备完成适用验收 | 原命令／退出码、正常速度音画审查、用户原话、设备测量。技术通过、合入或上线不单独构成完成 |

## 动作与转换

采证前在物种卡固定验收条件：实际Definition与身体／动作资源版本、攻击／受伤／死亡时长来源、脚／附件锚与可见／判定包络、允许的中断规则、终态持续与清理政策、镜头／分辨率、代表遭遇、目标设备和性能预算。需要数值容差时写依据与测量方法，不能看完结果再调阈值。留尸的末尾观察至少覆盖演出结束、真实稳定接地及声明的持有／恢复／清理场景；消失须观察到实际回收。静态证据、事件追踪、真实像素与主观判断分列。

状态表之外还需逐项核对实际可达转换。受伤不打断攻击的物种须说明反馈叠加与回到当前相位的方式，不擅加stagger。

| 转换 | 核对重点 |
| --- | --- |
| 待机 ↔ 移动 ↔ 转向 | 身体身份、脚步／拍翼与位移一致，镜像和附件不脱离 |
| 移动／待机 → 预警 → 攻击 → 攻击恢复 → 当前合法动作 | 前摇可读、判定同步、收势清楚，不闪回错误姿态 |
| 可受伤活态 → 受伤 → 当前合法动作 | 进入和退出都连续，保持当前朝向／运动／攻击相位；重复命中依真实规则处理 |
| 任意可致死活态 → 死亡 → 终态 | 致死覆盖非致死反馈；失力、落地与终态身份一致，不默认翻转活图替代设计 |
| 相关态 → 暂停／慢时／取消／卸载／重载 | 时钟与所有权正确，恢复无补发、旧请求或重复演出 |

按物种选择逐帧、骨骼或程序方法；静态末帧可以是合格尸体。缺实现不能标不适用，确实无某状态／器官／声音须说明设计依据及替代可读性。统一检查完整性和效果，不机械统一制作方法。

## 完成度记录与声明

逐项只用原四态：`passed`（指定版本／范围有证据）、`failed`（实证不合格）、`unverified`（缺验证）、`not_applicable`（设计确不适用且有依据）。「实现事实」单列代码／资源路径、占位、缺失、已有待验；代码存在不是passed。

汇总写清范围、最高连续通过的G阶段、十一维、缺口／发现ID和下一动作。不得用百分比或平均分冲抵必需项失败；后段诊断通过不补签前段。对外声明边界：

| 表述 | 条件 |
| --- | --- |
| 行为原型／局部表现样板 | 只报已验项与缺口，workflow仍in_progress／review，不能简称怪物完成 |
| 技术与正式接入通过，待体验验收 | 适用技术／接入及独审已成立，其余视听／用户／设备逐项列明；不能自动标awaiting-device |
| 怪物完成 | 完整物种E01–E12全部满足，并满足原记录所有必需G0–G5与十一维，才可done |

未知项不一律追写failed；有实证才判失败，缺实现写清事实并保持对应未通过状态。历史失败、修复与当前源分别登记，修复链接后续版本及复验，不覆写旧报告。标准／制作卡的process交付不向怪物继承PASS。

## 每物种交付与执行

1. 用[Enemy Design Sheet](../templates/enemy_design.md)登记身份／机制、身体母版、状态与转换、E01–E12、正式消费者及单一原质量记录。
2. 先一个物种完整闭环：移动／攻击、实弹非致死命中、恢复、致死、终态；留尸补支撑／保存。先关身体及过渡反例再扩产。
3. 证据带source commit、内容版本、入口、Seed／Manifest、武器／能力／Definition、镜头、分辨率、表现链、接受事件与影片时间；fixture、正式场景、历史证据与fresh分开。观察型交真实影片，操作体验交准确版本Preview。
4. Development按依赖跑专项，Integration覆盖受影响完整系统和正式消费者，最终遵守Release。未改玩法可引用原证据并说明未受影响闭包，变化项重新验证。
5. 原G4独审、G5用户／设备关闭缺口；第二运动类型另验复用，通过后推广依赖该母版／动作方案的怪物。

enemy-creator负责设计／行为／遭遇及整卡；art-director负责身体／来源；animation-vfx负责动作／过渡／反馈／表现生命周期并与audio-director协作；game-quality-gate管理共用记录，gameplay-reviewer独审。数值、运行策略及质量policy仍由原权威管理。
