# Audio Style Bible · audio-director-v1

状态：设计提案已形成；所有新音色待用户试听。技术指标是防故障边界，不能证明悦耳或商业品质。

## 声音语言

柔和童话、精巧机械、轻盈魔法、清晰动作反馈。像木壳中一枚小钟簧：短而有触感的实体起音，温暖身体，稀疏透明尾音。隐藏悲伤以轻微下落、余韵与空白表现；不把常规动作处理成恐怖、军事或密集街机警报。

高频声尤其克制。一个事件首先提供一个可辨识的因果：木/皮/纸的动作，钟簧/小金属的机关，短铃/玻璃的魔法。最多2–3层，各有职责；不能用层数、响度、随机化数量替代选择。不在每次射击放奖励铃；不在每次受伤放惊叫。允许保留安静，不为填满Inventory新增声音。

## 声音家族

| 家族 | 设计与识别线索 | 避免 |
| --- | --- | --- |
| 移动、跳跃、落地 | 跳跃轻拨/空气抬升；落地软木身体；重落地同材质加重量 | 电子滑音当所有移动声，轻落地爆炸 |
| 枪与反冲 | 紧致木芯/簧片起音与短机械回弹；反冲合入同一个攻击包络 | 双重开火，刺耳军枪，整段混响遮下一枪 |
| 钩索 | 释放细绳掠动，连接扣锁短响，牵引有界纤维/链擦动；取消立刻清尾 | 借用聚焦/奖励导致语义误认，长loop越场景 |
| 敌人攻击/命中/受伤/死亡 | 命中是接触与已接受伤害；受伤有身体材质；死亡解构与下落余韵 | 固体碰撞冒充敌伤，所有生物同尖叫，Boss死亡覆盖主角危机 |
| 主角受伤/死亡 | 短软撞+低部警示，清晰但不刺痛；死亡一次性留空 | 与敌人同声混淆，无敌帧重复发声 |
| Boss预警 | 中频可辨节奏，先于判定；保留视觉等价提示 | 依赖听力才能避招，音乐遮盖，持续高频警报 |
| UI点击/确认/拒绝 | 同一小机械族；确认向上轻开，拒绝短低闭合；触控不泄漏成射击 | 每次点击奖励和弦，拒绝刺耳蜂鸣 |
| 金币/生命/普通物品/重要奖励 | 小金属 vs 温暖魔法；普通拾取短，重要奖励低频率可稍长 | 金币与大成就同响，连拾堆响压过受伤 |
| 世界与机关 | 风与植物柔且有空间；钟摆/齿轮点到为止，机关有可读因果 | 到处永动齿轮，背景噪声掩盖脚步/钩锁 |

## 区域与未来扩展

风铃平原：薄木、风铃、小铜扣、空气。光亮来自稀疏短余音；风铃不能与金币争同一频带。
荆棘森林：树皮、纤维、叶片、较暗木壳；仍使用同一机械瞬态与魔法尾音语言。允许稍暗和近景摩擦，不独立换成恐怖音库。
未来地区先填材质/空间/情绪/危险语义卡，引用此家族和事件规范。差异优先来自原材质与节奏，而非全局变调或重压缩。

## 制作与混音边界

候选WAV单声道PCM16/44.1kHz，短动作不设loop；持续阶段必须可停止。修剪静音、微淡入/淡出、必要高通/低通和轻动态，不强行把短瞬态拉到同一LUFS。按事件RMS区间与峰值留余量，绝对峰值不高于−3dBFS，短频发目标更低；相同事件A/B按相近响度试听，保留原版实际增益的额外对照。

总线Master→SFX/UI/Ambience/Music，均初始0dB以保现有增益语义。五首用户MP3原字节不动，沿现有MusicGain 0.16与交叉渐变；试听页用同样0.7会话音量、0.16音乐增益作为起点并可手调。单声与BGM混播分别验；对话/预警等未来ducking需真实消费者才增加。

优先级：死亡/主角受伤与危险预警 > 已接受关键动作/钩锁 > 命中/普通拾取 > 脚步/氛围。共享12voice；同声限制、短冷却、防连重复；局部表现随机独立于玩法随机。位置衰减以当前非空间服务为基线，禁止声称已全面3D/2D定位。空间扩展必须真实镜头/距离试验。

## 试听与淘汰

A偏温暖木芯与小机械；B偏透明魔法与纤维。它们是比较假设，不是批准方向。每个事件与原版单听、重复8–12次、BGM下、连续动作下比较：刺耳、拖尾、语义误读、疲劳、遮盖、是否契合世界。用户可逐事件选A/B/原版/都不合适；保留候选ID和版本，不由自动峰值检查替用户投票。

若两轮无改善，保留失败、换素材或重做层次，不以增响/加层交差。新事件按[Audio Director入口](README.md)读取风格、来源、事件目录后再制作。第一轮不推广全区域、全武器或全敌人。

环境混音反馈（2026-10-29）：环境应微弱衬底，不得盖住BGM。沿实际MusicGain 0.16比较，持续环境的初始基准比原首轮降低14dB，点声降低10dB；只是本轮起点，不是所有未来素材的通用响度保证。静听可辨、音乐存在时退后，动作预警仍清楚。不要为听清环境而提高设备总音量；用户未选前不推广。
