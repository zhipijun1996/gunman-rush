# 第一大关：平原模块的美术与空间编排

本轮用户授权将现有美术分支风格用于第一大关。当前是固定十关和独立随机试玩的可玩候选皮肤；本文件描述后续模块制作方向，未制作的装饰不得当成已完成素材或碰撞。

## 共用视觉语言

蓝灰远山、开阔草坡、冷灰岩石、风车与旧黄铜机械遗迹构成平原。草顶是一条连续可站立边；薄板与移动平台使用旧黄铜，尖刺红橙锐边、齿轮圆形运动形成危险预告。完整模块可以高低错落、反向进入、上下折返，背景不按模块切房。日光平原可比原幽暗参考明亮，保持清楚轮廓、原创机械与精密动作气质；当前SVG简化版不冒称绘画母版完成度。

美术不决定路线：先用真实Motor验证动作和资源，再沿几何铺皮肤。端口是内部连接数据，不画入口出口大字或绿色隔离段。机关运动空间与安全落脚边保持净空；草花/断柱/藤蔓必须在经过验证的装饰安全区内，不能暗示可站立、遮危险或改变随机布局。

## 接下来的制作顺序

先由用户实际手机查看平原皮肤，确认角色大小、危险对比与日光色调；再在多端口契约上做能向上/向下转折的连续路线，逐个验证后添加岔路。沿上述材质做高崖、断桥、风车台与机械通道的组合，大小模块混用，穿插安全观察台与连续动作段。正式平台/战斗/时机/容错预算与关卡类型节奏仍由GEN-DIFFICULTY负责，不以换皮宣称实现新曲线。

随后分层加入已存在的草花/断柱/黄铜环/藤蔓，装饰使用独立稳定流和排除区，并加入版本化表现记录；当前没有运行装饰抽样，不创建无人使用的全套皮肤框架。后续主题复用锚点、连接件和功能颜色契约，替换材质/景深/内容池，不直接改PlayerController。


## 风铃平原与维修通道

[世界背景](world_and_story.md)将本区工作名定为风铃平原，场景以草甸、木桥、风车、发光花和旧维修标记为锚点。下射抬升/侧射跨断桥应在安全可观察挑战中教学，枪向量与反向位移提示可由短姿势图表达；不在危险中强制读长对白。当前高崖/450远跳/854升台是已验证挑战样片，不自动作为首间入门房；木吊台、弹跳花、微弱气流属于候选外观/机制，未验证前不替换黄铜平台或改反冲参数。家园发光花不等于段起点。

## 平原精修的场景族

用户认为现有可玩皮肤不够精美，技术接入不代表视觉通过。[世界场景](world_and_story.md)和[品质标准](art_quality_target.md)覆盖原文件将简化SVG沿用为最终外观的理解。几何和已验证动作继续保持，表现按四种场景族细化：开阔草坡（自然草岩断面）、峡谷木桥（绳木和两岸遗迹）、风车吊台（木材/黄铜混合动力外观）、旧维修站（刻度、风铃与少量发光花）。场景族是可重复的美术组合，不是四个新大关或未验证机关。

固定宽度手绘平台不直接当循环tile；先精修端头/中段/填充/薄板连接套件。模块主题变化通过独立稳定的表面/装饰选择表达，同一区光照一致，短台/长岸/深井/高空/左右镜像均要实际合屏。主路的站立边和锯轮扫掠范围保留净空，风车和维修站不改变移动台相位。家园发光花不放成段回退标记。

## 平原动作尺度与生成节奏（2026-10-10）

本轮用户要求地图与角色大小跳、跳跃和位移能力绑定。当前候选极短按峰高从约41.57px提高至62.32px，完整长跳约162.91px保持；横速330与单次爆发154px保持。数据为真实Motor自由起跳测量，不是任何横向距离都能与最大跳高同时实现；动作链按具体起跳时机、碰撞、冷却、平台相位验证。当前默认次数是2/2但定义继续允许0/N，不把额外次数当平原入门路线门槛。

平原平台不是按固定屏宽或角色美术尺寸排布。单板/阶台应明确所需升程、净空、到达距离和动作余量；机关包络独立扣除落点空间。普通落点预留完整24×36碰撞体与操作余量；远跨越和高差不能只用距离≤速度×时间判断，更不能把最大横移与最高升程同时取满。

本轮最小算法切片：

1. 读取实际PlayerTuning与配置版本，生成单跳短/长按无碰撞筛选包络；包括重力、速度、加速和跳跃维持，反冲距离/次数/冷却另计。
2. 模块作者注明最低持跳升程、平地跳距、移动速度/冷却等需求，并依据已有真实Motor样片认证；性能不足不进入池。包络只做必要条件过滤，不提供充分可达证明，也不缩放现有地形掩盖不兼容。
3. 独立开发试玩使用平原标准压力配置；另保留入门配置和原高级挑战验证配置。开始安全，短板与连续模块混合，尖刺/锯轮逐步出现；连续高压后用原有安全草台缓冲，不加绿色连接段。平原标准不强制每次抽齐极高崖、远跳和高升摆渡。
4. 以Seed有界抽取兼容模块；端口重合、身体净空、机关全包络和模块间碰撞验证保持。失败重试后记录同试玩安全保底；禁止无限重试或自动强化人物。
5. Manifest保存实际配置hash、能力包络、压力配置/版本、模块/相位/预算与保底原因；重放核对实际内容，不仅验证签名。降低能力或改物理不能加载旧图冒充兼容。

后续仍需做局部转折/分叉、正式小关六类型与入门十关曲线消费者。入门配置只取低压模块；当前标准试玩以低中压为主、最多一个高级峰值及一个连续大模块，不代表正式首关主路。其高级峰值与独立高级挑战保留真实Motor验证；正式主路/困难支路分池仍需后续图规划，不因为本轮降低平原开局压力而删除其真实通行标准。正式每大关10关、Boss10保持；当前RANDOM STAGE仍独立练习，不发Run/Meta奖励，不表示已实现完整正式随机10关。

风车/桥面/草岩/维修站仍是视觉锚点，现有SVG为功能占位，黄金样板与用户视觉认可另行推进。后期贴墙缓降见[金色道具能力设计](wall_slide_design.md)，当前平原不依赖它。
