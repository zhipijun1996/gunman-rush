# 第一大关：平原模块的美术与空间编排

本轮用户授权将现有美术分支风格用于第一大关。当前是固定十关和独立随机试玩的可玩候选皮肤；本文件描述后续模块制作方向，未制作的装饰不得当成已完成素材或碰撞。

## 共用视觉语言

蓝灰远山、开阔草坡、冷灰岩石、风车与旧黄铜机械遗迹构成平原。草顶是一条连续可站立边；薄板与移动平台使用旧黄铜，尖刺红橙锐边、齿轮圆形运动形成危险预告。完整模块可以高低错落、反向进入、上下折返，背景不按模块切房。日光平原可比原幽暗参考明亮，保持清楚轮廓、原创机械与精密动作气质；当前SVG简化版不冒称绘画母版完成度。

美术不决定路线：先用真实Motor验证动作和资源，再沿几何铺皮肤。端口是内部连接数据，不画入口出口大字或绿色隔离段。机关运动空间与安全落脚边保持净空；草花/断柱/藤蔓必须在经过验证的装饰安全区内，不能暗示可站立、遮危险或改变随机布局。

## 接下来的制作顺序

先由用户实际手机查看平原皮肤，确认角色大小、危险对比与日光色调；再在多端口契约上做能向上/向下转折的连续路线，逐个验证后添加岔路。沿上述材质做高崖、断桥、风车台与机械通道的组合，大小模块混用，穿插安全观察台与连续动作段。正式平台/战斗/时机/容错预算与关卡类型节奏仍由GEN-DIFFICULTY负责，不以换皮宣称实现新曲线。

随后分层加入已存在的草花/断柱/黄铜环/藤蔓，装饰使用独立稳定流和排除区，并加入版本化表现记录；当前没有运行装饰抽样，不创建无人使用的全套皮肤框架。后续主题复用锚点、连接件和功能颜色契约，替换材质/景深/内容池，不直接改PlayerController。
