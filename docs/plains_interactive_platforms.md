## 操作与空间

| 实际组合 | 玩家操作 | 压力和选择 |
| --- | --- | --- |
| 五格草台左两格荆棘 | 提前读危险面、跳到其余三格 | 全脚宽落点；不能贴刺站立 |
| 刺墙 | 远离墙面起跳、越过墙脸、落到无刺墙顶 | 起跳距离与高度；正反方向分别可行 |
| 荆棘后接齿轮 | 安全格落地，再观察齿轮相位起跳 | 连续但不同的两个动作，回程不同起跳点 |
| 远程风铃门 | 匹配符号与编号、出发前瞄准远门开关 | 沿地面花射击精力，或关门状态走上层四跳/下穿单向平台的无射击绕行 |
| 射铃摆渡 | 启动、登船、射击停靠、恢复运动、离船 | 控制运动相位、消耗精力；两岸都有同号操作铃，停船不重置相位 |
| 安全落点跃扑守卫 | 读冻结落点预告，选其他绿格或等跃扑回收 | 怪物限制落点，无强制清怪 |
| 船上俯冲与扇射 | 读船相位，再读俯冲预警起跳 | 单纯站船中心会受伤，操作改变结果 |

新模块与旧10类局部动作组合共同进入正式连接池，总14类动作语法。并非14类互斥操作；绕行、慢等、救场仍合法。风铃门上层绕行与地面射铃真正共用同一空间，未另建战斗房间。地下、风道、环路、反侧捷径、雾图、稳定奖励/商店账本与预算保留。

PlatformThornDefinition记录真实平台索引、表面方向、段范围和深度；危险碰撞由实际host派生。五格host320px，每格64px，左128px危险、右192px安全；缩短的只是旁边草岸。TOP/LEFT/RIGHT/BOTTOM美术与镜像范围相同，根部嵌入真实石面。旧坑底danger_bounds仍是跌落传感器，标注DEEP DROP，不再画成空中荆棘；原危险碰撞、保护与段回退未放宽。

远程铃、门/渡台使用AI浪纹/太阳/叶纹＋颜色＋唯一 LINK NN编号，射中有传播粒子。正式配对记录在Manifest，不靠猜同色三类图标。现有原机关消费者扩展toggle_ferry，不用永久“已开门”账本替代可重复开停状态；存档记运行状态和motion_clock。暂停、段回退、卸载重载不重抽、不归相位；待提交时死亡仍先结算死亡。支持稳定actuator_id扩展，但没有虚称金币门/复杂逻辑机关已实现。

正式HP保持36、原一跳与反冲规则保持。第一图独立鸣铃巡游机及其开场名字、自由攻击方向保持；本轮重绘的是第二图牧风者。

跨图Manifest恢复还修复道具相容：根据已记录ItemDefinition及堆叠限制，用BuildState重新计算合法人物参数，逐项比对；稳射/刹车/开火间隔等不再因偏离基础值被误拒，任意改参数/未知或畸形道具记录仍拒绝。

## 主动发现和修复

真实上台射铃失败追到PhysicsShapeQuery：旧intersect_shape带motion会把未来地面与当前铃芯混为同组，先拿到地面就吞弹。现初始重叠和首次扫掠接触的intersect_shape均临时motion=ZERO，移动仍经cast_motion；薄墙、护甲、友方和旧epoch规则保留。独立2px薄墙探针确认挡弹，近距离合法铃芯命中也确认，不以扩大铃芯解决。

新组合680px＋260px，余60px连接地面；最初720＋260只余20px，无法给完整角色合法站位，导致候选拒绝。保留原失败与修复，未降低可达性断言或删掉失败组合。100固定种子14类动作全实际出现、无生成重试/保底；正式复合连接双向真实Motor验证。

独立审查发现RIGHT/BOTTOM荆棘贴图方向错误、左岸第三阶段跳射漏洞、II误提示不存在的符印、暂停重载渡台短暂原点显示；均针对真实消费者修复并留反例。生成v7、region随机流v3、items仍v2；随机版本明确改变实际内容与实例配对。历史D080证据保持，当前runner输出改写本轮目录。
