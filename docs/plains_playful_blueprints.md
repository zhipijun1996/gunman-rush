# D065 平原：有区别的整关编排与风险选择

用户授权按趣味性方案逐步完成多个任务。本轮可交付门槛是：两个能实际走通且空间/动作不同的关卡编排、分岔风险收益、反冲救场段、同局编排交替以及端到端试玩回归。通过这些门槛只说明已具备更丰富的可玩结构，不代表用户已经认可趣味性，也不承诺后台无限迭代。

## 两种编排与节奏

断桥横渡：公共路以横向跨越为主，预告普通跳跃、观察落点，再经过允许反冲补救的断桥。风车攀升：公共路连续升高，初期为静态落脚台，中后期加入已验证移动平台与反冲升阶。两者均保持安全出生、挑战之间可站立观察/恢复动作资源，最后才分为通向各自末端门的两条路线。

宏观图仍是公共路接两条终端路线；本轮改变实际高差与动作编排，不宣称已实现多重分岔、回环或围绕中央塔身的左右往返。折返/汇合仍需新端口与真实完整路线验证。平台、机关与皮肤复用现有契约，不改变人物运动参数。

## 路线选择与收益

上支路为挑战路线，具有更强平台/反冲要求；下支路为相对稳妥路线，保留跳跃与探索但不要求反冲、不堆危险。两条均可继续本局。路牌继续显示实际下一小关房型，并额外标注STEADY PATH或CHALLENGE + LOOT。主路必需动作不能依赖随机奖励。

挑战支路增加3金币和1音符为可配置demo试调值，读取已记录branch_profiles，在末段安全落点生成独立拾取物，沿用现有领取ID/账本，不在路牌或触碰门时提前发奖。金币属于RunCoin，音符属于Meta；回退、重复安装或重复领取不能复制奖励。不是全体奖励加稀有度，也不改变门确认后奖励规则。

## 容错与补救

新的plains_recovery_bridge正常一跳可过；刻意早跳的相同动作会掉下，向后射一枪可在若干已测时机救回且保留一发。观察空间与宽接收平台使失败有补救机会。详见[实际轨迹](recoil_recovery_validation.md)。不能宣称所有失误都能挽救或133毫秒足够所有手机用户操作；慢时与真机体验仍需试玩。

## 同局交替与复现

PlainsBlueprintSchedule使用独立blueprint命名空间，按Seed决定初始编排并在1–7槽位交替横渡/攀升。1–3为入门，4–7可组合动态机制；商店/回血覆盖为休息，Boss8保持固定核心。休息会中断动作节奏，因此不承诺任意两间被服务关隔开的动作房绝不重复；也不是跨局记忆或完整挑战标签去重。

manifest保留blueprint_plan版本/槽位/请求与实际blueprint/模块/预算，RunManifest用root_seed重新校验计划。不读取未记录本机历史；奖励抽样不推进地图或计划随机流。能力不足或有界求解失败保留明确兼容方案，不偷偷把请求冒充实际已生成。
