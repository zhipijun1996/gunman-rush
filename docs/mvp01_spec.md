# MVP-01

交付角色灰盒、固定测试场景、统一 InputRouter/PlayerController/PlayerMotor、键鼠与手柄适配、安卓触屏、调参、HUD、自动测试和 debug APK；准备并独立验证 Windows Desktop 导出。不做随机地图或正式商业发布。Android 横屏当前优先，Windows 为未来正式平台，不只用于调试。

物理 60 Hz；参数见 [唯一配置](../config/player_tuning.json)。调试 HUD 显示普通/反冲速度、跳跃与射击资源、冷却、状态、检查点及输入捕获。

场景分四区：基础移动、跳跃边界、八方向反冲与碰撞、组合动作。追加开关、单向平台、固定补充点与死亡检查点。

交付先按任务分批：环境与跨平台契约 → 移动跳跃 → 射击碰撞 → 输入 → 续航机关 → 固定挑战。输入就绪即可构建 APK，固定挑战的最终门槛仍是 APK 真机验收；Windows 构建另记结果。CORE-01 覆盖可配置跳跃次数、土狼时间、跳跃缓冲和失败返回非零的真实自动测试；射击次数也数据化，不把默认两次当作不可扩展限制。

手机保持双摇杆与独立跳跃键、右杆拖瞄松手射击；键鼠释放射击动作发射；手柄右轴有效偏移后回死区一次射击，带方向缓存、防抖与重新武装。断连、失焦、暂停取消不射击。桌面隐藏触屏控件，提示随设备切换；死区、灵敏度和映射支持配置。具体实现与验收以 [输入契约](controls_contract.md) 为准。

一套世界与人物物理独立于屏幕和设备；存档共用 schema，文件存储与未来云同步分层，Steam 服务保留独立可选适配边界。MVP 不实现持久存档、完整 Steamworks 或商店，开发无需 Steam 账号/SDK。能力、机关、敌人 AI、Boss 与原创美术边界继续遵守已合并架构契约。

完成要求参见 [验收](acceptance_tests.md)。初始 20–30 秒挑战为节奏目标，需真机试玩调整；不能以源码生成视为可玩。
