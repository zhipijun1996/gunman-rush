# MVP-01

交付角色灰盒、固定测试场景、桌面输入、安卓触屏、调参、HUD、自动测试和 debug APK；不做随机地图或正式商业发布。

物理 60 Hz；参数见 [唯一配置](../config/player_tuning.json)。调试 HUD 显示普通/反冲速度、跳跃与射击资源、冷却、状态、检查点及输入捕获。

场景分四区：基础移动、跳跃边界、八方向反冲与碰撞、组合动作。追加开关、单向平台、固定补充点与死亡检查点。

交付先按任务分批：环境 → 移动跳跃 → 射击碰撞 → 输入 → 续航机关 → 固定挑战 → APK 真机。

完成要求参见 [验收](acceptance_tests.md)。初始 20–30 秒挑战为节奏目标，需真机试玩调整；不能以源码生成视为可玩。
