# Demo 试玩 / Plains and fixed playtest

本页面说明`scenes/demo/demo.tscn`开发试玩链，实际可用构建/网页版本以[交接](handoff.md)为准。正式每大关10小关，第10 Boss；标题ENTER HOME进入安全行走家园，工坊NPC消费永久音符，右侧出发门开始正式冒险；DEVELOPMENT DEMOS子页提供**10 rooms / Windchime Plains**独立随机平原入口，并保留3关development_only快试与10关固定回归。10关仍只验证一个大关，不定义游戏大关总数或完整通关。只有原固定入口使用固定图；平原随机入口每关独立生成，样片与回归不混为同一验收。

## 开始与操作

默认标题ENTER HOME进入可操控家园，出发门开始正式平原。DEVELOPMENT DEMOS可输入Seed并选择 **3 rooms / A quick taste** 或 **10 rooms / The full route**固定回归；SETTINGS调整输入，操作帮助保持独立入口。Desktop: A/D移动，Space短按小跳/长按大跳，鼠标瞄准、释放左键开枪；靠近交互点使用当前设备提示或屏幕按钮。Mobile: 横屏，关内左杆移动、独立JUMP跳跃、右杆拖动瞄准/松手射击；靠近补给和商店时点击交互按钮。正式随机关进入出口自动结算，道具弹窗选一；固定开发场景仍显式交互。家园提供LEFT/RIGHT/INTERACT安全操作。Controller: 左杆移动、跳跃键短/长按、右杆有效偏移后回中心开枪；断连/失焦/暂停均取消而不开枪。

枪口方向决定弹体方向，角色向反方向快速位移。空中向下射击可获得向上反冲。空中有效瞄准保留慢时/黄色外围遮罩原型，消耗精力，落地恢复；不让普通跳跃/移动/射击额外消耗精力。点击HUD的MENU或按Esc暂停。菜单提供RESUME、SETTINGS、CONTROLS、YOUR BUILD、RETURN TO HOME；返回家园需再次确认LEAVE RUN，KEEP PLAYING继续当前局。打开设置/帮助/构筑时保持暂停，返回子页不会提前恢复物理。

## 3关快试路线

1. 第一关击败巡逻无人机。怪物接触扣血并留在当前位置；环境危险扣血，存活时回当前安全段起点。途中靠近绿色SUPPLY使用一次回血补给。
2. 完成战斗后两个出口显示SHOP与ITEM名称，进入哪个就决定第二关类型。出口锁定直到房间完成，一次选择只能切关一次。
3. SHOP展示价格与库存，购买加跳道具会扣RunCoin，库存用完不可再买；允许不买离开。ITEM显示两个候选，只能领取一个，领取后才可推进。能力变化由可撤销Modifier产生。
4. 第二关两个出口都进入第三关Boss。观察其阶段/攻击、躲避并用实际弹体攻击。击败后领取唯一金道具，回家园显示胜利摘要。
5. 血量归零直接结束本局回家园；不再执行环境回退。同帧双方死亡暂定玩家失败优先，无金奖励。新局清道具/金币/路线，当前正式App配置永久存储并保留摘要；无存储测试fixture只在进程保留次数，正式试炼的大关完成单独记录在completed_biomes。


## 10关固定大关试炼

第1～9关通过两个出口选择下一关类型，出口展示名称与图标。战斗房击败目标；商店可购买或离开；金币房领取10枚RunCoin；回血房恢复当前血量2点（不增加最大血量）；道具房二选一后推进。金币/回血数值属于演示fixture，正式奖励平衡和血量房规则仍待决策。房间内容与奖励只结算一次，段回退不刷新。

第9关两个出口都指向第10关Boss。击败Boss并领取唯一金道具后，以`biome_complete`返回家园，单独累计大关完成次数，不累计为完整游戏胜利。整个试炼使用固定灰盒布局；路线、奖励和实际交易输出写入本局版本化Manifest，不等于已经实现随机地图或跨会话存档。

## 输入设置

SETTINGS提供移动灵敏度、瞄准灵敏度、触屏死区、手柄瞄准阈值和回中阈值五项滑条。回中阈值必须小于瞄准阈值，无效组合不应用。调整后点击APPLY；RESTORE DEFAULTS仅预览默认值，还需APPLY。设置在当前页面会话的新局中保留，刷新页面后恢复config/input_profile.json；暂停或改设置取消旧瞄准，不会意外射击。

## 重点反馈

请分别反馈 Android浏览器与iPhone Safari的双杆多点触控、短/长跳、向下开枪反冲、空中慢时手感、遮罩/UI遮挡、横屏安全区域和性能。构建/自动测试不能替代真机证据。

段回退后检查敌人HP、机关相位、已用补给、道具领取和商店库存保持原状态，不能重复刷奖励。当前音符/永久升级与Meta摘要已有持久服务，实际Web刷新已验证；进行中的Run不提供断点续局。平原独立随机已实现，正式完整经济、剧情和其他地区仍未完成。


## 可重复检查

完整物理/事务/SceneTree回归：`python3 tools/run_tests.py`。Web导出：`python3 tools/build.py web`。可选实际浏览器检查：安装Playwright、Pillow与Chromium后，从仓库根运行`python3 tools/verify_demo_browser.py`；也可把公开试玩URL作为第一个参数。检查有界超时、失败非零，截图/报告写入忽略的build/verification/demo。它只是Chromium触屏模拟，不能代替iPhone Safari或Android真机。


## 随机整关试玩

主页点RANDOM STAGE，按FLOW方向通过大小不同的单平台与连续挑战段，镜像路线向左走；图中含高攀升、远平台和交错上升摆渡，模块直接无缝拼接，没有绿色连接段或中间ENTRY/EXIT。Seed输入可以复现同一布局；RETRY重试当前图，NEW SEED换新组合，OVERVIEW查看全关再返回玩法；高塔向下松手射击抬升，远距缺口向反方向松手射击跨越，摆渡观察停靠后登乘。段起点在安全平台内部记录、不显示编辑标记；末端LOW/HIGH A/HIGH B三面金旗是不同整关终点，任选其一只完成一次；高路要求实际跳跃，低路可步行。尖刺和不同大小的移动锯轮扣血后回安全段起点，地图/机关相位不重抽，零血回主页。这是独立组合试验，尚未接正式房间奖励、两出口、Boss或十关Run，不计家园永久进度。保留触控/键鼠/手柄现有操作。


## 平原美术试玩

主菜单十关试炼第1房与RANDOM STAGE显示同套原创平原候选皮肤。rush-demo为向右高攀升，left-proof-1为镜像向左路线。检查草顶落脚边与危险轮廓、枪/飘带无碰撞的读图一致性、平原远景是否遮平台、手机实际尺寸与性能。MAP OVERVIEW隐藏触屏控件；无需安装，安卓/iPhone浏览器均可先试，真实Safari单独验收。机关伤害/地图路径不因换皮重算。


## 平原10关独立随机与音符

从标题ENTER HOME进入家园，向右移动到出发门、W/上/触屏INTERACT打开出发确认，点击BEGIN / WINDCHIME PLAINS；也可在开发入口选择 **10 rooms / Windchime Plains**。每关固定左下起点、局部模块镜像，向右上推进。第1关战斗，击败本关所有敌人后，走进高/低两个不同位置出口之一选择下一类型；金币房平台沿途金色金币自动拾取，至少拿一枚并到达终点推进；商店安全区域购买跳跃升级，金币不足也可离开；回血房仍独立恢复当前2HP，关卡奖励在进入出口时结算，道具房弹窗二选一后再切关。第9关出口均进入Boss10。走入固定战斗核心才开战，入口缓冲不受Boss伤害；退回缓冲不重置HP/相位、不刷金道具，击败Boss后触碰金色出口，在弹窗选择唯一金奖回真实家园。

紫色音符自动拾取进入永久钱包，合法保存后消失，死亡保留；局内金币结束清除，不自动转音符。家园永久生命升级显示价格/等级，当前demo成本5/10/15音符、最多三级，每级下局基础最大及初始HP+1；这些是可配置候选数值。刷新网页应保留已保存音符/升级；浏览器私密模式、清除站点数据或拒绝存储可能丢失/无法保存，失败界面会说明，不提供云同步或中途续局。

本轮自动验证的完整十关为流程fixture，实际Motor只覆盖代表阶段/新模块与Boss核心。请用户分别试玩Android Chrome与iPhone Safari横屏，记录落点阅读性、瞄准/反冲、触控与帧时；无真机记录不记通过。技术网页与确切包hash见handoff。

## 本轮画面与加载

正式镜头倍率1.6，世界物理与碰撞不放大；背景低饱和冷灰轻虚化、三个独立视差层。顶部紧凑HUD只显示必要资源，INFO或F3开启路线/镜头调试和操作说明。地面开火反冲倍率0.65、空中力度不减；空中有效瞄准慢时20%。跳跃/落地/枪口/尾迹/命中与合法拾取有有界装饰粒子，不产生额外伤害。

Web首载使用可恢复压缩传输，再次加载复用hash引擎与游戏包，版本提示允许手动更新而不清音符存档；首次与再次加载的实际传输证据见[加载报告](web_loading.md)。iPhoneSafari压缩/缓存支持与性能仍须独立测试。
