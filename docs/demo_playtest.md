# 固定 demo 试玩 / Fixed demo playtest

本页面说明`scenes/demo/demo.tscn`开发试玩链，实际可用构建/网页版本以[交接](handoff.md)为准。正式每大关10小关，第10 Boss；主页现在提供3关development_only快试与10关固定大关试炼。10关仍只验证一个大关，不定义游戏大关总数或完整通关。地图为固定原创灰盒，不是随机生成关卡。

## 开始与操作

主页输入Seed，选择 **3 rooms / A quick taste** 或 **10 rooms / The full route**。左侧START返回模式选择，SETTINGS调整输入，HOW TO PLAY查看操作。Desktop: A/D移动，Space短按小跳/长按大跳，鼠标瞄准、释放左键开枪；靠近交互点使用当前设备提示或屏幕按钮。Mobile: 横屏，左杆移动、独立JUMP跳跃、右杆拖动瞄准/松手射击；靠近补给、出口、道具和商店时点击屏幕交互按钮。Controller: 左杆移动、跳跃键短/长按、右杆有效偏移后回中心开枪；断连/失焦/暂停均取消而不开枪。

枪口方向决定弹体方向，角色向反方向快速位移。空中向下射击可获得向上反冲。空中有效瞄准保留慢时/黄色外围遮罩原型，消耗精力，落地恢复；不让普通跳跃/移动/射击额外消耗精力。点击HUD的MENU或按Esc暂停。菜单提供RESUME、SETTINGS、CONTROLS、YOUR BUILD、RETURN TO HOME；返回家园需再次确认LEAVE RUN，KEEP PLAYING继续当前局。打开设置/帮助/构筑时保持暂停，返回子页不会提前恢复物理。

## 3关快试路线

1. 第一关击败巡逻无人机。怪物接触扣血并留在当前位置；环境危险扣血，存活时回当前安全段起点。途中靠近绿色SUPPLY使用一次回血补给。
2. 完成战斗后两个出口显示SHOP与ITEM名称，进入哪个就决定第二关类型。出口锁定直到房间完成，一次选择只能切关一次。
3. SHOP展示价格与库存，购买加跳道具会扣RunCoin，库存用完不可再买；允许不买离开。ITEM显示两个候选，只能领取一个，领取后才可推进。能力变化由可撤销Modifier产生。
4. 第二关两个出口都进入第三关Boss。观察其阶段/攻击、躲避并用实际弹体攻击。击败后领取唯一金道具，回家园显示胜利摘要。
5. 血量归零直接结束本局回家园；不再执行环境回退。同帧双方死亡暂定玩家失败优先，无金奖励。新局清道具/金币/路线，家园只在当前进程保留快试完成、失败与大关完成次数，正式试炼的大关完成单独记录在completed_biomes。


## 10关固定大关试炼

第1～9关通过两个出口选择下一关类型，出口展示名称与图标。战斗房击败目标；商店可购买或离开；金币房领取10枚RunCoin；回血房恢复当前血量2点（不增加最大血量）；道具房二选一后推进。金币/回血数值属于演示fixture，正式奖励平衡和血量房规则仍待决策。房间内容与奖励只结算一次，段回退不刷新。

第9关两个出口都指向第10关Boss。击败Boss并领取唯一金道具后，以`biome_complete`返回家园，单独累计大关完成次数，不累计为完整游戏胜利。整个试炼使用固定灰盒布局；路线、奖励和实际交易输出写入本局版本化Manifest，不等于已经实现随机地图或跨会话存档。

## 输入设置

SETTINGS提供移动灵敏度、瞄准灵敏度、触屏死区、手柄瞄准阈值和回中阈值五项滑条。回中阈值必须小于瞄准阈值，无效组合不应用。调整后点击APPLY；RESTORE DEFAULTS仅预览默认值，还需APPLY。设置在当前页面会话的新局中保留，刷新页面后恢复config/input_profile.json；暂停或改设置取消旧瞄准，不会意外射击。

## 重点反馈

请分别反馈 Android浏览器与iPhone Safari的双杆多点触控、短/长跳、向下开枪反冲、空中慢时手感、遮罩/UI遮挡、横屏安全区域和性能。构建/自动测试不能替代真机证据。

段回退后检查敌人HP、机关相位、已用补给、道具领取和商店库存保持原状态，不能重复刷奖励。刷新页面会丢失家园内存摘要；正式永久存档、经济、剧情与随机地图均未完成。


## 可重复检查

完整物理/事务/SceneTree回归：`python3 tools/run_tests.py`。Web导出：`python3 tools/build.py web`。可选实际浏览器检查：安装Playwright、Pillow与Chromium后，从仓库根运行`python3 tools/verify_demo_browser.py`；也可把公开试玩URL作为第一个参数。检查有界超时、失败非零，截图/报告写入忽略的build/verification/demo。它只是Chromium触屏模拟，不能代替iPhone Safari或Android真机。


## 随机整关试玩

主页点RANDOM STAGE，沿横向路线通过连续模块，绿色接桥连接下一个挑战。Seed输入可以复现同一布局；RETRY重试当前图，NEW SEED换新组合，OVERVIEW查看全关再返回玩法。蓝绿色点为段起点，环境存活伤害回段起点且地图/机关相位不重抽，零血回主页。这是独立组合试验，尚未接正式房间奖励、两出口、Boss或十关Run，不计家园永久进度。保留触控/键鼠/手柄现有操作。
