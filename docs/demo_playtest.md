# 固定三关 demo 试玩 / Fixed demo playtest

本页面说明`scenes/demo/demo.tscn`开发试玩链，实际可用构建/网页版本以[交接](handoff.md)为准。正式每大关10小关，第10 Boss；当前3关仅development_only。地图为固定原创灰盒，不是随机生成关卡。

## 开始与操作

家园输入seed，点击 **BEGIN RUN**。Desktop: A/D移动，Space短按小跳/长按大跳，鼠标瞄准、释放左键开枪；靠近交互点使用当前设备提示或屏幕按钮。Mobile: 横屏，左杆移动、独立JUMP跳跃、右杆拖动瞄准/松手射击；靠近补给、出口、道具和商店时点击屏幕交互按钮。Controller: 左杆移动、跳跃键短/长按、右杆有效偏移后回中心开枪；断连/失焦/暂停均取消而不开枪。

枪口方向决定弹体方向，角色向反方向快速位移。空中向下射击可获得向上反冲。空中有效瞄准保留慢时/黄色外围遮罩原型，消耗精力，落地恢复；不让普通跳跃/移动/射击额外消耗精力。PAUSE暂停，RESUME继续，END RUN / HOME取消本局。

## 完整路线

1. 第一关击败巡逻无人机。怪物接触扣血并留在当前位置；环境危险扣血，存活时回当前安全段起点。途中靠近绿色SUPPLY使用一次回血补给。
2. 完成战斗后两个出口显示SHOP与ITEM名称，进入哪个就决定第二关类型。出口锁定直到房间完成，一次选择只能切关一次。
3. SHOP展示价格与库存，购买加跳道具会扣RunCoin，库存用完不可再买；允许不买离开。ITEM显示两个候选，只能领取一个，领取后才可推进。能力变化由可撤销Modifier产生。
4. 第二关两个出口都进入第三关Boss。观察其阶段/攻击、躲避并用实际弹体攻击。击败后领取唯一金道具，回家园显示胜利摘要。
5. 血量归零直接结束本局回家园；不再执行环境回退。同帧双方死亡暂定玩家失败优先，无金奖励。新局清道具/金币/路线，家园只在当前进程保留完成/失败次数。

## 重点反馈

请分别反馈 Android浏览器与iPhone Safari的双杆多点触控、短/长跳、向下开枪反冲、空中慢时手感、遮罩/UI遮挡、横屏安全区域和性能。构建/自动测试不能替代真机证据。

段回退后检查敌人HP、机关相位、已用补给、道具领取和商店库存保持原状态，不能重复刷奖励。刷新页面会丢失家园内存摘要；正式永久存档、经济、剧情与随机地图均未完成。
