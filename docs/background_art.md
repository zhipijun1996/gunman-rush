# 平原背景美术与随机地图契约

交付四个运行时 SVG：`assets/backgrounds/plains/plains_sky.svg`、`plains_far_hills.svg`、`plains_meadow.svg`、`plains_distant_ruins.svg`。尺寸均为 1920 × 1080；天空不透明，其他层透明。由 AI 编写的 `tools/build_background_assets.py` 可确定性重建。背景不含碰撞、奖励或机关，也不参与玩法随机。

## 引擎接入

按天空、远山、草原、远景遗迹顺序，推荐 z_index -40 / -39 / -38 / -37。水平 scroll_scale 为 0.04 / 0.12 / 0.22 / 0.28，垂直为 0。使用 Parallax2D 的 repeat_size=(1920, 0)；若按统一倍率缩放节点，同时缩放 repeat_size。不要设置垂直循环。底边是背景画布填充而非可站立表面。

天空云团在左右边界有周期复制；山脊来自整数周期函数，首尾位置与斜率一致；遗迹全部位于画布内部，边界透明。随机地图每个区域连续使用同一组背景相位，不能在每个玩法模块处重置背景，否则会跳变。长距离可在安全过渡段换背景套件。为减少手机开销，SVG 导入后作为静态纹理使用，不逐帧重新绘制 SVG。纹理显存与实际手机表现未验证。

## 原创与 AI 来源

依据批准参考 `exec-b229b4a0-ec16-4180-905b-14954d71d657.png` 中柔和日光、蓝灰远山、草原与机械遗迹提取配色。运行时 SVG 属于 AI 编程创作，强调循环、低对比和辨识度；其细节密度低于绘画母版，仍需整关试玩与最终风格验收。

`source/plains_painted_master.png` 是 image_gen 根据同一参考生成的 AI 绘画母版，仅用于调色与氛围参考，不可当作透明分层或循环纹理。完整生成提示词与工具输出路径保存于 `source/provenance.json`。该母版没有角色和 UI，因此不作为角色授权或角色一致性证据。

## 验证

生成脚本正常退出；四个 SVG XML 可解析，尺寸检查通过，山脊首尾坐标一致。无需外部字体、网络、外链图片或 SVG 滤镜。`python3 tools/check_docs.py` 通过。Godot 导入和真机验收由主任务统一执行；本任务未单独执行 Godot 或真机试玩。
