## 4. Boss修复规格

### 4.1 第三阶段末墩循环

状态：observe→chase→pier_warning→pier_impact→pier_open→next_or_final。前两个墩推进，第三墩进入final_hold，循环warning/open；Boss留在末墩，不取模回0，不传送到起点。

初版时长候选：预警0.8游戏秒、撞击0.2、开放维持现exposed_seconds+1；恢复0.8。末墩每周期有明确核心窗口，错过可再试，未击败前不会跑出竞技场。撞击只在已定义危险包络造成1伤害；不能把整个巨羊图片变伤害体。如果现玩家常在羊后方，末墩核心朝向必须让两侧的合法桥台都存在至少一种真实弹体攻击路径。

段回退取消旧攻击，但保持phase/chase_segment/已破坏地形，进入对应安全恢复状态；暂停冻结，不新增一次撞击或重置走位。取消操作分清“暂停”“回退”“死亡/离场”，不要全部粗暴变observe。

### 4.2 阶段切换

达到阈值先关闭旧攻击和弱点，显示0.8～1.2秒切段预告；旧弹体按既有epoch取消。断桥撤除必须先提示受影响地面与可站桥面。玩家半空时不能冻结输入或瞬移到危险边缘；可给现有保护，不能凭空补血/枪。

Boss换位优先真实有界运动＋舞台遮挡；确需瞬移式舞台切换，必须显式过渡、落点清楚、取消接触伤害直至恢复，不能一帧无预告改变全局位置。Arena版本升级与Manifest同步。

### 4.3 必须复现

| 用例 | 正确结果 |
| --- | --- |
| P3全三墩都不攻击Boss | 到末墩仍能继续攻击；无瞬移/无软锁 |
| 三阶段中任意模式暂停/恢复 | Boss、窗口与地形连续；没有旧攻击重复 |
| 玩家在地面/桥上/半空打出切段弹 | 都有可理解下一落点，不瞬间无预警受伤 |
| 切段/胜利与玩家零血同帧 | 失败优先，无金/永久重复结算 |
| 各桥台胜利、未立即领取 | 奖励可达，安全站位有效，ENTER/STAY正常 |
| 多次坠落回退 | Boss血与阶段保留，不刷金币，不免费满精力 |

## 5. 主角与Boss动作精修

动作必须与真实速度和事件同步。纯表现状态不可决定跳跃时机、伤害、位移或输入锁。

| 动作 | 目标表现 | 默认演出预算 |
| --- | --- | --- |
| 站立 | 小幅呼吸，枪稳定，脚底固定 | 呼吸位移≤1世界px |
| 起跑/停止/换向 | 上身轻倾、脚步随地速；换向不整图弹跳 | 过渡0.06～0.10秒，不影响Motor |
| 起跳 | 发力姿态和脚底小尘；到顶自然转下落 | 不加输入前摇；表现压缩≤0.04秒 |
| 反冲 | 肩/枪先承压、身体沿反方向倾，尾迹短 | 对齐实际0.14秒爆发，结束及时收尾 |
| 落地 | 随实际落速改变尘量与压缩 | 0.08～0.12秒，不锁移动 |
| 受伤 | 清楚短闪与姿态，不持续遮角色 | 沿现0.28秒，不新增击退 |
| 巨羊冲撞 | 低头蓄势→脚步加速→撞停/卡角 | 前摇沿玩法时钟，足底与轨迹一致 |
| 风车阶段 | 叶轮危险/安全态清楚，铃开放有独立动作 | 视觉叶缘对齐真实厚叶扫掠 |
| 追逐撞墩 | 向前蓄势、短撞击、喘息露铃 | 不使用单张冲撞图贯穿全循环 |

优先骨骼/部件动画与少量母版编辑，避免每动作独立AI重画导致衣服、脸、枪漂移。验收需要连续运动录像和手机尺寸画面。

## 10. 用户新增五项要求：本轮优先验收

2026-10-11 11:22追加。本节是明确用户反馈，优先于旧候选描述。当前仍只更新策划，不实施森林或新精力系统。

### 10.1 落地镜头：保留路线视野，禁止落地强制回地面

用户反馈：落地时镜头会强制只看当前地面，失去上方/前方路线。代码核对：`StageCameraRig`沿actor_position+(lookahead,-80)和dead_zone跟随，没有显式落地重置；另有session变化时snap、world_bounds裁剪与角色安全可见修正。**不能凭反馈就假定存在landed回调强制复位；必须检查实际轨迹和其他相机调用，定位落地前后哪个分支改变目标。**

目标：镜头服务即将继续的路线，不把每个平台落地都当作新的起点。落到小台、摆渡台、连续爬升台时保留之前的纵向构图；确实进入较低新区域时缓慢过渡，允许玩家观察下方。

实施规则：

- 普通落地不得调用snap_to_target/reset_smoothing，也不得强制把相机Y绑到当前地面高度；真正重生和场景切换允许明确镜头切换。
- 纵向死区用非对称上下阈值与滞回；角色落在屏幕安全范围内时保持相机高度。连续跳台中保留上方落点，避免起跳上移、落地下移的反复抽动。
- 下降超过安全范围时跟随实际下降并预留可见落区；不能“保持高度”导致角色离屏或看不见落点。
- 平台移动与轻微落地起伏不立即推动镜头。前视依据实际前进路线/移动，不依据枪朝向瞬间反转。
- 记录camera position/anchor/session/bounds clamp/安全范围修正，在录屏对应帧定位原因。先修造成突变的分支，不以加大平滑掩盖错误目标。

验收场景：原地连跳、上下台连续跳、摆渡落地、反冲后小台落地、长下落、Boss桥台回射。连续录像应看到下一落点；正常落地无突然下压、无反复上下拉扯，角色始终可见。Boss镜头与普通关镜头分别测试。

### 10.2 玩家、Boss、敌人：完整弹体特效体系

用户要求涉及**飞行中的子弹本体**，不能仅补枪口和命中粒子。

| 弹体 | 发射表现 | 飞行表现 | 命中／消失 | 判读要求 |
| --- | --- | --- | --- | --- |
| 玩家鸣钟弹 | 精准枪口短闪、轻音爆 | 暖白金色小核心＋短方向尾迹；与背景分离 | 地形碎尘；护甲灰火花；弱点钟音亮闪 | 飞行方向清楚，贴图不夸大实际碰撞半径 |
| 敌人种子弹 | 花芽／哨台收缩后喷出 | 深色轮廓、橙红或紫红危险核心；大小可辨 | 地形短裂、打中玩家走实际受伤事件 | 不与金币、音符、玩家弹体混同；不只靠颜色 |
| Boss踏地波 | 蹄下压缩、地面亮边预告 | 贴地弧形波头＋沿地短尘带 | 碰墙／寿命结束收散；受伤按实际提交 | 波头危险范围可读，不用漫天尘遮住安全跳高 |
| Boss风叶／近身攻击 | 叶轮蓄势、剪影方向提示 | 危险叶缘短亮、扫掠弧仅展示真实轨迹 | 命中与结束反馈分开 | 属于攻击特效，不能画出假的飞行弹丸 |

玩家/敌人/Boss不同轮廓、音色和尾迹节奏；单发多命中只播合法事件。弹体生命周期结束立即停尾迹，暂停/阶段切换/回退清陈旧攻击；不留下漂浮火花误认为可伤弹。低特效保留弹体本体、方向与危险边缘，减少的是装饰数量。

验收：白天空、深草、Boss背部三种背景；多弹同屏；全角度发射；慢时与暂停恢复；实际命中和贴图位置一致。运行效果从`player_projectile.gd/boss_projectile.gd/enemy_attack_projectile.gd`分别接入，不能只修改PlayerFeedback就宣称全弹体完成。

### 10.3 Boss血条、登场与切阶段过场

代码现状：DemoApp已有THE WINDKEEPER与当前/最大HP的文本，不等于已经交付正式Boss血条。需从现HealthState读取真实生命，完成正式UI与演出。

血条要求：Boss激活后显示独立长条与“牧风者 / THE WINDKEEPER”，真实HP下降立即反映，延迟残血层0.25～0.45秒作为表现；阶段阈值可标两处刻度。血条不能盖右摇杆、跳键或关键落点。弱点关闭可用小护甲图标说明，不伪造HP变化。死亡后残血归零再淡出，奖励出现时不再占屏。

咆哮默认是表现，不附带未经设计的全屏伤害/强制击退。过场不通过随意改Engine.time_scale实现，避免与空中慢瞄冲突；独立演出状态管理Boss攻击与输入。暂停、跳过、死亡、离场都要取消过场回调，不能恢复后重复开战或领奖。

借鉴空洞骑士的“名字、停顿、声音与动作形成仪式感”，采用原创字体布局、声效与角色动作，不复制其专属素材。重复挑战简短登场可跳过；长过场不能变成重试惩罚。

### 10.4 Boss动作僵硬：按动作链重做，不能只加震屏

用户明确认为僵硬。本次作为需要修复的表现问题；其根因可能是姿态、过渡、脚步与运动不同步，不能单凭静态图确定只有素材不足。

每招至少具备准备→发力→运动→接触/停下→恢复，五段可以部件动画实现。巨羊脚步频率随实际速度，躯干有克制的重心起伏，角/耳/毛束有延迟跟随；脚底固定，不能整张贴图飘移冒充跑动。冲撞前抬肩低头，卡角后有受阻回弹；风叶随真实blade_angle，身体姿态不能风叶已停仍暴走。核心受击有独立短反应，不取消玩法攻击或改变HP时序。

建立动作检查片：idle、stomp_warning/stomp、charge_warning/charge/neck、blade_warning/blades/back、chase/pier_warning/pier_open、phase_transition、defeat。至少左右朝向与实际速度均检查。阶段图之间统一体型、脚底和风车轴心，避免突然换形。

验收采用同一招慢放与正常速度录像；看准备是否读得懂、脚步是否滑、受阻是否有重量、各阶段姿态是否连续。若仅替换六张姿态图、播放速度变化或加粒子，不能标记此项完成。

### 10.5 更多风铃挑战、更多敌人与更高遭遇密度

明确增加内容与可互动遭遇，保留第一关教学和Boss前休息。敌人总量与实际遭遇次数分别统计；不能把敌人集中堆在一小块区域就称全关丰富。

新增风铃组合：①稳定平台射铃开门；②跳跃中射铃、反冲落宽台；③摆渡平台上射铃解锁下一渡口；④上下两条路分别触铃，同一奖励组只领一次；⑤可选支路按可见顺序敲两铃，错过能重试；⑥铃打开短周期门，必须有等待台与重复开启机会。只有后两种引入新的时序规则，首次先独立无敌教学。
