# 全武器与钩索合同

本页规定当前武器消费者及动作练习的验收范围。武器树方向见 [动作设计入口](../design/player_actions/README.md)，操作以 [输入合同](../controls_contract.md) 为准；资源以 [攻击与恢复](../combat_and_recharge.md) 为准。具体数值由 Definition／Resource 提供。

## 所有权和资源

同一角色只有一个当前 WeaponRuntime，拥有攻击包、持续状态、有限弹体和布置物。Lv.1 为枪／影步手里剑／反冲炸弹；六个 Lv.2 分支各保留到 Lv.3，三级技能与普通攻击分别提交。正式授予由运行流程决定，练习可自由选择，不能用练习配置推定正式成长已开放。

基础一发空中弹药；合法攻击启动按当前弹药策略结算一次，射击不消耗时间能量。枪械与钩索的空中瞄准慢时共用 AirFocus。共鸣独立，真实敌人提交伤害后按攻击包／目标去重和上限累计；技能原子付费，技能伤害不能自充。持续武器的停止条件、弹药策略和伤害窗口从当前武器定义读取，不另设递增射击精力。

切换、死亡、回退和会话失效清理旧攻击实体、请求与回调。暂停取消未完成起手／持续动作，世界实体按暂停合同保留。移动只交给 PlayerMotor；出手路径不能越墙生成弹体。

## 分支合同

| 家族／分支 | 验证重点 |
| --- | --- |
| 枪／三连机关枪 | 一包攻击的一次弹药与反冲结算、独立弹体命中 |
| 恒流激光 | 持续输入、真实射线与墙体截止、伤害窗口、停止与释放后重启 |
| 影步／散华手里剑 | 出刃与反向闪步，散华二次采样方向，受碰撞约束 |
| 遥控回旋刃 | 单一飞刃，情境操作直线高速召回，真实接刃才按入射方向推动 |
| 反冲炸弹／磁吸遥爆雷 | 当前基础炸弹爆发时序，磁雷表面附着、遥爆与真实距离／遮挡借爆 |
| 坍缩奇点 | 在角色当前位置生成，有限固定与轻敌牵引，接触停止环及定向弹射 |
| Lv.3 技能 | 当前分支普攻保持 Lv.2 行为；技能付费、起手、方向、伤害和 epoch 清理独立验证 |

位移及触屏持续控制的细则见 [动作预算](action_budget_spec.md) 与 [武器手感](weapon_feel_spec.md)，恢复事件见 [空中恢复](air_action_refill.md)。

## 钩索与输入

H 为独立能力，360°瞄准、保持后松开发射；合法命中后的拉近／踢跳及有界离开保护只覆盖该目标身体接触，其他怪物、敌弹与环境照常结算。失败、取消、死亡或会话变化立即清理保护。W／D 只有已授予后才能由合法恢复事件恢复。

键鼠、手柄和触屏提交相同动作意图；激光持续、情境召回／遥爆、技能操作按输入配置和当前控件执行。系统取消不能当射击，零方向按当前有效方向合同处理。按钮映射不在本页另立版本。

## 验证

实际入口为主菜单动作练习 → 装备选择 → 武器靶场；训练敌人有真实 HP 和伤害接收，不发正式成长奖励。验证全部 15 装备节点的真实输入、命中、反冲、资源、Lv.2／Lv.3 普攻等价，以及切换／暂停／死亡／回退。覆盖多帧率、固体／平台、贴墙出手、距离／遮挡与 H/W/D 连招。

从 `python3 tools/harness.py --list` 选择现存武器、人物与资源专项。正常速度带音轨录像、实际桌面／触屏、独立审查与实体设备分别记录，任务证据沿 ALL-WEAPONS-01 及当前 [活跃议题](../tasks.md) 定位。旧轮次的断言数和 CI 结果不能签署当前源码或用户体验。
