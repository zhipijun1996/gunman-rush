# 关卡质量 Q1–Q8：自主生产、审查与返工准绳

Q1–Q8 是玩家体验的审查视角，不是新增质量状态、分数或 G 门槛。沿用 [G0–G5](../development_quality.md) 与 [policy](policy.json) 的十一维。每项结论必须给实际消费者、版本、Seed/路线/能力/设备、观察和可证伪条件；`not_applicable` 说明原因，不用平均分抵消失败。工程检查、AI 专家判断、玩家最终认可分别留证。

## 每次自动执行前加载权威，不重新发明世界规则

地区/挑战任务在生成设计或 mission 前读取 [current_state](../current_state.md)、[handoff](../handoff.md)、[动作入口](../design/player_actions/README.md)、[regions_v0.3](../design/player_actions/regions_v0.3.md) 全文与 [weapons_v0.8](../design/player_actions/weapons_v0.8.md) 全文；涉及控制再读 [controls_v0.1](../design/player_actions/controls_v0.1.md)。跟随入口读最新 [位移预算](action_budget_spec.md)、[空中恢复](air_action_refill.md) 等覆盖规则，并核对真实授予点/装备 Definition/Runtime/Motor。旧文件中的横向钩索、禁止恢复 D、八小关等历史条目不能覆盖最新修订。

产出一个随任务保存的 authority ledger：`path/section/hash → requirement → LOCKED/PROPOSED/OPEN → implemented_consumer → formally_granted → evidence_scope`。LOCKED 表示方向已确认，不表示实现、正式授予、数值/设备/审美全部通过；已实现的 PROPOSED 技能仍不是用户最终认可。冲突先查最新明确修订，记录适用条款与被覆盖条款；真正未决核心方向才交用户判断。下表仅为读取索引，不代替原文。

## Q1–Q8 的统一通过与拒绝依据

| 维度 | 专家设计启发式与必须观察的内容 | 可证伪反例/返工方向 | 映射现有十一维 |
| --- | --- | --- | --- |
| **Q1 空间与探索** | 分支有可读的风险/收益/发现差别；地标帮助定向，多层/回环/捷径改变去返程；从入口、Boss 直达、成长探索、高收益返回实际走路 | 两条边同目的同动作同回程成本却称有意义选择；奖励不可见且没有发现线索；绕路后只能重复长高压。改局部空间/收益信息/回程，不刷连通边数 | design、gameplay、formal_integration |
| **Q2 平台跳跃与连续动作** | 观察→承诺动作→空中修正→落点/恢复；每次射击兼顾攻击/机关和反冲；短语有真实速度/资源/相位衔接，熟练后可减少停顿 | 模块独立可过而连段冷却/次数不足；动作只是 jump/shot 标签串；加刺/缩台代替新判断。回编舞和几何，保持 Motor | design、technical、gameplay、animation |
| **Q3 战斗、敌人与地形联合** | 敌人改变起跳时机、站位、瞄准/反冲方向；允许绕过、等待、引诱、压制或利用位移；玩家可先读安全落点再应对 | 敌人死亡/移动/未激活后唯一锚点或回能来源消失而必经无解；击杀成为默认唯一策略；敌人无预告占满唯一落点。提供不依赖随机敌态的合法恢复/备选路，验实际敌人 AI | design、technical、gameplay、formal_integration |
| **Q4 区域特色与机制进化** | 从既有地区权威提取核心机制、空间/行为身份；新机制先展示再练习再组合；单项能力的深度先于堆全部能力 | 森林重设计成默认墙跳/二跳地区；S2 高阶偷要求第二能力；每段强制全能力；只换皮/数值。回 authority ledger 与对应阶段机制 | design、gameplay、formal_integration |
| **Q5 节奏密度与玩家情绪** | 按真实路线安排学习/紧张/释放/好奇/奖励/安静，明确观察、恢复、叙事和眺望的留白用途；看首次与返回两种经历 | 用“安全区”标签掩盖无目标长走廊；因低互动告警给所有空白加敌人；高潮后无喘息。验证留白用途，不成立则压缩冗余或改变决策，不单向最大化密度 | design、gameplay、audio_vfx、player_acceptance |
| **Q6 美术、构图与视听** | 黄金母版→系列拆分/透明与锚点→地形边界/接缝→Godot 正式合屏→正常速度动态可读；焦点/轮廓/层深/光照与节奏一致 | 原画替代运行截图，静图替代动作，前景/特效遮唯一落点，资产重复造成相同构图；只做资产存在检查。回构图或资产工序，不改已验碰撞 | visual、animation、audio_vfx、performance、player_acceptance |
| **Q7 肉鸽随机与重复游玩** | 结构、动作、机制互动、探索决策、视觉五类分开比较；同构筑/策略下不同 Seed 应有实质变化，重复亦可承担学习/主题呼应 | 改坐标/ID/贴图/Hash 当新玩法；整图丰富而玩家路径同样；换 Seed 避开失败。保留最差 Seed，改实际选择/依赖/组合，未测签名标未验 | design、technical、gameplay、player_acceptance |
| **Q8 公平、手感与工程** | 当前单武器+真实资源+唯一 Motor；镜头先展示；失败可理解/可恢复；死亡奖励保存/epoch 正确；设备输入负荷和性能可测 | 传送/注能过关，输入请求冒充接受动作，换装困死，旧回调发奖，手机被迫额外多指，改变重力让地图过关。回明确责任实现，原回归与真实设备分别验 | technical、formal_integration、gameplay、performance、independent_review、device、player_acceptance |

十一维仍逐项记录；Q 发现可以映射多个维度，未观察到的维度不得随技术通过自动升级。Q3 的 Enemy 失效正/反例必须说明状态是正常游玩产生还是边界 fixture 设置，二者都可诊断但不能互相冒充。

## 把启发式转成可执行的设计实验

每个切片先填写“玩家此时看见什么→做哪个判断→通过哪组实际动作→获得什么反馈→失败如何恢复”，再提出至少一个设计备选和一个不改方案。比较行为变化、范围、可逆性与新风险，选最小可验证方案。普通主路、奖励支线、隐藏大师用不同压力/恢复/失败成本，不用动作数或障碍数量单独定难度。

联合设计实验至少同时标地形落点、敌人感知/移动/攻击区域、机关相位、镜头窗口、资源余量和奖励/返回。先在少量代表状态验证，再扩大 Seed；单独敌人测试、平台测试和一张合屏都不能替代联合空间。若射击将敌人杀死也消掉所需钩点/命中恢复，必须实测无敌人备选或确定的安全返回，不能保证“玩家不会先杀”。

留白审核填写 `purpose / viewer_goal / visible_information / recovery_rule / next_beat / return_experience / observed_support / counterexample`。有效例：安全台让玩家观察运动落点一周期，之后有可解释的择时；无效例：没有观察对象、资源恢复或叙事反馈的长直地面被事后改名“休息”。目的声明本身不消除告警；保留长度/时间观测及人审理由，不能靠改标签、调阈值或空发输入清除候选。

素材不够时先做已标注的灰盒/旧素材技术片并完成物理；由 art-director 明确缺口再调用实际可用的 AI 资产流程。记录母版、完整提示词、模型/工具、来源许可、原图/派生哈希、裁切缩放/锚点、导入设置和消费者；未知来源写 unknown。用户已认可范围可继承，未认可的全新画风/核心创意才需用户决策，不让用户反复发现接缝/遮挡等常规问题。

## 真正自主循环的完成合同

沿 [原生产循环](production_loop.md) 和现有 Harness 执行，不平行另造任务系统。一次真正循环须留下实际 worker 设计/实现产物、工具执行证据、独立只读审查、结构化发现、修复输入/修改和复验；mission JSON、计划、fake-worker 测试或脚本打印“调用成功”均不足。

1. **冻结基线**：用户授权范围、authority ledger、任务依赖、可写路径、禁改 core、Source/配置/能力、初始 Seed 集、最大轮次/调用/时间预算和恢复目录。
2. **专家设计**：选 Q 目标与可观察差异、失败反例、设计备选；按专业 Skill 形成真实可实施卡，禁止仅复制报告生成 TODO。
3. **实现并执行**：在准许路径改真实消费者；运行当前已存在且适用的 CLI/真实 Godot/GUI。命令不存在、依赖缺失、非零/超时/缺标记明确失败，不能换成文档检查。
4. **独立审查**：新只读会话读冻结源码、证据、Q1–Q8 和历史失败，自己复现反例；不修改审查对象，不以作者自评/伪 reviewer 名称代签。
5. **返工包**：每条 finding 含 `id/Q/gate/location/observed/expected/reproduce/evidence/severity/owner/minimal_fix/regression`；交责任 Skill 执行并重跑受影响验证，关联修复提交及复审。
6. **有界恢复**：保存 round/calls、任务/依赖/输入指纹、源码快照和证据；相同状态可续做，外部改动/规格变化使旧通过失效，另建一轮。无进展、越界、超预算或缺外部依赖保留现场并明确 blocked/budget_exhausted，不无限重抽或自动扩范围。
7. **宣布范围**：技术与客观专项可先完成；核心创意偏好、审美和最终体验交用户，实体设备另列。用户不担任常规 Bug 发现员，缺主观认可不阻止已授权技术修复继续。

若所有真实版本首轮通过，不为制造返工证据故意把缺陷加入生产；用隔离反例演练拒绝/恢复并明确其 scope，真实缺陷出现时保留真实修复链。工具接口按当前 `--help` 和已注册 profile 调用，新增 CLI 只有实际 runner/失败例就绪后才写为可运行。

## 本轮平原证明集合

本轮目标包含实际自主闭环与至少一个正式平原优化切片，不只完成规范。冻结前后同一组至少 10 个不同 root Seed，逐项覆盖两张正式地图（标 intro/advanced 与派生 map Seed）、不同探索路线，保留最差种子。采集矩阵列计划与实际，不拿 10 个静态 Manifest 当 10 次真实路线；缺一项写失败/未验，不自动填 PASS。

保留正式敌人已实例化/状态和实际画面证据；旧 assembler 无敌人轨迹只证明旧 scope。对受影响段增加敌人存活/移动离开/已死亡/未激活、资源边界、失败再试与返回；公平工程必须满足，合理留白则按用途判断。森林只做沿既有 S2-H 权威的设计/路由 dry-run，不开放地区或暗授能力。

前后对照固定 Seed、地图索引、构筑、资源、输入策略、观测阈值/工具语义和设备/分辨率；实现源与 Manifest 可以因合法改动不同，但必须记录差异。实际路径改变时按稳定语义 ID 和明确的区间映射比较，不强行配对。布局改善、动作连贯、敌人关系、视觉效果分别报告，不能把单指标变化外推趣味提高。

## 可复用知识与来源边界

任务经验记录包含 `rule_id / source_kind / source_path_or_url / exact_scope / observation / inferred_heuristic / authority_conflict_check / positive_case / counterexample / validated_consumer / source_version / unresolved`，放同任务证据/设计资料并供下一轮按相关性检索。源码、已确认用户原话、真实轨迹、实际画面、外部资料与 AI 推断分别标识；失败经验也保留。

可借鉴“小挑战先独立打磨再编排”“安全展示→练习→组合”“失败让玩家理解动作原因”等方法。仓库 [procedural_generation](../procedural_generation.md) 已记录社区 Wiki 阅读和 GDC 摘要范围；引用这些只能称复用项目已记录的阅读，不冒称本轮看过完整演讲/玩过原作。新引用先实际读取并注明精度，不能从截图推断隐藏输入/通关率，不复制具体地图、资产、角色或本游戏没有的动作。经验提炼须有反例和适用条件，不能把某 Seed 修复升级为所有地区硬规则。
