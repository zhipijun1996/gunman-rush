# QUALITY-ITERATION-01 — 当前游戏审查与生产循环

基线：`5fd9c272d74616ae477809fa4285f609e6b697c6`（PR57，运行源码与 main `6568e9a` 相同）。本轮分支 `feature/quality-review-and-production-loop`。已 fetch；并行 PR56 Foundry 更新为 `f721795`，不是本轮分支祖先，未静默混入其开发能力原型。

目标是让技能能自动路由、让大任务可多轮执行，并以当前平原验证通用审查方法。用户给出的现象是回归线索；独立审查者没有拿到这些具体线索，按空间/状态/时间/消费者契约发现了暂停重置攻击、可见身体超出 hurtbox、正式画面周期接缝，初审 REJECT。原始报告见 [初审](../evidence/quality_review/initial_independent_audit.md)。

本轮玩家体验：平台边界与可通行性可读，乘平台时画面相对稳定，战斗不因菜单而重置，Boss 身体危险与阶段保护一致，登场有准备/到位/冲击/恢复的连续表现。用户补充的地形原则已明确确认：可变长宽素材必须覆盖八方向边界及兼容接缝；具体画风与最终合屏尚未认可。

| 契约 | 场景与方法 | 观察及失败条件 |
| --- | --- | --- |
| 空间/视觉一致 | 短平台、长平台、高墙、L/T并集，实际绘制 | 非实体空隙被画实、内部边界被画端头、轮廓对不上碰撞即失败 |
| 相对参考系 | 实际 Motor 在平台上经历移动/驻留/反向，再真实跳离 | 共同位移被镜头弹簧拖后，或离地仍跟平台即失败 |
| 状态不因观察而变 | 正式敌人预警中暂停/地图，比较状态计时和弹体 | 清弹、重置恢复或免费打断即失败 |
| 危险与保护一致 | 两种 Boss 多阶段/入口消费者 | 活跃身体不伤害、介绍/死亡仍伤害，或 Lab与正式规则分叉即失败 |
| 可见即能交互 | 不同朝向/动画的不透明身体对真实 hurtbox | 大块实心头壳可穿弹即失败；附属特效不算身体 |
| 构图和语义 | 不同层平台与区域安静节点 | 同深度随机灰化、装饰无承载面、假交互铃和落点遮挡即失败 |
| 演出生命周期 | 正常速度登场、跳过、暂停、卸载 | 瞬跳、遗留特效、音效重复或画面遮挡操作即失败 |

敌人数量不是简单加一个整数的验收。现有实现有 patrol/charger/diver/sentry/fan_sentry/hopper，但素材身份和遭遇职责表达不足。新增两项可玩开发候选，尚不入正式随机池：

- **苔盾甲虫**：前向护盾，锁向突进，完整恢复窗可击；背后也可攻击。玩家可诱导突进再还击，或用反冲越过换到背面。复用 EnemyActor/Motor/Health/DamagePolicy，HP不堆叠。0.8s预警、0.65s突进、1.1s恢复为候选设计值，非用户已认可的难度。外形、六态母版、护盾音和预警轨迹已接入开发样板。
- **柳籽蛾**：悬停观察、锁定两条不同高度的种子射线，间隔0.5s发射；鼓励利用反冲改变空中路线，后发射线不重新追踪。真实弹体、暂停/死亡/Retry由现有生命周期处理。0.8s预警/1.1s攻击/1.1s恢复为候选。二次发射和预警可读性需连续体验审查。

入口：Development → Module Lab → More Trials → ENEMY CANDIDATES。候选不授予 Run奖励、不修改保存和正式生成算法。正式准入仍需多地形/组合压力、连续动画、死亡反馈、玩家趣味和视觉验收；不能用这两个原型声称“怪物丰富度已完成”。

本轮不改 PlayerMotor 基础物理、正式路线/随机流/收益算法、能力授予规则或正式入口。新能力/武器 Skills 建立完整制作责任，不虚构二段跳、墙跳或武器升级已经新制作完毕。
