## 三个共享大型家族（前两族优先）

### A：宽低岩层岸肩 / 后方崖裙（优先1）

用途：草原坡脚、风车台地根基、溪谷岸后接合、营地岩岛后方、Boss两端岩肩。共同语言为大片斜向断面、3–4个主块、细苔缝和小根，不出现等距砖阶。它是横向大体量，不是旧竖柱。首件是**完整宽低侧岸肩**，后续同族再做右向、内凹、无草暗裙；不能把一件镜像当全部家族。

源目标1536×1024 RGBA，独立物体而非atlas；主体宽高比至少2.8:1，约 x48..1488/y380..900，含不规则下裙、下缘向陆侧收。先要求完整轮廓，返回尺寸不符保留失败，不改阈值救图。世界首试W620/H约190（屏幕992×304）；只等比缩放，不能把高柱横压。固定源锚是上缘靠船道端的“岸接点”，返回后实际测定坐标，而非先伪称已有像素。

溪谷应用：岸顶y528保留，草缘528..556不被新图覆盖。左岸上缘接点=(1780−20,528+28)，全部主体在x≤1760 landward；右向应另画，不能默认镜像同样光照。岸肩可跨相邻模块组织，位置从真实bank union读取。**若完全放在旧矩形后会不可见；不能再次把隐藏Sprite算成功。** 应由scene-composer选择“实体内部表面覆片+下裙”或“独立后方崖肩”：前者只在真实实体内可见且不动站立边，后者距玩法层更远并有清楚冷暗断面；不能跨船道盖旧直角制造新的站立面。旧矩形边若仍完整露出，结论是构图/地形轮廓仍未解决，不以新资产存在自称修好。

层级：近岸接合有效z=-3（地形-1之后/玩家之前），世界锁定无视差；独立后崖有效z=-12左右，可有微量视差但不与近岸共享接点。不得把同一个接合件一边锁岸一边0.12视差拉开接缝。alpha外缘自然破碎；内面实心，不允许穿全高的透明直缝，不要求整个alpha为矩形。透明处不保留灰色背景；无柔光外圈。纹理颜色以v8为锚，岩身暗面对玩法边明度退让。

其他镜头首试尺寸：草原后崖W850/H220world（屏1360×352），风车基座W520/H170（832×272），营地后裙W440/H180（704×288），Boss侧翼W380/H220（608×352）。这些为本轮设计候选；只可因真实场景重新推导锚点，不能照抄溪谷坐标。坡肩不可在唯一落点上方伸出水平草顶；角色可碰区域必须由正式碰撞面决定。

### B：维修石木横构 / 桥梁承接（优先2）

用途：风车维修院的低厂房与传动梁、钟庭的横向残垣、营地桥侧桁架与工作间、Boss场后方的旧风车检修环。使用奶白石基、深旧橡木、少量哑光黄铜接头，主轮廓横展、垂直支点不等距；避免每个模块重复一扇门。

首件完整侧视“维修桥侧结构/低工作间后身”，源1536×1024 RGBA；主轮廓约x48..1488/y100..950，W:H约1.7–2.0，底部完整支点。世界首试W580/H330（屏928×528）；营地只取完整构件的小规格W450/H255，而不是裁掉脚。斜梁/屋檐高处必须倾斜或破缺，没有齐平亮草台面。所有可见楼梯/可走门洞删除；窗是暗小窗，不能读成新通路。营地商店处后方留透明或低对比空区，不遮实际摊位轮廓。

锚：结构两端真实支座的脚点，不以屏底为根。营地桥约屏x0..587/y439..471，应把侧梁放在木桥后侧/下侧，支点落在真实岸/静态岩岛，主梁低于站立线28world；**若没有两个真实支点，则只用单侧伸出的检修廊/独立远楼，不画实支桥墩。** 风车支点来自真实台地；钟庭横构远于路径，由完整远侧石基支撑而不是悬挂在单向桥。有效z=-8..-12，透明边自然，近脚世界锁定；远屋独立视差0.08候选，必须与接点解耦。禁止拉伸横梁、反复端头和色调修正掩盖裁根。

家族变体：低工作间后身、单侧斜撑、双岸桥侧梁、破损钟庭横垣、Boss检修环半弧。首件合屏过后才按同母版生成变体。它们共享接头/石基语言，不共享同一剪影。

### C：远层树脊 / 残垣横带（优先3，可先复用后生成）

用途：开放草原的暗树脊、风车后围篱、钟庭远侧残垣/偏心钟盘、Boss中央背后的低谷。世界W1100..1500/H180..300（屏1760..2400×288..480），纹理远小于玩家，视差候选0.06..0.10；不会像当前panorama随屏漂移的同一山桥一再居中。透明上轮廓不规则，下方须完整延伸/在实际地形后隐藏，禁止硬水平裁底出现在天空。首批不为它占图生：现全景继续作极远世界尺度，先用A/B构出有效局部空间，再看是否仍缺。

## 统一采样/alpha/动态要求

1. 源图保留真实tool结果与原字节；alpha≥2/128/250分别测bbox与透明沟槽，报告尾部差异。严格透明/半透明尾部与GPU halo不是同一结论。自然外轮廓允许凹凸和洞口；不能以“矩形alpha完整率”否决全部非矩形资产。
2. 首图独立透明物体，不用多图atlas赌切片。外边留可测padding，生成目标16..48px；不允许主体截断，内部不允许意外全高切缝。无拼接线、标签、棋盘、投影地板和外光晕。门洞/负空间必须alpha0，不画假天空色底。
3. 等比缩放，运行linear/filter_clip按正式消费者真实验证；未GPU合屏前不判通过。输出中漂亮的RGB预览底不等于实际alpha有底。
4. 以现zoom1.6的1280×720正常尺度，核对角色、弹道、危险、铃、奖励及HUD；原保护区是候选，实际alpha/运动仍需看。接合件不得漂移，远物才视差；风草/布/铃共用风场但岩/建筑不摆动。静态大形成立再交animation-vfx。
5. 每空间三窗口：进入/经过/回望；溪谷至少22/32/40秒同条件，钟庭需上升/回望，Boss需预告/攻击/换阶段。未验证的规格保持proposed，作者不签自己的最终独审。
