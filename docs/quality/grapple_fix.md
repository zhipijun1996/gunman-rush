# GRAPPLE-FIX-01：短钩索、小跳与移动目标

用户本轮要求基于最新分支并行修复三项钩索问题：射程约为一次反冲位移的1.5倍，抓取后只需轻微斜上小跳，钩中向右移动的敌人与其他方向应一致。基线为 `feature/production-capability-repair` 的 `9ffe8e7c7d299a2d9cf710287c6c07e8c04b8385`；修复分支 `fix/grapple-range-and-moving-target`，不合并 main。

采用仓库 `game-quality-gate`、`project-integration` 与只读 `gameplay-reviewer`，按已有能力的小修验收。实现分别由移动目标、参数、回归测试代理承担；独审代理不修改实现。

## 行为与验收

- 默认单次空中反冲为 `1100 × 0.14 = 154px`，唯一运行资源 `resources/player/traversal.tres` 将钩索射程设为 `231px`。辅助瞄准、发射、命中距离检查共用现有同一字段，不扩大头部探测允许的最远接触点。
- 弹离使用完整 `hook_kick` 向量 `(240,-240)` 与 `0.10s`，横向及上升各 `24px`；维持从来向一侧45°弹离。原每轴约120px。基础跳跃、重力、武器反冲及能力授予不变。
- 拉近每帧只向唯一 PlayerMotor 请求速度，在该 Motor 步完成后的 `after_move` 判断抵达。原逻辑在下一帧才判断，逃离方向的目标会先移出停止圈，造成持续追赶直至超时。结算保留原伤害事件 ID、目标有效性及身体接触保护，进入接触阶段后不重复伤害。
- 30/60/120Hz 下验证左右两侧、敌人迎面和逃离的真实 EnemyActor/AI/Motor；验证一次伤害、同帧抵达、镜像弹离和实际小跳位移。保留近失准辅助、超距未命中、墙阻、目标死亡、360°、地面出钩、续航恢复和取消检查。

## 既有测试迁移依据

`actor_actions_runner.gd` 的原300px锚点移到210px，抵达峰值相应平移90px，保留逼近目标至50px内及45°弹离、真实地面出钩等原断言。续航链的敌人初始偏移200px改70px：实际向右射击先把角色向左反冲154px，原场景的再钩索距离超过新上限；新场景仍完整经过真实子弹伤害、D/H恢复、再次出钩、接触、小跳。`action_budget_runner.gd` 的近失准目标从固定260px改为实际射程减8px，保留扩展头部捕捉与墙阻性质，并新增范围外反例。

历史H-only森林开发路线依赖旧长钩索与大弹离，不是正式开放地区。本任务不重做其生产布局；其兼容回归须明确冻结历史参数、准确标注实际资源路径与哈希，不作为默认短钩索路线证明。原路线和反例不得删减。新接触事件发生在 Motor 后，原因果检查必须按明确的接触阶段识别其真实坐标，其他事件继续保留原时序约束。

实际命令、失败链、独审和结论见本任务质量记录与 `docs/evidence/grapple_fix/`。用户手感及实体设备保持未验证；实际GUI范围见下文。
