# 可变形状地形：邻接、素材与验收

状态：候选；上一版边框拼贴已被用户和独立审查拒绝，正式地形已撤回到本轮基线。不得用本文件或拓扑测试声称画面获认可。

## 研究依据与适用边界

2026-10-13 阅读以下实现文档，借鉴自动拼接方法，不复制商业游戏素材或假称研究过其私有实现：

- [Godot TileSet terrain](https://github.com/godotengine/godot-docs/blob/master/tutorials/2d/using_tilesets.rst)：区分匹配边、角、边与角的 Terrain Set；变体不能破坏连接条件。
- [Tiled terrain sets](https://github.com/mapeditor/tiled/blob/master/docs/manual/terrain.rst)：两类角标记可有 16 种，混合边角可有 256 种；不是所有规则都能用九宫格覆盖。
- [Blob / sub-blob tiles](https://www.boristhebrave.com/2013/07/14/tileset-roundup/)：单一实体/空域的八邻接可归约为 47 种；四个象限各使用外角、两种边、内角、填充五类局部配置。
- [Unity RuleTile](https://docs.unity3d.com/Packages/com.unity.2d.tilemap.extras@3.0/manual/RuleTile.html)：邻居条件与规则顺序用于自动选择，不等于素材已经无缝。

47 是本次**单一实体材质的局部边界拓扑**，不是所有游戏地形的全集。不同材料相接、悬浮木桥、单向平台、坡面和超出一格的外轮廓需要各自契约。不能用土墙代替应可穿越的木桥，也不能因为视觉裁切改变物理。

## 形状和连接契约

- 基准格 32 世界单位、材质源 4 像素/单位。每格判断 N/E/S/W/NW/NE/SE/SW。相邻两条直边不同时存在时，相应对角位不影响该实体的内凹边界，256 种输入归约到 47 种合法形态。
- 同时支持单格、单行、单列、多行、L/T/十字、台阶、孤岛、内凹角和洞口。不能仅画上边和左右端头。
- 1×1 是完备兜底；1×2、2×1、2×2、4×2 是画面分块，不是改变碰撞的工具。宏块覆盖的每格仍保留自己的邻接 ID；不能跨空格或覆盖洞口。可扩展尺寸，但超出着色器局部预算应拆块。
- 每条接口的坐标、材质相位、笔触尺度、颜色、法线方向与 alpha 约定一致。变体只改变接口保护带之外的内部；不能让多个独立生成的整平台图依靠拉伸、镜像或遮盖“碰巧”拼上。
- 草只沿朝上的外露表面生长；相接内部不重复草帽。左右侧壁、底边与内凹角按同一光照方向解释，不能旋转带方向的完整纹理充当四边。
- 正式地图包含非整格和极薄碰撞体。后续适配必须在实际边界裁切；本轮候选 gallery 尚未证明这种正式适配，禁止改变碰撞尺寸对齐网格。

## 当前真实消费者

`resources/art/plains_tile_catalog.json` 由 `tools/terrain_tiles.py` 产生，Godot `PlainsTileComposer` 实际读取并为每个绘制块记录其 mask。母版 `assets/plains_v7/meadow_tile_material.png` 被运行时 shader 共享采样；绘制分块改变不应改变采样相位或显露边界。

入口：Development Demos → Module Lab → More Trials → Terrain Tiles。SHAPES/47 MASKS 展示组合与全集；MACROS/1x1 ONLY 对照同一几何的不同分块。这里只验证素材组合，不代表正式探索已接入，更不代表可玩路线通过。

母版仍是候选。共享边界保证连接的一致性，不能自动保证美感：过硬轮廓、明显重复、糊边、草土比例、手机缩小后的落点辨识必须看实际画面。新变体先做黄金合屏，经用户认可后扩产。

## 可复现验收

| 场景 | 方法 | 可观察通过条件 | 失败 |
| --- | --- | --- | --- |
| 全部八邻接 | 枚举 256 输入及 47 输出，运行时与目录对照 | 合法映射、直边不丢、每种有消费者 | 漏形态、未知 mask、角盖住洞 |
| 小形状及孔洞 | 307 种 1–6 格固定形状，加环与非矩形孔；不同宏块覆盖 | 每个实体格恰好一次，空域保持 | 漏格、重复、填洞、改变几何 |
| 分块不变性 | Godot 同图切换 1×1 与宏块，GPU 截图像素对照 | 地形区域像素保持；UI 标签除外 | 块界细线、草帽重现、纹理跳相 |
| 可见边界 | gallery 单行、多行、L/T、阶梯、洞、孤立列 | 外露边清楚，内部接缝消失，内外角一致 | 接缝凸起、底边当顶边、细块被角片覆盖 |
| 正式合屏 | 实际随机地图、真实角色与镜头，多长度/厚度/相邻模块 | 画面统一、身体与可站面吻合、危险可读 | 仅 gallery 好看、落点偏移、装饰掩盖边缘 |
| 主观及设备 | 用户看黄金合屏、正常速度视频、目标设备 | 有实际认可和测试证据 | AI 自评代签、构建代性能 |

失败保留截图与源版本，回到素材/连接/导入/GPU 对应步骤。自动测试与人工审查分开；不得给“漂亮”编造分数。
