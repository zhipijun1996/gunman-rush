# 人物动作实现合同（ACTOR-ACTIONS-01）

2026-10-13 用户授权按完整skills/harness实现现有人物动作；武器本轮仅普通枪与Lv.2三连机关枪，并明确包括二段跳、爬墙跳、钩索。用户要求连续美术动画。参考空洞骑士的动作节奏而不复制角色、素材或运动参数。基线37c2153，规划PR64作为依赖保留在本分支，不合并main。

## 正式范围和设计

Courier共享正式Player场景新增可授予H/W/D；基础枪不改变默认射击/物理/资源，三连一次包一次空中资格与一次精力费用，包内命中返还上限一次（首轮候选政策）。三连每次读取有效新方向、三次独立弹体和短反冲；碰墙/顶、受伤/死亡/取消终止后续段。

H只横向飞行，命中带grapple_target标签对象才拉近；必须通过唯一Motor碰撞、接近后前上踢跳，不补射击/二跳。W只在wall_climbable安全墙，离墙至少5px且间隔0.12秒后真实接触才能再蹬；不刷弹药。D沿已有JumpAbility次数与第二速度，新增独立羽翼动作及声音。

新能力/机关枪首先通过主菜单ACTION STUDIO实际装备/授予与输入可玩；正式平原默认一跳/普通枪不自动升级，不新增未经设计的地区奖励。共享运行消费者真实实现不等于六阶段授予/存档迁移完成；这一正式成长系统仍后续规划。

盘点全部实际人物：Courier、家园实际Artisan（其他NPC未显示）、巡逻甲虫及charger/sentry/hopper/diver/fan_sentry、开发guard/moth、ClockworkGuardian（历史开发）、Bellstrider、Windkeeper。敌人/Boss保留既有AI/攻击/伤害与生成池，补齐可读动作过渡和身体连续形变；开发人物不冒充正式遭遇。

## 动作表现

新手绘24姿态扩展同一Courier母版，测量每格脚底/肩轴、透明边与一致尺度，独立武器握持；状态转换保留上一帧并平滑接入，连续重复射击独立反冲包络，落地恢复/受伤独立动作，羽翼不可只用白粒子。墙贴/蹬出、钩投/拉近/踢跳及二跳均有专属姿态、尾迹/碰撞事件反馈与声音。暂停/慢时/死亡对应玩法时钟，中断不重播旧事件。

## 验收

新actor-actions专项通过真实Controller/Motor、三端输入、资源账本、阶段取消、同墙/双墙、钩命中/失效/阻挡、二跳/缺能力与30/60/120Hz正反测试。连续正常速度带音轨录像及逐帧事件/锚点分析；所有实际演员在同一可玩Studio及正式入口分别核查，不能用单图或直接搬人物证明运动。运行gameplay/art/web相关profile，既有断言不删。
