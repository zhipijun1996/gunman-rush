# 空中动作恢复与试玩更新（AIR-REFILL-01）

2026-10-13 用户最新明确要求覆盖 ACTOR-ACTIONS-01 的“不补二跳”旧合同。基线9c9b156，继续feature/complete-actor-actions；更新现有GitHub Pages试玩，不合并main。

已授予D时：成功蹬墙跳、H命中合法目标并完成Motor拉近/前上踢腿小跳、空中发射的子弹对敌人实际提交伤害，各恢复空中额外跳跃资格。恢复后used_jumps=1，保持原有最大跳数来源；不赠送地面第一跳、土狼时间、能力、速度或新的输入。普通二段跳有且只有一次可用资格，立即使用仍播羽翼动画。

已授予H时：空中接受发射消耗一次；落地和上述三个成功事件恢复一次，不叠加。空发、阻挡、目标消失、暂停、换枪、受伤取消、失败蹬墙均不恢复；地面可重新发射，真实新Actor session重置。贴墙本身不恢复，必须接受蹬墙动作，仍要求真实离墙/重贴。

子弹必须由既有Damageable提交伤害后通知；敌人阵营enemy（含Boss有效核心），仅墙碰撞/护甲接触/非敌人目标不算。射击时在空中且回调时仍离地才恢复；旧session、已死亡、同一子弹重复回调无效。三连每一实际子弹可恢复移动资格，原包内射击精力/弹药返还仍最多一次，彼此独立。

唯一PlayerMotor继续每物理帧最多一次位移。恢复不取消当前上升/后坐力或吞掉下一跳输入，不自动补射击弹药。Studio真实共享组件显示钩索/跳跃剩余次数；正式平原默认仍普通枪/一跳，未授予能力不能借命中获得D/H。

验收：30/60/120Hz真实两跳→空钩失败→实弹扫掠提交敌人伤害→再次羽翼跳→再次钩索→拉近踢跳，记录成功及失败；旧session/地面发射/非敌人/重复回调/未授予/暂停和实际反复蹬墙边界。边界状态初始化单独标注，不能冒充真实路线。初次新增测试在0.32秒就断言钩拉已完成，实际仍在牵引，因此失败；改为完整0.6秒观察窗，不缩短动作或删除断言。原失败日志保留。

发布：沿用tools/publish_playtest.py，冻结推送后由CI重新gameplay/art/web再Pages部署；核对线上build-info的source_commit和真实桌面/触屏GUI。独立审查、真机和用户最终手感仍未验。

网页首次/二次检查发现旧测量把跟随镜头下人物屏幕位置当世界位移（实际地形平移108px），以及暂停后80ms仍可能截取旧渲染帧。保留失败；新增静态地形纹理配准还原镜头位移，仍要求实际世界移动超过原3px门槛；暂停先等待500ms渲染稳定，再保持原零位移断言，错误日志拒绝不变。
