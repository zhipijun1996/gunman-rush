# 空中动作恢复

恢复只作用于已经授予的能力，与射击弹药结算分别处理。实际参数和授予来源见 [资源合同](../combat_and_recharge.md) 与 [流程](../run_and_routes.md)。

已授予 D 时，成功蹬墙跳、H 合法命中后完成 Motor 拉近／踢跳、空中发射的子弹对敌人实际提交伤害，各恢复一次空中额外跳跃资格。恢复后 used_jumps=1，最大跳数仍取原授予来源，不赠送地面第一跳、土狼时间、能力、速度或输入。

已授予 H 时，空中接受发射消耗一次；接地及上述成功事件恢复一次，不叠加。空发、阻挡、目标消失、暂停、换枪、受伤取消和失败蹬墙不恢复。贴墙本身不恢复，蹬墙仍须真实离墙／重贴；地面重新发射与新 Actor session 按生命周期重置。

子弹须由既有 Damageable 对 enemy 阵营提交真实伤害，包含 Boss 有效核心。仅墙碰撞、护甲接触或非敌人目标不算。射击时和回调时均须离地；旧 session、死亡和同一子弹重复回调无效。三连各实际子弹可恢复移动资格，攻击包内弹药返还的去重与上限另算。

唯一 PlayerMotor 每物理帧最多一次位移。恢复不取消上升／反冲，不吞下一跳输入，也不自动补弹药。Studio 显示剩余跳跃／钩索资格；正式角色未授予 D／H 时，命中不能生成能力。

验证覆盖 30/60/120Hz 的真实两跳、空钩失败、实弹命中、再次羽翼跳与钩索／踢跳，并保留旧 session、地面发射、非敌人、重复回调、未授予、暂停和重复蹬墙反例。完整观察动作时窗；状态初始化 fixture 与真实连续路线分别记录。正常速度音画、真实网页输入和实体设备／用户手感按实际证据验收，发布沿独立手动交付流程。
