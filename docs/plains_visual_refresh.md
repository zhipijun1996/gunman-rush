# 平原可见远景与交互物精修候选

本轮用户要求自然的多层平原，而非全灰天空；金币、音符、门、荆棘和敌人使用原创生成素材。品质权威仍是 [art_quality_target.md](art_quality_target.md)，来源与文件摘要见 `assets/plains_refresh/manifest.json`。这些是待视觉评审的运行候选，不宣称用户已认可风格。

## 实际素材与使用

`image_gen.imagegen` 实际生成透明对象图集：风铃花金币、淡紫黄铜音符、藤叶花朵石木门、浅色锐刺荆棘，以及左右朝向橡实甲虫。另生成三条透明平原远景：远丘、风车遗迹田野、近处花草；模型再次编辑背景清理浮空杂点。PNG 原样保存，未以 Python 修改图像。Godot `AtlasTexture` 仅在运行时裁选区域；没有把程序几何画成的占位称为生成美术。

背景使用原有天空与三条新景层，水平运动比例分别为 0.03、0.12、0.30、0.50。田野轮廓绑定屏幕地平线，避免相机升高或透明画布居中后只剩天空；垂直漂移有界，天空仍覆盖可见视口。自然橄榄绿、暖金、灰蓝保留，通过不同远近的饱和度、雾色与轻模糊压低对比。图集边缘未经无缝循环认可，因此采用有限、有界漂移，不声称无限背景。首次实际 GPU 合屏暴露景层底缘水平露天空缝；已在 shader 中夹紧图集区域，保持上部绘画原高度，将下缘田野延伸到视口外并渐隐，二次 GPU 确认天空缝消失，但发现延伸像素形成竖向拉丝；下缘已改为渐变到各层匹配的柔和雾色，不再延续纹理列，结果需新包 GPU 复看。

金币缓慢翻转、音符浮动摆动；门随可用状态调整明度；甲虫有小幅姿态浮动和实际扣血闪色。这些为程序动画，未宣称已有完整手绘动画帧。它们只读关卡资源/完成状态，不决定领取、伤害或切关。荆棘仍使用原危险矩形，不扩大碰撞、不改变伤害结算。

## 验证界限

`tests/painterly_skin_runner.gd` 检查四层实际贴图、相机极值覆盖、层速度差与田野屏幕可见区；具体通过日志由本轮交接记录提供。真正视觉验收需要 GPU 合屏观察：丘陵、田野、花草是否清晰可区分，两个图像边缘是否出现残留彩色光晕，金币/音符在手机缩小画面是否可读，荆棘是否清楚表达危险。

实际浏览器 GPU、真机性能和用户视觉意见分别记录，不能以图集生成成功代替。若需要最终动画帧、敌人更多动作或无缝景层，将作为下一次素材迭代；本轮不改变已有敌人 AI、碰撞和运动政策。
