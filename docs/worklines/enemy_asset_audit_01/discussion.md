# 验收机制与生产流程：一起讨论，尚未生效

用户已拒绝上一轮制作质量。当前先完成资料／素材盘点，没有生成新图、修改生产代码或重写skills。这份文件用来讨论下一步，不是已经确定的新门槛。

## 先纠正这轮偏移

我把“完善所有现有怪物”收窄成了“给现有图增加程序动作，并录齐事件链”。网格、源追溯、真实伤害、保存和录像交付确有工程产出，但它们没有回答每只怪的造型、动作和反馈是否足够好，也没有拦下全体制作质量的参差。

[补充复盘](review-postmortem.md)区分了两类问题：

| 原本已有、应先执行的要求 | 这一轮发生了什么 |
| --- | --- |
| 反查最终身体绘制叶及替换分支 | fan的实际身体、原scene是否走mesh都与制作卡不一致 |
| 先看正常速度完整动作，再定位逐帧问题 | 主要靠抽帧和局部crop验裂口／锚点；未完成全体正常速度成品质检 |
| 先完整黄金样板，再用第二类运动／体型验证复用 | 样板动作质量未完成验收，已铺到全体；有样板文件不等于具备扩产条件 |
| 真实角色尺度、正式合屏及物种差异 | 同母版／有纹理／旧Boss换图被过快视作问题关闭，缺全体横向品质比较 |
| 实现事实与验收结论分开 | “事件齐全”“0gap”“局部ACCEPT”形成了过强的整批接受信号 |

这些不能靠增加一轮测试数或把用户最终审核列为未验来补救。原测试仍要保留，用来防工程故障；艺术与动作判断需要真正执行。

## 需要一起决定的几个问题

1. **目标是什么样，而不只是不能有哪些Bug？** 从现有素材／游戏中选一个接近目标的正例和一个反例，标明为什么：轮廓、材质、像素密度、比例、发力、节奏、反馈。若现有怪没有正例，可以以已采用的玩家／场景或明确参考为目标，不勉强把一只现有怪称黄金。
2. **哪些身体保留，哪些重做？** “来源合法”“同一张PNG”“不换形”只是事实；不是保留理由。共享家族可以合理，但需要明确每只怪的可辨身份、角色尺度及机制对应。旧Queen2×是否可接受，也应由实际效果决定。
3. **每个动作适合怎样制作？** 单图程序动画、分层关节、关键姿态／逐帧或混合都可选择。需要改变轮廓、前后遮挡、抬脚／换支撑、翼面翻转时，若现图没有这些结构，就得补素材；不能默认单图网格足以覆盖全部，也不为追求帧数机械重画。
4. **怎样才算专家验收，而不是让用户找常规问题？** 建议必需的动作先完整正常速度观看，再用局部连续帧核边界；同屏看承重、蓄势、释放、恢复和反馈。审查需写出具体好／坏理由。看不完或没有所需片段就缺验；效果不好就退回对应工序，不能“有限ACCEPT＋大量尾注”带过。
5. **何时扩产，何时需要你看？** 原规范有黄金先行，但没有统一规定所有授权内黄金都必须先等用户确认。是否在这轮质量重建中改为“先共同认可一只完整怪物，再做第二运动类型，之后才批量”，需要我们一起决定；不应倒写成过去已有的规则，也不需要让你批准每次普通修补。
6. **制作卡怎样才有用？** 建议保留原G0–G5和四态，用现有逐怪卡直接呈现：当前采用的设计、身体母版、所需姿态／动作、正在用与未用的素材、已见问题、下一交付及退出条件。由skill整理，不让你填表；不另建平均分／总完成率去掩盖最差一只。

## 可以讨论的生产次序

资料与真实消费先对齐 → 选一只作为目标样板 → 先看静态身体及真实角色尺度 → 设计关键动作并选择制作方法 → 完成该怪完整动态与声音／特效合屏 → 做明确的正反例复审 → 验证第二运动类型 → 才考虑扩到其余物种。

这只是建议。第一步先决定“哪些现有东西值得保留，什么才算达到目标”，再修改skills和具体退出条件。当前不继续全体关节化、不默认把未用旧格接回、不默认再录更多全量影片，也不把本次资料盘点当新成品通过。
