# 七怪制作卡与复审目标

本卡属于 `PLAINS-MONSTER-REVISION-01`，按用户本轮逐怪意见制作。下列全部是目标／待验项，不是通过结论；实际状态回填同一[质量记录](../../quality/records/PLAINS-MONSTER-REVISION-01.json)。原怪物机制、伤害结算和已选地区方向继续作为输入。

## 共同复审项（对应原 E03–E11）

1. **真实比例与碰撞**：回正式平原，用同屏玩家、未改尺寸俯冲及新怪比较；记录原可见体／新可见体尺寸与倍率。脚底、头胸、前角和核心主身体的碰撞边界对应画面；不把源 PNG 大小或翼展外缘直接当身体碰撞。
2. **统一细像素粒度**：执行用户追加“像素粒度要对齐整体美术”。与玩家、地形及俯冲同屏核1wu采样／nearest、轮廓锯齿尺度和高光密度；不能把高分原图存在当粒度已对齐。新 shader 的实际 GPU 画面另验。
3. **去血量与辅助线**：普通怪在满血、受伤、攻击、恢复、死亡和重入都不显示血量；去纯瞄准／路径／状态线。Boss 仅去辅助显示，保真实危险实体。用正常游戏尺寸确认主动怪的蓄势、出手、收招能单靠头／躯干／肢体读出，不能因移除线而留下不可读攻击。
4. **同体连续与中断**：移动→受伤→当前合法动作；蓄势／出手／收招各阶段受伤；连续命中、转向、左右、空中、慢时和暂停恢复。母版、锚点及身体身份连续，不用换成另一物种帧、光晕或粒子遮接缝。
5. **失力、落位、退场**：致死立即停止生成攻击、撤掉关联预警；已有归属攻击按原取消规则清理。死亡身体与装饰碎片无伤害。需要落地的先找到真实支撑，再完成落位和停留／淡出；冲锋与俯冲稳定留尸，末态无循环摆动、闪烁或再次死亡。
6. **生命周期和声音**：暂停冻结原时钟，卸载清资源；当前保存／回退恢复不重播死亡、铃声、攻击或奖励。低铃声跟随实际落铃接触，而不是以有音轨或通用 defeated cue 代签。实际声音及对象清理各自记录，未听不得签听感。
7. **交付与认可**：保存带原音轨的正常速度连续影片、动作事件和当前源；工坊按具体怪／动作／版本复审，历史意见不覆盖。独立专业审查与用户、实体设备认可分开，保持 review／unverified，直到各自有真实证据。
