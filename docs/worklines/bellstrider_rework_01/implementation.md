# 鸣铃巡游机：本轮实现说明

最新反馈修订见[第二轮](review_02.md)：投铃跟瞄0.35秒、锁点0.35秒，飞行1.10／1.27秒并配合1935重力；精确接触覆盖真实车壳和轮组。下方为上一审核候选的实现说明和原证据范围。

本轮只改鸣铃巡游机。用户完整要求与可证伪验收见[制作卡](spec.md)；原16HP、整车可伤与固定轮换作为历史保留。当前是待同源实机审片的候选，不代表用户或设备验收。

- 血量40，20进入第二阶段；当前招组完成后升压。出招由自身时钟和距离／高差／站位停留／近招历史驱动，命中与回合数只用于统计。
- 巡游机过远先追近，再选攻击；180wu/s追近有加速，冲锋380／420wu/s、0.22秒加速、最长1.35秒。回冲在第一冲前确定，第一预警有双拍与不同压重姿态。
- 主风铃的摆动、绘制与真实受击Area同用Rig。铜壳使用与画面同源的凸多边形，左右轮有各自圆形装甲，身体接触随承重姿态变化；上端风铃不受旧方向门槛限制。
- 主铃与装甲共用一份Health与帧结算，装甲只挡弹并反馈。弹体／光束／范围与实体武器／物品／钩索均保持真实来源、session、epoch和去重；范围效果先排除装甲，再记目标或冷却。
- 铃波每次敲击与真实波、声音同步。投铃由独立发射器先跟瞄，再锁0.35秒；实际出口与抛射方向对应发射器。高台弧线1.65秒，较低落点1.9秒，减少提前撞台；实体平台仍能提供真实遮蔽。落地局部震荡的绘制厚度与14wu伤害体一致。
- 致死立即撤攻击和接触，1.8秒完成卡滞、侧沉、架体折落与熄灭；1.05秒主撞击喷出现有12元奖励。5／5／1／1沿原重力、弹跳、吸附、逐枚领取和保存账本结算；门户不再重复发币，原+1回血与后续关卡链保留。未拾完金币时不自动弹出挡路的离场框。
- 新音效沿现有12声部池，关键预警优先，普通命中限频；原已选受伤A和BGM不变。暂停清理仍释放失效所有者的资源。正式重载同步边界重新绑定当前Health epoch，终态只接续未来的失效声，不重播已经发生的死亡。

验收分三层：组件与受控App回归；正式App中自主Boss与合法输入玩家的连续实战；用户对动作、听感和操作体感的审核。自动输入、一次初始入场准备与晚撤对照会在影片和工坊中标明，不替代人工试玩。

所有失败原件保留在本轮开发证据：包括旧身体可伤断言、JSON计划类型恢复、暂停音频异步混音观察、终态重播、提前离场弹框以及早期自动玩家失败。通过之后的新记录不回写旧失败。
