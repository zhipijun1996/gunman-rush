状态：实现中，尚未验收。接在 CHEST-ART-01 后，不重复生产道具美术。

现有 `ItemCatalogV5` 的 JSON/Resource 目录是只读道具数据库，保存定义、参数及效果组件；不另引入 SQLite。`home_items.json` 只管理家园可用性和可调音符价格，玩家存档只保存发现、永久解锁和下一次携带选择。未知／下架 ID 保留历史但不允许新解锁或携带。

开放原家园 `relics` 位置，不替换成就档案。未获得条目只显示问号，获得后显示独立图标及实际数据。默认需曾获得再用音符永久解锁，可配置；该项已向用户征询，未回复时采用推荐默认。价格蓝5／紫12／金25为实验值，可逐 ID 覆写。

仅正式奖励／购买 COMMITTED 收据及成功出发入包记录发现；浏览、装备、修理、幂等回放和地图重建不创造获得记录。永久音符扣除、解锁和携带选择复用原存档原子提交和交易账本。失败不留下部分更新。当前保存版本显式升级，不静默丢弃图鉴数据；稳定 Web key 保留以加载原存档。

已解锁道具可以单选一件，也可不带。每次新局只加入一个 Lv.1 实例，来源带当前 run 唯一 ID，不自动装备，不消耗永久解锁。切图、环境回退不再次发放；真正结束清理局内实例，永久图鉴与选择保留。武器、核心能力、齿轮与背包职责保持独立。

图鉴打开暂停家园，PC／手柄／横屏触控复用主题、字体与滚动组件。所有购买和选择验证当前 Home、窗口焦点、会话和档案 revision；关闭清空输入，过期按钮不能提交。
