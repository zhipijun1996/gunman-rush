# 区域上下文

确定区域时，从锁定的世界版本提取它的房间、边界门、授予与回访条件，按区域主题选取材质与物种。施工和验收以真实来向、实际绑定与宿主中的表现为据。 版本与导入方式见[世界输入](../data/world/README.md)。开发入口为[普通房间制作](../bible/room_authoring.md)。旧地图和房号可在[冻结版本的区域上下文](https://github.com/zhipijun1996/gunman-rush/blob/4f2bb5e41573e930603789c64b52a0c15a6a3dc4/docs/project/region_context.md)查阅。
