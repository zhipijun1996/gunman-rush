# 怪物审查方法

新物种重点审查美术统一与玩家体验，以下项目按本次范围选用；局部修复和规则调整只验证实际影响。对象规范描述完整设计，检查结果留在工作线。Boss按需要观察招式组合、阶段和场地。

| 项目 | 完成所需的实际内容 |
| --- | --- |
| E01 设计 | 职责、玩家判断、反制和地区联系明确，符合合法进入构筑 |
| E02 行为 | 接敌、移动、预告、攻击、收势和失去目标成立，墙／边缘／安全区可应对 |
| E03 身体 | 比例、材质、肢体和功能色统一，在正式镜头可读 |
| E04 动作 | 相关状态及进入、退出、中断有完整表现，静止状态也有明确设计 |
| E05 连续性 | 移动／攻击到受伤及回接、致死到终态、转向和连续命中保持同一身体 |
| E06 命中 | 反馈对应真实结果，装甲、接受伤害与落空可分辨 |
| E07 死亡 | 威胁停止，演出、留尸或回收符合该物种设计，支撑／返回／保存正确 |
| E08 声音 | 预告、攻击、受伤、死亡及静默语义明确，正常速度实听可辨 |
| E09 遭遇 | 在真实地形、同伴、机关、资源和镜头下有可行反制与恢复 |
| E10 接入 | 正式对象、表现、资源与生成选择一致，暂停／回退／重入／旧请求无重复结果 |
| E11 性能来源 | 资产、许可和资源可追溯，对象峰值、回收和目标设备预算有实际依据 |
| E12 验收 | 实际检查与观察有依据；仅本任务明确需要的用户／设备／独审列入验收 |

结果用 passed／failed／unverified，有实证才判失败，不适用项省略。共享组件、Lab或局部样板通过不自动覆盖整物种。按实际方法保留正常速度音画、真实输入、反例和来源，未知不代签。
