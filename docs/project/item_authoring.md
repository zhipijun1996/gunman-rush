# 道具配置维护

道具设计见 [具体数据](../data/items.md)，配置在 `config/item_v5_*.json`。修改行为先整理对应设计，再改配置与实现，同一任务完成同步。

## 编辑

沿实际 ItemCatalogV5 与 authoring 读取已有身份、等级、通道、标签、能力条件、互斥、外观及出现权重。编辑现有条目、下架或新增时保留稳定 ID，核当前运行消费者支持的字段；不靠显示说明虚构效果。

运行覆盖、下架与元数据通过当前配置入口处理，资源默认与覆写优先级由真实加载器决定。新增图标和特效要有实际消费、来源与许可，独立未用素材不计为接入。

## 验证

从 [模块导航](module_map.md) 选择相关库存、装备、经济、成长及协同专项，覆盖购买／领取去重、切换、回退和载入。真实界面检查名称、图标、等级、说明与收益一致；未启用条件和未决规则保持明确。

P17、协同候选和当前待验内容从 [活跃任务](tasks.md) 进入。配置说明只规定当前编辑方法，逐轮实现与截图结果归工作线。
