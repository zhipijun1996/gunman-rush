## 最终行为

P20退潮渠畔原先只用32单位薄壳包住房形，视觉实墙背后没有碰撞；用户确认沿闸门贴墙跳跃后进入空腔。现有外缘填充同时提供实体碰撞，门洞、平台索引、闸门和H支路保留；第二返程踏板改为安全侧96宽，不再伸入只有16净高的顶板下；(2200,400)等视觉实体内部不再可站立或被安全落点判定接受。

旧集死亡怪物落在多边形地形后，尸体记录使用ground_polygon支撑，但校验器原先拒绝该合法类型，使回血和出口整份提交失败。保存校验与真实多边形支撑恢复已对齐，未知或空ID仍拒绝；不绕过写盘、不删存档。正式世界地面怪失去支撑后由原EnemyMotor受碰撞地下落，飞怪和跃击有效攻击弧线保持原逻辑，独立森林运动不接管。

小鸡安卓版手柄出现东侧跳跃、LT开地图，不能由标准键号推断实体位置。设置提供南侧跳跃、东侧回复、LT跳跃、RT主动道具、View/Select地图五步校准；按下并松开后接受，扳机支持模拟轴或数字键，RT和地图可显式跳过。映射按平台／GUID／设备名保存，互斥输入拒绝复用，未校准设备／触屏／键鼠保持原规则；暂停、断连和保存失败不补交动作。具体规则归输入合同，项目不按品牌猜测型号。

Windows针对用户报告的P22风压引渠最大化闪烁，改为ANGLE／Direct3D和固定1280×720内部视口，房间光照和镜头不改。Windows专项直接启动受保护的发行EXE/PCK，通过已有隔离逐房入口进入P22；等待HUD出现后检查正常、最大化、还原和大窗口的真实桌面帧，正常关闭后严格检查日志。构建机显式使用Dummy音频，软件显卡检查不代签用户显卡或真实声卡。
