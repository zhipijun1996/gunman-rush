# 原生试玩问题修复

基线main／v0.1.0为`dec47408ce8b7c4b98c5e215c8a23db482bc7864`，分支`fix/native-input-room20`。本轮写集仅固定世界边界、必要输入与相应规范、验证和原生交付；不重部署关卡平台、不改角色动作数值或房间拓扑。

## 当前定位

P20截图显示角色位于上层东侧凹角的外缘黑色墙体中。实际物理点查询确认(2200,400)在视觉实体内却没有碰撞；旧外边界只有32单位薄壳，外缘填充仅有表现。修复让现有外缘实体分区同时参与碰撞，保留门洞、房间轮廓、机关及平台索引。实际进入方法仍待用户说明；新碰撞需验证真实门对和原有P20动作后才能发布。

安卓版的小鸡手柄被用户报告为东侧键跳跃、LT开地图。现行按字母标准键号和单一模拟轴推断实体位置不可靠，现设置提供五步按实体位置校准，按平台／GUID／名称独立保存；南侧与LT共用跳跃，东侧回复，地图必须独立或从暂停菜单打开。旧设置保持可读，键鼠／触屏及未校准手柄保持原规则；不猜具体型号、不对所有Back键强改跳跃。

Windows闪烁由用户进一步定位为P22风压引渠后、主要在窗口最大化时出现。本轮Windows改用ANGLE／Direct3D，并与Web一样固定1280×720内部视口，避免最大化直接改变内部渲染尺寸；不修改房间光照参数或镜头。原生工作流新增实际Windows图形窗口装载P22、最大化／还原／大窗口、连续画面和可见桌面截图。软件图形测试不等于用户显卡复验，根因尚不能宣称已由实际设备确认。
