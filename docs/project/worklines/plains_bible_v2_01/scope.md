本轮在 [PR150](https://github.com/zhipijun1996/gunman-rush/pull/150)、`feat/approved-platform-rooms` 接入平台r80导出的P10、P20人工初审稿；沿用已接入的33房。源基线为`ded9633df210060710d97d25fec908f7fd0c010b`。三方字段比较保留当前正式美术与输入。平台保持只读，不部署、迁移、采用或改写人工审核状态。Z01没有初审记录，仍不装载；平原小站教学独立于该外区，不发尚无法完成的调查任务。

P12西岸守箱巡逻怪按用户明确决定使用规范9血。P10／P20审批在r79完成，本次读取的平台快照为r80；更新审批指读取并实现已审核内容，不代替用户审批其他草稿。

巡游机P11掉落第一枚共用技能芯，树根T06原托座改为三联机芯；保留材料总量、后续技能层及既有所有权。P10武器匠免费消耗技能芯，沿唯一install_skill_core_1事务安装普通枪冰弹，未来G01同服务共用收据。
