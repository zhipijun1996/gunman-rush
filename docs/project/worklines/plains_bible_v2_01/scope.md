# 平原完整制作当前交接

## 目标与基线

接续 PR141@0e742706c59e3409b23c4536ba74f89af6a2146b，分支 `feat/plains-v07-complete`。本轮按用户授权整合两个 ZIP、关卡与美术 Skill，以 v07.1 的 309 房世界／35 房平原替换旧地图，制作 P-R01—P-R35。任务进度唯一见任务表。

原附件身份见 [世界来源](../../../../config/world/provenance.json) 与根 [美术入口](../../../../ROOM-ART-START.md)。世界主数据与 ZIP 最新版本逐字节一致；施工尺寸、真实门台、碰撞和对象摆放按实际控制器校准。冻结附件只供溯源，不生成第二套运行世界。

## 实现与所有者

- `config/world/world.json` 持有拓扑、分区和永久动作；`construction.json` 持有尺寸／门口／来向落脚／镜头；35 个手工场景持有实地形与放置。逐房用途、决策、压力、恢复、美术焦点见 [职责表](../../../../game/world/regions/P/room_design.json)。
- 正常入口为 FixedWorldApp。草坡—车厢—引渠—候车棚—望站坡组成渐进教学；小站、西侧检修圈、牧风者、钩索、修钟、三条捷径组成完整主循环。东侧串联风棚、风车、旧田、谷仓、矿口、旧集、汇口与钟影前庭；保留独立支路、安静地标和后续能力回访。
- 井中射击升降台、风车双承载、慢平台、七处奖励折梯、水岸回退使用真实碰撞／弹丸／搭乘。FixedWorldState 提交后才启动机关或播放成功表现；失败、卸载、死亡和重复请求不额外授奖。齿轮保存独立来源身份，交付与里程碑不生成免费数量。
- 新绘 16 组动画、17 件构件、4 套室内背墙，原始母版及机械裁切配方见 [SOURCES](../../../../assets/plains_v07/SOURCES.md)。回收者、织时匠、阿栖章节动作、充电站、齿轮／碎片／钩索／行装包、修钟／折梯／收集散光均沿当前像素风格。复用既有玩家／敌人／Boss 动作和声路由，水声来源明确。
- 阿栖按最新章节资格选择唯一宿主，谈话后留下布条、纸条或修补长椅；站位有实支撑，不强制谈话、不赠送主线能力。对话与服务使用同族面板、动态肖像和小屏文字；地图按实际探索显示施工房形与实体门口连线，是区域示意图。

## 实际验证与专业判断

所有验证使用锁定 Godot 4.7.2。`tools/run_world_loop.py` 统一执行世界专项：连续新档主循环、实际牧风者／巡游机、各类奖励获取、真实展开返程、东侧连续片区、能力反例、全部来向落脚、事务／服务／损坏恢复及独立进程重启。连续新档主循环不传送、不预授能力、不写主线进度；其他指定入口／能力测试均明确标为夹具。

已实际通过：日常 CI 四项、世界图路线与施工检查、整区专项、35 房原生窗口截图、960×540 对话、独立 PCK 的 35 场景实例化。原生窗口完整主循环录像为 9414 帧／156.9 秒，实战取得 H、修钟后回小站；另对 Boss 镜头补验保持落点地面与相同缩放。原生镜头、Web 与实体设备结论分别记录于 [质量记录](quality/record.json)。可复查日志、完整录像和逐房截图位于 `build/plains_v07/`；正式审看摘要与精选画面保存在质量目录。

审看中修正了重复单向台导致下穿停滞、侧门台阶卡肩、P12 折梯开后仍被墙封住、P17 返程缺落地、旧集上层叠台挡头、谷仓上下层未参与主路、东境反冲绕过 H 高台，以及两处阿栖浮空。长桥与东境分别验证 H 正解及无 H 反例；根井验证 H+D 正解及九组无 D 尝试。地图、对话和人物层次以原生画面复查，不能把图可达或截图当作所有玩法证明。

导出时共用关卡接口变化使旧开发工坊签名失效；已用原有构建流程重新验证 36 个开发片段和 18 条连续组合，更新派生回放与导出签名。它仍是开发内容，不替代固定世界。

## 明确边界与恢复入口

ZIP 给出 50 个装备来源槽，未给出其余 48 件最终效果与价格；沿 `ITEM-V5-01` 的现有边界，本轮三处地图行装包具有真实获取、动画、唯一收据和持久收存，但未冒称已接入最终可装配效果。既有试制商店与装备效果保留独立身份。其余 274 房、外区能力获取、全世界结局及实体手机／手柄性能不在本轮已通过范围内。

未合并、未发布试玩网站。继续制作时直接修改当前配置／手工场景，运行 `python3 tools/world/build.py`；不要重跑一次性 ZIP 导入器或 build 中的临时施工脚本。验证入口见 [模块导航](../../module_map.md)；普通房间修改按实际影响选择检查。
