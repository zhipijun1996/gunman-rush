## 当前实现

WorldCamera唯一拥有正式游戏镜头；WorldCameraZones只解析玩家所在区与已提交的通路状态。统一选择→唯一目标→分轴平滑→展示边界/玩家可见性→安全震动。旧房形条带选框、场景预读焦点、旧参数与末端坐标覆盖已删除；旧DemoApp的显式回归消费者独立保留，不接入正式入口。

- 四模板：双轴、横向、纵向、固定/有限场地；基础缩放1.6，特殊缩放只允许显式区配置；Boss区明确启用合屏，最低1.0、缩放阻尼0.45秒，过大场地保留有限跟随。默认合同覆盖309房，重点手工校准当前六房。
- 移动意图确定观察方向，停止保持；一次反冲或反向瞄准不翻转，持续位移确认后再转。前瞻按画幅12%，位于死区计算之后；高速补偿和下落追赶平滑退出。
- 普通纵向观察从地面上方随上升减速走向顶点居中，再随下落趋势偏向下方，落地0.24秒恢复上方构图；已设计的下降段落点预读、Boss全场及安全边界优先，不叠加落地震动。
- 左杆上下/键盘上下方向持续0.3秒启动查看，幅度为可见高度28%；成功交互、下穿、瞄准、回复、移动、跳跃或攻击优先。同一次被消耗的持有不延后补做查看，回中后才能重试。取消回当前基础构图。
- 镜头区分别定义触发、展示、普通跟随及查看范围。明确入口带支持双向和掉头，开启隐藏入口不立即拉镜头；遮挡防止尚未进入的秘密泄露。跨场景遮挡切换；重生/地形失败清瞬态。震动只在最终合法范围内叠加。
