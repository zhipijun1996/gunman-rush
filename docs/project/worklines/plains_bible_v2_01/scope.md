## 已查明的失效原因

| 问题 | 实现或审查证据 | 整改入口 |
| --- | --- | --- |
| 独立矩形与连线 | `tools/world/build.py`的`map_origin`分支生成矩形并标记`survey_with_explicit_connections`，只验重叠与图连通，绕过另一分支的门口接缝闭合；`world_map.gd`据此画连接线 | 整区总图与实际施工坐标共同重建，完成后移除该替代路径；禁止只隐藏线 |
| 角色突兀压暗 | `PlainsRoomArt`按实体矩形投硬阴影，角色与地形材质的受光响应不同；小站x=1620同位置开关日光投影可见角色明暗差 | 核对受光对象、遮挡轮廓、环境底光和动态阴影边界；尚未复现用户全部行走轨迹 |
| 上下门落脚不直观 | `FixedWorldApp`从上口入场会横向朝安全锚点转向；门口合同通过未约束落台必须在上口正下方 | 按现行房间规范重整门对、净空与实体落台，实际双向跨房验证 |
| 离地与错误层次 | 道具默认按整张纹理底边定位，未验实际基座/台底接触；P-R24候车棚明确被放到`layer=-15, depth=0.64` | 逐项区分贴地实体和独立景深，检查正常镜头移动中的接触面；离地现象不能一律归因透明边 |
| 长板与空房 | P-R23用多块单向长板补上口返程；路线回放优先满足到达，未充分审查建筑体量、转角分区和遭遇决定 | 按整体空间重新组织内部；安静房有明确职责，普通穿越须有有效互动，不以统一加怪配额补救 |
| 验收与迭代失效 | 用定点画面、既定输入与局部机关短片作主要检查；发现整体质量失败仍扩到35房，让用户重新跑开头发现基础缺陷 | 先建立逐房审查入口和相连片区审看，基础问题自行发现和修复后再发布 |

## 本批运行修复

- 玩家随身光由 `PlayerCarryLight` 消费 `player.json`，跟随共享玩家跨房保留；角色身体保持原始调色，不被环境底光与投影突然压黑。局部光实际照亮附近场景并接受实体遮挡，受伤等已有状态表现保留。
- 16个平原上口按既有实体落台重新对齐洞口，直接下落交还；15个已施工下口去掉托盘/横板，保留净空和旁岸。同步施工门位、归一化坐标、入场/安全锚点与失败备用锚点；门对方向与拓扑未变。不能把入口检查通过当作动作路线通过，回归同时覆盖反冲/承载净空和反向过门。
- P-R23用三级实体草坡与支撑旧高台替代横贯画面的单向长板，保留阿栖安静叙事职责；P-R24棚屋移回贴地近景。六种明确贴地道具使用自身接触修正，石柱基座和梁底重叠消除缝隙。
- 标题、暂停与试玩顶栏接入逐房选择、真实来向、base/H/H+D、重置及直达链接；内存保存隔离正式槽。切换能力会清除上一夹具的进度，返回正式游戏后继续原存档。下拉列表复用现有触屏适配，支持触摸选择与滚动；链接复制失败时仍可从文本框手动复制。

当前改动没有把运行时独立矩形地图替换为连续地区，也未完成35房生态与美术终审。空间候选与诊断/画面证据位于 `build/plains_space/`、`build/plains_review/`，均不作为第二套正式设计源。正式场景中不保留试验用的加宽入口台或额外小台。
