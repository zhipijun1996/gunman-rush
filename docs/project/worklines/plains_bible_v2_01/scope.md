整屏构图以房间地点与动作带为依据，P25、P26保留已认可的主体设计，P01右上仅保留原墙缺口的上下窗沿，P08井内保持下述候选；长桥与原野保持通风净空，P33由完整塔基后墙承接门廊和建筑台地，Z01新绘后殿与真实左上窗，P08使用连续砌体与固定世界坐标的曲面受光，三段绞盘绳索随真实吊台伸缩，窄窗与落岸灯提供实际光源。P27形成背风休整，P14内场沿实际平台使用原生平原地形，关闭旧亮绿地面绘制。室外背景继续使用独立云层、固定地表和分场所风点。无碰撞支撑退后；多余长柱删除，不逐台加装饰。

12间目标房更新配置，小站作为已认可的路线起点与返回基准复验。静态地形的重复体积和入墙部分在源场景裁清；平台ID、单向属性与材质映射随分片保持。13房修改前后实际碰撞并集、实体并集逐矩形比较一致。世界地图、门对和敌人／机关配置保留。

方法归现有[美术技能](../../../../.agents/skills/godot-room-art/SKILL.md)和Visual Bible：用户说“优化视觉体验”即按指定范围检查整屏、层次、材质、真实光源、环境运动、角色与碰撞可读性、接地和穿插。技能仅留执行顺序与判断原则，不装房间坐标、聊天记录或迭代历史。仓库内技能是本项目的执行入口；未声称同步其它会话安装的云技能。

## 检查与证据

当前写集为P06场景、场所云层参数与已作者化门口覆盖；射击改动集中于Motor及三个既有武器消费者，规则归人物物理正文。Motor只裁去接地射击请求的Y分量，不把斜射重新放大；跳跃先于本帧射击，延迟连发按实际发射时接地判定。旧测试中的“地面下射起飞”预期移到真实空中夹具，不保留互相冲突的规则。

- P06六个正式机位覆盖井口、低岸、东侧落岸、中层、上层和顶口。无新素材，复用现有原生木条、平原草、挂铃及井砌体，碰撞和敌人配置不变。
- 地面射击专项1343项通过：普通／旧冲量模式的上下与斜射，连发、飞镖、持续激光及冰弹／风暴／激光主动技能，地面高度、水平分量、同帧跳射、移动平台携带。
- 武器手感专项1224项通过；P06两段真实反冲动作通过。P06入口／落点合同19项、原战斗事务回归及日常CI四项通过；文档和差异格式检查通过。修改前后实际碰撞、平台和房界快照一致。
- 录屏采用声明起点、真实Router／Motor和正式镜头；战斗干扰隔离，不能作为完整战斗通关或手机性能证明。静态对照保留敌人位置，AI冻结以便比较。两段小视频和六机位对照用于本房快速反馈。

本轮用户指出背景重复、山体占比过大：现行室外四种底景为opening_plains（13房）、plains（9房）、orchard（P25）和clockheart_vista（P32）。室内优先按material_for_profile选择，不计入室外数量。P06沿用既有opening_plains；未新换背景，也不把当前候选视为用户认可。问题来自丘陵底景跨地点复用过广及统一填满视口的取景方式。暂停向后扩铺这套背景，给当前四种实图目录；P06现有丘陵背景尚不适配其全高选路空间，不作为视觉完工。按用户最新要求，每房先判断腔体、设定与空间，适合已有素材才复用，不适合则新创所缺分层。下一轮先重整P06背景构图，再继续下一房；方法直接写回现有Visual Bible及美术Skill，不另建报告。
