# 手机关卡工作台

目标：安卓手机快速审核、提出反馈和微调；主游戏持续拥有怪物、基础组件、镜头与剧情的实现。新行为先在主游戏完成，再将同版组件目录、房间与真实试玩包更新到工作台。无需模型API，AI会话通过MCP读取和修改明确数据。

## 来源与写集

起始基线为用户指定PR142 `29bd6b58cfe80d38f6ef5a8d3b843b59115f8af8`，接续分支 `feat/mobile-level-workbench`、PR145面向main。正式场景和世界源的所有权、完整接入命令及更新合同见[接入规范](world_io.md)。当前发布身份由[项目定位](../../../../tools/workbench/site-project.json)记录，网页源码归同名私有Site仓库。

本轮写集：游戏侧组件目录及严格场景codec、全登记物种资源闭包、精确接受包与公开版本发行工具；Site触屏手势、目录控件、三方迁移、恢复检查点、按范围定稿及同源运行版本路由。房间原始布局不属于本次工具修复。

## 当前功能

点按只选中，直接拖动移动；静止长按约520ms或点“属性”打开参数。位移、双指、取消和模式切换取消长按，新增元素留在画布中可立即拖动。常显添加、属性、删除和试玩；小对象触控命中保持44 CSS px，实际游戏尺寸不变。

组件目录从主游戏导出，包含28类描述，其中21类可直接添加；14种实际注册怪物、46项美术与16项交互表现来自真实注册表。地形、单向平台、移动平台、铃机关、荆棘、齿轮、钩点、攀爬墙、危险区、环境、镜头关注区、恢复区、告示、装饰、NPC和动作宿主按正式类型提供属性。固定流程落点允许微调，禁止增删身份。地形沿现行水平地面、垂直墙面与台阶规则，不提供坡地创建项。

反馈分工具问题与关卡意见。工具问题独立保存页面、屏幕尺寸、输入方式、工具版本及真实错误，不修改房间。草稿与选区采用严格修订比较，保留人工微调和锁定；MCP按类型处理反馈，不把工具问题当作关卡修改。

游戏更新保留旧来源与运行版本，先作三方比较，再保存检查点并CAS切换。无法证明身份的旧数组及同字段冲突明确呈现。代码、目录或运行包变化均重新建立试玩握手，日常房内换稿复用引擎。主游戏构建通过不可变发行资源和小型公开索引提供更新，不公开用户草稿。旧版按资源哈希保留供恢复。下载直链出现明确暂时故障时，使用同一仓库、提交标签和文件的官方公开资产API，继续核对原字节数和哈希；限流及身份错误不反复尝试。相同哈希与字节数的附带资源、已校验缓存可跨游戏版本复用，HTML和Service Worker正文保留当前版本URL作用域。

定稿固定指定修订和范围，纳入必要门位和收集宿主依赖；不将依赖房间其他微调混入。AI读取接受包，使用同一Godot codec候选保存回读和原世界编译器，再按授权写回、提交。源码合入、工作台版本更新与正式游戏发布分别跟踪。
