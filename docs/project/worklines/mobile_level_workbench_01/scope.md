## 设计与所有权

区域、房间、连接、资格和永久动作唯一归 `config/world/world.json`，施工尺寸与门台归 `config/world/construction.json`，实地形与放置归房间场景。完整接入和版本合同见[接入规范](world_io.md)，前置整合见[整合交接](../pr_integration_141_145/scope.md)。不手写第二份世界图或复制物理。

世界审核由实际合同导出16区域、38条跨区连接和平原8个外接接口，包含双端门位、安全落点、能力条件与施工状态。反馈保存世界/区域/连接/房间范围、稳定ID与来源修订。当前草稿的门位、门洞及落点优先于派生坐标。未施工端点可审核，不据此开放正常游戏。

额外房通过 `config/workbench/rooms.json` 登记，仍走同一WorldRoomDraft codec、来源哈希及接入校验。不同区域和连通分量分组，不伪造平原直连星桥或叠放两组局部原点。

V-R12职责见[区域规范](../../../bible/regions/starbridge_gate.md)与该区域room_design；实体唯一归V-R12.tscn。反冲与D主导，两个钩点支持换向与接续。全部实体墙侧面可攀附，限制接触处使用墙刺。攀墙及钩头命中恢复动作次数的统一规则见[能力合同](../../../data/abilities.md)，由主游戏实现，房间不私有补资源；Q的2秒冷却保留。

路线归场景独立 `route_guide`，不为编辑器指引创建实体告示；V-R12兼容既有首告示元数据。工作台按同一组编号和方向箭头绘制；工作台另显示动作说明与危险图例。金色光幕需要反冲保护，粉红刺和齿轮不可由Q抵挡；低位光幕已按从下方挂环后的身体包络校准。箭头是推荐通路，不是整链已验证的证明。

## 编辑与迭代流程

点按选中、拖动移动；静止长按约520ms或点属性打开参数，位移/双指/取消会取消长按。常显添加、属性、删除、试玩，小对象触控范围44 CSS px，游戏尺寸不变。组件与怪物目录来自主游戏注册表，固定流程落点可微调但不增删身份；地形提供水平地面、垂直墙面与台阶，不增加坡地。

审核支持整区、房内、生成队列、候选比较、采用和微调。工具问题独立保存界面、屏幕、输入方式、版本与真实错误，不修改房间；关卡意见绑定实际对象范围。修改前读取最新修订，人工锁定及并发编辑不可覆盖。

新行为先改主游戏并完成基础检查，再发布同提交运行包、36房seed、组件目录与世界审核上下文。发布前让完整新seed通过工作台实际 `validateState`，包括组件枚举与参数范围，避免游戏可运行而编辑器拒绝导入；本轮36房校验无错误。更新顺序：`check_game_update`→读取最新修订→`preview_game_update`→仅在can_apply且无未决冲突时应用。应用先存恢复点，再CAS迁移；对人工房间实际内容做前后比较。

运行资源来自不可变公开发行，经哈希和字节数校验后缓存，HTML/Service Worker保持当前版本作用域；相同资源可跨版本复用。代码、目录或包变化重新握手，普通房内微调复用驻留引擎。下载故障按现有有界重试和官方资产API回退，不把发行成功说成安卓首屏秒开。

定稿固定修订和范围，纳入必要门位与收集宿主依赖，不混入依赖房的其他微调；通过同一Godot codec保存回读、原世界编译器校验后按授权接入源码。源码合入、草稿更新与正式主站发布分别记录。
