# 手机关卡工作台

目标：安卓手机快速审核、提出反馈和微调；主游戏持续拥有怪物、基础组件、镜头与剧情的实现。新行为先在主游戏完成，再将同版组件目录、房间与真实试玩包更新到工作台。无需模型 API，AI 会话通过 MCP 读取和修改明确数据。

## 来源与写集

工作台随主游戏源码维护；游戏源码已推进至 PR147 的 `679df755`，本轮在该提交基础上按最新反馈重做 V-R12 布局与恢复机制。前置整合见[整合交接](../pr_integration_141_145/scope.md)。游戏开发分支为 `feat/world-review-stargate`。正式场景和世界源的所有权、完整接入命令及更新合同见[接入规范](world_io.md)。发布身份由[项目定位](../../../../tools/workbench/site-project.json)记录，网页源码归同名私有 Site 仓库。

本轮写集：从现有世界合同导出 16 区域和 38 条跨区连接的审核上下文；Site 增加世界连接、双端门位与平原 8 个外接接口定位；使用既有 V-R12 身份制作高难度多方向全能力挑战灰盒，并沿同一 codec、隔离试玩、版本迁移和公开发行链接入。平原人工草稿及原有审核队列、候选比较、采用和微调流程保留。

## 设计与数据合同

区域、房间和连接身份仍唯一归 `config/world/world.json`，门位与落地合同归 `config/world/construction.json`。审核上下文从实际编译合同生成，并绑定来源提交与内容版本，不独立手写第二份世界图。外区未施工端点允许审核和反馈，但不据此打开正式游戏封闭边界。区域反馈保存世界、区域、连接或房间范围，以及 region、connection、door 稳定 ID 和来源修订，AI 能在新会话中读取相同对象。

当前草稿门位、门洞和安全落点优先于导出时的派生坐标，人工微调不会被旧审核数据遮盖。缺少匹配世界上下文时，不显示旧版本世界拓扑；已有房间仍能按稳定房号前缀在本编辑集合内分组并查看灰盒，页面提示更新世界数据。

可编辑房集合由平原 35 房与 `config/workbench/rooms.json` 的显式附加房构成。V-R12 沿真实区域与连通分量单独显示，不能制造平原直连星桥天门的假边，也不能把两组局部原点叠在同一地图中。附加登记与场景仍走来源哈希、共享编解码器和正式接入校验；不绕过世界身份与施工状态约束。

V-R12 使用后期 `hwdq` 审核能力阶段。当前制作目标是反冲与二段跳 D 主导连续空中位移，安排上下左右折返，用 2–3 个钩点和多处可攀墙支持恢复与换向；钩索 H 不再承担整条路线的主要推进。实际抵达钩点或首次有效攀墙接触时，主角统一机制补当前空弹并恢复 D/H/Q 使用资格；持续挂环或贴墙不重复补充，Q 的 2 秒冷却仍保留。恢复由真实动作接触触发，不由房间隐藏补给或按键顺序计数替代。失败恢复点和完成后的回程继续需要清楚、安全的实体地形。正式新游戏能力及相邻未施工房不受审核能力夹具影响。

## 工作台功能

点按只选中，直接拖动移动；静止长按约 520 ms 或点“属性”打开参数。位移、双指、取消和模式切换取消长按，新增元素留在画布中可立即拖动。常显添加、属性、删除和试玩；小对象触控命中保持 44 CSS px，实际游戏尺寸不变。

组件目录从主游戏导出，地形、单向平台、移动平台、铃机关、荆棘、齿轮、钩点、攀爬墙、危险区、环境、恢复区、告示、装饰、NPC 和动作宿主按正式类型提供属性。怪物种类、美术与交互表现来自实际注册表；新增类型先在主游戏实现再更新目录。固定流程落点允许微调，禁止增删身份。地形沿现行水平地面、垂直墙面与台阶规则，不提供坡地创建项。

“地图”包含世界连接与房间整区两层。世界审核可从区域选择连接，查看两端房号、门 ID、门洞、坐标、安全落点、出向规则和施工状态，再定位当前已接入房间的门位。未施工且未进入 seed 的房间不伪装为可编辑或可试玩。审核首页保留整区、房内和生成队列，并提供世界连接及 V-R12 灰盒入口。

反馈分工具问题与关卡意见。工具问题独立保存页面、屏幕尺寸、输入方式、工具版本及真实错误，不修改房间。关卡意见支持世界、区域、连接和房内范围；连接反馈携带双端上下文。草稿与选区采用严格修订比较，保留人工微调和锁定；MCP 按类型处理反馈，不把工具问题当作关卡修改。

游戏更新保留旧来源与运行版本，先作三方比较，再保存检查点并 CAS 切换。无法证明身份的旧数组及同字段冲突明确呈现。代码、目录或运行包变化均重新建立试玩握手，日常房内换稿复用引擎。主游戏构建通过不可变发行资源和小型公开索引提供更新，不公开用户草稿。旧版按资源哈希保留供恢复。下载直链发生明确暂时故障时，可使用同一仓库、提交标签和文件的官方公开资产 API，并继续核对原字节数和哈希；限流及身份错误不反复尝试。相同哈希与字节数的附带资源、已校验缓存可跨游戏版本复用，HTML 和 Service Worker 正文保留当前版本 URL 作用域。

定稿固定指定修订和范围，纳入必要门位和收集宿主依赖；不将依赖房间其他微调混入。AI 读取接受包，使用同一 Godot codec 候选保存回读和原世界编译器，再按授权写回、提交。源码合入、工作台版本更新与正式游戏发布分别跟踪。

## 实际检查与验收边界

Site 的 113 项针对测试、TypeScript 检查和生产构建通过。覆盖原有编辑、迁移、定稿及运行包握手合同，以及世界上下文来源绑定、跨区反馈、隔离地图分组和旧 seed 无世界数据时的灰盒兼容。390×844 手机宽度浏览器已验证世界范围反馈、连接双端及门位导航。浏览器界面验证不等同安卓设备操作、性能或触感验收。

V-R12 已按最新反馈改为2个钩点、6面攀附墙、反冲与D主导。关卡基础检查8项通过：同一codec、真实加载、入口支撑、两段代表动作与返程落井静态碰撞；能力恢复短检查17项通过。旧路线的整链、镜头和能力反例结果不作为新版通过证据；其历史留在 Git。当前不声明新版全链可达、无伤、镜头完整预读或手机体验通过。

每轮以基础场景导入、同 codec 导出/回读和本轮关键动作段检查为足够门槛，发现直接影响试玩的错误即修，随后尽快交付手机试玩与反馈。完整回归、全链自动输入和大批反例在定稿或用户明确要求时再做，不把它们作为每次灰盒迭代的前置负担。实际运行包仍需遵守来源一致性、范围与资源闭包等发行合同。

世界审核、范围导出与正式接入的 18 项数据检查，以及 Provider 范围和施工源绑定检查仍是对应数据范围的已有证据；它们不证明新版 V-R12 的动作手感。36 房可编辑或可临时加载，也不代表未施工房间已完成设计、正式接入或体验验收。

历史基线的压缩运行下载约 138.2 MB；这是已有包体记录，不是本轮新发行或安卓测速结果。编辑器不等待引擎下载，同一运行版本的位置和参数修改复用驻留引擎，但不能据此声称首次试玩秒开。本轮未完成安卓设备上的首次下载、WebGL 运行、帧率与触感验收；原生控制器证据和移动宽度 UI 检查不能代替这些结果。界面证据与本地检查产物位于 `build/workbench/evidence/` 等构建输出目录，提交和发行按既有产物规则处理。
