反馈分工具问题与关卡意见。工具问题独立保存页面、屏幕尺寸、输入方式、工具版本及真实错误，不修改房间。草稿与选区采用严格修订比较，保留人工微调和锁定；MCP按类型处理反馈，不把工具问题当作关卡修改。

游戏更新保留旧来源与运行版本，先作三方比较，再保存检查点并CAS切换。无法证明身份的旧数组及同字段冲突明确呈现。代码、目录或运行包变化均重新建立试玩握手，日常房内换稿复用引擎。主游戏构建通过不可变发行资源和小型公开索引提供更新，不公开用户草稿。旧版按资源哈希保留供恢复。

定稿固定指定修订和范围，纳入必要门位和收集宿主依赖；不将依赖房间其他微调混入。AI读取接受包，使用同一Godot codec候选保存回读和原世界编译器，再按授权写回、提交。源码合入、工作台版本更新与正式游戏发布分别跟踪。
