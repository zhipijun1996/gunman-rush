# 手机关卡工作台

目标：以手机完成“生成—审核—迭代—微调”，先让空间与玩法成立，再进入用户试玩和美术收尾。主游戏持有运动、怪物、组件、相机与世界合同；工作台使用同源结构化草稿，AI通过MCP参与，不需要额外模型API。

## 来源与写集

游戏分支 `feat/mobile-graybox-review`，基于 main `7a2f022b5df6e4fe1a63b4705587badc5a24160b`。写集为审核上下文导出、真实动作采样工具、现行制作流程及工作台Site界面/审核状态合同。没有修改角色物理或正式关卡布局。数据归属、接入命令和限制见[接入规范](world_io.md)。Site身份由[项目定位](../../../../tools/workbench/site-project.json)记录。

## 当前功能

默认进入审核页，整区图使用真实占地和门缝，去除矩形分块的内部边线。每房显示职责、教程顺序与探索标记；点选查看路线、压力、恢复、收集和来向。可下载当前SVG，也可进入不加载美术/引擎的房内灰盒。详细编辑保留原触屏拖动、长按属性、组件目录、添加/删除/尺寸修改。35房可预览，正式施工仍为6房；16区309房职责可查询，平原之外尚未接入此编辑器的实际场景。

一批选择1–6个相连房间，填写目标、能力阶段和范围；圈选空间可随任务保存。复制指令给当前ChatGPT会话，AI读取完整任务后回写候选；手机比较当前/候选，提出意见继续迭代，或采用到草稿。采用可撤销，不直接改主游戏；范围外、锁定和已发生的人工微调不被覆盖。任务及反馈在撤销和升级时保留，定稿携带审核说明供正式设计文档同步。

动作尺使用真实控制器在平地夹具中的5组采样，不用简化抛物线假称真实可达。短跳/长跳/反冲/二段跳/钩索样例均有实际动作回执并回落地面；它们不证明房间通关、初见可读或趣味。源码、参数和来源校验防止沿用过时轨迹。

现有主游戏更新与接入流程保持：三方比较、检查点、精确采用包、同一codec及世界编译器。修正旧迁移器将退休镜头空集合补回的问题，避免35房被误判为人工改动，并按实际差异收敛热替换和导出范围。只移除新版目录已不支持且确为空的字段，不清除有内容的编辑。

## 实际验证与边界

锁定Godot 4.7.2。主游戏 `python3 tools/ci.py` 四项通过，含239条合同断言、39条Meta Notes保存断言；5组真实动作采样全部收到对应跳跃/射击/钩索回执并落地。Site的99项测试全部通过，包含实际store的任务创建、重试幂等、候选隔离、采用和撤销、人工改动保留、跨范围/锁定/过期拒绝、迁移退休字段、SVG边界与审核入口服务端渲染；发布身份见项目定位和本次PR。

生产构建及TypeScript检查通过；35个场景真实提取和seed生成通过，验证309房职责、16区目录及5组动作样例同源。本环境没有Sites要求的cua_repl浏览器控制工具，因此未启动替代浏览器进行触屏/布局验收；服务端渲染和自动测试不能代替安卓真机使用。真实网页引擎加载、触感、移动性能及完整关卡趣味仍未验证，未将它们写为通过。
