# 手机关卡工作台

目标：在安卓浏览器圈选和微调实际房间，与现有 ChatGPT 订阅共享草稿；复用正式 Godot 运行逻辑，接受后确定性写回场景和世界源。

基线为用户指定 PR142 的 `29bd6b58cfe80d38f6ef5a8d3b843b59115f8af8`，实现分支 `feat/mobile-level-workbench`。正式世界保持原来源和稳定身份，工作台草稿按修订进行冲突检测。编辑器先加载轻量数据；试玩运行包按需加载，之后通过桥接重建房间，不重载 WASM/PCK。

## 写集

- 游戏：共享房间草稿编解码器、显式工作台桥、Provider/App 的入树前应用、真实多边形地形及呈现。
- 工具：场景导出/保存、世界源候选校验与写回、工作台专用运行包。
- 加载：按当前实际资源规模设置缓存预算，复用容量索引；不让放不下的 PCK 先驱逐运行时。
- 网页：触屏编辑、草稿历史与锁定、反馈和真实截图、ChatGPT MCP、同源留驻试玩。

## 已实现的闭环

网页以实际源码提取的约444KB种子打开35房、24项收集/主要目标、真实门位和玩家尺度；不先加载游戏。支持点选、拖动、圈选、吸附、数值微调、平台/多边形坡面/怪物/危险区/钩点、既有机关参数、房形与成组门台编辑、A/B候选、撤销重做与锁定。

Sites D1持有用户草稿与不可变编辑记录，R2持有真实截图；修改同时核内容修订与锁定选区，旧AI补丁不能覆盖新稿。MCP只读写明确数据，不调用模型API；用户在已有ChatGPT会话里表达意图。跨房奖励或连接规则改变会明确等待原编译器，不能用旧试玩规则冒充已应用。普通地图奖励的简单迁移目前仅TG01和part_triple符合唯一宿主/无独立返程闩合同。

真实试玩采用单线程Godot Web专用包。同源桥逐次串行发送草稿，快速修改只保留最新待发版本；成功回执包含房间、修订、数据hash、耗时和临时预览标记。每次换稿建立选定入口/能力阶段的隔离测试起点，不继承上一稿的击杀、奖励和玩家位置；同次试玩跨房保持内存进度，退出恢复正式保存。35房可编辑及尝试临时加载，29房仍未按新房形完成施工与体验验收。

接受后用同一Godot codec写候选场景、保存回读，随后用原世界编译器检查，并可通过`--write`写回经过核对的精确字节。来源哈希冲突拒绝自动覆盖。接入后更新Site种子/试玩包，并调用`adopt_published_baseline`逐项核对当前草稿再开始下一轮；只改未施工房时正式内容版本可不变，以来源哈希同时识别基线。完整源映射、命令及拒绝边界见[接入规范](world_io.md)。

## 实际检查

固定`4.7.2.stable.custom_build.gunman_sd1.ed1daf0bf`引擎、18个导出模板均核对锁定SHA256。`python3 tools/ci.py`四项通过：项目检查、导入、12条启动断言、239条合同断言及39条Meta Notes保存断言。`tools/check_docs.py`通过。

`tests/world/workbench.gd`为0失败：35场景提取；真实Motor走上/下256wu坡并跳跃反冲着地；草稿热替换与过期拒绝；失败恢复原暂停房；真实相机/碰撞合同；35房单端门缝冲突拒绝，P22/P23成对移动门台后同修订真实过门；未施工P17临时加载并实际落地；正式存档原字节保持。容器headless换房实测约78–130ms，仅是本机功能测量。

正式接入分别验证P22怪物x从3056到3072，以及TG01从P04迁移到P22，codec回读及原编译器均通过；隔离发布的字节hash和重编版本一致，正式43项来源哈希未变化。Python7项反例通过。网页Domain/运行队列11项针对测试通过；浏览器实际验证打开35房、添加坡面、D1保存修订、撤销及重做。

新PCK为130529900字节（124.48MiB），旧包237144744字节，减44.96%；含单线程WASM的压缩分块下载135525121字节，比旧230684963字节减41.25%。空项目载实际包验证1402文件/119项raw哈希、35场景、正式6房与7物种，未报告脚本/资源错误。Site发行356文件、最大单文件524466字节，全部分块解压/长度/整包hash核对通过。

原缓存128/80MiB容纳不下旧PCK，还会在拒绝超大文件前驱逐引擎；现在容量跟随实际包，预先拒绝超限并复用缓存索引。专用Site发行依赖同源Service Worker与gzip解压流，不能用时明确显示错误；缓存和Site启动状态机测试通过。日常房内换稿不重新下载引擎/PCK。

## 当前限制与恢复入口

云端预览浏览器明确缺少WebGL2，因此当前不能完成网页Godot画面、触控和截图端到端验收；页面会报告真实启动错误，不提供伪物理替代。Android真机加载时间、帧率、手势操作感受和实际截图仍须以目标设备验证，不能由headless毫秒数代签。所有35房的完整玩法/艺术质量不属于本轮工具验证。

新拓扑、增删门、复杂剧情/能力/返程奖励须由AI在原世界源成组修改和编译，当前手机编辑器拒绝不完整的端点重连。现有门台只有唯一独立支撑矩形时允许简单移动，其余交给完整地形修改。

本机证据位于`build/workbench/logs/runtime-test.log`、`daily-ci.log`、`apply-p22/receipt.json`、`apply-tg01/receipt.json`、`publication-test.json`、`web/workbench-build.json`。构建命令为`python3 tools/export_workbench.py`；Site发行使用`python3 tools/export_workbench.py --site-copy-only --site-copy <Site/public/play绝对路径>`，不能直接删除完整Web包的raw文件。
