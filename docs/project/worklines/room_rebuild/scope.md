## 接续制作

1. 从正在施工的玩家来向读取房间身份、锁定尺度、外轮廓、门线、资格、奖励、首访和回访体验。在两端同时标明跨房方向、世界门线与安全落点。
2. 在同一底图画出整房轮廓、主路线、分支、镜头所见的落脚面和区域视觉重点。用真实角色、已有 TileSet、机关和物种组装一段可连续试玩的路线。
3. 从上一房实际走进来，再正走、走错、折返；检查远近提示、角色站稳时的视野、落脚余量、开门及已领取状态。保留按横屏触控输入的实机短片和原比例整房图供审核。
4. 对照上一房和下一门端验收后，再从玩家下一个有意义的选择继续施工。房号、绑定位、整房完成度分别维护。
