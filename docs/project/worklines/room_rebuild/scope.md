# 普通房间重做

## P01、P03 教学联测 · 待整房评审

两房沿用已认可 P02 的运行入口和 `world-room-model-27`。从 P01 出发走过 P02，再到 P03。P01 与 P03 使用各自的场所、地形和原生配景，F08、P04、P13 做到对侧能落稳并原路返回。P16、P19 沿用样板接收段。

| 房间 | 首访从角色机位读什么 | 重试、支路和返回 |
| --- | --- | --- |
| [P01](../../../../production/rooms/world/P01.json) | 草场上的木牌、由立柱托住的高台和台下空地形成同一处练习场。在同一点普通跳够不到台面，跳起向下射击可借反冲登台。向东从 d001 进 P02。 | 失手落回草地，无需重置，也可沿草地继续教学。西侧 d223 林栅首访关闭，玩家从 F08 一侧解闩后可双向穿行。 |
| [P03](../../../../production/rooms/world/P03.json) | 从西下方 d002 到谷底，先向东登阶，再从头顶的旧路折向西，在 d003 进入 P04。旧路上的巡虫留出观察与处置空间。 | 跳短落回谷底，可再次上行。谷底拾取零散金币。东壁上方能预见菌光与齿轮，取得壁攀后才能进入东龛，从 d017 接上 P13。 |

验证顺序以房间自己的设计问题为准。P01 在同一起跳点对照普通跳和反冲，检验木台有没有真正教到新动作；P03 分别使用首访和已有壁攀的进度，检查上下两条路的可读性、上层能否绕进东龛、齿轮是否只领取一次。用相邻两端的真实机位比对接缝，并从新进度连续通过三房。三房连续控制器回归覆盖往返、重试和领取。两次无壁攀试跳分别从回头路高处与井底发起，验证角色会撞回岩脊或落回谷底；从 F08 林闩内侧进场与从 G08 已获壁攀的回访分别用独立进度验证。7 条物理连接的 14 个端点与锁定地图相符。[联测脚本](../../../../production/tests/plains_intro_rooms.gd) · [接收段与素材](../../../../art/rooms/plains_intro/README.md)

一位未读解法的试玩者在 P01 主动找到了木牌，也借反冲落上贴着风旗的横梁；第一次读牌依赖了既有的按键知识。告示现在会在可读距离内显示 ↑ / W，打开后收起提示。P03 首访与已获壁攀回访的动作录像分段标注。

普通房回归入口为 `python3 tools/check_ordinary_rooms.py`。P02 的认可和下面的第 6 版资料对应原样板。

## P02 田埂反冲教学 · 整房已认可

地图依据为 `world-room-model-27`。制作范围是一间完整 P02，以及四个邻房门槛以内的接收段。根工程继续运行冻结平原。用 Godot 4.7.2 打开 `production/project.godot`，选 [P02.tscn](../../../../production/rooms/world/P02.tscn) 后按 F6，从 P01 接近西田埂。A/D 或方向键移动，空格跳，鼠标瞄准、松开左键射击，M 打开局部地图。

v26 和 v27 的四条门线及房号相同。d009 在世界地图沿 y=39 的水平边界跨接两房，P02 在上、P16 在下。房间说明中的“侧通道”是主路线的探索分支，草台接近方向和最终跨房方向见下表。

西岸先让玩家看清断口和同高的钟架，反冲落上钟台后铃响一次。主路与两条低路各有自己的用途。地形和角色沿用现行平原材质。[P02 美术与素材来源](../../../../art/rooms/P02/README.md)

| 位置 | 玩家在这里做什么 |
| --- | --- |
| 西田埂、断口和钟台 | 从宽台读出落点，尝试在空中朝身后开枪。钟响给出落稳反馈，起跳线与钟台上都能停下来观察。 |
| 沟底和西侧两级田阶 | 跳短时安全落地。向上攀阶可以重新挑战钟台，往西沿草坡可以探索。 |
| 西边低岸与草口 | 一只田埂小虫在远岸来回爬动。想去那一侧时可以先从近岸开枪，也可以跳过去。靠近草边才看得到井口，从 P16 返回后可以直接回田阶。 |
| 钟台以东的排水阶和井颈 | 玩家站在钟台上可以选择跨到东田，或者逐阶下降去 P19。向上返房时，从井肩起跳能重新登上田埂。 |
| 东田平路 | 越沟落稳以后，在宽路上单独遇见同种小虫。有空间退让射击，也可跳越，继续走向 P03。 |

两只小虫各自巡逻，击败后掉落本物种的基础金币，走到掉落处即可拾取。清怪是可选玩法。普通换房时保留每只小虫的生命与位置。样板的初始复活点在 P01，生命耗尽后可从那里满血重新出发。新周期刷新普通怪，已拾取的金币、P16 的生命碎片和已发现的支路均保留。

| 世界门 | 从 P02 出发 | 从邻房返回 P02 |
| --- | --- | --- |
| d001 | 向左走出西田埂，进入 P01 | 从 P01 右缘向右走入西田埂 |
| d002 | 向右走出东田，进入 P03 | 从 P03 左缘向左走入东田 |
| d009 | 在西田埂下发现草缝，从草槽底向下落入 P16 | 从 P16 顶部草根口向上跳，落在东侧凹阶，再爬回草台 |
| d330 | 从东侧排水井向下落入 P19 | 从 P19 顶部井颈向上跳，落在西侧凹阶 |

[房间数据](../../../../production/rooms/world/P02.json)持有地形实例、入口、发现点和配景锚点。[邻房接收段](../../../../production/rooms/world/p02_connections)保存各侧可走地形。局部地图从锁定内容包读取房间轮廓，随实际到访和草径发现更新。会话内保留发现和领取记录。

## 样板复盘

2026-11-27，用户认可 P02 整体。对应第 6 版试玩，游戏提交为 [d7e0fd85](https://github.com/zhipijun1996/gunman-rush/commit/d7e0fd853ca985c7e8bfad3fbf07de6964c7549e)。范围是一间完整房和四个接收段。[整房、短片与试玩](https://plains-p02-room-review.zhipijun1996.chatgpt.site/)

| 返工处 | 为什么当时没发现 | 这次用什么判定修好 |
| --- | --- | --- |
| 门能过，方向却错 | 把“侧通道”当成了横向门。两房和测试沿用同一方向，双向通过也掩盖了错误。 | 独立从锁定门线推导方向，再实走四门八个方向，观察对面落稳和交还控制。 |
| 画面像堆贴图，洞口与路线脱节 | 先看整图和单个素材，覆盖地形的装饰在角色尺度下打断了纹理连续性。坡面和洞形也没给出对应动作。 | 恢复平原原生地形，配景对齐可站立面；从起跳线看得到钟台，跳短能沿田阶回来。 |
| 草口远看就像路 | 只检查靠近会触发发现。遮住了草尖，井壁和返程台阶还暴露在远景里。 | 正常机位从首访远处录到靠近、退远和回访。远观草坡连贯，近处能先认路再下井，地图保留发现。 |
| 房间可通，部分路段却空；加怪后暴露恢复问题 | 只走成功路线，看不出宽路上的选择，也触发不了回访巡逻范围漂移和零血后失去操作。 | 西岸实测射击、拾取，东田实测跳越活敌；反复换房验证巡逻边界，实际受击致死后从 P01 再次走进 P02。 |

首见方面，早期一次未读解法的 AI 试玩自行发现了回跳窄台，并在越过排水井后折返。那次观察早于最终布怪。第 6 版的整房认可、真实控制器验证和这次首见观察各有对应版本。

后续制作沿用[布局与构图](../../../bible/room_authoring.md#布局与构图)的顺序，从新房的世界连接、教学位置和场所出发。复现本样板可运行 `python3 tools/check_ordinary_rooms.py`；内容绑定和奖励检查见 `python3 tools/check_content_channel.py`。
