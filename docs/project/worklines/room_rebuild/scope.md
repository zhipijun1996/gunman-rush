# 普通房间重做

## P02 田埂反冲教学 · 待评审

样板分支为 `feat/p02-terrace-pilot`，基于机关库合入后的 `7ff567e8`。在 Godot 4.7.2 打开 `production/project.godot`，选中 [P02.tscn](../../../../production/rooms/world/P02.tscn) 后按 F6，即可从西田埂开始。根工程仍提供冻结平原。地图身份取自内容通道 `world-room-model-26`，本次只绑定 P02。四个出口在样板内终止。

这间房教玩家向身后偏下开一枪，借反冲上对岸。西田埂、钟架承台和东排水涵决定了全房剖面。主断口宽 304 个世界单位。普通跳失足会落在浅沟，西侧两级退台可以回到原起跳点。西草涵通向隐藏支路，东排水涵可下探，主路也可以直接跳过排水井。此处留出视线和试错空间，全房采用水平承重面，无敌群。

[房间数据](../../../../production/rooms/world/P02.json)持有平台实例、教学意图、出口、发现点和近景锚点。[美术源](../../../../art/rooms/P02/README.md)记录了田野远景、两处涵洞、承重剖面和钟架的来历。运行 `python3 tools/check_ordinary_rooms.py` 验证真实控制器，从进入、失足、恢复、反冲跨越，一直走到两条涵道并返回。

本轮交付供单房评审。后续房间、跨房接线和方法推广等待评审决定。
