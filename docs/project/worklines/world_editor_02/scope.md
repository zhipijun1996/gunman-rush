# WORLD-EDITOR-02 当前交接

合同归[编辑器协议](../../../data/world/editor_protocol.md)，来源归[世界输入](../../../data/world/README.md)。

## 基线与写集

用户指定PR156基线，接续来源修复 `dfd3bae`，分支 `feat/world-spatial-layout`。本轮允许房间尺寸与位置适配；309房、409连接、149奖励/目标及NPC与能力路线身份不变。新增唯一空间初稿 `config/world/spatial_layout.json`，由导出器显式 `--spatial-draft` 读取；默认正式导出与construction不被候选覆盖。编辑器草稿可导入继续调整，审核后再按正式接入流程落实。

## 当前结果

16区全部房间已有世界单位坐标、尺寸和占地；265间未施工房以原施工体量、区域方向、森林已有方案及正常视口尺度编排。保留35个平原房与所有已编写房的内部实体、逻辑和奖励。工城G02在候选里整体东移至[26048,768]，解决被平原围住无法外接；S01的未来C26口向西、K01的未来room-link-076口向上，避开P20/P18。三处调整均标记adapted_entry，未修改正式运行门位。

409连接包含48已有接缝、357正交通道候选及4显式换层连接；同层房间无占地重叠，新通道中心两侧48单位不切入第三房。通道交叉不自动新增邻接；60条连接含上跨/下穿待审位置，53条通道长度超过6000单位，后续应优先压缩空间或细化为有职责的通行段。这些是明确剩余设计工作，不是通过几何检查就认可的游戏性。所有原连接条件、房内能力锁和收集身份保留。

同源审核交付含可触摸缩放HTML、带每房名称/一行职责/收集ID的SVG、总览PNG、编辑器schema3完整导入JSON。HTML可筛区域、切室内层、按房号搜索、查看奖励/休息/Boss/NPC/房内能力路线并点邻房跳转。独立图只提供空间审核，不冒充实景与正式可玩内容。

## 验证与后续

4项空间专项和6项原编辑协议测试通过；检查房间不重叠、所有通道端点、正交和第三房净空、玩法身份不变、默认导出不受候选污染。编辑器freshWorkspace实测接受309房文件。桌面和390×844浏览器检查搜索、邻房切换及布局，无页面异常；不等同实体手机触控验证。文档检查通过。证据与生成媒体在build/world-layout，源码不带运行资源或构建媒体。

App长任务的当前限制已定位：最多12轮工具循环，模型不再调用工具即结束，尚无全目标覆盖完成校验。进度、分批计划和续跑属于编辑器后续改进，本轮按用户优先级先交付整世界空间初稿。正式房间施工、连续实机通关和美术均未在本轮扩展。
