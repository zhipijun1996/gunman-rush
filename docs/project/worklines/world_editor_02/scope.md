## 坐标与方案

统一左上原点，X向右、Y向下，画布64×48规划格。1规划格暂按1024世界单位（32个32px地形格），所有地区同尺度。图上位置是outline外接框左上角，宽高由该几何直接计算，不是实际填充面积；源坐标可乘除1024转换。尺寸尚待房间及动作校准。

轮廓恢复平直横纵边界，用有限退台、宽窄与区域错位组织空间。工城为多层街区；矿井是小型换层井簇，实际规划占地约为工城的五分之一，不能按连接数放大。冰川上层、低廊与下缘存在高差，避免平底山块及连续锯齿。主图同时标出功能分区、通行意图、接口和右侧16区坐标尺寸表。

保留牧风者W、森林H／地穴D先后自由、古堡Q；工城早访服务街和后续分层回城，手里剑断绳仍是可选路线。接口资格是接近段设计意图，不在普通房门上加能力检查。骨架线不代表施工走廊；边界与少量空缺仍可在审核及后续房间细分时调整。
