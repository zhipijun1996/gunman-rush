## 当前区域方案

工城规划占地约为平原2.27倍，是最大区域；接平原、古堡、浮岛、矿井、熔炉，服务街、上街、高港、矿货和炉渠分别承担不同阶段用途。矿井沿城市下方展开，浅矿竖向贴近平原和沼泽，主矿层接沉水遗迹、城市与熔炉。两个枢纽各有5个邻区；工城—矿井保留抽风井回程与矿货东站两个不同接口。

西侧依高度安排冰川—峡谷—森林—地穴／圣殿，水系经沼泽与沉水遗迹接地下枢纽；世界钟心保持中心高塔，古堡在城市上方，浮岛与星桥形成高处回访。16区30个计划接口直接落在共享边界上，不以长线补偿彼此远离的区域。共享边界不是任意可穿越边界。

保留基础动作→牧风者W→森林H或地穴D（顺序自由）→古堡Q。早访工城服务街和钟心门厅，不等于开放两区主体。手机页展示5条宏观游历意图；H/D限制须在后续内部接近段用地形落实，不能直接当跨区传送门的资格检查。手里剑断绳仍为可选收藏／捷径，不作为主线硬锁。
