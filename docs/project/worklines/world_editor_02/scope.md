# WORLD-EDITOR-02 当前交接

目标是可在手机审核、导入编辑器的完整世界初稿。玩家体验、可信地理、能力锁、分支与回访优先，用户允许优化拓扑与房间。当前优先重排平原东西线与早期工城行程。用户实玩完整P13—P04—P25—P26—P27西线后仍感到很快抵达牧风者，而东线冗长、缺乏探索欲望；不能归因于近路提前开放，也不能仅用驿车缩短服务路程视为解决。工城四区候选已形成，但发布暂缓；依据[片区设计](../../../bible/regions/eastern_cluster.md)与[世界输入](../../../data/world/README.md)。

## 基线与写集

用户指定PR156；分支feat/world-spatial-layout，PR158基于fix/editor-planning-provenance，保持草稿。本轮接续3c3e057，最终身份由PR提交与附件manifest确认。正式源仍为309房／409连接，候选为16区324房／426连接。正式world/construction、已施工实例、main、APK和在线平台不被候选覆盖。

单一输入为spatial_layout.json、spatial_clusters六份片区及森林room_design.json。region_programs持有各区地理和三阶段探索；world_routes持有具体行程、起始资格、本地动作与收益；review_groups用于手机片区筛选，onboarding_guidance持有工坊短访的提示与收益安排。新增房、改口、资格和动作调整均在候选清单，房形与门位在片区源，不复制第二份身份或拓扑。

全世界原有地理编排保持；本轮新增K25外院交接庭，G37交货台、G39观钟廊、G38街梯，以及N23—N25检修井段。古堡外院经K06沿C16进入工城上街，不必先修古堡钟；K11另以KG-ARCHIVE-HIGH接高庭。供料廊的档案和收藏入口同步锁定，避免新增来向绕过纹章、修钟或HWDQ收藏挑战。

C20矿货升降仍到东站，C21恢复为矿井到工坊试射室的第二来向，s21在N23内侧操作，开后双向。退役N04—N06交班转场及G26已无作用的access:H_D分区。城市上街通过配重梯实际接上高庭；主炉修复恢复供能，HDQ段有稳定准备台。工城跨区接口由6增至9（其中P31与P07是同一农货线的两个上车点），连接5个外部区域；全图32对连续跨区接缝、20对显式交通，无待定接缝。

P31新增修复风鸣钟后直达工坊的同线驿车，不必先穿越平原东部。P10约定、P15修钟提示与P31站牌共同引导，跳过剧情也保留获知；这些提示和交通仅为候选，未改正式剧情或平台。六条行程覆盖H首访救匠人并完成攻击升级、HW古堡来访、HD矿井来访、深矿携材料回工坊、赴炉与新回程、修炉后高庭回访。行程沿指定的相邻房顺序验证，开关只在作者指定位置操作，不用全世界寻路绕过失败段；它们是可选探索顺序样例，不强制玩家每条都走。赴炉不要求先打工城督工；修总钟仍要求督工已败。现有奖励、NPC、Boss、服务身份与平原实例保持。

专业审图检查四区整体、上街到高庭连续性及矿井到工坊的空间关系。机关职责改为停线救人、离合放桥、井盖回程和供能恢复；这些是候选设计，尚未施工动作、车辆或演出，不把文字与图上成立视为玩法完成。
