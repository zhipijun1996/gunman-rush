## 基线与当前失败

用户指定PR156，以来源修复dfd3bae接续；工作分支feat/world-spatial-layout，[PR158](https://github.com/zhipijun1996/gunman-rush/pull/158)已退回草稿。用户明确否定全世界309房自动排布的空间质量。world-layout-preview.1发行已撤回公开展示，不能继续推荐其中的导入文件，也不能把无重叠和连接完备当成设计验收。

失败原因是按旧中心、统一尺度和避重叠摆房，再用路径连接；森林还错误丢弃了原设计中已属于房间的通道占地。结果呈现孤立块体和长细线，60处分层交叉与53条长通道被当作待审项交付，没有在空间编排阶段解决。

## 当前修正

删除自动全世界排布数据和无继续消费者的泛用画线审核器，历史留Git。spatial_layout.json仅登记森林校准范围，几何仍由game/world/regions/F/room_design.json唯一拥有；不另外复制一套森林。导出完整主体与通道占地，30对区内门在同一世界坐标共享接缝，5外接口保留预留方向；平原35房仍为不变的同尺度基准。默认正式导出与运行均不变，其它尚未编排区域仍标未定位。

森林原设计只是恢复正确的数据表示，不意味着已经达到平原的空间、美术或玩法质量。校准图明确标为对照与未验收；不重新发布为全世界完成版。下一步应联合森林主体、全部出口、枢纽和回环留白重新编排，缩短无职责连接，按已成立平原比例比较后再扩展相邻区域。
