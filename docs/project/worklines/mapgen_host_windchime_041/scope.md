## 实现与收敛

普通家园出发经 RunSession.PlainsMapGeneration → RuntimeMapV2Provider → LevelPlan／公共 Runtime → MapgenPlainsStage。完整装入 SDK 的实例、连接、原始几何和受支持对象，复用原敌人工厂、伤害、掉落、宝箱／商店、Boss、地图、UI和美术；两图之后仍为金色奖励、H选择、森林 v15。改动入口见 [模块导航](../../module_map.md)。

五个共用生成组件迁入 `game/world/generation/mapgen/`，保留 UID；实验切片引用同一实现。旧平原生成器只服务显式旧版本／试验和原 Manifest 校验，普通出发没有旧地图回退。

[宿主配置](../../../../config/plains_mapgen.json) 维护44个兼容模块及62个排除项。请求读取真实身体、武器与当前已授予能力；没有暗授二跳或H。基础武器的反向闪现仅投影为 SDK 的名义反冲标签，具体距离、时序和连续路线仍由真实运动验证。生成在同一实际种子上使用常规／提前预留两种 SDK 搜索配置，最多五个种子；保留原始搜索错误，PASS后的宿主拒绝直接失败。

生成视图随 App 释放并支持返回家园；地图在物理准入成功后提交到本局缓存。重装使用已提交结果。Manifest保存整数精度完整的地图、内容、请求和绑定，排除计时等观察值；存档重建核来源、配置、种子作用域和内容身份，不重新生成地图。Manifest仍只用于内容复现，不提供中途续局。

## 上游与后续边界

- **SDK搜索**：基础能力和当前兼容池下，种子 `636655029801813` 等会以 `SEARCH_EXHAUSTED / no_goal_and_reservation_compatible_boss` 退出，诊断含 `boss_reward_space_reservation`。宿主两种预留配置与有界重试已覆盖本次失败样本；上游仍需改进真实入口下的奖励空间预留、终点搜索及回溯，不能保证任意种子成功。
- **Boss模块合同**：1.1.0的 `game-plains-bellstrider-arena` catalog.purpose为“鸣铃巡游机战场”，而SDK只接纳 `boss_arena` 终点。若要指定该专用战场，上游需规范用途字段并提供适合现行Boss的战场／站立区合同。本次在SDK已支持的Boss模块原生宽地面上分别绑定既有两位Boss，没有篡改库元数据。
- **扩展模块**：垂直端口、HQ组运动、成对／联动门以及附带未消费字段等在生成前排除；它们属于待接宿主能力，不能全部算作SDK缺陷。扩池前按排除原因补目标身份、联动／时钟恢复合同和消费者，再以真实身体验证。名义能力标签也需上游补足跨武器距离／时序及连续接缝资格。
