# 平原怪物全动作交付

## 目标与输入

用户批准 B/C 造型及同屏明暗分离，授权七类普通怪、鸣铃巡游机、牧风者全部静态／待机、移动、攻击前摇、攻击、后摇、受伤、死亡；牧风者二阶段的大风车直接从头顶生长。采用 PR142 `cc62d369d3cec2597db483f1137ff976e25863cf` 地形和背景，分支 `art/plains-enemy-static-pr142`，PR144 面向 main。此次修复基线 `f7b6e49`；交付提交由 Git/PR 追溯。

批准稿来源 `a5668a4` 的十张静态 PNG 保留原字节。D 与另起的兽类候选已删除，不再作为生产输入。保留 B/C 形体、装饰和像素尺度，以象牙白、青绿及铜色的小范围明暗分离解决背景混淆。

## 制作与正式接入

`assets/plains_actors_142/` 包含十张批准静态、55张动画图集、1129个运行帧（784个独立绘制姿势，345个关键帧复用，含攻击尺度校准行）。七怪七动作、巡游机三套招式、牧风者每阶段六套招式及头顶风车转换接入正式表现。待机／移动为八帧循环；Boss前摇、攻击、收招、受伤和死亡为九帧，风车生长两段各九帧。本轮增加212个绘制姿势，原关键帧保持字节一致。

`*_flow` 每行动作包含上一动作端点、原四个关键帧与四个新绘中间姿势。前摇末帧等于攻击首帧、攻击末帧等于收招首帧；长恢复期在0.72秒内完成收势，再保持末姿，不改变实际恢复窗口和伤害时钟。原基础图集仍作为动作来源、校准和现有消费者输入；无消费者的候选素材不保留。

图像生成原图、提示词和裁切配置保存在 `source/`，`.gdignore` 阻止原图进入游戏导入。冲锋怪最初生成的完整提示词未留在本地，元数据明确此限制。`build_plains_actor_animations.py` 只做透明阈值、连通域清理、按行内透明间隔识别四列姿势、固定身体尺度／配准和最近邻烘焙，不绘制姿势。原生像素对应世界单位，图集有两像素透明间隔；Boss 以核心至地面的身体高度标定，每帧记录核心与所需炮口位置；新增巡游机炮口在新姿势上重新测量，牧风者出口跟随新帧核心偏移。

用户报告牧风者残留底色，实查确认一阶段扑击和二阶段横扫共32姿势存在大片灰白底色，已由图像编辑清理源图并重新烘焙。两份 `.alpha.json` 记录原输入、编辑提示词和输出来源。其余牧风者图集做中性灰连通域检查并在对比底色上抽查高值候选；小块象牙材质与腿部阴影保留，不按灰色一刀切删除。

俯冲怪在预告开始时锁定玩家实际XY，不再把X夹到巢点范围或把Y固定在巢点下方。出手后直线到达锁定点，速度至少覆盖完整冲程；玩家躲开后不追踪转弯，地形或玩家身体阻挡会结束俯冲。

普通怪通过 `UnderworldEnemy` → `PlainsRevisionVisual` → `PlainsActorSkin` 消费正式帧图。受伤来自已接受事件；死亡由真实地形支撑与尸体持久化负责。俯冲怪／腾空跳跃怪在空中死亡后先下坠，落地再完成死亡；当前俯冲怪实战片段实测下落约40世界单位；新增实际Actor致死、暂停与真实落地检查。定点怪不新增走路 AI，巡逻怪不新增攻击 AI，完整动作库可独立检视。

两位 Boss 的 Presentation 消费 Encounter 的状态、阶段、时间和已接受事件。`PlainsBossFrames` 以 Encounter 缓存按需加载，切阶段清空旧缓存，离房释放。核心随图像对齐；巡游机后置炮管由同帧裁切并围绕铰点瞄准，真实投射物从炮口发出。牧风者种子出口与喙部对齐，横扫消费正式碰撞端点。

牧风者腾空致死后立即取消活体扑击／跨台推进，停止伤害和风场，使用配置重力下落至实际向上地形表面，随后推进坍塌与结算。下坠速度纳入快照，暂停冻结；不再沿原锁定跳跃继续飞行。奖励可达性和幂等仍由正式系统负责。

生产材质 `plains_actor_separation.gdshader` 保持已批准的明暗分离、场景光照，不画外部光圈。背景、TileSet、主角和相机规则未修改。无消费者的旧 Boss 绘制函数已移除；被旧回归使用的资源保留。

## 复现与查看

- `python3 tools/art/build_plains_actor_animations.py` 从源图生成图集与Godot资源，可传单个图集ID。
- `python3 tools/art/package_plains_actor_animations.py` 检查尺寸、透明边距、动作差异、八帧循环与九帧动作中的原关键帧及衔接端点字节一致性，生成哈希清单、逐帧网页及ZIP。网页只持有当前图像；离线查看需保留 `review-assets/` 相对目录。
- `tools/art/capture_plains_enemy_combat.gd` 在真实P-R06地形布置一只审查怪，用正式Actor、AI、Router、投射物、伤害与尸体系统录制七段实战；单怪位置是显式夹具。
- `tools/art/capture_plains_actor_combat.gd` 在正式P-R11／P-R14录制两Boss及牧风者二阶段。开场位置与二阶段生命阈值是夹具；录制专用宽镜头按双方包围范围取景（最大1.5倍），同时保留反冲跳跃与地面，正式游戏相机不改，其余状态和时钟自然推进。字幕显示当前动作，不代表自然通关或覆盖所有随机组合。
- 图形捕获使用 `DISPLAY=:97 bash tools/godot.sh --path . --rendering-method gl_compatibility --audio-driver Dummy --fixed-fps 60 --write-movie build/plains_actors_142/<name>.avi --script <capture-script>`。全录普通怪母版为 `enemy-combat.avi`，Boss为 `combat-revision.avi`；本轮仅重录普通怪中的俯冲，命令追加 `-- diver` 并输出 `diver-combat.avi`；分段时间来自各自 `timeline.json`。
- `python3 tools/art/package_plains_actor_mobile.py` 从上述实际战斗母版切十段独立MP4，输出 `build/plains_actors_142/mobile-combat/`。本轮使用 `--enemy-master diver-combat.avi --reuse-manifest build/plains_actors_142/unchanged-clips.json`，复用清单记录六段原源提交与SHA256，打包先核哈希。960×540、60fps、游戏原声、H.264 Baseline、faststart，每段小于3MB。定点动作播放仅保留为素材库复核，不再作为默认手机交付。

## 实际验证与边界

本次通过CI四项；帧绑定、九帧动作／衔接端点、恢复末姿、受伤、暂停和落地277项；俯冲实际AI锁点、直线、躲避、到达玩家／锁点及墙阻挡89项；敌人结构733项、遭遇策略55项；牧风者六组专项（1198／97／76／63／139／130项）；巡游机战斗276项、武器88项。结构检查发现巡游机只读快照携带动画Resource，现已仅保留帧标识和几何值，正式渲染仍由宿主读取资源。

图集检查55张／1129运行帧／784独立绘制姿势／十张静态，原关键帧保留、透明边距与每行姿势差异通过。新增Boss图集全部帧未发现超过250像素的高亮中性灰连通底色，并在对比底色上检查造型。浏览器检查133种角色／招式／动作选择及4／8／9帧滑块，390px布局无脚本错误，十个视频链接均存在，十段MP4在浏览器实际解码播放，H.264 Baseline／AAC／60fps／faststart与小于3MB限制通过。日志在 `build/plains_actors_142/` 的 `*-flow*.log`。

额外运行旧生成关卡的 `plains_exploration_pressure_runner.gd`：5项通过，零伤害断言失败（HP 5→4，连续路径和到站成功）。将俯冲策略换回基线 `f7b6e49` 后，相同种子、路径和伤害结果仍复现；这不是本轮俯冲修改引入的回归，不宣称该旧路线已能无伤通过。

制作方审查了八帧运动、九帧动作接续、透明边缘及实战中的主角／怪物／地形相对位置。最终Boss录制实际覆盖牧风者一阶段扑击、二阶段横扫，可直接复核两组残留底色修复；二阶段也出现头顶风车转换、移动、种子与死亡，一阶段覆盖踏击、种子和扑击。正式战斗录像保留真实受击与伤害，不把原地轮播当战斗。普通怪片段覆盖各自实际拥有的AI动作；跳跃怪空中死亡专项由受控致死测试验证，实战片段未必在跳跃最高点击杀。物理身体和伤害范围由正式骨架／配置承担，不等于装饰轮廓。现行游戏跟随相机在双方拉开时可能裁到Boss远侧；本次Boss录像使用已标注的审查宽镜头，以便看清双方和真实地面，不能据此声称正式相机在所有站位都能完整合屏。软件渲染录制耗时包含编码，不能作为目标设备帧率。未执行自然通关、手机真机验收、合并或部署；用户审美反馈与机器检查分开。
