# 平原怪物与 Boss 动画当前交接

## 目标与基线

用户已批准整体风格及七类小怪。本轮接续草稿 PR144，保留 PR142 背景、批准 B/C 造型和现有固定骨骼部件，处理巡游机转向、牧风者转身与后跳脱身、二阶段展开演出、身体与边界墙重叠。

分支 `art/plains-enemy-static-pr142`，本轮基线 `937454930d74cfc2ed217d63dba5e07589ae8d4f`，面向 main。运行源码为本提交；后续交接提交补入源码与预览的完整 SHA。`assets/` 与十张批准静态相对基线无改动；七类小怪图集、AI、死亡落地与既有视频保留。

## 当前实现

两 Boss 沿现有 Skeleton2D／Bone2D 固定分层素材与接受战斗时钟采样。巡游机换向时轮组经过前后错开的弧线，轮辐相位不随视角回卷，正面轮胎保持竖直，保留先刹停再回身的节拍。

牧风者换边增加交错抬足，并在接受新方向前保存已显示的转身终点，避免结束时重新镜像。转完后承诺当前出手方向，玩家再次换边不会导致无尽转身。接近状态恢复原来的接近目标；跨台预备也经过转身。

贴身或前进受阻时，下一次攻击预备可进入压低／后跳／落地，再继续原招组。后跳有冷却，方向与落点在预备时锁定；地面落点检查前后脚和中心的真实支撑，第三阶段使用现有跨台轨迹与真实支撑。保存恢复包含后跳、冷却、转身后续状态和风车起始时钟，死亡继续由既有重力落地终态负责。

二阶段使用同一头部附件依次抬起支架、从轴心向外展开四片原生风叶，再加速旋转；支架到位前不显示孤立轴心。全屏稀疏风压／光晕与短震动消费阶段时钟；表现只叠加自己的镜头偏移，暂停冻结，暂停中取消也立即清理，退出不留下镜头偏移。第三阶段保留已展开风车，不重复生长。身体尺寸不随展开变化。

地面移动按完整躯干、头部与披风留出墙边余量，伤害仍沿真实躯干和关节。高台落点另查真实实体墙，不按地面巡逻边界截断飞行；单向桥面继续允许巨兽身体处于其后方。旧生成地图最右棚台不能容纳完整身体，会被 Boss 落点检查拒绝，玩家地形保留。其支撑回归的初始站位夹具改选能容纳完整身体的棚台，并增加墙边无效落点反例；原有跨台、空中快照、实际落地、死亡和奖励断言保留。

`tools/art/capture_plains_actor_combat.gd` 在 P-R11／P-R14 运行真实 AI、Router 输入、伤害、投射物及地形。一阶段自动玩家通过普通移动／跳跃绕背并贴近，实际触发转身和后跳；二阶段设生命阈值以观察展开与吹风。开场站位、生命阈值及固定倍率宽镜头均在片内标注；镜头只平移，不改变角色倍率。该覆盖不代表自然通关或全随机招组。
