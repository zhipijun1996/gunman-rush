# 平原怪物与 Boss 动作交付

## 目标与输入

用户已确认七类小怪没有问题，本轮只继续修两位Boss：巡游机快速冲锋／转向，牧风者一阶段主动接近与更快节奏，二阶段头顶风车吹风配合远程攻击，以及两Boss的地波／弹体美术和特效。

采用PR142 `cc62d369d3cec2597db483f1137ff976e25863cf` 的地形和背景，分支 `art/plains-enemy-static-pr142`，PR144面向main。本轮基线 `f416f80`；交付提交由Git／PR追溯。十张 `a5668a4` 批准静态保留原字节；D及另起兽类候选已删除。用户批准B/C形体、象牙白／青绿／铜色明暗分离及小怪结果，尚未对本轮Boss给出审美结论。

## 当前实现

`assets/plains_actors_142/` 有58张身体图集、1156运行帧、805独立绘制姿势及十张批准静态。待机／移动八帧，Boss前摇／攻击／收招／受伤／死亡九帧，风车生长两段各九帧。`*_flow`保留原关键帧，前摇末帧等于攻击首帧，攻击末帧等于收招首帧；长收招先回稳再保持末姿。

三套新增九帧转向覆盖巡游机与牧风者一／二阶段：侧面、四分之三视角、正面、另一侧，保持承重与头部附件；首尾使用原待机及其镜像，新增21个中间姿势。转向时保持原绘制基准，结束后才切逻辑朝向。巡游机普通换边、远距离接近、后炮瞄准及回冲统一经过真实转向状态；其中的朝向、续接动作和时间支持JSON快照恢复。牧风者也消费完整回身姿势。

巡游机冲锋速度按正式资源提高到600／680，保留完整前摇、加速、碰撞阻挡与收势，轮下出现跟随真实位移的扬尘，刹停／回身产生短促扬尘。远距离接近仍先完成转向再移动，选招计划和随机状态不因回身重新抽取；后置炮管转到玩家一侧后才进入瞄准。

牧风者一阶段将接近阈值、步速、短扑、预告、连招间隔和恢复调整为更主动的节奏。重踏也先走入实际近战准备距离，不在较远处反复空踏；接近有时限与支撑保护，保留反制窗口。二阶段提高风压／远程组合的权重，风压持续中按Definition的两个固定时点发出风籽齐射，沿预告锁定的目标射击，最终恢复不补发。风从当前帧实测的头顶风车轴心流向作用区域；风压实际推力仍通过PlayerMotor原有局部速度接口，死亡和取消立即止风。快照记录已发风籽轮次，恢复不重播第一轮。

`assets/plains_boss_fx_142/` 新增两张效果图集、32绘制帧：巡游机地波、翻转铜铃、铜金冲击与轮尘；牧风者风籽、地波、叶屑冲击与定向风束。发射、碰撞、落足、刹停均消费真实事件；装饰尾迹不改变伤害几何。波前缘按实际半径绘制，铜铃落点震荡按真实表面方向和局部伤害范围绘制。旧圈线／多边形弹体绘制被这些素材替换，基类仅增加可覆写的表现钩子，其余敌人沿原消费者。

效果实例由房间持有，弱引用检查Encounter、攻击epoch和终态；数量有上限，暂停冻结，取消、死亡、恢复和切房释放。风车轴心从现有二阶段风压图集逐帧测量，弹体从该实际显示位置发出。身体主铃／核心仍随图像定位，巡游机炮管从同帧裁切并绕铰点瞄准，只读状态快照不暴露实时Resource。

普通怪保持上一交付：俯冲预告锁定玩家实际XY后直冲完整距离，躲开不追踪，实体阻挡结束攻击；空中死亡先受重力落到真实地形再坍塌。牧风者腾空死亡停止活体跳跃，落地后坍塌，速度可快照且暂停冻结，奖励按原世界幂等链结算。定点怪和巡逻怪没有为展示动画新增AI。

## 素材来源与复现

生成原图、提示词、参考提交、裁切配置保存在各素材目录的 `source/`，`.gdignore`阻止生成原图进入运行导入。Python只做alpha阈值、连通域清理、透明间隔分列、裁切、身体配准／最近邻采样和几何测量，不绘制姿势。牧风者一阶段扑击、二阶段横扫先前残留底色已清理，原 `.alpha.json`记录继续保留。

- `python tools/art/build_plains_actor_animations.py` 烘焙身体图集，可传单个ID；转向分三行三列并保留原首尾关键帧。
- `python tools/art/build_plains_boss_fx.py` 烘焙两套效果，保持冲击扩散尺度，并生成风车轴心数据；效果清单记录源图与图集哈希。
- `python tools/art/package_plains_actor_animations.py` 检查边距、姿势差异、原关键帧和转向镜像端点，生成按需加载单图的检视页及完整素材ZIP；转向检视往返播放。
- `tools/art/capture_plains_actor_combat.gd` 在正式P-R11／P-R14，使用正常Router输入、AI、伤害、真实投射物和地形，录四段：巡游机冲锋／转向、巡游机地波／抛铃、牧风者主动接近、风车风压／远程。仅开场位置、二阶段生命阈值和标注的审查宽镜头为夹具，不修改正式相机。
- 图形捕获：`DISPLAY=:97 bash tools/godot.sh --path . --rendering-method gl_compatibility --audio-driver Dummy --fixed-fps 60 --write-movie build/plains_actors_142/combat-actions.avi --script tools/art/capture_plains_actor_combat.gd`。可传角色列表、秒数、`trace`进行无截图的逻辑预跑；预跑不是画面验收。
- `python tools/art/package_plains_actor_mobile.py --skip-enemies --boss-master combat-actions.avi --reuse-manifest build/plains_actors_142/unchanged-enemies.json` 将四段新Boss录像与七段已确认的小怪录像组合。复用前核原SHA256，清单保留各自源提交，不能把复用片段标成新录制。

## 验证与边界

专项确认：转向中途快照／多姿势／最终朝向，真实冲锋达到600并在半秒位移约257wu；牧风者接近约222wu后在距玩家约168wu开始重踏前摇；风车风压内两轮齐射、从头顶实际轴心发射、恢复不重播／不补射，以及特效暂停／取消／切房，共25项通过。巡游机战斗281项、武器88项；牧风者时钟1198项、攻击几何97项、支撑76项、正式App63项、奖励139项、音频130项通过。原四帧动画没有被用作新的转身体积姿势。

CI四项、帧绑定277项、身体图集58张／1156帧／805独立姿势及透明间隔、关键帧／镜像端点检查通过。新素材在对比底色上审查，风籽和地波前缘与碰撞中心配准；实战抽帧确认回身的正面／四分之三姿势、冲锋位移、地波和头顶风束，播放器按正常1×完整播放四段新Boss视频。网页136个动作选择和11个视频入口通过。四段新片分别约2.24、1.95、2.24、1.74MB；11段均核H.264 Baseline／AAC、60fps、faststart和体积，七段复用原哈希保持不变。

实际战斗用原生伤害，录制者通过合法移动／跳跃／射击展示招式。录制站位使巡游机冲锋、转身与地波均能出现，牧风者展示接近、短扑、踏地／风籽和头顶吹风。短片不是自然通关，也不覆盖全部随机组合。物理身体／伤害范围由正式骨架与配置承担，不等于所有装饰轮廓；审查宽镜头不证明正式跟随相机在所有站位均能合屏。软件渲染与编码耗时不是目标设备帧率；没有手机真机验收、合并或游戏部署。

旧生成渡船路线零伤害测试在上一轮及基线俯冲策略下均为HP 5→4，路径与到站通过；本轮不修改该旧路线，不宣称其无伤验证通过。
