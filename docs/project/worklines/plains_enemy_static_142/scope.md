# 平原怪物全动作交付

## 目标与输入

用户批准 B/C 造型及同屏明暗分离，授权七类普通怪、鸣铃巡游机、牧风者全部静态／待机、移动、攻击前摇、攻击、后摇、受伤、死亡；牧风者二阶段的大风车直接从头顶生长。采用 PR142 `cc62d369d3cec2597db483f1137ff976e25863cf` 地形和背景，分支 `art/plains-enemy-static-pr142`，PR144 面向 main。此次修复基线 `0c59134`；交付提交由 Git/PR 追溯。

批准稿来源 `a5668a4` 的十张静态 PNG 保留原字节。D 与另起的兽类候选已删除，不再作为生产输入。保留 B/C 形体、装饰和像素尺度，以象牙白、青绿及铜色的小范围明暗分离解决背景混淆。

## 制作与正式接入

`assets/plains_actors_142/` 包含十张批准静态、36 张动画图集、652 个运行帧（572 个独立绘制姿势，含攻击尺度校准行；80 个已有关键帧在运动图集中复用）。七怪七动作、巡游机三套招式、牧风者每阶段六套招式及八帧头顶风车转换均接入正式表现。新增十张待机／移动过渡源图，原四关键帧原样保留在偶数序号，新绘中间姿势放在奇数序号，循环扩至八帧；前后摇、攻击、受伤、死亡仍按各自正式时钟播放，不改伤害窗口。

图像生成原图、提示词和裁切配置保存在 `source/`，`.gdignore` 阻止原图进入游戏导入。冲锋怪最初生成的完整提示词未留在本地，元数据明确此限制。`build_plains_actor_animations.py` 只做透明阈值、连通域清理、裁切、固定身体尺度／配准和最近邻烘焙，不绘制姿势。原生像素对应世界单位，图集有两像素透明间隔；Boss 以核心至地面的身体高度标定，每帧记录核心与所需炮口位置。

用户报告牧风者残留底色，实查确认一阶段扑击和二阶段横扫共32姿势存在大片灰白底色，已由图像编辑清理源图并重新烘焙。两份 `.alpha.json` 记录原输入、编辑提示词和输出来源。其余牧风者图集做中性灰连通域检查并在对比底色上抽查高值候选；小块象牙材质与腿部阴影保留，不按灰色一刀切删除。

普通怪通过 `UnderworldEnemy` → `PlainsRevisionVisual` → `PlainsActorSkin` 消费正式帧图。受伤来自已接受事件；死亡由真实地形支撑与尸体持久化负责。俯冲怪／腾空跳跃怪在空中死亡后先下坠，落地再完成死亡；俯冲怪实战片段实测下落120世界单位；新增实际Actor致死、暂停与真实落地检查。定点怪不新增走路 AI，巡逻怪不新增攻击 AI，完整动作库可独立检视。

两位 Boss 的 Presentation 消费 Encounter 的状态、阶段、时间和已接受事件。`PlainsBossFrames` 以 Encounter 缓存按需加载，切阶段清空旧缓存，离房释放。核心随图像对齐；巡游机后置炮管由同帧裁切并围绕铰点瞄准，真实投射物从炮口发出。牧风者种子出口与喙部对齐，横扫消费正式碰撞端点。

牧风者腾空致死后立即取消活体扑击／跨台推进，停止伤害和风场，使用配置重力下落至实际向上地形表面，随后推进坍塌与结算。下坠速度纳入快照，暂停冻结；不再沿原锁定跳跃继续飞行。奖励可达性和幂等仍由正式系统负责。

生产材质 `plains_actor_separation.gdshader` 保持已批准的明暗分离、场景光照，不画外部光圈。背景、TileSet、主角和相机规则未修改。无消费者的旧 Boss 绘制函数已移除；被旧回归使用的资源保留。

## 复现与查看

- `python3 tools/art/build_plains_actor_animations.py` 从源图生成图集与Godot资源，可传单个图集ID。
- `python3 tools/art/package_plains_actor_animations.py` 检查尺寸、透明边距、动作差异和八帧循环中的原关键帧字节一致性，生成哈希清单、逐帧网页及ZIP。网页只持有当前图像；离线查看需保留 `review-assets/` 相对目录。
- `tools/art/capture_plains_enemy_combat.gd` 在真实P-R06地形布置一只审查怪，用正式Actor、AI、Router、投射物、伤害与尸体系统录制七段实战；单怪位置是显式夹具。
- `tools/art/capture_plains_actor_combat.gd` 在正式P-R11／P-R14录制两Boss及牧风者二阶段。开场位置与二阶段生命阈值是夹具；录制专用宽镜头按双方包围范围取景（最大1.5倍），同时保留反冲跳跃与地面，正式游戏相机不改，其余状态和时钟自然推进。字幕显示当前动作，不代表自然通关或覆盖所有随机组合。
- 图形捕获使用 `DISPLAY=:97 bash tools/godot.sh --path . --rendering-method gl_compatibility --audio-driver Dummy --fixed-fps 60 --write-movie build/plains_actors_142/<name>.avi --script <capture-script>`。普通怪母版为 `enemy-combat.avi`，Boss为 `combat-revision.avi`；分段时间来自各自 `timeline.json`。
- `python3 tools/art/package_plains_actor_mobile.py` 从上述实际战斗母版切十段独立MP4，输出 `build/plains_actors_142/mobile-combat/`。960×540、60fps、游戏原声、H.264 Baseline、faststart，每段小于3MB。定点动作播放仅保留为素材库复核，不再作为默认手机交付。

## 实际验证与边界

本次通过CI四项；普通怪帧绑定／八帧循环／受伤／暂停／空中死亡与落地205项；牧风者六组专项，另补终态下坠的快照速度与暂停检查，支撑专项76项；巡游机战斗276项和武器88项。图集检查36张／652运行帧／572独立姿势／十张静态，原关键帧保留、透明边距与每行姿势差异通过。浏览器检查133种角色／招式／动作选择、4／8帧滑块及390px布局，无脚本错误。日志在 `build/plains_actors_142/` 的 `*-revision*.log`。

制作方审查了八帧运动接续、透明边缘及实战中的主角／怪物／地形相对位置。最终Boss录制实际覆盖牧风者一阶段扑击、二阶段横扫，可直接复核两组残留底色修复；二阶段也出现头顶风车转换、移动、种子、扑击与死亡。正式战斗录像保留真实受击与伤害，不把原地轮播当战斗。普通怪片段覆盖各自实际拥有的AI动作；跳跃怪空中死亡专项由受控致死测试验证，实战片段未必在跳跃最高点击杀。物理身体和伤害范围由正式骨架／配置承担，不等于装饰轮廓。现行游戏跟随相机在双方拉开时可能裁到Boss远侧；本次Boss录像使用已标注的审查宽镜头，以便看清双方和真实地面，不能据此声称正式相机在所有站位都能完整合屏。软件渲染录制耗时包含编码，不能作为目标设备帧率。未执行自然通关、手机真机验收、合并或部署；用户审美反馈与机器检查分开。
