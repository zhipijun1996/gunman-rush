制作方观察：室外兽类、飞禽与守卫的轮廓可区分，颜色与原主角及建筑材质有共同来源；室内哨兵炮管、根铃钟腔及飞禽浅腹可见，树干和深木在暗部仍有细节损失。巡游机主铃外露，牧风者头顶四叶风车完整可见。两Boss明显大于主角。上述只是静态观察，不代签用户审美审批，也不声称动态威胁、场地净空或碰撞适配通过。

正式Boss场地相机将地面压在视口底边，二阶段风车接近上方HUD区域；本轮未改变相机掩盖问题。审批后的动作与可玩验证须检查旋转风帆、头部移动、HUD遮挡和反冲空间。
