# 永久装备交接

本次变更基于 main 的 `2245283f`，工作分支为 `feat/permanent-equipment`。设计依据是[装备系统](../../../data/items.md)，接入方式见[装备制作](../../item_authoring.md)。

重做版正式目录共 60 件。40 个原有 ID 继续使用，移出 32 个旧 ID，新增 20 个。14 件装备支持两个金币强化阶段。旧目录、出现权重、旧库存实例和协同配置已经从重做工程清理。冻结入口保有其历史内容。

世界奖励、装配界面与强化师向同一世界状态提交，玩家和武器消费当前装配。写盘失败时保留原资源、等级和来源状态。逐包战斗触发读取实际伤害提交；环境门使用当前装配。集成验证入口为 `python3 tools/check_ordinary_rooms.py`。

60 件装备各自具备独立图标。领取点、背包列表和详情按永久 ID 共享纹理；强化师使用独立角色动画。素材来源与维护入口见[装备制作](../../item_authoring.md)。

正式新房与连接尚待设计。房间作者须为每个正式来源指定实际可达的位置，将交易、直接拾取与物品门放入对应房间，并在正式地图上验收路线。
