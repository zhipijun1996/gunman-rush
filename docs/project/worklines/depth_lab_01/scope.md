# 纯2D引擎前置制作试验

用户选择先在Godot确定相机、真实角色与地形、空间结构和渲染职责，再约束生图、验证代表结构；本轮采用纯2D，不启动3D迁移。目标是减少概念图转实机时的重绘和隐含光影损失。当前仅固定机位代表结构，未视为正式房间、完整素材库或美术认可。

分支codex/depth-lab，本轮基线6231784；方法、素材和场景提交2ba98c6783413dfa2ee10690b9dc6d0962c32474。仍依赖PR156地形系统，尚未并入main。正式房间、玩法、机关定义、编辑器和游戏发行入口未替换。

## 当前方法与职责

仓库.agents/skills/godot-room-art/SKILL.md及references/engine-first-2d.md定义方法。云端同名Skill仍未回写，当前接口仅能读；观看页提供25文件的新版方法ZIP／TAR.GZ，完整项目素材归仓库。原五区认可不扩展为本轮候选认可。

参数唯一入口config/art/engine_first_2d.json；运行入口game/presentation/experiments/engine_first_2d/room.tscn：

| 内容 | 本轮消费者与约束 |
| --- | --- |
| 相机与比例 | Camera2D固定机位，1280×720、1wu／1px，与正式视口／尺度一致；不是正式WorldCamera连续游玩验证 |
| 地形与角色 | 生图前已有TerrainComposer的windchime_plains两岸、正式44wu角色；风铃使用现有表现消费者同源图像，仅接表现，无机关行为验证 |
| 静态环境 | 一张连贯生产组画，承担环境、桥身材质与静态环境明暗；不包含人物、风铃和局部暖光 |
| 受光分区 | 结构遮罩在生图前由灰盒导出；同张原生纹理按同坐标互补遮罩分区，PointLight2D只照结构分区及实际地形／风铃，远景不受光 |
| 水面 | 实际screen-texture反射。代表结构测试后补充前景水面，覆盖下部岸体断面，使钟龛下方反射可见；站立边缘未改，未验证物理水域 |

这些受光片段不是已补全背景的独立资产，不可单独移动或视差。静态组画使用共同世界坐标；未恢复遮挡后图像，也未证明能覆盖长房或移动相机。L／W／T切换局部光、水面、地形；空格仅演示风铃与水纹动画，不接正式控制器。

## 实际制作与筛选

先捕获真实角色、地形、结构、铃位与局部光的Godot灰盒；再隐藏动态实体／局部光得到绘制输入，并导出结构遮罩。assets/engine_first_2d/source/render-input*.json、配置快照与PNG哈希记录生成前输入。提高灰盒对比后发现并修正桥墩与桥身的接合，正式生成输入使用修正后的连续结构。

首张生图受到旧整景参考影响，中间桥墩一侧约偏40显示像素，水岸也改变；记录rejected_geometry，不通过移动遮罩迁就它。第二次只送入修正后的引擎绘制输入与正式地形参照，基本遵循两岸、桥墩与钟龛；拱缘有少量绘制偏差，未声称模型做到像素级几何锁定。完整提示词和真正送入的参考归source/generation.json与attempt01-prompt.json。

生产组画一次nearest烘焙至1280×720后，所有受光片段复用同一纹理，不再让AI分别重画桥体或远景。原始绘画→原生烘焙→预先遮罩→实际动态内容的来源归assets/engine_first_2d/manifest.json及tools/bake_engine_first_2d.py。生成前配置快照与代表结构细化后的运行配置分别保留，不把后续修改伪称为生成前已固定。

初次实际合屏发现前岸遮住钟龛的反射；修订水面职责与前景覆盖，复验可见反射和实际受光。当前有实帧、生成前灰盒、绘制输入、生产底图、关灯、关水面和预先遮罩七种观看视图。

## 证据与判断

- 实际Godot4.7.2窗口捕获，无Node3D；导入和运行无脚本／引擎错误。仅有llvmpipe驱动不支持调整V-Sync的警告。
- 关闭实际地形、角色、风铃、灯光和水面后，互补遮罩回拼与原生底图921,600／921,600像素RGB完全一致，最大通道误差0。这证明回拼忠实，不证明画面好看或符合全部灰盒轮廓。
- 灯光开关改变82,117个像素；y496以上、结构遮罩以外的检查区域改变0像素；钟龛下方反射检查区改变2,649像素。观察与计算范围归build/engine-first-2d/pixel-recombination.json，不扩张为完整光照物理正确性。
- build/engine-first-2d/editable.tscn可在本项目打开并运行3帧；依赖本项目资源，非独立运行包。8秒效果片为96张Godot真实帧按12fps导出，关光2秒／开光4秒／关光2秒，不是正式游玩录像。
- 日常CI四项通过，254项合同与39项保存断言无失败；文档检查通过。构建媒体和日志仅保留build，不提交为源素材。

制作者判断：本轮使“传图后又被重新画成另一套素材”的损失可检查、可避免；动态职责也能实际开关。当前石材细节仍偏密，整屏美术尚待用户评价，不宣布黄金样板。未验证正式运动／碰撞、完整机关行为、路线、战斗、跨房、独立视差或目标设备性能。

旧果园和第1轮引水渠实帧均维持用户否决。第1轮构图稿得到正向评价，实帧的重绘、地形和反射损失已推翻原先“仅颗粒不同”的判断；旧技术通过不抵消视觉失败。历史由Git和观看页折叠区追溯，不作为本轮制作基准。真实3D路线仅保留先前讨论，未选定或施工。
