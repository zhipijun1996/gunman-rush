# PLAYER-PRESENTATION-01 当前交接

目标：正式角色保持既有比例，提供共鸣回复的集气与释放动作、声音和特效。分支`fix/world-support-story-lighting`，基线main `f1e9e0e8`；进度由[任务表](../../tasks.md)维护。正式入口与工作台共用，休息站既有表现保持；尸体、小站教学及环境光修复见[平原交接](../plains_bible_v2_01/scope.md)。

## 当前实现

- WorldFocusHeal消费真实可接受的静止地面回复，PlayerAuthoredPoses使用独立收臂／集气／舒展补帧；持续向胸口汇聚光点，只有恢复与保存成功才向外扩散。GameAudio使用同一12声部池、可取消的集气声及短恢复和弦，不新增无限声源。原成本35、恢复1格、1秒蓄力和取消规则不变。
- [蓄力素材](../../../../assets/player_presentation_01/focus/README.md)按正式motion_v1母版统一缩放与脚底登记；不旋转原站姿。动作参数归player.json的focus_heal，减弱特效减少光点密度及亮度。失败保存、中断、暂停、切房和死亡没有成功反馈。

- 充电补帧与已校准的苏醒、贴墙、上下查看统一以当前正式默认角色motion_v1首帧为母版；头部、胸腹、靴子宽度及原脚底偏移按44wu显示尺度检查。充电使用10张独立姿态，退出接回当前原待机，不用旋转／缩放站姿代替进入和走出。源图、请求、统一尺度与锚点收据归[素材目录](../../../../assets/player_presentation_01/charging/README.md)。
- WorldRestSequence拥有趋近、入舱、充电、出舱和临时冻结；实际趋近沿PlayerMotor碰撞步进，途中失去支撑、挡路或新伤害会取消。WorldChargingStation使用黄铜拱架、暖灰石质内腔、侧线圈、前柱和底槛分层；青绿只留在线圈与电流，适配正式角色尺度并与草边接地。旧六帧站体和瞬时恢复光环消费者退休。
- FixedWorldApp仍为休息提交唯一主人。充电中段仅提交一次；成功才恢复HP、登记复位点并推进周期，播放恢复音与柔光。失败不改变资源与周期、不播成功反馈。共鸣、永久事实和当前房间怪物的延迟刷新规则保持，详见[休息与保存](../../../bible/home_and_save.md)。
- 电流和接通／恢复声音使用共享GameAudio有界声部，显式冻结世界时允许播放。暂停菜单冻结姿态、电流和声音；切房、退出、生命周期变化清除临时所有权。没有独立无限声源或无界粒子。
- 数值归RestPresentation资源：入舱0.64秒、充电1.4秒（0.85秒提交）、出舱0.72秒；闪光0.55秒，峰值透明度0.075，减弱特效0.025。苏醒、查看和墙面能力的既有规范不变。

- P01回收匠与柜台位于升降井东岸固定地面，归途钟台底座完整收在西岸，储物箱位于棚屋右侧；风铃架、路灯、告示与剧情NPC按实际平台接地。平台、两段载台和通路配置未改。

本轮7项比例／素材登记检查通过（新增蓄力头、胸腹、靴宽和脚底对比）；原生正常窗口实看集气、成功释放及取消，与当前待机合屏尺度一致。29项共鸣专项验证既有资源事务、键鼠／手柄／触控取消与新增姿态／声音／保存失败反馈；CI四项通过。正常速度蓄力短片6.7秒、约1.2MB，临时证据在build/world-feedback/，并非手机性能认证。

以下为既有充电站验证范围：

`tests/test_player_pose_registration.py`六项检查真实母版、中性头身／靴子宽度、脚底登记、统一缩放、充电帧差异及站体前后层像素来源。`rest-station`检查正常恢复、重复交互、保存失败、暂停、阻挡趋近、同帧伤害优先、减弱特效、切房和返回标题；`focus_heal`24项与`demo_regressions`20项分别验证共鸣不被休息重置、当前房间不当场复活敌人及离开后刷新。

本轮6项比例／素材登记检查、`station-grounding`与日常CI四项通过。接地专项在P01检查NPC双脚、摆件底座左右端与中心均有固定地面，拒绝把移动载台当永久支撑，并从实际站位触发两位服务NPC交互；该专项接入发行流水线。剧情回归将守路者的旧固定脚底坐标改为北口范围内的真实固定支撑检查，跳过剧情与钟心后开放北路均通过。正常Godot窗口实看西岸站体、完整充电、服务区、棚屋、东侧与高处落台，临时证据位于`build/round10/`。
