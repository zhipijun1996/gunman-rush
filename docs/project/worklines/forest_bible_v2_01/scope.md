# 森林整区初稿与灰盒接续

本轮交付24房地图和初版玩法方案，未施工森林运行场景。进度归[任务表](../../tasks.md)。现行候选与当前工作台的整区审核同步，准确发布身份见[工作台交接](../mobile_level_workbench_01/scope.md)；正式主游戏仍六房。

唯一候选为 `game/world/regions/F/room_design.json`。继承世界源的24房、30条内部连接、5个跨区接口、W／手里剑／Boss／修钟与唯一奖励身份；每房说明职责、阶段、动作生态、发现与返回和失败恢复。轮廓与连接共用世界坐标，C01锚定平原P04实际门位，通道纳入相邻房形。25处通道按实际空间加宽；树腹竖井、冠层横廊和根窟回环体现地区结构，短门颈与回程捷径保留收窄，统一等宽细管不再作为默认画法。占地仍待审核，不自动覆盖construction或扩大正式可玩范围。

[手机初稿](https://windchime-level-workbench.zhipijun1996.chatgpt.site/?review_region=F)在工作台“整区审核→荆棘森林”内提供完整图、五条路线、房号选择、双指缩放、相邻房跳转、每房方案和SVG下载。反馈暂存当前浏览器，复制回聊天才提交；不混入线上已发布的可玩草稿或假称云端已收到。

## 实际检查

`python tools/export_runtime.py --plan-only` 后运行 `python tools/world/forest_review.py`：24房／30连接／5外区口身份、五条路线有效边、房形与通道无相互重叠、与平原35房无重叠、P04世界接缝一致。SVG、JSON和离线页面从同一候选生成；导出默认在 `build/forest-review/`。工作台只读取派生forest.json并复用整区地图组件，SVG保留下载；旧独立网页地址跳转到整合审核入口，不维护第二套网页交互。

生成检查不证明动作包络、能力锁、Boss战、存档或实机节奏。相邻四区未施工，只保留朝向明确且未被本区包围的接口；不宣称完整世界空间已验证。手机触摸实机和浏览器视觉未验证。
