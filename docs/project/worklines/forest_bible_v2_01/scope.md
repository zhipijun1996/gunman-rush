# 森林整区初稿

本区24房的现行候选由 `game/world/regions/F/room_design.json` 唯一持有，正式运行仍只开放F01示例。世界空间制作接续[当前世界工作线](../world_editor_02/scope.md)，进度只归任务表。

候选保留24房、30条内部连接、5外区接口、W／手里剑／Boss／修钟及奖励身份。以已制作平原的世界坐标为基准，首访横廊、树腹实践、W后根井双环、女王上庭与游侠东庭联合编排；规整横廊和竖井取代重复凸角房块，必要枢纽有侧腔。通道纳入两侧房间占地，接缝共享坐标，长段具有明确职责。游侠东庭缩回平原教程房外侧，避免穿入P03/P21/P22。

使用 `python3 tools/world/forest_calibration_review.py` 生成同尺度平原35房—森林24房对照、森林完整SVG、路线/逐房审核页及导入JSON。现有在线工作台未重新部署，不能以旧站点内容代表当前候选。

结构检查覆盖身份、五条路线、区内占地/通道不重叠、与平原占地不冲突及C01锚点。校准导出额外验证30对共享接缝和完整空间面积。以上不证明动作包络、能力锁难度、Boss战或实机节奏；未来制作须按真实控制器细化每段观察、行动、落点和恢复。
