# 房间组装、要素分类与可交互元素库

普通房间按定义实例、参数和稳定ID联动组装；共用实例化但按library分开地形、机关、美术表现、怪物与遭遇、NPC与剧情、奖励和内部服务；每种机关独立定义，其唯一说明入口为[可交互元素库](../../../data/world_objects.md)，合同归[关卡要素](../../../bible/world_elements.md)。旧存档不兼容，现行编辑器草稿保留并一次性升级。受击隐藏入口、伸缩刺、风场、弹跳蘑菇与浮石是扩展用例，本轮没有将尚未实现的行为登记为可放置对象。

接续主游戏codex/terrain-material-system@c1bbf89、编辑器codex/unified-elements@e4dbd2e；交付在[主游戏PR156](https://github.com/zhipijun1996/gunman-rush/pull/156)与[编辑器PR2](https://github.com/zhipijun1996/gunman-rush-editor/pull/2)，单写者Codex，本轮分类实现提交为主游戏8829ef1、编辑器f00e8b9，后续交接正文提交由PR追溯。写集包括统一目录、schema3房间协议、房间组装与特殊宿主、44房数据、编辑器、旧入口清理及相关规范和回归。不合并、不部署、不删除在线用户数据。

## 实现结果

- config/world_elements/index.json为唯一注册索引，26个行为合同、127个独立定义；其中16个机关、76个表现、20个怪物与遭遇、7个地形、3个NPC／剧情、1个奖励、4个内部服务。机关库不再收录其它分类，怪物直接指向既有物种／Boss文档。涵盖当前地形、四类承载、危险、机关、装饰、建筑、敌人及NPC／奖励／充电站／遭遇／剧情／Boss宿主。内部服务不可直接放置；敌人与奖励继续引用原状态所有者。
- 44个已编写房间改为schema3定义实例，309房编辑视图同步；根节点不再持有可放置内容的另一份权威配置。WorldRoomAssembly负责构建和服务绑定，WorldRoomFeature通过登记参数接入特殊消费者；V12改为标准房间加表现宿主。批量地形保留正式物理与共享轮廓，固定实体使用47邻接，构件和单向平台沿已有材质规则。
- 稳定ID、类型信号、组合、状态提交及区域／宿主材质选皮统一；原风铃、门、载台、齿轮、地刺和墙刺沿同一实例目录。上下接缝与危险替换的素材和实现保持前序成果。
- 独立编辑器只有一个按游戏目录library筛选的放置入口，schema2工作区在持久检查点之后迁移基线、草稿、历史及锁定；人工管理记录保持，旧候选保留但不可直接采用，随后继续三方更新。原生运行包必须匹配document_schema=3。
- 旧Demo正式入口、手机工作台桥接、schema1草稿入口及专用发布流程退役；测试夹具、公共校验、几何、运行资源闭包和有效回归迁入明确消费者。已有在线Site与数据保持原状。

## 交付边界与后续

源码审查以两仓PR为入口；运行包是本地验证产物，不表示已发布。Android SDK／AAR未就绪，本轮没有重建APK或进行实体手机验证；ChatGPT登录、在线发布和正式定稿往返仍沿各自任务验收。后续新增机关先修改独立定义；确有新行为时登记实现、参数和端口／状态合同，再补对应创建、信号、保存和卸载检查，不向房间添加专属分支。充电站暂停恢复的基线引擎错误单独修复并重跑世界回归。
