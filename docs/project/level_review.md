# 地区体验审查

围绕实际地区和合法构筑，分别观察以下方面：动作与资源判断、连续挑战、战斗／地形协同、探索决策、恢复与返程、多样性、空间可读性、画面声音与地区身份。

从正式入口、代表与最差 Seed 出发，记录本次路线、能力、资源、相位和真实输入。比较主路、奖励支路、非击杀策略和完整返程；模块数量、Hash不同或几何连通不直接代表丰富、可玩或有趣。

问题应定位到场所、路线、对象、动作或时刻，并说明预期和实际。优先修复使玩家失去判断、无法恢复、看不清威胁或只能重复同一动作的问题。自动诊断提供候选，不代签真人体验。

结论与未验范围归当前任务，长期规则直接回 [生成圣经](../bible/procedural_generation.md)、地区圣经或对象规范。方法见 [审查方法](review_method.md)。
