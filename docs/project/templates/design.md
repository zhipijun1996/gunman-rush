# 具体内容设计模板

工作线记录 task_id、baseline_commit、content_version、玩家体验目标、交付物、检查方法与证据、失败和未验范围；本模板用于正文设计。

## 目标与联系

说明对象／场所的用途、相关圣经和与既有内容的实质区别。

## 行为与体验

写玩家会观察、判断和操作什么，进入／持续／退出、反制、恢复与返程。关卡写入口、路线与能力要求，武器／能力写出手、运动、命中和取消，资产写空间用途与完整边界。

## 画面与声音

写轮廓、比例、材质、动作衔接、预告和反馈，描述正常镜头与连续操作中的效果。

## 数值与关联

链接唯一配置和相关规则。代码结构、字段映射与验证命令归模块导航，正文保持完整当前设计。
