# Web 构建与加载

构建、传输和缓存优化复用锁定 Godot，不改变引擎版本、玩法、输入或存档。运行包由实际导出及其 build-info／内容摘要识别，HTML 与游戏资源分别处理更新。

## 资源与缓存

引擎、PCK 和音频工作文件使用内容身份；首次下载和重复加载分别验证。Service Worker 缓存带内容身份的游戏资源，启动检查更新不打断正在玩的会话。压缩／分块恢复后核完整原始长度和内容，错误、缺块或旧包不能冒称新源。

弱网、中断、缓存驱逐、低空间、权限拒绝及不支持的浏览器都有明确恢复或正常加载路径。镜像与内容寻址分发不改变包内来源身份；浏览器实际接收到的完整 PCK 与目标构建一致。

## 开发与交付

当前实现位于 `tools/web/cache_startup.js`、`cache_worker.js` 和实际导出／部署工具。相关检查从手动 Harness 选择 `web-cache`、`web-build`、`web-bundle`；端到端测试明确设备、浏览器、缓存状态、包身份和实际入口。

发布优先复用同源已验包，使用现有 prepared 工作流；公开后核 build-info、完整包和真实 GUI。具体授权与独立预览规则见 [协作交付](cloud_production.md)，本页不保留旧下载性能成绩或失效路径说明。
