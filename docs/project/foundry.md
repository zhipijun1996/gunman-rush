# 关卡工坊

开发菜单的 LEVEL FOUNDRY 用真实角色、输入、资源、机关与段内回退验证模块组合；练习配置显式选择，不发正式局内或永久奖励，也不自动推广到正式地图。

## 使用

从家园开发菜单进入，或启动 `experiments/generation/entries/foundry_lab.tscn`。选择片段、能力配置与 Seed，手动试玩、重试、暂停、输入回放并记录观察。回放重放输入，不按记录坐标搬动角色。

## 生成与准入

`tools/foundry.py --help` 列实际来源、构建、回放与体验入口。生成有界，候选以真实 Motor、危险、相位、入口出口和连续组合验证；只有完整有效的实际路线加入开发清单。

工坊晋级只代表开发内容可用，不是正式池、趣味或美术认可。新模块先完成一个完整动作场所，再核不同组合与返程；动作包络和实际资源来源清楚，不把旧多发弹药或能力配方当当前基础值。

设计与体验方法见 [关卡工具](level_design.md)，正式流程见 [地图生成](../bible/procedural_generation.md)，实际检查由 [模块导航](module_map.md) 选择。实验与失败保留必要原件，当前结论留在工作线。
