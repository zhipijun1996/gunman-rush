# 验证范围

日常 CI 只有 project／import／smoke／contracts 四项，由 `tools/ci.py` 和 production.yml 定义。它不读取历史任务、证据索引或手动专项表。

手动检查从 `tools/harness/profiles.json` 的现存 manual ID 选择；只记录命令、超时和成功标记。大专项、长路线、画面音频、浏览器、发布和历史复现按本次任务显式执行，方法见 [Harness](harness.md)。

| 范围 | 当前规则 |
| --- | --- |
| 游戏行为 | 核心、物品、保存、敌人／Boss、地区和 mapgen 的真实回归保留 |
| 创作协议 | 当前路由、来源绑定、写集、独立身份、取消、预算和恢复保护继续验证 |
| 历史回放 | 明确版本／输入下执行，只证明对应来源；不升级为当前默认 CI |
| 已退休架构 | full/profile/lane、自动输入缓存、影响升级、旧计时／归档协调器不再执行；对应专用断言不作为当前要求 |

原生脚本／Shader错误、非零退出、超时、缺成功标记或资源退出泄漏都算失败。计划不等于执行，自动检查不代签画面、声音、趣味或真机。具体任务的实际命令和结果留在工作线及必要 evidence，不在本页累积历次成绩。
