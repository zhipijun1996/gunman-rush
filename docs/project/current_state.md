# 当前开发基线

P01、P02、P03 已有 schema 3 整房数据，玩家可从开场连续进入三房。P02「田埂反冲教学」第 6 版已获用户整房认可。P01、P03 已接在样板两侧，等待整房评审。三房交付使用横屏触控布局录屏和整房图。玩家从 P01 草地倒地开场，起身后拾枪，经试枪台与 P02 田埂抵达 P03 折返沟谷。当前 production 工程 F5 运行 [world.tscn](../../production/rooms/world/world.tscn)。认可版本和制作复盘见[样板记录](worklines/room_rebuild/scope.md)。根工程继续运行冻结平原。原有存档、默认场景、已发布试玩与新工程分开维护。
