## 当前缺口

- 本轮35房真实占地和43门缝已校准；全部35房场景按当前初审稿接入并发布；连续教程、机关反例、入场／恢复、选定门对和独立保存按当前交接记录，不作为新档连续全收集或正式体验终审。安全落点与选定动作、承载通过不代表完整主环、能力锁反例及收集返回已验，后续沿连续片区复核。P10使用无攻击浮铃芽练习靶及普通双轴镜头；P12按用户反馈改为井笼、错层反冲、限时侧闸和奖励返程，守箱怪使用规范9血。P11技能芯与T06三联机芯已按用户决定对调，P10免费安装、真实贯穿与保存失败／读档已验证。全区美术、剧情、UI、音效、设备与完整探索趣味仍未终审。
- mapgen旧正式量产目标停止，保留当前开发消费者用于回归；其余旧PR独有成果已放弃，见 [迁移交接](worklines/mv_migration/scope.md)。
- 剧情设计具体人物、日程和结局仍有提案，未整体接入游戏；从 [剧情入口](../bible/story.md) 加载。
- 实体手机／手柄、目标性能、平衡、听感、审美与完整探索趣味按任务证据分别验收。

系统职责与复用/适配/新增缺口见 [架构](architecture.md)；PR138清理已在main，不再作为开发前置。旧五房试制由当前六房首段取代；验证按本轮工作线继续，未完成的外区与全装备系统分别验收。
