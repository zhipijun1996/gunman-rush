# 当前开发基线

重做版当前有一条普通房间运行路径和零个已发布房间。P02「田埂反冲教学」第 6 版已获用户整房认可。P01、P03 已接在样板两侧，等待整房评审。在 production 工程打开 `rooms/world/P02.tscn` 按 F6，从 P01 的教学木台出发，过 P02 后进入 P03。认可版本和制作复盘见[样板记录](worklines/room_rebuild/scope.md)。根工程继续运行冻结平原。原有存档、默认场景、已发布试玩与新工程分开维护。
