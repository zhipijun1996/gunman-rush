# 画面采集与对照

`tools/visual_director.py` 连接真实 Godot 录像、完整输入轨迹、媒体抽帧与独立画面观察。它记录来源和测量，不自动签美术、玩法或设备认可。

## 使用

通过 `capture／inspect／compare／finalize-existing --help` 查看当前参数。采集先固定真实消费者、Seed／Manifest、能力、输入、引擎和源码，再运行正常场景；从实际完成的录像抽帧，保留原轨迹、日志与媒体元数据。

捕获记录核命令、退出、完成标记、源前后、实际场景／资源、录像／音轨／抽帧和内容 SHA。缺件、源改变、错误 consumer、伪造位置／资源或不完整媒体均失败；空白和重复画面诊断只是候选观察。

## 恢复与比较

仅在原生运行真实完成、原命令／引擎／轨迹和前后来源一致时，可对失败的后处理执行 finalize-existing。保留原失败与新产物的联系，不重新生成录像或给旧源改签。

前后对照说明消费者、策略和条件的可比范围，不能将同驱动等同逐像素／同轨迹或性能对比。正常尺寸像素、连续运动、实际试听和独立判断分别记录。真实输入条件变化时重新采集，不借别的 Seed 或版本图片。
