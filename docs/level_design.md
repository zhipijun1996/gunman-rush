# 关卡、主题、类型与挑战段

正式每大关10小关，1–9推进/10Boss；主题与类型独立，非终点推进关两个有图标/名称的出口；第9双Boss出口暂定，Boss必达已确认。完整路线协议见run_and_routes；小关完成条件由StageRule定义，Loader只实例化已验证LevelDefinition。

## 固定验证先行

先在Movement Playground保留移动/跳跃/反冲与碰撞、单向平台/开关/补充点测试，追加固定Health/一个敌人/怪物伤害/多个SegmentAnchor/环境回退与零血返回Home占位。旧即死检查点仅显式Legacy测试模式，不进入正式跑酷/战斗策略。

固定挑战节奏候选仍20–30秒：起步→N跳→下/斜射越障→补充→机关/敌人→安全段起点→终点。普通环境失误扣血并段回退，零血结束run，不能把真正死亡写成≤0.5秒原地重生；≤0.5秒回到可操控状态仅为非致命段回退候选目标。A15三次真机完整通关、A16设备性能仍未验证，慢时游戏clock与墙钟分别记录。

## 独立段起点与地图数据

LevelDefinition包含版本、主题/类型引用、StageEntry、SegmentAnchor列表、对象stable_id、出口、补给、奖励/商店引用、BossArena模板（若适用）和最低能力快照。SegmentAnchor不是持久存档、不是家园；同小关可有多个，通过完整身体/地面/危险包络验证后激活。回退保留敌人/机关/补给/奖励账本，不整场重置；细则见damage_and_respawn。

地图随机可包含战斗、平台、机关、补给与挑战段，但不能仅A*连通就声称可玩。先固定图验证新两类伤害/动作链，再提取模块；用户已确认初验并进入生成设计；详细分设备录像/三次通关/性能继续独立跟踪，固定模块Motor验证、布局反馈及安全出生测试作为运行生成基础。

Boss首版战斗核心与必要躲避空间固定；入口/装饰/外围随机，战斗平台/危险机关仅从攻击模式兼容模板选，核心面积/数量具体数值待Boss任务确定。不随机封闭闪避或把出口放在必死区。


## 多形状小关（新增用户要求）

横屏操作不等于横向地图。LayoutProfile分别支持横向链、纵向上升、方形环路，后续加入下降折返/分叉等；世界尺寸和入口出口使用世界坐标，不能按手机窗口比例缩放物理。两个小关出口可汇集在一个安全区，也可分布在两个已验证可达区；模块内部出口和进入下一小关的ExitOffer不同。

ModuleGraph主路始终有当前能力合法解，奖励支路明确可选且能返回或安全汇合。垂直落差必须预告落点，高速坠落与向下反冲上升分别测；不能复制横向模块旋转90度。回环不改变领取/交易去重。具体蓝图和拓扑图见[生成契约](procedural_generation.md)。
