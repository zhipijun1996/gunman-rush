# 关卡设计

正式每地区两张随机连通探索图，第一图学习并接小Boss，第二图深化并接地区Boss。入口、能力权益和地区选择见 [运行流程](run_and_routes.md)。

## 挑战与空间

以场所而非固定屏宽划分内容。每个挑战明确入口状态、观察、承诺动作、落点、反馈与失败恢复；普通主路、可选奖励、隐藏大师分别控制压力与连续深度。

敌人、机关、奖励和返程一起设计。安全停留需要实际观察或恢复目的；长绕路提供发现、收益或新的返回方式。能力锁按真实授予及合法单武器构筑验证。

## 身体、地图与恢复

StageEntry、SegmentAnchor、HomeEntry和永久保存是不同概念。安全点检查完整身体、地面及危险包络；存活回退保留世界账本，零血结束本局。

Boss核心场地与招式兼容，允许观察和反制；入口／外围变体不能破坏闪避、奖励和退出。地图几何与视觉的关系按真实碰撞审查。

## 生产与验证

先黄金模块／场所，再连接、随机布局和正式消费者。生成合同见 [地图生成](procedural_generation.md)，动作门槛见 [动作入口](design/player_actions/README.md)，体验审查见 [Q1–Q8](quality/level_quality_dimensions.md)。

结构、真实Motor、连续路线、正常速度音画及设备／玩家认可分别记录，检查从 [模块导航](module_map.md) 选择。
