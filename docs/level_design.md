# 固定关卡优先

## Movement Playground

1. 平地、边缘、转向：验证加减速。
2. 高台、短缺口、低顶：验证双跳、土狼、缓冲。
3. 墙与顶：八方向反冲、碰撞修正。
4. 开关、单向平台、补充点与尖刺：交互和重生。
每区可单独传送开始测试，不要求玩家先通关前区才能调试。

## 第一张挑战

约 20–30 秒熟练玩家挑战目标：安全起步 → 二段跳 → 向下/斜向射击越障 → 空中补充 → 移动机关 → 安全落点 → 终点。至少一个中途检查点；死亡到可操控目标 ≤0.5s，可配置。先宽容再收紧，平台间距用实际轨迹而非想象估算。

LevelDefinition 提供 spawn、checkpoint、goal、hazards、recharge targets 和版本。Checkpoint 只激活安全站立区；重生避免机关立即覆盖出生点。机关使用关卡局部时钟，重开明确恢复初始相位；不使用不可复现的系统时间。

验收包括完整触屏录像、至少三次完整通关、失败原因与布局反馈。先验证固定链条，再提取 room modules。不能仅靠机器人通关认定真人触屏难度合理。
