# 平原机关密度与教学节奏

本轮在现有横渡／攀升编排内提高机关可见度，不新增骨架，不改变260移速、一段跳、两次空中射击或8关结构。整体机关风格继续使用平原荆棘与齿轮素材；风铃属于后续独立交互。

## 实现

`PlainsBranchLayout`版本5、蓝图版本3、`plains_branch_profile.json`版本5：

- 第1关先静态平台／荆棘，任何路径不得提前出现本轮两种齿轮。
- 第2–3关两种动作骨架共同段均提供一处小齿轮（brook，半径20）；第4关起可使用小／大齿轮（glade，半径26）。引入阶段通过独立配置控制。
- 机关位于共同段第6号节点；其前后保留独立安全观察／接收地面。攀升机关放在台阶教学之后、反冲转移之前，不叠加到强制反冲落点。
- 两个安全出生模块不变；下分支继续不要求射击、不放环境机关。共同段有机关不代表“稳妥分支”之前整关无危险。
- 小机关主体只有220／300像素入口出口跨度，继续复用短连接板；机关数预算未调大。
- 为让敌人密度有真实安全空间，新增480像素巡逻草甸板`plains_patrol_meadow`：两端锚点20／460，无中间锚点、机关或高台。共同段末尾与两条支路门前各一处；保留其前恢复板，尾部原本没有恢复板时补100像素短板。门仍在独立`plains_door_landing`上。每条实际路线经过两处巡逻清地，敌人规划与此几何空间解耦，具体刷怪由敌人密度任务验证。该空间尚不等同已完成敌人遭遇验收。
- 出口距离不足时安全延长插在巡逻板之前，不能将巡逻板与终端门的契约打散。此次版本同时包含新板，不重复变更版本。
- 服务关不加入机关；弱能力使用兼容筛选及现有正式生成器保底。不能跳跃时由`PlainsStageGenerator`选择兼容路线，而不是强行进入需跳跃的分岔规划器。

版本化Manifest验证阶段门槛、能力池、指定共同段位置、前后安全地面和总预算。替换／提前引入或篡改版本后即使重新计算hash仍应拒绝；全空间危险扫掠与接缝检查继续执行。随机流与奖励结算不变。
