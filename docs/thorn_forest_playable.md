# 荆棘森林：第二区域试玩

当前任务 `FOREST-DEPTH-02`，承接PR76/bee850c6的基本可玩原型。registry默认已选择 `thorn-forest-region-v2` 试玩候选；显式v1与旧存档仍走原算法／Boss。当前本轮尚未部署新的公开包，准确源／build_id／HTTPS以[当前状态](current_state.md)的实际发布记录为准，不能拿旧包测试新版。

## 快速进入

标题 → `DEVELOPMENT DEMOS / ALL ENTRIES` → `DEBUG / SELECT REGION + MAP` → 填Seed → `THORN_FOREST / MAP 1` 或 `THORN_FOREST / MAP 2`。调试森林只授H，不附送W／D、金币、构筑或Boss胜利，Manifest明确debug入口；也可直接选平原两图。

用这些固定Seed可快速对照，勿把名字末尾自行加上地区／map后缀：

| Seed | 入口 | 重点 |
| --- | --- | --- |
| `forest-depth-hollow-00` | 森林图2 | 北庭短接与下降转折孔 |
| `forest-depth-hollow-02` | 森林图2 | 水平双孔、下层跨联奖励与另口返回 |
| `forest-depth-hollow-02` | 森林图1 | 外根营地、取奖返营和活萤返冠选择 |

键鼠A／D或方向键移动、Space跳；鼠标指向目标，E或右键独立发钩。左键按住瞄准、释放射击；向左开枪产生右向反冲。枝台“下＋跳”可下降。触屏有独立HOOK方向盘，松手出钩。H是能力代号，不是键盘H键；实际合同见[输入说明](controls_contract.md)。射程231、360°瞄准、身体24×36和来侧小踢离未改；钩头碰到目标不等于身体到达，成功到达后恢复下一H，不补空中枪。

## 自然流程

家园 → 风铃平原两图 → Boss后领取金道具 → 选H → 确认森林。保留血量、金币、构筑和本局能力。森林图1根铃守卫后进入图2；图2棘冠女王后领取独立森心护符、选择实际可用且尚未持有的W／D，再到明确的S3开发边界结束本局。第三地区尚未制作，不进入空地图。森心护符只增生命上限2，不自动补当前血量。

本局版本随Manifest pin，两图不会中途换算法。保存／暂停／死亡／奖励幂等和epoch沿原系统；调试选择不冒自然通关。当前自然流程49、调试50与版本106项的实际范围及原失败见[默认专项](evidence/forest_depth_v2/default_promotion01/README.md)，不是完整游戏或实体设备验收。

## 新版先体验什么

- 同一实体巨木的树腹、内外根与冠洞形成共享环路；营地、奖励位置与进入关系改变探索先后，北庭和左营地有短回程。
- 水平双孔先在安全囊观察，再横H→来侧kick→反冲接岸。图2另有下降转折孔，要先离檐、下瞄后侧接低岸；可保枪接岸缘，也可R进宽岸中段。普通反冲快解和屋顶旁路保留。
- 外根活萤可借点返冠，也可普通满跳双R或经下窗绕回。清杀是合法选择，活体死亡不堵路；蛛线、旧支持面籽哨与根盘冲刺各有不同反制。
- 根铃守卫常态可伤：观察真实移动铃，H夺取后返撞；同时应对独立身体跨场，第二阶段二者并行。不是等定时开树心。
- 棘冠女王常态可伤：高低迁巢、持续旋网／升降网；可借活结换位，或射断同结改变场地。普通换层进攻保留，不要求按唯一解谜步骤。

两Boss具体参数、状态机、场地与完整影片分别见[守卫](design/rootbell_guardian_v2.md)、[女王](design/thorn_queen_v2.md)。生成、动作和敌人设计见[整体设计](design/forest_depth_v2/README.md)、[探索](design/forest_exploration_v2.md)、[生态](design/forest_enemy_ecology_v2.md)。图2上层双敌／活锚候选已被强普通低跳反证并删除，不用凑怪数填安静段；真实取奖异口返回继续验证。
