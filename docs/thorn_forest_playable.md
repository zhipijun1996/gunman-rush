# 荆棘森林：第二个可玩区域

任务 `FOREST-PLAYABLE-01`；实现版本 `forest-playable-v1`。本轮用户明确授权把上一轮设计做成可玩第二地区，并接入能力奖励、下地区选择和调试直选。此前只设计／不开森林的任务范围由本轮覆盖。保持六阶段／16地区长期框架，这次实际开放范围为平原与森林；S3及峡谷／沼泽尚未制作。

## 如何试玩

普通入口：标题 → 家园 → 风铃平原两图。第二图Boss后先领取金道具，再选择H钩索，随后确认荆棘森林。跨区保留当前血量、金币、构筑和本局能力，不重新开局。森林第一图守卫后进入第二图，第二图荆棘女王后领取独立金道具、选择尚未获得的W或D，再到明确的后续开发边界结束本局。

快速入口：标题 → `DEVELOPMENT DEMOS / ALL ENTRIES` → `DEBUG / SELECT REGION + MAP`。可以填Seed并直接选 `PLAINS / MAP 1`、`PLAINS / MAP 2`、`THORN_FOREST / MAP 1` 或 `THORN_FOREST / MAP 2`。森林调试入口只授H，不附送D/W、金币、构筑或Boss胜利；Manifest标记 `natural_progression:false`，不冒充自然通关。

键鼠：沿用正式操作。基础跳起后瞄准铜环，按E或鼠标右键出钩；左键按原释放射击规则开枪，方向决定反冲。枝台上“下＋跳”可下降。触屏使用现有独立钩索方向盘，松手出钩。H仍为当前运行资源的231px射程、360°瞄准、来侧每轴24px小踢跳，不是长绳摆荡。操作真值见[输入合同](controls_contract.md)。

S1的W／U1候选明确显示不可用原因：对应下地区还没制作，不能选进空地图；当前可提交的路线是H→森林。森林结束只展示实际实现的W／D，不假装已开放第三地区，也不宣称整局终战完成。

## 关卡与机制

`ThornForestRegionGenerator → ThornForestRegionAssembler → ThornForestRegionStage` 是真实正式消费者；没有复制平原生成器或使用旧460px森林fixture。三种空间骨架分别改变分岔的转折序列／高度与镜像；两图均有固定学习前缀、左右枝路、根洞营地、皇冠高奖、异路下降返回和Boss接近。图2接近段增加转向与高度判断。

安全教学允许基础跳跃直接到枝，不能拿“没有H事件”当作无H几何不可达。森林的真实能力锁是**藤结门**：必须成功钩住并完成指定铜环的拉近／踢跳，才解除通往Boss的实体藤结。空钩、挡钩、发请求、只有H标签、钩别的目标均不会解门；开启状态随地图实例保存。主路固定环不依赖怪物存活，活锚怪物只给可选借力。

同高度相交枝台共用一个碰撞归属，保留每个原始矩形与真实空隙，避免“下＋跳”被隐藏的第二个支撑接住。接收面、钩线、身体扫掠、镜像、落空、安全撤回与奖励返程均须真实Motor验证；不改变PlayerMotor／射程／武器资源来救几何。

第一轮实际修复保留了遮挡钩线、镜像出口双反、竞技场底面压头、单向台缺标准碰撞节点名、重叠支撑阻断下降，以及缓存缺正式奖励字段的失败。黄金路线和完整拼装路线分开采证，不能用单片通过外推全地图。

## 怪物与Boss

- 铃囊萤：停留→转向预告→短距巡游的真实活锚。玩家可以借它换枝或击杀，固定环和恢复地形始终保底。钩中／踢伤／死亡／失活使用已有Actor、Health和DamagePolicy。
- 棘籽哨：只锁定玩家当时有真实支持面的旧枝面，预告后发弧线种子并留下短暂危险区。可以换层、等待、绕过或真实开火压制；树干阻挡、暂停、失活和epoch取消均生效，不预读输入。
- 荆棘守卫：第一图两阶段，从开放树心射击过渡到观察亮侧再换位。
- 荆棘女王：第二图三阶段，旧枝预告／种子飞行／短刺区／树心开放循环，再深化左右开口与相对旧站位的对侧进攻。固定枝台与铜环帮助换侧，地板不撤掉；只有已接受的真实弹体在正确窗口／方向经正式伤害管线结算。

树心采用可读开放窗口与来弹方向判断，开放期间受击范围是可见树身，不冒称独立的小圆弱点。原生局部与正式DemoApp整段战斗分别记录；程序绘制用于低成本可玩原型，不声称商业美术完成。

森林Boss的金色“森心护符”增加本局生命上限2，当前生命不自动回复；它与平原金色枪管是不同真实道具，避免原 `power_gold` 不可重复领取造成第二地区结算卡死。金道具与核心能力是两笔不同权益，旧道具的叠加政策未改变。森林缓存、商店与构筑池不加入第二移动能力。

## 状态、重放与验证入口

`RunCampaignProgression` 管本局能力／完成地区／能力和地区选择阶段；Director保持同一run epoch并在跨图／跨区递增stage和actor epoch。死亡优先、旧token、重复领取与相同收据回放拒绝／幂等语义保留。结束和死亡清空本局能力／金币／构筑，永久音符仍走原Meta服务。

旧schema1平原Manifest保持兼容；跨区／调试使用schema2，记录累计stage 1–4与每地区map 1–2、能力快照、真实生成版本和区域转移。森林JSON数值域做严格规范化，拒绝1.5等非法地图索引、重算hash后的篡改地形／能力，以及未知地区。声明目录仍是候选世界资料，不用修改它的runtime标记来开放地区；[设计检查合同](design_contract.json)的当前运行清单单独版本化。
