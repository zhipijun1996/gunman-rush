# D064 平原一跳、告示牌与机制段落

本轮用户确认平原取消二段跳；后续每个大关获得一个新能力。具体能力对应地区、发放时点、局内/永久保留仍待决定，后期地区尚未开放。默认配置一跳，两次空中射击保持，能力组件仍支持N跳。平原道具池剔除额外跳跃，正式生成平原商店以伤害升级替代跳跃升级；旧开发测试与通用Modifier继续验证多跳能力。

## 路口可读性

在真实分岔的安全决策点设置双层木质告示牌，箭头来自路线初始连接方向，名称和图标来自对应实际ExitOffer。路牌不碰撞、不交互、不结算；两条路线末端的门仍需确认后切换，第7关预告Boss。保持平原材质与低饱和配色；实际手机尺寸下文字可读性待用户验收。

## 生成内容切片

新增荆棘长堤、高台连跳、荆棘脊线三个独立模块，复用原有平原皮肤和完整身体碰撞。围绕荆棘跨越、高台攀升、风车摆渡三种主机制选择关键段，再混入次机制与安全落点。关卡长度和后续段落随Seed变化，金币关有更长收集路径；商店/回血维持低压力。连续高压、机关数量、移动平台和射击资源仍受预算约束，不用任意堆叠障碍创造“随机”。

高台/宽沟按实际一跳能力筛选。需要二跳的两种高级宽沟保留为后期能力样片，不能进入当前平原；单跳反冲横渡使用既有已验证长沟模块。新模块需正反向实际Motor轨迹与全身危险扫掠验证，独立样片通过不能自动证明所有地图组合。

本轮是机制段落组合扩充，宏观图仍为公共路接两条末端路线，尚未完成三种宏观骨架、环路或局内骨架去重。不能把三个段落主题说成三种拓扑。后续继续GEN-ARCHETYPE-01，以横渡/攀升/折返固定样片、反向端口和完整双路线为先。

## 复现与验收

Manifest记录编排版本、主机制、实际模块/镜像/相位、当前能力与保底原因；类型与Seed共同确定内容，同版本同Seed重放一致。最多四次空间求解，失败使用显式同类型兼容保底。新字段需校验对应实际关键模块，不接受只改标签的伪造manifest。

验收见A90–A92，实际结果见当前handoff。不同Seed的机制分布、失败/保底统计与实际Motor路线分别记录；真实手机手感、告示牌读图和完整8关体验继续待验。

## 回归中发现并修复的测试前提

默认从两跳改为一跳后，旧土狼边界/可变二跳/空中爆发接管测试有5个隐式二跳前提失败。默认一跳拒绝另有实测；专测多跳能力的fixture显式启用两跳，保留原断言。

出口同帧死亡fixture通过直接重定位跨越新地图危险，残留跨场景运动扫掠提交了环境伤害；按既有环境优先批次策略，这并不等同于原测试想隔离的怪物致死请求。测试重定位前按已有App测试惯例使actor epoch失效，清掉旧轨迹，然后仍在同帧提交出口与合法致死伤害，并新增提交成功断言。生产伤害优先级未改，不能删除死亡优先断言来通过。
