# Visual Bible

## 全局规格

统一细粒度童话像素风。正式地形原生32px／32wu，世界表现1wu采样、nearest；保留Underworld家族的47邻接、精确边界适配及实际光照／材质语言。原图内容、显示尺寸与物理碰撞分别管理。

当前共享技术参考从 [Bible注册表](creative_direction/bibles/registry.json) 的`shared_style_authority`解析；两区域总谱由同一注册表的`direction_path`定位。画风意图、技术绑定与用户视觉认可分别记录。

## 空间与功能

角色、弹道、危险预告和落点最清晰。远景低对比，中景承接大体量和区域地标，近景稀疏且避开唯一通路。暖光与清透空气透视按场景目的使用；区域特色由材料、生态、结构、形体及色光表达。

岩壁有连续体量与断面，建筑有根基，藤枝有真实宿主；平台、端头、填充和附件分别处理。刺与危险的实际方向、支撑及碰撞一致。材质切片、边界与光照不制造可站立性的假象。

## 母版与合屏

先一件适合真实空间用途的母版，核完整边界、alpha、锚点及采样；再在正式镜头、角色、敌人、UI与连续动作下审查。通过黄金样板后扩资产族，并在不同结构的第二空间验证复用。

实际运行像素、正常速度音画和来源记录共同构成审查依据。相关资产／构图／动画由对应专业Skill执行； [内容流程](content_pipeline.md)、[动画规范](animation_vfx_standards.md)及 [质量规则](development_quality.md) 提供专属要求。
