# D069 平原内容密度：遗忘的十字路口参考方向

用户明确要求参考《空洞骑士》遗忘的十字路口的内容密度，增加机关和敌人；同时认可射击风铃，并要求按顺序加入。执行顺序：先改善正式平原的遭遇编排，再验证风铃样片，最后才考虑把新机关纳入随机池。不是复制原地图、敌人、素材或剧情。

## 当前问题的代码证据

D068之前及3eaa86d基线：GeneratedDemoStage只在combat生成小怪，第1–3关整张地图1只、第4–6关2只、第7关3只。金币/道具关无守卫；候选按各模块最宽平台全图均匀取样，没有公共路和两支路配额。因此实际选定路线可能很长时间不遇敌。现有飞行怪和地面怪共用巡逻逻辑；飞行只是高度与表现不同，不能声称已经有不同攻击行为。

公共路线主要只有横渡、攀升两种动作结构，定时齿轮只在中期横渡出现。随机序列和贴图变化没有解决长段空白与相似解法。移动舒适度、画面精修和趣味性是不同验收，D068技术通过不等于用户认可内容。

## 本项目的转译目标

围绕可读的短遭遇安排内容：安全入口→地面巡逻→地形或机关→无敌人的观察落点→宽敞空间的飞行骚扰→路牌分岔→有不同风险的末端路线→安全门区。主路可绕过或击杀，非Boss仍不要求全清。金币关强调移动收集、有少量守卫；道具关提高挑战；商店/回血维持休息。

数量按公共路/各支路预算，不以整图数量冒充玩家单次必遇数量。不把每块安全板都占满：保留出生、路牌、补给、末端门、关键反冲接收台与移动机关的完整安全空间。无安全候选时记录实际缺额和原因，不硬塞。较密不等于更苛刻，继续按一跳、260普通速度、不开慢时验证代表路线。

第二小关开始逐步引入容易看懂的小齿轮，后续可换大齿轮；两骨架均有定时观察机会，保留机关前后落脚地，不把敌人放到必达落点上。所有预算属于本项目可调整的试玩数值，不是《空洞骑士》原版统计。
