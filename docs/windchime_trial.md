# 射击风铃固定练习

入口：主页 MODULE LAB → 右侧第二组 WINDCHIME TRIAL。原八模块按钮位置不变。仅固定练习，不加入正式平原随机池，也不结算Run、金币或永久成长。

## 操作与两段学习

第一段在宽地面向黄铜风铃A松手射击，真实子弹命中后打开同色/同编号门A。第二铃B悬在100px宽浅井里：可以站在井边斜向下射击，先打开门B再跳过去；也可以跳入井上方，向下松手射击，同一发子弹开门，反作用力同时将人物向上送。第二种是鼓励的连招，不是强迫精确同帧的唯一解法。两铃全开且真实落地到EXIT才显示练习CLEAR。

保留一跳、260普通速度、0.55地面反冲倍率、1100×0.14空中爆发和既有松手射击；不新增动作资源消耗，不改核心物理。使用现有触屏、键鼠和手柄适配器，触屏三指控制沿用现有实现。

## 组件与边界

ShotLatch拥有局部HealthState、Damageable、射击目标和门体；PlayerProjectile的实际形状扫掠命中交付请求，不以距离/玩家位置直接打开。铃目标28×34、独立layer8，玩家mask1不会把铃当成额外落脚点；门24×270、layer1真正阻挡。实体碰撞和风铃表现分别管理，透明新铃素材只用于显示。

每发子弹记录Controller session与完整lifetime token，另核实射手、faction、目标与Health epoch。未命中或被墙挡住不触发。eligibility按实际弹体配置寿命过期清理，开门后清空且不再登记。每个铃只永久打开一次；碰撞变更deferred执行前再次核对life、session、局部请求代际和玩家存活，以便同帧死亡、暂停、回退、退出、重试取消旧请求。

环境存活回退保留两个铃和门的实例/开闭状态、已用补给、扣除的HP、精力及冷却；清除旧弹体和请求。明确RETRY开始全新尝试，两个门恢复关闭。暂停取消旧弹体和待开门，不在Resume重放。死亡先结束lifetime并返回家园，不能趁延迟回调开门。
