# 动画、特效与声音同步标准

与 [Visual Bible](visual_bible.md)、[输入](controls_contract.md)、[物理](player_mechanics.md)、[资源](combat_and_recharge.md) 配套。动画表现订阅真实已接受事件，碰撞/伤害窗口/资源/时间倍率由原玩法负责。不能为动画对齐而偷偷改玩法。

## 核心动作链

瞄准 → 松手提交射击 → 枪口出现真实弹体 → 反冲爆发 → 空中姿态 → 真实命中或落空 → 落地恢复。对链上每一环记录 gameplay event、视觉启动/结束、音频触发和测量延迟；预算先在 G0 按目标设备约定，不能生成随意合格分数。

使用 [Animation/VFX Specification](templates/animation_vfx_specification.md) 定义 idle/move/jump/fall/aim/shot/recoil/land/hurt/death 及内容专属状态，关键姿态、进出条件、中断优先级、过渡/混合策略、脚底/肩轴/枪口锚点、朝向与慢时表现。按动作需要选择逐帧/骨骼/程序动画，不统一要求帧数。

## 必验场景

| 场景 | 方法与观察 | 失败条件 |
| --- | --- | --- |
| 左右/斜上/斜下瞄准连续射击 | 正常速度录像并标出枪口/弹体首帧，必要时逐帧定位 | 枪口漂移、弹体不可见、明显离枪口出现 |
| 跑跳反冲落地连段 | 脚底/重心/朝向/武器锚点与真实位移同步 | 滑步、瞬间换姿、落地悬浮、碰撞被图像误导 |
| 预警→攻击→恢复 | 同步 gameplay tick/attack_id 和视觉/音频时间轴 | 伤害早于可读预警，结束后仍伤害，判定范围不对应 |
| 受伤中断/死亡/暂停/重载 | 在动作各阶段触发，检查 epoch/计时/粒子/音频 | 旧枪补发、旧特效再次支付伤害、死后动作/音频泄漏 |
| 慢时/解除慢时与不同朝向 | 实际输入连续录像，标注游戏/实时 clock | 动画突跳、声音多播、恢复后反馈错位 |
| 高密度战斗与相机移动 | 镜头位置/落点可见性、帧时间与活动节点/粒子数 | 落点被闪光遮挡、相机突跳、节点随轮次持续增加 |

G2 交付实际合屏截图和正常速度连续录像；逐帧分析作为定位附件，不能用慢放掩盖真实突兀。比较同一输入/Seed 的改前改后，注明观测区间。G3 进入正式消费者重新测，因为测试场景不能覆盖镜头/UI/同时攻击。

## VFX/音频与生命周期

命中、护甲拒绝、受伤、掉落、领取/交易各跟随真正接受结果；UI 声可在暂停消费，世界声遵循现有暂停策略。禁止命中粒子自行判伤/回能。特效说明所属 run/stage/actor、spawn/deactivate/free、池上限、最大同时粒子和超额降级策略；不用池掩盖泄漏。音频记录来源、格式、采样率、峰值、响度/循环点，检查重复疲劳/削波/接缝/事件重播。工具不可用写 blocked，不虚构声音。

技术检查、连续性审查、视听美感和用户手感分别记录。无法录制则 G2 unverified；没有设备实测则 performance/device 按适用范围未验。

## 武器与能力扩展动作

按 [动作规划](quality/player_action_plan.md) 和 [覆盖卡](templates/player_action_coverage.md) 建立阶段与from→to转换。人物每时刻一个当前武器，身体/上身武器/能力附件按动作决定叠加或覆盖；事件与素材指纹绑定连续音画证据，不只检查各动作首帧。原有脚底/枪口测试与资源哈希不能证明完整连招自然；新增专项仍待实现。
