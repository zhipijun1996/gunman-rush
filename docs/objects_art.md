# 平原 Demo 功能物件、移动 HUD 与事件特效

本套素材沿用已确认平原参考图的暗灰机械、旧黄铜、青色菱形射击资源与琥珀双箭头跳跃资源。采用 AI 编写的确定性 SVG 制作管线，属于可实际导入的矢量功能素材；细节密度有意低于概念图，以适应手机显示。不是逐像素复刻，也不包含第三方素材。

## 交付与重建

`python3 tools/build_objects_art.py` 重建 35 件透明 SVG 并逐件解析 XML。来源、尺寸、锚点、角色、留白、九宫格参数及碰撞提示在 `assets/objects/manifest_fragment.json`。本文件是分包 manifest，整合者将其登记到全局 manifest；不自行覆盖共享资源登记。

| 类别 | 素材 | 数量 |
| --- | --- | --- |
| 地图功能物件 | 锯轮、移动平台、压力板开关态、门开关态、两类补充物开关态、检查点开关态、终点 | 13 |
| HUD | 射击/跳跃图标、移动/瞄准/跳跃控制、暂停/重开、面板/卡片、四种资源条 | 13 |
| VFX | 枪口、弹体、反冲、落地、两种补充环、检查点环、死亡碎片、火花 | 9 |

目录：`assets/objects/`、`assets/ui/`、`assets/vfx/`。SVG 不含文字、外部图片、脚本或字体依赖。UI 文本由 Godot 控件排版，方便本地化。

## 导入与锚点

Godot 以 SVG 导入 Texture2D；CanvasItem 展示。源 SVG 无滤镜，无阴影烘焙。Vector 导入缩放可适配目标分辨率，最终纹理图集按集成阶段性能预算决定。世界物件源像素与游戏单位的换算由关卡统一配置，不能对每件临时随意缩放。

以 manifest 中 `anchor_px` 为局部节点原点。Sprite2D 使用 centered=false、position=-anchor_px，或由集成脚本计算 offset。锯轮 pivot=(64,64)，图形最大边缘约 radius 61.5（含描边），建议玩法半径 60；碰撞参数只是美术提示，以世界组件配置为权威。平台锚点=(128,5)，站立表面在 y=5，左右可见端点 x=4..252；角色落点使用玩法几何。

门和检查点锚定底部。枪口锚定喷发起点，弹体锚定头部；不要用图像矩形代替碰撞。Active/inactive 成对资产保持相同画布和 pivot，可直接替换 Texture。

UI `control_*` 设计尺寸 128×128，推荐 CanvasItem modulate alpha≈0.55–0.75；按下时提高 alpha 并缩放 0.95。触控命中范围独立于可见圆，最小物理触控尺寸由设备验收确定。`selection_panel` 九宫格边距 20；`selection_card` 含中央图标，应等比缩放，不使用九宫格；卡片正文位于 [20,90,120,75]。资源条九宫格左右 7、上下 3，填充长度由数据绑定；文字和进度值不能烘焙进贴图。

## 事件驱动动画配方

以下都是视觉建议时长；不参与判定、冷却、奖励或死亡事务。订阅组件事件并在对象卸载时断开。动画使用 Tween / AnimationPlayer / GPUParticles2D，允许表现降级而不影响玩法。

| 触发事件 | 表现配方 | 建议参数 |
| --- | --- | --- |
| shot_fired | 枪口 flash 朝发射向量旋转；弹体由现有玩法位置驱动；recoil_streak 位于身体后方 | flash 0.06–0.09 s，scale 0.75→1.15，alpha 1→0；弹体保持清楚头部 |
| 反冲反馈 | 少量火花与反冲线，朝速度变化方向拉伸 | 0.10–0.16 s；不修改 PlayerMotor 速度 |
| landed | 脚底 dust 向两侧扩散 | 0.18–0.28 s，scale (0.6,0.6)→(1.2,0.85)，alpha 0.55→0；低落差可略过 |
| reward_granted(shot/jump) | 对应色环在奖励位置扩散，成功后才切换 inactive | 0.20–0.30 s，scale 0.45→1.3，alpha 1→0；资源满拒绝不切状态 |
| checkpoint_activated | active texture + amber ring + sparks | 环 0.45 s，scale 0.5→1.5；灯光小半径，检查点状态来自服务 |
| died | 8–12 枚 death_shard 和 3–5 枚 spark 爆散 | 0.25–0.5 s，散射初速度 80–160 视觉单位/s；本体隐藏时机跟随死亡事件 |
| trigger_changed / gate_changed | 同画布替换开关态；门开启动画沿本地竖向移动独立门叶 | 0.12–0.25 s；碰撞启停由机制决定 |
| motion_updated | 锯轮围绕精确中心转动；平台位移跟随 Motion | 不用 Tween 推导玩法轨迹；所有实例独立初始相位 |

默认 blend 为 Mix；光环、火花、枪口可选 Add，先在亮天空下验证可见性。不要为每枚粒子加实时灯光。旋转锯轮本体无烘焙定向阴影，可稳定连续旋转；平台具有上表面，不应垂直翻转。

## 随机地图约束

功能物件与地形资源分离：随机模块仅配置其位置、状态和运动路径，替换区域皮肤不改变触发方式、资源类型或碰撞。锯轮预留运动范围，检查点预留安全站立区，补充物周围保留轮廓空间。Inactive 补充物弱化明度但保留菱形/双箭头语义；只能在明确规则允许时隐藏。

地形承载移动平台锚点及轨道，由模块定义提供，不使用装饰图推导位置。装饰不得覆盖 active 补充物、门通道或锯轮边缘。机关初始相位进入 replay 配置；视觉粒子随机与玩法随机分开。

## 验证及限制

2026-10-09：`python3 tools/build_objects_art.py` 退出 0，生成并 XML 解析 35 SVG。素材未修改玩法逻辑。资源需由整合者执行 Godot 导入、场景布局与实际手机验收；XML 有效不等于真机可读性通过。当前矢量精细度是 Demo 级功能资产，可在稳定尺寸和动作验收后，用统一参考图进行 AI 材质升级，同时保持 ID、画布、锚点和语义。

## 可选手绘锯轮候选

`assets/objects/painted_saw.png` 是 image_gen 独立生成并未经编辑的透明 PNG，1254×1254，初始建议旋转 pivot=(627,627)。提示词在同目录 `painted_saw.prompt.txt`。采用磨损铁齿和八颗黄铜铆钉，已目视检查单一完整锯轮、无链条和地面。作为材质升级候选，不自动替换已验证的 SVG。图形中心与几何中心可能有少量偏差；最终显示缩放、实际 alpha 安全边缘及碰撞半径尚待集成校准，不承诺直接套用 SVG radius=60。生成脚本保留此类额外登记，不覆写 PNG。
