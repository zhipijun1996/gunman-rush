# 画面与操作反馈

风格、尺度与区域差异唯一见 [Visual Bible](visual_bible.md)。本页定义玩家在真实操作中需要辨认的反馈。

## 操作目标

输入响应、轨迹、落点和受伤原因可预测。短按／持跳、反冲、输入缓冲和土狼时间由正式控制器与Motor负责；表现不能延后输入接受或改变资源结果。

相机用实际StageCameraRig和运行配置验证死区、前瞻、边界与高速动作留白。暂停、段回退和切图清理旧镜头状态；比较普通移动、微调、反冲和长距离下落的正常速度观感。

## 反馈层

角色、武器、弹道、危险预告和落点优先。枪口、附件、脚底与真实姿态一致；命中、受伤、补充和奖励使用不同事件及视听语义。

慢时边缘提示订阅AirFocus接受状态，位于世界之上、输入UI之下，不捕获事件。强度与淡入淡出归表现参数，时间倍率和能量仍归能力。

## 验证

固定同Seed／输入／镜头／分辨率比较前后实景，检查实际触屏／指针、完整UI、连续动作、暂停与取消。记录响应、遮挡、危险可读、死亡到可操作和真实设备性能；主观舒适性与客观行为分别报告。

制作规范见 [动画标准](animation_vfx_standards.md)，视觉评审见 [美术目标](art_quality_target.md)。
