# 地图生成

随机探索服务于反冲位移、平台操作和路线选择。每地区两张连通探索图，主路、可选奖励、隐藏挑战、汇合营地、Boss接近与返回有明确意图。地区主题与能力锁见 [地区框架](regions.md)，具体实现与当前来源见 [模块导航](../project/module_map.md)。

## 空间与通行

场所有真实体量、宿主、支撑和连通关系。模块端口、镜像、连接与封口使用实际身体包络、速度、冷却、资源及机关相位验证；几何连线不代表角色能通过。主路只使用已合法授予的能力和实际动作容量；原测试配置仅是资格证据，不能修改正式角色资源。已适配模块进入内容池，未拥有的能力或未满足的动作容量由生成输入筛选，敌人死亡或离开后仍有符合设计的通行／返回方案。

地图生成不改变基础移动、武器、资源和保存规则。新地图来源须接通真实敌人、机关、奖励、Boss与返回流程，才可作为完整地区采用。模块内部成立后，还需验证相邻连接、完整路线与正常镜头。

纵向开口和单向平台保持原生碰撞与角色规则：上穿、接地落脚和主动下穿可组成跨模块路线；不因端口方向整模块排除。

随身地图和展开地图按实际地形、平台及开口绘制缩略图，叠加本局探索迷雾、玩家位置和必要标记；未探索部分不提前暴露。

## 探索与压力

地标、岔路、观察点、捷径与回环共同建立探索节奏。动作、空间、机制、探索决策和视觉变化分别比较；同一种动作换坐标或名字不算内容差异。主路覆盖当前合法构筑和学习，进阶／大师内容自愿进入，有相称收益、恢复与返程。

平台动作、战斗、时机与容错分别观察。P／C／T／R候选标签用于筛选，不机械相加为难度。高平台压力时限制同时战斗／时机压力；复杂战斗保留退路和可读落点。低压观察、奖励接近与紧张挑战交替，不固定第几房间必出商店或Boss。

## 确定性与失败

地图、奖励、商店和Boss使用独立随机流。实际选择、内容版本、能力快照与稳定对象身份进入Manifest；同版本重建保留实例、收据和机关相位，已提交地图回退不重抽。

生成有界重试并记录拒绝原因。缺版本、身份、必要输入或安全出生时明确失败；保底只采用已验证且语义相同的内容。不能通过改玩家物理、暗授能力或取消危险来掩盖不成立的场所。

## 内容验证

先完成一个真实黄金场所，再扩模块与Seed。依次覆盖模块、连接／相位、完整主路与返程、正式消费者、Manifest往返和回退／取消；保留最差样本与失败反例。实际动作轨迹、正常速度画面、探索决策和玩家反馈用于校准，统计只作诊断。执行方法见 [关卡审查](../project/level_review.md) 与 [Harness](../project/harness.md)。
