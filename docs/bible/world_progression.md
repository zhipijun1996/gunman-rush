# 固定世界推进

从 P-R03 开始，通过房间和分区探索、取得永久能力、回访奖励与修钟推进。世界源拥有全部能力/奖励位置、行动条件、服务与结局关系；使用 [按房工具](../data/world/README.md) 查询，不手工复制第二份拓扑或能力地点表。

H/W/D/Q 永久解锁；能力环境的预览和退回遵守 [世界结构](world_structure.md)。武器本体、攻击升级、分支材料和共用技能芯分别处理，见 [成长](rewards_and_builds.md)。不能沿旧每区Boss后能力三选一、U1/U2阶段授予或六阶段选路推进。

区域状态分别为已发现入口、已深入主体、钟已修复、深部记录已取得。普通结局按主体探索及 canonical.endings；真结局按15地方钟、16深部记录及其剧情条件，不要求先通普通结局，不以22Boss全清、40齿轮或装备100%加锁。

路线 A先W、B先D、C真结局用于验证可行路径，D审计材料与齿轮；不代表唯一或最短顺序。分区模拟只证明逻辑关系，真实跨房、能力动作、镜头和战斗需后续运行验证。所有唯一动作/购买重复调用都不得重复发奖或扣费。

进程相关叙事见 [剧情](story.md)，永久/周期边界见 [保存](home_and_save.md)。旧原型继续承担过渡回归，实际入口见 [当前状态](../project/current_state.md)。
