# 家园、永久成长与保存

## 家园入口

标题“开始游戏”进入可操作安全家园，复用正式控制器和操作HUD。武器工坊提供三种Lv.1武器，会话内记忆选择；刷新默认脉冲枪。织时匠提供当前会话外观切换。永久升级、道具图鉴与出发携带通过各自真实服务操作。

面板打开、关闭、失焦和切换取消旧输入；退出家园创建新局。死亡或当前开发流程结束返回家园。

## Run与Meta

Run拥有金币、临时背包／装备／能力、地图、生命／资源与交易账本；本局结束撤销临时来源并清钱包。MetaProgression拥有独立音符钱包、永久升级、图鉴发现／解锁和出发选择。音符合法拾取即提交永久保存，金币不自动兑换音符。

升级、解锁和出发选择校验报价、余额、前置、上限与事务ID，在同一ProfileRevision提交扣款、结果与收据。相同请求重试不重复扣款／授予。永久基础修正用于新局基础，不累加上一局临时属性。

## 保存服务

SaveService校验并序列化版本化Profile；存储适配负责平台写入与确认。Envelope包含schema、content版本、profile ID／revision、校验和、Meta及永久收据。内容Manifest另用于地图复现，不提供完整中途续局。

原生写入临时文件、flush并读回校验、保留上一有效备份后替换；Web通过localStorage写入和读回确认。保存确认后才发布成功，失败保留先前有效状态并允许显式重试。

加载验证checksum、schema与稳定ID。坏主档可尝试有效备份；主备均坏时保留原件并报告恢复失败。未知未来schema明确不兼容，迁移通过纯数据转换及独立版本校验完成。

## 剧情与验证边界

剧情知识、NPC和结局完整系统尚未接入；设计见 [剧情入口](story.md)。当前没有云同步或账号系统。各平台的持久化与设备结果分别验收。

验证覆盖拒绝存储、重复事务、坏档／备份、切档、图鉴下架／取消、出发一次领取和实际Web刷新。代码与运行专项见 [模块导航](../project/module_map.md)。
