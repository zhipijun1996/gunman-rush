# 安全服务、休息与保存

小站和地区安全区承载NPC、休息、交通与装配。交通抵达、进入安全房、对话、购物、锻造、维修、交付与自动保存均不是休息。服务位置和永久身份取 [世界源](../data/world/README.md)。

## 四种状态寿命

| 寿命 | 内容 | 边界 |
| --- | --- | --- |
| 永久 | 能力、成长、唯一奖励收据、Boss胜利、修钟、捷径、任务、装备所有权/等级/破损、售出库存、累计交付 | 死亡、过房、休息均不清除 |
| 休息周期 | 周期ID、普通敌人状态、限定次数、装配/锁装 | 普通过房、交通、对话、保存和读档不刷新 |
| 挑战尝试 | 当前房/分区、真实进入侧、失败锚点、局部瞬态机关 | 存活失败返回实际进入侧 |
| 动作瞬态 | Q资格/冷却、反冲、攻击包、有限射线预算 | 换房不补资格或清冷却，读档安全重建不补发永久结果 |

普通敌人的死亡状态与尸体持续到休息周期更新；死亡后立即失去接触和攻击能力，过房与读档不复活、不重播死亡奖励。显式休息恢复HP、登记复活点并推进周期，允许重新选择装配。其他房间的普通敌人按新周期刷新；当前房间保持休息当刻的存活、受伤和尸体表现，离开后再次装载才应用刷新，不在玩家眼前突然生成怪物；不刷新Boss、库存和唯一奖励，不强制卸下全部装备。刷新额度不能在满HP时白白消费回血次数。共鸣恢复与技能消耗须另行明确，不能从HP恢复推定全部资源充满。死亡处理见 [伤害](damage_and_respawn.md)。

## 充电站休息表现

玩家在充电站同层安全地面明确交互后，先走到舱口，再以独立转身、踏入和接通姿态进入站内。黄铜拱架与侧线圈分前后层，站内保留足够容纳正式44wu角色的空间；不缩小角色、不旋转站姿代替进出补帧。站内电流沿两侧接点绕过身体，短暂抬肩、披巾轻动，随后放开接点、转身迈出，接回原待机。

休息期间冻结世界玩法，保留站体、角色和电流表现；操作锁定，重复交互不重复提交，暂停菜单可冻结当前过程。切房、角色生命周期变化或退出时清理临时姿态、声音与闪光并释放冻结；不可跨旧角色继续提交。走向舱口受真实碰撞约束，地面不同层、途中阻挡或失去支撑则取消，不强制穿墙定位。

进入后先播放柔和接通声与有限时长低频电流声，充电中段由应用层执行一次原休息事务。仅保存成功后恢复HP、提示复位点登记，播放清亮而短的恢复和弦，并以低透明度青白色单次柔光提示世界周期刷新；减弱特效设置下进一步降低强度。保存失败保留原资源、周期和复位点，跳过成功音与闪光，正常退出并显示失败原因。当前房间怪物仍遵守上文的延迟刷新规则。

## 事务与介质

扣费/扣料、授予、库存及唯一收据在同一版本修订提交；失败保留旧状态，同ID重复请求返回原结果。继续复用 MetaSaveService 的checksum、备份、schema/content版本校验、原生临时文件flush/读回/替换及Web写入读回机制。

新世界使用明确的新schema、内容版本和独立原生槽位/Web key；不兼容旧Run/Meta，不覆盖用户旧档。schema解释结构，内容版本解释稳定身份和引用。新世界自身后续升级只转换有明确语义对应的字段；身份变化、位置失效和缺失引用要显式处理并保持有效永久结果，以合法已登记落点安全恢复。实际退出重启恢复成功后才声明持久化成立，不能以会话内重入替代。未知未来schema拒绝，坏主档尝试有效备份，主备均坏保留原件并报告。保存成功确认后才发布成功事件。

固定世界使用独立世界payload和新槽；服务包括回收匠/织时匠、少量明确试制装备、委托与小站试鸣结果；购买、升级、维修、装配锁及周期道具已沿同一世界修订保存。正式48件/价格和完整剧情修钟仍待确认，不把试制结果标成正式世界修钟。旧原型Meta仍独立保留；具体代码与受影响验证见 [模块导航](../project/module_map.md)。
