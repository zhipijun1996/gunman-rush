# 地穴、沼泽与圣殿空间编排

本片为世界地图初稿。正式身份、资格与收集归world.json，候选改线沿spatial_layout.json；候选空间与逐房体验归config/world/spatial_clusters/underground.json，正式碰撞仍归construction和房间JSON。审核图与编辑器从候选源派生，不将地图定位视为关卡已施工。

W后从F16根道可进入地穴，与上树取得H互为自由选择，不要求钩索。蕈灯地穴以明亮上廊和营点为方向基准，经普通遭遇、可停看的菌台与弹菇前庭抵达蕈灯之母；获得D后展开上层收藏、后庭与菌钟支路。灯在黑暗门之前获得，HP03与CAP02保留独立回访目标。菌幕小环开放回营捷径，避免每次重走能力教学段。

萤雾沼泽保持宽岸、浅湾、倒树与深池的横向层次。滤芯之前可走干岸外圈、拿浅堤收藏并预览深区。滤芯与WH或WD分别承担装备和动作要求，不新增游泳资格；深池胜利后回程变短，毒水专门挑战仍保留。休息和服务在干岸，敌人不堵休息入口。

根脉圣殿以森林根井到达门厅，地穴从另一侧汇入。外层门厅、根柱和横廊让来向可辨；内层根桥承担HW应用，主Boss、调律室、维修收藏构成闭环。修钟后开放直接回门厅的根桥；技能双卫从整备点分流，不强制与主Boss连续战斗。T03外层横廊收束为根岸渡舟，通遗迹R01；移除无新决策的T03—T12长外环，主线仍由门厅、分流侧庭与内层推进，修钟回桥沿SC-T01。

P03的钩索高口与M02井室沿用现有占地；M02至M01采用明确的井内升降转场，两端各有停靠点和同一连接标记，保留L22/s03条件。转场不以穿过森林或平原的长线表现，也不将两个房间永久合并。地穴M01接沼泽旧渡堤S13，平原来路S01与S13在S14汇合；双闸S10位于遗迹市场上方。其它明确配对捷径仍单独标识，连续邻接使用有净宽的共享接缝。

审核时每房显示一句职责、Boss、休息、奖励和房内能力阻隔；按首访、能力后回访、主目标与可选路线分别查看。通路为房间占地的一部分；实际动作距离、敌人压力、镜头与失败恢复由后续灰盒验证。
