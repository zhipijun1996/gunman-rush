# 风铃平原

平原是学习反冲、观察风向和选择落点的首区。体验轻盈、开阔而有层次，草海、石灰岩、旧桥、铜铃和风动设施组成可记忆的探索空间；情绪从启程的发现走向高台上的动作考验。

## 探索与动作

| 地图 | 主要体验 | 场所与终点 |
| --- | --- | --- |
| 迎风草甸 | 安全试验跳跃、瞄准和反冲，发现高路奖励并回到主路 | 晨露入口、双岔台地、断桥低谷、风车岔口、鸣铃巡游站 |
| 逆风钟庭 | 读取多层路线，在机关和敌人压力下组合反冲、换层与落点修正 | 双铃峡谷、悬轮栈道、风车钟庭、静铃旧址、牧风高台 |

两张连通探索图都有上下层、环路、捷径与可选挑战。主路清楚，奖励高路、桥下旧址和侧路能从观察点被发现；取得奖励后有实际回返，不把支路做成只进不出的长尾。

典型挑战是反向射击越短沟、在破桥失误中修正落点、绕岩壁改变射击角度再返回开门路线、观察移动齿轮相位、围绕风车骨架交替横纵移动，以及低顶紧凑落点的自愿技巧路。地形、敌人、机关和收益共同改变判断，而非只换坐标和Seed。

主路支持正式进入构筑，并保留观察、恢复与接收位置；当前动作和资源沿全局合同。风、钟和地貌应提示空间联系、方向或可互动对象，不只是装饰。

## 画面与生态

统一采用 [Visual Bible](../visual_bible.md) 的细粒度像素语言。草顶石灰岩有完整顶、边、角、岩底、洞边与内部体量；风化石桥有梁、断口、拱孔和桥墩；木铜栈道有端头、支架、吊台与承载关系；旧址用半埋钟座、钟柱、拱门和石阶建立年代感。

远景以连续天空、缓云与山谷薄雾保持开阔；中景钟塔山脊、风车和旧桥承担地标；近背景草坡、林丛与木桩延续区域结构。草籽、花粉、风线、旗帜和铜铃轻摆随空间与机关状态变化。光色服务于路径和焦点，不把每个碰撞矩形各贴一张独立插画。

初风草坡、断钟石桥、风车钟庭、静铃旧址和牧风高台各有整体体量与可辨认用途。桥面和桥下探索可同时被看见，高台可回望走过的草坡与风车；植物有根基，机械有支撑，装饰不制造可站立性的假象。

自然生物占据草坡与桥墩，旧交通机械联系道路和风铃设施。敌人让玩家改变跳跃、瞄准、反冲与站位，普通探索可战可绕。普通怪样例见 [冲锋怪](../../data/enemies/plains_charger.md)，机关和声音从 [对象索引](../../data/README.md) 定位。

## Boss 与成长

地图一的鸣铃巡游机通过可预读冲锋、铃波和抛铃考验换位；地图二的牧风者以主动追压和全身招式考验持续判断。招式、弱点和表现以 [巡游机](../../data/bosses/bellstrider.md) 与 [牧风者](../../data/bosses/windkeeper.md) 规范为准，不在本页复制参数。

核心能力权益与随机道具奖励分开，胜利、回家与进入森林沿 [运行路线](../run_and_routes.md)。当前采用范围见 [当前状态](../../project/current_state.md)，地区品质依实际探索、正常速度音画和体验审查判断。
