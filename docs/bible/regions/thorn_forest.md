# 荆棘森林

森林围绕有根的巨树、交错枝路、可借用的活体和有去有回的探索网络建立身份。玩家先观察目标与落脚点，再选择钩索、反冲、普通跳跃或不同路径；不把整区简化为同一钩点链。

## 空间与动作

两张地图有明确差异，主路平缓教学，奖励分支增加技巧与决策。树腹、枝背、内外通道、树冠和回望构成地标及回环，落点、安全观察与返程共同设计。H 的合法授予及实际射程沿动作合同，主路只使用当前合法进入能力。

场所须有可辨认的地形用途和真实连通关系。相同动作换坐标、标签或模块名不算丰富度；机关、敌人和奖励应改变路线判断。完整探索时长是体验目标，需要真实游玩测量。

## 生态、地块与画面

动物、果实、蛛网、枝条和藤蔓有真实宿主与根基；可借用目标、危险和装饰在玩家尺度下可分辨。森林继承全局像素尺度和材质画法，通过生态、树体、围合、空气层次与动态体现地区差异。

具体敌人行为见 [森林对象](../../data/enemies/forest.md)，Boss 见 [对象索引](../../data/README.md)。画面与声音共同表达蓄势、运动、命中和环境变化，BGM 使用用户提供版本。

## 版本与采用

普通出发默认 `forest-bible-world-v15`。显式版本和候选不因文档日期自动晋升；v18 的每图初步8–12分钟、充分探索15–20分钟是尚待实玩验证的体验目标。采用范围与未验事项归 [当前任务](../../project/tasks.md)，具体生成版本由实际 Provider／配置选择。
