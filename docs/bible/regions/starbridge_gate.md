# 星桥天门：折星回路快速灰盒

当前房间沿用可选极限支线 `V-R12`「连锁反冲井」，这版的玩法副题为“折星回路”。正式区域、门 ID 和邻接关系仍以 `config/world/world.json` 为准；V-R11/V-R13 尚未施工，工作台展示接口而不伪装成可通过的正式房。`construction.implemented` 仍为 false。

## 本版目标

反冲和二段跳 D 是主要重复动作。房间只保留两个关键钩点，以六面可攀墙接续动作；布局包含窄道下降、横向冲出、竖直抬升、宽腔斜跨、绕墙下缘及折回内侧。预期路线约使用九次反冲，具体打法允许玩家优化。没有按钮计数或固定动作顺序门。

旧版十二环接力设计已被用户否决，本版不沿用旧版的完整通关、用时、12H/2W/2D及镜头检查结论。旧通关、恢复和绕法长脚本已由短基础检查替代。

## 真实尺度与资源

实体与组件唯一输入是 `game/world/regions/V/rooms/V-R12.tscn`，经同一 `WorldRoomDraft` 给工作台、原生运行和源码接入使用。房间保持1024×2048世界单位、24×36角色碰撞包络，入口、中继、终台及返程桥接口不变。灰盒皮肤读取同一组实体、墙、环和尖刺，不维护第二套碰撞几何。

按主游戏最新规则，玩家本体成功抵达钩点、首次有效贴住可攀墙，会补满当前空弹上限，恢复已拥有的D/H，并重新具备Q资格。仅钩头碰到目标、普通墙碰撞、持续挂住/贴住都不能重复补给；同墙须真实脱离后再接触才产生下一次恢复。墙跳保留既有D/H恢复，不重复算同次弹药/Q补给。

Q的2秒冷却不因地面、钩点或墙面恢复而清零。Q仅在有效反冲窗口保护光幕与敌人；荆棘、齿轮和实体墙仍危险。光幕前可以在环或有效墙面读路并等冷却，但不把每次反冲都强制成Q题。

`hwdq`是明确标注的后期隔离试玩配置，不修改正式新档或存档。新规则在主游戏能力消费者实现，本房不私有补资源。

## 空间职责

| 区段 | 空间与动作 |
| --- | --- |
| 入口至西折墙 | 起跳斜反冲、D调整接第一面墙，再左上反冲与D换向。实体平台保持稀疏。 |
| 岩舌下降窄道 | 横向冲入悬垂实体下方，绕过岩舌末端后下落向内；局部侧刺给出可读边界。 |
| 低位抬升窗 | 本房第一个钩点用于转向和恢复；向上反冲穿水平光幕，D侧移接内侧墙，再组合反冲与D上中继。 |
| 中继宽台 | 真正落地记录本段入口，供快速重试；不清冷却、不自动休息回血。 |
| 上部宽腔与折返 | 斜冲外墙、绕隔墙下缘，D抬升抓第二个环；随后向左下反冲回内侧墙，再斜跨高墙。 |
| 终台与返程 | 最后一段组合墙跳、反冲、D收束。真实手柄放桥后可走左侧安全落井返回入口。 |

两处齿轮的完整运动轨道可见。危险集中在转折与路线边界，不用密铺尖刺填满每个空隙。没有新增敌人、坡面或独立移动规则。

## 本轮验证范围

用户要求快速尝试，本轮只运行 `tests/world/stargate_basic.gd`：检查真实codec、场景加载、H/W/D/Q配置、左侧返程落井静态碰撞，以及两段代表操作。第一段由真实入口起跳，斜反冲加D接第一面墙；第二段明确使用局部测试起点，真实抓低位环后向上反冲穿幕、D侧移接墙。局部起点不是整房通关证据。

输出为 `build/stargate_basic/basic.json`，可选 `--capture` 保存正常镜头的代表段PNG。完整路线可达性、手机首见难度、连续节奏和好玩程度等待这版的实际试玩反馈，不再以长自动通关脚本作为快速发行前置。
