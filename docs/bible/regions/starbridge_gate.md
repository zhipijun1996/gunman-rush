# 星桥天门：折星回路快速灰盒

当前房间沿用可选极限支线 `V-R12`「连锁反冲井」，这版的玩法副题为“折星回路”。正式区域、门 ID 和邻接关系仍以 `config/world/world.json` 为准；V-R11/V-R13 尚未施工，工作台展示接口而不伪装成可通过的正式房。`construction.implemented` 仍为 false。

## 本版目标

反冲和二段跳 D 是主要重复动作。房间只保留两个关键钩点，以实体墙侧面接续动作；布局包含窄道下降、横向冲出、竖直抬升、宽腔斜跨、绕墙下缘及折回内侧。具体打法允许玩家优化。没有按钮计数或固定动作顺序门。

## 真实尺度与资源

实体与组件唯一输入是 `game/world/regions/V/rooms/V-R12.tscn`，经同一 `WorldRoomDraft` 给工作台、原生运行和源码接入使用。房间保持1024×2048世界单位、24×36角色碰撞包络，入口、中继、终台及返程桥接口不变。灰盒皮肤读取同一组实体、墙、环和尖刺，不维护第二套碰撞几何。

所有实体墙侧面均可攀附，不再用颜色或标签区分资格；禁止接触处使用可见墙刺。攀墙与钩头确认命中时恢复次数，冷却保留；完整规则唯一引用[能力合同](../../data/abilities.md)。

Q的2秒冷却不因地面、钩点或墙面恢复而清零。Q仅在有效反冲窗口保护光幕与敌人；荆棘、齿轮和实体墙仍危险。光幕前可以在环或有效墙面读路并等冷却，但不把每次反冲都强制成Q题。

`hwdq`是明确标注的后期隔离试玩配置，不修改正式新档或存档。新规则在主游戏能力消费者实现，本房不私有补资源。

## 空间职责

| 区段 | 空间与动作 |
| --- | --- |
| 起步与墙脚折返 | 起跳斜反冲、D调整接第一面墙；沿墙下滑绕墙脚横向反冲，D抬起后向上抓低位环。西侧上墙保留为可选攀墙练习支路。 |
| 岩舌窄道 | 岩舌和侧刺界定抬升窗左缘，防止把光幕误读成可随意穿行的背景。 |
| 低位抬升窗 | 本房第一个钩点用于转向和恢复；向上反冲穿水平光幕，D侧移接内侧墙，再组合反冲与D上中继。 |
| 中继宽台 | 真正落地记录本段入口，供快速重试；不清冷却、不自动休息回血。 |
| 上部宽腔与折返 | 斜冲外墙、绕隔墙下缘，D抬升抓第二个环；随后向左下反冲回内侧墙，再斜跨高墙。 |
| 终台与返程 | 最后一段组合墙跳、反冲、D收束。真实手柄放桥后可走左侧安全落井返回入口。 |

两处齿轮的完整运动轨道可见。危险集中在转折与路线边界，不用密铺尖刺填满每个空隙。没有新增敌人、坡面或独立移动规则。

## 路线可读性

路线唯一来自场景首个告示的 `route_guide`：工作台“路线与机关”显示编号、动作说明、箭头和危险图例，实际灰盒绘制同一编号与箭头。箭头表示建议通行方向，不是逐帧输入或已验证整链的证明。金色光幕标“反冲穿幕 · Q就绪”；粉红刺与齿轮不可由Q抵挡。所有墙使用相同实体配色。

## 本轮验证范围

快速检查由 `tests/world/stargate_basic.gd` 执行：真实codec、场景加载、H/W/D/Q配置、左侧返程落井静态碰撞；从真实入口连续执行斜反冲+D接墙、下滑绕墙脚、横向反冲+D抬起抓低位环、向上反冲穿幕+D侧移接内墙。第二处光幕使用明确局部起点，抓高位环后向左下反冲穿出。低位光幕按从下方挂环后的实际身体位置留出完整穿越余量。

输出为 `build/stargate_basic/basic.json`，可选 `--capture` 保存正常镜头的代表段PNG。当前11项基础检查与17项恢复检查通过，不代表中继之后的完整连续上攀、无伤整房或手机手感已通过；不以长自动通关脚本阻塞日常快速发行。
