# 峡谷、冰川与墓园空间编排

本片与平原、森林和地下三地区共同组成同坐标地图初稿。候选占地归config/world/spatial_clusters/northwest.json；身份、能力、奖励与永久动作继续归world.json。每次扩展都重新检查全部已定位片区的真实占地、共享接缝和邻区预留，不以各区局部通过代替全图成立。

轮廓围绕活动空间组织：避风岸用宽台与折壁，冰阶用阶状接落，墓园用庭院与双层回廊；Boss场地保留完整地面。只在功能换层处改变腔体，不为打破矩形而堆小锯齿。

峡谷从森林西侧避风岸登高，短壁井、横风桥、背风宽台与石窟交替。HP04支路兼有通墓园的横向出口；上风口预告冰川，峡风Boss另有整备棚。回程井和永久捷径接回谷底，不以无限下坠或单根攀井承担全区。

冰川从山麓看见镜峰，HWD要求放在镜脊房内的可预览断桥。固定冰阶、折层廊与沉雪侧洞组成紧凑回环；冻结车站转为普通地面战，再经折桥抵达检修台与镜峰守卫。战后冰钟操作台独立于战场，ATK03工棚支路与核心分开。复行索道连接山麓，墓园回口沿既有s10资格，不增加运输或新能力前提。

墓园从平原西口进入碑草旧道，经守花庭与长径抵达守夜处；森林、峡谷分别汇入守夜处的安全来向台。送葬岔庭区分冰川回口、可选月刃前庭和礼拜堂主路。灯门前有整备前室；送葬Boss、内墓末钟与王室纹章使用原身份。墓园以水平庭院、回廊和内墓层次展开，避免为容量堆竖井。

C02保留P27西口锚点，C08保留森林西口，C12保留森林北口；C09/C10/C11两端共同编排。C23向钟心中环预留实际接近段，不能越过最终封印。此前地穴井内升降转场保持独立标识。除明确转场外，两侧房间用同一点、相反门向与足够口宽相接；长通道要归入相邻房间并承担观察、遭遇或分层恢复，不用跨房线替代。

地图交付包含所有已定位区域、跨区接缝局部图、各房职责、休息/Boss/奖励和首访/回访路线。仍需后续灰盒校准动作距离、怪物压力与镜头，不因结构通过而升级审核状态。
