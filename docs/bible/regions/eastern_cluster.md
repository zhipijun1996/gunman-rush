# 古堡、工城与矿井空间编排

世界空间候选以玩家体验和可信地理重排，来源与正式运行的区别见[世界输入](../../data/world/README.md)。逐房完整房形、门口与路线归eastern.json及city.json；不以固定房数或旧跨区线限制布局。

古堡以外院、内廷、钟楼和档案侧翼组织回环。初访看见王室封门，纹章回访展开内廷；战前候钟室整备，骑士授Q后展开光幕后厅。修钟后的档案侧翼K11接工城高庭G31，要求纹章和clock_K；K24露台接钟心Z05基座，保留s24与纹章。删掉穿过平原且没有独立收益的C17远接矿井线，跨区旅行经过工城货运节点。

工城按生活西街、桥上步道、桥下货运、下城供能、上层授时院分层。P07田货轨车抵达G02安全街口，H门槛仍在入口分区内；G12—G15—G16的小庭回环返回同一熟悉街院。东站楼梯接桥下G18，货梯G18—G25保持已确认双向与资格。修炉后高庭检修车连接G30—G31；授时回程返回G23工人驿屋。G35高处作坊在clock_G后接浮岛A03，不能提前穿过修钟门槛。

矿井从平原闸口与沼泽干岸到上层中转；N01—N03—N13—N04按同一工作层接续。爆破仓战后取得爆破武器，深矿门保持HW或HD。工城矿货升降接N04，上下交班笼N04—N06保留s21，由N06交班站启动。遗迹R02来路接N05的entry:L12，先看见门槛而不落在锁后。N19矿井侧打开s33后，R10退水设施经N19泵廊、N20运水廊、N22沉泵间、N21检修井到N06，逐段留准备岸；N14冷却回廊接E04炉壁侧台，保留s34。

所有交通以具名两端展示，其运行设施与演出尚待施工。地图结构、资格模型与实际动作分开验收；稳定落点、敌人压力、视野与失败回程在灰盒中校准。
