# 古堡、工城与矿井空间编排

本片先完成职责、路线、能力阶段与跨区接续；用户要求轮廓细节留待世界初稿完成后集中打磨。保留简单可读的房腔与有实际宽度的通道，仍须检查重叠、阻塞和错误门向，不以暂缓轮廓打磨豁免结构错误。来源沿世界输入，房间与奖励身份保持。

古堡外院先展示王室封门与侧库；带墓园纹章回访后，内廷回环、侍钟骑士路线与档案支线分流。战前候钟室允许整备，击败骑士获得Q后，安全厅先留稳定岸，再进入逆相光幕后厅；内廷钟楼与修钟后的档案分开，原有永久捷径回到王冠庭院。HWDQ偏记室独立于主线，不把无Q初访引进不可退死路。

工城保留工房与生活街区、悬钟桥及桥下步道、东站战斗与定束机修、动力沟与授时院五种职责。救出武器匠先给服务回报，东站胜利与熔火供能分别按原状态推进；不因先到传动总钟而提前完成修复。检修吊笼SC-G01原设计就是成对停靠点，使用明确升降转场而非画穿房线；用户指定P07向东调整；连同P18接近段移至城门下方，保留连续进城，不采用城门短转场。工城内部G18→G25货梯是否改为跨层转场仍待确认，决定前不改其连续通道合同。

矿井从平原闸口与沼泽干岸抵达上层中转，普通矿道环先能往返。爆破仓战后取得爆破武器；深矿入口保留HD，封闭采时井与矿钟围绕爆破门展开，磁轨侧室和攻击提升支线各有预告与安全回程。长的高差段要分成能辨认方向与停靠恢复的工作层，不做一口气盲坠。

古堡C05、矿井C06与沼泽C31以现有锚点接续；C16/C17/C20/C21由相邻地区共同编排。钟心、浮岛、遗迹和熔火的接口保留具名方向和接近空间。地图通过只证明候选空间成立，不代表灰盒、战斗、美术或人工初审通过。
