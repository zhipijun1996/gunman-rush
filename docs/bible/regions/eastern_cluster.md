# 古堡、工城与矿井空间编排

世界空间候选以玩家体验和可信地理重排，来源与正式运行的区别见[世界输入](../../data/world/README.md)。逐房完整房形、门口与路线归eastern.json及city.json；不以固定房数或旧跨区线限制布局。

古堡外院是城市的王家供料端，内廷才由纹章封门保护。K18经外院交接庭K25到供料廊K06，沿C16进入工城上街；不必先修古堡钟，工城入口仍以H配W或D分隔安全预览与主体。K06去K15的收藏路线保留clock_K与HWDQ，去K11档案厅须纹章和clock_K，不能通过新外院口绕入收藏或内廷。内廷、骑士授Q、钟楼和K24通钟心的既有职责保持。档案厅另有修钟后直达工城高庭G31的检修口，与首访上街口用途不同。

工城是分阶段反复穿行的城市枢纽。生活西街、王家上街、桥上步道、桥下货运、下城供能和授时院以同一悬钟地标建立上下关系。风鸣钟修复后，同一农货轨车恢复P31小站东门直达G02的班次，P07保留沿途田货站。首次服务不用步行经过P35、P18和P07；H即可完成G02—G01—G03—G01的解救、工作台整备、ATK01领取及基础攻击一阶升级，再选返回或探索庭院。上街G37—G39—G38连续落到橱窗旧街G15，承接古堡来向，不能把上街和城市主体分成孤岛。矿井货梯抵达东站G22，先听见广场钟声，再从东支座打开回桥。玩家可先选古堡、矿井或武器支路；首次赴熔炉不用先打督工。

引导以服务收益和恢复运转的设施为主：P10武器匠支线提前约定工城见，但不能作为唯一提示；P15首次修钟提供东门驿车与工坊线索，跳过演出也保留获知状态；P31用真实站牌和可辨认车辆确认方向。地图只标已听说的工坊服务与车站，不揭示未知房形。原有材料与升级事务保持唯一，不另发重复免费奖励；不封西线、不要求清空城市，不以长任务说明替代空间引导。此项与交通演出均为候选设计，尚未接入正式运行。

机关按设施作用改变路线：工坊停线解除匠人困局；东支座放桥形成跨街近路；深矿检修路从内侧解除工坊井盖s21；修炉恢复主轴维护门及王家上街配重梯。配重梯从G37的HDQ准备分区接G31，高庭和下街成为连续空间；G30—G31检修车是另一条回路，G18—G25已确认货梯保持。玩家从炉区新口回G28后，可进高庭，也可先回工坊升级；G35通浮岛仍要求clock_G。

推荐行程是选择样例，不是强制顺序：H首访西街后折返；HW从古堡外院沿上街进入；HD从矿井升到东站并开回桥；深矿支线携材料走检修井返回工坊；取得Q后赴炉，修炉后从维护侧回城，再选高庭或服务回访。每次进入要带来新街区、新视角或永久捷径，不能只换入口后重复整条主路。地图审核同时展示条件、休息点、Boss、素材收益及失败退路。

矿井从平原闸口与沼泽干岸到上层中转；N01—N03—N13—N04按同一工作层接续。C20矿货升降抵达工城东站，保留入口HW或HD检查。爆破仓授予爆破武器，N05深矿入口仍要求HD；进入矿钟支线还需爆破。N17分向标定收藏与废轨提升井N25，经冷凝检修层N24、工坊抽风井N23抵达G11试射室。s21只能在N23内侧解除，开后双向；井道分段提供停止、观察和恢复台，不能做连续空爬或凭空电梯。这条路把矿井探索收益带回工坊，与东站货梯互补。

遗迹R02来路接N05的entry:L12，不绕过深矿门。N19矿井侧打开s33后，旧城泵廊经N20、N22、N21接N06；N14冷却回廊接E04炉壁侧台，保留s34。修炉同时开放炉后矿井回路和城市维护回程，玩家可选继续采矿、带材料回城或去授时院；热危险本身不因修钟全部消失。

所有交通以具名两端展示，其运行设施与演出尚待施工。地图结构、资格模型与实际动作分开验收；稳定落点、敌人压力、视野与失败回程在灰盒中校准。
