# 遗迹、熔火与高空片区

本阶段交付统一坐标的空间候选。完整房腔、门口、职责与路线归[下东片区](../../../config/world/spatial_clusters/lower_east.json)和[高空及钟心](../../../config/world/spatial_clusters/upper_world.json)；身份与候选改线的所有权见[世界输入](../../data/world/README.md)。

遗迹位于湿地双闸下方：干岸旧船所、旧街、市场与泄洪设施按水位分层。R01—R03—R13—R15—R02是首访干街，市场下探R16/R12形成探索分支；clock_R后打开R03—R12，缩短回访。R02东侧进入深矿门前而非锁后；退水后的R10泵道进入矿井交班层，冷却渡路在s35后接炉底E11。圣殿T03到R01为根岸渡舟，保留原资格，两端各有安全停靠，不把运输距离画成长空廊。

熔火围绕炉口观测、压力绕行、主轴修复和冷却回程组织。E15工炉装卸站承接工城货运，HDQ入口分区随C22迁移，资格没有被跨区落点绕过。初访可预览E10冷却检修廊的ATK04；clock_E后才从E15进入领取并接回工城维护侧。热流动作之前有安全观察岸，连续段之间留可停靠恢复的空间。修炉后E10通G28是新来向，E04通N14是继续矿井的选择；城市配重梯与主轴维护门恢复供能，玩家可先回工坊或挑战高庭，不强制原路回城。四区行程见[工城片区](eastern_cluster.md)。

浮岛以落脚岛、错层桥岸和高处回访路组织方向；星桥分为观测中庭、双翼与独立极限支路。平台挑战的空隙与恢复岸后续按真实动作确定，不能把地图跨度当成一次跳跃。工城G35高露台接A03，古堡K05屋顶接A06；角色在不同高度反复看到同一塔身，帮助建立世界位置感。

世界钟心以基座、主轴、封印环、档案侧翼和最终场地向上展开。墓园C13通过s23回到Z01熟悉门厅，古堡侧露台接Z05基座；封印前环经Z17检修台、Z14观测井、Z18接引露台到星桥V03。检修台负责横向辨路，观测井分层恢复，露台负责登顶后的观察与跨区接近；最终封印资格仍在主轴入口，不由此绕过。P33进入Z01沿既有正门转场，当前Z01运行剧情保持；最终场地的宏伟体量服务战斗与构图，具体尺度仍需灰盒校准。
