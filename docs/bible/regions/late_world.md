# 遗迹、熔火与高空片区

本阶段只交付世界空间初稿，轮廓精修与真实动作校准后置。逐房职责、尺寸、通道、路线和失败恢复分别归[下东片区](../../../config/world/spatial_clusters/lower_east.json)与[高空及钟心](../../../config/world/spatial_clusters/upper_world.json)；身份、能力、奖励、NPC与永久动作继续归world.json，不复制身份表。

沉水遗迹从旧船所与水闸形成多来向汇合，静水辨路、错层桥岸和沉井挑战交替。明确哪条是当前可退的干岸、哪条是能力回访，奖励支路完成后归回已见主路。熔火腹地围绕首炉观测、压力绕行、主轴回程组织；先在安全岸观察热流，再把动作和热流周期结合，连续段之间留真实停靠，不把冷却等待放在强制空中连段中。

破碎浮岛以落脚岛、上行连接和回访高路组织三维方向感；宽岛承担观察、遭遇与恢复，窄路承担明确动作。星桥天门把两翼路线与中部场地组合，极限支路独立于正常推进；隔离挑战的资格、奖励和返回仍沿原合同。高空坠落的恢复必须随实际灰盒安排，地图中的长连接不能直接当成可玩跳跃距离。

世界钟心保留损毁门厅、古堡／墓园来向、内部主轴、档案支路与最终场地的纵向层级。平原P33进入Z01沿既有前门转场；最终场地的体量服务多阶段战斗和宏伟构图，不按截图缩小成一间普通平台房。地图候选不改变当前Z01运行剧情。

连续连接归两侧房间实际占地；原设计的具名成对交通使用同号端点，不画穿过其它房间的通道。所有候选尚需按角色参数、镜头、能力锁反例和失败回程逐区校准，不以地图无重叠替代玩法验收。
