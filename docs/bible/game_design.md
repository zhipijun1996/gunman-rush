# 游戏设计

Gunman Rush 是横屏动作肉鸽，以反冲位移、精确平台操作和随机探索为核心。战斗服务于站位、空中资源和落点判断；奖励支线提供更深的可选技巧与构筑收益。

## 产品范围

正式入口为标题、可操作家园、平原两图、H／钩索权益、森林两图及开发边界。每地区第一图较易并有小Boss，第二图深化机制并有地区Boss。普通探索可绕过怪物；Boss遭遇按实体封场和胜利流程结算。

长期框架为S1–S6六阶段、16地区设计池，每次访问各阶段的一条合法路线。地区能力门槛见 [地区设计](regions.md)，实际开放与缺口见 [当前状态](../project/current_state.md)。地图／能力候选不等于已开放内容。

## 核心体验

- 输入表达移动、跳跃、瞄准、射击和能力意图；唯一PlayerMotor处理碰撞运动。
- 动作衔接遵守 [资源合同](combat_and_recharge.md)，攻击资源、瞄准慢时与能力恢复各有职责。
- 同一时刻装备一种武器家族。武器进化、H／W／D与随机道具分别承担攻击解法、移动能力和本局构筑。
- 主路依赖已授予能力并提供可读恢复；高收益及隐藏路线可要求更深入的技巧。
- 关卡变化体现在动作、决策、探索和视觉身份，而不只体现在坐标或Seed。

## 敌人与 Boss 战斗原则

敌人改变地形中的站位、空中动作和落点决策，不依靠单纯提高生命或数量制造新机制。预告、攻击、真实命中与恢复保持明确时钟、可读形状和反制空间；接敌距离、视线、安全点与同时压力分别考虑。主路覆盖实际合法构筑，开发候选不自动进入正式池。

伤害和生命周期遵守共用合同，表现消费接受结果。Boss 由实例 Encounter 管理招式、弱点与阶段，地图管理封场和地图级账本；终态按实际演出／失效时序提交胜利，奖励只结算一次，玩家同帧死亡优先。对象行为、具体招式与参数从 [对象数据索引](../data/README.md) 进入，不在本页复制。
