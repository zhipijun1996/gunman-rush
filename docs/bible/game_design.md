# 游戏设计

《失序之钟》是固定世界类银河恶魔城。玩家以射击反冲、平台动作、能力解锁和回访探索16地区；永久收集、修钟和捷径改变世界。房间、分区与连接身份以 [世界输入](../data/world/README.md) 为准，实际实现见 [当前状态](../project/current_state.md)。

## 核心体验与范围

基础移动、跳跃、射击反冲和既有主动时间能力沿用当前真实控制器参数。地区加速、缓时、停时由画面、BGM、敌人和机关表达，不自行改变玩家重力、跑速或能力距离。Input 提交意图，唯一 PlayerMotor 执行运动，表现消费接受事件。

探索围绕可识别地标、入口预览、房内能力阻隔、解锁后的回访与有意义回程展开。战斗服务于站位、空中资源和落点判断；高风险支线提供相称收益。结构灰盒允许占位，但实际运动、门台、状态、交互和失败恢复必须成立；Boss胜利替身不证明战斗完成。

## 敌人与 Boss

保留现有物种、招式、弱点和演出成果；新世界中的实例位置与永久胜利由世界身份绑定。预告、命中、恢复使用明确时钟和可读形状。Boss通常安全窗口容纳2枪，第3枪是贪刀风险，不用隐藏伤害上限封顶。最简单普通敌人9HP；其他HP按首访攻击档和职责选定后固定，不随玩家升级涨血。旧对象40/60HP是原型配置，不能直接作为新战斗定稿。

轻量18–28、标准36–48、较长关键48–64次普通枪有效命中仅为候选参考，需实战调试。攻击预算见 [武器](../data/weapons.md)。玩家同帧死亡优先于未提交胜利/奖励；已提交永久结果不可清除。
