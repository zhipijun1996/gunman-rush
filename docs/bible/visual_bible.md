# Visual Bible

## 全局规格

统一细粒度童话像素风。正式地形原生32px／32wu，世界表现1wu采样、nearest；保留Underworld家族的47邻接、精确边界适配及实际光照／材质语言。原图内容、显示尺寸与物理碰撞分别管理。

当前共享技术参考从 [Bible注册表](../data/creative_direction/bibles/registry.json) 的`shared_style_authority`解析；两区域总谱由同一注册表的`direction_path`定位。画风意图、技术绑定与用户视觉认可分别记录。

## 空间与功能

角色、弹道、危险预告和落点最清晰。远景低对比，中景承接大体量和区域地标，近景稀疏且避开唯一通路。附属于可玩地面的棚屋、建筑和道具使用世界坐标及所属支撑，不能把实体素材降对比并施加后景视差来制造层次；独立后景须有自己的地面、距离和遮挡关系。暖光与清透空气透视按场景目的使用；区域特色由材料、生态、结构、形体及色光表达。

岩壁有连续体量与断面，建筑有根基，藤枝有真实宿主；拱门只在真实门洞或桥梁结构中使用，不把整座石拱反复立在道路和薄平台上充当地标。支撑件按实际梁底、地面和两岸高差拼装，材质对比与远近层次一致；平台、端头、填充和附件分别处理。贴地道具按可见基座与地形接触面定位，柱顶对齐实际梁底；NPC双脚及道具整个底座须有同层真实支撑，不能只校中心点，也不能借临时升降台遮住悬空。平台或井口改形后，同步重排依附物并从两侧复查；不能只把PNG外接框下沿设为地面就认为接地完成。沿镜头移动和上下层观察接触缝，不用统一下移掩盖不同素材的锚点问题。刺与危险的实际方向、支撑及碰撞一致。材质切片、边界与光照不制造可站立性的假象。封闭室内使用相应墙体、梁架、轴系与局部灯光；室外天空、完整风车外立面、远山和自动草丛不混入室内。室内外门口由实际连接决定，使用建筑侧缘/洞井开口和内暗外亮的纵深提示，避免室外直接触碰无建筑的边界就切到室内。窗外景物须有明确窗洞和遮挡，破损处植被须有具体生长位置；同一室内判定同时约束背景、前景、地形材质和环境粒子。

远处大型地标必须和其所在山体、雾层共享稳定的景深参照。P32世界钟心塔属于完整背景底板，塔基由远山和谷雾遮住；不把可见底座的建筑剪影独立贴在近景平台上，也不随切镜头重新寻找近景落地高度。

环境照明按房间材质选择稳定的天光或室内底光；室外投影来自固定方向的天光，室内亮区对应可见开口、灯具或充电站线圈。灯光锚点绑定实际发光像素，不以整张贴图高度比例猜位置；投影计算覆盖整房遮挡体，不能随镜头裁剪范围变化而突然改变。修钟只按修复事件缓慢改变各自环境基调，室内不套室外亮度。

人物自带随身柔光，光源跟随真实身体位置，克制地照亮附近地面、墙体与道具，并受实体遮挡。主角与怪物本体保持稳定的原色可读性，不受环境阴影压黑；怪物自身的受击闪光、攻击预警与原图明暗保留，只有具有发光设定的部位投射局部光，不为每个怪叠加大范围灯光；受伤、死亡和恢复的状态表现仍按实际事件保留。环境中的地面、建筑和附着道具继续共享可读的投影来源、方向与明暗关系，不整体取消场景光影。以正常速度穿过明暗边界、进入室内和跨房检查随身光连续性；参数归`config/world/player.json`。

平原空气与受光按PR141认可参考校准：暖日光与冷天光形成地形/道具受光层次，发光面与局部灯位一致；风点按实际可见空气面积维持可读密度，保留亮核、短尾、主风向和实体遮挡，不按大房间总面积稀释。人物随身光保持原调色可读。P32世界钟心塔是低对比远景地标，以慢视差和空气透视表达体量，不使用贴在可行走平台上的前层道具代替远观。

## 母版与合屏

人物补帧以正式入口当前实际绘制的身体为母版，不能用同角色的旧立绘代替。登记母版资源、实际切片和显示变换；在同一世界尺度、脚底与镜头下并排比较待机、动作进入、关键姿势和退出。除总高度，还核对兜帽体积与宽度、头身比、胸腹宽度、四肢长度、鞋底宽度及像素密度。屈膝、趴地和低头自然降低高度，不能逐姿势拉到同高；头身比例错误须返工原画，不能整体缩放掩盖。正常速度反复切换，出现变瘦、变大、脚底漂移或画法跳变时不得以碰撞、资源或动画状态测试通过替代视觉通过。

先一件适合真实空间用途的母版，核完整边界、alpha、锚点及采样；再在正式镜头、角色、敌人、UI与连续动作下审查。通过黄金样板后扩资产族，并在不同结构的第二空间验证复用。

实际运行像素、正常速度音画和来源记录共同构成审查依据。相关资产／构图／动画由对应专业Skill执行，生产与审查方法见 [内容流程](../project/content_pipeline.md) 和 [质量规则](../project/development.md)。

## 素材与连续动作

先完成同族代表资产的真实空间用途，再制作完整边、角、端头、内部、孔洞和变体。原图像素、显示尺寸与物理碰撞分别核对，不能为贴图改变碰撞或强吸附网格；dual-grid 等实现方式只在实际消费者与语义验证成立时采用。

角色、敌人和机关的进入／持续／退出／中断保持同一身体、重心、脚底及附件关系。大体量Boss优先采用固定分层素材、骨骼／铰点和动作曲线；刚性车体、轮组及巨兽躯干不能靠整图形变或全身缩放模拟连续动作。不同批次的补帧须检查相邻姿势、材质明暗及内部透明孔洞的一致性，数量增加不等于连续；持续动作、一次性动作与轮组／风车等旋转部件分别计时，不把整身预备动作当作高速循环。动作、特效和声音对应真实事件，镜头、危险预告、弹道与落点始终可读。素材保留原图、参考、许可和生成／加工来源；黄金成立后在第二种空间核复用。
