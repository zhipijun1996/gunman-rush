# Visual Bible

## 全局规格

统一细粒度童话像素风。正式地形原生32px／32wu，世界表现1wu采样、nearest；保留Underworld家族的47邻接、精确边界适配及实际光照／材质语言。原图内容、显示尺寸与物理碰撞分别管理。

当前共享技术参考从 [Bible注册表](../data/creative_direction/bibles/registry.json) 的`shared_style_authority`解析；两区域总谱由同一注册表的`direction_path`定位。画风意图、技术绑定与用户视觉认可分别记录。

## 空间与功能

角色、弹道、危险预告和落点最清晰。远景低对比，中景承接大体量和区域地标，近景稀疏且避开唯一通路。暖光与清透空气透视按场景目的使用；区域特色由材料、生态、结构、形体及色光表达。

岩壁有连续体量与断面，建筑有根基，藤枝有真实宿主；拱门只在真实门洞或桥梁结构中使用，不把整座石拱反复立在道路和薄平台上充当地标。支撑件按实际梁底、地面和两岸高差拼装，材质对比与远近层次一致；平台、端头、填充和附件分别处理。刺与危险的实际方向、支撑及碰撞一致。材质切片、边界与光照不制造可站立性的假象。封闭室内使用相应墙体、梁架、轴系与局部灯光；室外天空、完整风车外立面、远山和自动草丛不混入室内。室内外门口由实际连接决定，使用建筑侧缘/洞井开口和内暗外亮的纵深提示，避免室外直接触碰无建筑的边界就切到室内。窗外景物须有明确窗洞和遮挡，破损处植被须有具体生长位置；同一室内判定同时约束背景、前景、地形材质和环境粒子。

## 母版与合屏

先一件适合真实空间用途的母版，核完整边界、alpha、锚点及采样；再在正式镜头、角色、敌人、UI与连续动作下审查。通过黄金样板后扩资产族，并在不同结构的第二空间验证复用。

实际运行像素、正常速度音画和来源记录共同构成审查依据。相关资产／构图／动画由对应专业Skill执行，生产与审查方法见 [内容流程](../project/content_pipeline.md) 和 [质量规则](../project/development.md)。

## 素材与连续动作

先完成同族代表资产的真实空间用途，再制作完整边、角、端头、内部、孔洞和变体。原图像素、显示尺寸与物理碰撞分别核对，不能为贴图改变碰撞或强吸附网格；dual-grid 等实现方式只在实际消费者与语义验证成立时采用。

角色、敌人和机关的进入／持续／退出／中断保持同一身体、重心、脚底及附件关系。大体量Boss优先采用固定分层素材、骨骼／铰点和动作曲线；刚性车体、轮组及巨兽躯干不能靠整图形变或全身缩放模拟连续动作。不同批次的补帧须检查相邻姿势、材质明暗及内部透明孔洞的一致性，数量增加不等于连续；持续动作、一次性动作与轮组／风车等旋转部件分别计时，不把整身预备动作当作高速循环。动作、特效和声音对应真实事件，镜头、危险预告、弹道与落点始终可读。素材保留原图、参考、许可和生成／加工来源；黄金成立后在第二种空间核复用。
