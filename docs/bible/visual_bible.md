# Visual Bible

## 全局规格

统一细粒度童话像素风。正式地形原生32px／32wu，世界表现1wu采样、nearest；保留Underworld家族的47邻接、精确边界适配及实际光照／材质语言。原图内容、显示尺寸与物理碰撞分别管理。Windows与Web以1280×720内部视口渲染，再适配窗口；最大化和还原不改变内部像素采样或角色尺度。Windows的GL Compatibility通过ANGLE／Direct3D呈现；渲染路径调整须检查实际窗口与房间，不能用无界面启动代替。

当前共享技术参考从 [Bible注册表](../data/creative_direction/bibles/registry.json) 的`shared_style_authority`解析；两区域总谱由同一注册表的`direction_path`定位。画风意图、技术绑定与用户视觉认可分别记录。

## 空间与功能

角色、弹道、危险预告和落点最清晰。远景低对比，中景承接大体量和区域地标，近景稀疏且避开唯一通路。平台附着前景从具体岸沿、桥底、局部顶棚或建筑构件产生，房间内部也可设置，不按世界外边框或每块平台自动铺一圈，不运行按边界随机补草或枝叶的前景系统。每个前景实例须在房间规划中明确宿主、位置、体量、遮挡与运动。它随所属支撑的世界坐标稳定附着，枝叶根部固定、末端轻动；局部交叠表达前后层次，角色附近可做有限避让，不能遮住落点、怪物预警或造成假碰撞。附属于可玩地面的棚屋、建筑和道具使用世界坐标及所属支撑，不能把实体素材降对比并施加后景视差来制造层次；独立后景须有自己的地面、距离和遮挡关系。暖光与清透空气透视按场景目的使用；区域特色由材料、生态、结构、形体及色光表达。

房间是空间美术的整体设计单位。先依据已定路线、房形、出口与角色尺度安排全房的体量、明暗、留白、景深和地标，再沿正式镜头路径检查连续整屏构图，之后才绘制与组装构件。整房美术可重做，不以保留当前装饰为前提；局部修改必须服从整体方案。为构图微调地形时须明确变化范围，保留房间职责和能力门，并复验路线、净空、落点和相邻接缝。房间氛围先用一句空间设定约束材料、光向和运动，再沿入口、动作中点、落点与出口的实际镜头形成连续构图。先看去除装饰后的大明暗块和主角剪影；背景大结构解释空间，必要的附着构件解释建筑或机械用途，局部亮区引导动作，稀疏前景只框住画面边缘。窗框、窗外纵深、墙面凹槽与落光必须一起设计；尘粒在光路里更可见，遮蔽处收敛。禁止用全屏雾化或到处加亮窗代替纵深。

连续路线先建立空间节奏：同一区域共享地形、像素密度与色光基调，开阔通道、地标前庭、封闭内室、竖井与战前休整依各自用途分配远近体量、视野留白和风尘密度；不能逐房堆装饰或整条路套用相同密度。入口、动作中点、落点、出口及返回方向均按正式镜头合屏复查。

主题素材清单不等于房间构图：先按实际相机段核对明暗块面、主角对比度、像素密度与动作带，装饰的亮度和细节不能压过主角；大型树木须在合屏中校准体量。窗洞按建筑层高、墙面分区和梁柱布置，门口连同入口平台、墙身、屋檐和内外景深整体组织，不能靠多贴几个独立窗框或门脸声称已完成定制。地形拓扑、材质分区、表面替换和跨材质接缝遵守[地形与材质](terrain_materials.md)。接缝仍按场所组织，像素密度、根部和真实实体连续，不以换材遮盖不合理空间。岩壁有连续体量与断面，建筑有根基，藤枝有真实宿主；拱门只在真实门洞或桥梁结构中使用，不把整座石拱反复立在道路和薄平台上充当地标。支撑件按实际梁底、地面和两岸高差拼装，材质对比与远近层次一致；平台、端头、填充和附件分别处理。

悬空平台不默认加立柱：自然岩台、短跳台和反冲动作带可保持简洁独立轮廓，不能为了逐块解释承重搭成柱林。只在桥梁、建筑、升降机械等有明确用途处保留支撑。无碰撞的柱梁属于背景结构，保留稳定附着坐标与完整基座，用环境色压低明暗反差和亮边，在角色与危险后方形成连续关系；不使用玩法墙体的强轮廓、顶边或落脚暗示，也不靠透明或漂移视差假装退后。柱梁切断动作带或像可攀墙时优先删除，不能为了装饰增加碰撞。保留构件才检查柱顶与梁底接缝，不将接地规范误用成每台必有柱。

人物与地面怪按可见脚底、实际碰撞足点和地形不透明承载面共同校准；透明草尖只作覆盖，不当作实体面。贴地道具按可见基座与地形接触面定位，柱顶对齐画出的梁底，不以碰撞盒底代替；平台端头在岸面收口，不穿插地形；NPC双脚及道具整个底座须有同层真实支撑，不能只校中心点，也不能借临时升降台遮住悬空。平台或井口改形后，同步重排依附物并从两侧复查；不能只把PNG外接框下沿设为地面就认为接地完成。沿镜头移动和上下层观察接触缝，不用统一下移掩盖不同素材的锚点问题。刺与危险的实际方向、支撑及碰撞一致。正式射击风铃的主铃和访问铃使用同一纹理、原生比例与接受反馈，不因父场景样式标记不同切换旧图标。材质切片、边界与光照不制造可站立性的假象。

封闭室内使用相应墙体、梁架、轴系与局部灯光；纵向井道的曲面感可由固定在世界坐标的连续受光与实际窗灯体现，纹理保持原生密度，不按镜头段重复圆柱透视或明暗重置。宽检修厅与窄井身分别构图；室外天空、完整风车外立面、远山和自动草丛不混入室内。室内外门口由实际连接决定，以门洞、门槛、连续基座、墙体或屋檐和照明组成完整建筑片段，室外土石在门槛处接入砌体，使用内暗外亮的纵深提示；可进入洞口须显出洞沿厚度与后方空间，不能用贴脸实墙封死视线。内外两侧共享材质和可辨识构件，换房后仍能理解是同一建筑。已有墙体缺口可只用贴合上沿、下沿的简洁窗框明确入口，保留轻薄接驳平台；不为强调入口另造整座立面或加厚台地。入口交互类型按房间制作规范区分边缘通路与场景内建筑门。房内正面门应连同接近落台、建筑下部、门框厚度与门内暗部整体构图，不能只贴一张门图；进入和返回的方向与切换表现一致。入口素材的视角必须匹配实际通行方向：横向进入应能看见被顶板、地面与背墙围合的侧向通道，角色实际走入覆盖范围；正面门脸不能代替侧向入口，接地与调色也不能补救错误视角。侧向通道优先保留：先把接近落台、可走短廊、顶部体量与前景遮蔽作为一段建筑剖面设计，再装材质。用无装饰灰盒检查空间收束与角色穿行，不能把现有薄墙缺口固定不动、仅补门框和背墙后就判定侧切不可行。需要调整局部通道时按关卡合同校验路线、净空和返回；相邻两侧保持洞口净高、材料关系与来向一致，切换应发生在已辨认的通道内。结构方案仍不适合本房时才采用场景内门前交互。可见实体顶板与真实碰撞一致，避免室外直接触碰无建筑的边界就切到室内。窗外景物须有明确窗洞和遮挡，破损处植被须有具体生长位置；同一室内判定同时约束背景、前景、地形材质和环境粒子。

隐藏小室按实际顶板、地面和可见净高制作封闭背墙，与相邻空间共享材料。完整房间插画不能作为小室墙纸重复平铺，不能出现被顶板截断的拱洞、假入口或与室内混用的天空。遮蔽入口继续由真实前景覆盖，不以背墙亮区提前泄露。

室外以天光、低对比远山和具有自身地面的远处植被建立空气纵深；附着树木的全部根部须在承载面内，不能以最低一条根须接触地面代替根盘落地；树干、根须的体量与像素纹理在合屏下匹配现有地形，缩小和调暗不能补救画法不合。动作带保留安静背景；高处奖励借平台剪影与可读构图提示，不靠巨大树木抢占画面。建筑入口与台地砌体、墙身、屋檐共同构成完整边界。

背景中的云使用独立透明层，位于天空底色与固定山体／塔景之间；不同云层缓慢漂移、错相交替并轻微变换疏密，边缘循环无突跳，暂停时冻结。远景底图不得烘焙静止云或通过扭动天空像素冒充云层。居民物种与角色体型沿[故事](story.md)的动物居民设定，场景和肖像共用同一形象。玩法层NPC的面部和轮廓优先可读；后排建筑降低局部对比并融入环境色，保留房间基调，不以透明幽灵建筑或给NPC叠巨大光圈解决层次。

远处大型地标必须和其所在山体、雾层共享稳定的景深参照。P32世界钟心塔属于完整背景底板，塔基由远山和谷雾遮住；不把可见底座的建筑剪影独立贴在近景平台上，也不随切镜头重新寻找近景落地高度。

环境照明按房间材质选择稳定的天光或室内底光；开阔室外以固定方向的暖日光和冷天光照明，不把悬台和地面当作无限长日光遮挡体。局部遮阴只在实际屋檐、洞口及建筑覆盖范围内成立，边缘有清楚宿主；室内亮区对应可见开口、灯具或充电站线圈。灯光锚点绑定实际发光像素，不以整张贴图高度比例猜位置；投影计算覆盖整房遮挡体，不能随镜头裁剪范围变化而突然改变。修钟只按修复事件缓慢改变各自环境基调，室内不套室外亮度。

人物自带随身柔光，光源跟随真实身体位置，克制地照亮附近地面、墙体与道具，并受实体遮挡。主角与怪物本体保持稳定的原色可读性，不受环境阴影压黑；怪物自身的受击闪光、攻击预警与原图明暗保留，只有具有发光设定的部位投射局部光，不为每个怪叠加大范围灯光；受伤、死亡和恢复的状态表现仍按实际事件保留。环境中的地面、建筑和附着道具继续共享可读的投影来源、方向与明暗关系，不整体取消场景光影。以正常速度穿过明暗边界、进入室内和跨房检查随身光连续性；参数归`config/world/player.json`。

平原空气与受光按PR141认可参考校准：暖日光与冷天光形成地形/道具受光层次，发光面与局部灯位一致；风点按实际可见空气面积维持可读密度，保留亮核、短尾、主风向和实体遮挡，不按大房间总面积稀释。人物随身光保持原调色可读。P32世界钟心塔是低对比远景地标，以慢视差和空气透视表达体量，不使用贴在可行走平台上的前层道具代替远观。

每间房在选图前根据腔体、地点设定、空间层次及进出视线判断已有背景与构件是否适配；先核对直接相邻房的室内外关系与高度，下层不自动等于地下室，封闭背墙须有真实围护结构和出入过渡作为依据。成对比较门内外正常镜头的岸顶、净空、材料及地平线，几何可通过不等于视觉连续；适合才复用，不适合就新创所缺层次，不以缩放、染色或堆叠装饰迁就不合适的素材。室外远景按地点职责、真实高度与相邻房连续性选用；同区域共享色调与地理关系，不等于所有房间铺满同一丘陵底图。先在正式镜头核天空／远地占比与地平线，再设视差及地点地标，登高应显出高度变化。小站、开阔岔路、果园和塔前庭必须保留各自空间辨识度；不通过逐房随意换图制造差异，也不把山体放大到压过玩法层。

平原的大面积地形和普通平台沿用正式平原tile set及其细像素、草边和暗部语言；可穿越平台保留已使用的同族木踏板。构图稿的认可只确认其空间关系、体量与明暗层次，不自动授权改成概念稿中的岩层、笔触或新材质。通用tile负责绝大部分重复地形；特殊入口的上下围合、檐口、洞壁与承托体可按整体构图定制绘制，不要求套用已有tile。定制件仍须匹配正式像素尺度、调色及真实净空，并与普通地形自然收口。石材限明确建筑、门槛、墙身和支撑构件，与自然地形有可辨的过渡。连续结构材质突变应按场所恢复正确区域材质，不能为遮盖接缝把整片自然地形换成室内砌体。

静态合屏的素材融合是渲染路线选择的前置：使用正常镜头、角色尺度、真实地形与独立素材检查空间、主次和连接；静止画面尚未成立时先修正素材与组装，不以视差、透视或后期运动的吸引力作为已解决贴图感的证据。

## 生产与复用

房间是构图与体验审查单位，区域套件是共享素材生产单位。普通房使用同族地形、结构、完整独立景深和已验证组合，少数重要地标或特殊入口按职责定制；不默认每房专画一张整景，也不以素材数量替代完整空间。

生图前确定实际引擎的相机、角色尺度、几何与渲染职责。需要独立移动、视差、破坏或镜头露出的部分，应从开始具备完整边界和必要覆盖；静态连贯组画可保留，但其同坐标受光分区不等于完整独立背景。素材与局部几何可共同校准，保留房间职责、能力门、状态身份和连接，并复验动作与恢复；不冻结任意灰盒，也不任意拉伸像素素材。

区域套件需在不同几何与实际镜头运动中验证后，才在对应范围扩展。共享材质／组合问题修共享源，单房构图问题修本房。具体生产、取证和扩展方法由[godot-room-art](../../.agents/skills/godot-room-art/SKILL.md)持有；技术通过、固定机位改善、套件复用与整区视觉认可分别记录。

## 母版与合屏

人物补帧以正式入口当前实际绘制的身体为母版，不能用同角色的旧立绘代替。登记母版资源、实际切片和显示变换；在同一世界尺度、脚底与镜头下并排比较待机、动作进入、关键姿势和退出。除总高度，还核对兜帽体积与宽度、头身比、胸腹宽度、四肢长度、鞋底宽度及像素密度。屈膝、趴地和低头自然降低高度，不能逐姿势拉到同高；头身比例错误须返工原画，不能整体缩放掩盖。正常速度反复切换，出现变瘦、变大、脚底漂移或画法跳变时不得以碰撞、资源或动画状态测试通过替代视觉通过。

先核整房墙体、平台、危险与自然岸地是否属于同一可信场所：承重、围合、分路、落点、失败恢复各有明确用途；关卡边界和内部内容均可按整体构图与玩家体验调整，不把保留动作与房间职责理解成冻结旧轮廓、每块地形或摆放。整房构图须同时核对主体体量与轮廓走势、主体／入口／附属体比例、实际房界填充、墙顶和负空间；修正一个局部后重新审看整房及沿途机位，不能以点名缺陷消失代替整体成立。地标的尺度服从世界设定：巨塔近处以超出画面的连续塔身、厚重基座、入口纵深与人物尺度表达体量，不为展示完整外形而缩成小建筑；远观、塔底和内部共享结构与材质逻辑。室外边界不得读成无出处的悬空洞顶，无用途的黑色凸块应修正空间本身，不能靠贴图掩盖。材质分界服从建筑与自然岸地的真实界面，不沿对象编号换材质；必要的局部几何调整与动作一起复验。

认可构图转入实现时，同时绑定整体构图、正式角色／tile材质参照与固定镜头取景，明确哪些是必须保留的空间关系、哪些只是概念示意。前景宿主、遮挡范围、光源位置与方向、受光／遮阴范围、风和视差归属在拆素材前规划；不能将其留作收尾装饰。先以正式tile与角色完成全房体量和景深，再细化新构件与局部前景、光照、运动；每阶段用相同角色位置、镜头范围和场景状态对照轮廓、地平线、留白、明暗主次及动作可读性。新增细节破坏整体时删减或重作，不能用调暗、透明或额外装饰掩盖。静态对照通过后，用正式入口连续走到主路、分支和出口，再返回；沿途检查行走、跳跃、反冲的遮挡、接地和灯光连续性。局部起点录像仅证明该片段，不能跳过入口连接、上下落差或必经平台后声称通路完整。检查与测试不能代替视觉判断。

先一件适合真实空间用途的母版，核完整边界、alpha、锚点及采样；再在正式镜头、角色、敌人、UI与连续动作下审查。通过黄金样板后扩资产族，并在不同结构的第二空间验证复用。

实际运行像素、正常速度音画和来源记录共同构成审查依据。相关资产／构图／动画由对应专业Skill执行，生产与审查方法见 [内容流程](../project/content_pipeline.md) 和 [质量规则](../project/development.md)。

## 素材与连续动作

先完成同族代表资产的真实空间用途，再制作完整边、角、端头、内部、孔洞和变体。原图像素、显示尺寸与物理碰撞分别核对，不能为贴图改变碰撞或强吸附网格；dual-grid 等实现方式只在实际消费者与语义验证成立时采用。

角色、敌人和机关的进入／持续／退出／中断保持同一身体、重心、脚底及附件关系。大体量Boss优先采用固定分层素材、骨骼／铰点和动作曲线；刚性车体、轮组及巨兽躯干不能靠整图形变或全身缩放模拟连续动作。不同批次的补帧须检查相邻姿势、材质明暗及内部透明孔洞的一致性，数量增加不等于连续；持续动作、一次性动作与轮组／风车等旋转部件分别计时，不把整身预备动作当作高速循环。动作、特效和声音对应真实事件，镜头、危险预告、弹道与落点始终可读。素材保留原图、参考、许可和生成／加工来源；黄金成立后在第二种空间核复用。
