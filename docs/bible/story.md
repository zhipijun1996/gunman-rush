# 固定世界剧情

《失序之钟》以探索失序王国、帮助NPC、恢复地方钟与理解中央钟的责任为主线。钟外小站是可回访社区，任务结果、真实移交的唯一物件和修钟永久保留。具体NPC、任务、行动与结局条件只引用世界源，见 [世界推进](world_progression.md)。

时间主题通过地区美术、动画、BGM、敌人与机关表达，普通世界玩家操作尺度一致。修钟后形成可辨识的声音/画面变化并便利旧路，不抹去挑战和永久结果。

旧“每Run循环最后一天、首通救老师后必须多轮成功”的细案不再是现行推进合同。是否保留循环叙事、院长/老师关系和终局对白仍待 STORY-DESIGN-03 按固定世界条件整合，不能借故事清除进度或新增结局锁。

普通/真结局与16深部记录遵守现行世界条件；齿轮40枚尾声是提案，不锁战力或结局。剧情用玩家能看到的短对话、物件、行为与回访变化表达。Boss招式与对象身份以现行对象规范为准，叙事不擅自替换战斗设计。
