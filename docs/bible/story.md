# 剧情：让最后一天真正结束

王国反复度过灾难发生的最后一天，家园保留记忆与成长，主角逐渐发现循环的代价。统一方向已选定；钟院、具体人物关系、日程与多通结局细案仍为提案，未整体接入游戏。

## 时间与世界

时间在一天内正常向前。午夜最后一声钟响，联网王国回到事故日黎明；钟外小站及已经实际脱离追踪的人和物不被回拨。巨树、冰川、浮岛和发光菌是原有童话地貌，不另引入地区时间魔法。

回返恢复同一批人和物，不复制王国。完成救援的人在小站继续生活，原处留下可解释的空缺；独特物件真实移交后不在原处重复生成。

| 情况 | 回返结果 |
| --- | --- |
| 黎明前已死亡 | 没有可恢复的活人状态 |
| 当天在网内死亡、未脱网 | 下一轮恢复黎明状态，可重新改变当天结局 |
| 脱网后死亡 | 不再受回拨保护 |
| 主角零血 | 玩法结束本局，叙事为致命后果前由回程信标召回 |
| 取消回返后的死亡 | 普通生命继续向前，没有下一次恢复 |

家园通过独立储存、归途与记录保存成长；脱网者外勤需回程安排。救援要完成活人的实际移交，只见面不算完成。死亡、放弃或返家结束冒险，不等于玩家立即遥控世界回拨。

## 事故与人物

钟院希望“大合钟”使各地机器同步，中央联锁却绕过地方制动，引发运输、排水、供暖与动力的连锁事故。应急回返用于重试同一天，控制站保存记录；院长坚持不能取消庆典、废弃主机或承认工程根本不安全，使居民成为不知情的试验对象。

主角与老师的关系以具体照顾、共同生活和未完成的小事建立。老师参与工程并承担责任，救回老师不是掩盖责任；院长的执念是证明这一天能够成功，而非单纯毁灭世界。住民、家园伙伴和地区人物通过短对话、物件、动作与当日困境表达自身目的。

## 多次成功的提案

| 层次 | 玩家解决什么 | 仍留下什么 |
| --- | --- | --- |
| 首通：《归来的人》 | 救出老师、停下眼前危险主机，老师真实回家 | 午夜仍回到同一天，循环未结束 |
| 深层：《未发生的事》 | 取得控制站记录，认识反复伤亡与被否定的止损方案 | 仅保存知识和权限，外界机器仍会复位 |
| 最终：《明天的来信》 | 在最后同一轮通知撤离、恢复地方制动、安全停机并取消回返 | 接受工程与声誉损失，让王国拥有真实明天 |

真正放弃的是危险工程，不是再牺牲朋友。起点前的失去不能靠循环追回，痛苦被忘记不等于没有发生。具体通关次数和人物细案仍可讨论，不将提案当作用户全部定案。

## 地图、成长与呈现

随机地图表达固定更大世界中不同路线、支路与遭遇；地标、灾难源和当日进展保持一致。同一轮生成后不因暂停、剧情或段回退重抽。地图映射不成立时修关卡，不用新时间法则解释。

脱网住民、记录、唯一带回物件及合法永久事实可保留；网内居民、机器和本局临时构筑依各自政策复位。记得一种能力不等于下一局已获授予，叙事不改变资源、奖励或保存规则。

真结局后现实进入第二天。挑战重玩明确为旧日回放，不从回放带出活人或自动重复终局奖励；现实居民通过来信和到访延续故事。最小交付可以只有明确的回放入口与现实家园。
