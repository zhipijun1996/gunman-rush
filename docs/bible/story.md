# 固定世界剧情

主角是由时间齿轮驱动的机器人。外观、苏醒和修复遵循[人物规范](player_mechanics.md)。玩家从 P01 风铃坡起点起身，经田埂和沟谷逐步接触平原居民，前往世界钟心调查地方时序与王国失序的关系。

## 居民与行动

房间、NPC、对白、任务和结局来自[锁定世界内容](../data/world/README.md)。按该包的 `npcs`、`dialogues`、`events`、`quests` 取稳定身份、发生地点、触发条件、首访及重复结果。P08 钟外小镇有装卸员与铃铺主人·禾灯；到镇、读牌和服务各自有身份。迟禾、砧叔、苔婆和阿汐的支线分别有明确线索、收取与交付条件。落到实机时，由[实际房间](../../production/rooms/world)与交互消费者承载，按真实取得的进度验证。

动物居民的轮廓与动作围绕身份、职责和生活环境设计。场景、对话和服务使用一致的角色外观、脚底基线与尺度。时间主题通过地方环境、机关、行动和回访变化表达。

## 世界钟心

结局文案、终端位置和前置条件由锁定包的 `endings` 持有。普通结局《钟声再起》和真结局《把明天还给他们》在 Z08 由玩家明确交互。地方核心、战斗结果、天门及钟师记忆按各结局所列条件分别核对。设计包列出结局，正式游玩覆盖另查[当前状态](../project/current_state.md)。

冻结平原的 P15 风鸣钟、P10 武器匠、旧开场及其对白保存在[原版剧情](https://github.com/zhipijun1996/gunman-rush/blob/f27b46819d2d95e7bad1a8572f85a57d117cfdb9/docs/bible/story.md)。新地图的事件 ID 与房号直接取自当前内容包。
