# 固定世界结构

世界由固定房间与分区组成；稳定 ID、连接和交互位置只在 [世界源](../data/world/README.md) 维护。到过入口不等于深入主体，更不等于能领取全部奖励。世界重排先做区域级图：确定区域的相对体量、主轮廓、邻接、分向接口及首访／回访目的，再在各区域内部安排房间、内部回环与门对，最后施工房内内容。不能先固定旧房坐标，再以细长连接段补出区域关系。区域轮廓是待细化的空间预算，不是要求房间填满的模板；允许岩层、庭院与未开放空间留白。后续房间统一使用同一世界坐标，不能为各区单独缩放后硬拼。

齿轮工城是宽阔的大城市枢纽，街区、上街、地下设施从不同方向接平原、古堡、浮岛、矿井与熔炉；矿井贴近周边地区下缘，以矿层与分段竖井形成地下交汇区，接平原、沼泽、遗迹、城市及熔炉。枢纽同时承担自己的探索与目标，不能只是无收益过路大厅。相邻边界只表示地理相接，通路必须另有明确接口；每个接口注明环境意义、首次阶段、回程和收益，区域级能力标记表示内部接近段的门槛，不在跨房门上凭空检查能力。

地区地图表达真实空间。区域图确定后，再确定房间占地、成对门口接缝与回环。房形可有折角、分层和凹口，不以独立外接矩形加连接线替代连续地理。施工尺寸与地图使用同一空间来源，相机候选按该空间实测。

已施工房间的空间由施工输入中的相连矩形分区并集定义；外轮廓、实体边界和地图轮廓由此派生。房间主体不必整条边贴合；可由短窄廊道、桥颈、门廊或井道衔接，保留地貌留白与分区轮廓。连接段必须有真实宽度、碰撞、可见通路和明确的房间归属，随所属房间进入施工空间；不是跨空白的示意连线。门可以位于折角或连接段边界，不必位于主体外接矩形的最外侧；成对门口仍须在同一世界坐标相接，所有回环闭合，不允许独立测绘坐标或长连接线补偿偏差。地图保留真实尺度及玩家局部位置。分区同时承担可玩的路段、观察/恢复或互动用途，不能为拼接地图添加无用途长廊。镜头按少量玩法区及明确入口交接，不能机械按每个几何转角切区；具体规则归[正式镜头](room_authoring.md#正式镜头)。

## 门与能力环境【已确认】

左右门两侧为连续可步行地面。向上跨房后短暂接管，自动跳至入口侧指定实体地面，真实落地再交还操作；不能越过本房能力阻隔。从上方落入下方房间的上口时，安全实体落脚面位于开口正下方，保留可见下落净空；不得自动横移至远处侧台。向下离开本房的下口是连续地面中的实际空洞，不用多层薄台、托盘或装饰填住。门、入口台与交还控制位置不能被危险、敌人或机关占用。交通以对话式交互触发，抵达不等于休息。

H/W/D/Q 条件属于房内分区路线，通过真实环境实现；普通房门不检查这些能力。入口安全区允许看见地标与未能通过的路线，并可原路退出。道具、剧情、捷径和Boss封场可有真实门条件。奖励、Boss、休息、修钟等绑定所在分区；取得能力不能要求自身能力。

## 回访与修钟【已确认】

世界重排采用“基础跳跃／射击／反冲 → 牧风者授予W贴墙与墙跳 → 森林取得H钩索或地穴取得D二段跳（顺序自由）→ 古堡Q”的成长顺序。早期武器服务和普通枪冰弹属于可选准备，不要求H；平原西路保留反冲主导，东侧将有明确收益的风车支路靠近小站，远田与矿口不再串成首次成长的必经路。能力不是房数配额：前置空间要让玩家用旧动作完成有区别的实践，新动作则打开已见过的高差、回程与另一个地区入口。

森林以W沿树干进入，取得H后探索枝冠和跨腔回环；地穴以W进入、D改变纵向回程，两区主能力不得依赖对方能力。工城早期只开放救匠人与服务街，主轴、矿货与高庭分别随成长多次进入；古堡—工城—矿井—熔炉的不同来向必须有本地收益和回城出口，不能退化为串行地区。

手里剑断绳是可选环境交互：绳索连接可下落平台，命中后永久断开，平台落到预设安全承接位置，形成捷径或收集支路。先展示绳、载台和落点的因果关系；落台不封必经路、不压住唯一退路，死亡／读档重建同一结果。未取得手里剑仍能完成主线与全部必需能力，断绳不作为地区硬锁。它不能代替原有射铃、钩索或统一移动平台行为。

上述顺序先在世界空间候选中校准，正式运行在候选通过后统一迁移，不能将候选奖励与旧运行地形混装。路线验证同时覆盖H先／D先、早期服务短访、无手里剑主线及断绳回访。深度优先探索仅使用已见门和本地可用动作，记录能力变化后重新可达的旧岔路、无收益折返和连续无新选择路段；不以最短路径或虚构趣味评分代替初见试玩。

允许回路和能力解锁后的回访。已开捷径只保留真实地形必要条件，单向控制侧和开启状态必须一致。永久奖励只授予一次。修钟主要改变区域美术、时间现象和BGM，可开放捷径与交通、便利旧路；后续专门挑战保留要求和布局。切换状态不得消除落脚、封退路或丢奖励。

## 镜头与施工

正式镜头模板、镜头区、手动查看、隐藏连接与交接唯一遵循[房间制作规范](room_authoring.md#正式镜头)。施工保持实际空间与镜头展示范围分离，Boss按招式、动作和竞技空间选择固定或有限跟随构图。
