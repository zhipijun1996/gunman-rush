# 固定世界结构

世界由固定房间与分区组成；稳定 ID、连接和交互位置只在 [世界源](../data/world/README.md) 维护。到过入口不等于深入主体，更不等于能领取全部奖励。地区地图表达真实空间：先确定整区轮廓、房间占地、成对门口接缝与回环，再施工房内内容。房形可有折角、分层和凹口，不以独立外接矩形加连接线替代连续地理。施工尺寸与地图使用同一空间来源，相机候选按该空间实测。

已施工房间的空间由施工输入中的相连矩形分区并集定义；外轮廓、实体边界和地图轮廓由此派生。房间主体不必整条边贴合；可由短窄廊道、桥颈、门廊或井道衔接，保留地貌留白与分区轮廓。连接段必须有真实宽度、碰撞、可见通路和明确的房间归属，随所属房间进入施工空间；不是跨空白的示意连线。门可以位于折角或连接段边界，不必位于主体外接矩形的最外侧；成对门口仍须在同一世界坐标相接，所有回环闭合，不允许独立测绘坐标或长连接线补偿偏差。地图保留真实尺度及玩家局部位置。分区同时承担可玩的路段、观察/恢复或互动用途，不能为拼接地图添加无用途长廊。镜头按当前分区及转角过渡，不能只约束整房外接矩形。

## 门与能力环境【已确认】

左右门两侧为连续可步行地面。向上跨房后短暂接管，自动跳至入口侧指定实体地面，真实落地再交还操作；不能越过本房能力阻隔。从上方落入下方房间的上口时，安全实体落脚面位于开口正下方，保留可见下落净空；不得自动横移至远处侧台。向下离开本房的下口是连续地面中的实际空洞，不用多层薄台、托盘或装饰填住。门、入口台与交还控制位置不能被危险、敌人或机关占用。交通以对话式交互触发，抵达不等于休息。

H/W/D/Q 条件属于房内分区路线，通过真实环境实现；普通房门不检查这些能力。入口安全区允许看见地标与未能通过的路线，并可原路退出。道具、剧情、捷径和Boss封场可有真实门条件。奖励、Boss、休息、修钟等绑定所在分区；取得能力不能要求自身能力。

## 回访与修钟【已确认】

允许回路和能力解锁后的回访。已开捷径只保留真实地形必要条件，单向控制侧和开启状态必须一致。永久奖励只授予一次。修钟主要改变区域美术、时间现象和BGM，可开放捷径与交通、便利旧路；后续专门挑战保留要求和布局。切换状态不得消除落脚、封退路或丢奖励。

## 镜头与施工【方向已确认，参数待实测】

普通房采用统一基准视觉尺度，特殊Boss可明确例外。横向稳定跟随并有移动趋势前瞻，小跳不摇镜头；纵向提前显示索点及落点。紧凑决斗用固定构图，大型/多层场地用受战斗区约束的有限移动。L/T形房间分相机区；不只限制整房外接矩形。短反冲不导致反复反向摆镜，前瞻不追枪口。

跨房先确定构图和落脚再交还操作，只显示当前房。安全站立观察需兼容瞄准输入。旧1.95/1.60/1.20仅用于比较，不能当新世界冻结常数。Boss按招式→躲避/攻击动作→竞技空间→镜头→外框与门设计，入口前庭、战场和奖励区分开。

门台、尺寸、相机意图归施工输入，房内地形、敌人及装饰归手工场景；重建不得覆盖场景。动作方法见 [房间制作](room_authoring.md)，状态见 [保存](home_and_save.md)。
