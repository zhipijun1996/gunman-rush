# 攻击与独立资源

## 当前资源

| 资源 | 所有者与行为 |
| --- | --- |
| Health | HealthState／Definition；零血进入终态，恢复当前HP与提高上限分别处理 |
| 动作次数 | ActionResources；基础空中弹药一发，跳跃次数按当前能力；接地／真实命中及已授予能力恢复事件分别处理 |
| 时间能量 | AirFocus与ShotEnergyPolicy；枪械／钩索共用，只有实际空中瞄准慢时消费，接地按真实秒渐回 |
| 共鸣 | CombatEnergyState；合法敌人伤害产能，主动技与装备共用其提交政策 |

基础射击本身不消费或返还时间能量；[永久装备](../data/items.md)可以在满足自身条件时返还，不能延长同次腾空的慢时预算。默认资源Definition是`game/player/resources/demo_ui_01/time_energy_v2.tres`。可重新凝聚的练习靶不提供共鸣或金币，真实命中仍恢复空中动作；其余合法敌人的产能规则不变。成功命中按会话、攻击包、目标和动作收据去重；空中实际伤害可补弹，并恢复已授予的H／D资格。

H合法命中与首次有效W贴墙由TraversalAbility发出一次资源恢复事件，ActionResources补满当前空中弹药上限，已拥有的H／D恢复，WorldRecoilGuard获得Q触发资格但保留剩余冷却。持续停留和同墙射击后的姿态切换不重复补给；事件边界见 [能力合同](../data/abilities.md)。通用H／D恢复接口不补弹或Q，时间能量、共鸣及射击冷却也不受影响。

## 发射事务

校验活动状态、方向、冷却、动作次数和明确资源政策 → 原子消费 → 冷却 → 反冲 → 弹体 → 接受事件。请求失败不改变状态。射击发出即产生反冲，命中不重复施加同次反冲。普通子弹按世界距离限制为正式基准画幅约半屏；从枪口开始累计，最后一帧裁剪到射程终点，不随分辨率、慢时或帧率延长。扩震钟环（B22）按武器类别扩大相应的射程、宽度或伤害半径，具体边界见装备定稿。轻微弹道辅助只选择射程内、无遮挡、当前可接受命中的敌人或机关，不选尸体、已失效机关或墙后的目标；有限角度修正只影响弹道，不篡改玩家输入与反冲方向。基础参数归玩家配置，索心校准环（139）和追迹定标镜（117）的修正规则归装备定稿。

当前武器来自WeaponDefinition及运动Definition；同一时刻只有一个装备家族，其多弹体仍属于同一WeaponRuntime。伤害统一提交 [帧伤害策略](damage_and_respawn.md)，同帧死亡优先于奖励。

## 共鸣蓄力回复

按住回血动作，由[基础回血配置](../../production/config/focus_heal.json)提供基础费用、回复量与蓄力时间。深聚心核（143）改变费用和回复量，疾聚心核（144）缩短蓄力，两者共用一次完成结算。游鸣聚能体（P17）允许在蓄力时按等级移动，暮钟心契（P18）禁用普通治疗。各组合的费用、时间与移动资格见[装备系统第 5.4 节](../data/items.md)。

开始与完成时均检查回血资格和足额共鸣，成功后在同一修订提交扣费、实际回血与消费进度。中断或保存失败保留原资源。普通读档与跨房保留已存共鸣。

蓄力表现消费已经接受的回复状态：身体收臂、微屈膝集气，身体两侧清楚可见的上行气流与收束光丝汇入胸前，脚边光带扩散；亮度、粒子速度和可听集气声随真实进度抬升。以空洞骑士回血的“持续聚集—蓄满释放”可读节奏为参照，保持本项目暖白与淡金色、正式角色尺度和独立动作帧。只有HP与共鸣保存成功才播放舒展补帧、明显向外释放的短光浪与恢复和弦；不闪白全屏，不掩盖落点与攻击预告。取消时迅速收暗、停止集气声，不播放成功反馈；持续回复每次重新起势。集气与恢复音在共享声部池中具有明确优先级，不能因脚步等低优先级声音占满而静默；减少特效设置保留进度与成功辨识。

## 恢复与取消

补射击次数、恢复HP、提高HP上限和补共鸣是不同效果。提高上限不隐式回血，卸下来源只钳制当前值，零血不复活。接地恢复不重置射击冷却。

发射时按攻击包快照记录弹体伤害与装备参数。武器切换保留在途弹体的快照，角色死亡使该会话失效。新世界的永久、休息周期、挑战尝试与动作瞬态边界见 [保存与休息](home_and_save.md)。

武器各分支设计从 [动作入口](../data/player_actions.md) 按需读取；实际数值以配置、Definition与Runtime为准。代码与验证见 [模块导航](../project/module_map.md)。
