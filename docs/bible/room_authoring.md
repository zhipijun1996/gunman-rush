# 房间与 Section 制作

以 room_id/section_id、来向、能力、永久状态与周期定位，按 [世界结构](world_structure.md) 制作。整区先完成真实空间总图及门口接缝，再安排每房职责与沿途节奏，用相连代表内容校准，按连通片区完成全区；普通手感以实际控制器为准。执行方法见 [多能力关卡设计 Skill](../../.agents/skills/godot-recoil-level-design/SKILL.md)，现行规则仍由本页、区域圣经和对象规范持有。

## 职责与动作

以连续玩家体验决定内容取舍，而不是按问题截图或对象数量验收。每处可达空间都应承担观察、操作、战斗、探索、恢复或叙事中的明确作用；安静与留白也需要用途，无用途则收短或并入环境实体。每房先明确主要用途、首访与回访的来向能力、可观察的玩家决定、完成后的收益或下一步机会，以及失败实际去向。沿用当前世界的身份、连接、能力门和奖励引用；全区职责表覆盖主线、支路、枢纽、休息、剧情、Boss与回环，避免把所有房间都做成同一种挑战。整区审核图将每房的一行主要职责直接写在房形内，并标明首访推进、能力取得后归途、探索支路、收集要素及资格、Boss、休息点、NPC、修钟、捷径开启侧与外区去向。可分层查看路线与要素，但不能只交付无内容的轮廓；连接变更明确区分现行关系与待审提案，说明收益、代价及受影响的来向。

每个新增平台必须改变射线、落点、时机、路线选择或失败恢复中的至少一项。移除后不改变玩家决定的孤立平台直接删除；同一动作重复铺台不能充当内容。大空间先按玩法分区，未使用部分收短或并入有根基的墙体，不以堆怪、撒刺或浮台数量掩盖空旷。观察和喘息是有效用途，但必须对应看得见的下一段局面；优先比较玩家连续经过这一段时做了哪些不同决定。

平原以反冲主导；后续区域按各自圣经确定主要动作与协同能力。各入口记录实际已授予能力、最低通行组合与允许替代，不按区域顺序假定玩家拥有全部前置。组合动作应改变下一动作的起点、目标、射线、时机、资源或落点；正式能力锁、动作练习和高效路线分别设计。回访可因新能力更轻松或出现近路，仍需保留的世界门槛按当前源验证。能力行为与参数归 [能力规范](../data/abilities.md)，组合方法见 Skill，不逐区域复制技能流程。

承担反冲通行的环节，必须让反冲实际解决跨距、高差、换向、落点或机关状态与位置的关系。普通动作和恢复路线不能直接绕过该环节；验证须包含满跳、晚起跳、土狼时间、移动台极端相位和各实际可站立边缘，不能只删除既定回放中的一枪就判定不可替代；能够完成同一目标的本阶段合理反冲或组合解法可以保留，不以枪数、轨迹检查点或固定操作顺序开门。普通战斗允许站射、走位和绕行，反冲提供后撤、越敌换边、争取制高点或命中续枪的实际价值。

短教学可只处理一个判断；进阶内容让前一步的落点、射向、目标、资源或机关状态改变下一步。多一个坑、多打一枪或换一组坐标并不自动产生新体验。射击与反冲组合时，让真实弹丸命中改变门、承载或障碍，同时让同一枪的位移取得通行窗口；通过目标位置、遮挡、跨距和时间建立关系，不以隐藏的“必须在空中”标签判定动作。限时窗口按真实控制器校准，提供可读倒计时、失败重试和完成后的稳定落脚。先安排观察、动作、落点、后续机会与恢复，再决定房间体量；扩大房间应增加有用的关系，而不是空跑或失败返程。

恢复可采用就地重组、回到当前挑战或分步动作。所有实际可跌落的坑底、夹层、岸侧和承载下方都必须有当前能力可完成的恢复路线；无法提供时，制作可预读的危险并复用正式地形失败返回。不能保留安全但爬不出的死坑，也不以无提示高度扣血补救。枚举低层、台阶、梁顶、运动台端点和不同来向，检查它们是否成为无意的前进旁路。必需的命中回枪目标须考虑已击败、命中后失误、漏枪落地和重入；本阶段可取得的目标仍须能重试或通过保留主要动作价值的替代路线抵达，能退回入口只证明没有软锁。用可见地形与正式重试规则解决资源，检查重试成本，不由房间脚本偷偷补怪、补弹或重置机关。

## 空间与通行

可行走地形采用水平地面、垂直墙面、台阶和承载平台，不制作可行走斜坡。高差通过这些构件及既定动作能力组织；草坡、河岸等地貌名称按此碰撞规则制作，装饰轮廓保持可读，不暗示不存在的斜面通行。

整区轮廓先在无文字、无路线覆盖的剪影中检查地域主次、空间比例和虚实关系，再加入职责与要素。纯剪影仅辅助检查整体，最终审图以保留房间分界的完整地区图为准，不把整个地区塑造成一个夸张的单体造型。房间以清楚、规整的横廊、竖井和大厅为基底，结合必要的高差、转角或侧室打破纯矩形；不为每间房追求独特外形，不在四边反复添加凸包、凹口、阶梯齿或长曲线。整体变化主要来自长宽比例、方向、错层排列和大小空间的组合；同一条街、井道或岩层保留连贯的尺度与轴线。复杂挑战可在房内用墙、平台和障碍分区，不必把每一段玩法都投射成外轮廓的起伏。自然边缘的局部变化服从地貌，建筑保留承重直边，二者都保持克制。

参考用户提供的《空洞骑士》整图时，先观察主体房间的规整程度、尺度差异、层次和留白，再考虑局部自然边缘；不把“非矩形”理解成“不规则越多越好”。重新设计不受旧矩形包络限制，也不统一缩边后用细管串起每房。普通相邻空间直接接续，门洞、井口或岩颈按实际用途收窄；连接和标注检查不代替整体观感审查。

枢纽的多出口应在一次安全观察中读出不同去向，入口、地标、材质、声音与回访机会共同引导；推荐主线不等于封死其它可探索出口。能力锁的预览要指向真实后续路线，并留下可记忆地标和安全退路；地图只记录玩家实际发现的信息。获得能力后，通过首次安全运用和返回熟悉枢纽，让旧锁与新能力建立联系，再呈现多条自愿路线。普通捷径的胜利锁不能误标为能力锁，方向文案须区分区域目标方位与当前房间的实际出门方向。

场所有真实体量、宿主、支撑和连通关系。房间门台、分区、连接与封口使用实际身体包络、速度、冷却、资源及机关相位验证；几何连线不代表角色能通过。主路只使用已合法授予的能力，敌人死亡或离开后仍有符合设计的通行／返回方案。

利用房间的横向、纵向与前后可读关系组织主路、挑战、探索和返回。用墙体、岩层、障碍、桥面与桥下空间分割区域，形成错层通路、绕行、局部回环或相互可见的目标；不能在大房里只铺一条台阶线，把其余空间留空。短平台必须承担换射向、接续、遭遇或观察的具体职责；不以密集悬空梯子填补高度差。优先用连续岸台、实体廊道、少量承载和有支撑的梁架组织路线，删去重复的免费落点，并验证保留路线的难度与来向。空间利用不等于填满平台，留白须承担看见目标、辨路、观察机关、战斗周转或环境叙事。开阔区域结合既定连接提供可辨认的路线与出口选择，让玩家比较方向、风险和收益；短教学、休息等单一用途仍按自身职责安排，不为凑分支增加无意义出口。

房间边界的实地与普通底面是安全地带；只有明确制作、可读的尖刺、毒雾、深坑等危险可以造成伤害，不能按房间底部高度统一扣血。门口以墙面缺口表达，不绘制黄色框。左右入场可见地步行约一个身体宽度；上行入场短跳到开口旁最近的实体落脚面；从上方落入下方房间的上口时可见地直落至开口正下方的安全落脚面，不以自动横向驾驶补偿偏置落台。上方入口的接收台可以是实体平台或可穿越平台；可穿越平台必须稳定接住落入的角色，单独下推只查看，按“下方向＋跳跃”才主动下穿。动作由PlayerMotor执行。落地后才恢复控制，不自动跨越房内挑战。下行出口以连续地形中的适度缺口表达，宽度由身体包络、下落与来向验证确定；出洞后的落脚并入周边地形，洞内保持净空，不为接门堆叠薄台、长板或扩大成无意义凹槽。

室内外连接在实际开口处表现建筑外缘、洞口/井缘、遮檐、材质和光色过渡；室外走入室内前应能看出正在进入哪一种结构，室内返回可见来向的外光。装饰石门不冒充通路，门洞表现不遮挡真实身体净空，也不改变门的状态所有者。同一可见出口对应一条明确通路，门台间保留辨识和落脚空间。未施工连接只保留数据身份，当前场景使用连续实体边界，不画作拥挤的假出口。探索地图按已施工房间的实际空间和成对门口对齐，共享接缝开口，形成连续地区；保留局部玩家位置，不以孤立矩形和长连接线替代空间连接。宏观拓扑不是碰撞数据，施工须落实相邻边界、通路和回环，不通过改成示意图绕过接缝约束。房间可走空间不能无意重叠，来向与门口方向必须一致。

Boss战斗区保留外侧整备、内部战场和奖励区；完整入场才封门，胜利开门。房间制作不改变角色物理、武器、资源及保存规则；实际碰撞、展示空间、玩家触发区和相机中心范围分别声明，不能互相代用。

## 正式镜头

正式入口只由WorldCamera拥有镜头。采用《空洞骑士》式稳定跟随、镜头区构图和动作响应的方法，不声称复刻其引擎算法；[Team Cherry实景](https://www.teamcherry.com.au/blog/the-forgotten-crossroads-a-hollow-knight-tour)用于构图参考。参数归config/world/player.json的camera，房间配置归construction.json的camera；不保留另一组场景兴趣点或几何自动选框规则。

- 四个模板为双轴范围跟随、横向跟随（限制普通Y）、纵向跟随（限制普通X）、固定场地。固定构图放不下必要活动空间时使用有限跟随。基础缩放统一，特殊场景显式配置，不按房间尺寸自动缩放。Boss入场、战斗及离场均保持探索缩放，只缓慢平移到战场边界约束下的构图。左右展示边界直接取战场墙/封门的坐标，不添加水平外扩；镜头到左端时画面左边贴左墙，到右端时右边贴右墙，前瞻和震动也不能显示墙外。与大房间相同，中心范围按实际视口半宽内缩得出。小场地固定，放不下一屏的场地有限跟随，不能为容纳全场而拉远；仅上下保留明确配置的构图余量。验收必须独立对照实际墙位检查两端，不能只检查画面落在相机自己声明的范围内。
- 每帧只有一条流程：玩家位置/已提交通路状态选择区或显式演出接管 → 生成包含观察方向前瞻、动作补偿、手动查看的唯一目标 → 横纵分轴平滑 → 统一约束展示边界与玩家可见范围 → 安全范围内叠加震动。门口与引导约束在目标/合法范围内计算，不在末尾改坐标。演出使用持有者令牌，结束平滑归还；震动不回写基础状态。
- 观察方向取最近明确移动意图，停止保持，与瞄准和枪口分离。单次反冲和受击不翻转；持续实际位移达到确认时间后逐渐改向。明确高速动作可增加有限速度补偿，结束平滑退出。前瞻按可见宽度配置，在稳定跟随基点之外叠加，不能被死区吞掉。
- 纵向自由度由区配置；基础跟随与房间构图负责高低差和落点预读。跳跃观察只在基础构图上叠加微小偏移：地面略偏上，上升逐步归零，顶点无额外偏置，下落略偏下，落地柔和回到略偏上。幅度按可见高度设置并封顶，不能拿房间构图偏置当动作摆幅，不能在起落时切换跟随锚点或强制角色居中。Boss及已设计的下降段构图优先；不额外弹跳或震动。小动作保持稳定，持续上升继续跟随；快速下落保留追赶迟滞。不为每种能力创建镜头模式。验收必须以实际控制器连续检查原地跳、跳上高台、走落低台/连续下降及各自落地，不能仅用原地短跳通过代替体验。
- 手动查看复用左摇杆上下（键鼠W/S或↑/↓），是有冲突即让出的低优先级意图，不新增按钮，见[操作合同](controls_contract.md)。稳定站立并持续按住，短延迟后平滑上下偏移；松开、明显移动、跳跃或攻击取消，回到当前基础构图。查看距离按可见高度，玩家仍安全可见。普通Y锁与查看许可独立；每区分别设上看/下看与合法范围，Boss/演出可禁用。查看不改变区归属，不越界揭露秘密。
- 区只按玩法设置少量，普通房有稳定默认值；不能把房形分解条带或每次转角直接当区。区声明触发范围、展示范围、构图锚点、普通中心移动范围、优先级、迟滞及连接。重叠区的交接由玩家进入明确过渡带触发，支持双向返回、中途掉头；视口宽高比和缩放参与范围计算。某轴不足一屏时固定该轴，以现有墙体/背景补足画面，不产生反向夹限。
- 隐藏连接沿世界/机关所有者查询开启状态。未开启保持主区构图，并以必要的环境遮挡保护内部，前瞻、查看、震动都不能泄露。开启仅改变连接资格，不拉镜头、不永久合并两区。玩家进入过渡带才逐渐解除旧区出口侧限制，在合法局部展示范围内连续交接；不能先夹到新区再平滑或被旧边界拉回。返回恢复主区，开启/发现按正式保存规则持久化，临时交接/查看/接管状态不保存。跨场景或无法连续展示时显式遮挡切换。
- 出入口所在方向在临近门口构图中贴画面边缘；垂直轴不足一屏用连续岩壁/建筑体量填充，不能露出地图空白。普通探索靠镜头区，兴趣点仅可用于明确设计的演出引导。切房、重生、地形失败返回清除前瞻、查看、追赶、震动与平滑速度，需要跳变时在遮挡期间重定位。

验收以动作前实际画面、动作中的稳定和失败后继续行动为准，包含全部偏移。覆盖平路转向/反向射击、连续反冲、高速钩索、竖井下落、三设备查看与取消、区/门往返、小房/L转角、隐藏开启/进入/掉头/返回/读档、Boss和重生；有限夹具与实体设备结论分开。角色物理与关卡布局不能为镜头问题作补偿修改。

## 探索与压力

地标、岔路、观察点、捷径与回环共同建立探索节奏。动作、空间、机制、探索决策和视觉变化分别比较；同一种动作换坐标或名字不算内容差异。主路覆盖当前合法构筑和学习，进阶／大师内容自愿进入，有相称收益、恢复与返程。

有探索收集物的房间，先设计发现、接近、取得和返回的完整路线，再放置奖励。根据该收集物的职责选用下列形式，可以组合，但不把每件奖励都套成同一题：

- **困难挑战**：当前能力可完成、有相称收益的自愿挑战；成功到达收集侧后有单向捷径接回主路线，避免原样重跑困难段。捷径从主路一侧不能提前反向绕过挑战，失败恢复仍须能重新尝试。
- **能力锁预览**：首访能看到收集目标及阻隔，从地形、机关或一致的能力线索理解以后可以回来；可安全退出。回访使用已合法取得的能力完成真实通路，不能只靠文字声称锁住，也不把尚无能力的预览误记为当期挑战失败。
- **隐蔽入口**：利用墙隙、遮挡、地貌差异、声音或构图提供可发现的线索；入口后的空间与奖励有实际内容和可靠返程，避免无提示盲撞墙或不可读跳入深坑。

逐房沿现有奖励与状态身份记录所选形式、发现位置、挑战或能力条件、失败去向及回主路的出口。奖励位置、捷径开通和领取状态沿正式所有者处理，获得后及重入时的通路与表现保持一致；不另建奖励或捷径状态副本。

每条完整探索或推进路线都应有环境带来的操作与选择，不能仅由走路和连续跳台组成。结合怪物、短平台、机关、墙体与障碍建立关系，例如墙体改变射线和接近角度，短落点影响反冲后的站位，齿轮扫过改变离台时机，地刺分割可落脚面，墙刺限制空中横移与贴墙停留，实体障碍改变跳跃净空，敌人迫使玩家选择清理、换层或绕行。刺床贴合真实支撑面，朝向与危险面一致；连续刺段使用端头与中段拼接，保留完整刺尖、连续根部和真实危险边界，不裁装饰簇底部充当地刺；沿动作选择局部刺段与可穿行间隔，不按面积铺满，也不把恢复点设在危险包络内。危险必须在正常镜头下可预读，留下等待位、可用落点和失败后的重试路径；伤害判定与可见轮廓一致。按路线职责组合，不要求每一小段堆齐全部元素；短教学和观察、交谈、休息空间保留必要安静。检查各分区如何互相影响，避免把地形、怪物和机关各自孤立摆放。

平台动作、战斗、时机与容错分别观察。P／C／T／R候选标签用于筛选，不机械相加为难度。复杂连续障碍段优先保证读地形和执行动作；普通穿越、宽落点和探索通道主动考虑轻遭遇。敌人应使玩家改变瞄准、接近、攻击时机、换位或落点，数量由同时激活的实际威胁决定，不按面积填怪。

复杂战斗保留退路和可读落点。专注跳跃的段落可把遭遇放在准备区、稳定中继或完成后的宽地，邻段追击与弹丸不能无意覆盖精密操作和重试点。专门的战斗跳跃组合须先让玩家理解各元素，再验证组合和恢复。NPC、休息、辨路与首次机关观察保留必要安静；沿路线交替安排轻战斗、探索、观察与紧张挑战，不固定第几房间必出商店或Boss。

## 验证与复用

安全庭院、错层踏桥、反冲升井、周期穿越、折返下降、移动接续、环形分支、Boss整备入口是可复用动作主题，不是固定八模块配额。使用当前身体包络、普通跳与各射向反冲、冷却、接地/命中回枪和该阶段能力校准几何，不改变基础物理来迁就房间。

先用真实Motor验证房内动作、命中、承载、目标和恢复，再按正式入口验证相邻房、不同来向、能力回访、清怪/休息/死亡/重启后的连续路线。反冲关键环节检查关闭反冲、机关已开、从低层前进和省略后续动作等相关反例；多能力段验证真实切换、取消、资格恢复与保护对象，不相加单项最大距离。普通战斗与舒缓房按各自职责判断。有限回放只证明其覆盖，图可达和三个样房通过不能代替整区完成。

在正常速度与统一镜头下审看线索、决定、反馈、相邻内容差异及失败成本。具体检查按风险选择，长期规则回归正文，参数留实际配置，进度和一次交接沿项目约定维护。
