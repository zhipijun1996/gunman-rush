# D068 平原实体辨识与移动舒适度

用户反馈覆盖此前冲突的候选数值。平原仍是一跳、两次空中射击；未来可解锁多跳，但第二跳应低于第一跳。没有新增平原二跳奖励，也没有把视频观感当作《空洞骑士》官方参数。

## 控制与地图一起校准

普通移动上限试调300→260世界px/s（约降低13.3%）。触屏保留慢走/跑步两档与防抖，默认慢走为上限的0.55；普通移动加减速保持灵敏，不能用增加滑行距离换取变慢。相机舒适算法、空中慢时0.20、反冲速度和次数保持。参数唯一来源仍是config/player_tuning.json和config/input_profile.json。

未来第二跳的起跳速度试调为首跳的90%；实际Motor测得首跳150.366px、二跳新增126.544px（总高度276.910px），而不是声称“速度九成等于高度九成”。平原max_jumps=1不变，多跳仅显式开发配置/后续能力可用。后续能力授予关卡仍待具体设计。

关卡门槛必须根据降低速度后的实际轨迹重验。正式反冲升阶从260降至190px，接收台从210加宽到260px；仍通过无枪负例确认一跳不能直接登台。不能只测一个完美开枪帧：覆盖起跳后多个发射时机、向下瞄准角度偏差和镜像。模块几何变化提高definition_version，生成正式版本更新为plains-run-v6-grounded-comfort；旧记录不能在未告知情况下套用新碰撞。

## 平台与大地的视觉语义

是否能从下方穿过由one_way_platform_indices决定，不能根据图片厚薄猜测。薄木栅板表现单向可穿平台；连地石灰岩表现全实体。D071补充：无法安全落地的实体台与移动台用有厚底梁、封闭端板和铜铆钉的木制机械台表现，不能从底部或侧面穿过；不能仅凭“木材”判断单向，需看薄板与加框台区别。显示必须从实际碰撞标志派生，不为美术一致性偷偷改变碰撞。

所有有安全支撑空间的草岩实体地面（包括30px薄实体）向关卡底部延续为真正有碰撞的大地。保留显式单向空中薄板；地柱不得填平挑战缺口、挡住其他模块的下层通道、掩埋危险或阻挡移动平台/锯轮包络。v2在相邻同层端口处合并地基，避免旧版40px模块重叠区形成竖缝；有下层站立面或移动台的其他模块仍保护整个world_bounds及其跳跃/反冲空域。无法安全接地的平台明确改成机械木台，不用悬空石块掩盖问题。石台及地基使用同一世界坐标岩纹，扩大岩层纹理尺度，不按每块矩形重新铺图。同高相接石台的内部端头改连续middle，重叠部分草缘只绘制一次；地面表面只保留草叶及站立线下14px渐隐草根岩缘，不再整块40px石砖图覆盖岩壁。这些接缝字段只用于绘制，不改变任何碰撞或manifest。表现和碰撞使用同一组矩形，完整记录ground_support_version及ground_supports到manifest并校验，不能用无碰撞的岩石图片误导玩家。

近处装饰恢复自然颜色，背景继续保留距离雾和分层视差。荆棘需要连续而有变化的轮廓，按危险矩形裁切，不因新外观扩大伤害范围。出口保持真正的门，不能用房型箭头路牌冒充；提示、确认、奖励和切关契约不变。新增视觉只是候选，手机审美与危险辨识由用户试玩验收。

## 验收

- A100：单向/全实体/移动平台的视觉分类来自真实碰撞属性，站立线清楚；近处装饰不再整体灰化；荆棘覆盖窄/宽危险区，门风格与平原协调。实际截图与用户认可分开记录。
- A101：实体地柱有真实物理查询命中；不封住缺口、下层房间或机关包络；同Seed/manifest重放一致，篡改地柱或缺失版本必须失败。正式完整路线在安装地柱后无损通行。
- A102：260速度下触屏档位/停下/反向正确；首跳与未来二跳实际升程符合预期，平原空中第二次请求仍无效；真实模块库、完整路线和弱能力回归通过。反冲台多时机/角度/镜像通过且无枪不能到达。测试失败非零，真机手感不由自动化替代。

技术结果、具体最终几何、失败修复与公开试玩版本见[交接](handoff.md)。本轮不新增地区、能力解锁或改奖励规则。
