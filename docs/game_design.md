# 游戏设计

## 定位

原创横版精确平台跑酷，面向 Android 横屏。移动、二段跳、射击反冲构成核心；空中补充点延长动作链。参考精密机关挑战的节奏，不复制角色、场景或音乐。

## 已确定

左右模拟移动；上下特殊交互；重力；独立跳跃按钮；右摇杆拖动瞄准松手开枪。射击不需要命中即可反冲。二段跳和射击资源相互独立。默认两次空中射击；有效落地恢复。死亡回检查点，清空残留输入。

## 循环

第一版：观察 → 尝试动作链 → 死亡快速重试 → 到达终点。后期：选择路线与强化 → 完成本局 → 失败重开或结算。程序生成不自动等于肉鸽。

## 范围

先固定灰盒，再触屏与固定挑战，再模块化随机，最后肉鸽循环。初期不做墙跳、装备交易、联网、账号、排行榜或付费。未来武器、能力、机关、素材与地图持续扩展；若增加实际交易系统，需另立需求，当前不预建商城。

## 待试玩

反冲叠加与部分重定向、三指布局、挑战时长、移动目标速度、视觉与音乐风格。不得用待试玩项推翻已确定输入。

## 风格与长期扩展

[整体美术与操作风格](visual_and_gamefeel.md) 是用户确定的苦痛之路参考方向。能力可增减、次数可配置；地图组件独立；敌人/Boss 与玩家通过通用 Actor/战斗契约解耦，详见架构。
