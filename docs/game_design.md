# 游戏设计

本版整合用户新增动作肉鸽设计，替代旧的纯跑酷定位、正式玩法机关即死回检查点和整场景重置规则。实现进度与正式规格分开记录，见[任务](tasks.md)与[交接](handoff.md)。

## 定位与平台

原创2D横版动作肉鸽：精确平台跳跃、松手射击与反冲移动、敌人与Boss战斗、分支路线、局内道具流派、死亡后家园永久成长。整体美术与操作气质参考《空洞骑士》苦痛之路，人物、场景、音乐与素材原创。

继续Godot Standard + 类型化GDScript；Android横屏与未来Windows/Steam共用玩家、能力、世界、战斗与运行逻辑。手机双杆与独立跳跃键、键鼠释放射击、手柄有效右杆回中射击不变；统一Router、唯一Motor位移入口、可启停能力与0/N动作资源不变。Linux/macOS/Steam Deck后续独立验证，开发不依赖Steam账号或SDK。

## 人物、枪支与独立资源

人物具有当前/最大血量、精力、枪支与能力/动作资源。不同CharacterDefinition可配置基础属性、初始能力和武器；具体人物数量与数值待定。Health、Stamina、ActionResources独立，精力不默认消耗在移动、跳跃或射击上，也不替代空中射击次数。

正式精力用途待决策。已有AirFocusAbility耗精力慢时与金黄遮罩是此前授权的原型实验，保留其代码与试玩基线；它不自动成为正式角色的资源政策。已提取独立Stamina接口，后续由明确能力策略绑定正式用途，不把原型参数100/45/30锁成正式平衡。

武器由WeaponDefinition与行为组件改变冷却/射速、弹体、伤害、反冲、散布和资源消耗。保留有效按下后释放才开枪；提高射速只缩短可配置冷却，不意味着自动连射。其他武器的发射方式待决策。

## 一局与路线

一局包含多个大关，总数待定；每大关一个主题，正式每大关10小关，1–9推进、10固定Boss。小关地图随机，含平台、机关、敌人、补给和挑战段；模块大小不统一，允许一块平台的微模块与精心设计的连续大挑战段混用，端口支持多个入口/出口、左右镜像，直接贴合，不在地图中显示模块边界或绿色连接段；整关可横向、纵向、方形或其他空间拓扑，主题、类型和外形独立。出口数量可配置，当前默认非终点小关提供两个出口，未来允许多出口；展示下一关类型图标/名称，选中只切换一次；主题和类型分离（例如火山金币关、冰川道具关）。第9关所有出口均指向第10关Boss（当前默认两个）是暂定呈现策略，不允许正式路线跳过Boss。

至少定义普通战斗、商店、金币奖励、血量奖励、道具奖励、Boss六类；事件、精英、休息、挑战后续扩展。道具关完成后给两个候选，只能领取一个；血量恢复与最大血量提升分开，血量关采用哪一种或两种并存待定。商店预留购买/价格/库存/交易去重，内容与刷新待定。详见[运行路线](run_and_routes.md)与[奖励构筑](rewards_and_builds.md)。

## 战斗、段内回退与死亡

怪物伤害扣血、留在当前位置、给予可配置短时怪物受击无敌；击退是否开启待定。环境伤害扣血，仍存活则返回当前挑战段安全起点，清运动/反冲/残留输入与旧请求；这是本局内回退。任何已结算伤害使血量归零，优先结束本局、取消延迟事件/未结算奖励并返回家园，不执行环境回退。

每小关可有多个挑战段。段起点、小关入口、家园、持久存储点分别建模。回退不全场景reset、不重置已领取奖励或商店库存。边界暂定策略见[伤害规格](damage_and_respawn.md)和[决策](decisions.md)。新固定demo已接入两类伤害/段回退/零血终局；旧即时死亡灰盒独立保留为LEGACY测试模式，不作为正式伤害验收。

## Boss与家园

每大关最终Boss死亡必产一个金道具，结算一次；双方同帧死亡暂定玩家失败优先、无Boss奖励，按帧事务而非回调顺序裁定。首版Boss核心战斗区与必要躲避空间固定，入口/装饰/验证外围随机；战斗平台与危险机关只从匹配攻击模式的模板选择，详见[Boss规格](enemies_and_bosses.md)。

死亡清局内临时构筑，保留永久进度；家园有基础升级、简单剧情/互动、下一局入口与可扩展解锁。RunState与MetaProgression分离，RunPolicy定义保留/结算范围；局内金币和永久货币独立，兑换、带回家规则与永久升级货币待定。详见[家园存档](home_and_save.md)。

## 分阶段范围

当前已分阶段接入固定demo的血量/巡逻敌人/两类伤害/段回退/死亡、补给/可撤销构筑/二选一/最小商店、3关开发链/Boss/金奖励/家园入口。正式10关固定试炼已接入；用户确认初验后开始模块/空间/难度设计，运行生成和详细真机验证按任务分别推进，再增加主题、人物、武器、道具、永久成长与剧情；最小内存家园不代表持久存档或永久经济已完成。3关不是正式规则。联网、账号、排行榜、付费与商店发布不在本轮范围。

跳跳乐参考采用原创模块组合：预告→短挑战→安全落点→组合挑战，射击反冲保留核心地位。具体模块、空间/相机与难度候选分别见[生成契约](procedural_generation.md)、[模块蓝图](platforming_modules.md)、[难度曲线](difficulty_profiles.md)，不自动采用原作独有动作或原地图。
