本次用户最新要求覆盖 D054–D074 的正式八关/第八 Boss/出口结算。默认家园出门进入一张地图，通道之间不卸载、不切换 stage；八关生成器、房间语法和所有历史危险回归保留在 `start_plains_regression`，菜单旧八关标 DEVELOPMENT。六地区为计划，实际消费者仅平原。

基线检查：2026-10-11 fetch 后 main=ab51fca；PR41/42/43 OPEN，最新 feature/plains-room-grammar=733b21a 依次包含修复。新分支 feature/plains-connected-region 从 733b21a 建立，初始工作区干净；未合并/覆盖其他分支，也不自动合并本 PR。

正式 RunProfile=formal_plains_region v1，单一 world stage，Boss 在同一张地图；内部 boss_stage=1 是 world 容器身份，不能解释成必须过一关才能见 Boss。正式完成只在牧风者死亡并接受金色奖励后 biome_complete。结算明示“大能力选择→下一地区选择”尚未实现，未发能力，安全回 Home，不计全游戏胜利。原 formal_eight 只能从显式回归消费者使用，formal_build 校验拒绝。

生成顺序：独立 region_topology 流生成连接→三层空间/真实端口→开放/反侧机关→局部挑战组合→地区预算内位置奖励→独立内容布置→验证。三个骨架 woven_layers（交错竖向连接）、linked_rings（地表串联/地下连续环/高处间断）、crossroads（外层连通/地表间断/多个竖向交汇）改变实际可用行程。随机 20 或 23 个区域节点，固定样板 12；节点为路口/营地/教学/挑战奖励/Boss，不是八个房间拼接。连接有有向规则与动作资源/安全落点端口记录。四次有界重试，完整23节点、含全部奖励与深层挑战的已验证地图为保底；保底不退化成直线。

物理模块复用现有 meadow_gap、recoil_span、gear_glade、顺序/计时风铃、两层渡台/移动齿轮、recoil_step 和固定 Boss 核心。新增真实多端口平台路口、每100世界单位上升的交错单向阶梯和反侧开启实体横闸。普通连接分别验证上行/下行，单向深层挑战从另一节点撤离，不能把单向落差当作双向通路。所有输入由原 Controller/Motor 消费，未改 player_tuning、玩家碰撞或精力规则。

奖励在地图宝箱处领取（普通金币/有限心补给接触领取）。地区普通金币24、三处一次性1HP补给、两处中级宝箱（普通二选一+8金币）、一处高级（紫色二选一+18）、一处地区顶级（金色二选一+30）；高级/顶级只在可选渡台→反冲登高终点，下降出口指向下一熟悉区域。固定样板用于连接验收，只含中级箱；正式随机地图含完整预算。新增紫/金伤害或最大血量道具复用 Modifier，不增加跳数/空中弹数/反冲速度。地图增长不增加强道具名额。风险记录包含探索、平台、时序、资源和返程，不按直线距离定档。

实例 ID 由地区/区域/通道/奖励角色组成，与访问顺序无关。PlainsRegionState 为局内已领取、已开启、访问、敌人、模块时钟的实例账本；永久音符仍经原 MetaSaveService。整张地图在一次探索中保持实例；段回退不生成新地图。JSON 地区快照用于场景卸载/重建，不等同“退出游戏自动续跑”的新永久存档功能。商店由原 ShopService 账本保持有限库存，奖励由原 RewardService 与钱包收据保持幂等。伤害批次先于交互，死亡取消领取/结算。

行程不是入口菜单选项：可以尽早沿可用路径找金色 Boss 接近标记；可以绕中部/地下环路取普通奖励、找营地；可以随时改走高处组合挑战。营地不是强制关卡。分岔、营地、反侧捷径、深层宝箱及单向撤离都有场景标记，暂停/帮助仍可使用。

验证与实际失败修正记录在交接和 evidence/plains_connected_region。设备手感、Windows/手机/实体手柄仍须用户试玩；headless 轨迹不代替真人趣味性或美术验收。


短教学、12节点样板均有真实往返验证；正式地图及23节点保底完成全连接正反巡游、两条高难挑战及不同节点撤离。自动选择骨架必须与指定骨架回放消耗相同随机流；原“指定骨架通过、默认一直保底”的失败已被默认入口20/23节点断言、50个自动骨架种子及Web控制台校验捕获并修正。地图 Manifest 记录实际模块定义版本/加载后物理数据指纹、相位、玩家参数源哈希、随机流命名与消耗位置、机关/连接/内容/预算受限掉落/奖励；重签名虚假连接、移除地形或篡改奖励仍被拒绝。

[三类实际生成图](figures/plains_region_topologies.svg)由已保存的Manifest绘制，仅用于审查连接；通行证据来自连续Motor轨迹。物理数据指纹不读取导出时被重映射的.tres源文件，原生与Web可重放。固定种子快速到Boss整备约32–49秒、中部成长约72–84秒，不含战斗与观察耗时；全连接双向巡游约7–9分钟，不作为正常通关时长。
