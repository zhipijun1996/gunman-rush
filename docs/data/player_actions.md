# 动作与武器概览

## 动作合同

基础空中弹药、射击、慢时与共鸣分别由 [攻击资源](../bible/combat_and_recharge.md) 维护：射击不耗时间能量，空中枪械与钩索瞄准慢时共用 AirFocus。移动与碰撞遵守 [人物物理](../bible/player_mechanics.md)，操作映射只见 [输入合同](../bible/controls_contract.md)。

钩索360°瞄准发射，合法命中后的拉近、踢跳及有限离开保护只覆盖该目标身体接触；其他怪物、敌弹和环境照常结算。H/W/D 只恢复已授予资格，具体行为见 [能力](abilities.md)。

## 武器与能力

同一时刻使用一种武器家族及当前分支；Lv.3 普攻保持 Lv.2 行为，增加独立技能。攻击、位移、控刃、爆发和视听效果统一见 [武器](weapons.md)，避免多个专题页重复定义。

H/W/D 是独立永久移动能力，Q保护见能力规范，正式授予沿 [运行路线](../bible/world_progression.md)，练习自由选择不代表正式成长已开放。平衡和具体技能仍按候选／已实现状态判断，当前范围见 [状态](../project/current_state.md)。

## 设计来源

武器树与长期地区方向的原始附件只用于来源核对；当前设计从 [地区框架](../bible/regions.md) 与以上正文加载。原件、用户选择和必要哈希保留在 evidence，不作为另一套可编辑规则。
