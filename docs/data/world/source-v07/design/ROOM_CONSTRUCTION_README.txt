失序之钟 v07｜逐房施工合同说明
=============================

本包为309房固定世界的结构灰盒设计。world-room-layout-v07.json是连接、分区、环境能力要求、交互与永久ID的唯一主数据。design/room-graybox-contracts-v07.json给出每房工作包络、门/出生点、真实入口落脚、镜头和可读活动占位。它不是已经通过Godot物理测试的地形。
规则以design/world-graybox-bible-v04.txt为准。工城/天门新设计见design/CITY_SKY_WORLD-v07.txt；当前规模和具体统计以handoff-status.json为准。

一、尺寸与形状
世界示意图单位不能直接转换成统一像素比例。普通施工以当前控制器、参考视口1280×720和工作视野800×450比较；1.6缩放只是首批候选，需在样房冻结。角色碰撞与移动参数开工时从真实仓库读取，不由房间各自改写。
工城与天门重新安排职责，旧房尺寸允许有意重定；其他既有房间保留可复用工作包络。新增房有职责驱动的宽高。Boss竞技矩形与前庭、奖励边带分别记录，不将所有Boss统一一屏或统一八边形。
多边形仅作主形体意图；可以用简单矩形主厅加一两个侧翼/大台阶。细裂纹、藤蔓、装饰齿轮交给美术。不要为了不规则而切碎通路。

二、跨房接口
每条连接生成一对door与明确target_spawn。左右门连续地面步行，向上门进入后自动短跳至旁侧真实平台再交还控制，向下门下方有安全平台。交通通过明确交互触发，不自动休息或回血。
required_reserved_areas包含门喉、净空、承重地面、接管动作体积、活动站位及Boss竞技区。净空不可生成实心地形；同高支撑可以并入已有地面，不把每个预留框变成悬浮砖块。图面轮廓不够容纳时调整真实前廊或外框。

三、分区与能力
普通门没有H/W/D/Q检查；门把玩家带入安全预览section，房内环境通路再通向main或深部。入口能观察障碍及出口，缺能力时可沿来门退回。道具、剧情和机械开关可放在实际门上。
所有NPC、奖励、Boss、修钟、休息、裂缝必须绑定section。进入入口不意味着可拿主体奖励，不因解锁一个裂缝就开放全地区。
Q只保护反冲位移中的怪物与相位光幕；齿轮/荆棘/熔岩/毒水/实体墙仍生效。连续Q之间有真实地面与足够2秒冷却，换房/换枪/失败不刷新冷却。

四、失败与休息
普通地形失败扣1HP，熔岩等重伤2HP；返回本段实际来向入口。HP归零则死亡回实际休息点。长组合用稳定台划分小段，不允许意外连续掉层后长爬。合法下落门与失误坠落是不同事件。
54个休息位置包含挑战房的安全侧龛。整房安全的服务房和“房里有一张长椅”分开；V07/V08/V11/V13仍可承担平台挑战，敌人/机关不侵入休息section。休息回血并重置普通敌人，永久Boss/奖励/修钟/捷径不重置。

五、城市与天门
G六片区7+5+8+6+6+4共36房。初次H走西街/广场12房；HW或HD从K/N进入东城与下城，累计26房；clock_E后HDQ走主轴上城，累计36房。这里的“初次/二次/三次”不是程序计数，条件齐可以连续做。
G07督工战，G23邻近休息；激光部件在G06，地方总钟在晚段G08。工房G01仍是第一次熔火必经服务；从E回工城的维护路在修炉后开通。
V主10房两翼可换序，每翼永久开回中庭；两翼开关使上层机械门开放。V11-V14极限支线不影响真结局，没有必需武器材料/记录。Q光幕后与Boss前都需稳定准备位；5处休息在14房内，不另外虚增房间数。

六、NPC与永久交互
14名常驻NPC每名唯一宿主，阿栖由全局单实例管理器按章节/实际到访落位，不能每个故事槽都静态生成一位。G23为T05/T06同幕备选；见过同幕不重复播放或发奖励。
开局4个物件复用既有交互宿主，P33三处塔脚故事物件只记录阅读，不发主线钥匙。到站一次目标提示不锁输入；对白和看风景都不成为能力、修钟或结局前置。
物品领取、消耗、永久收据与发放按同一事务保存。迁移奖励只改变原ID的位置，不生成新副本。商店价格未定；来源槽与成品装备效果区分。

七、生成与核对
从本目录运行python3 design/build_room_contracts_v07.py。输入主JSON、包内v04尺寸基线、历史扩容职责和当前叙事合同；不需要旁边的旧版目录。
回放文件必须与主JSON的原始字节hash一致，才纳入首访与Boss重试样本。过期样本会被省略，不能作为当前证据。几何合并后应重跑回放和编译。
房号、门/出生点成对、section绑定、唯一宿主、预留区与边界检查通过，表示接口一致；不能证明真实跳距、所有平台净空、Boss战、镜头或自然记忆已经通过。数值与动作请按首批样房校准。
