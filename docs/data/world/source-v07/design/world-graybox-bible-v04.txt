失序之钟｜灰盒开工规则
版本：4.0　日期：2026-11-07

适用范围
本文件汇总固定世界灰盒的操作、跨房、伤害、能力阻隔、战斗、修钟、镜头与场地规则。用户在2026-11-06确认的规则优先于旧地图和旧合同中的相反表述。本文的“已确认”是设计决定；“实施解释”是让决定可执行的建议；“候选”仍须实机标定。本文不表示游戏仓库已经实现这些规则，也不表示309间房的像素尺寸已定稿。

一、普通世界操作与时间主题【已确认】
1. 普通世界沿用当前游戏的玩家移动、跳跃、射击反冲及既有能力参数，保持各区域的基础操作一致。
2. 地区的加速、缓时、停时通过美术、动画、BGM、敌人及环境机关体现。地区主题不自动改变玩家重力、跑速、输入响应或能力距离。
3. 玩家原有主动技能与操作系统按当前设计保留；不能把“地区不改变物理”误解为删除已有主动时间能力。
4. 新房间根据现有控制器实际运动范围搭建。房间制作不能自行修改角色参数来补偿某个跳距或镜头问题。

二、房间连接与落脚【已确认】
1. 左右连接均为步行门，门两侧有可步行地面。
2. 向上跳跃跨房：跨房后短暂接管移动，自动跳到入口旁指定地面，实际落地后交还操作。
3. 向下跨房：每个目标入口下方均有安全平台，不让玩家在换房后直接跌进危险。
4. 交通门以对话式交互触发，完成交通不等于休息。
5. 普通跨房、交通、进区域、NPC对话与自动保存不自动回血、重置普通敌人、重置休息周期或刷新唯一奖励。

实施解释
• 每个入口记录真实落脚台、进入方向、相机初始构图和交还控制的位置。左右门不再承担保留空中运动状态的职责。
• 向上自动跳台仅完成入口落脚，落在本房入口侧安全区；不能越过本房待验证的H/W/D/Q障碍。
• 自动落到真实地面可满足Q的落地资格，但不会清除2秒冷却。
• 向下平台必须在入口下方可读、可达，平台宽度按角色速度和镜头实测；普通门与入口台均不能被敌人、危险地形或关闭机关占用。
• 交通的安全落脚与休息交互分开，不把抵达传送点当作已经使用该处休息点。

三、地形失败、死亡与永久状态【已确认】
1. 普通地形失败扣1HP。标记的特别危险地形失败扣2HP，例如熔岩。
2. 地形失败返回本次挑战实际进入侧的入口，不按最近出口或最近地面选点。
3. 休息恢复HP，重置普通敌人；死亡在休息点复活。
4. 能力、武器成长、唯一奖励、Boss胜利、修钟、捷径等永久结果保留。

实施解释
• 危险对象显式保存damage=1或2；同一次失败只结算一次，避免接触伤害与复位流程叠加扣血。
• 扣血后HP小于等于0执行死亡，不能借挑战复位取消死亡。
• 复位不回血、不重置休息周期、不重新发放本周期次数。必要时仅复位本段瞬态机关。
• 合法向下连接属于导航，不按坠落失败处理。
• 装备提供的抗毒等保护按其自身规则结算；Q本身不提供地形保护。
• 复位到真实地面可恢复动作资格；Q冷却保持独立，失败不能刷冷却。

四、Q反冲保护【已确认】
1. Q保护仅在实际反冲位移阶段生效，能够通过怪物和光幕。
2. 荆棘、齿轮、熔岩、毒水等实体环境危险仍然触发伤害，Q不能作为它们的保护或通行方式。
3. Q增加2秒冷却。真实落地恢复下一次使用所需的落地资格。
4. Q不穿实体墙，不改变普通世界已有的反冲位移参数。

实施解释
• Q是反冲过程附加的保护，不是给普通射击或反冲运动增加2秒攻击间隔。
• 触发条件：拥有Q，发生合法反冲位移，落地资格满足，且2秒冷却结束。
• 冷却从实际触发Q开始，以有效游戏时间计时；暂停不推进。换枪、换房、交通和菜单不清除冷却。
• 空中等待2秒但未落地：仍不能再次触发。已经落地但冷却未满：仍不能再次触发。持续处于合法地面时可满足地面资格，冷却仍限制贴地连用。
• 位移结束、被取消或被实体阻挡时，Q保护结束。三连子弹或激光伤害分段不会各触发一次Q。
• 危险分类独立于伤害来源：普通敌方攻击按敌人伤害处理；即使由Boss制造，明确表现为实体熔岩、齿轮的环境危险仍按地形危险处理。
• Q期间持续保留实体地形碰撞与地形危险检测，不能用一个全局无敌开关屏蔽所有伤害。
• 光幕挑战按初始普通枪的实际有效Q位移标定。连续两次Q之间需要真实落脚，以及足够时间或安全等待位置让2秒冷却结束。
• 位移在光幕内部结束，应按普通地形失败返回进入侧并扣1HP；这是统一失败规则的实施解释，不向出口侧吸附。

五、能力阻隔与道具门【已确认】
1. H/W/D/Q不以普通房门上的资格检查阻止玩家进入。
2. 玩家可先进入下一个房间的入口空间，看到新区域、地标、环境和未能通过的路线，再由真实地形和关卡设计阻止入口至深部出口的通行。
3. 道具锁放在门上，可检查钥匙、纹章、指定道具或剧情资格。捷径机关和Boss战斗封闭按各自状态控制。
4. 发光与抗毒装备可装卸，卸下后玩家可以重新装备。这一项不再作为开工阻断问题；保留先前约定的换装权限，不额外推定可在任意地点换装。

逐房与模拟的表达
• 物理门记录连接、入口台和真正的道具/剧情/机关条件。
• 有能力阻隔的房间增加少量可达分区，例如入口台、主体、上层支路。普通房只保留一个main分区。
• 能力条件写在“分区到分区的房内路线”上，用于设计和抽象验证；游戏中由实体环境实现，不生成无形的能力检查墙。
• 出口、Boss、休息点、修钟点和奖励都绑定所在分区。到过房间入口不表示能接触全部交互对象。
• 预览入口需可原路离开；不能让尚无能力的玩家靠死亡离开预览区。
• 能力或道具的获得地点不能要求自身尚未获得的能力或道具。不得把已经走到奖励旁的玩家用隐藏资格拦住，以掩盖地形锁失效。
• 已开的快捷通路根据实际地形保留必要条件，不把所有捷径重复做成能力考试。

区域探索状态
已发现：进入该区域的入口安全区。
已深入：穿过该区指定的首个主体通路，或到达主体锚点。
钟已修复：实际完成地区修钟。
深部记录已取得：实际交互取得该区记录。
普通结局路线的地区覆盖以主体探索核对，入口预览另计。真结局保持既有15个地方钟与16个深部记录等条件，不因探头进入而提前完成。

六、攻击、普通敌人与Boss【规则已确认；成长档位为试制默认】
1. 一次完整攻击按一枪结算。普通枪每枪基础攻击沿用当前试制档位5/9/13/17/21，具体平衡可在实战中校准。
2. 三连枪或激光一次完整命中的单目标伤害为同档普通枪的1.5倍；其命中条件与普通枪差异不大，不以额外长时间持续照射来抵消该倍率。
3. Boss常规安全输出窗口一般允许2枪；第3枪属于贪刀，受到反击的风险增加。
4. 最简单普通敌人9HP。后期地区的敌人可以有更高HP；具体数值参考空洞骑士普通流程并结合本作武器与敌人职责制定。
5. Boss血量和有效受击次数参考空洞骑士普通流程。房间尺寸按Boss特色决定。

实施解释
• 三连一枪发出的三弹合计1.5B，不是每弹1.5B。需要小数精度时保留精度，不能逐弹向上取整。
• 激光一枪有有限攻击预算1.5B，不能把每帧或每个tick都算成一整枪，也不再把旧的无限持续射击公式当作完整攻击定义。具体表现时长由现有武器动作实现校准。
• “稳健2枪、贪3枪”是Boss动作与反击节奏的目标，不以隐藏每轮伤害上限阻止第3枪命中。
• 血量按明确的首访攻击档与目标命中数选择，敌人配置后保持固定，允许晚访更轻松。增加后期区域敌人HP不等于升级玩家武器时同步给所有旧敌人涨血。
• 多阶段、多敌体和装甲Boss分别记录血池；不能将只打装甲的命中与本体损血合并解释。

七、修钟与世界变化【已确认】
1. 修钟的主要呈现是区域美术、时间现象与BGM的变化。
2. 修钟可以开启捷径、恢复交通、让旧路更容易通过。
3. 后续专门挑战房间不因修钟被改成另一套难度。
4. 修钟结果永久保存。

实施解释
• 每个地区钟绑定一组完整的修复前/修复后状态，包括背景、色调、动画节奏、机关反馈、环境音和BGM。
• 地形侧优先改变少量捷径或旧路便利设施，避免修钟后重新改写全区碰撞地形。
• 状态切换不得让玩家落脚台消失、封闭必经退路或丢失唯一奖励。
• 修钟后挑战房仍保留原能力要求、失败伤害和主要挑战布局；它可以使用修复后的视觉与声音状态。

八、镜头与Boss场地【参考方向已确认；参数待样房标定】
1. 镜头参考空洞骑士的房间构图、局部约束与观察方式。本作既有1.95/1.60/1.20镜头可作比较，不将任何一个直接视为新世界已冻结的统一数值。
2. 普通房间最终采用统一的基准视觉尺度。特殊Boss或特殊空间可以定义明确的镜头例外；镜头类型依据房间用途，区域美术主题本身不自动更换zoom。
3. 普通横向通路：稳定跟随，适量移动方向前瞻，小跳不造成明显上下摇摆，到空间边界停止继续露出房外。
4. 纵向通路：提前展示上方索点和落脚层，长下落时保证下方落点可见，利用落脚层和转角形成稳定构图。
5. 固定战斗构图：用于紧凑决斗或可完整同屏的Boss场。关键预警、敌我和主要躲避位置同时可见。
6. 有限移动战斗构图：用于冲锋、大型或多层场地。移动受战斗区约束，阶段或空间切换有明确过渡，不随每次冲刺反复改变zoom。
7. L形、T形和扭曲矿道按主要空间设置多个相机区，不仅以整房外接矩形约束镜头。
8. 前瞻依据实际移动趋势和房间构图目标，不跟随枪口或鼠标。短促反冲不应每次造成镜头反向摆动；角色接近屏幕边缘时，保持角色与下一落点可见优先。
9. 安全站立时可以提供上下观察。输入映射需兼容现有瞄准，不直接占用已经承担瞄准的右摇杆；正常主路不要求每次手动查看才可通过。
10. 跨房接管期间先确定目标构图与落脚位置，再归还操作。镜头只展示当前房间，不泄漏相邻房间的敌人与地形。

场地制作顺序
Boss主要动作与阶段 → 首访玩家的合理躲避/攻击动作 → 有效竞技空间 → 镜头构图 → 房间外框与门。
决斗型优先控制敌我距离与同屏读招；冲锋型要有冲刺、避让、转身的空间；高处弱点型先定攻击弱点的动作高度；多平台型先定每个平台的战斗职责。
竞技空间、入口前庭、奖励区与整房外框分别记录。22场Boss逐场定义竞技场候选与镜头用途，再用实测动作校准。
空洞骑士没有本次可核实的官方统一竞技场像素表、zoom表或deadzone常数；不将自拟参数称为原作参数。

九、当前交接结构与验证范围
当前世界以world-room-layout-v07.json为唯一生效数据，保留16区域、309房间和稳定永久ID。房间内部能力路线、跨房门、交互所在分区及已发现/已深入状态分别建模。
施工合同由design/build_room_contracts_v07.py生成，包含世界单位工作尺寸、真实场景门的候选接口与安全落脚、相机用途、难度职责和首访配置。候选坐标用于开始搭建，可在首批样房校准后局部调整。
路线验证以simulation目录的v07结果为准。原始v03文件只放在source_inputs，作为迁移重建依据；旧房间级路线的可达房数与地区访问数不再作为新分区模型的证明。
能力与道具组合条件保持原意。普通跨房门不检查H/W/D/Q，内部路线用真实环境实现能力要求；奖励、Boss、休息与服务绑定具体分区，不能因进入房间而全部视作可达。
共享条件应合并到同一空间，不按每件奖励重新增加一段平台考试；已经开启的捷径只保留实际需要的条件。
现有世界图保留宏观方位和稳定房号；工城与天门重排房间，平原新增工城西入口，古堡/矿井改接东城、熔火修复后接主轴。世界图形状不直接按比例换成碰撞轮廓。
本包的readiness结论与逐项证据以handoff-status.json及人读图册为准。可开始结构灰盒不等于游戏仓库已实现，也不等于候选尺寸、镜头、Q节奏或Boss战经过实机验证。

十、实施顺序与修改权限
第一批做共享基础样房：P-R03→P-R21→P-R22→P-R23→P-R24教程与P-R01小站、P-R31至P-R35中央路网、P-R06分岔、P-R14基础Boss场地、F-R04纵向H与F-R10的W取得、I-R05/I-R11的HWD预览、K-R16/K-R05的Q应用、A-R04后期接续、S-R05装备环境。
这些代表房解决控制器与新镜头、左右/上跳/下落转场、真实落脚、1/2HP失败、Q过滤与2秒节奏、房内能力阻隔、唯一保存等共用问题。通过测试入口载入所需状态，不必先制作它们之间全部细节。
同时试制G13/G14广场、G20东岸、G25桥底和G28/G29主轴形成的四视角小环，V04左翼、V07右翼与V08光幕的动作组合样段。它们用于验证空间识别、回访和Q重试成本。随后创建全309房的可走外框、分区占位与门接口，接上NPC、休息、裂缝、Boss胜利占位、关键奖励、修钟、捷径与结局。占位对象应能识别其职责和实际条件；Boss胜利的开发替身必须标明未实现战斗，不能据此宣称战斗平衡。
最后按区域与房间职责完善平台、敌人、Boss招式、装饰、声音及经济。金币价格、非关键装备最终效果、镜头常数与碰撞边缘不阻止先完成结构灰盒，但不能虚构它们已验收。
房间内尺寸、平台和相机区可以局部迭代；变更房号、奖励ID、连接去向、能力取得或主要剧情条件，必须改主数据并重跑受影响路线。不要用开发代理各自的参数修改共同操作尺度。

十一、世界路网、开局与主线引导
当前世界为309房；工城36房、天门14房，其他区域容量沿用前版。此前中央平原5房路网完整保留。中央平原的P31站外铃场、P32悬铃长桥、P33钟影前庭、P34渠边旧集、P35东行汇口承接小站与钟心基座之间的空间。
小站保留西门到P08，新增东门到P31。出东门一房内可选西侧旧路、北侧塔脚、东侧田野。P32安全地面可去塔脚，房内high:H高位出口用钩索通向P35；H不检查在门上。P35直接接P18东田，P12地窖为旁支，南渠与北侧塔脚均能形成回环。
取得H、修复平原时钟后，从P15开通SC-P01回程梯，落到P32安全层。玩家可两门回站，也能就近尝试可见H路线向东。P20保留原H装备支路；只有实际看到本房地标才记录记忆，不远程揭露未见奖励。
开局五段教程后进入小站，西侧首Boss旅程仍保留首次9门与就近重试。P24的当前房间背景应同时表现近处小站与远方最高钟心；远景不加载相邻房间的碰撞或敌人。
首次到站记录一条主线目标：修复地区时钟，寻找三枚核心，重启世界钟心。NPC可选短对白解释时间失序与修钟工作的关系。P33塔脚提供巨大底座、断轴与三核心维修示意。王希望长生的旧承诺可以早见，神与王被控制的真相随地区探索展开。
Z01门厅、Z03观察窗等原有早期可达空间继续可进入；Z04的房内深入仍需H+(W或D)，后续上塔与装核继续使用既有三核心、clock_A、Q等条件。不能把三核心变成钟心最外门的新钥匙。
聊天、读物、远景观察和可选记忆标记都不成为能力、材料、修钟或结局的新前置。自动日志不自动休息；玩家可跳过叙事表现并继续选择路线。

十二、工城与天门的世界职责【当前采用设计】
工城为36房六片区：钟匠街与齿轮工房7、悬钟广场与市政步道5、东站与旧住宅区8、下城动力沟6、上层检修连廊6、旧授时院4。三次揭示按可达空间和永久状态分层，不以造访次数、对话次数或强制离开为前置。
首访P18→G02由H环境通路进入西街，接触工房和广场。二访可从K18→G20或N货运层抵达东城，以HW或HD成立；东城督工和激光分支不要求先修熔火。首次进熔火必须经过工房并取得武器匠服务收据，不要求付费购买。N/R的熔火替代入口只从修复后的熔火一侧开通。
熔火repair_E动作写入clock_E后，从E10维护出口返回G28主轴；HDQ即可进入上层与授时院，W不是硬前置。地方修钟、记录、居民任务和既有奖励使用当前房号，不复制旧位置。Q始终先在古堡取得，上城不能成为Q取得前置。
悬钟桥是横跨街谷、桥腹悬大铜钟的横向地标。西广场看正面，东住宅看背面，矿井出口看桥底，检修道看内部与旧街。世界钟心仍为全世界中央最高塔。工城主授时停摆与机器重复生产相冲突，修复主要恢复灯、钟声、居民节拍和旧路便利。
天门共14房：入口/中庭2、左翼2、右翼2、上层2、真相/回程2、独立极限4。左右翼顺序自由，完成一翼就能开回中庭的永久捷径，两翼完成开放上层机械通道。守门者、断契棱针、地区钟和深部记录均在主线10房内。
天门主线第一轮按每段4-6个关键动作试制，主线平台压力上限T4；极限支路允许T5，具体难度需真人标定。主线休息位置V01/V07/V08，极限V11/V13；安全侧龛不意味着整个挑战房无危险。地形失败统一扣1HP回本段，死亡回明确休息点；Q连续段必须容纳真实落地与2秒冷却。
真结局要求16区主体探索、15地方钟、16深部记录等既定条件，不要求每个房间全探、22Boss全清、40齿轮全收或V11-V14极限挑战完成。极限支路只给独立纪念/记忆，不布置攻击合金、分支材料、技能芯或强制剧情记录。普通结局可跳过整个天门。
