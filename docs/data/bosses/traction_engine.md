# 失控牵引总机

G19 的卷扬总机悬于吊轨，传动钢缆引出下方的横移吊臂与两侧配重。取得 W、H 后可在安全门廊发起挑战。先认吊灯和头部的运动刻度，借高台和吊点换侧。配重降下前，轨床会显出与实际重锤等宽的落点。

机体有 24 点耐久。每轮动作后，检修口亮青光 1.75 秒，玩家可以从恢复台射入。半程铃响后左右配重交替与横扫组合。首胜取得 190 币，工房装备另在 G18 领取。

横梁、卷筒、配重和吊线分开绘制。固定机体复用 gear_city_v2_pipe_junction 的铸件原画，新作卷索轴和分段悬挂结构。生成脚本在 art/bosses/machines/build.py，实房回归在 production/tests/machine_bosses.gd。
