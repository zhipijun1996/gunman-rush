# 熔脊蜕壳兽

E21 的熔脊兽背壳从尾到头亮起。最后一条亮纹指向整只身体的滚动方向。取得 W、Q 后可在安全肩台主动挑战，从侧面等其滚过或以实际反冲擦过兽身。喷气头、落壳和熔岩仍须躲开。冷却后腹部开放 1.72 秒。

兽体有 28 点耐久。半程后在预告过的右侧落点丢下一块旧壳。落稳的岩壳有实体，可作为低矮障碍或脚下支撑；左侧落台始终开放。后续滚动与侧向喷气均沿用首段的信号。胜利独立结算 190 币，藏室的装备需另外领取。

背部晶脊复用 ember_depths_v2_obsidian_fangs 原画。脚爪与甲片按此兽独立绘制。独立平地测试场加载正式熔脊兽、玩家和 E21 遭遇资格，验证蜕壳后能站在实体岩壳上，以及胜利收据和 190 币同时入账。[首领回归](../../../production/tests/machine_bosses.gd)
