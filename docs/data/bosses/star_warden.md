# 月冠星仪守卫

v27 古堡 K11 的战斗配置。镜架先指向玩家并固定射线，展开时射出三枚镜光。星仪臂沿一层台面扫过，玩家可在回缩后落地还击。生命降至半数后左右重锤和反扫加入循环；高处停脚位与准备时间仍然保留。收招阶段的开启核心收受普通攻击。

在星仪台确认胜利后，K12 档案室的护身技艺才可主动领取。攻击参数在[守卫定义](../../../production/resources/enemies/star_warden.tres)，地形、机体与胜利确认点在 [K11](https://github.com/zhipijun1996/gunman-rush/blob/24e5957206d3e966e7c7a9e98ce4982fb28c2a8b/production/rooms/world/K11.json)。
