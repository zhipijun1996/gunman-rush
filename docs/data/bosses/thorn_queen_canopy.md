# 棘冠女王 · Canopy

女王穿梭两道实体树肋，持续横扫并用织结改变路线。玩家先决定下一次在哪里站，再选择借结、剪网或换岸；推进伤害会使最近真正站稳的岸承受持续压力。

## 行为与应对

身体始终可受伤，不能作为钩索目标；可借用的是场地固定锚与真实织结。玩家可保留结作路线，也可剪断网络减压，H 不自动打断女王或清空织场。

| 阶段 | 新判断 |
| --- | --- |
| 越身 | 读整段已锁定的横扫路径与实体树肋，以普通跳跃／反冲换侧，或借固定锚越身后射击 |
| 高结留剪 | 高处生成一个结及网；完整细线先预告，再逐段生长并持续。可保结绕线、借结后反枪剪剩余生命，或直接射断；剪掉后不循环重生 |
| 接收岸换位 | 锁定玩家最近真正全脚站稳的岸，生成对应结与网；空中未来落点不作为依据。可离开旧岸保网、提前剪网，或先诱导站位再推进伤害 |

阶段变化不取消已经承诺的身体路线，不瞬移、回血或开放无敌窗口。已有网在后续预告和换阶段仍保持威胁；预告本身不伤人，开始生长后已长成部分即为危险。

织带不是实体墙，不推人、不挡枪或钩索。保结、剪结、诱导换岸是自由策略，玩家通过观察、瞄准与位移完成，不要求依次走一条固定按钮流程。

## 表现与版本

冠形轮廓、树肋、结与织带共同表达织冠者身份；受伤、命中、断结和阶段声音可区分，身体动作和环境变化形成连续节奏。致死后停止威胁并接当前胜利与奖励。
