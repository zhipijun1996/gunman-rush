# 鸣铃巡游机

平原鸣铃巡游机，固定房间位置以世界源为准。外观沿PR142现行平原的建筑与材质语言重绘，以完整、厚重的承重轮组、车体和外露主铃建立Boss体量与压迫感，避免空架、细杆及废铁堆叠。体型可重新适配，与主角同屏判断；B/C静态造型及关卡明暗分离已获用户批准，按同体制作分层铰接动画。上端主风铃是唯一可受伤部位，其他部件只产生装甲反馈。移动、攻击与收势期间都可击中主铃。

## 攻防节奏

根据玩家距离、高差与近期招式选择攻击组，出手前确定本组动作，普通命中不使它重新选招。躲过一组攻击后应有稳健两枪并撤离的机会；多贪一枪会压缩余量，站位与操作决定风险。

| 招式 | 预告、威胁与反制 |
| --- | --- |
| 滚轮冲锋 | 轮组绷紧、悬架压缩、车架前倾、主铃后摆，随后迅速加速冲过一段可读距离，以轮速、后掠衣饰和轮下扬尘明确表现快速冲锋；玩家可跳越、反冲换边或借平台避让。预告依身体和铃声表达 |
| 地面铃波 | 轮组撑稳、铃舌敲击，声响与沿地传播的波同步；波的可见形状对应伤害范围，基础跳跃可越过 |
| 高抛铜铃 | 车身先将后置炮管朝向目标，炮管抬起后投出铜铃，末段锁定落点；铜铃从实际炮口沿抛物线落到真实平台，落点阴影和局部震荡有清楚边界，玩家可离开落区 |

进入强化阶段后，冲速和组合压力提高。回冲须在第一冲之前以不同姿态和双拍铃声提示，中途刹停／转向与真正收势可分辨。换向必须先刹停，再经侧身、正面、另一侧的连续姿势完成回身；普通换边、后置炮管瞄准和回冲均不得瞬间镜像翻转。转身使用正面车壳／轮胎视图与同一骨架的位置投影，保持正面体积，不把整车压成薄片；左右轮绕车体前后错开完成回身，轮辐不因视角变化倒卷，正面轮胎保持竖直；连续铃波各有独立敲击节拍，第二枚抛铃另给预告。

## 动作、声音与终态

地波、抛射铜铃、炮口迸发与落地震荡使用同族细像素素材。地波前缘清楚覆盖实际危险边界，尾迹与扬尘保持稀疏；铜铃使用稳定的独立弹体贴图沿真实弹道连续翻转，不能按整张效果图集换行或高速闪切不同轮廓；后炮只旋转完整炮管，不得把车身、布料和背景碎片随矩形裁片带起。钟架内壁与铃体分别为固定素材，内腔遮挡和明暗稳定，不能用整图形变／alpha孔洞插值产生异样白边、亮斑或黑白闪烁。命中时才产生破裂／火星和局部波纹，取消攻击不伪造命中特效。

车体、悬架、钟架、铃体、炮管、轮轴与车轮分别绑定固定尺寸部件和铰点，使用可编辑骨骼与动作曲线；禁止跨招式换整身贴图或光流形变。车轮必须实际绕轮轴旋转，角度由有符号位移除以轮半径驱动，左右行驶反转，停下即止转；轮辐和铜色轮毂能看出滚动。冲锋身体只完成一次前倾并保持高速姿态，不按行程反复重播整身蓄力。悬架、车架、钟架与铃体有承重和滞后，受伤后自然接回当前动作。主铃明暖、铃口清楚，其他亮金控制在不混淆弱点的范围。

装甲命中为局部铜片震动、小火星和闷金属声；主铃命中为偏摆、短亮、少量碎屑和清晰共鸣。关键预告优先于连续命中声。

死亡立即停止威胁，依次表现末铃／裂铃、齿轮卡停、车架侧沉、钟架松脱和尾响消退，留下低矮、不挡路的残骸。金币从钟腔或破壳喷出并落到可拾取平台，演出、胜利和奖励各只触发一次。
