# 鸣铃巡游机

平原鸣铃巡游机，固定房间位置以世界源为准。外观沿PR142现行平原的建筑与材质语言重绘，以完整、厚重的承重轮组和钟楼形体建立Boss体量与压迫感，避免空架、细杆及废铁堆叠。体型可重新适配，与主角同屏判断；静态造型须经用户审批再制作全套动画。上端主风铃是唯一可受伤部位，其他部件只产生装甲反馈。移动、攻击与收势期间都可击中主铃。

## 攻防节奏

根据玩家距离、高差与近期招式选择攻击组，出手前确定本组动作，普通命中不使它重新选招。躲过一组攻击后应有稳健两枪并撤离的机会；多贪一枪会压缩余量，站位与操作决定风险。

| 招式 | 预告、威胁与反制 |
| --- | --- |
| 滚轮冲锋 | 轮组绷紧、悬架压缩、车架前倾、主铃后摆，随后沿选定方向加速；玩家可跳越、反冲换边或借平台避让。预告依身体和铃声表达 |
| 地面铃波 | 轮组撑稳、铃舌敲击，声响与沿地传播的波同步；波的可见形状对应伤害范围，基础跳跃可越过 |
| 高抛铜铃 | 独立发射器抬起后投出铜铃，末段锁定落点；铜铃沿抛物线落到真实平台，落点阴影和局部震荡有清楚边界，玩家可离开落区 |

进入强化阶段后，冲速和组合压力提高。回冲须在第一冲之前以不同姿态和双拍铃声提示，中途刹停／转向与真正收势可分辨；连续铃波各有独立敲击节拍，第二枚抛铃另给预告。

## 动作、声音与终态

轮速对应位移，悬架、车架、钟架与铃体有承重和滞后，受伤后自然接回当前动作。主铃明暖、铃口清楚，其他亮金控制在不混淆弱点的范围。

装甲命中为局部铜片震动、小火星和闷金属声；主铃命中为偏摆、短亮、少量碎屑和清晰共鸣。关键预告优先于连续命中声。

死亡立即停止威胁，依次表现末铃／裂铃、齿轮卡停、车架侧沉、钟架松脱和尾响消退，留下低矮、不挡路的残骸。金币从钟腔或破壳喷出并落到可拾取平台，演出、胜利和奖励各只触发一次。
