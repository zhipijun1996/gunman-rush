# 根铃守卫

森林根铃守卫，固定房间位置以世界源为准。身体扑越与独立实体铃共同构成“借铃返击”的判断：玩家辨认攻势、移动接收者与反击时机，选择躲避、普通攻击或使用已授予的 H。

## 招式与阶段

树心在入场结束后持续可伤，不要求先以 H 开甲。金属铃不可射坏，既挡普通弹，也是移动钩索目标。

| 招式 | 玩家判断与结果 |
| --- | --- |
| 抛铃／接铃 | 铃从威胁与射线障碍变成可借用媒介；玩家真正到达来铃并完成踢返后，铃沿固定弹道返回，真实撞到主人才能造成反击和短失衡。它仍可能撞地形、打空或被主人移动错开 |
| 身体扑击 | 预告时锁定玩家当时的真实支撑旧点，之后不追踪新移动；玩家可离开落点继续射击，身体遇地形会提前落定并收势 |

早期两招便于独立观察；低血量且玩家已经见到真实身体扑击后，外铃飞行时身体也开始追扑，接铃者位置随之变化。玩家同时选择避开身体、保持射线，或借来铃返击。合法高效输出可以提前击杀，不锁血强迫完成教学。

场地保留普通跳跃、射击与反冲的合法打法，H 为可选主动反击。站位、观察和操作共同决定收益，不能按一次按钮直接兑换伤害。

## 表现与结束

铃、身体、预告和命中保持可辨认关系，声响表达起动、借用、返撞与落地。受伤、打断和动作回接清楚，死亡停止威胁并接既有胜利／奖励演出。
