# 回潮司钟

取得 W、H 后，R23 的观察外缘可以安静查看三座固定铜泵。主动发起挑战后，被选中的泵先亮灯，水柱边缘出现引导刻度。水柱自喷口向上推到 156 像素处，玩家可以钩上相邻高台，或者移至另一条带。每次卸压后，司钟的铜质阀芯会开 1.55 秒。

机体有 30 点耐久。第一段依次认识左、中、右三座泵，剩余约三分之二时开始连续换泵，最后约四分之一时重排次序、夹入延拍。每次喷发都独立预警。观察外缘仍可撤退。独立确认首胜结算 190 币，R24 负责后续物品。

本体复用沉没遗迹 air_bell 与 fluted_column 的原生像素。铜灯、独立喷口与水柱按正式战斗的位置绘制。源文件为 art/bosses/tide_and_ember/build.py。
