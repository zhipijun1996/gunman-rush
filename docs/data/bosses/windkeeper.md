# 牧风者 · 主动追压版

平原牧风者，固定房间位置与永久能力取得关系以世界源为准。外观沿PR142现行平原的建筑与材质语言重绘，以完整躯干、强壮四肢和清楚的承重关系建立巨兽体量与压迫感，避免细腿、碎片甲壳及废铁感；体型可重新适配。一阶段主动迈步接近玩家，在相应攻击距离内开始重踏／高跃扑击，不在远处反复空踏；移动、连招间歇和收招保持敏捷明确的节奏，同时保留可辨认的预告与反击机会。通过距离、高差和站位变化组合攻击。

前两阶段以左右换边组织战斗：地面迈步逼近时，玩家可起跳并用反冲从巨兽上方越过；前扑时Boss主动腾空，玩家从其身下穿过。地面逼近侧墙前保留可起跳、可越顶的净空，不能把玩家挤到只剩接触伤害的死角。玩家被逼近侧墙且Boss已经贴近时，在下一次招式预备前向场内后跳让出空间；不打断已预告的攻击。同一次逼角只让位一次；落地后恢复实际迈步接近，在距墙的安全停步线止步，以有完整前摇的重踏／风籽／风压继续形成正面威胁，不停在远处循环空招，也不重新走入贴墙后跳循环。前两阶段踏波朝已预告的正面传播，沿真实地面进入平台下方，跳跃可躲，不能在已完成换边的玩家背后补生一波；风籽仍受真实地形遮挡，弹体寿命足以到达其已预告目标。前两阶段一组招式在首次攻击前摇时锁定朝向，各招在自己的前摇锁定正面目标；仍在正面的玩家可被实际追近，越顶或穿身后不在组内突然转身追打；完成原朝向招组与收势后才重新辨认、转身追击。这样换边获得真实反击窗口，原地墙角不因Boss让位而永久安全。玩家和Boss均离开该侧足够距离后才重新允许防逼角后撤，小幅贴墙进出不能反复重置。

普通贴身或走动受阻的后跳仍有独立冷却与真实落点。所有落点先验证，不以连续转身或反复位移拖延攻击。地面靠墙时按完整身体与披风留出移动余量；高台跳跃按真实平台支撑和实体墙体积验证落点，不用地面巡逻范围截断空中轨迹。伤害体积仍沿真实躯干、头部和四肢计算。

进入二阶段时，头顶必须长出／展开一座大风车，轮轴与支架直接连接头部，成为主轮廓；不能用背上风帆或悬浮背景风车代替。切换伴随短促屏幕震动和覆盖全屏的稀疏风压／光晕，支架先抬升，叶片依次展开，转子随后加速；演出由阶段时钟驱动，暂停冻结，取消／死亡／切房清理，恢复从保存进度继续。二阶段后保留该形态，三阶段不重复长出风车。风车的支架、转子与叶片不产生阻挡或接触伤害，玩家可从其视觉范围内飞过；巨兽真实头部、躯干和肢体仍保留接触威胁。头顶风车是实际出风器官：蓄风时加速转动，出风时覆盖面前从近地到头部高度的大范围空间，多层稀疏风痕持续横向流动，不能画成从轴心瞄准玩家的一条线；二阶段招组明确使用持续风压配合风籽远程齐射，风向与目标在前摇中确定，吹风结束立即止推，最终收势不补射。已批准的B/C一、二阶段保持同一躯干、头部与四肢身份；完整动画包含头顶生长转换以及各阶段动作，风车运动与招式预告保持可读。

## 招式与应对

| 招式 | 玩家要辨认与应对的内容 |
| --- | --- |
| 重踏 | 单足／双足的抬起姿态提前可分辨，落足有真实重量与地面威胁 |
| 高跃扑击 | 充分压低蓄力并短暂稳住后蹬地高跳；空中明确分为伸展离地、收腿越过玩家、伸足准备着地，朝前摇锁定的落点压下；主要安全应对是迎向 Boss，从抬起的身体下方穿到其身后。留在落点会受到实体接触伤害，不能用关闭空中碰撞伪造安全通道。起跳后不追踪改向，落地保持可读承重 |
| 风叶横扫 | 肩背侧转提示扫动方向与高低，身体运动和伤害范围一致 |
| 风车风压 | 头顶风车蓄力后向身前宽阔区域持续吹风，视觉风场的水平距离和上下边界与实际推力区域共用定义，风向、风籽齐射和环境运动共同提示推力与弹道；玩家可提前离开风区、利用高低差或弹间空隙，保留可读退路和落点 |
| 扇形风籽 | 仰首后射出扇形风籽，声响、方向和弹道对应 |
| 抬肢踏台 | 后期伸向已经锁定的真实平台，充分预告后施压，玩家能离开被选落点 |

保留三个生命阶段：早期以较短招组让玩家辨认招式，中期展开头顶风车并加入连招和风压／横扫，后期跳上三块等距、同宽的真实战台，预警后从下方原地面长出连续荆棘，用更长组合追压真实站位。地面本体保留，荆棘在预警与生长结束后覆盖整个战场地面至两侧封场墙，不保留可驻留的安全边角；第三阶段的登台、跨台、扑击与后跳适度增高，保持原有落点验证、预告与完整腾空轨迹。玩家利用预警期登台；碰刺按环境伤害返回已到达的安全战台，不能跌入场外下层。致死后立即止刺伤，荆棘收回，恢复战后地面通行。扑击与后跳保持较大幅度，前摇和滞空要足够读清，不能以过短腾空制造敏捷感。前扑以后肢蓄力蹬出、前足准备落地；后跳先把重心压向前足，再向后弹开，空中保持起跳朝向并以后足先准备着地。两者不能共用前扑姿势；连招衔接和收势加快，但关键起跳预告、空中穿身窗口与落地必须可辨认。招组开始时确定形式，预告后不暗改；整组最终收势提供反击与撤离机会，不在恢复中补发新攻击。

## 表现与结束

风籽、踏地波、发射瞬间和命中／落地使用同族细像素素材与分阶段特效：象牙白风痕、青绿叶片和少量金色核心延续本体材质。地波和弹体主体对应真实碰撞范围，尾迹不得掩盖伤害边界；特效只消费实际攻击／命中，暂停冻结，死亡、取消、切房和恢复清理旧效果。

换边先转头辨认方向，再以交错抬足、落脚和躯干回转完成侧面／正面／另一侧姿势。着地足在各自支撑段固定，近远肢遮挡随回身调整；正侧面材质保持实色，避免透明叠影、四肢穿插滑动和附件突然消失。头顶风车轴心随头部移动，转子保持连续旋转，不因朝向切换突然反转。正面躯干／头部视图和四足站位共同保留回身时的体积；转身以视角投影表现近远关系，肢段端点始终连接，不能把整身压成薄片。脚掌拥有独立关节，贴地段保持水平，空中收腿时不随小腿大幅翻转。躯干、颈头、四肢、披饰和风车使用固定尺寸的同一套分层素材，绑定明确关节／骨骼和可编辑动作曲线。待机、移动、预备、攻击、收势、受伤与死亡连续接合；身体起伏依靠关节和位移，禁止用整身贴图形变或整体缩放连接招式，二阶段只展开头顶风车，不改变躯干／头部／四肢尺寸。风车转子围绕固定轴心实际旋转。动作体现全身承重、起落和机械传导，普通命中不重置招组。关键预告、踏地、扫风、帆动和命中声能在连续战斗中分辨，画面和伤害位置对应。

致死后立即止伤、止风。死亡发生在腾空过程中时，终止主动扑击／跨台推进，身体受重力落到真实支撑，落地后完成坍塌；攻击与风场在死亡接受时立即关闭，不能沿活体的锁定跳跃继续飞行。身体失力落位后喷出金币，奖励落在可达平台；阶段切换、失败恢复与重复进入不重播胜利或重复领奖。
