# 牧风者 · 主动追压版

平原牧风者，固定房间位置与永久能力取得关系以世界源为准。外观沿PR142现行平原的建筑与材质语言重绘，以完整躯干、强壮四肢和清楚的承重关系建立巨兽体量与压迫感，避免细腿、碎片甲壳及废铁感；体型可重新适配。一阶段主动迈步接近玩家，在近战有效距离内开始重踏／短扑，不在远处反复空踏；移动、连招间歇和收招保持敏捷明确的节奏，同时保留可辨认的预告与反击机会。通过距离、高差和站位变化组合攻击。

进入二阶段时，头顶必须长出／展开一座大风车，轮轴与支架直接连接头部，成为主轮廓；不能用背上风帆或悬浮背景风车代替。二阶段后保留该形态。头顶风车是实际出风器官：蓄风时加速转动，出风时覆盖面前从近地到头部高度的大范围空间，多层稀疏风痕持续横向流动，不能画成从轴心瞄准玩家的一条线；二阶段招组明确使用持续风压配合风籽远程齐射，风向与目标在前摇中确定，吹风结束立即止推，最终收势不补射。已批准的B/C一、二阶段保持同一躯干、头部与四肢身份；完整动画包含头顶生长转换以及各阶段动作，风车运动与招式预告保持可读。

## 招式与应对

| 招式 | 玩家要辨认与应对的内容 |
| --- | --- |
| 重踏 | 单足／双足的抬起姿态提前可分辨，落足有真实重量与地面威胁 |
| 低身短扑 | 压低、起跳、锁定方向、落地承重连贯，玩家可跳跃或换位避让 |
| 风叶横扫 | 肩背侧转提示扫动方向与高低，身体运动和伤害范围一致 |
| 风车风压 | 头顶风车蓄力后向身前宽阔区域持续吹风，视觉风场的水平距离和上下边界与实际推力区域共用定义，风向、风籽齐射和环境运动共同提示推力与弹道；玩家可提前离开风区、利用高低差或弹间空隙，保留可读退路和落点 |
| 扇形风籽 | 仰首后射出扇形风籽，声响、方向和弹道对应 |
| 抬肢踏台 | 后期伸向已经锁定的真实平台，充分预告后施压，玩家能离开被选落点 |

早期以较短招组让玩家辨认招式，中期加入连招和风压／横扫，后期用更长组合追压真实站位。招组开始时确定形式，预告后不暗改；整组最终收势提供反击与撤离机会，不在恢复中补发新攻击。

## 表现与结束

风籽、踏地波、发射瞬间和命中／落地使用同族细像素素材与分阶段特效：象牙白风痕、青绿叶片和少量金色核心延续本体材质。地波和弹体主体对应真实碰撞范围，尾迹不得掩盖伤害边界；特效只消费实际攻击／命中，暂停冻结，死亡、取消、切房和恢复清理旧效果。

换边采用四足原地踏步回身的连续侧面／正面／另一侧姿势，头顶风车随头部转向，不瞬间翻转本体。动作体现全身承重、起落和机械传导，普通命中不重置招组。关键预告、踏地、扫风、帆动和命中声能在连续战斗中分辨，画面和伤害位置对应。

致死后立即止伤、止风。死亡发生在腾空过程中时，终止主动扑击／跨台推进，身体受重力落到真实支撑，落地后完成坍塌；攻击与风场在死亡接受时立即关闭，不能沿活体的锁定跳跃继续飞行。身体失力落位后喷出金币，奖励落在可达平台；阶段切换、失败恢复与重复进入不重播胜利或重复领奖。
