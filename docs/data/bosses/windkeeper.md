# 牧风者 · 主动追压版

平原牧风者，固定房间位置与永久能力取得关系以世界源为准。外观沿PR142现行平原的建筑与材质语言重绘，以完整躯干、强壮四肢和清楚的承重关系建立巨兽体量与压迫感，避免细腿、碎片甲壳及废铁感；体型可重新适配。主动接近玩家，通过距离、高差和站位变化组合攻击。

进入二阶段时，头顶必须长出／展开一座大风车，轮轴与支架直接连接头部，成为主轮廓；不能用背上风帆或悬浮背景风车代替。二阶段后保留该形态。静态审批同时提交一阶段和二阶段，保持同一躯干、头部与四肢身份；用户通过后再制作生长转换以及各阶段完整动作，风车运动与招式预告保持可读。

## 招式与应对

| 招式 | 玩家要辨认与应对的内容 |
| --- | --- |
| 重踏 | 单足／双足的抬起姿态提前可分辨，落足有真实重量与地面威胁 |
| 低身短扑 | 压低、起跳、锁定方向、落地承重连贯，玩家可跳跃或换位避让 |
| 风叶横扫 | 肩背侧转提示扫动方向与高低，身体运动和伤害范围一致 |
| 展帆风压 | 帆、风向与环境运动共同提示持续推力，玩家有可读退路和落点 |
| 扇形风籽 | 仰首后射出扇形风籽，声响、方向和弹道对应 |
| 抬肢踏台 | 后期伸向已经锁定的真实平台，充分预告后施压，玩家能离开被选落点 |

早期以较短招组让玩家辨认招式，中期加入连招和风压／横扫，后期用更长组合追压真实站位。招组开始时确定形式，预告后不暗改；整组最终收势提供反击与撤离机会，不在恢复中补发新攻击。

## 表现与结束

动作体现全身承重、起落和机械传导，普通命中不重置招组。关键预告、踏地、扫风、帆动和命中声能在连续战斗中分辨，画面和伤害位置对应。

致死后立即止伤、止风，身体失力落位后喷出金币，奖励落在可达平台；阶段切换、失败恢复与重复进入不重播胜利或重复领奖。
