## 织结与路线

同一个活结既可借用，也可被普通枪剪断。真实 H 接触伤结并恢复合法空中动作，随后反向射击可剪掉剩余生命、清网并改变自身位置；保结留下借点与持续危险，剪结清场但失去该借点。全剪后普通跳跃／反冲与应急固定环仍合法。

| 阶段 | 空间变化与应对 |
| --- | --- |
| 高巢巡视 | 预告一次锁定完整巡视路线；玩家读路径、让岸、换射角，或借结到巡线上方输出 |
| 同岸低巢 | 女王从内口下降，实体枝体遮挡部分射线；玩家等待移动射窗、换层／换侧，或主动借结剪网 |
| 高低连接 | 路线连接高低巢，已有网络叠加可预告的升降网；玩家保网抢角、剪网或在需要时恢复，不硬性要求固定次数的 H |

阶段网络可以先预告，身体完成已承诺路线后再换路线，不瞬移、不复活已剪结，移动中仍可受伤。地网、旋转网和升降网在后续阶段持续存在，危险范围、成长预告与可站空间在实际镜头清楚可读。

身体运动、织结、剪网、受伤和终态保持连续，最终演出停止威胁并接原奖励。返回场地保持本版本生命、路线和网络结果。
