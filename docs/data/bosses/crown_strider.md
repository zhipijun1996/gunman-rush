# 石冠巡崖机

v27 风蚀峡谷 Y20 的战斗配置。巡崖机在宽岩台横扫并沿台面冲到另一侧。侧壁的实台和上方吊点给玩家换面的机会。二阶段移位后瞄准脚下砸落，随后的反扫要求抬高站位或退开。预告落点固定，收臂停机时核心可受击。

打倒机体后在岩冠确认胜利，结算本次遭遇的金币。继续走过 Y21、Y22，在 Y23 主动取二段跳。首次挑战可用攀壁与钩索。攻击参数在[巡崖机定义](../../../production/resources/enemies/crown_strider.tres)，位置、支撑与胜利确认点在 [Y20](https://github.com/zhipijun1996/gunman-rush/blob/24e5957206d3e966e7c7a9e98ce4982fb28c2a8b/production/rooms/world/Y20.json)。
