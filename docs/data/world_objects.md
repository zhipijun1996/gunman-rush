# 机关、危险与交互对象

对象通过外形、预告、运动和反馈让玩家理解功能。数值取实际 Resource／配置；各具体对象需要时在本页对应条目完善，不另复制通用伤害、奖励或保存规则。

| 对象 | 玩家感知与交互 |
| --- | --- |
| 尖刺、锯轮、熔岩 | 危险方向、运动轨迹与伤害范围一致；到达威胁前可观察，恢复点不落在危险中 |
| 周期机关、移动平台 | 起动、停顿、转向与可站面清楚；相邻动作有可执行的时机和落点 |
| 开关、门与压力板 | 触发条件、状态改变和影响目标可辨认；返回后保持已声明的开启／关闭状态 |
| 钩索锚、活果与可借用目标 | 与装饰可区分，提示可用方向和有效距离；失败／取消有反馈，不暗中授予能力 |
| 补给、宝箱与商店 | 说明恢复、购买或领奖的实际收益；重复交互、返回和失败恢复不重复发放 |
| 段起点与出口 | 起点安全可观察，出口去向和准入要求清楚，主路不依赖未来能力 |

具体地区组合见 [平原](../bible/regions/windchime_plains.md) 和 [森林](../bible/regions/thorn_forest.md)。机关与敌人一起改变玩家的站位、观察与路线选择，不能以遮住唯一出口制造必损血局面。工程位置和验证见 [模块导航](../project/module_map.md)。
