# 平原敌人

平原敌人让玩家练习观察预告、离开攻击路线和用反冲修正落点。主路以基础跳跃与当前武器可应对，遵守 [平原圣经](../../bible/regions/windchime_plains.md)。本页覆盖基础物种；冲锋怪的完整规范见 [平原冲锋怪](plains_charger.md)。

地面怪以实际脚底支撑约束走位：平台边缘转向，乘载台时跟随载台位移再执行自身行动，不能悬空或自行走落。当前平原灰盒普通弱怪9生命、中等怪14生命，对应基础枪5伤害的两枪与三枪；数值归各房遭遇配置，Boss独立。

## 行为与反制

| 物种 | 玩家能观察到的行为 | 应对与出手机会 | 数值配置 |
| --- | --- | --- | --- |
| 巡逻体 | 在出生地附近往返，以身体接触形成路线压力，没有主动远程招式 | 观察往返空隙，跳过、绕行或先清除 | [patrol_drone](../../../resources/enemies/patrol_drone.tres) |
| 俯冲体 | 在巢区二维巡飞，横纵均有明显位移；较宽视野内主动预告，锁定玩家当时的实际位置与冲线，出手后直接冲向该位置，冲程足以到达锁定点，随后返回巢点，不在途中持续追人转弯 | 预告后离开冲线，利用冲过与回巢间隙反击 | [plains_diver](../../../resources/enemies/plains_diver.tres) |
| 跃击体 | 锁定巡逻范围内的落点，以弧线跃出并回到原活动区 | 看清起跳和落点，换层或让开落区，落定与回程时攻击 | [plains_hopper](../../../resources/enemies/plains_hopper.tres) |
| 单发哨兵 | 定点预告，朝承诺方向发出弹体，再恢复 | 用实体遮挡、跳跃或反冲离开射线，恢复期接近 | [plains_sentry](../../../resources/enemies/plains_sentry.tres) |
| 飞羽铃哨 | 飞翼与悬挂三铃明确表达悬空身份；悬停预告后向承诺方向发出三枚扇形弹 | 看清扇面、换层或利用遮挡，收势期反击 | [plains_fan_sentry](../../../resources/enemies/plains_fan_sentry.tres) |
| 行枝铃哨 | 保留原木根、骨白披羽、青绿披布与三铃美术；在地面巡行，停步预告并发出同样的三枚扇形弹，收势后继续走位；平台边缘转向 | 避开扇面，在收势与巡行时接近；不能依靠它走落平台消除威胁 | [plains_ground_fan_sentry](../../../resources/enemies/plains_ground_fan_sentry.tres) |
| 浮铃芽 | 苔绿叶翼与旧黄铜铃腹，在固定高度附近轻轻悬浮；无弹幕、无冲锋、无接触伤害 | 作为基础枪空中命中续枪的稳定目标；两枪消散后在原位重新凝聚，不掉金币、不提供共鸣 | [chime_target](../../../resources/enemies/chime_target.tres) |
| 根铃 | 对站在同层实体地面上的玩家标记固定落区；预告后地面短促脉冲，不追随已经离开的玩家 | 离开标记或跳起；预告期造成真实生命伤害可打断，打在护甲上不算。没有合适支撑时不隔空生成地面攻击 | [plains_root_bell](../../../resources/enemies/plains_root_bell.tres) |

封场波次的入场预警结束后不再把玩家出生点当永久免战位置；战斗必须由主动威胁形成换位压力。俯冲、冲锋提高追击频率和速度，同时保留可读前摇与锁定后的躲避机会，参数归对应Definition。

冲锋与俯冲的索敌范围按怪物当前身体位置计算，约半个基准画幅，出生位置只用于巡逻／返回；不因旧出生点仍接近玩家而远距离发动。俯冲、跃击和哨兵先确认视线与可交战距离，预告失去目标可收招；俯冲与跃击回程受实体地形限制，不能用瞬移穿过障碍。根铃是普通敌人，与森林 Boss 根铃守卫分别设计。

浮铃芽用于P10的三段射击攀升，正常镜头采用双轴范围跟随。先击中靶子恢复空弹，再向下射击续升；失手后可回平台等待重凝，不会因清空靶子而断路。暂停冻结重凝；切房、重生和读档按原出生点恢复，不沿用旧飞怪的游走位置。浮铃芽消散成碎光而非尸体；其余敌人仍遵守实际支撑上的尸体规则。

## 表现

美术以PR142的现行平原为参照：`art/world-art-v2` 的 `windchime_plains_v2` 背景与 `assets/plains_v07` 建筑／道具共同约束材质、色光和细节密度。九类普通怪与两位Boss必须统一画风，体型可按威胁和轮廓重新适配，不沿用旧素材尺寸作为设计限制。显示尺寸与实际碰撞分别核对。

用户已明确认可B/C一批的造型，当前问题是怪物颜色与背景容易混淆。以该批形体、细节、像素画法和阶段身份为保留基线；不再因辨识度问题替换物种、重生成形体或套用粗像素风。当前B/C静态造型与显示分离方向已获用户批准。原扎根扇射造型归行枝铃哨；飞羽铃哨按用户要求重新绘制飞行动物体态，沿用同族材质色谱，禁止用地面站姿表达悬飞。两者分别维护完整状态动画，攻击时序由AI拥有。

先在相同原图、尺寸、位置和正式相机下校准前后景的明暗关系，核对环境光、阴影与背景受光方式。亮背景前保持轮廓，暗背景前保护主体中间亮度和局部受光面；避免彩色光圈、粗描边或整只发白。怪物身体采用自明材质保持原色，不被环境阴影再次压暗；地形、建筑与背景继续受环境光影响。发光部位才配置局部光，避免全身光圈及多怪叠灯；在正式房间同时检查身体、攻击预警和受击闪光。

辨识度同时依靠轮廓、明暗层次和少量功能焦点，在亮天空、草沿和暗室木墙前判断，不用整套高饱和对比色或统一灰暗滤镜替代设计。

当前制作范围包括待机、移动、准备／攻击／收势、受伤与死亡等完整动作。定点物种不为展示移动动画而擅自新增行走AI；巡逻体仍按接触伤害行为处理，不新增主动招式。旧版及错误基线重绘不作为新设计母版；被替代资产与无消费者实现删除，历史由Git保留。

动画的连续性必须在真实移动、攻击和正常速度战斗中检查，定点轮播只能用于查帧。移动、待机、Boss的前摇／攻击／收招及死亡均需要足够的过渡姿势，长恢复期先完成收势再保持稳定末姿，不能将少量姿势均匀拉长为幻灯片，不以提高视频帧率冒充动作补帧。图集逐帧核对外轮廓、腿间与附件孔隙，不能残留灰白底色。空中死亡时立即停止活体攻击和悬停，身体沿重力下坠，接触真实支撑后才播放落地与终态；不能在原空中位置播完整落地死亡。

遵守 [Visual Bible](../../bible/visual_bible.md)：移动、准备、出手、收势、受伤和死亡保持同一形体与朝向。俯冲突出指向与速度变化，跃击突出起跳和落点，哨兵突出发射方向；根铃的地面标记必须与实际脉冲范围对应。

预告声、真实命中和死亡声可分辨，提示依附身体或真实落区。威胁结束后标记与声音同步退出；取消、死亡或回退不能留下延迟攻击。通用伤害与恢复见 [伤害合同](../../bible/damage_and_respawn.md)。

冲锋沿预告方向推进，不受普通巡逻半径截断；接触真实墙体或无支撑边缘提前收势。地面巡逻在每一步检查真实脚底支撑，平台边缘提前转向；不得按固定巡逻半径走入空气。出生以碰撞脚底贴合所属平台，表现继续使用脚底锚点，不额外悬浮。跃击锁定有支撑的同层落点，保留真实跳跃弧线；飞行怪不受地面探针限制。
