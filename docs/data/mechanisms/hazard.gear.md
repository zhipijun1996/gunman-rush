# 移动齿轮

直线模式沿中心两侧的半程移动，圆弧模式绕可见支点在两个角度之间摆动。两端可独立于移动时长停顿。齿轮通过 `drive_id` 共享运动所有者的时间，也可用自己的时钟。暂停时齿面仍按真实位置造成接触伤害。
