# G13 周期发射口

固定、追踪后锁定和手动拨档共用预告及冷却。手动喷嘴的真实朝向同时驱动射击和全宽喷流。余烬弹采用登记的落弹资源，只有合格承托顶面可留下跟随承托面的短时火池。
