# 伸缩刺

尖刺从根部沿面法向伸缩，可周期启停或按信号切换目标。预告时根部发亮；伸出、外露和缩回按真实露出深度裁切危险体。时停保留当时的露出形态和接触危险。

针床和夹座沿固定边排列，预告亮点按伸出前的实际进度依次点亮。危险针面使用当前支撑材质的尖刺原画，随四种朝向和实际行程裁切。
