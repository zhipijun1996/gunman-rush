# 危险区域

持续危险直接使用角色接触；周期模式交替显示安全间歇、预告与完整危险。伤害、暴露间隔和避害罩资格来自[环境危险档案](../../../production/config/environment_hazards.json)。来源按当前房间与稳定实例绑定，覆罩仅暂停符合资格的暴露。

槽口布置在危险矩形内。安全期保留阵列和边界，预告时槽口亮起并冒出短流，危险期出现整幅热流或雾柱。边缘的源标识与绑定的避害罩呼应。
