# 共轴运动驱动

轮轴持有角相位、旋转方向与统一时钟。每个踏台按自身稳定 ID 对应的偏角从同一时钟采样，保持水平。信号输入只连接轮轴，单个平台上的合法时间附魔也解析到轮轴。
