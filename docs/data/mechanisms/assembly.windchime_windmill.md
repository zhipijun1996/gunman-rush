# P01 风车渡台

踏台保持水平，按各自偏角围绕同一轮轴公转。数量由互异偏角列表确定。射铃启停保留统一相位；命中可时控成员时附魔解析到驱动。调整半径、大小或偏角后应验证每个踏台完整回转包络及角色离面路线。

轮轴的闭合轮壳包住青铜齿轮，带铜边的镂空辐臂从轴芯接到每块水平踏台的铰销。辐臂与轮芯一起转到驱动的实际角度，停转时留在该角度。[轮芯原图](../../../production/assets/plains_v07/native/mill_gear.png) · [绘制入口](../../../production/game/presentation/world/carrier_hardware.gd)
