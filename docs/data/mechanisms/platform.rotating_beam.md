# G08 转向梁与旋转指针

射击轴心可切换双姿态或切至下一档。连续指针按转速运行；承重梁按玩家真实支撑点左右倾斜；踩压翻面板经预告露出刺面。轴心、安全实体、刺面与承载都读取当前实际角度。

独立轴心持有角度和时钟。双姿态、连续和多档梁可把 `drive_id` 指向另一根相同模式的独立梁。主轴和从动梁先一起检查本次扫掠，全部安全后再同步转角。连续梁的 `set_active` 与离散梁的 `toggle`、`set_pose` 交给主轴受理。P02 与 P04 展开后的梁由预组驱动，同一射击的时间附魔只作用一次。

承重与踩压翻面独立采样正式顶面。时停或受阻时保留当前角度和危险面。挑战复位按配置恢复初始姿态。

梁面和端帽取自房间区域。工城为三角铰架，森林为双弦束根，砌筑区开浅拱洞，绳架区用交叉拉索。分档刻度固定在轴座，偏载灯随真实负载换边；翻面尖齿随实际梁角转动。
