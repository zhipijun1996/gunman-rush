# G20 周期冲压机

压头依次经过上位停留、预告、下压、下位停留和回升。顶面运输乘员，底部齿带在静止和运动中沿正式危险通道受理伤害。

启停、附魔缩放与安全等待保留当前阶段进度；普通侧面和乘客受挤时保持上一安全位置。

导套固定在行程起点，伸缩杆追随压头。压头正面用区域材质，左右端为本区压肩，预告灯位于安全面，齿尖贴合实际下表面的危险深度。
