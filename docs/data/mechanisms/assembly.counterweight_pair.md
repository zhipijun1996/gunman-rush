# G12 配重双台

A 或 B 单侧承载时该侧下降，另一侧上升。两侧都空时按归位速率回到初始共享进度，两边同时受载时保留进度。上端点、行程和尺寸可以分别编辑；任一成员下一步受阻时整组等待。

两端封闭滑轮共用一根桁架，吊链垂到各自台面的轴销。吊链逐节绕过滑轮，绞盘随实际配重进度收放。铜缘、铆接横梁和绞盘使用现有原生纹理。[绞盘图集与来源](../../../production/assets/plains_v07/manifest.json) · [绘制入口](../../../production/game/presentation/world/carrier_hardware.gd)
