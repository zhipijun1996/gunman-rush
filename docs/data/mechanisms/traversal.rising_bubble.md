# 升浮气泡

- **玩法**：接触待发气泡后被包裹，随气泡竖直上升；按现有跳跃键破泡，立即接回普通空中控制。气泡到达顶端或接触上方实体后破裂，稍后在原位再生。
- **变化**：泡体大小、上浮速度、上升距离和再生间隔；实际路线由起点向上派生。
- **恢复**：破泡释放、动作次数和冷却分别沿正式角色规则；当前挑战复位后恢复原位待发形态。
