# 捷径门

给捷径门指定本房行动 ID、闭合挡板和开通后的落脚台。行动收据驱动门与碰撞；制作时从两侧检查未开启及已开启状态。

## 区域外观

石门的嵌石取地形材质，承重门框、横箍和锁座取房间区域材质。金属翻盖和开启后的台阶也读取区域构件；开启后的通路与门体终态对应。
