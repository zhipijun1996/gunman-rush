# 定点避害罩

射击中心受击钮撑起保护圆。完整身体在圆内时，绑定的热浪或排放雾暂停暴露。临近到期闪烁，冷却后可再激活；重叠护罩共享保护资格。编辑实例时须指向本房同分区、档案允许局部避害的危险源。
