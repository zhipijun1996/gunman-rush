# 告示

把文字和位置交给房间，标牌根据附近地形确定落脚面和交互位置。靠近并交互后显示本文字，再次交互或取消可关闭并恢复控制。摆放时给玩家预留停留空间。

## 区域外观

告示根据下方可承托的地形落地。立柱、边框与顶饰跟随房间区域，浅色纸面和笔画标识阅读位置。
