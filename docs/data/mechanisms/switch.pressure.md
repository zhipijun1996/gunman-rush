# 压力踏板

玩家实际站到顶面时亮起。可选用落稳并登记的货箱或重物压板；最后一个来源离开后按配置保持触发。板面表达当前承压，边沿灯表达含保持时间的输出，线路显示等待目标受理的意图。

受压时踏面向下压入承座，离板后踏面回弹，边沿的四格指示随保持时间递减。底座和两侧的轴卡读取当前区域材质。
