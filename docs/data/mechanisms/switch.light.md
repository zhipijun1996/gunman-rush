# G33 感光花盘

花盘读取所选灯台、灯虫和装备灯的照度。连续达标后输出开启，连续失光超过保持时间后输出关闭。中心亮度表示当前照度，花瓣表示受光进度，外圈提示目标仍在等待。灯源的整条潜在路线和可控实体遮挡参与控制环路校验。装备灯须在正式休息站装配，其范围取自[灯光配置](../../../production/config/equipment_lamp.json)。
