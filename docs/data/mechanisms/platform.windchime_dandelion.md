# P06 蒲公英浮台

沿局部路径漂移，有存活玩家真正踩在顶面时叠加下沉，离台后逐步回到漂移路线高度。路径和升沉消费一份缩放时间；暂停仍保留真实承载，受阻的一步保持当前偏移和时钟。

真实承载面位于乳白绒冠顶沿。区域枝叶托在绒冠下方，随承重下弯，露出赭色悬种。顶沿、两端与中央绒簇可按平台宽度独立拼接。[原生绒冠](../../../production/assets/mechanisms/carriers/dandelion_canopy.png) · [素材来源与裁切记录](../../../art/mechanisms/dandelion/provenance.json)
