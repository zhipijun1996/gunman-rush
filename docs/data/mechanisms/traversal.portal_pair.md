# 同房折跃门

- **玩法**：从门面正面进入，立即从同房另一端的门面移出；两端双向通行。出口朝向决定速度的转向，传送瞬间保留原速度大小，动作次数沿原状态接续。
- **变化**：两端位置、各自朝向、门口尺寸、出口净距和初始启用；可通过现有开关启停。
- **恢复**：出口空间可行时完成传送；离开出口完整感应范围后可再次进入。挑战复位恢复初态，房间通路按实际折跃边验证能力与资格。
