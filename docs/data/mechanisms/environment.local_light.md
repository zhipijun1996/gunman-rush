# G27 局部灯台与引路灯虫

固定灯台和移动灯虫按同一距离衰减、实体遮挡和最大值叠加规则供暗区和花盘采样。灯虫模式的灯囊固定在起点，可见圆壳对应真实射击部位。启用且待发时射击后沿局部路线前进，各路点可停留，末端可折返或停靠。停用时熄灭并保持位置与剩余停留。本条目的时钟随当前挑战推进。
