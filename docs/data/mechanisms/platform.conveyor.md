# 传送带

- **玩法**：地面带沿水平方向输送真实站立的玩家；墙面带在玩家以 W 实际附墙时向上或向下输送。实体位置固定，带面的纹理显示运动方向。
- **变化**：地面／墙面、尺寸、速度、墙面接触侧与开关控制；玩家可行走、起跳、墙跳或主动离开相应表面。
- **恢复**：启停按本段规则复位；输送只在正式承载或合格附墙接触期间存在，离开当步解除关联，动作恢复由正式接触规则结算。

输送带由区域面板、连续履片、端轮和中间托辊组成，履片沿指定有效面运行。停转时轮组与带面保留暗色实体。
