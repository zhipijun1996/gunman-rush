# 钩索锚点

放置真实钩索目标。`hang_enabled` 决定锚点可否悬挂。`material_family` 默认为 `inherit`，根据功能从区域清单读取 `bounce_texture` 或 `hang_texture`。缺省使用机械外观，实例可显式选择机械或根系外观。贴图共用相同的钩索判定。能力授予由上层进程持有。
