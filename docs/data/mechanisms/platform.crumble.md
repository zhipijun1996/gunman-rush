# 坍塌与显隐台

顶面踩踏与合格附墙启动一次开裂倒计时。周期型独立循环；起跳型用正式受理的跳跃交换目标形态。淡轮廓的位置保留恢复提示，完整身体占据待生成位置时保持空缺。

实体板由带卡扣的区域材质板节拼成，钩纹标出可附墙侧。开裂时缝隙延伸，缺失状态露出卡槽轮廓，复原时板节从预告轮廓中显出。
