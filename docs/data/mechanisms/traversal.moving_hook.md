# 移动钩点

- **玩法**：循环钩点沿可见路线运动，支持弹跳或停留；滑索钩头停在上站，玩家用 H 挂载后沿索滑向下站。收缩钩藤初始伸出，玩家钩中并挂载后沿固定轴向根部收缩，到内端停留；离钩后等待片刻再伸回原位。
- **变化**：循环路径、停靠与初相位，滑索下站与速度，或钩藤轴向、伸出长度、内端位置、启动预告和收缩速度；挂载结束后的等待、返程速度及再次可钩的冷却可分别配置。一次合法钩索命中提交一次既有动作恢复。
- **恢复**：沿正式钩索流程接入、跳离与取消；挑战复位先解除关联，再执行安全恢复。**时控：目标路径运动、停靠、启动预告与返程等待；再次可钩的资格冷却使用正式物理时钟。**

循环轨与滑索以金属绳、端座和轮轴标出行程；滑索轮随实际沿线位移转动。收缩钩藤显示根座、分枝、真实长度和启动预告。
