# 安全恢复点

以范围和安全落点描述挑战恢复位置。房间保存该实例；重生或失败返回的应用层在选择恢复点时读取范围并校验落脚。

C12 只在玩家实际进入本分区的范围后登记候选点。恢复坐标须有双脚稳定支撑和完整身体净空；登记时还沿进入侧扫掠身体，防止在封闭门后记录落点。离开分区会清除旧记录。环境失败通过正式恢复接口结束当前动作、复位本分区尝试级机关，生命、耐力、冷却和空中动作次数沿用当刻值，正常落地时再处理着地资源。
