# G17 诱敌声源与响叶地毯

射中声源可引来同房听觉范围内的地面巡逻敌人。地毯模式只在真实脚底第一次踏上顶面时发声，声源取脚底接触点；站在上面直到冷却结束仍属于原来的接触。外部脉冲在地毯顶面中心发声。巡逻者先检查地面支撑与路径障碍，抵达合法调查站位后才开始停留。受击、死亡或发现可交战的玩家会结束调查。

射击声源的琥珀吊坠对齐受击点，地毯用连续的枯叶和枝条标出可踩的顶面。区域可通过 `charm_texture` 和 `mat_texture` 换材质。
