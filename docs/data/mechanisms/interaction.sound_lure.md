# G17 诱敌声源与响叶地毯

射中声源可引来同房听觉范围内的地面巡逻敌人。地毯模式只在真实脚底第一次踏上顶面时发声，声源取脚底接触点；站在上面直到冷却结束仍属于原来的接触。外部脉冲在地毯顶面中心发声。巡逻者先检查地面支撑与路径障碍，抵达合法调查站位后才开始停留。受击、死亡或发现可交战的玩家会结束调查。

响器的发声部位与正式受击点对齐。地毯用低矮、连续的材料标出承载顶面。荆棘森林使用琥珀吊坠和枯叶，其他区域从当地灯具和挂件取材。区域可用 `bank_atlas` 配置整套外观，或用 `charm_texture`、`mat_texture` 单独指定两种模式。 [区域原图与裁切](../../../art/mechanisms/regional-perception/provenance.json)
