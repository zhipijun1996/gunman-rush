# C16 风铃与升降台

一次放置生成独立的 bell 和 carrier，默认暂停。射击风铃启动载台，再次射击在原相位暂停。初始运行同时设置两件的状态。作者可编辑起点偏移、局部路线、端点停靠和周期。第一版已经保存的 switch 与 carrier 继续以原身份及参数加载。

轨道、两端定位块和台身采用房间的区域材料。两端定位块位于真实路线的起止点，折线路径的末段也有落点标记。
