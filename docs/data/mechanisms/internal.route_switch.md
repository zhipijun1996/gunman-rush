# G14/P02 互斥切换驱动

控制铃的两个状态分别请求 A、B 组激活。预告后统一检查两组，全部目标可受理时再切换。同步翻板共用一次预告、一次转动时钟及完整组扫掠。

占用等待期间保持原布局。待有限动作完成后重新待发，重复射击沿当前请求处理。
