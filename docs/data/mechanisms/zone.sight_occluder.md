# G25 遮视芦苇

植物轮廓标出视线遮挡矩形。双方视线在矩形内部穿过正长度时，启用的芦苇阻止敌人视觉发现目标。关闭后植丛收拢，视觉查询立即读取新的开关状态。角色、飞行弹丸和伤害继续沿正式通道运行。

启用时，遮视物从根部立到配置范围上缘；停用时只剩短桩、残叶或收起的帘脚。森林保留长穗芦苇，蕈灯地穴用菌伞，工城使用管簇。区域可用 `bank_atlas` 配置整套外观，或分别指定 `tall_texture`、`cut_texture`。 [区域原图与裁切](../../../art/mechanisms/regional-perception/provenance.json)
