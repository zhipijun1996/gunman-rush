# 固定钩索点

放置共享钩点的便捷定义。一个房间可放置多个独立位置；移动点位后应复验射向、到达的落脚面和离钩恢复。

固定点实例化可悬挂的[钩索锚点](traversal.hook.md)，共用所在区域的悬挂贴图。
