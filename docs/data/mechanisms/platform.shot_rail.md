# G03 受击滑轨台

瞄准台端金属受力片发射。首次合法命中按实际入射方向与相邻轨段的点积选站；并列方向、端点外侧、移动中及停稳期间保持本轮目标。行进和停稳共用时控；停在原位时仍是实体承载面。
