# 世界行动宿主

给可交互对象绑定本房行动 ID、作用半径与所属 section。配置 `action_owner_id` 时，由 G16 的射击锁扣启动这次行动。独立宿主使用接近交互。宿主读取行动的资格和收据，开箱等庆祝效果在提交成功后才播放。

## 区域外观

可直接交互的世界行动在底座上显示区域支座和顶饰；由预组代办的行动仍通过该组的可见机关呈现。
