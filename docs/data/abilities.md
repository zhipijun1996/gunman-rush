# 移动能力与空中恢复

H 钩索、W 墙面移动、D 额外跳跃及 Q 反冲保护为永久能力，取得沿 [世界推进](../bible/world_progression.md)，资源沿 [攻击资源](../bible/combat_and_recharge.md)。未授予的能力不能靠命中或读档获得。

| 能力 | 行为与恢复 |
| --- | --- |
| H | 全角度瞄准，保持后松开发射；合法命中后拉近，再按目标踢跳或停留。钩头确认命中合法目标时立即恢复动作次数，本体抵达不再重复恢复；有限离开保护只覆盖该目标身体接触 |
| W | 本体首次有效贴上可攀墙即恢复动作资源；同墙停留或射击取消姿态后重贴不重复恢复，须真实离墙达到配置间隔或换墙。成功蹬墙仍恢复已拥有的H／D，但不再次补弹或重给Q资格 |
| D | 使用已授予的额外空中跳跃；合法恢复只恢复本次飞行中的额外资格，不赠送地面第一跳、速度或新输入 |

已拥有W时，所有实体地形的侧墙均可攀附，包括普通墙、台阶侧面及移动实体；不再按墙体标签或颜色区分。限制攀附的地段使用可见墙刺；墙刺沿实体危险规则造成伤害，Q不能抵挡。

## Q 反冲保护【已确认；新世界运行已接入】

仅实际反冲位移期保护怪物与光幕，不穿实体墙，不屏蔽荆棘、齿轮、熔岩或毒水。触发必须同时满足拥有Q、合法反冲、恢复资格及2秒冷却。真实落地、H合法命中和首次有效W贴墙给予恢复资格；空中单纯等待不恢复，获得资格也不清除剩余冷却。冷却从触发起按有效游戏时间计，暂停不推进，换房/交通/菜单/换枪不清除。位移结束、取消或实体阻挡立即结束保护，三连或激光分段不重复触发。

实施解释：入口自动跳台实际接地可满足资格但不清冷却；光幕内位移结束按普通地形失败回进入侧。Q不改基础反冲参数或普通射击间隔，不以全局无敌实现。

Q的关卡门槛应接在可稳定等待的墙面、停留钩点或安全平台之后，使用出发后的第一次反冲。连续空中动作不在中途加入必须等待冷却的Q门槛。HUD沿现有能力图标风格显示可用、冷却进度与生效状态；角色在实际保护窗口显示短促护光和反冲轨迹，结束立即收束，不把尾迹当作延长无敌。

## 合法恢复事件

有效接地、H钩头确认命中合法目标和首次有效W贴墙，补满当前空中弹药上限并恢复已拥有的H／D及Q触发资格。持续挂在同一钩点或贴在同一墙上不逐帧补给，任何实体墙的有效攀附均可补给；钩索未命中或命中非钩索目标不补给，已确认命中后的拉近失败不撤销恢复。恢复不授予未拥有能力，不补时间能量或共鸣，也不清除射击与Q冷却。

成功墙跳与空中发射弹体对敌人提交真实伤害，仍可恢复已授予的H／D；该通用恢复接口不补弹、不恢复Q资格。命中补弹另按武器攻击包政策结算，弹体发出与伤害提交时都需符合空中条件。空发、阻挡、目标消失、暂停、换枪、受伤取消、旧角色回调和重复命中不能补资格；各类收据分别去重，恢复不打断当前上升或反冲。

## 表现与控制

钩点使用两种稳定轮廓：开口三角弹簧扣仅拉近后弹跳，闭口承托环允许悬挂等待；不能只靠颜色区分。以旧钟铜铁与根系包覆两组共享材质覆盖多区，同类行为在不同区域保持轮廓一致，根系款仍保留可辨认的钟机构件。命中有局部受力摆动与短亮点，悬挂时承托环保持低亮，不以整圈霓虹描边替代材质。

钩索辅助线与实际钩头探测一致，落空有快速回收；踢跳方向由来侧决定，结束时改瞄准不暗改已承诺动作。额外跳跃、钩索剩余与恢复反馈清楚，取消立即释放旧保护和未完成请求。
