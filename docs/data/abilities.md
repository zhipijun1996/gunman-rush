# 移动能力与空中恢复

H 钩索、W 墙面移动、D 额外跳跃是独立能力，正式授予沿 [运行路线](../bible/run_and_routes.md)，资源沿 [攻击资源](../bible/combat_and_recharge.md)。未授予的能力不能靠命中或读档获得。

| 能力 | 行为与恢复 |
| --- | --- |
| H | 全角度瞄准，保持后松开发射；合法命中后拉近、踢跳并产生有限离开保护，仅覆盖该目标身体接触。空中发射消耗资格，接地及合法恢复事件恢复，不叠加 |
| W | 贴墙本身不恢复能力；成功接受蹬墙动作才算恢复事件，重新蹬墙仍需真实离墙／重贴 |
| D | 使用已授予的额外空中跳跃；合法恢复只恢复本次飞行中的额外资格，不赠送地面第一跳、速度或新输入 |

## 合法恢复事件

有效接地、成功墙跳、钩索拉近后完成踢跳、空中发射弹体对敌人提交真实伤害，按当前能力政策恢复已授予资格。弹体发出和命中回调时都需符合空中条件；墙、护甲或非敌人接触不算。

空发、阻挡、目标消失、暂停、换枪、受伤取消、旧角色回调和重复命中不能补资格。连续弹体的移动资格恢复与攻击包弹药返还分别去重，恢复不自动补弹药，也不打断当前上升或反冲。

## 表现与控制

钩索辅助线与实际钩头探测一致，落空有快速回收；踢跳方向由来侧决定，结束时改瞄准不暗改已承诺动作。额外跳跃、钩索剩余与恢复反馈清楚，取消立即释放旧保护和未完成请求。

参数取 [traversal配置](../../resources/player/traversal.tres) 与实际动作资源；具体按钮只在 [输入合同](../bible/controls_contract.md) 维护。代码和验证见 [模块导航](../project/module_map.md)。
