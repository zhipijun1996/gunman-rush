# 声音设计

声音帮助玩家分辨动作、威胁、命中、状态变化和空间氛围。BGM 使用用户提供版本；音效和环境声采用当前选定素材，许可与原始来源随资产记录保存。

| 事件 | 可感知要求 |
| --- | --- |
| 移动、跳跃、落地 | 表达起动、接触和重量，节奏与真实动作一致 |
| 射击、钩索、能力 | 起手、发出、命中／落空、取消和结束可区分；连续动作中不叠成噪声 |
| 敌人／Boss预告 | 对应实际招式、方向和节奏，在命中音中仍清楚 |
| 命中、装甲、受伤、死亡 | 材质和结果可区分，同一次事件不重复播放，致死与受伤衔接自然 |
| 环境动态与音乐 | 衬托地区材料、生态和空间，避开关键操作反馈；场景切换和暂停行为一致 |

修钟演出的齿轮咬合与钟声通过明确的演出音效入口，在暂停角色操作期间仍播放；复用当前世界的有界音源池及退出清理。普通战斗音效不借此绕过暂停规则。P24波次开始切入平原Boss曲，清场恢复探索曲，死亡与切房沿既有音乐生命周期恢复。

具体对象的发声时机与表现归该对象规范。音量、并发、衰减、当前候选选择与事件映射由 `config/audio_director/` 及实际音频资源维护。实现与试听入口见 [模块导航](../project/module_map.md)，许可或历史对照仅在具体任务需要时读取 evidence。
