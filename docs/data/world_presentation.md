# 场景美术表现

本页管理只负责可见外观的场景要素：无碰撞布景、建筑饰面、附着前景、景深构件和世界事实驱动的视觉表现。它们属于 `presentation` 分类，不属于机关库；即使会播放动画或跟随世界状态显隐，也不因此成为机关。合屏、尺度、附着和明暗规则归[Visual Bible](../bible/visual_bible.md)。

## 放置与资源

从统一关卡目录的“美术表现”分类选择定义，配置位置、宿主、层次与外观参数。独立定义位于[定义目录](../../config/world_elements/definitions/)，以 `library=presentation` 登记并指向本页；编辑器只消费主游戏目录，不再复制一份美术实例清单。当前可放置布景使用 `decor.*` 定义；状态表现与星桥专用表现由服务创建，不出现在普通放置列表。

共用稳定ID、创建、移动、删除和附着关系，保留与其它场景要素相同的编辑操作。贴图没有独立机关进度，不提交开门、伤害、奖励或运动状态。区域／材质换皮遵循[地形与材质](../bible/terrain_materials.md)；机关自带的反馈和皮肤仍由对应[机关定义](world_objects.md)消费，不拆成第二个玩法状态所有者。

## 空间组合与可选复用

先在实际房间中校准地形、平台和建筑的共同画面，再按需提炼同族材质、完整景深或结构组合。区域套件只是待验证的可选组织方式，不是强制生产单位、新的运行时业务库或第二份房间格式。已有组合合同可让实体、饰面、附着物和机关引用各自定义，房间继续持有稳定实例；组合按主要用途归类，成员保留原职责。

入口、桥跨或墙体组合应一起说明连接、尺度、根基、前后遮挡和光源归属，避免把一组独立道具视为完整场所。实际支持的尺寸／方向、接续和镜头覆盖必须经过合屏与移动检查；目录中可放置、组合能展开，不代表该资产族已满足视觉复用要求。生产方法见[godot-room-art](../../.agents/skills/godot-room-art/SKILL.md)，组合身份与实例化仍沿[共同合同](../bible/world_elements.md)。

## 碰撞与交互边界

建筑贴图不自动产生碰撞。可站立建筑由地形／静态结构定义持有实体，建筑饰面通过稳定宿主关系附着；一个建筑组合可以跨分类引用成员，各成员保持自身职责。纯贴图齿轮属于美术表现，造成伤害或受机关控制的齿轮属于机关。背景风动属于表现，施加实际推力的风场属于机关。装饰风铃属于表现，能被攻击并发出联动信号的风铃属于机关。

可破坏隐藏入口由机关拥有破坏条件、状态与碰撞，外观复用地形材质；仅遮蔽入口的草丛或前景贴图仍是表现。类别取决于实际职责，不按图片名字、是否运动或是否可实例化判断。
