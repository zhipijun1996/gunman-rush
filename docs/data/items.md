# 道具与成长数据

道具为本局构筑提供攻击、移动、资源、经济或主动使用的变化，与核心能力授予分开。正式流程和永久成长分别遵守 [奖励构筑](../bible/rewards_and_builds.md) 与 [家园保存](../bible/home_and_save.md)。

## 数据来源

72件道具、16成长和联动的当前身份、效果、等级与候选状态由 `config/item_v5_*.json` 及 ItemCatalogV5 读取。每件对象的具体数值只维护在配置；显示说明应表达玩家实际得到的变化，未启用或条件未明确的条目不能当作正式收益。

同名道具的库存实例、成长与装备容量按当前规则处理。局内金币、音符和家园永久权益分开，购买、拾取、切换、回退和读档都不得重复授予同一收益。

## 体验与表现

道具图标、名称、等级和效果相符，主动／被动与触发条件可区分。装备或升级后玩家能从动作、伤害、资源或反馈中识别收益；协同说明只列当前有效组合。

P17 的满速蓄力与候选阶梯仍待选择；G19 的 Boss 资格为明确候选。已取消和未明确条件的联动保持禁用，不从整理文档推定新设计。

逐件规则仍需随实际功能任务收敛，当前配置编辑方法见 [道具配置](../project/item_authoring.md)，实现与验证见 [模块导航](../project/module_map.md)。
