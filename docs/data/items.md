# 《失序之钟》装备系统

装备是永久收集、以负荷限制装配的角色构筑系统。玩家通过装备调整武器、反冲、钩索、空中瞄准、时间控制、生命防护、召唤物与探索能力，在休息区配置组合，在装备强化NPC处支付金币提升可强化装备的等级。

## 1. 系统规则

### 1.1 装备规模与装配

| 项目 | 规则 |
|---|---|
| 装备总数 | 60件，包含发光灯、抗毒滤芯2件环境工具 |
| 可强化装备 | 14件，等级为Lv1、Lv2、Lv3 |
| 固定效果装备 | 46件，等级为Lv1 |
| 单件负荷 | 1–5；同一装备各等级负荷相同 |
| 负荷容量 | 初始8，通过永久成长提高至14 |
| 装卸地点 | 休息区 |
| 时间附魔互斥组 | 103逐时弹芯、104缓时弹芯、105零刻弹芯，同一时间至多装备1件 |

装配总负荷不得超过当前容量。被动装备按各自条件生效；主动装备通过主动装备动作键使用。装备组合按单件效果和本文的叠加规则结算，不产生额外套装奖励。

二段跳、攀墙跳、钩索、保护冲刺及武器主动技能由各自能力系统解锁。装备作用于已拥有的能力，不授予基础能力或提升负荷容量。

### 1.2 获取与身份

每件装备具有唯一永久ID，获得后永久持有。同一件装备的等级与外观不增加独立装备数量；装备ID使用字符串，与名称和等级分别保存。完整目录见第4节。

每件装备配置一个唯一可达的获取来源；具体房间、领取条件和来源类型由世界奖励配置定义。领取装备时同时记录所有权与来源领取状态，回访及读档保持已领取状态。

## 2. 共用机制

### 2.1 资源与腾空周期

| 资源 | 用途 | 结算规则 |
|---|---|---|
| 时间能量 | 空中武器与钩索瞄准 | 基础容量100，瞄准每个有效真实秒消耗45；B04降低消耗，B06返还能量；每次腾空的瞄准总时长上限为2秒 |
| 共鸣 | 武器主动技、主动装备、回血、G04救命 | 主攻或钩索攻击包的命中收益分别封顶12；B18、B19、75的收益与基础收益共用对应上限 |
| 动作次数 | 空中弹药、跳跃、钩索等 | 由能力系统管理；时间能量与共鸣的回复不恢复动作次数 |

一次腾空从角色真实离地开始，到角色控制器确认在可站立地面获得稳定支撑时结束。贴墙、钩中敌人或虚影、空中回弹、跨房、换武器、开菜单及读档均保持同一腾空周期。擦边接触不构成稳定落地。

每次腾空使用同一个`air_epoch`记录2秒瞄准预算、B06返还额度与75命中计数。B06和75要求攻击包在该次腾空中发射并命中；落地后命中的弹体不参与下一次腾空计数。75的两次命中可作用于同一敌人，但必须来自两个不同的主攻击包。

### 2.2 伤害与触发

**B为同永久攻击等级下，普通枪未计装备增伤的基础完整普攻伤害。** 装备从武器基础伤害表读取B。装备附伤、持续伤害（DOT）、齿环、连锁、冲击波及全部伴机均以B计算。

武器直接伤害按完整攻击包分配。三连枪一次主攻总伤害为1.5B时，三颗弹各为0.5B；激光同次有限攻击的各伤害段共用该次攻击的完整伤害预算。P08贯穿与83反弹按实际弹体的直接伤害份额计算。

P05与P13的主攻直接增伤采用同类加算：

`主攻直接伤害 = 武器直接伤害 × [1 + P05条件加成0.30 + P13条件加成0.20]`

两者同时满足时为×1.50。P03只作用于已解锁武器主动技的直接伤害，最高×1.28。主攻增伤、主动技增伤与装备附伤分别结算。

每次被接受的主攻请求建立唯一攻击包。三连弹、激光多段、贯穿、反弹及同次回旋刃往返共用该包身份；武器直接伤害按武器自身规则命中，装备触发按以下规则去重：

- B06、B18、75、P31、P09、B24、P29、119等每包最多处理一次合格触发，并遵守装备冷却。多目标命中取最早的合法事件，同帧按稳定目标ID排序。
- 标明“每目标”的范围伤害、标记或时间效果，以“攻击包＋目标＋效果”为单位结算；同目标的多弹或多碰撞形状共用该次触发。
- 命中收益要求对存活、可受伤敌人实际提交正值伤害。墙体、机关、无敌目标、已死敌人、诱饵和钩索虚影不提供共鸣或命中计数。
- 派生伤害不触发装备附伤、返共鸣或时间附魔。归属玩家的真实击杀正常结算金币及84等击杀效果，同一死亡事件结算一次。
- 弹体在发射时快照直接伤害和装备参数。P15在生成时快照B；P14、G19、G05每次攻击读取当前合法B，已发射弹体保持发射快照。
- 内部伤害保留小数或足够精度的定点值，在伤害结算层统一处理；低伤害段不提前截断为0或逐段向上补足为1。

B24持续伤害到期与再次施加发生在同一时刻时，先结算到期的最后一跳，再建立新的3秒周期。其他有限持续伤害同样先结算到期伤害，再结束或替换效果。

### 2.3 时间规则

| 时钟 | 定义 | 适用对象 |
|---|---|---|
| 有效真实时间 | 正常游玩经过的时间；暂停菜单、加载及过场期间冻结 | 腾空2秒瞄准预算、时间能量消耗、回血蓄力、P26的3秒持续与30秒冷却 |
| 世界时间 | 有效真实时间×空中瞄准世界倍率 | 弹体、DOT、伴机运动与攻击、P15寿命、G05受伤无敌、装备内冷却、虚影/标记/风屏寿命、时间附魔到期及105的5秒重施间隔 |
| 目标局部时间 | 世界时间×目标局部倍率 | 目标移动、动画、AI动作、攻击进度与兼容机关运动 |

本文未明确注明“有效真实秒”的秒数均使用世界时间。界面选择与读档保持各计时状态。

世界慢时只在空中瞄准期间生效。基础世界倍率为15%，N01对应12%／10%／8%；满HP且装备P06时为0%。倍率按优先级取一个值。射击、出钩或取消瞄准结束该窗口，已经使用的腾空瞄准时间保持计入预算。

P06使世界倍率为0时，伴机、DOT、敌弹及其他世界模拟停止。时间附魔的到期按世界时间计算；目标自身局部时间为0不冻结该效果的到期计时。时间效果结束后，目标从已保存的动作进度继续运行，攻击前摇、AI状态和Boss阶段保持连续。

## 3. NPC金币强化

### 3.1 强化流程

装备获得时为Lv1。玩家在装备强化NPC处选择已拥有的可强化装备，查看当前效果、下一级效果、金币价格和负荷，支付金币后提升一级。强化只要求装备所有权、可提升的等级和足额金币；未穿戴装备也可强化。

等级依次为Lv1→Lv2→Lv3，各级参数独立取值，升级时使用所达等级的参数。同一装备各等级负荷相同。P03强化已解锁技能的伤害，武器技能的解锁由能力系统负责。

固定效果装备显示“固定效果”，没有强化入口；达到Lv3的可强化装备显示“已强化至最高等级”。

### 3.3 交易结算

一次强化依次核验装备所有权、当前等级和金币，将扣款、升级与永久保存作为一笔完整交易。失败时金币与等级同时恢复；同一交易ID的重复提交只结算一次。报价与当前状态不一致时重新核验。

强化仅更新装备等级及相应参数。当前生命、共鸣、时间能量、临时护盾、救命次数、冷却和腾空周期保持各自状态；提高生命或共鸣上限时只提高容量。满级装备不能继续购买等级，强化不提供降级或退款操作。

## 5. 效果结算

### 5.1 时间附魔

103、104、105在装配层互斥。已装备的时间弹芯通过主动装备键切换开启或关闭，开启状态不额外消耗共鸣；普通射击的弹药消耗和发射冷却按武器规则结算。

附魔适用于玩家主动发射的普通枪械弹丸，包含三连枪子弹。激光、爆炸范围、武器主动技、手里剑/回旋刃、伴机、连锁及DOT不施加附魔。同一攻击包可分别影响多个实际命中的目标，对每个目标只施加一次。

### 5.3 生命、护盾与受伤

玩家最大生命为：

`最大HP =（永久最大HP + B11对应等级加值）× P18倍率`

未装备P18时倍率为1，装备时为2。B11提高生命上限但不回复当前生命，卸下时裁剪超出上限的当前值。P18装卸在真正休息流程内完成：先确认装配和生命上限，再由休息恢复生命。打开装备菜单不构成休息或治疗。

共享临时护盾上限为3点，每点抵消1HP伤害，剩余伤害进入生命结算。B13在真正休息后执行`shield=min(3,max(shield,2))`。G02每累计3次真实HP受伤事件产生1点盾，并将计数清零；已满盾时也清零。单次损失多点HP只计一次事件。

每点护盾保存来源装备身份，按生成先后消耗。卸下B13或G02时，只移除该装备尚未消耗的护盾点。

玩家伤害按以下顺序结算：

1. **强制地形结果：**尖刺、岩浆、坠落等按场景规则处理，装备防护和保护冲刺Q不替代地形处理或滤芯物品门。
2. **弹体空间碰撞：**按实际运动顺序处理87的子弹对消、P16的盾体拦截及99的风屏偏转。已销毁弹体结束后续碰撞；99偏转后的弹体保持敌方归属。
3. **已有保护：**普通受伤无敌、Q保护或P26挡住伤害时结束结算，不消耗P16接触额度、共享盾或G04。
4. **P16接触防护：**P16就绪且玩家本体将受到合格怪物接触伤害时，抵挡该次伤害并进入12秒冷却。盾体单独接触怪物不消耗额度，拦截普通敌弹不触发冷却；冷却期间P16全部保护失效。
5. **共享临时盾：**按剩余伤害扣盾，再计算未被吸收的HP损失。
6. **G04致命保护：**剩余敌方伤害将致死时，检查受击前共鸣是否至少35及本休息周期的可用额度。满足条件则扣35共鸣、保留1HP、消费额度并给予标准受伤无敌；该事件不触发B14或G02。
7. **真实HP受伤：**实际扣除HP后处理B14与G02；本次受伤产生的共鸣不能参与前一步的G04资格判断。

P16的敌弹拦截范围由盾体实际碰撞形状与运动决定。共享盾承伤、P16接触挡伤和G04救命均进入一次标准受击保护；B27只延长符合普通受伤定义的保护窗口。

G05独立结算生命与受伤，不共享玩家的护盾、治疗、救命或受伤收益。钟卫受伤不计入B14或G02。

### 5.4 共鸣回血

玩家按住回血键蓄力，完成时一次扣除共鸣并回复生命。143与144均为固定效果装备，可以同时装备，使用同一个回血动作。

先按是否装备143确定费用与回复量，再应用144的0.65倍蓄力时间：

| 配置 | 装备负荷 | 消耗共鸣 | 蓄力时间（有效真实秒） | 一次回复 |
|---|---:|---:|---:|---:|
| 基础回血 | 0 | 35 | 1.00 | 1HP |
| 143深聚心核 | 3 | 50 | 2.00 | 2HP |
| 144疾聚心核 | 3 | 35 | 0.65 | 1HP |
| 143与144同时装备 | 6 | 50 | 1.30 | 2HP |

开始与完成时均检查缺血、足额共鸣、动作允许回血及治疗许可。完成时将扣款与回复作为同一结算；蓄力中断不扣款、不回复，深聚在完成时一次回复2HP。完成前已被其他来源补满时结束该次回血且不扣款。仅缺1HP也可使用深聚，费用为50共鸣，实际回复1HP；回复量以最大HP为限。

跳跃、攻击、出钩、受伤或提前松开回血键会中断蓄力。无P17时，移动资格由角色基础回血动作规定；装备P17时允许以基础水平速度的40%／55%／70%移动，速度与B28加成相乘。143、144不改变移动速度。暂停菜单、加载和过场冻结蓄力计时；世界慢时及目标局部时间不改变回血所需的有效真实时间。

| 相关装备 | 结算规则 |
|---|---|
| P02共鸣整流器 | 回血费用保持35或50共鸣 |
| P17游鸣聚能体 | 为各回血配置提供相同的移动资格，费用与回复量由回血配置决定 |
| P18暮钟心契 | 禁用普通治疗、地面治疗拾取及所有共鸣回血配置；真正休息回复生命 |
| P15续鸣装配匣 | 只累计回血成功完成时实际扣除的35或50共鸣 |

### 5.5 伴机与召唤

伴机自动搜索射程内、视线合法的目标，攻击受实体墙体阻挡。伴机伤害按B计算，不携带玩家时间附魔、不产生共鸣或装备命中计数；归属玩家的击杀按第2.2节结算。

每台伴机生成后等待完整攻击间隔才进行首次攻击。P14三台小机各自瞄准；P14与G19卸装时移除，重装后从完整攻击间隔开始。P06使世界时间停止时，伴机运动、攻击、P15寿命、G05受伤无敌及召唤冷却同步停止。

**P15续鸣装配匣**

装备期间累计实际已扣除的共鸣，包含武器主动技、主动装备、成功回血与G04救命，按P02折后实际支付额计入。每累计45共鸣生成一台临时无人机，余量保留。未扣款、取消或失败的动作不计消费。

每台P15无人机存在8秒，每1.5秒攻击一次；首次攻击在生成1.5秒后，最多5击、总伤害1.75B。寿命截止与已排定攻击同刻发生时，先结算该次攻击，再移除实体。

最多同时存在2台P15无人机。达到上限时，消费进度最多保存44，不累计待生成队列；一台离场后须有新的实际消费跨过45门槛才生成。消费余量跨房、存档与卸装保留，未装备期间不累计新消费。

**G05永恒钟卫**

| 项目 | 规则 |
|---|---|
| 召唤 | 主动消耗45共鸣，P02生效时为36；成功生成时扣款，生成失败不扣款 |
| 生命 | 固定6HP，独立于玩家生命上限、B11与P18 |
| 存续 | 存活期间持续跟随，生命归零时销毁，无时间寿命 |
| 攻击 | 每1.8秒攻击一次，每击0.75B；首次攻击在成功召唤1.8秒后 |
| 受伤保护 | 每次实际扣血后获得0.5世界秒无敌，B27不延长此窗口 |
| 冷却 | 从成功召唤开始计算12世界秒，钟卫死亡不重新起算 |
| 数量 | 最多1台 |
| 界面 | 显示当前HP／6及召唤冷却 |

钟卫受到实际覆盖自身的敌方近战、弹体及范围攻击伤害，扣血量使用该招式的HP伤害；敌人选目标规则保持不受钟卫影响。尖刺、毒雾、坠落等玩家专属环境判定不作用于钟卫。

钟卫使用非阻挡受伤判定，敌弹命中它后保持飞行方向、敌方归属及贯穿额度，可继续与玩家碰撞。单个敌方攻击包对同一钟卫只结算一次；明确分段的持续攻击按各段身份结算。钟卫不继承玩家的护盾、无敌、治疗、救命或受伤返能效果。

钟卫存在时，召唤请求不扣费、不补血、不替换实体，也不刷新攻击或冷却。钟卫不存在、召唤冷却结束且共鸣足够时，可由玩家再次付费召唤。生命归零后停止发起攻击，已发射弹体按发射快照继续结算。

跨房和普通读档保存钟卫的存在状态、剩余HP、攻击进度、受伤无敌与召唤冷却。真正休息回满仍存活钟卫的6HP，已摧毁或未召出的钟卫保持不存在；打开菜单不治疗。休息保持攻击进度与召唤冷却。玩家死亡或卸下G05时移除钟卫，重新召唤须满足费用与冷却条件。

### 5.6 空间效果与探索

84的虚影为弹跳钩点，最多同时2个，持续2.5秒，第三个替换最早者。有效钩中后消耗该虚影并执行弹跳，不提供悬挂固定。钩中虚影可按基础钩索规则恢复已拥有的动作次数，但保持当前腾空的瞄准预算，不产生共鸣或金币。

89在空中反冲起点生成最多1个诱敌虚影，持续3世界秒，冷却从生成起算6世界秒；冷却中的反冲不重建或延长虚影。它只供支持诱饵的普通敌人新启动瞄准攻击选取，已发射弹体保持原轨迹。虚影不承伤，也不提供钩点。

99风屏沿真实反冲轨迹形成宽16单位的折线带，持续1秒。接触的可拦截敌弹朝远离玩家的一侧偏转30°，速度与敌方归属保持；同一敌弹对同一个风屏响应一次。83、87、99与盾体均按实际碰撞顺序结算。

P39的25%金币加成只作用于击杀奖励，小数余量跨击杀、跨房与保存保留。例如四次基础各1金币的击杀合计获得5金币。

发光灯与抗毒滤芯在实际装备时满足对应物品门。照明参数和可过滤环境由场景配置定义；拥有但未装备不满足门条件，空中瞄准、保护冲刺与时间附魔不替代工具资格。

## 6. 数据与状态保存

### 6.1 装备定义

装备定义包含永久ID、名称、负荷、最高等级、各级参数、NPC强化价格、适用攻击与目标标签、触发时钟、冷却及互斥组。召唤物同时定义存续方式、生命值或寿命、受伤规则、攻击间隔与数量上限。

装备目录、界面说明与运行参数使用同一装备定义。世界奖励配置通过永久ID关联装备及获取来源。距离、射程、半径与宽度均采用游戏世界单位，碰撞依据实际场景几何。

| 状态 | 保存内容 |
