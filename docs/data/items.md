# 道具与成长

道具提供永久所有权下的攻击、移动、资源、经济或主动效果。获得、装备、交易与结束规则见 [奖励构筑](../bible/rewards_and_builds.md)，永久成长见 [家园保存](../bible/home_and_save.md)。本页保留旧实现候选的对象行为与参数来源；除灯与滤芯外48件效果尚未选定，不把旧目录全量晋升。

## 对象与参数来源

| 内容 | 唯一运行数据 |
| --- | --- |
| 物品身份、名称、触发、限制、等级效果与参数 | [items_v5.json](../../config/items_v5.json) |
| 主动物品集合、共享护盾上限、精英资格候选 | [item_v5_runtime.json](../../config/item_v5_runtime.json) |
| 报价、刷新、稀有度权重与专属池 | [item_v5_economy.json](../../config/item_v5_economy.json) |
| 装备容量与扩容 | [gear_capacity.json](../../config/gear_capacity.json) |
| 联动条件、启用与禁用 | [item_v5_synergies.json](../../config/item_v5_synergies.json) |

编辑与生成关系见 [道具维护](../project/item_authoring.md)：authoring 文件是编辑输入，生成后的当前目录由运行读取，不能绕过生成流程手改成两套参数。对象说明中的数值跟随配置；修订规则时同步触发、限制和参数，不另建一份手写数值清单。

## 逐件迁移合同

每件选择必须记录稳定装备ID、负荷、触发、叠加/互斥、NPC升级档位、破损、周期额度、锁装与装卸副作用。同名重复掉落升级改为NPC付金币升级同一永久ID。灯/滤芯可装卸，拥有与装备状态分开，按休息区装配权限重装。旧配置仍被原型消费，本轮保留。

## 旧效果候选与适配

| 对象 | 玩家可感知的规则 |
| --- | --- |
| B06 回声小匣 | 空中主攻造成真实有效伤害后返还时间能量，同一攻击包只计一次，并受本次腾空返还上限约束；不会延长同次腾空的慢时真实时间预算 |
| N01 迟暮钟摆 | 改变空中瞄准时世界的慢速程度，不改变时间能量消耗与单次腾空预算 |
| P06 满月枪歌 | 满血空中瞄准时优先使用世界停止；玩家动作、输入和防护计时继续。仍消耗时间能量与腾空预算，实体碰撞和静态危险保留 |
| P02 共鸣整流器 | 减少主动技能的共鸣消耗，保留最低成本；不折扣时间能量或被动救命消耗 |
| P18 暮钟心契 | 首次真实装备提高生命上限并按比例转换当前生命一次，此后休息周期锁装（保留该候选时）且常规治疗无效。菜单、切图或恢复会话不会再次换血 |
| B16 裂纹钱袋 | 装备期间，休息周期限额内的首次合法击杀提供额外金币；同一目标不重复收益。累计真实生命伤害后损坏 |
| B17 裂纹强击栓 | 提高主武器基础直接伤害，累计真实生命伤害后损坏 |
| B30 易裂心匣 | 提高生命上限，累计真实生命伤害后损坏；上限来源撤销时钳制当前生命 |
| G12 错位命运骰 | 真正装备时旧随机商店刷新/稀有度效果不适用于固定库存，待逐件重做或退出首发；卸装重装或重开界面不重置免费次数 |
| G19 灰铃侍钟机 | 装备后有常驻伴机，合法精英击败提升其成长；卸装保留实例进度，伴机伤害不产共鸣。精英资格的最终选择见当前任务 |
| P17 游鸣聚能体 | 作用于有真实蓄力前摇的三级主动技能，不解除奇点固定或增加跳跃；蓄力移动速度尚未定案，按当前任务选择后同步 |

B16、B17、B30 的损坏只计实际生命损伤，护盾吸收不计；破损立即撤销效果，维修后重新启用，不回血、不重领一次性收益。损坏、裂纹和成长随实例跨图保留。护盾上限、伤害次数、维修费、倍率和等级差异均读上述配置。

## 表现

图标、名称、等级与实际效果一致，主动／被动及触发条件清楚。装备、触发、损坏和修复有可辨反馈；玩家能从动作、伤害或资源变化识别收益。联动只显示当前有效组合，缺少条件或已取消的组合维持禁用。

P17 蓄力移动与 G19 精英资格的未决选择归 [ITEM-V5-01](../project/worklines/item_v5_01/scope.md)。其余条目按稳定 ID 查询配置，代码位置与行为检查见 [模块导航](../project/module_map.md)。
