# 《失序之钟》地区创作圣经 02｜荆棘森林

**地区编号：02｜荆棘森林（Thorn Forest）**  
**地区主题：缠绕、生长、借力与回返**  
**主导能力：钩索 H｜地区结构：两张相互延续的随机连通探索地图**

## 1. 地区意象

荆棘森林是一座活着的立体迷宫。古老巨树的树根在地下盘成道路，空心树干形成可以穿越的长廊，枝冠把天空割成细碎的窗口。曾用来传递钟声的果实状索点、旧铜铃与藤桥悬挂在枝间，被藤蔓重新吞没。光穿过薄叶，在苔藓、树皮与白色荆棘上形成温柔而危险的斑驳。

森林的核心体验是**看见目的地，却需要绕树、换向、借物体和改变高度才能抵达**。初次进入时玩家像在树根间摸索；熟悉后，整棵巨树逐渐变成能够自由穿梭的运动场。

地区情绪按“林缘的安宁 → 根洞的好奇 → 荆棘的压迫 → 高冠的轻盈 → 树心的肃穆”展开。标志性意象是生于枝端的钩索果实、巨树断面、细亮的刺丛和漂浮的铃囊萤。

## 2. 视觉基调与地区资产

### 2.1 画面语言

画面保持精简、可组合的像素地形语言，但森林以**扭曲的有机轮廓**而非平原的水平草甸构图为主：粗壮根盘、竖立的树皮墙、弯曲枝台、树洞负空间以及垂挂藤蔓。大形体优先形成“可以记住的树”，小形体才用于丰富局部。

| 要素 | 地区专属设计 |
|---|---|
| 主色 | 深松绿、苔青、褪色青蓝、温暖树皮褐 |
| 高光 | 透叶的淡金日光、萤灯青绿、黄铜的柔暖反光 |
| 危险强调 | 苍白荆棘尖端、受激后的绯红脉络 |
| 固体地形 | 深褐树皮外缘、温暖木质断面、青苔根石、空心根壁 |
| 单向平台 | 细枝、断枝、菌盖、藤编小托台 |
| 动态构件 | 摆荡的铃囊、横渡活枝、移动铜铃、张合刺冠 |
| 地标 | 双叉巨树、断铃庭、树腹透光井、旋根回廊、荆冠圣所 |

### 2.2 地形 Tile 家族

**A. 苔根地基**：厚实的盘根覆盖浅苔，形成安全的宽面、低坡、地洞底盘和恢复盆地。边缘圆厚，内部有延续的年轮走向。

**B. 树皮墙体**：垂直与斜向结构，具备向上延伸的粗糙肌理、可辨识的洞口边缘和分叉接缝。大段墙面以宽轮廓和木纹方向表达高度。

**C. 断枝承台**：细长单向平台及分叉端头；断口露出浅色木芯，兼有局部苔团。宽枝提供停顿与观察，细枝承担节奏和速度转换。

**D. 空心根洞**：深色内壁、弧形洞顶、木芯断面、侧窗与通往另一个高度的内外孔；洞口负空间本身成为导航标记。

**E. 荆棘材质**：生长于根面、侧壁、洞顶、断枝端和可移动刺枝；尖刺按实际危险表面连续排列，露出的白色尖端形成清楚危险轮廓。

**F. 钩索果实与钟铃构件**：森林通行索点是生长在树根、枝梢与洞壁上的果实，具备清楚的根枝宿主、短果梗与不同用途的视觉层级。移动活锚保留生物剪影；钟铃、门锁与 Boss 专用机关使用各自的黄铜机械形态。

### 2.3 纵深与场景层

- **远景**：巨树与雾林组成高耸、彼此交错的低对比轮廓，偶尔露出遥远的旧钟塔。
- **中景**：宽阔的盘根、粗藤桥、斜穿画面的巨大枝干，持续交代树体的整体体积与空间朝向。
- **近景**：稀疏细叶、苔屑、浅雾、垂挂种荚，在宽阔观察区与高速通行区交替疏密。
- **局部光源**：枝冠透光口、树洞菌灯、铃囊萤以及 Boss 树心；不同高度保持共同的森林光色。

典型构图是：玩家站在深色树腹的内枝上，左侧荆棘遮住直行，右侧枝端的钩索果实透出一束光；远处能同时望见上层奖励和下层归路。

## 3. 空间组织与探索结构

### 3.1 两张地图的定位

| 地图 | 空间气质 | 主要探索内容 | 终点 |
|---|---|---|---|
| **图一：盘根迷径** | 宽树根、低树洞、林缘外枝；视线相对开阔 | 钩索识别、横向侧拉、短距离连续换向、活体锚点与安全回路 | 根铃守卫 |
| **图二：裂冠巨木** | 更高的树体、更密的纵向叠层、断冠与深根交织 | 钩索+反冲的长动作句、荆棘窄口、侧窗转向、跨枝生态、奖励深路 | 棘冠女王 |

两张地图各自生成完整连通网络：入口、若干地标枢纽、主线、技巧支路、深层奖励、营地以及 Boss 前集结区域。图一通过根铃守卫后进入图二；图二最终抵达巨树高冠。

### 3.2 大地图的“五层一体”

1. **根盘层**：宽阔支撑、缓行路径、营地与分岔起点。可从这里辨认多个上方去向。
2. **树腹层**：内部横洞、侧窗、上下错位的枝台与果实索点；形成第一批方向判断。
3. **外枝层**：沿树外轮廓攀行，拥有开阔视野与纵横移动空间；连接奖励和捷径。
4. **荆口层**：尖刺挤压的短促走廊、枝梢狭窗、倒挂钩点与穿刺后的接收岸。
5. **冠顶层**：大幅垂直空间、反向借力、连续动作句与 Boss 前回环。

五层不是五条平行通道。每一层都有上下互通的洞口、回落点和环路；树腹与外枝互相观察，根盘与高冠能够通过不同路径抵达。

### 3.3 关键拓扑：交织而非树状二叉

地图空间由下列拓扑关系组织；不同地图种子改变实际连接、入口和奖励位置：

- **8 字环**：两条上行路线共享中央观察枝，各自从不同高度返回；同一中央枝前后承担不同导航意义。
- **内外双环**：树腹是较稳妥路径，树外是高速钩索路径，两路交叉处提供跳转机会。
- **下降—折返环**：玩家主动下入深根洞，以侧向钩索绕回高处，从新的方向接近原先看到的宝箱。
- **双孔结构**：同一洞壁存在高低两个横孔；一条横拉，一条需要先下降再斜侧钩。
- **冠层横连**：两根巨树的不同高度枝台之间，有移动活锚与可观察的反冲替代路线。
- **营地辐射环**：营地连接下根、外枝和树腹三路；探索完成后可以从新的方向返回营地再作选择。
- **捷径闭环**：完成高技巧挑战后，开启通往已见区域的横向/下行回路，使返程发生实际缩短。

随机变化包含：巨树各区块的真实连接方式、枢纽相对高度、洞口方向、内外层入口先后、奖励所处环、果实索点相对站位、营地联通位置与怪物生态配对。每次地图依旧保留完整的地标结构，使玩家既能熟悉森林，也能遇见不同的空间解法。

### 3.4 路线层级与奖励

| 路线 | 设计意义 | 典型结构 | 回报 |
|---|---|---|---|
| 主干路 | 持续前进、逐步掌握森林语言 | 宽根观察→单钩→安全枝→换向短链→门前营地 | 进入 Boss、稳定补给 |
| 支援环 | 改变去向、找到恢复位置 | 横洞→根盘→侧枝→原中央树腹 | 营地、商人、补给 |
| 探索环 | 看见但一开始难接近的目的地 | 上层窥见宝箱→绕树进入背侧→取宝→异口下降 | 金币、道具、地图秘密 |
| 技巧路 | 用主动位移换时间、方向与风险 | 空中两钩→反向开枪→跨窄口→高枝接收 | 快捷入口、高价值奖励 |
| 深根挑战 | 较长连续动作与精确观察 | 下落→侧钩→反冲上升→多次换向→上根唇 | 高级宝箱、稀有线索 |
| 隐秘枝冠 | 留给熟练者的极限运动 | 多段无落地钩索反冲、活锚换手、空中窄缝 | 地区标志性隐藏奖励 |

所有奖励支路都体现**出发、抵达、取得、回返**的完整探索过程。高难奖励往往处于初见可望见、实际需要改变高度和方向的空间。

## 4. 钩索关卡语言

森林通过钩索塑造三类独特运动：**牵引接近、接触踢离、与反冲组合的方向重构**。钩索既用于向上，也用于向侧方、向斜下方、在窄道中借力改变运动方向。

### 4.1 基础动作词汇

| 代码 | 动作短句 | 玩家感受 | 典型空间 |
|---|---|---|---|
| H | 观察锚点→钩中→侧踢→落枝 | 第一次理解牵引与落点 | 低根宽枝 |
| HH | 连续捕捉两个错位果实索点，第二次改变行进方向 | 从单次到连贯空中移动 | 空心树腹 |
| HR | 向侧前钩→来侧踢离→向背向射击修正 | 从拉向目标改为绕过目标 | 侧墙与断枝 |
| RH | 先反冲越出遮挡→侧钩将身体拉向安全枝 | 主动创造钩索射线 | 树外横枝 |
| RHR | 反冲出洞→侧钩→反向反冲接另一岸 | 穿过锯齿状狭道 | 荆棘窄口 |
| HRH | 横向钩→反冲越过枝端→再钩另一面 | 连续借力和换边 | 分叉高枝 |
| HRHHR | 下降后侧钩，反冲抬升，双钩切换，再反冲接根唇 | 一段完整的深根舞蹈 | 深根螺旋 |
| H（活锚）R | 钩向正在移动的生物，借真实位移踢离，再用枪改变终点 | 把怪物当成临时交通工具 | 林冠跨枝 |

动作代码仅表达目标节奏；具体次数随几何、射线、容错与实际可行策略组织。

### 4.2 八种代表性关卡组合

#### F01｜初果借枝（入门）

根盘上方生长着一枚明亮的钩索果实，粗枝与果梗清楚连在树根上，旁边有宽大的接收枝。玩家先跃起，钩住果实后身体被牵引靠近，再通过侧踢落向枝面。接收枝上可以从容观察下一环。此处让玩家第一次体会“钩住”和“到达一块平台”是两个不同的动作。

#### F02｜树腹双果换向（入门—中阶）

暗色树腹内，两枚带枝梗的钩索果实分别位于不同高度和方向，中央有宽观察枝。玩家从左侧靠近第一枚，再立即向另一侧钩去，最后落到树腹内枝。两侧弧形洞壁把动作自然组织成 S 形，形成空间方向记忆。

#### F03｜荆棘侧巷（中阶）

上下布满白色尖刺，仅有一条偏水平的安全空廊。钩索果实生长在侧壁转折处，玩家先离开起手岸、侧向牵引后借踢离改变轨迹，再以背向射击推动身体进入横向窄口。通道尽头是宽枝；失败路径落回先前可见的下层根盘。此处的核心是**用钩索改变横向运动方向，而不是获得高度**。

#### F04｜双窗换位（中阶）

同一树腹墙壁上下错开两个孔。高窗可从宽枝直接横钩；低窗需要先离开檐口，随着下落改变相对高度，再斜侧钩进入右侧支撑。两个孔通向同一庭院的不同入口，第一次接近与返程都可能选不同窗口。

#### F05｜断枝反身（中高阶）

上方奖励位于断枝背侧，正面难以直接抵达。玩家先沿外枝下降，在侧面钩住果实形成斜向牵引，随后向右下射击，把反冲转为向左上的回归轨迹，穿过断枝缺口落入奖励枝。技巧线连接高处奖励，宽根路线则连接另一个可探索入口，两路在树腹汇合。

#### F06｜织网树洞（中高阶）

洞内织棘蛛周期性伸出丝线，交替遮住横道与纵向通道。玩家在观察枝辨认放线节奏，决定等待、射杀或利用侧果实索点在丝线收拢前从另一个高度穿过。蜘蛛的危险位置与环的捕捉线形成三维般的空间判断：钩头可以到达不等于身体也能通过。

#### F07｜活萤渡冠（高阶）

一只铃囊萤在两根巨枝间往复移动。玩家可以先击杀它，再通过宽根阶与普通反冲抵达对岸；也可以等待其抵近后把它作为动态钩点，借踢离与反冲落向上方宝箱枝。获取奖励后，从树冠背面下降到先前看到的第二庭院，形成新的捷径。

#### F08｜深根螺旋（高阶/隐藏）

从断冠枝台主动落入巨大空洞。玩家先在安全盆地读懂向上盘旋的枝端果实，再完成 **H→R→H→H→R** 的长连招，绕过根盘外侧、穿过树根之间的曲折空腔，最终落到高处根唇。关卡中段透过树洞能够看到终点宝箱，底部宽根盆地与上方接收枝组织完整的下降—上升节奏。上方出口通向高冠奖励枝，并通过异侧根洞回到主环，形成有目的的高技巧奖励旅程。

### 4.3 复杂挑战的节奏

完整高阶挑战通常分为：**远看目标 → 选择起手面 → 第一动作建速 → 空中方向反转 → 通过危险界面 → 接收 → 看见新的可能路线**。

不同挑战改变的变量是动作方向、锚点的移动与否、空中是否有落地节拍、目的地是否在背后、危险是否周期变化、以及回路的空间收益。主线通过中短句形成连续节奏；长链集中在深层奖励和可选择的熟练者路线。

## 5. 地图一：盘根迷径

### 5.1 典型旅程

**林缘入口 → 铃根盆地 → 双叉树腹 → 林梢与外枝环 → 断铃庭 → 根铃守卫**。

入口处枝叶舒展，宽根和少量明亮果实索点提供明确方向。铃根盆地从一侧能看见上行的树腹钩点，另一侧能看见藏在下根的补给。上行后，玩家首次遇到内外两条路线：树腹的安全回环与外枝的短连续钩索；两者在断铃庭附近交织。守卫前的宽平台可远望吊铃路线，形成战场视觉铺垫。

### 5.2 地图一的特色组合

- 根盘的 **H→安全枝→HH**，建立短句串联。
- 一条从树腹穿向外枝的 **RH** 换位支路。
- 位于巡游铃囊萤背后的可选高枝宝箱。
- 树洞内由织网周期控制的替代通道。
- 从高枝返回营地的单向安全下降与另一条可反向通过的钩索回路。
- 守卫战前的移动铜铃练习段，使战斗中的返铃反击有视觉前奏。

## 6. 地图二：裂冠巨木

### 6.1 典型旅程

**外根抵达 → 根湾交织 → 内洞 / 外冠双入口 → 北庭与树腹支路 → 荆棘侧巷 → 破枝深根 → 冠顶圣所 → 棘冠女王**。

巨树占据地图中心，玩家多次从不同层级绕过同一树体。中央的宽根营地是空间基准；抬头能看见上部圣所，下方则有深根与隐秘宝箱。越往上走，枝台越疏，果实索点的方向性越强，树内外的路径频繁交织。

### 6.2 六个宏观探索区

| 区块 | 视觉与空间 | 主要玩法 | 与其他区块关系 |
|---|---|---|---|
| 根湾 | 宽根盆地、潮湿苔壁、半埋果实根梗 | 接地短钩、观察分岔 | 可进入树腹或沿外根爬升 |
| 内洞 | 黑褐树腔、上下错孔、枝端明窗 | HH、下降侧钩、换岸 | 通向北庭与荆口；回落到根湾 |
| 北庭 | 露天枝庭、两岸高差、活萤横渡 | 动态锚点、宝箱绕行 | 与外冠、树腹、营地相连 |
| 荆口 | 洞顶白刺、横向空腔、旧环座 | HR、RHR、精确横向调向 | 接到断冠高枝与下根岔路 |
| 深根 | 螺旋形树根、竖洞、侧壁刺枝 | HRHHR长连段 | 向上接高冠，向下返回安全根盘 |
| 冠顶 | 透光断枝、稀疏支撑、摇摆高环 | 连续空中换向、高速捷径 | 连圣所，也可下降回北庭 |

### 6.3 重点关卡网络

**网络 A｜根湾—内洞—外冠 8 字环**：进入根湾后，玩家可从内洞用短 H/HH 爬升，也可从外根以 RH 绕树。两路在冠枝重汇，且内洞中途能侧向转进荆口。返程通过较低根洞回到根湾，从而形成两个方向不同的环。

**网络 B｜北庭—西奖枝—下根回环**：从北庭一眼能看见对岸奖箱。玩家利用跨枝活锚或反冲过渡到高差另一端，从奖枝后侧下降至下根回岸，再经宽根阶梯返回北庭或改走树腹。奖励实际改变路线方向。

**网络 C｜荆口双窗—破枝侧廊**：水平与下降双孔把玩家引入不同高度。侧壁果实索点与反冲构成横向换位，通向高支撑与另一处根洞出口。成功后得到通向断冠的安全枝；左下方的回落口能返回内洞观察面。

**网络 D｜断冠—深根—高冠螺旋**：断枝处玩家能看到高处遗物，但正上方被带刺的树皮与悬根分隔。主动下降进入侧洞，以五动作长句绕树根外壁上升，最后借末次反冲越过刺唇。顶部出口连接冠层捷径和独有奖励区。

**网络 E｜高冠—下层营地异路回程**：自冠枝沿可控下落串联两组挂枝果实，跨入此前远看过的树腹窗口，然后沿安全内洞返回营地。该路线在获取上方宝箱、治疗或重新选择 Boss 入口时形成回程价值。

## 7. 森林敌人生态

| 敌人 | 造型 | 行为与玩法 | 主要栖息环境 |
|---|---|---|---|
| **铃囊萤** | 透明囊腹、微亮铜铃状甲壳、短翅 | 在两枝间缓行，身体接触伤害；可击杀也可作为移动钩点，改变一次跨枝路线的落点和时机 | 外枝、林冠、横跨空谷 |
| **棘籽哨** | 根茎支架上生长的针果与眼状铃蕊 | 锁定玩家当前支撑面，抛射弧形棘籽并形成短暂落区；玩家通过换层、遮挡或抢先突破应对 | 根盘、开阔庭院、狭窗前 |
| **枝道冲锋兽** | 木甲背脊、短角、根须四足 | 预警后沿当前支撑面迅速前冲；鼓励玩家跳离平台或借上方环反向脱身 | 宽枝、根桥、纵向通道出口 |
| **织棘蛛** | 黑褐细足、银白丝囊、悬铃形腹部 | 周期伸出丝线，短暂分隔两条路线；能等待收线、从旁枝绕过或直接击杀 | 树腹、双孔、窄枝 |
| **跨枝跃行兽** | 长节后足、苔甲、盘卷尾部 | 在不同高度枝岸间以可预告的抛物线移动；其真实飞行可成为临时钩索机会 | 北庭、高枝奖励环 |

### 7.1 生态组合场景

**根盘追逐**：冲锋兽沿宽枝横扫，上方有可钩的枝端果实。玩家可击杀，也可借上方果实索点垂直换层，等冲锋结束再从另一侧进入树洞。

**冠枝换岸**：铃囊萤横渡，远侧棘籽哨锁定原支撑面。钩向活萤意味着离开即将被攻击的原岸，抵达后还能改变射击角度。

**双孔织网**：洞口蛛线交替阻挡上下入口，侧旁固定果实索点连接洞外枝。绕洞、穿隙、等待与清怪构成不同的通行节奏。

**断冠赶路**：跨枝跃行兽在高低枝台间跳跃，玩家可以观察它落岸的节奏，以它为动态锚点，或者使用预设固定果实索点继续推进。

**深根守口**：棘籽哨迫使玩家离开刚刚停稳的安全根盘，前方是需要先反冲、再侧钩的竖井；行动压力与地形动作形成一体。

## 8. Boss 一：根铃守卫

### 8.1 视觉与角色

盘根深处的旧钟院守卫，披着厚树皮与黄铜甲。胸前露出温暖树心光，巨大铜铃系于臂侧。它既像守路的古老木偶，也像被森林收养的钟楼机械。战场是宽阔的断铃庭，四周有可用的侧枝与吊环。

### 8.2 战斗核心：借铃返击

守卫抛出的巨铃是**实际移动的危险实体，也是动态钩索目标**。玩家钩中巨铃、接触踢离，使其改变运动并有机会撞回守卫，从而造成显著伤害和短暂失衡。守卫的身体与树心也持续承受普通攻击，玩家可以根据自己的路线选择连续射击、躲避或主动返铃。

| 阶段 | 攻击 | 玩家决策 |
|---|---|---|
| 第一阶段：试铃 | 吊铃抛出；身体预告后扑向玩家站位 | 读懂实体铃轨迹，换位和第一次返铃机会 |
| 第二阶段：追铃 | 铃在空中时身体也追扑旧支撑，形成双目标运动 | 选择优先躲身体、改变高度、钩铃返击或沿枝台反冲 |

### 8.3 战场空间

中央是稳定宽地，两侧有高低错层单向枝，上部四处战斗用功能环可用于空中转移。巨铃经过不同高度时形成不同的截击窗口。守卫扑击会改变其自身位置，进而改变返铃路线；地形不是背景，玩家必须不断重估相对位置。

结尾守卫铜铃碎裂，响声沿巨树根系传播；通往裂冠巨木的深根门打开。

## 9. Boss 二：棘冠女王

### 9.1 视觉与角色

女王栖于巨树断冠中的空旷圣所。身体像细长的枝干女王，背部是开放的巨大刺冠，面部有被树脂封存的铜制面具。冠刺与可剪断的发光藤结构成她的战场语言。随着战斗推进，枝冠从静态王座变成四处延伸的活网。

### 9.2 战斗核心：换岸、剪网与空中追逐

女王持续巡视战场。她根据玩家真正站过的支撑岸布置持续荆网，使已熟悉的落点在一段时间内成为新的危险。玩家可以先行换岸、射断活结、借固定战斗环飞越荆网，也可以在空中反冲调整落脚。Boss 战的真正主题是**主动改变自己与危险的空间关系**。

| 阶段 | 战场变化 | 进攻与躲避重点 |
|---|---|---|
| 第一阶段：巡冠 | 女王沿树肋间固定的多段轨迹连续巡视，每次转段有明确预告 | 观察她的移动与可站枝位置，利用侧向果实索点变换攻击角度 |
| 第二阶段：织冠 | 高处生成第一枚活结与持续荆网，女王原有巡游路径继续 | 预判换岸，钩索绕过网顶，射断活结开出移动空间 |
| 第三阶段：锁岸 | 锁定玩家最近实际站稳的枝岸，生成第二枚活结与持续荆网；女王继续巡游，玩家可选择保网、剪结或诱导锁岸 | 结合连续侧钩、反冲换岸和移动中输出完成终战 |

### 9.3 战场结构

中央有宽阔树心地面，两侧为高度不同的枝台，上部和外缘设有战斗用功能环。枝台之间具有斜向的视线联系，女王的攻击轨迹不断穿过不同层级。场地保留多个可重复使用的连续换岸路线：下地面→外侧向果实索点→高枝→反向钩→另一侧枝台。女王的活结与刺网分别作用于这些路线，使选路与输出交织。

终战时女王冠刺缓慢垂落，树心一度露出晨光；深处的钟声与林间风铃形成短暂和声。

## 11. 环境叙事与区域剧情

森林旧时是钟院的林间运输与观察站。铜环与吊铃原本帮助运送物资、传递信号；巨树在漫长的修复与遗弃中包裹了钟院建造的路径。居民仍在同一个庆典日经过林缘：一位信使反复寻找丢失的风铃，一位守林人在大树下重复记录新的发芽，一封尚未送出的信藏在潮湿树洞。

玩家通过三个层级接近真相：林缘的温暖日常、树腹中仍在工作的旧铜环装置、冠顶留下的钟院运输与实验痕迹。多次探索可以发现相同日子的不同片段；视觉细节和可选信件逐渐让森林由单纯的危险区域变成有人生活过的场所。

可识别的叙事物件包括：半埋铃牌、旧邮袋、树皮上的同日日期刻痕、残破的木桥编号、树洞里的菌灯小屋、断冠上的钟院观察台。

## 12. 音乐、音效与演出

| 场所 | 听觉设计 |
|---|---|
| 林缘与根盘 | 明亮木管、轻拨弦、远处微弱铜铃与风叶声，温暖且带探索期待 |
| 树腹与内洞 | 更近的空腔木音、柔软水滴声、间断的高处铃响；旋律渐稀，保持好奇感 |
| 荆棘与断枝 | 短弓弦拨奏与不稳定节拍，空中动作有清楚的果实索点命中、拉紧和踢离反馈 |
| 高冠 | 透亮高音木管与风铃和声，随着快速连续换向呈现舒展感 |
| 根铃守卫 | 低铜铃节拍与厚木打击，回铃命中产生高辨识度的金属回应 |
| 棘冠女王 | 细弦紧张动机与高处空灵人声质感，后段节奏加强，终结时恢复林间风声 |

森林的环境演出围绕“树会回应运动”：经过枝台会抖落少量苔屑，钩中枝端果实会使附近细铃轻响，活萤在移动时照亮局部树皮，刺网生长时有清楚的木纤维绷紧声。演出强调动态物件与路线方向感。

## 13. 六个地区标志镜头

1. **第一次看见巨树**：林缘宽根上，远方巨树占据半幅画面，枝冠间悬着青铜铃，玩家的下一条路藏在树腹光窗内。
2. **树腹 S 形飞行**：黑暗树洞里两枚枝梗果实交错，玩家在光窗之间横向换手，下方是开阔的安全根盘。
3. **荆棘横巷**：上下密刺围出的薄长通道里，玩家正借枝端果实与反冲穿过，从右上远处能看到温暖的目标枝台。
4. **北庭活萤借力**：巨大双叉树之间，移动铃囊萤成为中途支点，玩家朝另一侧有宝箱的高枝弹离。
5. **深根螺旋长连段**：玩家沿巨根外缘连续上升，果实索点像被藤蔓串起的音符，底部安全盆地与顶部发光宝箱同时入镜。
6. **棘冠女王的换岸决战**：高低错层枝台上生长活网，女王从树心上方划过，主角借外侧功能环从已被封住的旧岸跃向新的攻击角度。

---

**地区设计识别句：** 荆棘森林不是向上攀爬的钩索走廊，而是一整棵可以从根部、树腹、外枝和冠层反复穿行的巨树。玩家逐渐学会用钩索改变方向、借移动生物调整路径，并在高低交织的路线中发现宝藏与归路。
