| D001 | Godot 4.7.2 Standard、GDScript | 仓库锁定版本；旧文的“官方 Latest”声明未经可复查安装证据支持，不能作为验证结论。ENV-01 须核实官方版本、下载来源与实际二进制；指定版本不可得时记录阻塞，不擅自替换 |
| D002 | 横版左右移动，上下交互 | 用户已确定；不改自由飞行 |
| D003 | 右杆拖瞄松手射击 | 用户已确定；触屏取消与方向缓存必须验收 |
| D004 | 固定关卡先于随机 | 先验证真实动作轨迹和触屏体验 |
| D005 | 独立反冲分量、统一 Motor | 避免常规移动覆盖反冲与重复位移 |
| D006 | 首个续航机制是固定空中点 | 分离命中时机与操控难度；移动补充弹体后续接入 |
| D007 | AI 制作全部内容为目标 | 记录来源授权，保留筛选与真机验收 |
| D008 | 主分支基线、开发分支 PR | 小步可回退，当前不自动合并 |

官方来源：https://godotengine.org/ 、https://godotengine.org/download/archive/ 。后续变更追加记录并更新权威规格，不能只改代码。
