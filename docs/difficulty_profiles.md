# 地区压力与路线节奏

本页细化 [生成合同](procedural_generation.md)，为当前连通探索地图提供设计维度。数值是待校准标签，不是正式八关曲线或用户已确认平衡。

| 维度 | 观察内容 |
| --- | --- |
| P 平台 | 动作组合、落点精度、连续空中链及恢复距离 |
| C 战斗 | 威胁类型、同时攻击上限、敌人与地形的共同压力 |
| T 时机 | 可观察周期、起动窗口、移动机关和相位组合 |
| R 容错 | 安全观察点、失败回退、资源余量、学习成本及返程 |

每轴可用 0–3 的候选标签帮助筛选，但不得机械相加或相乘为总难度。两个简单模块相连仍可能不可达。高平台压力时限制同时战斗／时机压力，高战斗压力时提供可读退路和落点；实际窗口由真实动作包络和目标设备反馈决定。

主路覆盖当前合法进入构筑、清晰教学和有限恢复；进阶与大师挑战自愿进入、明确收益并能学习失败。地图需有探索分支、地标、低压观察与回环，不能仅延长高压动作链。商店／恢复与 Boss 前整备由实际地图与流程消费者决定，不承诺固定第 4／7／8 关。

校准保存地区、消费者／版本、Seed／Manifest、能力与构筑、策略、资源／相位、实际轨迹及设备。连续高压、长无决策路段、重复遭遇和回程疲劳是待解释信号，不能只凭 Hash 不同或结构标签签趣味。具体门槛须有正常例、失败反例与玩家反馈，未测留为候选。
